# むかしの田辺市を合わせよう

小学3・4年生の社会科「市のようす」（市のようすのうつりかわり）で使う教材です。
2005年5月1日に、田辺市・龍神村・中辺路町・大塔村・本宮町の5つが1つになって、いまの田辺市ができました。
むかしの5つの市町村の形をパズルで合わせて、「いまの地区は、むかしはべつべつの市町村だった」ことを発見するのがねらいです。

## 基本情報

- **ファイル**：`むかしの田辺市を合わせよう.html` と地図データ `tanabe-map-data.js` の2つで動きます（同じフォルダに置く）。ネット接続・外部ライブラリ・ログインは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「社会」から開けます。
- **対応する機器**：パソコン・タブレット・スマホ（1人1台を想定）。マウスでも指でも操作できます。

## 使い方

1. **予想**：いまの田辺市の形（1つの色）を見て、「むかしは、いくつの市町村に分かれていた？」を2〜6から選びます。★（役場）の数で答えがわからないよう、この画面では★を出していません。
2. **パズル**：左上に出てくる形を、地図の正しい場所までドラッグします。1つずつ出てきます。
   - わたしたちの地区（`?home=`）があれば、その地区から。なければ旧田辺市から。のこりはばらばらの順です。
   - ちがう地区の場所に置くと「そこは○○の場所だよ。★（役場）や川を手がかりにしよう」。3回まちがえると、正しい場所がオレンジに光ります。
3. **名前カード**：はめるたびに、「むかし → いま」の名前、役場 → 行政局、住所での名前の残り方、広さ、人口（2000年、●1こ＝1000人）が出ます。
   - 旧田辺市のカードは必ず「いまの田辺市の8分の1くらい。広さはいちばん小さかった！でも人はいちばん多い（10人に8人）」と出ます。
4. **広さメーター**：右に、できた田辺市の広さの合計（km²）が、はめるたびにふえていきます。
5. **完成**：5つそろうと1つの色になり「2005年5月1日 新しい田辺市」。予想とくらべます。「むかしの田辺市は5つのうちの1つ。5つがいっしょに新しい田辺市になった」と説明します。
6. **まとめ**：穴うめ文を選んで完成させます。
   「田辺市は、［2005］年に、［5］つの市町村が1つになってできた。わたしの地区（○○）は、2005年までは、［田辺市とはべつの町や村だった］。」
   - 旧田辺市の子は「［5つのうちの1つだった］」が正解（「まわりの町や村をとりこんだ」はまちがい）。
7. **ふりかえり**：「ほかの地区について、わかったことは？」と、お家の人に「むかしの○○のころ」を聞く宿題の声かけ。

### むずかしさ

| むずかしさ | 内容 |
|---|---|
| かんたん | 形に、むかしの市町村の名前がついている |
| ふつう | 形だけ。★（役場）と川を手がかりに考える |

- 「境界線」を消すと、地図に点線の境目がなくなり、田辺市の形だけになります（早く終わった子のチャレンジ）。

### ねらっているつまずき

| 型 | 中身 | アプリでの手だて |
|---|---|---|
| ただの町名型 | 地区名を、市の中の小さな町名だと思う | 「龍神**村**」「本宮**町**」と村・町までつけ、役場があって自分たちで決めていたことを名前カードで伝える |
| 田辺がのみこんだ型 | 旧田辺市がほかの村をとりこんだと思う | 旧田辺市はいちばん小さいことをメーターとカードで見せ、完成画面・まとめの文で「5つがいっしょに」を確かめる |
| 山の地区いれかわり型 | 龍神・中辺路・大塔・本宮の位置がまざる | まちがえた場所の地区名と、★・川を手がかりにする声かけ |

## 先生モード（`?teacher=1`）

- わたしたちの地区をえらぶと、子ども用のリンク（`?home=○○&level=○○`）が作れます。地区は `tanabe`・`ryujin`・`nakahechi`・`oto`・`hongu`。
- 5市町村の一覧（郡・役場・いまの住所・行政局・広さ・人口）と出典。
- 印刷用の白地図（A4たて）：5つの形と★・川だけ。名前と、まとめの文は子どもが書きます。

## データ

| むかし | 役場 → いま | いまの住所 | 広さ | 人口（2000年） |
|---|---|---|---|---|
| 田辺市 | 田辺市役所 | 田辺市○○（そのまま） | 136km² | 70,360人 |
| 日高郡 龍神村 | 龍神行政局 | 田辺市龍神村○○ | 256km² | 4,461人 |
| 西牟婁郡 中辺路町 | 中辺路行政局 | 田辺市中辺路町○○ | 212km² | 3,710人 |
| 西牟婁郡 大塔村 | 大塔行政局 | 田辺市鮎川・合川など（「大塔村」は住所に残らない） | 219km² | 3,246人 |
| 東牟婁郡 本宮町 | 本宮行政局 | 田辺市本宮町○○ | 205km² | 3,869人 |

- 広さは地図データから計算した値です（合計 1028km²。田辺市の公式の面積は約1027km²）。
- 人口：2000年国勢調査（合併前の最後の国勢調査、和歌山県の統計表）。
- 住所：和歌山県「市町村合併に伴う住所表記の概要」。
- 地図：国土交通省「国土数値情報」の行政区域（2000年・2024年）と河川データを加工（`tanabe-map-data.js`、作り直しは `tools/build-tanabe-map.py`）。

## 授業での使い方の例（20分）

1. 導入（5分）：先生モードで電子黒板に予想の画面を映し、「むかしはいくつ？」を全員で予想。
2. 1人1台（15分）：パズル → 名前カード → 完成 → まとめの文。早い子は境界線を消してもう一回。
3. 後半：お家の人に「むかしの村や町のころのこと」を聞く計画を立てる。
