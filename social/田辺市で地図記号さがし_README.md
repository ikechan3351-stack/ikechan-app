# 田辺市で地図記号さがし

小学3・4年生の社会科「市のようす」で使う教材です。
「温泉はどこ？」のように出題された地図記号を、田辺市の本物の地図の中から見つけてタップします。
「自分の知っている場所も、地図では記号で表されている」ことに気づくのがねらいです。

## 基本情報

- **ファイル**：`田辺市で地図記号さがし.html`、地図データ `tanabe-map-data.js`、記号データ `tanabe-symbols-data.js` の3つで動きます（同じフォルダに置く）。ネット接続・外部ライブラリ・ログインは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「社会」から開けます。
- **対応する機器**：パソコン・タブレット・スマホ（1人1台を想定）。

## 使い方

1. むずかしさと地区をえらんで「スタート」。1回10問です。
2. 上に出た記号を、地図の中からさがしてタップします。
   - 指2本で広げる・＋ボタン・マウスのホイールで大きくできます。指1本で動かせます。「もどす」で地区ぜんたいにもどります。
   - さがしている間は、地図に名前は出ません（文字を読んで当てないように）。
3. 見つけると、本物の名前（ふりがなつき）と「ここに行ったことはあるかな？」が出ます。同じ記号のほかの場所も光ります。
4. 10問おわると「ふりかえり」。1回で見つけた数、まちがえた記号、見つけた場所が出ます。

### むずかしさ

| むずかしさ | 内容 |
|---|---|
| かんたん | まず記号を3つからえらぶ（にた記号が必ず入る）→ 地図でさがす |
| ふつう | 名前だけを見て、地図でさがす |
| チャレンジ | 田辺市ぜんたいから、ありそうな地区もえらんでさがす（記号のない地区をえらぶと教えてくれる） |

### まちがえたとき

- タップした記号の名前を教えて、1秒間はタップできません（でたらめに押して当てるのをふせぐため）。
- にた記号をまちがえたときは、ちがいを声かけします（小中学校と高校、市役所と町村役場、交番と警察署、神社と寺、郵便局と病院、図書館と博物館）。
- 「ヒント」ボタンで、あたりを円でしめします（2回目は小さい円）。

## 先生モード

アドレスの最後に `?teacher=1` をつけて開きます。

- **出題する記号のしぼり込み**（例：今日は学校と郵便局だけ）。
- **子ども用のリンク**：今のむずかしさ・地区・記号の設定が入ったリンクをコピーして、ロイロなどで配れます（例：`?level=normal&area=tanabe&kinds=school,post`）。
- **記号リスト**：地区ごとの記号の一覧。名前をタップすると、地図のその場所に名前が出ます。位置や閉校の確認に使います。

## 記号データ

- 15種類・185か所（旧田辺市112・龍神村26・本宮町23・中辺路町13・旧大塔村11）。記号の絵は「地図記号クイズ」と同じです。
- 国土交通省「国土数値情報」（学校2021年・郵便局2013年・医療機関2020年・警察署2012年・消防署2012年・文化施設2013年・福祉施設2021年・市区町村役場2014年）を加工しました。
- 神社・寺・温泉と博物館の一部は OpenStreetMap（© OpenStreetMap contributors, ODbL）から取りました。山の地区の神社・寺は少なめです。
- 交番の記号には駐在所もふくめています。町・村役場は行政局（もとの村や町の役場）です。病院は「病院」だけで、診療所は入れていません。老人ホームは特別養護老人ホームです。
- ふりがなは自動で付けたあと、地名の読みを手で直しました。まちがいがあれば `tools/build-tanabe-symbols.py` の `READ`・`NAME_READ` を直して作り直します。
- データの作り直しは `tools/build-tanabe-symbols.py` で行います（使い方はファイルの先頭に書いてあります）。
