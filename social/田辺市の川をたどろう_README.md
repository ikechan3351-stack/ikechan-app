# 田辺市の川をたどろう

小学3・4年生の社会科「市のようす」で使う教材です。
田辺市を流れる6本の川を、上流（山）から下流（海）まで指でなぞり、どの地区・町を通って、どこの海へ出るかを確かめます。**川は地区や町をつないでいること**、そして**田辺市の大きな川のほとんどは、田辺市ではない町の海へ出ること**（田辺湾に出るのは会津川と芳養川だけ）に気づくのがねらいです。

## 基本情報

- **ファイル**：`田辺市の川をたどろう.html`、地図データ `tanabe-map-data.js`、川のデータ `tanabe-rivers-data.js` の3つで動きます（同じフォルダに置く）。ネット接続・外部ライブラリ・ログインは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「社会」から開けます。
- **対応する機器**：タブレット横向き（1人1台）と電子黒板を想定。マウスでもなぞれます。

## 使い方

1. むずかしさをえらんで「スタート」。
2. **川をえらぶ**：はじめは「芳養川」（短くて、田辺湾に出る）がおすすめです。
3. **予想**：田辺市の外は雲でかくれています。青い線（田辺市の中の川）が、どちらの向きに市を出ていくかを手がかりに、海の🌊をタップして旗を立てます。
4. **なぞる**：上流の●から、指で川をなぞります。指が川の近くにあれば、水は川にそって進みます（上流へはもどりません。指をはなしても●から続きができます）。
   - 地区・町の境をこえると「○○に入ったよ」と出て、右の「通ったところ」にたまります。
   - 支流が合流すると「○○川が合流。水がふえたよ」と出て、水の線が少し太くなります。
   - 田辺市を出ると雲が晴れ、川の続きが見えます。
5. **河口に着いた**：予想とくらべます。はずれても「×」は出しません。田辺湾に旗を立てていたら「田辺市の海じゃなかった！」と、田辺市を出た所を光らせます。そのあと、通ったところのことばをタップして「○○川は（　）の山から流れ、（　）を通って、（　）の海へ出る。」の文をつくります。
6. **なかま分け**（2本以上たどると出ます）：たどった川を「田辺市の海に出る川／ほかの町の海に出る川」に分けます。川をタップしてから箱をタップ。
7. **どうしてかな？**：「田辺市で海に面している地区は？」と聞き、地図をタップして答えます。旧田辺市だけが海に面していて、山が広いから、川は谷にそってとなりの町の海へ流れる、とまとめます。
8. **ふりかえり**：たどった川の文の一覧と、「上流の龍神村でごみを川にすてたら、どこの海がよごれる？」の問い。

## 先生モード

アドレスの最後に `?teacher=1` をつけて開きます。

- **たどる川**：見せる川と順番をえらびます（おした順にならびます）。電子黒板の見本は芳養川がおすすめ。日高川・熊野川は、子どもが自分で見つけるようにとっておくと、おどろきが大きくなります。
- **わたしたちの地区**：学校のある地区をえらぶと、その地区を流れる川に🏠がつき、ふりかえりで「○○を流れる△△川は、□□の海に出る」と出ます。
- **子ども用のリンク**：むずかしさ・川・地区が入ったリンク（例：`?level=normal&rivers=haya,tonda,hidaka&home=ryujin`）。
- **印刷用の白地図**：田辺市の地区・となりの町・海岸線と、6本の川（線）の地図（A4たて）。子どもが川を色でなぞり、河口に海の名前を書きます。
- **川の一覧**：通る地区・町（上流から）・合流する支流・出る海。

## 6本の川（アプリの地図で判定したもの）

| 川 | 通る地区・町（上流から） | 出る海 |
|---|---|---|
| 芳養川 | 旧田辺市 | 田辺市の海（田辺湾） |
| 会津川 | 旧田辺市（上流は右会津川。左会津川が合流） | 田辺市の海（田辺湾） |
| 富田川 | 中辺路町 → 旧大塔村 → 上富田町 → 白浜町 | 白浜町の海（富田） |
| 日置川 | 中辺路町 → 旧大塔村 → 白浜町 | 白浜町の海（日置） |
| 日高川 | 龍神村 → 日高川町 → 御坊市 | 御坊市の海 |
| 熊野川 | 十津川村（奈良県）→ 本宮町 → 新宮市 | 新宮市の海 |

- 熊野川は、奈良県では「十津川」とよばれます。アプリでは十津川村の一部から始めています。
- 予想の旗の候補は、上の5つの海に「みなべ町の海」「すさみ町の海」を足した7か所です。

## 川のデータ

- `tanabe-rivers-data.js` は、国土交通省「国土数値情報」の河川データ（和歌山県・奈良県 2009年、三重県 2008年）から、6本の**本流**（いちばん長い流れ）を上流 → 河口の1本の線にしたものです。通る地区・町は、川の線と地区・市町村の形から判定しています。
- 三重県の形は行政区域データを使っていないので、熊野川と海岸のだいたいの形です（地図のはしだけ）。
- 作り直すときは `tools/build-tanabe-rivers.py` を使います（元データのフォルダ・`tanabe-map-data.js`・出力先を指定）。支流の名前は、ふりがなを確かめられたものだけ「合流」として出しています（スクリプトの `TRIB_KANA`）。
