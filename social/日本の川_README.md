# 日本の川

中学1年の地理（日本の地域的特色「自然環境」）で使う、日本の川の学習アプリです。
日本の川の特色（短く、流れが急で、季節による流量の変化が大きい）、川がつくる地形（扇状地・三角州・河岸段丘）、川とくらし・防災を、4つのモードで学びます。

## 基本情報

- **ファイル**：`日本の川.html` と、和歌山の川の地図データ `wakayama-rivers-data.js` の2つで動きます（同じフォルダに置く）。ネット接続（最初の読みこみと、ハザードマップのリンク以外）・外部ライブラリ・ログインは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「社会」から開けます。
- **対応する機器**：パソコン・タブレット（Chromebook・iPad）・スマホ。
- **ふりがな**：右上の「ふりがな」ボタンで、川の名前・県名・用語にふりがなを出せます（選んだ状態はブラウザに保存）。

## 5つのモード

| モード | 内容 |
|---|---|
| 🗾 川マップ図鑑 | 17本の川を地図に表示。タップすると拡大し、長さ・流域面積（日本での順位）・流れる都道府県・特色・くらしと防災が出る。流れる都道府県は地図で色がつき、白い点の動きで流れる向きがわかる。最初の画面は長さ・流域面積のくらべ |
| 📈 くらべてグラフ | 「河口からのきょり」と「高さ」のグラフ（日本と世界の川の縦断面）。日本6本・世界6本をボタンで出し入れ。「日本の川に合わせる（0〜400km）」「世界の川まで（0〜7,000km）」の切りかえ。「1kmで平均何m下がるか」の棒グラフつき |
| 🏠 和歌山・田辺市の川（図鑑の切りかえ） | 和歌山県の市町村の地図に、田辺市を流れる5本（会津川・富田川・日置川・日高川・熊野川）と、紀の川・有田川・古座川・ぶつぶつ川を表示。一級河川・二級河川の区別、長さ・流域面積・流れる市町村・特色・くらしと防災。全国の地図には田辺市の印 |
| ⛰️ 地形シミュレーション | 扇状地と三角州：水を流すと、石や砂利が谷の出口にたまって扇状地、細かい砂や泥が河口にたまって三角州ができる（けずる→扇状地→三角州→土地の使われ方の5場面）。河岸段丘：「土地がもり上がる」を3回おすと段丘ができ、土地の使われ方も見られる |
| 🌧️ 防災 | ハザードマップとは・洪水の水の深さの色・地形と水害の関係・和歌山県の大きな水害（1953年紀州大水害、2011年紀伊半島大水害）・調べる手順。国土地理院の「重ねるハザードマップ」（田辺市のまわり）と「わがまちハザードマップ」へのリンク。図鑑の各川にも、その川の下流を中心に重ねるハザードマップを開くボタンがある |
| ❓ クイズ | 地図で川あて（名前をえらぶ・地図をタップ）、地形あて（図を見て答える）、テスト対策（20問から）、和歌山・田辺の川（和歌山県の地図で川あて＋地元の問題10問から）、ミックス。各10問。正答率とさいこう点をブラウザに記録 |

## データについて

- 長さ・流域面積は国土交通省の一級河川の資料の値（四万十川・紀の川・熊野川・常願寺川は国土交通省のページで確認）。木曽川の流域面積は木曽川水系（9,100km²）の値。
- 地図は Geolonia japanese-prefectures（工業地帯マップと同じもの）。川の線は、おもな地点の経度・緯度を地図の座標に直してむすんだ**おおよその流れ**。地図のくせで少しずれる川は、`off`（ずらす量）で補正している。北海道は地図上で大きさがちがうので別の式を使う。
- くらべてグラフの線は、おもな地点の高さからえがいた**おおよその形**（教科書の縦断面図と同じ見せ方）。
- 流量の変化は、正確な数値がそろわないため、数値を出さずに説明文であつかっている。

## 先生モード

アドレスの最後に `?teacher=1` をつけて開きます（例：`日本の川.html?teacher=1`）。

- 電子黒板向けに、文字・地図・クイズの図が大きくなり、下の「つかい方」は表示しません。
- クイズは、選んでもすぐに答え合わせをせず、**「👀 答えを見せる」**をおすと正解と説明が出ます（地図の問題は、タップした川が青く光る）。みんなで考えてから答えを見せる使い方です。
- 正答率は記録しません。
