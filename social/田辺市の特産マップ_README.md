# 田辺市の特産マップ

小学3・4年生の社会科「市のようす」で使う教材です。
梅・備長炭・鮎・木材などの特産物を、とれると思う地区に置いて予想し、品物ごとに答え合わせをします。最後に土地の高さの色をかさねて、品物を「海・海に近い低い山のしゃ面・川・深い山」になかま分けし、**地区ごとに特産がちがうわけを、土地のようすから考える**のがねらいです。

## 基本情報

- **ファイル**：`田辺市の特産マップ.html`、地図データ `tanabe-map-data.js`、地形データ `tanabe-terrain-data.js` の3つで動きます（同じフォルダに置く）。ネット接続・外部ライブラリ・ログインは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「社会」から開けます。
- **対応する機器**：タブレット横向き（1人1台）と電子黒板を想定。スマホでも動きますが、カードが地図の下に来るのでドラッグしにくいです。

## 使い方

1. むずかしさをえらんで「スタート」。
2. **地区のようすを見る**：5つの地区をタップすると、土地のようす（海に面している、山が深い、どの川が流れるか、平均の高さ）が出ます。品物の名前は出しません。5つとも見ると、品物のカードが出ます。
3. **予想して置く**：カードを地図の地区までドラッグします。1つの品物を、いくつの地区に置いてもかまいません（何枚でも出てくるスタンプ方式）。置いた品物をタップすると取り消せます。すべての品物を1か所以上に置くと「答え合わせ」がおせます。
4. **答え合わせ**：品物ごとにボタンを押すと、本当にとれる地区が光ります（◎とてもさかん／○とれる）。予想とくらべて「あたり・見のがし（点線）・ちがった（×）」が出て、品物のひとこと説明が読めます。電子黒板では、先生がこのボタンを押して1つずつ進めます。
5. **なかま分け**：地図に土地の高さの色（緑＝低い → 茶色＝高い）がかさなり、本当の産地がならびます。品物を4つの箱にドラッグして分けます。分けると、その箱の品物と土地が地図で光ります（海なら海、低い山のしゃ面なら緑の土地、川なら川、深い山なら茶色の土地）。箱を押すと何度でも見られます。
6. **ふりかえり**：あたった数と、「（　）地区は（　　）なので、（　　）がさかん」のまとめの文。ノートや白地図に書きます。

### むずかしさ

| むずかしさ | 品物 |
|---|---|
| かんたん | 魚・ひもの、梅、鮎、木材、備長炭（5つ） |
| ふつう | かんたん＋みかん、しいたけ・ゆず、お茶（8つ） |

### わたしたちの地区（うちの地区だけ型）

子どもは、よく知っている自分の地区に品物を集めがちです。`?home=` で学校の地区を決めておくと、自分の地区に置いた品物が実はあまりとれないとき、「×」ではなく「○○地区でも見たことがあるんだね。でも、いちばんたくさん作っているのは△△。どうしてかな？」と声をかけます。ふりかえりでも、自分の地区にかたよっていたらひとこと出ます。

## 先生モード

アドレスの最後に `?teacher=1` をつけて開きます。

- **わたしたちの地区**：学校のある地区をえらびます（もう一度押すと解除）。
- **子ども用のリンク**：むずかしさと地区が入ったリンクをコピーして、ロイロなどで配れます（例：`?level=normal&home=tanabe`）。
- **印刷用の白地図**：地区の形と川だけの地図（A4たて）。地区の名前と特産物を子どもが書き、まとめの文を2つ書きます。
- **産地の一覧**：品物×地区の ◎○ と、なかま分けの箱、出典。

## 地図と地形のデータ

- 地区の形・川は `tanabe-map-data.js`（田辺市マップなどと共用）。
- 土地の高さの色は `tanabe-terrain-data.js`。国土交通省「国土数値情報」の標高・傾斜度4次メッシュ（約500mごと、2011年）を加工し、100m・300m・600m・1000m で色を分けています。作り直すときは `tools/build-tanabe-terrain.py` を使います。
- 地区ごとの平均の高さ（地区のようすに出る数）：旧田辺市 約192m、龍神村 約630m、中辺路町 約454m、旧大塔村 約467m、本宮町 約388m。
