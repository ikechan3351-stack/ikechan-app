# 田辺市マップ

小学3・4年生の社会科（市のようす・県のようす）で使う、田辺市の地図です。
田辺市全体の地図から、5つの地区（旧田辺市・龍神村・中辺路町・旧大塔村・本宮町）の拡大地図に切りかえられます。
これから作る田辺市の教材の「土台の地図」として作った試作版です。

## 基本情報

- **ファイル**：`田辺市マップ.html` と地図データ `tanabe-map-data.js` の2つで動きます（同じフォルダに置く）。ネット接続・外部ライブラリ・ログインは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「社会」から開けます。
- **対応する機器**：パソコン・タブレット・スマホ。

## 使い方

- 地図の色のところか、上のボタンをタップすると、その地区が大きくなります。「← 田辺市ぜんたい」で全体にもどります。
- 拡大すると、小さい川や目印の名前も出ます。右のパネルに、地区の名前・広さ・ひとこと・目印が出ます。目印をタップすると、地図のその場所が光ります。
- 「川」「目印」「ふりがな」の表示を切りかえられます。方位記号（北）と縮尺（ものさし）はいつも表示されます。
- アドレスの最後に `#tanabe` `#ryujin` `#nakahechi` `#oto` `#hongu` をつけると、最初からその地区の拡大地図で開きます（ほかの教材からリンクするとき用）。

## 5つの地区

| 地区 | 広さ（やく） | ようす |
|---|---|---|
| 旧田辺市 | 136 km² | 海に面した市の中心。市役所・駅 |
| 龍神村 | 256 km² | 北の山の中。日高川・龍神温泉・護摩壇山 |
| 中辺路町 | 212 km² | 富田川ぞい。熊野古道（中辺路） |
| 旧大塔村 | 219 km² | 日置川ぞい。百間山 |
| 本宮町 | 205 km² | 熊野川ぞい。熊野本宮大社・湯の峰温泉・川湯温泉 |

- 2005年に、この5つの市町村が合併して今の田辺市（やく1,027 km²、和歌山県でいちばん広い市）になりました。

## 地図データ

- 国土交通省「国土数値情報」の行政区域データ（2000年・2024年）と河川データを加工して作成しました。地区の形は、2000年（合併前）の境界を今の田辺市の形で切り取ったものです。
- 目印の位置は国土地理院の住所検索で調べました。行政局は地区（大字）の中心の位置なので、建物の場所とは少しずれます。行政局には町・村役場の記号（○）を使っています。
- データの作り直しは `tools/build-tanabe-map.py` で行います。ほかの教材でこの地図を使うときは、`<script src="tanabe-map-data.js">` で読みこむと `TANABE_MAP` が使えます。
