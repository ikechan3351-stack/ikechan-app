# 和歌山県 市町村パズル

小学4年生の社会科「県のようす」で使う、和歌山県の30市町村のパズルです。
市町村の形を地図までドラッグしてはめ、和歌山県の地図を完成させます。
完成した地方は「むかしとくらべる」で、平成の大合併の前（2000年）の50市町村と見くらべられます。

## 基本情報

- **ファイル**：`和歌山県市町村パズル.html` 1つだけで動きます。ネット接続・外部ライブラリ・ログインは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「社会」から開けます。
- **対応する機器**：パソコン・タブレット（横向き 1024×768 が基準）・スマホ。マウスでも指でも操作できます。
- **先生モード**：アドレスの最後に `?teacher=1` をつけると、パズルをとばして最初から「むかしとくらべる」が開き、全部の地方を見くらべられます（電子黒板で全体に見せるとき用）。

## あそび方

### パズル
- 左に出てくる市町村の形を、地図の正しい場所までドラッグします。近くに置くとはまります。
- はまった市町村は、郡ごとの色にぬられ、名前と「ようす（海ぞい・山の中・川など）」の一言が出ます。
- 3回まちがえると、正しい場所がオレンジ色に光ります。
- にた名前の市町村（有田市と有田川町、日高町と日高川町、紀の川市と紀美野町、白浜町と上富田町・美浜町）の場所に置いてしまうと、ちがいを説明する声かけが出ます。
- 「全部・紀北・紀中・紀南」でしぼり込めます。「境界線」を消すと、県の形だけになってむずかしくなります。「川」で主な川7本（紀の川・有田川・日高川・富田川・日置川・古座川・熊野川）の表示を切りかえます。

### むかしとくらべる
- パズルで完成させた地方から、くらべられるようになります（その端末に記録されます）。
- 色のついた市町が、合併してできたところ（12）。しま模様が、合併しなかった市町村です。
- 合併した市町をタップ →「むかし いくつの町村だった？」を2〜6から予想 → むかしの町村が1つずつ黄色く光り、名前と合併した年が出ます。
- 黄色の町村をタップすると、その地名が今どこに残っているかが出ます。
- 「むかしの境界をぜんぶ重ねる」で、全部の市町に、むかしの境界線（白い点線）を重ねます。

## 地図データ

- 国土交通省「国土数値情報」の行政区域データ（2000年10月1日・2024年1月1日）と河川データを加工して作成しました。
- 小さな島は省き、線はかんたんにしています。
- むかしの町村の形は、2000年の境界を今の市町の形で切り取ったものです。

## 授業での使い方の例（1時間）

1. 導入（15分）：1人1台でパズル（紀北 → 全部）。なれた子は境界線を消してチャレンジ。
2. 後半：先生モードで電子黒板に「むかしとくらべる」を映し、「田辺市はむかしいくつの町村だった？」を予想 → 確かめる、を全体で。
3. 「合併したのは、海に面した町と山の中の村、どちらが多いかな？」を話し合う。
