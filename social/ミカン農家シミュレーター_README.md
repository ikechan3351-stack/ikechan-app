# ミカン農家シミュレーター

小学3・4年生の社会科「地域の産業（農家の仕事）」で使う、学習用のシミュレーションです。
和歌山県のミカン農家になって、春・夏・秋・冬の1年間、ミカンをそだてます。
季節・天気・農作業と、ミカンのでき（とれた箱の数・あまさ）の関係を、ためしながら考えられます。

> **注意**：じっさいの農業をとてもかんたんにした「学習用のモデル」です。じっさいの収穫量を予想するアプリではありません。このことは、アプリの画面にも表示しています。

## 基本情報

- **ファイル**：`ミカン農家シミュレーター.html` 1つだけで動きます。ネット接続・外部ライブラリ・ログインは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「社会」から開けます。
- **対応する機器**：パソコン・タブレット・スマホ（画面のはばに合わせて並びがかわります）。

## 起動のしかた

- **公開ページから**：トップページの「社会」→「ミカン農家シミュレーター」をおします。
- **パソコンの中のファイルから**：`ミカン農家シミュレーター.html` をダブルクリックしてブラウザで開きます。
  - ブラウザによっては、ファイルを直接開くと記録（ふりかえりの表）が保存されないことがあります。そのときは公開ページを使ってください。

## 画面

| 画面 | 内容 |
|---|---|
| ① タイトル | 学習用モデルであることの注意、あそびかた、「はじめる」「これまでの記録を見る」 |
| ② ミカン畑 | 季節（春夏秋冬）の表示、その季節の天気、木の絵（花・青い実・オレンジの実・草・土のかわき）、5つのメーター、しごとのボタン、できごとのメッセージ。下の「❓そうさのしかた」で、操作としごとの説明が出ます |
| ③ 1年間の結果 | とれたミカンの箱の数、あまさ（★1〜5）、おいしいミカンポイント（箱の数×★）、来年への木の元気。「なぜ、こうなったのかな？」で、結果の理由を短い文で表示。季節ごとの天気とやったしごとの表 |
| ④ ふりかえり | 気づいたことを書いて記録する欄、これまでの記録（10回分）をならべた表、「同じ天気でもう一度」「ちがう天気でもう一度」 |

## しくみ（学習用モデル）

### 1つの季節の流れ

1. 季節のはじめに、天気が決まる（土の水分がかわる）。草がのびる。
2. しごとを **2つまで** えらぶ。ボタンをおすと、すぐにメーターがかわる。
3. 「つぎの季節へ」をおすと、畑のようす（草・水）が、木や実に えいきょうする。

### メーター（0〜100）

| メーター | 意味 |
|---|---|
| 🌳 木の元気 | 高いほど花がたくさんさき、実がよくそだつ |
| 🌿 草の量 | 60以上になると、木の水とえいようをとって、木の元気がへる |
| 💧 土の水分 | 25より下だと木が弱り、夏・秋は実が落ちる。秋は40以下だとあまくなり、80以上だと水っぽくなる |
| 🍊 実の数 | 春のおわりに、木の元気で決まる。60より多いと、1つ1つが小さく、あまさがへる |
| 🍯 あまさ | 収穫したときの★の数になる |

### しごと

| しごと | よい時期 | 内容 |
|---|---|---|
| 💧 水やり | 日でりのとき | 土の水分が上がる。土がしめっているときは ひつようない。秋にやりすぎると あまさがへる |
| 🌿 草とり | 夏 | 草がへる |
| ✂️ 枝の手入れ（せん定） | 春・冬 | 木が元気になる。春は実もあまくなる。夏・秋はこうかが小さい |
| 🧪 ひりょう | 春・冬 | 木が元気になる。秋（収穫前）にあげると、あまさがへる |
| ✋ 実をへらす（摘果） | 夏 | 実の数がへるが、あまくなる。秋はこうかが小さい |
| 🧺 収穫 | 秋・冬 | その季節のおわりにミカンをとる。冬は木の上でじゅくして あまくなるが、寒波がくると実がいたむ。冬までに収穫しないと、とれない |

### 天気

| 季節 | 出る天気 |
|---|---|
| 春 | 晴れ・雨・おそ霜（花がいたみ、実がへる） |
| 夏 | 晴れ・日でり・大雨・台風（実が落ちる） |
| 秋 | 晴れ・雨・台風（実が落ちる） |
| 冬 | 晴れ・寒波（木にのこった実がいたむ） |

天気はランダムに決まります。**「同じ天気でもう一度」をえらぶと、前の回と同じ天気になります**。天気を同じにすると、しごとのちがいだけで結果を比べられます。

## 授業での使い方（例）

1. **導入（5分）**：タイトル画面の「あそびかた」を全体で読む。「ミカン農家さんは、1年間どんな仕事をしているのかな？」と問いかける。
2. **1回目（10分）**：まずは自由にやってみる。結果画面の「なぜ、こうなったのかな？」を読む。
3. **2回目以降（15分）**：「🔁 同じ天気でもう一度」で、しごとを1つか2つだけ変えてためす。ふりかえり画面の表で、前の回と比べる。
4. **まとめ（10分）**：「気づいたこと」を発表し合う。
   - 「夏に草とりをしないと、木が弱る」
   - 「実をへらすと、数はへるけど、あまくなる」
   - 「台風や寒波は、人の力ではふせげないこともある」
   - 「冬のしごとは、来年のミカンのため」
   このあと、教科書や資料で、じっさいの農家の工夫（防風ネット・マルチ・スプリンクラーなど）と比べると、モデルとのちがいにも気づけます。

## 記録について

- 結果と「気づいたこと」は、その端末（タブレット・パソコン）のブラウザの中だけに保存されます（新しい順に10回分）。ほかの人には見えません。
- 「記録をぜんぶ消す」で消せます。ブラウザのデータを消したときや、共有の端末を初期化したときも消えます。
- 保存できない環境でも、ページを開いているあいだは表で比べられます。

## じっさいとのちがい

- 季節ごとに「しごと2つまで」としているのは、時間や人手にかぎりがあることを表すための、ゲームのきまりです。
- 収穫の時期・せん定・摘果・ひりょうの時期は、和歌山県の温州ミカンづくりを参考に、かんたんにしています。じっさいは品種によって収穫の時期がちがいます。
- 箱の数・あまさの数字は、ゲームの中だけの目安です。
