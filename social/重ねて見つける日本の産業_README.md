# 重ねて見つける日本の産業

中学1年の地理（日本の地域的特色「日本の産業」）で使う学習アプリです。
産地が「どこで何」の丸暗記になるのをふせぐため、地図を**重ねて**「なぜここで？」の理由（自然環境・交通網・大都市など他地域との関係）を見つけます。
「工場の場所は昔からそこ」という思いこみ（「昔からそう」型のつまずき）を、時代スライダーで工場の移り変わりを見て直し、産業の空洞化などの課題につなげます。

最小版（工場はどこへ？＋なぜここで？の農業4つ）に、「ふつう」「チャレンジ」の産地・和歌山でためす・理由クイズを足しました。

## 基本情報

- **ファイル**：`重ねて見つける日本の産業.html` と、和歌山県の市町村の地図データ `wakayama-rivers-data.js`（日本の川と共通）の2つで動きます（同じフォルダに置く）。ネット接続・外部ライブラリ・ログインは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「社会」から開けます。
- **対応する機器**：パソコン・タブレット（Chromebook・iPad）・スマホ。電子黒板でみんなで使うのが中心です。
- **ふりがな**：右上の「ふりがな」ボタンで、用語にふりがなを出せます（選んだ状態はブラウザに保存）。
- **記録**：理由クイズの正答率とさいこう点だけ、ブラウザに記録します（先生モードでは記録しない）。書く欄はありません（考えはノートやロイロに書く）。
- **企画メモ**：`~/Documents/脳メモ/教材開発/企画/2026-11-02_重ねて見つける日本の産業.md`

## 4つのモード

| モード | 内容 |
|---|---|
| 🏭 工場はどこへ？ | 時代のスライダー（1960年→1980年→2000年→2020年）を動かすと、その時代にできた代表的な工場が黄色く光ってふえる。「⚓ 港」「🛣️ 高速道路（その時代までに全線開通した主な道路）」「✈️ 空港」を重ねて、工場と何が重なるかを見つける。「🎨 2020年の工業」で、今の工業のさかんな県（太平洋ベルト）も重ねられる。「🤔 次の時代を予想する」で予想してから進む。2000年からは「🌏 海外へ」の矢印。2020年で「⚠️ 条件が変わると？」（産業の空洞化、国内に工場をつくる動き） |
| 🔍 なぜここで？ | 産地を3段階でえらぶ（かんたん：近郊農業・促成栽培・抑制栽培・畜産／ふつう：稲作・果樹栽培・漁業／チャレンジ：情報通信業・観光業）。「❄️ 冬の気温」「☀️ 夏のすずしさ（高原）」「⛰️ 土地のようす」「🌊 海流・潮目」「🛣️ 高速道路・フェリー・空港」「🏙️ 大都市からのきょり」「👥 人口が多いところ」「📅 東京に出荷する月」を重ねて、理由を「自然環境／交通網／大都市など他地域との関係」から**すべて**えらぶ。重ねて見た地図の理由だけえらべる。こたえあわせで、理由ごとの説明・足りない理由・余分な理由への声かけ。正解すると「⚠️ 条件が変わると？」（課題）とまとめの文 |
| 🍊 和歌山でためす | 和歌山県の市町村の地図で、梅（みなべ町・田辺市）・みかん（有田市・有田川町・湯浅町）・備長炭（田辺市・みなべ町・日高川町）・まぐろ漁業（那智勝浦町）・観光（白浜町・田辺市・那智勝浦町）の理由を説明する。重ねる地図は「⛰️ 山と土地のようす」「🌡️ 気候」「🌊 黒潮」「🛣️ 高速道路・鉄道・空港・港」「🏙️ 大阪からのきょり」。しくみは「なぜここで？」と同じ |
| ❓ 理由クイズ | 県名あてではなく「なぜ？」の理由をえらぶ4択。「🌾 農業・漁業・第3次産業の理由」（14問から）「🏭 工業の立地と変化」（12問から）「🍊 和歌山の産業」（12問から）「🔀 ミックス」から10問。まちがえた問題の説明つき |

## 先生モード

アドレスの最後に `?teacher=1` をつけて開きます。

- 電子黒板向けに文字が大きくなり、下の「つかい方」は表示しません。
- 工場はどこへ？：予想の選択肢をえらんでもすぐに進まず、**「👀 答えを見せる」**で次の時代に進みます。
- なぜここで？：地図を重ねなくても理由をえらべます。**「👀 答えを見せる」**で、理由・説明・課題を全部出します。
- 画面を決めて開けます（授業の導入10分ですぐ使うため）。
  - `重ねて見つける日本の産業.html?teacher=1&mode=kojo&year=1960`（工場はどこへ？・1960年。year は 1960・1980・2000・2020）
  - `重ねて見つける日本の産業.html?teacher=1&mode=naze&card=sokusei`（なぜここで？・促成栽培。card は kinko・sokusei・yokusei・chikusan・inasaku・kaju・gyogyo・joho・kanko）
  - `重ねて見つける日本の産業.html?teacher=1&mode=wk&card=ume`（和歌山でためす・梅。card は ume・mikan・binchotan・maguro・kankow）
  - `重ねて見つける日本の産業.html?teacher=1&mode=quiz`（理由クイズ。先生モードでは選んでもすぐ答え合わせせず「👀 答えを見せる」で正解と説明を出す。記録しない）

## データについて

- **地図**：Geolonia japanese-prefectures（MIT License）。日本の川と同じ地図・同じ座標の式。
- **2020年の工業のさかんな県**：総務省・経済産業省「令和3年経済センサス‐活動調査」製造業 第13表（都道府県別 製造品出荷額等、従業者4人以上、2020年1〜12月の実績）の構成比。色分けは 10%以上（愛知）／5〜10%／3〜5%／2〜3%／2%未満。
- **国内の工場の数**：同じ調査の第1表（従業者4人以上の事業所数）：2011年 233,186 → 2020年 176,858。
- **1960年・1980年の県別の出荷額**は、ネットで公開された資料が見つからなかったため使っていません。時代の変化は「代表的な工場の点」で表しています（すべての工場ではありません）。
- **工場の点**（できた年）：北九州の製鉄所 1901年／京浜・阪神 戦前から／豊田市の自動車工場 1938年／千葉の製鉄所 1953年／四日市の石油化学コンビナート 1959年／鹿島 1969年に港／水島 1960年代／九州のIC工場（熊本・大分・鹿児島）1970年代〜／苅田町の自動車工場 1975年／北関東の内陸の工業団地 1970年代〜／東北の高速道路ぞいのIC・電子部品工場 1980年代〜／宮若市の自動車工場 1992年／亀山市の液晶工場 2004年／大衡村の自動車工場 2011年／菊陽町の半導体工場 2024年。
- **高速道路**：全線開通の年で時代ごとに出す（名神1965・東名1969・中央1982・中国1983・関越1985・東北1987・北陸1988・高知道と瀬戸大橋1992・九州1995・山陽1997・常磐2015）。線はおもな地点をむすんだおおよその道すじ。
- **冬の気温**：1月の平均気温（県庁所在地などの、気象庁の平年値 1991〜2020年をもとにしたおおよその値）を5段階で色分け。
- **東京に出荷する月**：東京都中央卸売市場の産地別の入荷のようす（農畜産業振興機構「ベジ探」など）をもとにした**おおよその時期**。数値は出していません。

- **人口が多いところ**：2020年国勢調査で人口密度が1km²あたり1,000人以上の都府県（東京・大阪・神奈川・埼玉・愛知・千葉・福岡）。
- **海流**：黒潮・親潮・対馬海流と潮目・大陸棚の、おおよその位置。
- **和歌山県の地図**：市町村の形は和歌山県市町村パズル・日本の川と同じ（国土交通省「国土数値情報」を加工）。高速道路・JR・熊野古道の線、大阪からの円（直線きょり）は、おおよその位置。1月の平均気温は気象庁の平年値をもとにしたおおよその値（和歌山市 約6℃、潮岬 約8℃）。
- **和歌山の産業**：梅・みかんの生産量は日本一。森林は県の面積の約4分の3。勝浦港は生のまぐろの水あげが日本有数。「みなべ・田辺の梅システム」は2015年に世界農業遺産、熊野古道をふくむ「紀伊山地の霊場と参詣道」は2004年に世界遺産。
