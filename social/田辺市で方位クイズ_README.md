# 田辺市で方位クイズ

小学3・4年生の社会科「市のようす」で使う教材です。
「本宮町から見て、龍神村はどの方位？」のような問題に、方位記号を地区の★に置いてから、八方位のボタンで答えます。
方位を道具にして、田辺市の5つの地区（旧田辺市・龍神村・中辺路町・旧大塔村・本宮町）の位置関係を覚えるのがねらいです。

## 基本情報

- **ファイル**：`田辺市で方位クイズ.html` と地図データ `tanabe-map-data.js` の2つで動きます（同じフォルダに置く）。ネット接続・外部ライブラリ・ログインは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「社会」から開けます。
- **対応する機器**：パソコン・タブレット・スマホ（1人1台を想定）。

## 使い方

1. むずかしさをえらんで「スタート」。1回10問です。
2. 左上の方位記号を、「〜から見て」の地区の★までドラッグします。
   - 見る先の★に置くと「そこは見る先だよ。○○に立って見てみよう」と声をかけます（反対向きのまちがいを、答える前にふせぐため）。
3. 置くとボタンがおせるようになります。ボタンは方位記号と同じならび（北が上、北東が右上…）です。
4. 正解すると、★から見る先へ矢印がのびて、方位と地区（目印）のひとことが出ます。
5. 10問のあとは「まとめ」。わたしたちの地区を中心にした大きな方位記号に、ほかの4地区のカードを動かして並べます（地図は見えません）。最後に地図で矢印を見て確かめます。
6. 「ふりかえり」で、1回で正解した数とまちがえた問題が出ます。

### むずかしさ

| むずかしさ | 内容 |
|---|---|
| かんたん | 答えが東・西・南・北になる、地区どうしの問題だけ。ボタンは4つ |
| ふつう | 八方位。地区どうしの問題に、目印（龍神温泉・護摩壇山・百間山など）の問題がまざる。10問で8つの方位がすべて出る |
| チャレンジ | ふつうと同じ問題で、地図の地区名をかくす（形と★だけ）。「ヒント」で地区名を1.5秒見せる |

### ★（地区の中心）について

地区は広いので、地区のどこから見るかで答えが変わってしまいます（例：本宮町→龍神村は、地区の真ん中どうしなら北西、役場どうしなら西）。
そこで、市役所と行政局（もとの町や村の役場）を★にして、★どうしで考えると約束しています。

- 方位の境目にとても近い **旧田辺市↔龍神村**（境目まで2.7°）は出題しません。
- 境目まで8°より近い問題は、答えのあとに「東だけど、少し北よりだね」と出します。まとめでは、こういう地区はとなりのうでに置いても正解です。

### まちがえたとき

- 反対の方位を押したときは「それは○○から△△を見たときの方位だよ。△△に立って考えよう」。
- ほかの方位のときは、2つの★を光らせて「地図でくらべてみよう」。1秒間はおせません。
- 2回まちがえると、矢印で答えを見せます。

## 先生モード

アドレスの最後に `?teacher=1` をつけて開きます。

- **わたしたちの地区**：まとめの中心にする地区をえらびます（学校のある地区）。
- **子ども用のリンク**：むずかしさと地区が入ったリンクをコピーして、ロイロなどで配れます（例：`?level=normal&home=tanabe`）。
- **印刷用の白地図**：★と地区の形だけの地図（A4たて）。地区の名前と方位記号を子どもが書き、わたしたちの地区から見た方位を表に書きます。
- **問題と答えの一覧**：すべての問題と答え、方位の境目までの角度。線を引いた問題は出題しません。

## データ

- 地図・★・目印の位置は `tanabe-map-data.js`（国土交通省「国土数値情報」の行政区域・河川を加工）です。田辺市マップ・田辺市で地図記号さがしと同じファイルを使います。
- 方位は、地図の上で★から見る先への角度を計算して決めています（地図は北が上で、東西と南北の縮尺をそろえてあります）。
