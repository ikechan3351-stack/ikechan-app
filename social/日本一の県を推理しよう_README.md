# 日本一の県を推理しよう

中学地理（日本の地域的特色「農業」・日本の諸地域）で使う、生産量日本一の都道府県を**推理**するアプリです。
「りんご＝青森」と語呂合わせで丸暗記するのではなく、気候・地形・位置などの**条件カード**を1枚ずつめくり、当てはまらない県を**生徒が自分で消して**、日本一の県にたどりつきます。

## 基本情報

- **ファイル**：`日本一の県を推理しよう.html` の1つで動きます。ネット接続・外部ライブラリ・ログインは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「社会」から開けます。
- **対応する機器**：パソコン・タブレット（Chromebook・iPad）・スマホ。横向き 1024×768 が基準。
- **ふりがな**：右上の「ふりがな」ボタンで、用語にふりがなを出せます。
- **企画メモ**：`~/Documents/脳メモ/教材開発/企画/2026-11-02_日本一の県を推理しよう.md`

## 1問の流れ

1. **予想**：品目を見て、日本一だと思う県を直感で1つタップ（点数には入らない。結果の画面で推理した答えとくらべる）。
2. **条件カード**：カードを1枚ずつめくり、当てはまらない県をタップして消す。地方ごとにまとめて消すボタン、「ぜんぶもどす」もある。カードの「🗺️ 地図で」で、その条件に当てはまる県が緑色になる。
3. **決め手カード**：1位と2位を見分けるカード。ふつうのカードを全部めくり、県を「条件に合う県の数」以下までしぼるとめくれる（カードを連打して答えだけ見るのをふせぐ）。
4. **答える**：「🎯 答えをえらぶ」にして県をタップし、「これで答える！」。
5. **結果**：正解・不正解、1位の決め手、まちがえやすいライバル（2位）、上位の県の割合の帯グラフ（年と出典つき）。地図には日本一の県と、**消してはいけなかった県（赤わく）**が出る。まちがえたときは、合っていなかったカードの番号を示す。

- 点数：100点 −（めくったカード × 15点）−（決め手カード 25点）、最低10点。不正解は0点。
- 1回5問。最後に合計点と、まちがえた品目の決め手の一覧。

| 🌱 かんたん | りんご（青森・R7）、さくらんぼ（山形・R7）、さとうきび（沖縄・R6）、てんさい（北海道・R7）、レタス（長野・R6）、らっかせい（千葉・R6） |
| 🔥 ふつう | みかん（和歌山・R7）、うめ（和歌山・R7）、かき（和歌山・R7）、もも（山梨・R7）、ぶどう（山梨・R7）、茶（鹿児島・R7） |

- みかん・茶には「入れかわり注意」の札（茶は2024年に鹿児島が初めて静岡をぬいた）。
- 工業は推理しにくいため入れていない。はじめの画面から「重ねて見つける日本の産業」「工業地帯マップ」へ案内している。

## データについて

- 生産量の割合：農林水産省「作物統計調査」（果樹生産出荷統計・野菜生産出荷統計・作物統計）。令和7年産は概数値（確報は令和8年12月予定）。レタスは令和6年産の長野の割合のみ（農林水産省「都道府県の農林水産業の概要」長野県版）。らっかせいは千葉県の資料（令和6年産）。
- 条件の「冬もあたたかい」は、県庁所在地の1月の平均気温がおよそ5℃以上の県（気象庁の平年値をもとにした**おおよその分け方**）。「夏がすずしい」は北海道・東北地方と長野県。
- どの品目も「条件カードどおりに消せば正解の県が残り、決め手カードで1県にしぼれる」ことを確かめてある。品目を足すときは、ブラウザのコンソールで `__suiri.ITEMS` と `__suiri.inter(品目)` を使って同じことを確かめる。

## 先生モード

アドレスの最後に `?teacher=1` をつけて開きます。

- 文字が大きくなり、下の「つかい方」は表示しません。記録はしません。
- 「👀 答えを見せる」を押すたびに、カード → 決め手カード → 答え の順に見せられます（答えを見せた問題は正解に数えない）。
- `&level=easy`（normal / mix）で難しさを、`&item=mikan` で品目をえらんで開けます。品目のキー：ringo・sakuranbo・satokibi・tensai・lettuce・rakkasei・mikan・ume・kaki・momo・budou・cha。

## 記録

ブラウザ（localStorage の `nihonichi-suiri-v1`）に、解いた問題数・正解数・めくったカードの枚数・品目ごとの正誤を保存します。はじめの画面に正答率と1問あたりのカード枚数が出ます。
