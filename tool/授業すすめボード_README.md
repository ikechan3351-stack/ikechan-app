# 授業すすめボード（紙・操作・教材の一部を組み合わせて授業を進める）

先生が電子黒板で使うアプリです。授業の流れをカードで組み立て、1枚ずつ大きく映して進めます。
今までの教材は書きかえずに、ボードから必要な部分だけを取り出して使えます。

## 基本情報

- **ファイル**：本体 `授業すすめボード.html`、教材の一覧 `app-list.js`（自動生成）
- **公開ページ**：トップページ「先生用ツール」から開けます。
- **対応する機器**：電子黒板・パソコン・タブレット
- **保存**：授業は localStorage（キー `ikechan-tool-jugyo-board`）に保存します。ブラウザごとに別の保存になります。
- **保存しないもの**：映した写真と、まとめカードへの書きこみ
- **URL の設定**：`?debug=1` … 動作確認用（`window.__dbg`）

## 使い方

### 授業を作る

1. 「新しい授業を作る」で、学年・単元とひな形（算数4種類、国語・社会・理科、白紙）をえらびます。
2. 「流れを作る」でカードを足す・ならべかえる・書きかえます。合計時間が授業時間をこえると知らせます。
3. 教科に合わせて、カードの種類（例：はかる、音読する）を足せます。

### 教材の部分を取り出す

1. 種類が「アプリ」のカードで「教材と使う部分をえらぶ」を押します。
2. 教材を名前や単元でさがしてえらびます。
3. 左に出る部分のボタンを押すか、右の教材の画面でボタンを押して、使いたい画面まで進めます。
4. 「この画面を使う」を押します。部分を分けないときは「教材全体を使う」を押します。

**答えを押すなど、進める以外の操作はしないでください。** 押した順に、授業でも自動で押します。押した内容は左に表示されます。まちがえたら「はじめから やりなおす」を押します。

### 授業をする

- ページ送りは先生が「次へ」を押したときだけです。上の帯から好きなカードへ飛べます。
- めあて・こたえは「見せる」を押すまで出ません。タイマーも先生が始めます。
- アプリカードでは、教材がボードの中に開き、えらんだ部分まで自動で進みます。
- 「ほかの部分も見せる」で、隠したボタンを出せます。「全画面」「別のタブで開く」も使えます。別のタブでは、教材の最初の画面から開きます。

### ほかの先生・ほかの端末へ移す

「共有用にコピー」で出た文字を、相手の画面の「授業を受け取る」に貼りつけます。

## しくみ（直すときに読むところ）

- 教材は同じサイトにあるので、ボードは iframe に読みこみ、外からボタンを押せます。**教材のファイルは書きかえません。**
- 部分のボタンは、`data-part`・`data-tab`・`data-mode`・`data-step` のどれかがあり、画面に2つ以上出ているものを自動で探します。
- 先生が押したボタンは、カードの `steps` に順に覚えます。目印がないボタンは `id` か、ボタンの文字で覚えます。
- 授業ではカードを開いたときに `steps` を順に押し、同じ目印のほかのボタンを、教材の中に足したスタイルで隠します。
- ボタンが見つからないときは止まらず、そこまでの画面を出して知らせます。
- `app-list.js` は `python3 tools/update-obsidian-note.py` で `index.html` の表から作ります。先生用ツールと、ほかのサイトの教材は入れません。

## 注意

- 自分のパソコンのファイルを直接開く（`file:`）と、教材を読みこめず、取り出しは動きません。公開ページか、作業用のサーバーで確かめてください。
- 教材の作りが大きく変わると、覚えたボタンが見つからなくなることがあります。そのときは流れを作る画面でえらびなおしてください。
- ボタン以外の操作（図形のドラッグなど）は覚えません。
