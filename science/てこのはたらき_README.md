# てこのはたらき

小学6年生の理科「てこの規則性」で使うシミュレーションです。
実験用てこにおもりをつるして、つり合いのきまりを見つけます。支点・力点・作用点の位置と手ごたえの関係や、身近な道具のてこも調べます。

- てこには、支点・力点・作用点がある
- てこが水平につり合うとき、（左のおもりの重さ×支点からのきょり）＝（右のおもりの重さ×支点からのきょり）になる
- 力点が支点から遠いほど、作用点が支点に近いほど、小さい力で物を動かせる

## 基本情報

- **ファイル**：`てこのはたらき.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例、画面の下に先生用のメモが出ます。
- **保存**：ワークシートは localStorage に保存されます（キー：`ikechan-science-てこのはたらき`）。

## 3つのタブ

| タブ | 内容 |
|---|---|
| ① つり合いのきまり | 実験用てこ（左右のうでに目もり1〜10）。左右の「おもり置き場」から10gのおもりをドラッグして、目もりにつるす（1つの目もりに6こまで）。つるしたおもりはタップで1こはずれる。ドラッグで別の目もりへうつせる。左右の「重さ×きょり」の合計が等しければ水平になり、ちがえば重い方へかたむく。てこが止まると、ワークシートの表に自動で記録される（同じ条件は1回だけ）。「重さ×きょりを見る」（はじめは OFF）・「力の矢印を見る」の切りかえ。「ワークシートの問題」ボタンで、左3に2こをつるした状態にできる |
| ② 手ごたえをくらべよう | 棒の上の ▲支点（三角の台）・★作用点（砂ぶくろ 100/200/300g）・◆力点（手）をドラッグで動かす。手ごたえ（必要な力）＝砂ぶくろの重さ×（支点〜作用点）÷（支点〜力点）を、メーターと数字で表示。「支点が真ん中／作用点が真ん中／力点が真ん中」のならび方ボタン。「おしてみる」で、手が動いたきょりと砂ぶくろが上がったきょりをくらべられる |
| ③ 身近なてこ | くぎぬき・はさみ・ピンセット・せんぬき・バール・天びん・シーソー・一輪車。絵をタップすると ▲支点・◆力点・★作用点（色と形と文字）が出る。「小さい力で大きな力」「細かい作業」「つり合いを使う」のなかま分けクイズ付き。正かいすると下の表にたまる |

### 書きかえたいとき

- 目もりの数：`MARKS`、おもり1こあたりの重さ：`W1`、1つの目もりにつるせる数：`MAX_HANG`
- 身近なてこの道具：`TOOLS`（真ん中にあるもの `type`・なかま `cat`・しるしの場所 `pts`・せつめい `explain`・絵をかく関数 `draw`）
- ②のならび方ボタンのはじめの置き方：`SHAPES`

## ワークシート

- もんだい：左のうでの3の目もりに、おもりを2こ（20g）つるしたとき、右のうでの2の目もりには、おもりを何こつるすと、てこが水平につり合うだろうか？（答え：3こ）
- 予想：1こ／2こ／3こ／4こ／6こ
- 結果：表（左のおもり・右のおもり・結果・左の重さ×きょり・右の重さ×きょり）。グラフは散布図で、横じく＝左の重さ×きょり、たてじく＝右の重さ×きょり。つり合った記録（●）は、ななめの1本の線の上にならびます。かたむいた記録（■）は線からはずれます。

## じっさいとのちがい

本物の実験用てこは、うでやつり下げる金具の重さ・まさつで、少しずれることがあります。ここでは、うでと金具の重さを考えず、かたむきも小さく止まるようにしています。②の棒の重さも考えていません（1目もり＝5cm として、動いたきょりを表示）。③の道具の絵は、形をかんたんにしています。
