# メダカと人の誕生

小学5年生の理科「動物の誕生」（メダカの誕生・人の誕生）で使うシミュレーションです。

- メダカは、めすが産んだたまごと、おすが出した精子が受精して、受精卵ができる
- 受精卵は、たまごの中の養分を使って少しずつ変化し、子メダカがかえる（水温25℃前後で約11日）
- 人は、母親の体内（子宮）で、たいばん・へそのおを通して養分をもらって育ち、約38週で生まれる

## 基本情報

- **ファイル**：`メダカと人の誕生.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例が出ます。③人の誕生の画面に、家庭への配慮についての注意メモも出ます。

## ① メダカのおすとめす

- **見分け方**：おす（上）とめす（下）をならべています。ひれをタップすると、名前と見分け方が出て、オレンジの点線でかこまれます。
  - せびれ：おすは切れこみがある／めすは切れこみがない
  - しりびれ：おすは大きくて平行四辺形に近い／めすはおすより小さく、うしろが短い
  - めすは、はらがふくらんでいる
- **見分けクイズ**：右向き・左向きのメダカが出ます。「おす」「めす」で答えると、理由が出ます。
- **受精のようす**：おすがめすによりそう → めすがたまごを産む → おすが精子を出す（見える化 ON で表示）→ 受精して受精卵になる → めすが水草にうみつける、の順にアニメーションします。

## ② たまごの中の変化

- 水温（18〜30℃）と、受精してからの日数を選びます。「日を進める」で自動で進みます（はやさは ゆっくり／ふつう／はやおくり）。
- かえるまでの日数は「275 ÷ 水温」で計算しためやすです（25℃で約11日、20℃で約14日、30℃で約9日）。
- 変化の順番（25℃のとき）

| 日数 | ようす |
|---|---|
| 0日 | 受精したばかり。長い毛（付着毛）、たくさんの油のつぶ |
| 2日ごろ | 体のもとができる（だんだん細長くなる） |
| 4日ごろ | 目がはっきりする。心臓が動き、血液が流れはじめる |
| 8日ごろ | たまごの中でよく動く。目が黒く大きくなる |
| 11日ごろ | からをやぶってかえる。はらのふくろの養分で2〜3日すごす |

- 見える化 ON で、血液のつぶが流れるようすが見えます。
- たまごの中（目・心臓・油のつぶ・付着毛・体のもと・血液の流れ）をタップすると、名前とはたらきが出ます。
- かえると画面が小さくなり、から（約1mm）と子メダカ（約4〜5mm）の大きさの割合が本物に近くなります。
- かえってから「記録する」をおすと、水温とかえるまでの日数がワークシートに入り、グラフ（横：水温、たて：日数）になります。

## ③ 人の誕生

- 「受精卵」「4週」「8週」「16週」「24週」「32週」「38週」から選びます。「順に見る」で自動で進みます。
- 右に身長・体重と、身長の棒グラフ（めやす）が出ます。

| 時期 | 身長 | 体重 | ようす |
|---|---|---|---|
| 受精卵 | 約0.1mm | ― | 子宮のかべについて育ちはじめる |
| 4週 | 約0.4cm | ― | 心臓が動きはじめる |
| 8週 | 約3cm | 約4g | 目や耳ができ、手やあしの形がはっきりする |
| 16週 | 約16cm | 約100g | 顔や体の形がはっきりし、男女の区別ができる。体を動かしはじめる |
| 24週 | 約30cm | 約700g | 心臓の動きが活発。体を回転させてよく動く |
| 32週 | 約40cm | 約1800g | 体のしくみがほぼできあがる。頭を下にしている |
| 38週 | 約50cm | 約3000g | 生まれる。すぐに肺で呼吸をはじめる |

- 受精卵と4週は小さくて見えないので、「拡大」の丸の中に大きくかいています。
- 子宮・羊水・たいばん・へそのお・胎児・母親の血管をタップすると説明が出ます。
- **養分の道すじをたどる**：問題に答えながら、母親の血管 → たいばん → へそのお → 胎児 の順にタップします。まちがえると、そこが何かを教えてくれます。
- 見える化 ON で、● 養分など（母親 → 胎児）と ▲ いらなくなったもの（胎児 → 母親）が流れます（色だけでなく形でも区別）。

## ④ くらべよう

メダカと人について、育つ場所・受精卵の大きさ・養分・生まれるまで・生まれたときの大きさ・生まれたあと・同じところを表でくらべます。「？」をタップすると答えが出ます。「ぜんぶ見る」で全部開き、「もういちど」で閉じます。

## 配慮について（先生へ）

- 家族のかたちはさまざまです。「生まれたときのことを家の人に聞く」「赤ちゃんのころの写真を持ってくる」などの活動は全員に求めず、本や資料で調べる形や希望制にしてください。
- 流産・死産などを経験した家庭があることも考え、ことばを選んでください。
- 学習指導要領では「人の受精に至る過程は取り扱わないものとする」とされているので、この教材でも、人の受精のしくみには立ち入っていません。
- 生まれたあとの栄養は「母乳やミルク」としています。

## 数字を変えたいとき

HTML の `<script>` の中の「しくみの数字」で変えられます。

- `HATCH_K`：かえるまでの日数の計算（日数 ≒ HATCH_K ÷ 水温）
- `EGG_DAY_PER_SEC`：② の「ふつう」で1秒に進む日数
- `HU_SEC_PER_STAGE`：③ の「順に見る」で1つの週を見せる秒数
- `HS`：人の成長のデータ（身長・体重・説明の文）
- `DICT_SRC`：ふりがなの辞書。`{漢字|よみ}` の形で足すと、画面の文字に自動でふりがなが付きます

## じっさいとのちがい

- メダカのたまご・子メダカ・胎児の絵は、わかりやすくかんたんにしています。
- かえるまでの日数・身長・体重はめやすで、じっさいにはちがいがあります。
- 子宮や胎児の大きさの割合は、見やすいように変えています。
- たいばんは、受精してからしばらくのあいだに、だんだんつくられていきます。
