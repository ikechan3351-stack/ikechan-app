# 光のせいしつ

小学3年生の理科「光の性質」で使うシミュレーションです。
鏡ではね返した日光を、日かげのかべの的に当てて、次のことを確かめます。

- 日光はまっすぐ進む
- 鏡で日光をはね返すと、光の向きを変えられる（入る角＝はね返る角）
- はね返した日光を重ねるほど、明るく、あたたかくなる
- （発展）虫めがねで日光を集めると、光の円が小さいほど明るく、熱くなる

## 基本情報

- **ファイル**：`光のせいしつ.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例が出ます。

## 画面（上のタブで切りかえ）

| タブ | 内容 |
|---|---|
| 🪞 はね返そう | 鏡を0〜3まい置き、はね返した光を的に重ねる。的の温度が上がる。「⏱ 3分はかる」で温度を記録する |
| 🎯 的に当てよう | ミッション。だんかい1（鏡1まい）→ だんかい2（2まいを重ねる）→ だんかい3（3まいをぜんぶ重ねる） |
| 🔍 虫めがね | 発展。虫めがねと紙のきょりを変えると、光の円の大きさ・明るさ・温度が変わる。いちばん小さくすると紙からけむりが出る |

## 操作

| 操作 | 内容 |
|---|---|
| 鏡のまん中をドラッグ | 鏡を動かす（日なたの中だけ） |
| 鏡のはしの青い● をドラッグ | 鏡を回す |
| ↺ 回す ／ 回す ↻ | 選んでいる鏡（点線の丸）を少しずつ回す。おしたままにすると回り続ける |
| 光の道すじ ON/OFF | OFF にすると、じっさいの実験と同じように、かべに当たった光だけが見える |
| もういちど | 鏡を、はじめの置き方にもどす |

- 鏡の水色の線がおもて（光る面）、こい茶色の線がうらです。うらに光が当たると、はね返らずに知らせが出ます。
- 「かべを正面から見た図」では、光が重なるほど明るくなり、的に当たっているまい数を「×2」などの文字でも示します。

## ワークシート

- **問題**：はね返した日光を重ねると、的の温度はどうなるだろうか？
- **予想**：かわらない／少しだけ上がる／どんどん上がる
- **結果**：的に当てた鏡のまい数と温度の表、棒グラフ

## 正しさについて（じっさいとのちがい）

- はね返る向きは「入る角＝はね返る角」で計算しています。
- 上から見た図なので、光の高さは考えていません。鏡どうしで光をさえぎること、2回はね返ることは考えていません。
- 温度は目安です（日かげの的 約14℃、鏡1まい分の光で約6℃上がる）。虫めがねの温度も目安で、紙からけむりが出るところまでにしています。
