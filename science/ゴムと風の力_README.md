# ゴムと風の力

小学3年生の理科「風とゴムの力のはたらき」で使うシミュレーションです。
ゴムや風の力で車を走らせ、ものさし付きのコースで「走ったきょり」をくらべます。

- ゴムや風の力で、物を動かすことができる
- ゴムを長くのばすほど、車は遠くまで走る
- 風が強いほど、車は遠くまで進む
- （おまけ）おもりをのせて重くすると、きょりは短くなる

## 基本情報

- **ファイル**：`ゴムと風の力.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例が出ます。

## 画面

| 部分 | 内容 |
|---|---|
| タブ | 「① ゴムの力」と「② 風の力」を切りかえる |
| コース | 0〜10m のものさし付き。止まったところに旗ときょり（例：3m86cm）が出る。前の旗もうすく残るので、くらべられる |
| ① ゴム | スタートの左に、ゴムをかける台。ゴムののびは、見やすいように大きくかき、下に cm のものさしを付けている |
| ② 風 | 左に送風機（弱・中・強）。ほ付きの車に風を当てる。風は青い線で見える化（送風機から遠いほど、うすく・おそくなる） |

## 操作

| 操作 | 内容 |
|---|---|
| ゴムをのばす長さ | スライダーで 1〜15cm。または、車を左へドラッグしてのばし、指（マウス）をはなすと走る |
| 手をはなす | ゴムをのばした車を走らせる |
| 風の強さ・スイッチ ON | 弱・中・強をえらんで、送風機を回す。車が止まるまで風を送る |
| ゆっくり／ふつう／はやおくり | 車の動く速さ（0.4倍・1倍・3倍）。きょりはかわらない |
| コマ送り ON/OFF | 0.5秒ごとの車の前のはしのいちを、点とたての線で残す。点の間がひろい＝速い、せまい＝おそい |
| 力の矢印 ON/OFF | 車をおす力（ゴムの力・風の力）を、オレンジの矢印の長さで見える化。風の線もいっしょに切りかわる |
| おまけ：おもり | なし・1こ・2こ。おもり1こで、車の重さが1.5倍になる |
| もういちど | 車をスタートにもどし、旗を消す（ワークシートの記録は残る） |

走りおわるたびに、ワークシートの表に「ゴムの長さ／風の強さ・おもり・走ったきょり（cm）」を記録し、棒グラフを作ります。棒は、ゴムの短い順 → 風の弱い順にならびます。おもりをのせたときは、名前に ■ が付きます（例：10cm■■）。

## ワークシート

- **問題**：ゴムを2倍のばすと、車の走るきょりも2倍になるだろうか？
- **予想**：2倍より短い／ちょうど2倍／2倍より遠い
- **結果**：このシミュレーションでは **2倍より遠く（約4倍）** になります（5cm → 約94cm、10cm → 約3m86cm、15cm → 約8m75cm）。予想とのずれを、考察の話し合いに使えます。
- 風の強さ（目安）：弱 → 約1m80cm、中 → 約4m8cm、強 → 約7m65cm

## しくみ（正しさについて）

- **ゴム**：のばした長さに比例する力で車をおします（フックの法則）。ゴムが車をおすのは、のびがなくなるまでです。ためたエネルギーはのびの2乗に比例するので、2倍のばすと、きょりは約4倍になります。
- **風**：風と車の速さの差の2乗に比例する力で、ほをおします。風は送風機から遠いほど弱くなります。
- **まさつ**：車の重さに比例するブレーキ（ころがりまさつ）がかかり、おす力がまさつより小さくなると止まります。おもりで重くすると、まさつが大きくなり、きょりが短くなります。
- 数字は、HTML の中の「しくみの数字」（`K`＝ゴムの強さ、`WIND_U`＝風の速さ、`MU`＝まさつ など）でかえられます。

### じっさいとのちがい

- じっさいのゴムは、のびと力がぴったり比例するわけではありません。また、空気のていこうは考えていないので、じっさいの実験では「約4倍」より小さくなることが多いです。それでも「2倍より遠くなる」ことが多くあります。
- じっさいの実験では、同じじょうけんでもきょりが少しずつかわります。このシミュレーションは、毎回同じきょりになります。
