# じしゃくのふしぎ

小学3年生の理科「磁石の性質」で使うシミュレーションです。次のことを確かめます。

- 磁石には N極 と S極 がある。ちがう極どうしは引き合い、同じ極どうしはしりぞけ合う
- 磁石につくのは鉄でできた物。金属でも、銅（10円玉）やアルミニウム（アルミかん・1円玉）はつかない
- 磁石の力は、はなれていてもはたらく。紙や下じきをはさんでもはたらくが、はなれるほど弱くなる
- 砂鉄は磁石の極（両はし）にたくさん集まる

## 基本情報

- **ファイル**：`じしゃくのふしぎ.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例が出ます。②では、物の材料（鉄・銅など）がはじめから表示されます。

## 画面（上のタブで切りかえ）

| タブ | 内容 |
|---|---|
| ① N極とS極 | 2本の棒磁石をドラッグで近づける。引き合う／しりぞけ合うを、動きと矢印（太さ＝力の強さ）と文字で示す |
| ② つく？つかない？ | 9この物を磁石に近づけて調べ、「つく」「つかない」の箱に仕分ける。「答え合わせ」で ○／× が出る |
| ③ はなれていても | 磁石とクリップのあいだに紙・プラスチックの下じきを0〜5まいはさむ。引く力の矢印とメーターが弱まり、重さより弱くなるとクリップが落ちる |
| ④ 砂鉄 | 磁石のまわりの砂鉄のもよう。「1本」「N と S を向かい合わせ」「N と N を向かい合わせ」。磁石はドラッグで動かせる |

## 操作

| 操作 | 内容 |
|---|---|
| 磁石をドラッグ（①④） | 磁石を動かす。さわった磁石がえらばれる（オレンジの点線） |
| ↺ 回す ／ 回す ↻ | えらんだ磁石を45°ずつ回す |
| N と S を入れかえる | えらんだ磁石の向きを反対にする |
| 力の矢印 ON/OFF（①） | 力の矢印を出す／かくす |
| 物をドラッグ（②） | 実験台の磁石に近づけて手をはなすと調べられる。つく物は磁石のはしにくっつき、つかない物は落ちてもとの場所にもどる。調べた物は箱にドラッグして仕分ける |
| 砂鉄 ON/OFF・砂鉄をまきなおす（④） | 砂鉄を出す／かくす。まきなおすと、ばらばらの砂鉄がならんでいくようすが見られる |
| もういちど | そのタブを、はじめの状態にもどす（ワークシートは消えません） |

- N極は赤、S極は青で、「N」「S」の文字と、S極側のしまもようでも区別しています。
- 引き合う＝みどり、しりぞけ合う＝むらさきの矢印で、「引き合う！」「しりぞけ合う！」の文字も出ます。

## ワークシート

- **問題**：アルミかんは、磁石につくだろうか？
- **予想**：つく／つかない
- **結果**：②で調べた物・何でできているか・磁石につくか の表（調べると自動で記録。グラフはなし）

## 正しさについて（じっさいとのちがい）

- 磁石の力は、極にある「＋（N）」「−（S）」のつぶどうしの力（きょりの2じょうに反比例）として計算しています。
- ①の磁石は、台車にのせたように回らないようにしています（じっさいには、くるっと回って引き合う向きになることがあります）。
- ③の紙・下じきのあつさは大きくかいています（紙1まい約0.1mm、下じき1まい約1mm として計算）。力の強さは目安です。
- ④の砂鉄は、力の向きにならぶようすを計算でかいています。じっさいの砂鉄は、極にもっとかたまって集まります。

## 改造のしかた

- 調べる物をふやすときは、HTML の中の `ITEMS`（物の一覧）に1行たし、`ICON` にその物の絵（SVG）を足します。`iron: true` なら磁石につきます。
- ③の力の弱まり方は `D0`、クリップの重さは `WEIGHT` で変えられます。
