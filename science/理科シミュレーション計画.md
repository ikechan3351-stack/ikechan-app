# 理科シミュレーション計画（小学校3〜6年・全33本）

`CLAUDE.md` の「理科シミュレーションのルール」に従って作る、理科シミュレーションの計画表です。

## 使い方

1. Claude Code を `ikechan-app` フォルダ（いちばん上）で起動します。
2. 下の「進み具合」から作りたい単元を選び、その単元のプロンプトを**1本だけ**貼りつけます。
3. Claude が画面の案と題名の候補3つを出すので、了承して題名を選びます。
4. できあがったら自分でも内蔵ブラウザでさわってみて、よければ「push して」と伝えます。
5. 完成した単元は、下の表の状態を ✅ に書きかえます（Claude に頼んでもかまいません）。

- ファイル名は**仮**です。題名を選んだら、ファイル名とトップページの行もその題名に合わせます。
- 共通ルール（ファイルの置き場所・見た目・ワークシート・先生モード・ブラウザでの確認）は `CLAUDE.md` に書いてあるので、プロンプトにはくり返し書いていません。
- パートが多い単元は、**まずパート1だけ作り**、確かめてからパートを足していくと失敗が少なくなります。

## 作るときのコツ

- **1本ずつ作る**：まとめて作らず、動作確認→直す→次へ。パートが多い単元は、パート1から少しずつ。
- **今ある教材を活かす**：ふりこ・月と太陽はワークシートを付け足すだけ。回路・星座・人体は、新しく作る前に読ませて重なりを説明させる。
- **共通部品を育てる**：ワークシート（worksheet.js）、回路の判定（circuit-engine.js）、クイズ（quiz.js）は使い回せます。
- **教科書と照らし合わせる**：単元の順番や言葉は、教科書会社（東京書籍・啓林館・大日本図書・学校図書・教育出版など）でちがうことがあります。使っている教科書に合わせ、数値（とける量、気体の割合など）も最後に先生が確かめてください。
- **気になったら、そのまま頼む**：「かげの動きの文字が小さいので大きくして」のように、追加でお願いすればOKです。
