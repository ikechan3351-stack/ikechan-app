# 電流のはたらき

小学4年生の理科「電流のはたらき」で使うシミュレーションです。
かん電池のつなぎ方や向きを変えて、けん流計・モーター（または豆電球）のようすをくらべます。

- かん電池2こを直列につなぐと、電流が大きくなり（約2倍）、モーターは速く回る（豆電球は明るくなる）
- かん電池2こをへい列につなぐと、電流は電池1このときとほぼ同じ。そのかわり、電池が長持ちする
- 電流には向きがある。電池の向きを反対にすると、電流の向きが反対になり、モーターの回る向きも反対になる

## 基本情報

- **ファイル**：`電流のはたらき.html`。同じフォルダの `circuit-engine.js`（回路の計算）と `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例が出ます。
- **今ある教材とのちがい**：`回路シミュレーター.html` は自由に回路を組み立てる道具です。この教材は回路の形を決めておき、つなぎ方と向きだけを切りかえてくらべます。電流の計算は 3年「電気の通り道」と同じ `circuit-engine.js` を使い、モーター（motor）とけん流計（meter）の部品を足しました。

## 画面

| 部分 | 内容 |
|---|---|
| 回路の絵 | 上：けん流計、右：モーター（豆電球）、左：スイッチ、下：かん電池。つなぎ方を変えると、電池の部分の絵が組みかわる |
| 電流のつぶ | 黄色のつぶが電流の向きに流れる。電流が大きいほど速く流れる。赤い三角の矢印でも向きを表示 |
| けん流計 | 針は電流の流れる向きにふれ、ふれはばが電流の大きさ（0〜1A） |
| モーター | プロペラが回る。回る向きは ↻（右回り）・↺（左回り）の矢印と文字でも表示 |
| いまのようす | 電流の大きさ（A）、針のふれた向き、速さ（電池1このときの何倍か）、回る向き |
| 回路図 | 電気用図記号でかいた回路図。つなぎ方・電池の向き・スイッチに合わせて変わる |

## 操作

| 操作 | 内容 |
|---|---|
| つなぎ方 | 「1こ」「2こ直列」「2こへい列」 |
| 電池の向きを入れかえる | 電池をすべて反対向きにする（1こだけ反対にすることはできない） |
| つなぐ物 | モーター／豆電球 |
| スイッチ ON/OFF | ボタン、または絵のスイッチをタップ |
| 電流のつぶ ON/OFF | つぶを消して、矢印だけにできる |
| 結果を記録 | ワークシートの表に「つなぎ方・つないだ物・電流の向き・電流の大きさ・速さ（明るさ）」を記録する。同じ条件は1回だけ |
| もういちど | 記録を消して、はじめ（1こ・モーター・ふつうの向き）にもどす（予想と考察は残る） |
| 電池の長持ちくらべ | 新しい電池で、1こ・直列・へい列の3つの回路を同時に動かす。「ゆっくり／ふつう／はやおくり」で時間の進み方を変えられる。電池ののこりは、しまもようのバーと％で表示 |

## ワークシート

- **問題**：かん電池2こを直列につなぐと、モーターの回る速さはどうなるだろうか？
- **予想**：速くなる・おそくなる・かわらない
- **結果**：表と、つなぎ方ごとの電流の大きさの棒グラフ

## 正しさについて（じっさいとのちがい）

- 電池1こは1.5V、電池の中の電気の通りにくさは0.1Ω、モーターは4Ω（電池1こで約0.36A）として計算しています。けん流計の数字は目安です。
- モーターの速さは、モーターにかかる電圧に比例するとしてかんたんにしています。
- 長持ちくらべは、電池1こに 2.0（A×時間）の電気が入っているとして計算した目安です（1こ 約7時間半、直列 約4時間、へい列 約15時間）。電池がへると電圧が下がり、モーターがおそくなります。
- へい列で電池を1こだけ反対にするとショート回路になってきけんなので、この教材では電池の向きはまとめて入れかえます。

## 改造のしかた

- **回路の形**：`buildCircuit` の中で、たんしの位置（`P`）とどう線（`W`）を変えます。
- **モーターの強さ**：`circuit-engine.js` の `R_MOTOR` を変えます（ほかの教材には影響しません）。
- **長持ちくらべの時間**：`CAP`（電池の中の電気の量）を変えます。
