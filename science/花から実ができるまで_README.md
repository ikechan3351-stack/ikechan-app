# 花から実ができるまで

小学5年生の理科「花から実へ」（花のつくりと結実）で使うシミュレーションです。

- 花には、がく・花びら・おしべ・めしべがある（ヘチマ・カボチャは、お花とめ花に分かれている）
- おしべの先に花粉があり、めしべの先に花粉がつくこと（受粉）で、めしべのもとが実になり、中にたねができる
- 花粉は、虫・風・人の手などで運ばれる
- 受粉したものだけが実になることを、ふくろをかぶせた実験で確かめる

## 基本情報

- **ファイル**：`花から実ができるまで.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例が出ます。③実験の画面に、アサガオでおしべを取る理由の説明も出ます。

## ① 花のつくり

アサガオ・ヘチマ（お花／め花）・カボチャ（お花／め花）・アブラナから選びます。

- 左は「花をたてに切ったところ」、右は「分解図（がく・花びら・おしべ・めしべを ならべたところ）」。
- 部分をタップすると、名前とはたらきが出て、オレンジの点線でかこまれます。
  - おしべの先＝花粉が入っている／めしべの先＝べとべとしていて花粉がつく（受粉）／めしべのもと＝実になる
- アサガオ・アブラナは、がく・花びら・おしべ・めしべの数も出ます（アブラナ：4・4・6・1）。
- お花には「めしべ なし」、め花には「おしべ なし」と出ます。め花は、花びらの下のふくらみがめしべのもとです。
- **部分さがしクイズ**：「めしべのもとはどこ？」などの問題に、絵か分解図をタップして答えます。

## ② 受粉のしくみ

| 運び方 | 花 | 操作 |
|---|---|---|
| 🐝 虫 | カボチャのお花 → め花 | ハチをドラッグ、または「自動で運ぶ」 |
| 🌬 風 | トウモロコシ（上がお花、ひげがめしべ） | 「風をふかせる」 |
| 🖌 人の手 | ヘチマのお花 → め花 | 筆をドラッグ、または「自動で運ぶ」 |

- おしべにふれると花粉がつき、め花のめしべの先にふれると花粉がうつって「受粉した！」と出ます。
- 風では、多くの花粉が地面に落ち、一部だけがひげ（めしべ）につきます。
- 見える化 ON で、けんび鏡で見た花粉の形（カボチャ：とげとげ／トウモロコシ：つるつるで軽い）が出ます。

## ③ 実験

ヘチマのめ花か、アサガオを選び、A・B の2つの花の条件を決めて日にちを進めます（14日目まで）。

| 条件 | えらべるもの |
|---|---|
| おしべ（アサガオだけ） | つぼみのときに取る／取らない |
| ふくろ | つぼみのときにかぶせる／かぶせない |
| 花粉 | 花がさいたら筆でつける（つけたあと、またふくろをかぶせる）／つけない |

- 受粉する条件：花粉をつけた／ふくろがない（虫が運ぶ）／アサガオでおしべを取らない（花がさく前に自分の花粉で受粉する）
- 0日目 つぼみ → 1日目 花がさく → 2日目 しぼむ → 3日目 ふくろをはずす → 受粉したものはめしべのもとがふくらみ、受粉しないものはかれて落ちます。6日目から「⭕ 実ができた／✖ 実はできない」が出ます。
- 下の箱で、A と B のちがう条件の数を調べます。1つだけちがうときは、結果から言えることを出します。
- **くらべ方のれい**：ヘチマ：花粉／アサガオ：花粉（どちらもおしべを取ってふくろ）／アサガオ：おしべ（取る・取らない）
- A はオレンジの実線のわくと●、B は青の点線のわくと■（色だけで区別しない）。
- 「記録する」で、A・B の条件と結果をワークシートに入れます。

## ④ 実とたね

- **実が育つようす**：アサガオ・ヘチマ・トマトを選び、「受粉してから」の日数を進めます。花びらがちり、めしべのもとがふくらんで実になります。「中を見る」で切ると、たねが育っていくようすが見えます。オレンジの点線は、はじめのめしべのもとの大きさです。
- **切ってみよう**：トマト・カボチャ・キュウリ・ピーマンを「切る」（または野菜をタップ）と、中のたねが見えます。へた（がく）や花のあとも出ます。

## 共通のボタン

- はやさ：ゆっくり／ふつう／はやおくり（②③④の「実が育つようす」）
- 見える化（名前）ON/OFF：①④では名前、②ではけんび鏡の花粉、③では めしべの先の虫めがね と ラベル
- もういちど：いまの画面をはじめにもどす

## かんたんにしたところ（※じっさいとのちがい）

- 花や実の形・数・色はかんたんにしています。花粉は本当はとても小さく、目ではつぶに見えません。
- 日にちははやく進めています。実が育つ日数（アサガオ約30日・ヘチマ約40日・トマト約45日）はめやすです。
- ヘチマやトマトの実は本当はぶら下がりますが、見やすいように上向きにかいています。
- ふくろをかぶせないとき、虫が来なければ受粉しないこともあります。

## 改造するとき

- 花の形・色・数は、スクリプトの `SP`（花のデータ）で変えられます。
- 日数などは「しくみの数字」（`EX_MAX`・`EX_DECIDE`・`EX_DAY_PER_SEC`・`GR_DAY_PER_SEC`・`WIND_TIME`）で変えられます。
- 保存のキーは `ikechan-science-花から実ができるまで` です。
