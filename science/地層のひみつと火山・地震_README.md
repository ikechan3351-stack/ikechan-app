# 地層のひみつと火山・地震

小学6年生の理科「土地のつくりと変化」で使うシミュレーションです。
水そうで地層ができるようすを見て、がけの地層を調べて柱状図をつくり、化石から昔のようすを考えます。火山のふん火や地震で土地が変わるようすと、津波・ハザードマップも学べます。

- 土地は、れき・砂・どろ・火山灰などが層になって重なってできている（地層）
- 地層は、流れる水のはたらきや、火山のふん火でできる。ふつう、下の層ほど古い
- 化石から、その層ができたころのようすがわかる
- 火山のふん火や地震によって、土地のようすが変わる

## 5つのタブ

| タブ | 内容 |
|---|---|
| ① 地層のでき方 | 「土を流しこむ」で、れき・砂・どろがまざった土が、といから水そうに流れこむ。つぶが大きいほど速くしずむので、下から れき→砂→どろ の順に積もる（どろがしずむまで水がにごる）。くり返すと（最大5回）しまもようの地層が重なり、「1回目・2回目…」と「古い↓・新しい↑」の矢印が出る。「つぶの名前を見る」「古い・新しいを見る」の切りかえ。はやさ3段階 |
| ② がけの観察 | がけの5つの層（下から れき・砂（アサリの化石）・どろ・火山灰・どろ（木の葉の化石））をタップすると、ルーペでつぶの拡大図が出て、色・つぶ・化石がわかる。「何の層か」を答えると右の柱状図がうまる（まちがえるとヒント）。完成したら「ボーリング試料とくらべる」で200mはなれた所の柱状図Bが出て、「同じ層をつなぐ」で火山灰の層を線で結ぶ |
| ③ 化石と昔のようす | アサリ・サンゴ・木の葉・恐竜の骨・アンモナイト・山の上のアサリ の6問。正かいすると、右に「昔のようす」の絵（浅い海・あたたかい海・湖・大昔の陸・大昔の海・持ち上がった土地）が出る |
| ④ 火山 | 「ふん火させる」で、マグマが上がり、よう岩が流れ、ふん石が火口の近くに落ち、火山灰が風にのって広く降り積もる（火山に近いほど厚い）。風（西→東／東→西／なし）を変えられる。A地点・B地点の「地下の断面」で、火山灰の層が一度に広い範囲にできることを確かめる（最大3回）。「ルーペ」で火山灰（角ばっている）と川の砂（丸い）をくらべる。下に、温泉・地熱発電などの「めぐみ」と、火山灰・よう岩などの「災害」のなかま分けクイズ |
| ⑤ 地震 | 4つに分かれる。**断層**：「力をくわえる」で力がたまり、たえきれなくなると地層がずれて地震（ゆれ・段差）。引っぱる力／おす力でずれる向きが変わる（最大3回）。**しゅう曲**：スライダーか「ゆっくりおす」で、地層が曲がる。**津波**：海の底で地震→海の水が持ち上がり、浅くなると高くなって町までおし寄せる。高台は安全。**ハザードマップ**：架空の町の地図で、にげる場所・川ぞいの危険・「色がない所でもぜったい安全ではない」の3問 |

### 書きかえたいとき

- がけの層：`CLIFF`（種類 `t`・厚さ `th`・色・つぶ・化石・わかること）、ボーリング試料：`BORE`、がけの化石の位置：`CL_FOS`
- 水そうのつぶの数・しずむ速さ・積もる厚さ：`KIND`、流しこめる回数：`MAX_POUR`
- 化石クイズ：`FOS`（選たくしの1番目が正かい。画面ではまぜて表示）
- めぐみと災害：`GIFTS`、ハザードマップの問題：`HZQ`（選たくしの1番目が正かい）
- 地震の地層：`EQ_LAYERS`、ふん火の回数：`MAX_ERUPT`、地震の回数：`MAX_SLIP`
- ふりがな：`DICT_SRC` に `{漢字|よみ}` の形で足す

## ワークシート

- もんだい：がけに見える地層の中で、いちばん古い層はどれだろうか？（答え：いちばん下の層）
- 予想：いちばん上の層／まん中の層／いちばん下の層／どれも同じ
- 結果：表（どこで・したこと・わかったこと）。①の流しこみ、②で答えた層、③の正かい、④のふん火（A・B地点に積もったか）、⑤の断層・しゅう曲・津波などが自動で記録されます（同じ内容は1回だけ）。グラフはありません。

## じっさいとのちがい

本物の地層は、何千年〜何万年もの長い時間をかけて、少しずつ積もってできます。①では、つぶの大きさで分かれて積もるようすを、はやめて見せています（本物の水そうでは、どろはなかなかしずまず、長い時間にごったままです）。また、層は水そうの底に平らに積もるようにしています。②〜⑤の図は形をかんたんにし、つぶの大きさ・層の厚さ・断層のずれ・津波の高さなどを大きくかいています。ハザードマップは架空の町の例です。
