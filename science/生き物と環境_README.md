# 生き物と環境

小学6年生の理科「生物と環境」で使うシミュレーションです。

- 生き物は、「食べる・食べられる」の関係でつながっている（食物連さ）
- もとをたどると、動物の食べ物は、日光を受けて自分で養分をつくる植物にいきつく
- 生き物の数は、植物 → 草食動物 → 肉食動物の順に少なくなり、ふつうはつり合いが保たれている
- 生き物は、空気（酸素・二酸化炭素）や水をとおして、まわりの環境とつながっている
- 人のくらしは環境にえいきょうをあたえる。環境を守る取り組みがある

## 基本情報

- **ファイル**：`生き物と環境.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例、画面の下に先生用のメモ（食物網・分解者など中学校につながる説明）が出ます。
- **保存**：ワークシートは localStorage に保存されます（キー：`ikechan-science-生き物と環境`）。

## 5つのタブ

| タブ | 内容 |
|---|---|
| ① 食物連さ | 草原（草→バッタ→カエル→ヘビ）・池（植物プランクトン→ミジンコ→メダカ→サギ）・海（植物プランクトン→動物プランクトン→イワシ→マグロ）・森（木の葉→ガの幼虫→シジュウカラ→オオタカ）から選ぶ。ばらばらの「生き物カード」を、いちばん「食べられる」側から順にタップしてならべる。まちがえると「○○は△△を食べるかな？」とヒントが出る。上の大きな矢印と下の文で、矢印は「食べられるもの → 食べるもの」（養分が移っていく向き）であることを強調する。ならべ終わると、養分のつぶ（◆）が矢印の向きに動く。植物▲・草食動物●・肉食動物■のマークも付く |
| ② 数の変化 | 左に植物▲・草食動物●・肉食動物■のピラミッド（はじめは 1000本・100ひき・20ひき）、右にそれぞれの数のグラフ（点線＝はじめの数）。肉食動物を「ふやす／へらす／いなくなる」、できごと「外来種が入ってくる」、天気「日照りがつづく」で、数が時間とともに変わる。へらすと草食動物がいちどふえて植物がへり、やがてもとのつり合いにもどる。いなくなる・外来種では、つり合いがくずれたままになる。「止める」「記録する」付き |
| ③ 空気と水 | **空気**：昼は植物が二酸化炭素■を取り入れて酸素●を出し、動物は酸素●を取り入れて二酸化炭素■を出す。夜は植物も動物も呼吸だけ。**水のめぐり**：海や川の水の蒸発、葉からの蒸散、雲、雨、川、根から吸う、動物が飲む、を水蒸気○としずくのつぶで見る |
| ④ 人と環境 | 森林の伐採・水のよごれ・地球温暖化の3つの場面。「人のえいきょう」スライダーを動かすと、木や生き物の数、川のにごりやよごれ、二酸化炭素・気温・氷のようすが変わる。「対策：する」で、植林・下水処理場・太陽光や風力の発電が出て、えいきょうが小さくなる |
| ⑤ 環境調べ | 川で見つかった生き物（指標生物）から水のきれいさを答えるクイズ6問。◎きれいな水（カワゲラ・ヒラタカゲロウ・サワガニ）、○ややきれいな水（カワニナ・ゲンジボタル・ヤマトシジミ）、△きたない水（ミズカマキリ・ミズムシ・タニシ）、✕とてもきたない水（アメリカザリガニ・サカマキガイ・エラミミズ）。多く見つかった仲間で判定する問題と、台所でできることの問題もある |

- どのタブにも「もういちど」ボタンがあります。
- 「はやさ」で、はやおくり／ふつう／ゆっくり を切りかえられます。「つぶを見る」で、養分・空気・水のつぶの見える化を ON/OFF できます。

## ワークシート

- 問題：「肉食動物がへると、草食動物はどうなるだろうか？」
- 予想：ふえる／へる／かわらない／いちどふえて、またもとにもどる
- 結果の表：年目・したこと・草食動物（ひき）・肉食動物（ひき）・植物（本）
- グラフ：折れ線（横じく＝年目、草食動物と肉食動物の2本）
- ②で、はじめに「記録する」→「－ へらす」→ 何年かごとに「記録する」の順で使います。

## 先生が変えられるところ

HTML の `<script>` の中の「数の設定」を書きかえると、変えられます。

| 名前 | 内容 |
|---|---|
| `MODEL` | ② の計算のモデルの数（植物のふえる速さ、食べられる強さなど）。はじめの数でちょうどつり合うように合わせてあるので、変えるときは説明のコメントを見てください |
| `SHOW` | ② の画面に出す、はじめの数（植物1000本・草食動物100ひき・肉食動物20ひき） |
| `YEAR_PER_SEC` / `GRAPH_YEARS` | ② の1秒に進む年数・グラフに出す年数 |
| `CHAINS` | ① の場所ごとの食物連さ（生き物を入れかえられる。絵は `ORG` にある） |
| `QUIZ` | ⑤ のクイズの問題 |

ふりがなは、`DICT_SRC` に `{漢字|よみ}` の形で足すと、画面の文字にもキャンバスの中の文字にも付きます。

## じっさいとのちがい

- ② の数の変化は、かんたんな計算のモデルです。ほんとうの自然では、生き物の種類がもっと多く、天気や季節でも数が変わるので、こんなにきれいな形にはなりません。時間（年）もめやすです。
- 実際の食べる・食べられるの関係は、1本のくさりではなく、網の目のようにつながっています（先生モードで説明）。
- 生き物の絵や大きさは、かんたんにしています。
- ③ のつぶは見えるように大きくかいたイメージです。昼の植物の呼吸は、図では省いています。
- ④ の場面の変化は、ようすを分かりやすくしたもので、数や温度は表していません。
- ⑤ の判定は、環境省・国土交通省の「水生生物による水質判定」をかんたんにしたものです。
