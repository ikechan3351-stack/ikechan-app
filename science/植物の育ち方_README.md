# 植物の育ち方

小学3年生の理科「植物の育ち方」で使うシミュレーションです。
ホウセンカ・ヒマワリ・アサガオから選び、たねまきから実・たねができるまで、日数を進めて育つようすを観察します。

- 植物は、たね → 芽が出る（発芽） → 子葉 → 葉がふえる → くきが太く高くなる → つぼみ → 花 → 実 → たね、の順に育つ
- 植物の体は、根・くき・葉からできている
- 水や日光が足りないと、元気がなくなり、育ちがおそくなる

## 基本情報

- **ファイル**：`植物の育ち方.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例が出ます。

## 画面

| 部分 | 内容 |
|---|---|
| 植物のタブ | ホウセンカ・ヒマワリ・アサガオ。植物ごとに育てている記録が別々に残るので、切りかえてくらべられる |
| 植物の絵 | 横から見た図。左にものさし（cm）、オレンジの点線が草たけ。植物が大きくなると、目もりが小さくなる |
| 土の中を見る ON/OFF | ON にすると、根ののびるようすが見える |
| 名前とはたらき | 根・くき（アサガオはつる）・葉・子葉・つぼみ・花・実・たねをタップすると、名前とはたらきが出る |
| いまのようす | たねまきからの日数、草たけ（アサガオはつるの長さ）、葉の数、ようす |
| 世話をしよう | 水やり、日なた／日かげ、土の水と元気のメーター（しまもようと文字でも表示）、おまかせ世話 |
| そだちグラフ | 草たけ（または葉の数）を毎日自動で記録した折れ線グラフ。花がさいた日に線が入る |
| 日数スライダー | 0〜120日。10日ごとの目もりと、花がさいた日のしるし（🌸） |
| 観察カード | 記録した日の絵・草たけ・葉の数・ようすをカードにしてならべる。「気づいたこと」も書ける |

## 操作

| 操作 | 内容 |
|---|---|
| さいせい／とめる | 1日ずつ進む。「ゆっくり／ふつう／はやおくり」で速さを変えられる。ようすがかわると、メッセージが出る |
| 日数スライダー | 前の日にもどすと、その日のようすが見られる。先へ進めた日は、おまかせで世話をしたことにする |
| 水やり | 土の水がいっぱいになる。土の水は毎日へる（日なたのほうがはやくへる） |
| 日なた／日かげ | 日かげでは育ちがおそくなり、元気も少しずつ下がる |
| おまかせ世話 | ON にすると、水やりと日当たりを自動でする。育ち方だけを見せたいときに使う |
| この日を記録する | いまの日のようすを観察カードとワークシートの表に記録する |
| もういちど | えらんでいる植物を、たねまきの日にもどす（観察カードは残る） |

- 前の日を見ているときに「さいせい」や世話をすると、その日から先を育て直します。
- 自分で世話をしているとき、土がかわくと再生が止まり、「水やりをしよう！」と知らせます。
- 世話をしないと元気が下がりますが、かれきることはありません。水やりをして日なたに出すと、元気がもどります。
- 観察カードは、このブラウザに保存されます（キー：`ikechan-science-植物の育ち方-cards`）。

## ワークシート

- **問題**：たねをまいてから、いつごろ花がさくだろうか？
- **予想**：1か月後ごろ／2か月後ごろ／3か月後ごろ
- **結果**：観察カードの記録（植物・日数・草たけ・葉の数・ようす）の表と、日数ごとの草たけの棒グラフ

## 育ち方の目安（よく世話をしたとき）

| | 芽が出る | 本葉 | つぼみ | 花 | 実 | たね | 草たけ |
|---|---|---|---|---|---|---|---|
| ホウセンカ | 5日 | 10日 | 50日 | 57日 | 70日 | 85日（実がはじける） | 約50cm |
| ヒマワリ | 8日 | 13日 | 60日 | 74日 | 88日 | 102日 | 約170cm |
| アサガオ | 6日 | 11日 | 55日 | 62日 | 74日 | 90日 | つるの長さ 約220cm |

数字は HTML の中の `PLANTS`（植物のデータ）でかえられます。

## しくみ（正しさについて）

- 「育った日数」を1日ごとに足していきます。よく世話をすると1日に1、日かげでは約半分、水が切れるとほとんど進みません。このため、世話が足りないと花がさく日もおそくなります。
- 芽が出るまでは、水があれば日光がなくても進みます（芽が出るのに日光はいらない）。
- 草たけと葉の数は、はじめはゆっくり、そのあと急にふえ、花のころにふえ方がゆるやかになる形（S字）にしています。
- 葉の数は子葉を入れずに数えています。たねができたあとは、下の葉からかれて落ちます。

### じっさいとのちがい

- 日数は5月のはじめにたねをまいたときの目安です。気温や地いき、年によってかわります。
- ホウセンカの枝分かれなどは、かんたんにしています。
- 水のやりすぎ（根ぐされ）は考えていません。
