# ふりこの実験

小学5年生の理科「振り子の運動」で使うシミュレーションです。
2つのふりこA・Bの条件を1つだけ変えてくらべ、ふりこが1往復する時間が何によって変わるかを調べます。

- ふりこが1往復する時間は、ふりこの長さによって変わる（長いほど長くなる）
- おもりの重さ・ふれはばを変えても、1往復する時間は変わらない

## 基本情報

- **ファイル**：`ふりこの実験.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例が出ます。画面の下に、発展のグラフと先生用のメモも出ます。
- **保存**：ワークシートは localStorage に保存されます（キー：`ikechan-science-ふりこの実験`）。

## 操作

| 部分・操作 | 内容 |
|---|---|
| 自動で測る／自分で測る | はかり方を切りかえる |
| ふりこA・B | 長さ（25〜100cm）・おもり（10/20/30g）・ふれはば（10〜40°）。変えると、はじめにもどる |
| くらべている条件 | AとBでちがう条件を自動で調べて出す。2つ以上ちがうと「何が原因かわからないよ」と出る。ちがう条件の名前には波線が付く |
| 同時にスタート（自動） | 1往復ごとにカチッと音が鳴る。10往復すると、10往復の時間と1往復の時間がワークシートの表とグラフ（横：長さ、たて：1往復の時間）に入る |
| はやさ（自動） | ゆっくり／ふつう／はやおくり。記録される時間は、はやさに関係なく本当の時間 |
| 自分で測る | 回数の表示がかくれる。測るふりこ（AかB）をえらんで「ふらせる」。ストップウォッチで10往復を測り、「記録する」 |
| 記録のあと（自分で測る） | 計算で求めた時間とのちがいが出る。10往復とかけはなれた時間は、数えまちがいかもしれないので記録しない |
| もういちど | ふりこを止めて、はじめにもどす |

## 計算のしかた

1往復の時間は T = 2π√(長さ÷9.8) で計算しています（`period()`）。おもりの重さ・ふれはばは入っていません。

## 発展（先生モードのみ）

長さと1往復の時間のグラフ。25cm（約1.0秒）と100cm（約2.0秒）に印があり、長さを4倍にすると1往復の時間が2倍になることがわかります。記録した結果も●で出ます。小学校の学習指導要領の範囲をこえるため、先生モードだけに出しています。

## じっさいとのちがい

- 本物のふりこでは、ふれはばが大きいと1往復の時間がわずかにのびます（40°で約3%、20°で約1%）。この教材では計算に入れていません。
- 空気のていこうや糸の重さは考えていません。
