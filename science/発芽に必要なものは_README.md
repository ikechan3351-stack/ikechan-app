# 発芽に必要なものは？

小学5年生の理科「植物の発芽と成長」で使うシミュレーションです。
インゲンマメのたねを入れた入れ物の条件を変えて、発芽するかどうかをくらべます。

- たねが発芽するには、水・空気・適当な温度が必要（光や肥料は、なくても発芽する）
- 調べる条件を1つだけ変えて、ほかの条件はそろえてくらべる
- 子葉にふくまれるでんぷんは、発芽やそのあとの成長に使われる

## 基本情報

- **ファイル**：`発芽に必要なものは.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例が出ます。冷ぞう庫と光の条件のそろえ方の説明も出ます。

## ① 条件をくらべよう

入れ物（だっし綿をしいたコップ）を2〜6こならべ、入れ物ごとに条件を決めます。

| 条件 | えらべるもの | 絵での見分け方 |
|---|---|---|
| 水 | あり／なし | だっし綿が水色（しずくのマーク）か、かわいた色か。かわいたたねは小さく、しわがある |
| 空気 | あり／なし（水にしずめる） | なしは、コップいっぱいに水が入り、たねがしずんでいる |
| 温度 | 室温（20℃）／冷ぞう庫（約5℃） | 冷ぞう庫のわく・雪のしるし・温度計 |
| 光 | 当てる／箱でおおう | 太陽のしるし／前を切りとった箱（しまもよう） |
| 肥料 | あり／なし | だっし綿の上の、むらさきと白のつぶ |

- 「空気なし」にすると水は自動で「あり」に、「水なし」にすると空気は自動で「あり」になります（水にしずめるには水がいるため）。
- **冷ぞう庫の中は暗い**ので、「冷ぞう庫」にすると光は自動で「箱でおおう」になります。室温・明るいままの入れ物とくらべると、ちがう条件が2つになります。

| 操作 | 内容 |
|---|---|
| 入れ物をタップ／番号ボタン | その入れ物をえらび、下のボタンで条件を変える。スタート後は、その入れ物の説明が出る |
| ＋ふやす／－へらす | 入れ物の数（2〜6）。あいているマスをタップしてもふえる |
| くらべ方のれい | 水・空気・温度・光・肥料（1つだけちがう2つ）、6つぜんぶ |
| スタート／＋1日 | 日にちを進める（10日目まで）。はやさは ゆっくり／ふつう／はやおくり。スタート後は条件を変えられない |
| くらべる2つ（A・B） | A はオレンジの実線、B は青の点線のわく。ちがう条件の数を調べて、下の箱に出す |
| 見える化 ON/OFF | 空気のつぶ（○）・しみこんだ水（しずく）・温度計・光の矢じるし |
| 記録する | その日の、すべての入れ物の条件と結果をワークシートに入れる |
| もういちど | 0日目にもどす（ワークシートの記録は残る） |

**くらべた結果のことば**

- ちがう条件が0こ：「条件がぜんぶ同じ」
- ちがう条件が1こ：「原因は○○だと言える」。結果が出たら「発芽には○○が必要！」「発芽に○○は必要ない！」
- ちがう条件が2こ以上：「何が原因かな？」。冷ぞう庫と光がちがうときは「くらべる相手も箱でおおって暗くしよう」

**育ち方**：水・空気・適当な温度がそろった入れ物だけ、2日目ごろにたねの皮がやぶれて根が出て、くきがのびて子葉を持ち上げ、皮が落ちて子葉が開き、本葉が出ます。光がないと、葉は黄色っぽく、くきは長くなります。水のある入れ物のたねは、発芽しなくても水をすってふくらみます。6日目をすぎても芽が出なければ「× 発芽しない」と出ます。

## ② ヨウ素液でしらべよう

| 部分・操作 | 内容 |
|---|---|
| 左：発芽する前のたね | 水にひたして半分に切ったもの。子葉・たねの皮・根・くき・葉になる部分（はい）の名前つき |
| 右：発芽して○日後の子葉 | スライダーで 0〜14日。日がたつほど、子葉はしぼんで緑っぽくなる。右上の小さな芽の絵で、どこの子葉かを示す |
| スポイト | ドラッグして、切った面の上ではなすとヨウ素液がたれる。「左にたらす／右にたらす」ボタンでもよい |
| 色の変わり方 | でんぷんが多いほど青むらさき色。色だけでなく、こい点（でんぷんのつぶ）の多さと、文字でも分かる |
| ふき取る | 色をもとにもどす |

## ワークシート

- **もんだい**：水がないと、インゲンマメのたねは発芽するだろうか？
- **予想**：発芽する／発芽しない／わからない
- **記録**：日数・入れ物・水・空気・温度・光・肥料・発芽したか（表だけ。グラフはなし）
- 保存キー：`ikechan-science-発芽に必要なものは`

## 数字を変えたいとき

HTML の中の「しくみの数字」で変えられます。

| 名前 | 意味 | 今の数 |
|---|---|---|
| `MAX_DAY` | 何日目まで進めるか | 10 |
| `SPLIT_DAY` | 根が出始める日 | 2 |
| `DECIDE_DAY` | 「発芽しない」と出す日 | 6 |
| `ROOM_T`・`COLD_T` | 室温・冷ぞう庫の温度（℃） | 20・5 |
| `STARCH_GONE_DAY` | 子葉のでんぷんがほとんどなくなる日数 | 12 |

## ※じっさいとのちがい

- 日にちは、はやく進めています。発芽までの日数は、気温やたねによってかわります。
- 冷ぞう庫でも、とても長い時間がたつと少し発芽することがあります。
- 光がないと、発芽はしますが、そのあとの葉は黄色っぽく、くきはひょろりと長くなります。
- 水にしずめたたねは、水をすってふくらみますが、発芽しません。
- ヨウ素液の色の変わり方は、わかりやすくしています。
