# ものの燃え方

小学6年生の理科「燃焼の仕組み」で使うシミュレーションです。
集気びんの中でろうそくを燃やし、空気の入れかわりと、燃える前と後の空気の変化を調べます。

- ものが燃え続けるには、新しい空気（酸素）が必要
- ものが燃えると、空気中の酸素の一部が使われ（約21％→約17％）、二酸化炭素ができる（約0.04％→約3〜4％）。酸素はぜんぶなくなるわけではない
- 酸素にはものを燃やすはたらきがあり、ちっ素や二酸化炭素にはない
- 火を消すには、燃える物・酸素（空気）・温度のどれか1つをなくせばよい

## 基本情報

- **ファイル**：`ものの燃え方.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例、画面の下に先生用のメモが出ます。
- **保存**：ワークシートは localStorage に保存されます（キー：`ikechan-science-ものの燃え方`）。

## 5つのタブ

| タブ | 内容 |
|---|---|
| ① びんをかぶせる | ふた（する／すき間／なし）と、びんの下のすき間（なし／あり）を選び、「火をつける」→「びんをかぶせる」。ほのおの大きさ・燃えた時間・円グラフ（ちっ素・酸素・二酸化炭素・そのほか）と表（かぶせる前／いま）が変わる。線香は指でドラッグして動かせる。消えたら（または30秒以上燃えたら）「記録する」 |
| ② 気体をしらべる | A（燃やす前の空気）・B（燃やした後の空気）を、気体検知管（酸素用 6〜24％、二酸化炭素用 0.03〜1％／0.5〜8％）と石灰水でしらべる。検知管は大きくした目もりを読んで、4つの中から答える。結果は「わかったこと」の表にたまる |
| ③ 気体だけのびん | 空気・酸素だけ・ちっ素だけ・二酸化炭素だけのびんに、火のついたろうそくを入れる（1つずつ／4つ同時）。空気＝しばらく燃えて消える、酸素＝大きく明るくはげしく燃える、ちっ素・二酸化炭素＝すぐ消える |
| ④ いろいろな物 | 木（わりばし）・紙・スチールウール（鉄）を、ふたをしたびんの中で燃やす → 石灰水を入れてふる。木と紙は白くにごる、スチールウールはにごらない（でも酸素は使われる） |
| ⑤ 火を消すゲーム | 6つの場面（アルコールランプ・たき火・ガスコンロ・てんぷら油・山火事・家の火事）で消し方をえらび、「燃える物・酸素・温度」のどれをなくしたかを答える。1回目で正かいすると1てん（12てん満点）。三角形の頂点が×になって、火が消える |

### ① びんをかぶせる の結果のめやす（ふつうのはやさ）

| ふた | びんの下 | ろうそく | 線香のけむり |
|---|---|---|---|
| あり | すき間なし | 約15秒で消える | びんの中に入らない |
| すき間 | すき間なし | 約20秒で消える | ほとんど入らない |
| あり | すき間あり | 約17秒で消える | ほとんど入らない |
| なし | すき間なし | 燃え続ける（ほのおは少し小さい） | 口のはしから入り、まん中から出ていく |
| すき間 | すき間あり | 燃え続ける | 下から入り、上のすき間から出ていく |
| なし | すき間あり | 燃え続ける（大きいほのお） | 下から入り、上から出ていく |

- 消えたときのびんの中：酸素 約17％、二酸化炭素 約3.4％。円グラフの横に「酸素は 0 にはならない！」と出る。
- 「空気のつぶを見る」：空気を100こ（酸素●・二酸化炭素■・ちっ素など・）で表す。燃えると●が減り、■がふえる。
- 燃えている間、びんの内側が少しくもる（水ができるため。先生モードのメモで説明）。
- びんをかぶせたあとでも、ふたは変えられる（記録に「とちゅうで変えた」と出る）。びんの下のすき間は変えられない。

### 数を変えたいとき

HTML の「数の設定」の部分で変えられます。

- `O_OUT`：ほのおが消える酸素の割合（0.170＝17％）
- `K`：ろうそくが酸素を使う速さ（大きくすると早く消える）
- `R_CANDLE`：使った酸素に対して、できる二酸化炭素の量
- `exchOf()`：ふたと下のすき間ごとの、空気の入れかわりやすさ
- ② の検知管の読み取りの値は `VAL`（A：酸素21・二酸化炭素0.04、B：酸素17・二酸化炭素3.5）
- ⑤ のもんだいは `FQ` に1行足すと増やせます（場面の絵は `drawFireScene()`）。

## ワークシート

- もんだい：びんの中のろうそくは、最後にどうなるだろうか？
- 予想：ずっと燃え続ける／だんだん小さくなって、消える／すぐに消える／もっと大きく燃える
- 結果：表（ふた・びんの下・ろうそく・燃えた時間・酸素・二酸化炭素）。グラフはありません。

## 安全について

タブごとに「⚠ 本物の実験では」のわくを出しています（燃えやすい物を近くに置かない・ぬれぞうきん・かん気・検知管の先とあつさ・石灰水と保護めがね・酸素の中でのはげしい燃え方・スチールウールの火花）。⑤では、本当に火事を見つけたときは「知らせる・大人をよぶ・にげる」を先にすることを書いています。

## じっさいとのちがい

気体の割合は実験のめやすで、びんの大きさ・ろうそくの太さ・はかるときの混ざり方で変わります。上だけあいたびん（下にすき間なし）は、びんの口の広さや高さによって、燃え続けることも消えることもあります。スチールウールや酸素だけのびんの燃える時間は短くしています。空気のつぶはイメージです。気体検知管の色は、会社や種類によってちがいます。
