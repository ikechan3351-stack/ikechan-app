# 電磁石のはたらき

小学5年生の理科「電流がつくる磁力」で使うシミュレーションです。
鉄しんにエナメル線をまいたコイルに電流を流し、引きつけるクリップの数や方位磁針のふれ方から、電磁石の性質を調べます。

- コイルに電流を流すと、鉄しんが磁石になる（電磁石）。電流を切ると、磁石のはたらきがなくなる
- 電流の向きを逆にすると、N極とS極が入れかわる
- コイルのまき数を多くしたり、電流を大きくしたりすると、電磁石は強くなる

## 基本情報

- **ファイル**：`電磁石のはたらき.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例、画面の下に先生用のメモが出ます。
- **保存**：ワークシートは localStorage に保存されます（キー：`ikechan-science-電磁石のはたらき`）。

## 操作

| 部分・操作 | 内容 |
|---|---|
| まき数 | 50回／100回／200回。えらぶと、0回からまいていくアニメーションが出る。まき数が少ないほど「あまった導線」がふえる（導線の長さを同じにして、電流を変えないため） |
| かん電池 | 1個／2個（直列）。電流計の値は 約0.9A／約1.7A |
| 鉄しん | あり／なし。なしでは、クリップはほとんどつかない（方位磁針は少しふれる） |
| 電池の向きを逆にする | 電流の向きが逆になり、N極とS極が入れかわる。方位磁針の針も逆にふれる。電流計の＋・－たんしも入れかわる |
| スイッチ | ボタンか、図の中のスイッチをおす。入れると電流計の針が動き、クリップが両はしに引きつけられる。切ると落ちる |
| 記録する | スイッチを入れているときにおせる。ワークシートの表と棒グラフ（横：条件、たて：クリップの数）に入る |
| もういちど | スイッチを切り、条件をはじめ（100回・1個・鉄しんあり）にもどす |
| 見える化 | 電流の流れ（つぶ）・N極とS極の表示・磁石の力の見える化（線）を、それぞれ ON/OFF できる |
| 安全のメッセージ | スイッチを入れたまま8秒たつと「電池が熱くなってきたよ」と赤く出て、電池から湯気のような線が出る |
| 条件を変えると | スイッチは自動で切れる（本物でも、つなぎかえるときはスイッチを切る） |

## 電磁石の利用

| タブ | 内容 |
|---|---|
| リサイクル工場のクレーン | 電流を流すと鉄だけがつき、アルミかんはつかない。右へ運んで電流を切ると、鉄が置き場に落ちる |
| モーター | 左右のふつうの磁石の間で、電磁石が回る。回るとちゅうでN極・S極が入れかわる。電池の向きを逆にすると、逆に回る |
| IH調理器 | コイルの磁石の力の向きが速く入れかわり、なべの底が熱くなる。なべの温度が上がり、ふっとうする |

## 計算のしかた

- 電流：電池1個 0.9A、2個（直列）1.7A（`AMP`）。まき数では変わらない（導線の長さを同じにしているため）。
- クリップの数（鉄しんあり）：`5 ×（まき数÷50）×（電流÷0.9）` に、0.9〜1.1倍のばらつきをかけて四捨五入（`clipBase()`）。
  - 例：100回・1個 → 約10個、200回・1個 → 約20個、200回・2個 → 約38個
- 鉄しんなし：上の数を12でわった数（ほとんど0個）。
- 方位磁針のふれ：地球の磁石の力（北向き）と電磁石の力を合わせた向き。強いほど、真横に近くふれる。

## ワークシート

- もんだい：コイルのまき数を2倍にすると、引きつけるクリップの数は何個になるだろうか？
- 予想：少なくなる／かわらない／2倍くらいにふえる／2倍よりもっとふえる
- 結果：表（条件・まき数・電池・鉄しん・電流・クリップ・右はしの極）と棒グラフ

## じっさいとのちがい

クリップの数は「まき数 × 電流」に比例する計算で、本物ほどばらつきません。電池2個の電流は、電池の中のていこうのため2倍より少し小さくしています。「磁石の力の見える化」の線（磁力線）は中学校の内容なので、イメージとして使う程度にしてください。
