# 月と太陽シミュレーター

小学6年生の理科「月と太陽」（月の満ち欠け）で使うシミュレーションです。
月を動かすと、上から見た図・地球から見た空・月の形が同時に変わります。月の形と見える方角が、月と太陽の位置関係で決まることを確かめます。

- 月は自分では光らず、太陽の光が当たっている側が光って見える
- 月と太陽の位置関係によって、月の見える形が変わる（三日月・上弦の月・満月・下弦の月など）
- 夕方に見える月の位置は、三日月は西、上弦の月は南、満月は東

## 基本情報

- **ファイル**：`月と太陽.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例、画面の下に先生用のメモが出ます。
- **保存**：ワークシートは localStorage に保存されます（キー：`ikechan-science-月と太陽`）。

## できること

| 操作 | 内容 |
|---|---|
| 月のドラッグ・回転 | 「北極側から見た図」の月をドラッグするか「回転」をおすと、月が地球のまわりを回る（1周30日）。「1日もどす／すすめる」もある。回転のはやさは はやおくり／ふつう／ゆっくり |
| 時こくスライダー | 0時〜24時。地球から見た空（東・南・西）の、太陽と月の位置が変わる。上から見た図では、観察する人（オレンジの人）が地球の上を回り、頭の側の白っぽい所にある月だけが見える。人の左手側が東、右手側が西 |
| 光の矢印を見る | 太陽の光が月に当たる向きの矢印。月の光っている側は、いつも太陽の方を向いている（ON/OFF） |
| 確かめよう | 「夕方の三日月」「夕方の上弦の月」「夕方の満月」「真夜中の満月」を1回でその日・時こくにする |
| 今の月を記録する | 月齢・月の形・時こく・方角（東／南東／南／南西／西の空、または見えない）・高さ（低い／中くらい／高い）をワークシートの表に記録する（同じ月齢と時こくは1回だけ） |

### 書きかえたいとき

- 1周の日数：`CYCLE`（30）
- 確かめボタンの月齢と時こく：`CHECKS`
- 月の形の名前とひとこと：`phaseName()`
- 方角・高さの分け方：`dirName()`・`altName()`

## ワークシート

- もんだい：三日月は、夕方（日がしずんだころ）どの方角の空に見えるだろうか？（答え：西の空の低い所）
- 予想：東の空／南の空／西の空／見えない
- 結果：表（月齢・月の形・時こく・方角・高さ）。グラフはありません。

## じっさいとのちがい

本物の月は、地球からのきょりが地球の大きさの約30倍もあり、太陽はもっとずっと遠く大きいです。図では、大きさときょりをかんたんにしています。月が同じ形にもどるのは約29.5日ですが、ここでは30日にしています。月の通り道のかたむきや、季節による月の高さのちがいは考えていません。
