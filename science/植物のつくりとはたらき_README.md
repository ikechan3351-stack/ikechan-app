# 植物のつくりとはたらき

小学6年生の理科「植物の養分と水の通り道」で使うシミュレーションです。

- 葉に日光が当たると、でんぷんができる（光合成）。でんぷんは、葉の緑色の部分でつくられる
- 二酸化炭素と水が材料になり、日光の力で、でんぷんと酸素ができる
- 根から取り入れた水は、根・くき・葉にある通り道（道管）を通って、体全体に運ばれる
- 水は、おもに葉の気孔から水蒸気になって出ていく（蒸散）
- 植物も、昼も夜も呼吸している。昼は光合成の方がさかんなので、全体では二酸化炭素を取り入れ、酸素を出している（発展）

## 基本情報

- **ファイル**：`植物のつくりとはたらき.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例、画面の下に先生用のメモが出ます。②のくきの断面には「師管」も出ます。
- **保存**：ワークシートは localStorage に保存されます（キー：`ikechan-science-植物のつくりとはたらき`）。

## 4つのタブ

| タブ | 内容 |
|---|---|
| ① でんぷんづくり | **ヨウ素液の実験**：3まいの葉（A 日光に当てる／B はくでおおったまま／C 一部だけはくでおおう）を、①前の日の夕方にはくでおおう → ②次の日に日光に当てる → ③葉を取って湯とアルコールで緑をぬく → ④ヨウ素液をかける、の順に調べる。つぎにおすボタンが黄色く光り、順番どおりにしかおせない。でんぷんのあるところは、青むらさき色に白い点のもようが付く（色だけで区別しない）。「記録する」で3まいの結果がワークシートに入る。「ふ入りの葉」にすると、ふちの白い部分は日光が当たってもでんぷんができないことが分かる。**葉の中（つぶのモデル）**：二酸化炭素（オレンジの■）が気孔から、水（水色のしずく）が葉脈から入り、日光が当たると、でんぷん（むらさきのつぶ）と酸素（青い●）ができる。日光を「当たらない」にすると、でんぷんはできず、できていたでんぷんは葉脈を通って運び出される |
| ② 水の通り道 | 「色水に入れる」で、ホウセンカを赤い色水に入れる。時間とともに、根 → くき → 葉 へ色が上がる。植物の図（くき・葉・根）をタップすると、右の大きな円にそこの切り口が出る。くきは「横に切る」（水の通り道が輪のようにならぶ）と「たてに切る」（すじになって見える）を選べる。「根を切ったもの（切り花）」にすると、くきの下から色が上がる |
| ③ 蒸散 | **ふくろの実験**：A 葉をつけたままの枝と、B 葉を取った枝にふくろをかぶせて日光に当てる。Aのふくろだけがくもって水てきがたまり、下に水がたまる。Bはほとんど変わらない。**葉の裏（けんび鏡）**：気孔を「開く／閉じる」で切りかえる。開いていると、水蒸気（○）と酸素（●）が出ていき、二酸化炭素（■）が入っていく |
| ④ 昼と夜 | **植物と空気**：昼は光合成（太い矢印）と呼吸（点線の細い矢印）、夜は呼吸だけ。右の表で、植物全体としての気体の出入りをくらべる。「呼吸も見る」で呼吸の矢印を消せる。**ふくろの実験**：ふくろに息をふきこんで気体検知管ではかり、1時間後にもう一度はかる。昼は 酸素 約17％→約19％・二酸化炭素 約4％→約2％、夜は 酸素 約17％→約16.5％・二酸化炭素 約4％→約4.5％（めやす） |

- どのタブにも「もういちど」ボタンがあります。
- 「はやさ」で、はやおくり／ふつう／ゆっくり を切りかえられます。「つぶを見る」で、つぶの見える化を ON/OFF できます。

## ワークシート

- 問題：「日光に当てないと、葉にでんぷんはできるだろうか？」
- 予想：できる／できない／少しだけできる
- 結果の表：葉（A・B・C）・葉の種類（ふつう／ふ入り）・日光（当てた／当てなかった／一部だけ当てなかった）・ヨウ素液での色
- グラフはありません（色の結果なので、表だけ）。

## 先生が変えられるところ

HTML の `<script>` の中の「数の設定」を書きかえると、変えられます。

| 名前 | 内容 |
|---|---|
| `NIGHT_SEC` / `DAY_SEC` | ① 夜のあいだ・日光に当てる時間が、何秒で進むか |
| `DYE_PER_HOUR` / `SEC_PER_HOUR` | ② 色水が上がるはやさ・1時間が何秒か |
| `BAG_MIN_PER_SEC` | ③ ふくろの実験で、1秒に何分進むか |
| `GAS_BAG` | ④ ふくろの実験の、酸素・二酸化炭素の割合（％） |

ふりがなは、`DICT_SRC` に `{漢字|よみ}` の形で足すと、画面の文字にもキャンバスの中の文字にも付きます。

## じっさいとのちがい

- 時間は、とても短くちぢめています（日光に当てるのは4〜5時間、色水が葉までとどくのは数時間〜半日、ふくろがくもるのは15〜30分ほど）。
- つぶは大きくかいたイメージで、二酸化炭素1つと水1つから、でんぷん1つと酸素1つができるようにしています（ほんとうの数の比とはちがいます）。
- くきの断面・気孔の形は、かんたんにしています。
- ふくろの実験の数値は、めやすです（植物の大きさや日光の強さで変わります）。
