# 水よう液のなかま分け

小学6年生の理科「水溶液の性質」で使うシミュレーションです。
リトマス紙などで水よう液をなかま分けし、とけているもの（気体・固体）や、金属を変化させる水よう液について調べます。

- 水よう液は、酸性・中性・アルカリ性になかま分けできる（リトマス紙：酸性＝青→赤、アルカリ性＝赤→青、中性＝どちらも変わらない）
- 気体がとけている水よう液がある（炭酸水・塩酸・アンモニア水は、蒸発させても何も残らない）
- 金属を変化させる水よう液がある（うすい塩酸にアルミニウム・鉄を入れると、あわを出してとける。出てきた固体は、もとの金属とは別のもの）

## 基本情報

- **ファイル**：`水溶液の性質.html`（画面の題名は「水よう液のなかま分け」）。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例、画面の下に先生用のメモが出ます。
- **保存**：ワークシートは localStorage に保存されます（キー：`ikechan-science-水溶液の性質`）。

## 4つのタブ

| タブ | 内容 |
|---|---|
| ① リトマス紙 | 塩酸・炭酸水・食酢・食塩水・砂糖水・石灰水・アンモニア水・水酸化ナトリウム水よう液（👩‍🏫先生）から選び、ガラスぼうで青／赤のリトマス紙に1てきつける（ボタンか、リトマス紙をタップ）。しみが広がって色が変わる。結果は「▲さん・●ちゅう・■アル」の形と文字でも出る。BTB液（黄・緑・青）・ムラサキキャベツ液（赤・赤むらさき・むらさき・緑・黄緑・黄）に切りかえると、試験管に2〜3てき入れて色の表とくらべられる。2まいとも調べたら「記録する」 |
| ② 蒸発・におい | 食塩水・石灰水・炭酸水・塩酸・アンモニア水・水を蒸発皿で加熱。液が少なくなると火を止め、のこりの熱で蒸発させる。食塩水・石灰水は白い固体が残り、ほかは何も残らない。「においを調べる」で、手であおいでかぐアニメ（塩酸・アンモニア水はつんとする）。炭酸水では「出てくる気体を石灰水に通す」で、石灰水が白くにごる。結果は右の表にたまる |
| ③ 金属を入れる | アルミニウム・鉄（スチールウール）・銅を、うすい塩酸・水・水酸化ナトリウム水よう液（👩‍🏫先生）に入れる。とけたら「液を蒸発させる」→ 出てきた固体を、もとの金属と「見た目・じしゃく・うすい塩酸・水」でくらべる |
| ④ 仕分けゲーム | 12まいのカード（塩酸・炭酸水・食酢・レモンのしる・食塩水・砂糖水・水・石灰水・アンモニア水・水酸化ナトリウム水よう液・石けん水・重そう水）を、酸性・中性・アルカリ性の箱に入れる。ドラッグ、またはカードをタップ→箱をタップ。「ヒント」でリトマス紙の変わり方がわかる。「こたえあわせ」で ⭕／✖（✖はわくが点線になる） |

### ③ 金属を入れる の結果

| 金属 | うすい塩酸 | 水 | 水酸化ナトリウム水よう液 |
|---|---|---|---|
| アルミニウム | あわを出してとける（温かくなる）→ 蒸発させると白い粉 | 変化なし | あわを出してとける → 白い粉 |
| 鉄 | ゆっくりあわを出してとける（液がうすい緑色に）→ 黄色っぽい粉 | 変化なし | 変化なし |
| 銅 | 変化なし → 蒸発させても何も出てこない | 変化なし | 変化なし |

くらべた結果：もとの金属は「つやがある・（鉄は）じしゃくにつく・塩酸にあわを出してとける・水にとけない」、出てきた固体は「粉でつやがない・じしゃくにつかない・塩酸にあわを出さずにとける・水にとける」。4つともくらべると「金属は、塩酸にとけて、別のものに変わった」とまとめが出ます。

### 「とけているもののつぶを見る」

ビーカー・蒸発皿の中に、とけているものを ○（気体）・■（固体）・◆（液体）で表します。蒸発させると、○は空気中に出ていき、■は残ります。③では、金属が変わってとけているものを ★ で表します。

### 書きかえたいとき

- 水よう液のデータ（なかま・ムラサキキャベツ液の色・とけているもの・蒸発で残るもの・におい）：`SOL`
- ①・②でえらべる液：`LIT_LIST`・`EVA_LIST`
- 金属と液の組み合わせ（とける時間・あわの多さ・液の色・出てくる固体）：`reactOf()`
- ④のカード：`SORT_CARDS` に `['名前', 'acid' か 'neu' か 'alk']` を1行足すとふえます

## ワークシート

- もんだい：炭酸水は、酸性・中性・アルカリ性のどれだろうか？
- 予想：酸性／中性／アルカリ性
- 結果：表（水よう液・青リトマス紙・赤リトマス紙・BTB液・ムラサキキャベツ液・なかま）。グラフはありません。BTB液などをあとから調べると、同じ液でもう一度記録できます。

## 安全について

画面の上に、いつも「保護めがね・薬品を手につけない・においは手であおぐ・手についたら水で洗う・こい酸やアルカリは先生が見せる」の帯を出しています。さらにタブごとに「⚠ 本物の実験では」のわく（リトマス紙はピンセットで持つ・ガラスぼうは液ごとに洗う・かん気・液が少なくなったら火を止める・水素に火を近づけない・家の洗ざいの「まぜるな危険」など）を出しています。水酸化ナトリウム水よう液には「👩‍🏫先生」の印を付け、えらぶと注意が出ます。

## じっさいとのちがい

つぶ（○■◆★）はイメージです。リトマス紙・BTB液・ムラサキキャベツ液の色は、液のこさや種類で少しちがいます（ムラサキキャベツ液の色はめやす）。蒸発やとける時間は本物より短くしています。鉄をとかした液から出てくる固体の色は、黄色っぽい色をめやすにしています。
