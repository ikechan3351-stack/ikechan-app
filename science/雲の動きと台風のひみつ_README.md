# 雲の動きと台風のひみつ

小学5年生の理科「天気の変化」で使うシミュレーションです。
日本付近の雲の動きから天気の変わり方を調べ、明日の天気を予想する学習と、台風の進み方・台風による雨や風・防災の学習ができます。

- 日本付近では、雲はおよそ西から東へ動く。そのため、天気もおよそ西から東へ変わる
- 西の地いきの天気を調べると、明日の天気を予想できる
- 台風は日本の南のあたたかい海で生まれ、はじめは西や北へ、日本付近では東よりに進むことが多い
- 台風の中心に近いほど、雨や風が強い。大きな災害がおきることがあるので、そなえが大切

## ① 雲の動き

| 部分・操作 | 内容 |
|---|---|
| 地図 | 日本付近を上から見た図（気象衛星の写真のような絵）。白いところが雲 |
| ◀ ▶・スライダー | 1日目 午前9時〜4日目 午前9時を、3時間ずつ・自由に動かす |
| 再生 | 雲が動くようすを再生する。はやさは ゆっくり／ふつう／はやおくり |
| 雨のところ ON/OFF | 雨がふっているところを、青いしまもようで出す |
| 動きの矢印 ON/OFF | 12時間で雲が動いたきょりを矢印で出す |
| 下のらん | 福岡・大阪・東京の天気（マークと文字） |
| 天気の表 | 時間が進むと、朝9時・夜9時の天気が入る。雨（しまもよう）が、福岡→大阪→東京の順に、ななめにならぶ |
| 記録する | その時刻の3都市の天気をワークシートに記録する |
| 発展：天気図（先生モードのみ） | 低気圧・高気圧・寒冷前線・温暖前線を重ねて出す（中学校の内容） |

### 雲のモデル（HTML の中の `SYSTEMS`・`CLOUD`・`RAIN`・`SPEED` で変えられます）

- 雲のかたまりは、北東〜南西にのびた形。まん中の方が雨のところ
- 1時間に経度0.45度ずつ東へ動く（日本付近で1日に約1000km）
- 福岡は2日目の朝、大阪は2日目の夜、東京は3日目の朝に雨になる

## ② 天気を予想しよう

1〜3日目の正午の雲と雨のところを見て、4日目の正午の天気（晴れ／くもり／雨）を予想するクイズ（5問）。答えると4日目の図が出て、答えと理由がわかります。答えはワークシートに記録されます。

## ③ 台風

| 部分・操作 | 内容 |
|---|---|
| 地図 | 日本の南の海までふくめた図。台風が生まれるあたたかい海に、点線のわく |
| よくある進み方 | 8月・9月・10月の主な進み方（学習用の模式）。線のもようで区別する |
| 台風を進める | えらんだ月の進み方にそって、台風が動く |
| 台風をドラッグ | 地図の上をタップ・ドラッグすると、台風がそこへ動く |
| 強い風の地いき | 強風域（黄＋しま）と暴風域（赤だいだい＋あみ）。進む向きの右側に少しずれている（右側は風が強い） |
| 雨雲 | 反時計回りのうずの雲 |
| 風の向き | 反時計回りに、中心へふきこむ風の矢印 |
| 都市の表 | 那覇・鹿児島・福岡・大阪・東京・仙台・札幌の雨・風の強さ。「ない／弱い（点）／強い（しま）／とても強い（あみ）」を色・もよう・文字で出す |

## ④ 防災

- ハザードマップ：川の近くの「水につかるおそれ」、山の下の「がけくずれのおそれ」の地いきを見て、Ａ（小学校）・Ｂ（高台の公民館）のどちらにひなんするかを選ぶ
- 注意報・警報・特別警報のちがい、市町村が出す警戒レベル（3・4・5）
- 台風が来る前のそなえ
- ○×クイズ（4問）

## じっさいとのちがい

- 雲・雨のところ・台風の進み方や強さは、本物の気象データではなく、学習用の模式です。
- 日本付近の雲は西から東へ動くことが多いですが、夏や台風のときなど、そうならないこともあります。
- 台風の大きさ・強さ・進む速さは1つ1つちがいます。日本の北の方では勢力が弱まることもありますが、この教材では大きさを変えていません。
