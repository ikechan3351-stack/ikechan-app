# 流れる水のはたらき

小学5年生の理科「流れる水のはたらき」で使うシミュレーションです。
砂場のしゃ面に作った川に水を流して、流れる水のはたらきを調べます。曲がったところのようす、石の形、大雨と災害・そなえ、上流〜下流の景色も学べます。

- 流れる水には、土をけずる（侵食）・運ぶ（運搬）・積もらせる（堆積）はたらきがある
- 流れが速いほど、けずる・運ぶはたらきが大きい。かたむきが急なとき・水の量が多いときは流れが速くなる
- 曲がったところでは、外側は流れが速くけずられ（がけ）、内側は流れがおそく積もる（川原）
- 上流の石は大きく角ばっていて、下流の石は小さく丸い
- 大雨で水がふえると、はたらきが急に大きくなり、災害がおきることがある

## ① 水を流してみよう

| 部分・操作 | 内容 |
|---|---|
| 左の図 | 砂場のしゃ面を上から見た図。上のじょうろから水を流し、下の池に流れこむ |
| 右上の図（断面） | 川を横に切った図。点線がはじめの形。上に流れの速さ（ぼうの長さ）、下に「外側・内側」 |
| 右下の図 | 上流から下流までの川底の高さ。青い線が水面 |
| しゃ面のかたむき | ゆるい／ふつう／急。変えると、しゃ面を作り直す |
| 水の量 | 少ない／ふつう／多い |
| 水を流す・止める | 30秒流すと自動で止まる |
| 大雨 ON/OFF | 水の量を一気にふやす。記録の条件に「大雨」と付く |
| 記録する | 条件・時間・けずられた土・運ばれた土・積もった土（cm³）をワークシートに記録する |
| はやさ | ゆっくり／ふつう／はやおくり |
| けずれた・積もった | けずられたところを「しま」、積もったところを「点」のもようで出す |
| 流れの速さ | 矢印の長さで流れの速さを出す |
| 土のつぶ | けずられた土のつぶが運ばれ、おそいところで止まるようす |
| 左の図をタップ・ドラッグ | 断面を見る場所が変わる（はじめは曲がっているところ） |

### 計算のしかた（HTML の中の `SIM` で数字を変えられます）

- 川にそって100本の断面をならべ、1本を33のますに分けて、ますごとの土の高さを計算します。
- 水の量に合うように水面の高さを決め、深いところ・かたむきが急なところほど流れが速くなります。曲がったところでは外側ほど速くします。
- 流れが一定の速さ（`VC`）をこえると、運べる土の量（運ぱんする力）がふえ、余ゆうがあれば土をけずり、運びきれなければ積もらせます。曲がったところでは、運ぶ土が内側へよせられます。
- 岸が急になりすぎると、くずれ落ちます（外側の岸がしだいにけずられて広がる）。
- 目安の結果（30秒）：かたむき ゆるい／ふつう／急 で、けずられた土 約140／210／280 cm³。水の量を多くしたり、大雨にしたりすると大きくふえる。

## ② 曲がったところ・石の形

- **曲がったところ**：上から見た図と、A（外側）・B（内側）を結ぶ線で切った断面。矢印の長さで流れの速さをくらべ、3問のクイズ（速いのは？ がけになるのは？ 川原になるのは？）に答えると、図に答えが出る。A・B をタップすると説明が出る。
- **石の形**：「石を流す」か、上の川の石（●）をドラッグすると、上流から下流へ運ばれるうちに、角がとれて小さく丸くなるようすが見られる。上流・中流・下流の石の見本つき。

## ③ 大雨のとき

| 部分・操作 | 内容 |
|---|---|
| 雨 | 大雨／記録的な大雨 |
| てい防・ダム・砂防ダム | ON/OFF を変えて、くらべる |
| 左の図 | 上流の山（ダム・砂防ダム）と、町を流れる川の断面。水が岸（てい防）をこえると、町に水があふれる |
| 右のグラフ | 雨の強さ（上）と、川の水の高さの変わり方（48時間）。川岸・てい防の高さの線つき |
| メーター | 川の水の量・流れの速さ・けずる運ぶ力（ふだんの何倍か） |

結果のめやす：大雨では、そなえがないとあふれ、てい防かダムのどちらかがあればあふれない。記録的な大雨では、ダムがいっぱいになり、てい防があってもあふれる（早めのひなんが大切）。

## ④ 川の景色

左の地図の番号をタップすると、上流（V字谷）・山から平地に出るところ（扇状地）・中流（曲がって流れる川と川原）・下流・河口（三角州）の絵と説明が出ます。下に上流・中流・下流のくらべ表があります。

## じっさいとのちがい

- ① の砂場はコンピューターの中の計算で、土の量（cm³）はだいたいの目安です。けずれ方は流れの速さだけで決まるようにかんたんにしていて、土のつぶの大きさ・重さのちがい、水がしみこむことは考えていません。
- ② の石の形や ④ の景色ができるまでには、何千年・何万年もかかります。
- ③ の雨の量・水の高さ・ダムのため方は学習用の模式です。「けずる・運ぶ力」は速さの3乗にくらべるとしています。
