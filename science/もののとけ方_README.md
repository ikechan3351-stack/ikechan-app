# もののとけ方

小学5年生の理科「もののとけ方」で使うシミュレーションです。
食塩・ミョウバン・ホウ酸・砂糖を水にとかし、とける量の限り、重さ、取り出し方を調べます。

- 水にものがとけても、全体の重さは変わらない
- 水にとける量には限りがあり、水の量や温度で変わる（食塩は温度でほとんど変わらず、ミョウバンは大きく変わる）
- とけたものは、水を蒸発させたり、水よう液を冷やしたりすると取り出せる

## 基本情報

- **ファイル**：`もののとけ方.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例、画面の下に先生用のメモが出ます。
- **保存**：ワークシートは localStorage に保存されます（キー：`ikechan-science-もののとけ方`）。

## 4つのタブ

| タブ | 内容 |
|---|---|
| ① とかす | とかすもの（食塩・ミョウバン・ホウ酸・砂糖）、水の量（50／100／200mL）、水温（10〜60℃、10℃ごと）を決めて、さじで1ぱい（5はい）ずつ入れる。「かきまぜる」ボタンか、ビーカーの中を指でなぞるとかきまぜられる。とけ残りが出たら「記録する」 |
| ② 重さはかわる？ | 水100g（20℃）ととかすもの（5／10／20g）を電子てんびんでのせてはかる → おろしてとかす → 薬包紙といっしょにもどしてはかる。とかす前と後が同じ重さになる |
| ③ 取り出す | 60℃の水50mLにとけるだけとかした液（とけ残りあり）を、ろ過 → 氷水で10℃まで冷やす／10mLを蒸発皿で熱する。出てきたつぶの形を「虫めがね」で大きく見られる |
| ④ つぶのモデル | 食塩（色なし）・コーヒーシュガー（色つき）・でんぷん（とけない）を水に入れたときの「見たようす」と「つぶで考えると」をならべて見る |

### ① とかす のくわしい動き

- さじ1ぱい：食塩・ミョウバン・ホウ酸は1g、砂糖は10g（砂糖はとてもたくさんとけるため）。
- とけたものは、形と色のちがうつぶ（食塩■・ミョウバン◆・ホウ酸▲・砂糖●）で見える化。「とけたもののつぶを見る」を消すと、本物のようにすき通って見える。
- とけているあいだは、とけ残りの上に「もやもや」が見える。
- とけ残りがあるときに水温を上げたり水をふやしたりすると、とけ残りがとける。とかした後に水温を下げると、つぶ（結晶）が出てくる。
- 水をへらすことはできない（「もういちど」で新しい水からはじめる）。とかすものを変えると、新しい水にとりかえる。
- 記録する量：とけ残りが出る前までに入ったさじの数 × 1ぱいの量（例：食塩・水100mL・20℃ → 35g）。同じ条件は2回記録しない。

### ③ 取り出す のくわしい動き

| もの | 冷やす（60℃→10℃、水50mL） | 蒸発させる |
|---|---|---|
| 食塩 | 約0.7gだけ（立方体のつぶ） | 白いつぶが出てくる |
| ミョウバン | 約25g（正八面体のつぶ） | 白いつぶが出てくる |
| ホウ酸 | 約5.6g（うすい六角形の板） | 白いつぶが出てくる |
| 砂糖 | 約48g（はしらの形）※本物は出にくい | 最後にこげて茶色になる |

蒸発させるときは、水が少し残ったところで火が自動で止まり、のこった熱で水がなくなります。

## とける量のめやす（水100mL・g）

| | 10℃ | 20℃ | 30℃ | 40℃ | 50℃ | 60℃ |
|---|---|---|---|---|---|---|
| 食塩 | 35.8 | 35.8 | 36.1 | 36.3 | 36.7 | 37.1 |
| ミョウバン | 7.6 | 11.4 | 16.6 | 23.8 | 36.4 | 57.4 |
| ホウ酸 | 3.6 | 4.9 | 6.8 | 8.9 | 11.4 | 14.9 |
| 砂糖 | 191 | 204 | 220 | 238 | 260 | 287 |

- 理科年表などの値を丸めた教育用のめやすです。ミョウバンは、焼きミョウバンではなく結晶のミョウバン（カリウムミョウバン）の値です。
- 水の量に比例させています（50mLなら半分、200mLなら2倍）。
- 数を変えたいときは、HTMLの中の `SUBS` を書きかえます（教科書の値に合わせたいときなど）。

## ワークシート

- もんだい：水の温度を上げると、食塩はたくさんとけるだろうか？
- 予想：たくさんとけるようになる／あまり変わらない／とける量がへる
- 結果：表（とかしたもの・水の量・水温・とけた量）と、温度ととける量の折れ線グラフ（ものごとに線が分かれる）
- グラフは、水の量が同じ記録どうしでくらべてください。

## じっさいとのちがい

とける量は10℃ごとのめやすを直線でつないで計算しています。とけるまでの時間・水温が変わる時間・ろ過や蒸発の時間は、本物より短くしています。ホウ酸は1ぱい1gなので、水50mLではとける量が「2g」のようにあらく出ます。冷やしたときのつぶは、本物ではゆっくり冷やすほど大きくなります。つぶ（■◆▲●）はとけたもののイメージで、本物のつぶはけんび鏡でも見えないくらい小さいです。
