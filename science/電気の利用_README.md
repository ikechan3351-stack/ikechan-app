# 電気をつくって、ためて、使おう

小学6年生の理科「電気の利用」で使うシミュレーションです。
手回し発電機や光電池で電気をつくり、コンデンサーにためて、光・音・熱・運動に変えて使います。省エネ（節電）と、センサーを使ったプログラミング体験もできます。

- 電気は、つくったり、ためたりできる
- 電気は、光・音・熱・運動などに変えて使われている
- 電気の使い方に気をつけて、むだなく使うくふうがある（センサーとプログラムで自動にするしくみもある）

## 基本情報

- **ファイル**：`電気の利用.html`（画面の題名は「電気をつくって、ためて、使おう」）。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）と `circuit-engine.js`（回路の計算部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例、各タブの下に先生用のメモが出ます。⑤には「解答例」ボタンも出ます。
- **保存**：ワークシートは localStorage に保存されます（キー：`ikechan-science-電気の利用`）。
- **音**：③の電子オルゴール・スピーカー、②の電子オルゴールで音が出ます。はじめは「音を出さない」になっていて、③の「🔇 音を出さない」ボタンで切りかえます。

## 5つのタブ

| タブ | 内容 |
|---|---|
| ① つくる | **手回し発電機**：ハンドル（赤い丸）を指でぐるぐる回すか、「回す速さ」のスライダー（0〜3回/秒）で回す。回す向き（右回り・左回り）を切りかえ。つなぐ物は発光ダイオード・豆電球・モーター。明るさ・回る速さ・電流の向き（つぶと矢印）・手ごたえが分かる。発光ダイオードは、ゆっくり（1.5回/秒以下）では光らず、向きを反対にしても光らない。「📍 結果を記録」でワークシートの表に入る。**光電池**：光の強さ（0〜100%）と当て方（正面から・ななめから・半分をおおう）を変えて、モーターの回り方をくらべる。「📍 表に記録」で下の表に入る |
| ② ためる | 回す回数（10・20・40回）をえらんで「① ためる」→ つなぐ物（豆電球・発光ダイオード・電子オルゴール）をえらんで「② つないで使う」。光った（鳴った）時間を表に記録し、ためた電気の量の変わり方をグラフにかく（最大4回分）。公平にくらべるため、ためるときは毎回空にしてからためる。時間の進み方は ゆっくり／ふつう／はやおくり |
| ③ 変える | 手回し発電機（1秒に2回）で、豆電球・発光ダイオード（光）、電子オルゴール・スピーカー（音）、電熱線（熱）、モーター（運動）を動かす。ためした変かんに ✔ が付く。**発展**：かん電池2こ（直列）に細い電熱線・太い電熱線をつなぎ、水 50mL の温度の上がり方を5分間くらべてグラフにする。**クイズ**：身の回りの道具8つが、電気をおもに何に変えているか |
| ④ むだなく | LED電球（7.5W）と白熱電球（60W）をつけて、消費電力・表面の温度・光と熱になる割合をくらべる。1日に使う時間（1〜12時間）から、1年間の電気の量・電気代・寿命の表を作る。**節電ゲーム**：家の間取り図（リビング・台所・子ども部屋・洗面所）の電気製品をタップして ON/OFF。3つの場面で、いらない電気を消して「これでOK！」→ ★で評価。冷蔵庫など、消してはいけない物もある |
| ⑤ プログラム | 「もし〜なら（でなければ）」「明かりをつける／消す」「〜秒まつ」のブロックを「ずっと くり返す」の中にならべる（↑↓で入れかえ、✕で消す、8こまで）。明るさのスライダーと「人が来る」ボタンで、人感センサー・明るさセンサーを動かして「▶ 動かす」。「✅ テストする」で、ミッションの条件を自動でためして ⭕❌ を出す。ミッション1：暗くなるとつく街灯／ミッション2：夜、人が来たときだけつく玄関の明かり／ミッション3：人がいなくなっても、しばらくついている明かり |

### 書きかえたいとき

- 手回し発電機の電圧：`GEN_K`（1回/秒あたりのV）、中の電気の通りにくさ：`GEN_R`、スライダーの最大：`GEN_MAX`
- 発光ダイオードが光りはじめる電圧：`VF`、コンデンサーの大きさ：`CAP_F`、電子オルゴールが鳴る電圧：`MELODY_V`
- 部品の電気の通りにくさ：`CircuitEngine.defineType(...)` の行（発光ダイオード・電子オルゴール・スピーカー・電熱線）
- 電熱線の発展の太さ：`HEAT5`、水の量：`WATER_G`
- 身の回りの道具クイズ：`QUIZ`
- 電球のデータ：`LAMP`、電気代：`YEN`
- 節電ゲームの電気製品：`DEV7`、場面：`SCENE7`（`on`＝つけておく物、`off`＝消す物）
- プログラミングのミッション：`MISSION`（`seg`＝明るさと人の変わり方、`chk`＝調べる時刻と正しい明かり、`ans`＝解答例）

## ワークシート

- もんだい：手回し発電機を2倍の速さで回すと、発光ダイオードの明るさはどうなるだろうか？
- 予想：明るくなる／変わらない／暗くなる
- 結果：表（回す速さ・回す向き・発光ダイオードの明るさ・豆電球の明るさ・モーターの速さ）。明るさ・速さは「3回/秒で回したときを100」とした数。グラフは折れ線で、横じく＝回す速さ。発光ダイオードの線は、1.5回/秒まで0で、そこから上がっていく形になります（2倍の速さでも、明るさはちょうど2倍にはならない）。

## じっさいとのちがい

手回し発電機の電圧は、回す速さに比例するとしてかんたんにしています。発光ダイオードは約1.8Vから光るとしています（色によってちがいます）。光電池は、一部にかげがあると、本当はもっと大きく電流がへることがあります。コンデンサーの光った時間・電熱線の温度・電気製品の消費電力や電気代は目安です。スピーカーは、音を出す回路につないで鳴らすとしています。プログラムの1つのブロックは0.1秒で実行されるとしています。
