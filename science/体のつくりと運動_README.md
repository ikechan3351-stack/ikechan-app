# 体のつくりと運動

小学4年生の理科「人の体のつくりと運動」で使うシミュレーションです。
うでのしくみ（骨・筋肉・関節）を動かしながら、体が動くわけを調べます。

- 体には骨と筋肉があり、骨と骨のつなぎ目（関節）で曲げられる
- 体を動かせるのは、筋肉がちぢんだりゆるんだりして、骨を引っぱるから
- うでを曲げると内側の筋肉がちぢみ、のばすと外側の筋肉がちぢむ
- 骨には、体をささえる・中のもの（脳・心臓・肺）を守るはたらきがある

## 基本情報

- **ファイル**：`体のつくりと運動.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例が出ます。

## ① うでの曲げのばし

| 操作 | 内容 |
|---|---|
| 手・下のうでをドラッグ | ひじを 0°（まっすぐ）〜145° まで曲げのばしする。反対には曲がらない |
| 曲げた角度のスライダー | ドラッグのかわりに、角度を変えられる |
| 筋肉の表示 | ちぢむ＝太い・こいオレンジ・横じま・実線・「→ちぢむ←」／ゆるむ＝細い・うすい色・たてすじ・点線・「←ゆるむ→」。下の2つの表示らんにも出る |
| 矢印 ON/OFF | ちぢむ筋肉が骨を「引っぱる」矢印 |
| はだ ON/OFF | うでの外がわの形（皮ふ）を出す・消す |
| 自動で曲げのばし | 曲げのばしをくり返す。はやさは ゆっくり／ふつう／はやおくり |
| 筋肉・骨・けん・関節をタップ | 名前とはたらきの説明 |
| 記録する | 角度・曲げる/のばす・内側と外側の「ちぢむ/ゆるむ」をワークシートの表に入れる |
| もういちど | まっすぐにもどす（ワークシートの記録は残る） |

「ちぢむ／ゆるむ」は、動かした向きで決まります（曲げている途中＝内側がちぢむ、のばしている途中＝外側がちぢむ）。止めたときは、最後に動かした向きのままです。

## ② 全身の骨

- 頭の骨・せぼね・ろっ骨・こつばん・うでの骨・あしの骨を、図か右の名前をタップすると、黄色くなって名前とはたらきが出ます。
- **中のもの ON**：脳・肺・心臓が出ます。骨が守っていることが見えます。
- **関節をさがそう**：かた・ひじ・手首・こし（またのつけね）・ひざ・足首の12か所をさがします。骨のとちゅうをタップすると「✖」が出ます。「答えを見る」で全部の場所が出ます。

## ③ 関節の動き方

- 左の「ひじ」：手（✋）をドラッグ。曲げのばしだけで、反対や 145°より先には動きません（ドアのちょうつがいのよう）。
- 右の「かた」：手をドラッグすると、ぐるぐる回せます（ボールとくぼみ）。1周回ると「🎉」が出ます。
- 動いたあと ON/OFF：手の通った道を点線で残します。

## ④ うでのモデル

厚紙の板2枚（骨）を わりピン（関節）でとめ、ゴム2本（筋肉）を付けたモデルです。

| 操作 | 内容 |
|---|---|
| ◎内／◎外 のわっかを左へドラッグ | そのゴムを引っぱる。内側を引くと曲がり、外側を引くとのびる |
| 「内側のゴムを引く」「外側のゴムを引く」 | おしているあいだ引きつづける |
| わっかを右へおす | 「ゴムは おせない」と出る → 曲げる筋肉とのばす筋肉がべつべつにいるわけ |
| 記録する | ①と同じ表に「モデル」として入る |

## しくみの数字（HTML の中の「しくみの数字」）

| 名前 | 意味 |
|---|---|
| `ARM_MAX` | ひじを曲げられる最大の角度（145°） |
| `W_RELAX` / `W_IN_ON` / `W_OUT_ON` | 筋肉の太さ（ゆるむとき／ちぢむとき） |
| `PULL_SPEED` | ④でボタンをおしているときの動く速さ |

## じっさいとのちがい

- うでの筋肉はたくさんありますが、内側と外側の1つずつにしています。
- じっさいには、ゆるむほうの筋肉にも少し力が入っていることがあります。
- かたは、どの向きにも自由に回るわけではありません。
- 骨の形や数は、かんたんにしています。
