# こん虫の育ち方

小学3年生の理科「こん虫の育ち方」「こん虫の体のつくり」で使うシミュレーションです。
5種類のこん虫から1つを選び、たまごから成虫になるまでを、日数を進めて観察します。体のつくりの観察と、仲間分けクイズもできます。

- こん虫の体は、頭・むね・はらの3つに分かれている。あしは、むねに6本ついている
- 育ち方には、たまご → 幼虫 → さなぎ → 成虫 と、たまご → 幼虫 → 成虫（さなぎにならない）の2つがある

## 基本情報

- **ファイル**：`こん虫の育ち方.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、「先生用メモ」と、ワークシートの先生用ヒント・解答例が出ます。「完全変態」「不完全変態」という言葉は、ここにだけ出します（3年の教科書では使わないため）。

## 4つのモード

| モード | 内容 |
|---|---|
| 🔍 育ち方 | 虫を選び、日数スライダーか「さいせい」で、たまご → 幼虫 → （さなぎ） → 成虫 を絵で見る。だんかいの名前・日数・大きさのめやす・せつめいが出る |
| 🐞 体のつくり | 成虫をせなかがわから見た図。頭・むね・はらを色ともよう（点・よこじま・ななめの線）で分ける。部分をタップすると名前とはたらきが出る |
| 🧺 仲間分けクイズ | 8まいのカードを「こん虫」「こん虫ではない」の箱にドラッグして分け、答え合わせで○✕と理由を出す |
| 📏 くらべる | 2つの虫の育ち方を、2本のタイムラインにならべてくらべる。さなぎにならない虫は「さなぎの時期は ない」と出る |

## 虫と育ち方のめやす

| 虫 | たまご | 幼虫 | さなぎ | 成虫 | もとにした月 |
|---|---|---|---|---|---|
| モンシロチョウ | 約5日（キャベツの葉の上） | 約2週間（青虫・だっ皮4回） | 約10日 | 約2週間 | 5月1日にたまご |
| カブトムシ | 約2週間（土の中） | 約10か月（だっ皮2回・土の中で冬をこす） | 約3週間（さなぎの部屋） | 約1〜3か月 | 8月1日にたまご |
| トンボ（シオカラトンボ） | 約10日（水の中） | 約10か月（ヤゴ・だっ皮10回・水の中で冬をこす） | ない | 約1〜2か月 | 7月1日にたまご |
| バッタ（トノサマバッタ） | 約7か月（土の中で冬をこす） | 約40日（だっ皮5回） | ない | 約2か月 | 10月1日にたまご |
| カマキリ（オオカマキリ） | 約6か月半（らんのうで冬をこす） | 約3か月（だっ皮7回） | ない | 約2か月 | 10月15日にたまご |

数字は HTML の中の `BUGS`（虫のデータ）でかえられます。

## 育ち方モードの操作

| 操作 | 内容 |
|---|---|
| さいせい／とめる | 日にちが進む。「ゆっくり（40秒）／ふつう（20秒）／はやおくり（8秒）」で、たまごから終わりまでの時間がかわる |
| だんかいのかわり目 | 再生がしばらく止まり、「さなぎになった！」「幼虫から、そのまま成虫になった！」などと知らせる |
| だっ皮 | 幼虫が皮をぬぐ日に「だっ皮した！（○回目）」と出て、絵がひとまわり大きくなる |
| 日数スライダー | 好きな日に動かせる。下の目もりは日数（モンシロチョウ）か月（ほかの虫） |
| 育ち方を記録する | 成虫まで進めると、ワークシートの表に「育ち方の順」と「さなぎの時期（ある／ない）」を記録できる |
| もういちど | えらんでいる虫を、たまごの日にもどす |

- **予想を大切にするしくみ**：まだ見ていないだんかいは、帯も「育ち方の順」も「？」になります。虫のタブの「さなぎは？」も、成虫まで進めると「● さなぎになる」「▲ さなぎにならない」にかわります。「もういちど」で「？」にもどります。
- 冬の月は、空が灰色になって雪がふります。カブトムシ・トンボ・バッタ・カマキリが冬をこすようすがわかります。
- たまごなど小さいものは「大きくしてかいています」と出ます。ほんとうの大きさは「大きさ（めやす）」に出ます。

## 体のつくりモード

- タップできる部分：頭・むね・はら・しょっ角・目・口・あし・はね（カブトムシは角も）。「見つけたもの」に✔が付きます。
- あしをタップすると、6本に1〜6の番号が出ます。どれもむねから出ていることがわかります。
- はねはすかして点線でかいているので、はねの下の体のつくりも見えます。
- カブトムシのむねは、せなかから見える大きな部分と、前ばねの下にかくれた部分の両方です。カマキリの細長い「首」もむねです。
- 「色分け」を OFF にすると、ふつうの色で見られます。

## 仲間分けクイズ

| こん虫 | こん虫ではない |
|---|---|
| チョウ・アリ（はねがなくてもこん虫）・テントウムシ・セミ | クモ（あし8本・体が2つ）・ダンゴムシ（あし14本）・ミミズ（あしがない）・ムカデ（あしが40本くらい） |

- カードはドラッグのほか、「カードをタップ → 箱をタップ」でも動かせます。
- 「もういちど」で、カードがまぜなおされます。

## ワークシート

- **問題**：トンボには、さなぎの時期があるだろうか？
- **予想**：さなぎの時期がある／さなぎの時期はない／わからない
- **結果**：記録した虫・育ち方の順・さなぎの時期（ある／ない）の表（グラフはなし）

### じっさいとのちがい

- 日数は目安で、気温や地いき、年によってかわります。だっ皮の回数も目安です。
- 絵はかんたんにしていて、大きさも見やすいようにかえています。
- トンボはシオカラトンボ、バッタはトノサマバッタ、カマキリはオオカマキリをもとにしています。
