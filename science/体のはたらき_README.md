# 体のはたらき

小学6年生の理科「人の体のつくりと働き」で使うシミュレーションです。
食べ物・空気・血液が体の中をどう通るかを、アニメーションで見ます（今ある「人体のつくりクイズ」はクイズとして残し、こちらは「動きで見る」教材にしています）。

- 食べ物は、口 → 食道 → 胃 → 小腸 → 大腸 → こう門 と通る（消化管。大人で約9m）。だ液などの消化液で消化され、養分はおもに小腸で、水分はおもに大腸で吸収される
- 肺で、空気中の酸素が血液に取り入れられ、血液から二酸化炭素が出される。はいた息は、酸素 約21％→約17％、二酸化炭素 約0.04％→約4％
- 心臓は血液を全身に送り出すポンプ。血液は、心臓 → 全身 → 心臓 → 肺 → 心臓 とめぐる。拍動は脈はくとして感じられ、運動するとふえる
- 血液は、養分と酸素を全身に運び、二酸化炭素と不要なものを運び出す。不要なものは、じん臓でこし出されてにょうになり、ぼうこうにためられる

## 基本情報

- **ファイル**：`体のはたらき.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例、画面の下に先生用のメモが出ます。心臓の4つの部屋の名前（右心房など）、体循環・肺循環、鳥の気のうなども、先生モードだけ図に出ます。
- **保存**：ワークシートは localStorage に保存されます（キー：`ikechan-science-体のはたらき`）。

## 5つのタブ

| タブ | 内容 |
|---|---|
| ① 消化 | **食べ物の旅**：「ごはんを食べる」で、ごはん（でんぷんのつながった●）が口から順に進む。小腸では養分（黄色の◆）が血液へ、大腸では水分（水色のしずく）が吸収される。右の表に、出る消化液と、じっさいの時間のめやす。**消化管をのばす**：口・食道・胃 約0.5m＋小腸 約6〜7m＋大腸 約1.5m＝約9m を、大人の身長（約1.6m）とくらべる。**ヨウ素液の実験**：でんぷんの液に A だ液・B 水を入れ、40℃であたため、ヨウ素液を入れる。B だけ青むらさき色。虫めがねの図で、でんぷんのくさりが切れるようす |
| ② 呼吸 | 「じどう／息をすう／息をはく」で、肺・あばら骨・横隔膜が動く。空気のつぶ（酸素は青い●、二酸化炭素はオレンジの■）が出入りする。**気体の割合**（円グラフと表）、**肺のおく**（小さなふくろと毛細血管での酸素・二酸化炭素の受けわたし）、**石灰水**（はいた息だけ白くにごる。ふくろの内側に水てき） |
| ③ 血液 | **血液のめぐり**：体の図で血液のつぶがめぐる（酸素の多い血液＝赤い丸に●、少ない血液＝むらさきの丸に■）。動脈は赤い実線、静脈は青い線に白い点線、毛細血管は細いあみ目。右に大きな心臓の図（拍動に合わせてちぢむ）。**脈はくと運動**：「すわって休む／歩く／走る」を選び、「15秒はかる」→ドクンに合わせて「トン」→×4で1分間の数 →「記録する」でワークシートへ。「自分」を選ぶと、ほんとうの時間で15秒はかれる（自分の手首の脈はく）。「じどうで数える」「メーター（答え）を見る」で、脈はくのグラフも出る |
| ④ まとめ | 4つの層（消化・呼吸・心臓と血管・じん臓）を全部出し、血液が運ぶもの（酸素●・養分◆・二酸化炭素■・不要なもの✕）を見える化。じん臓でこし出されたにょうがぼうこうにたまり、「トイレに行く」で出せる。問題7問（答えると、その臓器が光る） |
| ⑤ 動物 | フナ（えら。水を口から入れてえらを通して出す）・イヌ（肺。人とにている）・ハト（肺。歯がなく砂のうですりつぶす）・人をくらべる。下に、くらべる表 |

- 体の図の臓器（口・食道・胃・肝臓・小腸・大腸・こう門・気管・肺・横隔膜・心臓・血管・毛細血管・じん臓・ぼうこう）をタップすると、黄色く光って、下の説明らんにはたらきが出ます。
- 「見せる」のチェックで、層（臓器のなかま）ごとに出したり消したりできます。タブを変えると、そのタブに合った層にもどります。

### ③ 脈はくのめやす（画面の人）

| 体のようす | 脈はく（1分間） | 呼吸（1分間） |
|---|---|---|
| すわって休む | 約80回 | 約20回 |
| 歩く | 約100回 | 約26回 |
| 走る | 約135回 | 約40回 |

- 急には変わらず、だんだん変わります（ふえるときは約15秒、もどるときは約40秒がめやす）。走ったあと休んで、すぐ15秒はかると約120〜130回になります。

## ワークシート

- 問題：「運動すると、脈はくは何回ふえるだろうか？」
- 予想：ほとんど変わらない／10〜20回くらいふえる／30〜50回くらいふえる／60回以上ふえる
- 結果の表：はかった人・体のようす・脈はく（1分間）・呼吸（1分間）。棒グラフ付き。

## 数を変えたいとき

HTML の中の「数の設定」を書きかえます。

- `HR`・`RR`：休む・歩く・走るときの脈はく・呼吸の数
- `TAU_UP`・`TAU_DOWN`：脈はくがふえるまで・もどるまでの時間
- `MEASURE_SEC`：脈はくをはかる秒数（15秒×4）
- `GAS`：すう空気・はいた息の気体の割合（教科書に合わせて、はいた息の酸素を16％にするなど）

ふりがなは、上のほうの `DICT_SRC`（ふりがな辞書）に `{漢字|よみ}` の形で足すと、ボタンの文字にもキャンバスの中の文字にも付きます。

## じっさいとのちがい

- 臓器の形・大きさ・場所はかんたんにしています（じん臓は、ほんとうはおなかの背中側にあります）。
- 食べ物が進む時間はとても短くちぢめています（ほんとうは1〜2日ほど）。
- 血液や酸素などのつぶは、見えるように大きくかいたイメージです。
- 脈はく・呼吸の数は、人や年れいでちがいます。はいた息の割合はめやすです。
- だ液がでんぷんを変えたもの（麦芽糖など）の名前や、小腸のじゅう毛、心臓の4つの部屋の名前、体循環・肺循環は中学校の内容なので、先生モードだけで説明しています。
