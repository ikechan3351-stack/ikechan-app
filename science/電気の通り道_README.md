# 豆電球をつけよう！電気の通り道

小学3年生の理科「電気の通り道」で使うシミュレーションです。次のことを確かめます。

- 豆電球に明かりがつくのは、かん電池の＋極から豆電球を通って−極まで、回路が1つの輪になっているとき
- 豆電球を通らずに＋極と−極を直接つなぐ（ショート回路）と、電池が熱くなってきけん
- 電気を通す物（鉄・銅・アルミニウムなどの金属）と、通さない物（紙・木・ゴム・プラスチック・ガラス）がある

## 基本情報

- **ファイル**：`電気の通り道.html`。同じフォルダの `circuit-engine.js`（回路の判定）、`worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例が出ます。②では、物の材料（鉄・銅など）がはじめから表示されます。

## 画面（上のタブで切りかえ）

| タブ | 内容 |
|---|---|
| ① 回路をつくろう | かん電池・豆電球（ソケット付き）・スイッチを部品箱からドラッグしておき、たんしどうしをどう線でつなぐ。お手本（きほんの回路・スイッチつき）もある |
| ② 電気を通す物しらべ | とちゅうにクリップがある回路に、12この物をはさんで、明かりがつくかを調べる |

## 操作

| 操作 | 内容 |
|---|---|
| 部品箱の部品をドラッグ | じっけん台におく（タッチだけなら、あいている所におく）。かん電池・豆電球・スイッチは2こまで |
| たんし（●）からなぞる | べつのたんしまでなぞると、どう線が引ける |
| 部品をドラッグ | 動かす。じっけん台の外まで出して手をはなすと、とりのぞける |
| 部品・どう線をタッチ | えらぶ（オレンジの点線）。「↻ 回す」で90°ずつ回す、「🗑 とる」でとりのぞく |
| スイッチをタッチ | 「入」「切」が切りかわる |
| 🔍 ヒント | つかないとき、行き止まりのたんしなどに「？」の印を出し、理由を表示する |
| 電流のつぶ ON/OFF・ゆっくり／ふつう／はやおくり | 電流のつぶ（＋極から−極へ流れる）を出す／かくす、速さを変える |
| 予想のボタン・物をドラッグ（②） | 予想（○つく／×つかない）を選んでから、物をクリップのあいだにはさむ。タッチだけでもはさめる。はさんだ物をタッチするともどる |
| もういちど | そのタブを、はじめの状態にもどす（ワークシートは消えません） |

### 表示とヒント

- **ついた**：豆電球が光り、まわりに光の線が出る。じょうたいの欄が黄色になる。
- **ショート回路**：「⚠ あぶない！電池が熱くなるよ」と赤いしまもようの欄で知らせ、電池に「⚠ あつい！」とゆらゆらした線が出る。電流のつぶがとても速く流れる。
- **つかないとき**：まず「どこが切れているかな？」とだけ出して考えさせる。「ヒント」で、次のように理由を出す。
  - どこにもつながっていないたんし → 「？」の印
  - 豆電球の2本の線が、どちらも電池の同じ極につながっている
  - スイッチが「切」になっている
  - はさんだ物が電気を通さない

## ワークシート

- **問題**：回路のとちゅうに消しゴムをはさむと、豆電球の明かりはつくだろうか？
- **予想**：つく／つかない
- **結果**：②で調べた物・何でできているか・予想・明かりがついたか の表（調べると自動で記録。グラフはなし）

## 正しさについて（じっさいとのちがい）

- 電流のつぶは、目に見えない電気の流れを見やすくしたものです。電流の向きは、かん電池の＋極から−極へと決められています。
- じっさいのエナメル線は、はしのまくを紙やすりでけずらないと電気を通しません（このシミュレーションのどう線は、はじめから通します）。
- ショート回路は、じっさいの実験ではぜったいにしません。
- 電流の大きさは、かん電池1こ＝1.5V、豆電球＝5Ω として計算しています（`circuit-engine.js`）。

## 改造のしかた

- 調べる物をふやすときは、HTML の中の `ITEMS`（物の一覧）に1行たし、`ICON` にその物の絵（SVG）を足します。`cond: true` なら電気を通します。
- 部品の形・たんしの位置は `PARTS` に書いてあります。おける数は `max` で変えられます。
- 回路の計算（つながりの判定・ショートの判定・ヒントの理由）は、共通ファイル `circuit-engine.js` にあります。ほかの学年の教材でも使うので、変えるときは使っている教材も確かめてください。
