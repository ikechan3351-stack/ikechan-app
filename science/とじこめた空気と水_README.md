# とじこめた空気と水

小学4年生の理科「空気と水の性質」で使うシミュレーションです。
先をふさいだ注しゃ器で、とじこめた空気と水をおしくらべます。

- とじこめた空気はおしちぢめられる。体積が小さくなるほど、おし返す力（手ごたえ）が大きくなる
- 手をはなすと、空気は元の体積にもどる
- とじこめた水はおしちぢめられない（おしても体積はかわらない）
- 空気でっぽうは、前玉と後ろ玉の間のちぢめられた空気が、元にもどろうとして前玉をおし出す

## 基本情報

- **ファイル**：`とじこめた空気と水.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例が出ます。

## 画面

| 部分 | 内容 |
|---|---|
| ① 空気と水をくらべる | 先をゴムでふさいだ注しゃ器が2本（左：空気 ○、右：水 ■）。目もりは0〜120mL |
| 体積と手ごたえ | 2本それぞれの体積（mL）と、手ごたえ（★1〜5）。★は「おし返す」「引きもどす」の文字つき |
| 力の矢印 | オレンジ＝手がおす（引く）力、青＝空気や水がおし返す（引きもどす）力。太く長いほど大きい |
| つぶ | 空気のつぶは動き回り、おすとつぶの間がつまる。水のつぶははじめからすき間なくぎっしり |
| ② 空気でっぽう | つつ・後ろ玉・前玉・おし棒と、0〜5m のものさし。飛んだところに ▼ とつめ方の名前が残る |
| 4つのだんかい | ①後ろ玉をおす → ②間の空気がちぢめられる → ③空気が前玉をおし返す → ④前玉が飛び出す。今のだんかいが光る |

## 操作

| 操作 | 内容 |
|---|---|
| スライダー | 2本の注しゃ器を同じだけおす（引く）。おさえたままになる |
| ドラッグ | さわった注しゃ器だけをおす（引く）。指をはなすと元にもどる |
| 記録する | おしているときの「とじこめたもの・体積・手ごたえ」をワークシートの表に記録（空気と水を1行ずつ）。同じ記録は1回だけ |
| 手をはなす | スライダーでおさえていたピストンをはなす。空気はふくらんで元の100mLにもどる |
| つつの中 | 空気／水を入れてみる。水だと前玉はチョロッと出て、すぐ下に落ちる |
| 前玉のつめ方 | ゆるい・ふつう・きつい。きついほど空気を強くちぢめてから飛び出し、遠くまで飛ぶ |
| ぐーっとおす | おし棒を一定のはやさでおす（おし棒は右へドラッグしてもおせる） |
| つぶ ON/OFF・力の矢印 ON/OFF | 見える化の切りかえ（両方のタブで使える） |
| ゆっくり／ふつう／はやおくり | つぶの動き・ピストンがもどるはやさ・空気でっぽうの動きのはやさ |
| もういちど | 注しゃ器と空気でっぽうをはじめにもどす（ワークシートの記録は残る） |

## ワークシート

- **問題**：とじこめた水をおすと、空気と同じように体積が小さくなるだろうか？
- **予想**：空気と同じくらい小さくなる・少しだけ小さくなる・小さくならない
- **結果**：表と、横じく＝体積、たてじく＝手ごたえ（★の数）の点グラフ。空気は●が右下がりにならび、水は■が100mLのところにたてにならぶ

## 正しさについて（じっさいとのちがい）

- 圧力の式は画面に出していません。手ごたえは「100 ÷ 体積 − 1」の大きさを5だんかいに分けたものです（90mL→★1、80mL→★2、70mL→★3、60mL→★4、50mL→★5）。
- 本当は水もほんの少しだけちぢみますが、注しゃ器で強くおしても0.005mLくらいなので、0にしています。
- 空気のつぶは本当は目に見えないほど小さく、数もずっと多いです。ピストンのまさつは考えていません。
- 水は、おした力と同じだけおし返すので、手ごたえは「おした強さ」で表しています。
- 空気でっぽうの飛ぶきょり（ゆるい1.8m・ふつう2.8m・きつい4.2m）は目安です。

## 改造のしかた

- **おせる・引ける量**：`PUSH_MAX`（50mL）・`PULL_MAX`（20mL）を変えます。
- **もどるはやさ**：`RETURN_TIME` を変えます。
- **つぶの数**：`AIR_DOTS`・`GUN_DOTS` を変えます。
- **空気でっぽう**：`POP`（飛び出すときのちぢみぐあい）と `FLY`（飛ぶきょり）を、ゆるい・ふつう・きついの順に書きます。
