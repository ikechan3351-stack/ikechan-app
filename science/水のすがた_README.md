# 水のすがた

小学4年生の理科「水のすがたと温度」で使うシミュレーションです。
ビーカーの水（または氷）を熱したり冷やしたりして、すがたの変わり方と温度の変わり方を、つぶとグラフで見ます。

- 水は温度によって、氷（固体）・水（液体）・水じょう気（気体）にすがたを変える
- 氷がとけている間・水がこおっている間は0℃、ふっとうしている間は約100℃で、温度が変わらない
- ふっとうしているときのあわは水じょう気（気体）、湯気は小さな水のつぶ（液体）
- 水が氷になると体積が約1.1倍になる。氷は水にうく

## 画面

| 部分 | 内容 |
|---|---|
| ビーカー（左） | 200mL のビーカー。熱するときはアルコールランプ・三きゃく・金あみ、冷やすときは氷と食塩（約−15℃）の入れもの |
| つぶ | 氷＝線でつながってきちんとならび、その場でゆれる／水＝自由に動き回る（温度が高いほど速い）／水じょう気＝速く飛び回ってビーカーの外へ出ていく。どのすがたも同じつぶでかいている |
| 氷 | 熱すると、氷のかたまりが水にうく（約9わりがしずむ）。冷やすと、かべと底から氷ができていく |
| 体積 | 赤い点線＝水のときの高さ。ぜんぶ氷になると「約1.1倍にふえた」と出る |
| ふっとう | 底からあわ（中は水じょう気のつぶ）、ビーカーの口のすぐ上は何も見えない部分、その上に白い湯気（つぶが集まった小さな水のつぶ） |
| 温度計 | 赤い液の高さと、上の札の数字（℃） |
| グラフ（右） | 温度と時間（分）。0℃と100℃に点線。平らなところに「とけている間」「ふっとうしている間」「こおっている間」と出る。前の実験の線もうすく残る（4本まで） |
| 温度・すがた・体積 | 今の温度、すがた（氷・氷と水・水・ふっとう中）、体積（mL） |
| 安全メッセージ | 熱するとき：ふっとう石・やけど。冷やすとき：食塩をまぜた氷の冷たさ |

## 操作

| 操作 | 内容 |
|---|---|
| 熱する／冷やす／止める | ランプで熱する、氷と食塩で冷やす、時間を止める（つづきから始められる） |
| はじめ | 氷（−10℃）から／水（20℃）から。えらぶと、はじめからになる |
| 水の量 | 少ない 50mL（▲・点線）／多い 100mL（●・実線）。グラフで、ふっとうまでの時間をくらべられる |
| ゆっくり／ふつう／はやおくり | 時間の進み方（10倍・30倍・120倍） |
| つぶ ON/OFF | つぶの見える化の切りかえ。OFF にすると、本当の見え方（水じょう気は見えない） |
| 記録する／2分ごとに自動記録 | そのときの時間と温度を、ワークシートに記録する |
| グラフを消す | 前の実験の線を消す（今の線は残る） |
| もういちど | 今の実験をはじめにもどす（ワークシートの記録は残る） |
| ビーカーをタップ | 氷・水・あわ・ビーカーの口の上・湯気の説明が出る |

水が、はじめの35％までへると、からだきしないように自動で火を消します。

## 時間の目安（ふつうの速さで）

| 実験 | シミュレーションの時間 | 画面の上の時間 |
|---|---|---|
| 水100mL（20℃）がふっとうするまで | 約10分 | 約20秒 |
| 水50mL（20℃）がふっとうするまで | 約5分 | 約10秒 |
| 氷100g（−10℃）がとけきるまで | 約9分 | 約18秒 |
| 水100mL（20℃）がぜんぶこおるまで | 約17分 | 約35秒 |

## ワークシート

- **もんだい**：ふっとうしているとき、温度はこのあとどうなるだろうか？
- **予想**：どんどん上がっていく／上がらずに、変わらない／下がっていく
- **記録**：水の量・時間（分）・温度（℃）・すがた。グラフは水の量「少ない」「多い」の2本の折れ線
- 保存キー：`ikechan-science-水のすがた`

## しくみ（先生向け）

ランプから毎秒もらう熱（ジュール）を、次の順に使う計算です。

1. 氷の温度を上げる（氷1gを1℃上げるのに 2.1J）
2. 0℃で氷をとかす（1gあたり 334J）→ この間、温度は0℃のまま
3. 水の温度を上げる（水1gを1℃上げるのに 4.2J）
4. 100℃で水を水じょう気にする（1gあたり 2260J）→ この間、温度は100℃のまま

冷やすときは、氷と食塩（−15℃）との温度の差に合わせて熱をうばいます。
数字は HTML の中の「しくみの数字」（`P_HEAT`・`H_COOL` など）でかえられます。

## ※じっさいとのちがい

- 時間ははやく進めています。ランプの火の強さで、本当の時間はかわります。
- 本当の水は100℃ちょうどではなく「100℃近く」でふっとうします。ここでは100℃にしています。
- 教科書では、水をこおらせるときは試験管に少しの水を入れて冷やします。
- 本当は0℃より少し下がってからこおり始めること（過冷却）もありますが、ここでは0℃でこおり始めます。
- つぶは、本当は目に見えないほど小さく、ずっと数が多いです。
