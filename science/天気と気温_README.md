# 天気と気温

小学4年生の理科「天気の様子」で使うシミュレーションです。
空の雲の量から天気を決める練習と、晴れ・くもり・雨の日の1日の気温をはかってグラフにする学習、気温のはかり方の練習ができます。

- 空全体を10として、雲の量が0〜8なら晴れ、9〜10ならくもり。雨がふっていれば雨
- 晴れの日は、1日の気温の変化が大きく、昼すぎ（午後2時ごろ）に最も高くなる
- くもりや雨の日は、1日の気温の変化が小さい
- 気温は、日光が直接当たらない風通しのよいところで、地面から1.2〜1.5mの高さではかる（百葉箱）

## ① 雲と天気

| 部分・操作 | 内容 |
|---|---|
| 空の絵 | 見上げた丸い空（まわりは木）。雲が空の円の何わりをしめるかを、画面の点の数で数えて、雲の量 0〜10 にぴったり合わせている |
| 雲の量のスライダー | 0〜10。雲がふえたりへったりし、右に天気記号（晴れ＝○にたての線、くもり＝◎、雨＝●）と天気が出る |
| 雨 ON/OFF | 雨がふっていれば、雲の量に関係なく「雨」。空が暗くなり、雨のすじが出る |
| マス目を出す | 空を同じ広さの10こに分ける線と番号。雲の量を数えるときの手がかり |
| 新しい空 | 雲の形をかえる |
| もんだい | ランダムな空を見て「晴れ／くもり」を答える。8と9のさかい目が多めに出る。答えたあとに雲の量とマス目が出る |

## ② 気温の変化

| 部分・操作 | 内容 |
|---|---|
| 景色 | 南を向いて見た校庭と百葉箱。太陽は東（左）から南を通って西（右）へ動く。右のらんは百葉箱の中の温度計 |
| 晴れの日／くもりの日／雨の日 | 天気をえらぶ。はかった記録は天気ごとに残り、グラフに3本の線でかさなる |
| ◀ ▶・はかる | 時刻を1時間ずつ動かし、その時刻の気温を記録する（記録すると次の時刻へ進む） |
| 自動で1日はかる | 1時間ごとに自動ではかる。はやさは ゆっくり／ふつう／はやおくり |
| はかり方 | 自動：数字が出る／目もりを読む：温度計を読んで ＋ − で入れる。合っていれば記録、2回まちがえると答えを出す |
| 時間 | 午前9時〜午後3時（教科書と同じ）／朝6時〜夕方6時 |
| 熱の矢印 ON/OFF | 晴れ：日光が地面を温め、地面が空気を温めるようす。くもり：雲が日光をさえぎるようす |
| グラフ | 晴れ＝●実線、くもり＝■点線、雨＝▲こまかい点線（色だけで区別しない）。晴れの日の最も高い時刻に名前が出る |
| まとめの行 | 天気ごとに、いちばん高い・いちばん低い・差（℃） |
| もういちど | グラフを消す（ワークシートの記録は残る） |

| くもり | 17 | 17 | 18 | 18 | 19 | 19 | 20 | 20 | 20 | 20 | 19 | 19 | 18 |

午前9時〜午後3時の差は、晴れ 8℃・くもり 2℃・雨 1℃です。

## ③ 気温のはかり方

| 部分・操作 | 内容 |
|---|---|
| 百葉箱（左） | タップすると、くふうの説明が出る：白い色・よろい戸・とびら（北向き）・しばふ・1.2〜1.5mの高さ・中の温度計。見つけた数（6こ中）が出る |
| 温度計クイズ（右） | 10問。目もりを読む 7問（うち3問は目もりと目もりの間 → 近いほうを読む）・目の位置（真横から読む）2問・はかる場所 1問 |
| もういちど | 新しいもんだいで、はじめから |

0℃より低い温度は出しません（4年の学習のはんいにあわせています）。

## ワークシート

- **もんだい**：晴れの日と雨の日で、1日の気温の変わり方はどうちがうだろうか？
- **予想**：晴れの日のほうが、大きく変わる／雨の日のほうが、大きく変わる／どちらも同じくらい
- **記録**：② で「はかる」と、時刻・天気・気温を記録。グラフは晴れ・くもり・雨の3本の折れ線
- 保存キー：`ikechan-science-天気と気温`

## ※じっさいとのちがい

- 気温は、よくある形にした学習用のデータです。本当の日は、風や雲の動きで、もっとでこぼこします。
- 雲の量は、空の円の中で雲がしめる広さで決めています。
- 雲の量が0〜1のときを「快晴」と分けることもあります。
- 雲の動きと天気の変化（西から東へ）は、5年「天気の変化」でくわしく学びます。
