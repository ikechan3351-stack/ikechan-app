# 太陽系の惑星たんけん

小学6年生の理科で、発展として使うシミュレーションです（中学校3年「地球と宇宙」につながる内容）。
8つの惑星のならび・公転の速さ・大きさとたがいのきょり・特ちょうをくらべ、地球の自転・公転と季節の変化を見ます。

- 太陽のまわりを、地球などの8つの惑星が回っている（公転）
- 太陽に近い順に、水星・金星・地球・火星・木星・土星・天王星・海王星（すいきんちかもくどってんかい）
- 太陽に近い惑星ほど、短い時間で1周する
- 惑星には、それぞれ大きさや特ちょうがある（岩石の惑星・ガスの惑星・氷の惑星）

## 基本情報

- **ファイル**：`太陽系の惑星たんけん.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例、画面の下に先生用のメモが出ます。
- **保存**：ワークシートは localStorage に保存されます（キー：`ikechan-science-太陽系の惑星たんけん`）。

## 5つのタブ

| タブ | 内容 |
|---|---|
| ① 惑星のならび | まぜてならんだ8つの惑星を、2つずつタップして入れかえ、太陽に近い順にならべる。「答え合わせ」で、正しい場所は ⭕、ちがう場所は ✖。全部正しいと「すいきんちかもくどってんかい」が出る |
| ② 公転のようす | 上から見た図で、8つの惑星が太陽のまわりを回る（速さは本当の公転周期の比）。「1秒で進む時間」スライダー（約1か月〜約5年）とはやさボタン。左の表に、それぞれの惑星が回った数が出る。地球が1周すると、ほかの惑星が何周したかを自動で記録。「記録する」でいつでも記録できる |
| ③ 大きさくらべ | **大きさモード**：地球の直径を1として同じ縮尺でならべる（木星は約11倍。太陽は約109倍なので左のはしだけ）。惑星をタップすると大きさを記録。**きょりモード**：太陽〜地球のきょりを1目もりとして、海王星（約30目もり）までを同じ縮尺でならべる。ドラッグかスライダーで横に動かす。下の地図で、今見ている場所がわかる |
| ④ 惑星カード | 惑星をタップすると、太陽からのきょり・大きさ・公転・自転・表面の温度・輪・衛星の数・特ちょうが出る。□岩石の惑星／○ガスの惑星／◇氷の惑星のなかま分け（まちがえるとヒント）。全部できると記録 |
| ⑤ 地球の動き | 左：ななめ上から見た公転（夏至・冬至・春分・秋分）。地じくはいつも同じ向きにかたむいている。右：地球の拡大図で、日本（北緯35度）の通り道の昼（黄）と夜（青）の長さ、1日で1回転する日本の位置。季節ボタン・動かす・地じくのかたむき ON/OFF・日光の矢印 ON/OFF。「記録する」で、日づけ・昼の長さ・正午の太陽の高さを記録 |

### 書きかえたいとき

- 惑星のデータ：`PLANETS`（太陽からのきょり `dist`・公転 `period`・直径 `size`・衛星の数・輪・温度・自転・特ちょう・色・なかま `type`）
- なかまの名前・しるし：`TYPES`
- 地じくのかたむき・緯度：`TILT`・`LAT`、⑤のはやさ：`DPS`
- ふりがな：`DICT_SRC` に `{漢字|よみ}` の形で足す

## ワークシート

- もんだい：太陽にいちばん近い惑星は、どれだろうか？（答え：水星）
- 予想：水星／金星／地球／火星／木星
- 結果：表（どこで・調べたこと・わかったこと）。①のならべ方、②の周回数、③の大きさ、④のなかま分け、⑤の昼の長さと太陽の高さが記録されます（同じ内容は1回だけ）。グラフはありません。

## じっさいとのちがい

数値は、教育用のおおよその数です（衛星の数は、新しく見つかってふえることがあります）。本物の太陽系は、大きさにくらべてきょりがとても遠いので、1まいの図に大きさときょりを同時に正しくかくことはできません。②の図では、惑星の大きさと軌道の間かくを見やすいように変えています（回る速さの比は本当に近くしています）。軌道は円にし、すべて同じ平面にかいています。⑤の昼の長さと太陽の高さは、東京（北緯35度）として計算したおおよその数です。
