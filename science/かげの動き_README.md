# かげの動き

小学3年生の理科「かげと太陽」で使うシミュレーションです。
時こくを動かすと、太陽が 東→南→西 へ動き、ぼうのかげが 西→北→東 へ動くようすを確かめられます。

- かげは、太陽の反対がわにできる
- 太陽の向きが変わると、かげの向きも変わる
- 正午ごろ、太陽がいちばん高くなり、かげはいちばん短くなる（真北を向く）
- 日なたの地面は、日かげの地面より温度が高い

## 基本情報

- **ファイル**：`かげの動き.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例が出ます。

## 画面

| 部分 | 内容 |
|---|---|
| ① 真上から見た校庭 | 北が上。真ん中に高さ1mのぼう。太陽（輪の上）と、太陽の向き（オレンジの実線の矢印）、かげ（こい灰色の帯と点線の矢印）を表示 |
| いまのようす | 太陽の方位、かげの向き（8方位）、かげの長さ（cm） |
| ② 横から見た図 | 太陽とぼうを横から見た図。太陽が高いとかげが短く、ひくいと長いことがわかる |
| ③ 地面の温度 | 日なたと日かげの地面の温度（目安）。午後1時ごろにいちばん高くなる |

## 操作

| 操作 | 内容 |
|---|---|
| 時こくのスライダー | 午前8時〜午後4時 |
| さいせい | 時間が自動で進む。「ゆっくり／ふつう／はやおくり」で速さを変えられる |
| かげの先にしるしをつける | いちばん近い、ちょうどの時こく（8時〜4時）のかげの先に◆のしるしをつけ、ワークシートの表に「時こく・かげの向き・かげの長さ」を記録する。①の図でかげの先をタップしてもつけられる。しるしは点線でつながる |
| 矢印 ON/OFF | 太陽とかげの矢印を消して、自分で向きを考えさせたいときに使う |
| もういちど | しるしと記録を消して、午前8時にもどす（予想と考察は残る） |

## ワークシート

- **問題**：正午に、ぼうのかげはどちらを向くだろうか？
- **予想**：東・西・南・北
- **結果**：時こく・かげの向き・かげの長さの表と、「時こく」と「かげの長さ」の折れ線グラフ（正午がいちばん短い、U字の形になる）

## 正しさについて（じっさいとのちがい）

- 太陽の位置は、北緯35度（東京あたり）・春分の日として計算しています。このため、しるしは東西にまっすぐならびます。季節が変わると、しるしは曲線になります。
- 時こくは、太陽が真南にくるときを正午としています。じっさいは、場所によって正午から少しずれます。
- 地面の温度は、教科書によく出る値をもとにした目安です。
