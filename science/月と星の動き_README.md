# 月と星の動き

小学4年生の理科「月と星」で使うシミュレーションです。
時こくを進めて、月と星が空でどう動くかを観察します。

- 月は、日によって形が変わって見える
- 月は、1日のうちで、東の方からのぼり、南の空を通って、西の方へしずむ（形がちがっても動き方は同じ）
- 星も、時間とともに位置が変わるが、星のならび方は変わらない
- 北の空の星は、北極星を中心に回るように動く

## 基本情報

- **ファイル**：`月と星の動き.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例が出ます。
- **今ある教材とのちがい**：`星座シミュレーター.html`（4〜6年、日づけを変えて星空を見る道具）の星の位置の計算と、`月と太陽.html`（6年、満ち欠けのしくみ）の月の形のかき方を写して使っています。もとの2つの教材は変えていません。

## 画面

| 部分 | 内容 |
|---|---|
| 空の図（南の空） | 南を向いて見上げた空を半円でかく。下の線が地平線（左が東・まん中が南・右が西）、てっぺんが真上。空の色は時こくで、夕やけ→夜と変わる |
| 空の図（北の空） | 北を向いた空。北極星（点線の輪）を中心に、北斗七星・カシオペヤ座が反時計回りに回る |
| いまのようす | 月の形、いま見える方位（8方位）と高さ（にぎりこぶし何こ分・約何度）、月の出・真南・月の入りのおよその時こく |
| 方位磁針の使い方 | 方位磁針の絵と、南の見つけ方の手順（ひらいて見る） |
| 安全メッセージ | 夜の観察は大人といっしょに／太陽は見ない |

## 操作

| 操作 | 内容 |
|---|---|
| 時こくのスライダー | 午後6時〜次の日の午前6時 |
| さいせい | 時間が自動で進む。「ゆっくり／ふつう／はやおくり」で速さを変えられる |
| 月の形 | 三日月（3日目）・半月（7日目）・満月（15日目）のボタンと、「新月から何日目」のスライダー（1〜29日目） |
| 月の位置を記録 | いちばん近い、ちょうどの時こくの月の位置に◆のしるしをつけ、ワークシートの表に「時こく・月の形・方位・高さ」を記録する。月が地平線の下のときは記録できない |
| 夏の夜／冬の夜 | 星の位置を、8月1日／1月20日の本物の位置にする（月の形とは別に選べる） |
| 星座の線・名前 ON/OFF | 星座の線（大三角は黄色の点線）と、星や星座の名前を出す・消す |
| 1時間ごとの位置 ON/OFF | 月の1時間ごとの位置（点線の丸と時こく）と、星の通り道（線）をのこす |
| 目もり ON/OFF | 高さ30度・60度（こぶし3こ・6こ）の線と、南東・南・南西の線 |
| 星座の形をうつす | いまの星座の形を、水色の点線でのこす |
| うつした形をかさねる | 時間を進めたあとにおすと、うつした形が動いて回って、いまの星座にぴったり重なる（ならび方が変わらないことを確かめる） |
| 星や月をタップ | 名前が出る |
| もういちど | 記録を消して、午後6時・満月・夏の夜・南の空にもどす（予想と考察は残る） |

## ワークシート

- **問題**：2時間後、月はどちらに動くだろうか？
- **予想**：東の方へ動く・西の方へ動く・動かない
- **結果**：時こく・月の形・方位・高さの表

## 正しさについて（じっさいとのちがい）

- 月は30日でもとの形にもどるモデルにしています（本当は約29.5日）。
- 月と太陽の通り道は、春分・秋分のころの太陽と同じ（天の赤道）にしています。本当の月の通り道は、日によって高さが変わります。また、月と星のならび方は本当の日づけとはちがいます。
- 空の色（夕やけ・夜）も、春分・秋分のころの太陽で計算しています（夏の夜は、本当はもう少し明るい時間が長いです）。
- 星の位置は、北緯35度・東経135度から見た本物の位置です（`星座シミュレーター.html` と同じ計算）。
- 月は見やすいように、本当より大きくかいています。
- 半円の図は、見ている方角の地平線からのはなれぐあい（角度）を、半円の中心からのきょりにしてかいています。このため、地平線の近くや半円のふちの星座は少しゆがんで見えます。「うつした形をかさねる」は、このゆがみを調整して重ねています。

## 改造のしかた

- **星を足す**：`STARS` の表に `[記号, 赤経(時), 赤緯(度), 等級, 色, 名前]` の1行を足します。
- **星座を足す**：`CONSTS` に `{ name, anchor, dy, lines: [[星,星], ...] }` の1行を足します。
- **季節を足す**：`SEASONS` に `{ m: 月, d: 日, name }` を足して、HTML に `data-season` のボタンを足します。
- **月の形のボタン**：HTML の `data-day="3"` などの数字（新月から何日目）を変えます。
