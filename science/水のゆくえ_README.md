# 水のゆくえ

小学4年生の理科「自然の中の水のすがた」で使うシミュレーションです。
水がどこへ消えるのか（蒸発）、コップの外の水てきはどこから来るのか（結ろ）、自然の中で水がどうめぐるのかを、つぶの動きで見ます。

- 水は、水面や地面から蒸発して水じょう気になり、空気中へ出ていく
- 日なたや、風があるところでは、早く蒸発する。ふたをすると、ほとんどへらない
- 空気中の水じょう気は、冷やされると水にもどる（結ろ）
- 水は、すがたを変えながら、海 → 空 → 雲 → 雨 → 川 → 海 とめぐっている

## 基本情報

- **ファイル**：`水のゆくえ.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例が出ます。

## ① 蒸発

同じ形の入れ物4つに、100mL ずつ水を入れて、日数を進めます。変える条件は1つずつです。

| 入れ物 | 置き場所 | 1日にへる量（目安） | くらべ方 |
|---|---|---|---|
| A | 日なた | 6mL | A と B で「日光」 |
| B | 日かげ | 2mL | 基準 |
| C | 日かげ＋風（せん風機） | 4mL | B と C で「風」 |
| D | 日なた＋ふた（ラップ） | ほぼ 0mL | A と D で「ふた」 |

| 操作 | 内容 |
|---|---|
| ＋1日／日にちを進める | 1日ずつ、または自動で進める（14日まで）。はやさは ゆっくり／ふつう／はやおくり |
| つぶ ON/OFF | 水面からつぶが空気中へ出ていくようす。D では、つぶがふたの内がわで水てきになり、たまると落ちてもどる |
| 入れ物をタップ | その入れ物の条件と、へり方のわけ |
| 右の棒グラフ | へった水の量（mL）。A〜D は色・もよう（ぬり／しま／水玉／十字）・文字で見分ける |
| 記録する | その日数の、4つのへった量をワークシートに入れる |
| もういちど | 0日目にもどす（ワークシートの記録は残る） |

赤い線は、はじめの水面のしるしです。

## ② 結ろ

| 部分・操作 | 内容 |
|---|---|
| コップの中み | ぬるい水（30℃）／水道の水（20℃）／氷水（0℃）。スライダーで 0〜30℃ にも変えられる |
| コップの表面 | 冷たいほど、水てきがたくさんつく。大きくなると流れ落ちて、コップの下にたまる |
| 虫めがね（つぶ ON のとき） | 空気中の水じょう気のつぶが、冷たいガラスにふれると、とまって集まり水てきになる。あたたかいと、はね返る |
| 中の水に色 | 中の水を青くし、虫めがねの中に「■ 色のもと」が出る。外の水てきには色がつかない → 中の水がしみ出したのではない |
| ふた | ふたをしても水てきはつく → 水てきのもとは、まわりの空気の水じょう気 |
| コップをふく | 水てきを消して、はじめから |
| 冬のまど／メガネ／はく息 | 身近な結ろの例の説明 |

水てきがつき始める温度は、ここでは15℃にしています（部屋の空気25℃のとき）。画面には出していません。この数字は、HTML の中の `DEW_T` で変えられます。

## ③ 自然の中の水

| 部分・操作 | 内容 |
|---|---|
| アニメーション | 海・水たまり・せんたく物から水じょう気が上がる → 空の高いところで冷やされて雲 → 雲が山のほうへ流れ、大きくなると雨 → 陸にふった雨が川を流れて海へ |
| つぶ ON/OFF | 水じょう気と川の水のつぶ。OFF にすると、本当の見え方（水じょう気は見えない） |
| 矢印 ON/OFF | 蒸発・雲・雨・川の矢印と名前 |
| タップ | 海・空気の中・雲・雨・川・水たまり・せんたく物・太陽の説明（液体か気体かもふくむ） |

## ワークシート

- **もんだい**：風があると、水は早くへるだろうか？
- **予想**：早くへる／おそくへる／変わらない
- **記録**：日数と、A〜D のへった水の量（mL）。グラフは日数ごとの4本の棒
- 保存キー：`ikechan-science-水のゆくえ`
- スマホのせまい画面では、記録の表は表の中で横にスクロールします。

## ※じっさいとのちがい

- 日にちや時間は、はやく進めています。水のへる量は、季節・気温・入れ物の口の広さでかわります（ここでは目安の数です）。
- 水てきがつくかどうかは、空気にまざっている水じょう気の量によってもかわります。むし暑い日は、水道の水でもつくことがあります。
- 雲のでき方はかんたんにしています（くわしくは5年で学びます）。
- つぶは、本当は目に見えないほど小さいです。
