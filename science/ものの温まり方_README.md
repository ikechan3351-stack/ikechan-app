# ものの温まり方

小学4年生の理科「ものの温まり方」で使うシミュレーションです。
金属・水・空気を熱して、温まり方のちがいを色とつぶで見ます。

- 金属は、熱せられた部分から順に温まっていく（切れ目があると回りこんで伝わる）
- 水は、温められた部分が上へ動き、上のほうから順に、やがて全体が温まる
- 空気も、温められた部分が上へ動く。冷えた空気は下へ動く

## 基本情報

- **ファイル**：`ものの温まり方.html`。同じフォルダの `worksheet.js`・`worksheet.css`（ワークシート部品）もいっしょに使います。ネット接続・外部ライブラリは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「理科」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。タブレットの横向きでは、ワークシートが画面の右に出ます。スマホでは下に出ます。
- **先生モード**：アドレスの最後に `?teacher=1` を付けると、ワークシートに先生用のヒントと解答例が出ます。

## 画面

| 部分 | 内容 |
|---|---|
| ① 金属 | 銅のぼう（24cm）・正方形の板（12cm）・円形の板（直径12cm）。●▲■ の印に、熱したところからのきょりが出る |
| ろう／温度の色 | ろう：60℃でとけ、うすい黄色（つぶつぶもよう）から銅の色にかわる。とけたさかい目は点線。温度の色：青→赤（20〜120℃）と、同じ温度を結んだ線 |
| 切れ目 | 板のまん中に、上から8cmの切れ目を入れる。熱は切れ目を回りこんで伝わる |
| ② 水 | ビーカー（横10cm・深さ8cm）を下から熱する。示温インク（40℃より低いと青、高いとピンク）または温度の色。おがくずと水の流れの矢印 |
| ③ 空気 | 部屋（横6m・高さ3m）の温度の色。ストーブと線香のけむり、エアコン（だんぼう・冷ぼう）の風とけむり |
| 温度計 | ドラッグして置くと、その場所の温度（℃）が出る |
| 上のほう・下のほう | 水は水面近くと底近く、空気は天井近くとゆか近くの平均の温度 |
| 安全メッセージ | タブごとに、アルコールランプ・ビーカー・線香とストーブの注意を出す |

## 操作

| 操作 | 内容 |
|---|---|
| 熱する／止める（スイッチ ON／OFF） | ランプやストーブ・エアコンをつけたり消したりする |
| 金属をタップ | そこにランプを動かして、はじめからやり直す |
| 熱する場所（水） | 中央／はし |
| ストーブ・だんぼう・冷ぼう、風の向き | エアコンは風の向きを「横向き」「下向き」から選ぶ |
| ゆっくり／ふつう／はやおくり | 時間の進み方（0.5倍・1倍・5倍） |
| つぶ ON/OFF・矢印 ON/OFF | おがくず・けむりと、流れの矢印の表示の切りかえ |
| もういちど | 今のタブをはじめにもどす（ワークシートの記録は残る） |

## ワークシート

- **問題**：熱した場所から遠いところのろうは、何秒でとけるだろうか？
- **予想**：近いところと同じころにとける・近いところより、あとでとける・近いところより、先にとける（何秒かは理由に書く）
- **結果**：① で印のろうがとけると、形・切れ目・印・きょり・とけた時間を自動で記録。きょりととけた時間の点グラフ（切れ目なし●・切れ目あり■）

## 正しさについて（じっさいとのちがい）

- 金属は銅（熱の伝わりやすさ 1.1cm²／秒）として、マス目（2mm）ごとに温度がとなりへ伝わる計算をしています。ぼうは見やすいように太くかいています。
- ろうは60℃でとけるとしています。とける時間の目安（ふつう・切れ目なし）：正方形の板 ●約40秒・▲約60秒・■約65秒、ぼう ●約5秒・▲約20秒・■約40秒。ランプの火の強さで本当の実験とはかわります。
- 水と空気の流れは、「温まったところが上へ動く回る流れ」をかんたんにした形で計算しています（本物の流れの計算ではありません）。温かいものが下にあると上と入れかわるようにして、熱の量がかわらないようにしています。
- 部屋の温度は、冬の朝（10℃・外5℃）、夏（32℃・外33℃）から始めています。エアコンの風は、だんぼう38℃・冷ぼう15℃としています。

## 改造のしかた

- **金属の種類**：`ALPHA` を変えます（アルミ 0.97、鉄 0.23）。
- **ランプの強さ**：`LAMP_Q` を変えます。ろうのとける温度は `MELT` です。
- **水**：流れの速さ `WATER_V`、温める強さ `WATER_Q`、示温インクの色がかわる温度 `INK_T`。
- **空気**：回る流れ `AIR_V`、エアコンの風 `JET_V`、ストーブの強さ `STOVE_P`、温度で上下に動く強さ `BUOY`。
