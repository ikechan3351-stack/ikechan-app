# 正負の数トランプ（ゼロ対ババ抜き・得点ババ抜き）

中学1年「正負の数」の加法を、**トランプ**で遊びながら身につけるアプリです。
黒（♠♣）を **正の数**、赤（♥♦）を **負の数** と決めて、2つのゲームで遊びます。

- **ゼロ対ババ抜き**（加法・反数）：たすと 0 になる組（**ゼロ対**）をすてる。すてるたびに式と数直線が出て、「＋7 と −7 で 0 にもどる」ことを確かめられる。
- **得点ババ抜き**（加法・減法）：手札5まいの合計が点数。引く＝たし算、わたす（取られる）＝ひき算。「**赤（負の数）をわたすと点が上がる**」体験から、ひき算＝反数のたし算 を実感する。

## 基本情報

- **ファイル**：本体 `正負の数トランプ.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中1）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）・スマホ。
- **カードの約束**
  - ♠ スペード・♣ クラブ（黒）＝ 正の数。♠7 は ＋7
  - ♥ ハート・♦ ダイヤ（赤）＝ 負の数。♥7 は −7
  - A＝1。絵札ありのときは J＝11・Q＝12・K＝13
  - ジョーカー＝ババ（すてられない）
  - マークは本物のトランプどおり黒・赤。カードのまん中に「＋7」（オレンジの札）「−7」（青の札）を大きく書き、色だけでなく記号でも見分けられるようにしています。
- **URL の設定**
  - `?teacher=1` … 先生モード（カードと式が大きくなる・CPU の動きがゆっくり・「あいての手札を見せる」ボタン・ワークシートのヒントと解答例）
  - `?rule=zero`・`?rule=score` … 設定画面をとばして、すぐにゼロ対ババ抜き／得点ババ抜きを始める
  - `?lv=2`・`?lv=3` … レベル（ふつうは Lv1）
  - `?play=team&teams=3` … チーム対抗（2〜4チーム）
  - `?cpu=3` … ひとりで遊ぶときの あいてを3人にする（ふつうは2人）
  - `?face=1` … 絵札（J・Q・K）を入れる
  - 得点ババ抜きだけ：`?calc=self`（点数を自分で答える）、`?win=zero`（0に近い人の勝ち・発展）、`?str=easy`（あいてが でたらめに わたす）
  - 例：`正負の数トランプ.html?teacher=1&rule=zero&lv=2&play=team&teams=3`
- **記録**：この端末の localStorage に、ワークシート・つまずきの回数・勝ち負けを入れます。保存キーは ゼロ対ババ抜き `ikechan-math-正負の数トランプ`、得点ババ抜き `ikechan-math-正負の数トランプ-得点`。
- ワークシートは「はじめる」を押したときに、えらんだルールに合わせて出ます。設定でルールを変えると、ページを開き直して始めます。

## 遊び方（ゼロ対ババ抜き Lv1）

1. カードを全員に配ります（A〜10 なら 40枚＋ジョーカー）。
2. 手札の中から、たして 0 になる2枚（例：♠7 と ♥7）をタップしてえらび、「🗑 すてる」。式 `(+7)+(−7)=0` と数直線が出ます。
3. もうないと思ったら「▶ すておわった」。まだ残っていると注意が出ます。
4. 自分の番では、つぎの人のうら向きのカードを1枚タップして引きます。ゼロ対ができたら すてて「▶ つぎの人へ」。
5. 手札がなくなったら あがり。最後にジョーカーを持っていた人の負けです。

- 「↔ 小さい順にならべる」で手札を −10 〜 ＋10 の順にならべると、ゼロ対が見つけやすくなります（数直線の並びと同じになる）。
- 「💡 ヒント」は2段階です（1回目：ことば、2回目：組になるカードが光る）。
- 「👀 答えを見せる」で、えらんだカードの和を、すてる前に式と数直線で確かめられます（Lv3 では先生モードのときだけ）。

## レベル

| レベル | すてられる組 | ねらい |
|---|---|---|
| Lv1 | 同じ数の黒と赤の2まい（＋7 と −7） | 反数・和が0になる2数 |
| Lv2 | 2まい以上で、和が 0 の組（＋3・＋4・−7 など） | 3項以上の加法、「＋の合計と −の合計が同じなら 0」 |
| Lv3 | Lv2 と同じ組。ただし すてる前に、えらんだカードの和を数字ボタンで答える | 異符号の加法の計算。答えのまちがいから つまずきを見つける |

- Lv3 では、答える前は数直線の矢印をかくします。答えたあとに矢印と終点が出ます。
- **止まりルール（Lv2・Lv3）**：3まい以上の組をすてると、のこったカードが「4まい以上そろわないと 0 にならない」形になり、だれも すてられなくなることがあります。だれも すてないまま 全員が3回ずつ引いたら、そこで おわりです。あがっていない人は手札の少ない順、ジョーカーを持っている人が最下位になります。おわりの画面で「のこったカードをぜんぶたすと 0」を式と数直線で見せます。

## チーム対抗（電子黒板1台）

- 設定の「あそびかた」で「チーム対抗」をえらび、2〜4チームに分けます（コンピューターは入りません）。
- 番がきたチームは前に出て、「手札を見る」をおして操作します。ほかのチームの手札はうら向きです。
- 先生モードの「👁 あいての手札を見せる」で、全チームの手札を表向きにして、クラスで「どの組がすてられる？」と話し合うこともできます。
- つまずきは「クラスのつまずき」としてまとめて出ます。

## 遊び方（得点ババ抜き）

1. 1人（1チーム）5まいずつ配ります（ジョーカーは入れません）。手札の合計が点数です。
2. 自分の番では、**まえの人**のうら向きのカードを1まいタップして引きます → `(+4)+(−3)＝+1` のように **たし算** の式が出ます。
3. 手札から1まいえらんで「🎁 わたす」で **つぎの人** にわたします → `(+1)−(−5)＝(+1)+(+5)＝+6` のように **ひき算＝反数のたし算** の式が出ます。数直線では「はじめ」の点から、カードと反対の向きに点線の矢印で進みます。
4. 「▶ つぎの人へ」。全員が **3回** ずつやったら おわりです（3周すると全員5まいにもどります）。
5. 合計点が いちばん大きい人の勝ち。発展ルール「0に近い人の勝ち」もあります。

- ひとりで遊ぶとき、コンピューターに **取られた**・コンピューターから **もらった** ときも、あなたの点数の式と数直線が出ます。
- 「点数の計算：自分で答える」にすると、引くたび・わたすたびに 合計点を数字ボタンで答えます。
- 「💡 ヒント」は2段階です（1回目：ことば、2回目：わたすと いちばん得になるカードが光る）。
- コンピューターの強さ：やさしい＝でたらめにわたす、ふつう＝いちばん得になるカード（大きい人の勝ちなら いちばん小さいカード）をわたす。

## みんなで対戦版（ストップ得点ゲーム）

1人1台の端末で、班ごとに4人で対戦するオンライン版です。アドレス：https://aiue-battle-kslr.onrender.com/seifu/
（サーバーは非公開リポジトリ aiue-battle の `seifu.js`・`public/seifu/index.html`。この HTML とは別のファイルです）

1. 先生がクラスの **合言葉**（例：1年2組）を決めて伝えます。子どもは なまえ・合言葉を入れて、**班（1〜10班）** をえらんで入ります。班のボタンに 何人いるかが出ます。
2. 班で最初に入った人が「はじめる係」です。「▶ はじめる」で始まります。**4人に足りない席には コンピューター** が入ります（強さ：やさしい・つよい）。
3. A〜10 とジョーカー（**0点**）を まぜて、1人5まい配ります。手札の合計が点数。ほかの人の点数は見えません。
4. 自分の番：**つぎの人** のうら向きのカードを1まい引く（たし算の式）→ 自分のカードを1まい、その人にわたす（ひき算の式。`(−12)−(−9)＝(−12)+(+9)` のように反数のたし算で出ます）。手札はいつも5まいです。
5. **1周目はストップできません**。2周目から、自分の番のはじめに「✋ ストップ」できます。
6. ストップしたら全員の手札と点数を見せます。ストップした人が いちばん多ければ（同点もふくむ）成功。そうでなければ **ビリの人と手札をぜんぶ交換** して、交換後の点数で順位を決めます（ストップした人が自分でビリのときは交換なし。ビリが何人もいるときは、ストップした人の つぎから順に見て さいしょの人）。
7. ストップがかかるまで続きます（コンピューターは、周が進むほど 低い点でもストップするようにして、終わらなくならないようにしています）。

- とちゅうで通信が切れた人の席は、30秒たつと コンピューターが代わりに動きます。同じ合言葉・同じ班・同じ名前で入りなおすと もどれます。
- 1台版の「得点ババ抜き」は「まえの人から引いて つぎの人へわたす」ので手札が4〜6まいに変わりますが、対戦版は ストップで点数をくらべるので「引いた相手に わたす」にして、いつも5まいにそろえています。

## 授業での使い方（例）

- **導入（10分）**：先生モードで電子黒板に映し、「♠7 と ♣7 は組になる？」と問う。ふつうのババ抜きとのちがいから、「符号がちがい、数が同じ2数の和は 0」に気づかせる。
- **練習（15分）**：1人1台で CPU と対戦。まちがえて すてようとした組は「あなたのつまずき」に出るので、ふりかえりに使う。
- **3項以上へ（15分）**：Lv2 をチーム対抗で。「♠3・♣4・♥7 はすてられる？」をクラスで考えてから、チームで対戦する。Lv3 は、計算の練習をかねて個別に。
- **まとめ**：ワークシートに、すてた組の式を記録し、「たして 0 になるのは〜」の形でまとめる。
- **減法の導入（15分）**：得点ババ抜きの前に「赤のカードを取られると、点数は上がる？下がる？」と予想させる（ワークシートの①予想）。先生モード・チーム対抗で遊び、赤をわたしたときの式 `(+4)−(−3)＝(+4)+(+3)` を板書して、「ひくことは反数をたすこと」にまとめる。
- **練習（15分）**：得点ババ抜きを「自分で答える」で個別に。まちがえた型が「あなたのつまずき」に出る。

## つまずき検知の一覧

| 型の名前 | まちがいの例 | 画面に出すことば |
|---|---|---|
| ふつうのババ抜き型 | ♠7 と ♣7 → (+7)+(+7) | 同じ数・同じ色の2枚は、たすと 0 にならない。黒と赤で組にしよう |
| 同じ符号の組み型 | (+3)+(+5) | 同じ符号どうしをたすと 0 から遠ざかる。符号のちがう2枚をさがそう |
| 数のずれ型 | (+7)+(−5) | 符号がちがっても、絶対値が同じでないと 0 にならない |
| ジョーカー型 | ジョーカーをえらぶ | ジョーカーはババ。すてられない |
| 符号えらび型（Lv3） | (+3)+(−5) を +2 と答える | 符号のちがう数の和は、絶対値の大きい方の符号になる |
| 絶対値たし型（Lv3） | (+3)+(−5) を −8 と答える | 符号のちがう数をたすときは、絶対値の「差」を求める |
| 計算ミス型（Lv3） | そのほかのまちがい | 数直線の矢印を 0 から順にたどって たしかめよう |
| ひき算そのまま型（得点ババ抜き） | (+4)−(−3) を +1 と答える（赤を取られたら下がると思う） | ひくときは、ひく数の符号を変えて たす。赤を取られる・わたすと、点数は上がる |

得点ババ抜きの「自分で答える」では、たし算のまちがいに 符号えらび型・絶対値たし型・計算ミス型 も使います（ひき算は 反数のたし算に直して見分けます）。

## ※じっさいとのちがい

- ふつうのババ抜きは「同じ数の2枚」をすてますが、このアプリでは「たして 0 になる2枚」をすてます。
- CPU は、引くカードをランダムに選びます（かけひきはしません）。
- 引く相手は「つぎの人」に決めています。手札がなくなった人はとばします。
- Lv2・Lv3 の「止まりルール」は、このアプリで足したルールです（本物のババ抜きにはありません）。
- 得点ババ抜きの もとの実践は「4人班・1人5まい・3周」です。このアプリでは 3〜5人（3〜4チーム）で遊べるようにしています。周の途中は、手札が4〜6まいになる人がいます（3周すると全員5まいにもどります）。
- コンピューターは Lv2 でも、まず2まいのゼロ対を すて、なければ「合計がいちばん小さい組」を すてます。

## 先生向けメモ（改造するとき）

- 計算の部分（カードの値・山札・ゼロ対の判定・組さがし・止まりルール・順位・つまずきの型）は、HTML の中の「ロジック ここから／ここまで」の間にまとめています。
- つまずきのことばは `TRIP`、CPU の名前は `CPU_NAMES` を書きかえると変わります。
