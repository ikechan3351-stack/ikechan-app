# わけて つないで 分数と小数

小学5年生の算数「分数と小数、整数の関係」（東京書籍 新しい算数 5上 108〜117ページ）で使う教材です。次のことを体験します。

- **整数のわり算の商は分数で表せる**：□÷○＝□/○（わられる数が分子、わる数が分母）。わり切れないときも、分数ならぴったり表せる
- **分数→小数**：分子÷分母（3/4＝3÷4＝0.75）
- **小数→分数**：0.1＝1/10、0.01＝1/100（0.7＝7/10、0.25＝25/100）
- **整数→分数**：3＝3/1＝6/2
- 分数と小数を同じ数直線にならべて大きさをくらべること、**分数倍**（5m は 3m の 5/3倍）

## 基本情報

- **ファイル**：`わけて つないで 分数と小数.html`。共通ファイル `worksheet.js`・`worksheet.css`・`math-render.js` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。テープ図・数直線は SVG で描いています。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。数直線の点は pointer events でマウスでもタッチでも動きます。ボタンは48px以上。スマホのたて向きでも画面がはみ出しません。
- **漢字**：分数・小数・整数・分子・分母・数直線・倍 などの算数のことばと、5年でまだ習っていない漢字にふりがなをつけています。「せってい」で消せます。
- **保存**：ワークシートと「せってい」を、このブラウザの localStorage（キー：`ikechan-math-わけて つないで 分数と小数`）に保存します。もんだいの成績は保存しません。

## 3つの画面

### 🧃 わけて 分数に

- 「□L のジュースを ○人で等しく分けると、1人分は何L？」の場面です。□ は 1〜5L、○ は 2〜9人。
- 「✂️ わける」で、1L のテープ □ 本をそれぞれ ○ 等分し、番号 1 の部分（1人分・オレンジ）を見せます。下に、1人分を集めたテープを 0L・1L・2L の目もりの上にならべ、□/○ L になることを見せます。1L より多いとき（5÷3 など）は 1L の目もりをこえます。
- 右に「□÷○＝□/○」と、小数の答えを出します。わり切れないとき（2÷3）は「0.666…（わり切れない！）分数なら ぴったり 2/3」と出ます。
- 「考え方」は「1L を ○人で分けると 1/○ L → □L だと 1/○ L が □ こ分 → □/○ L」の順です。
- 「ひとつ もどす」「もういちど」あり。ワークシートの「＋ きろくする」で、しき・分数・小数を記録します。

### 📏 数直線で つなごう

- 上は小数（0.1きざみ・青）、下は分数（1/○ きざみ・オレンジ）の数直線（0〜2）です。分母 ○ は 2・3・4・5・6・8・10 から選びます。
- 赤い点をドラッグ（または数直線をタップ）すると、上下が点線でつながり、その位置の分数と小数が出ます（例 6/4 ＝ 3/2 ＝ 1.5、2/3 ＝ 0.666…）。すいつく目もりは「分数の目もり」「小数の目もり」「すいつかない（0.01きざみ）」から選べます。
- 「なおし方」の3つのカードに、いまの点の数で、分数→小数（分子÷分母）、小数→分数（0.01 が いくつ分）、整数→分数（2＝2/1＝4/2＝6/3）を出します。
- 「どっちが 大きい？」で、3/4 と 0.7 などの2つの数を同じ数直線にならべ（分数はオレンジの丸、小数は青の三角）、どちらが大きいかを出します。

### ✏️ 分数と小数 もんだい

- 5種類がまざって出ます（5問なら1つずつ、10問なら2つずつ）。
  - **わり算を 分数で**：7÷9 → 7/9
  - **分数 → 小数**：3/4 → 0.75（分母は 2・4・5・8・10・20・25 で、わり切れるものだけ）
  - **小数 → 分数**：0.25 → 25/100（1/4 でもよい）
  - **どっちが 大きい？**：3/4 と 0.8 → ＞・＝・＜ を選ぶ
  - **分数倍**：赤 7m は 白 4m の何倍？ → 7/4倍（テープ図つき）
- 分数は「分子」「分母」のわくをタップして切りかえて入れます（PCは Tab キーか / キーでも切りかえ）。
- 約分は次の単元（5-10）なので、約分していない答え（6/8、25/100）も正解にします。

## つまずき検知

| 型の名前 | 見つけ方 | 例 | 出す声かけ |
|---|---|---|---|
| 分母と 分子が ぎゃく | わり算・分数倍の答えが、正しい分数の分母と分子を入れかえたもの | 9÷4 → 4/9、7m は 2m の何倍 → 2/7 | わられる数が分子（上）、わる数が分母（下）。「□は○の何倍」も □/○ |
| 数字を ならべるだけ | 分数→小数で「分子.分母」や「0.分子分母」と答えた | 6/4 → 6.4、1/5 → 0.15 | 分数を小数にするには、分子÷分母 を計算する |
| 小数の けた数と 分母の ずれ | 小数→分数で、分子は合っているのに分母の0の数がちがう | 0.2 → 2/100、0.25 → 25/10 | 0.1＝1/10、0.01＝1/100。小数第一位までなら分母は10、第二位までなら100 |

- 見つけた型は「あなたの つまずき」として出し、次にその型の「にた もんだい」を1問足します。2回目もまちがえたときも、1回目のつまずきの説明は残します。
- 終わりの画面に、型ごとの回数を出します。

## 先生モード（アドレスの最後に `?teacher=1`）

- わけて 分数に：「▶ じどうで わける」で 1÷3、2÷3、3÷4、5÷3 を順に分けて見せます。
- 数直線：分数（7/4）か小数（1.25）を入力して「おく」と、その位置に点をおきます（0〜2）。
- もんだい：「💡 こたえ」。ワークシートに、先生用のヒントと解答例が出ます。

## 授業での使い方の例

1. **わり算と分数（1〜2時間）**：「2L を 3人で分けると？」とワークシートの「よそう」を選ばせる → 「わけて 分数に」で 1÷3、2÷3、5÷3 を試し、□÷○＝□/○ のきまりを見つける → わり切れないときの小数と分数をくらべる。
2. **分数倍（1時間）**：「もんだい」の分数倍で、テープ図を見ながら何倍かを分数で表す。
3. **分数と小数・整数（2時間）**：「数直線で つなごう」で点を動かし、なおし方の3つのカードを確かめる → 「どっちが 大きい？」でくらべ方を話し合う → 「もんだい」。

## 正しさ

- 分数の計算は共通ファイル `math-render.js` の Fraction で、分子と分母を整数のまま正確に行っています。分数を小数にするときも、筆算と同じように1けたずつ整数で計算しているので、小数の誤差は出ません。
- わり切れない小数は、小数第三位まで書いて「…」をつけています（画面下にも書いています）。
- 発展（循環小数）は入れていません。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| 小数の数直線／分数の数直線 | 青／オレンジ | 上と下の位置、「小数」「分数」の文字 |
| 1人分の部分 | オレンジ | テープの中の番号 1 |
| くらべる2つの数 | 青／オレンジ | 三角（小数）／丸（分数）の印 |
| わり切れる／わり切れない | 緑／むらさき | 実線／点線のわく、「わり切れない！」の文字 |
| 赤いテープ／白いテープ | 赤／青 | 「赤」「白」の文字、実線／点線のわく |
| 正解／まちがい | 緑／赤むらさき | ◎・△ の記号 |
