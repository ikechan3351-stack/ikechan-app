# 5問ミニテスト（授業のはじめの5問。分数・√・式の答えも自動で答え合わせ）

中学1〜3年の数学で、**授業のはじめに5問だけ前の学習をふりかえる**ためのアプリです。生徒が答えを入力すると、分数・累乗・√・文字式・方程式の答えでも自動で答え合わせをします。値は合っていても「約分していない」「√ を簡単にしていない」ときは「△ おしい」と教えて、1回だけなおせます。

`tool/一問一答メーカー.html`（全教科用）の見た目と流れを受けつぎ、数学専用に作り直したものです。一問一答メーカーはそのまま残っています。

## 基本情報

- **ファイル**
  - 本体：`5問ミニテスト.html`
  - 数式の表示：`math-render.js`（数学アプリの共通部品）
  - 問題データ：`minitest-data/中1.js`・`中2.js`・`中3.js`
  - ネット接続・外部ライブラリは不要です。
  - 問題データを JSON ではなく .js にしているのは、ファイルを直接開いた（file:）ときも読みこめるようにするためです。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）・スマホ。
  - 横向きの広い画面では、左に問題、右に入力のボタンが並びます。
- **問題数**：全65問。

| 学年 | 単元（問題数） |
|---|---|
| 中1（27問） | 正負の数 17・文字式 5・一次方程式 5 |
| 中2（16問） | 式の計算 6・連立方程式 4・一次関数 6 |
| 中3（22問） | 平方根 8・展開 4・因数分解 5・二次方程式 5 |

## 使い方

1. **学年 → 単元**（いくつでも）→ **問題の数**（3・5・10問）→ **出しかた** → **制限時間**（なし・1・2・3・5分）を選んで「はじめる」。
2. 出しかたは2つです。
   - **個人（タブレット）**：1問ずつ答えを入力して答え合わせ。記録が残ります。
   - **全体（電子黒板）**：問題を一度に大きく並べます。生徒はノートに書き、先生が「答えを見せる」で全問の答えと解説を出します。記録はしません。
3. **答えの入力**：画面のボタン（0〜9・分数・√・＋−・かっこ）で入力します。タブレットのキーボードは出ません。パソコンのキーボードでも打てます。
   - 問題に合わせて、x・y・＝・，（区切り）・±・累乗・空白のボタンが足されます。
   - 入力した答えは、すぐ上に数式の形で見えます。
4. **答え合わせ**
   - ○：正解。解説が出ます。
   - △：おしい。値は合っているが、いちばん簡単な形になっていないとき。理由が出て、1回だけなおせます。
   - ×：ざんねん。よくあるまちがいと同じ答えなら、その理由と正しい答えが出ます。
5. **結果**：○△× の一覧、「あなたのつまずき」、「まちがえた問題だけ、もう一度」「類題」のボタン。
6. **きろく**（はじめの画面のいちばん下。その学年をといたことがあるときだけ出ます）
   - 前回の点数
   - まちがえた問題の数と「まちがえた問題でテスト」
   - よくあるつまずき（多い順に3つ）と類題
   - 単元ごとの正答率
   - 記録を消す

### 答えの書き方

| 答え | 書き方の例 |
|---|---|
| 分数 | `-1/6`（□/□ ボタン）。`√2/2` は分子が √2 になります |
| 根号 | `6√2`。√ の中が式のときは `√(x+1)` |
| 累乗 | `x^2`（x² と打ってもよい） |
| 文字式 | `2x+7`。分数の係数は `5x/6` か `5/6 x`（空白を入れる） |
| 因数分解 | `(x+2)(x+3)`、`(x-3)^2` |
| 方程式 | `x=5`（`5` だけでもよい）、2つの解は `x=2, 3` か `x=±3`、連立方程式は `x=3, y=2` |
| 直線の式 | `y=2x-3` |
| 座標 | `(1, 3)` |

### 先生モード・URL での設定

- `?teacher=1` を付けると先生モードになり、個人モードで画面の左下に答えが小さく出ます。
- URL に設定を書くと、その設定ですぐ始まります。授業ダッシュボードなどからリンクするときに使えます。

| 書き方 | 意味 |
|---|---|
| `grade=1` | 学年（1〜3） |
| `mode=all` | 出しかた（`all`＝全体、`one`＝個人） |
| `min=3` | 制限時間（分） |
| `n=5` | 問題の数 |
| `unit=正負` | 単元名の一部（ふくむ単元をえらぶ） |
| `start=1` | すぐ始める |

例：`5問ミニテスト.html?mode=all&grade=1&unit=正負&min=3&start=1`

## 授業での使い方の例（授業のはじめ 5分）

1. 電子黒板で「全体モード・前の時間の単元・5問・3分」を出します（URL をブックマークしておくと1回で出せます）。
2. 生徒はノートに解きます。のこり30秒でタイマーがオレンジ色になり、0で音が鳴って「時間です」と出ます。
3. 「答えを見せる」で答え合わせ。まちがいが多かった問題は、解説を見ながら全体で確認します。
4. 1人1台のタブレットがあるときは、宿題や朝学習で「個人モード」を使うと、まちがえた問題とつまずきの記録が残ります。次の授業のはじめに「まちがえた問題でテスト」から始められます。

## つまずき検知の一覧

| つまずきの型 | 見つけ方 | 出すことばの例 |
|---|---|---|
| 符号 | 答えの符号が反対、または問題データのまちがい | 答えの符号（＋・−）を、最後にもう一度たしかめよう |
| 符号と絶対値 | 問題データ（中1 加法） | 符号がちがう数のたし算は「絶対値の差」 |
| ひき算の符号 | 問題データ（中1・中2） | ひく数の符号を変えてたし算に直す |
| 累乗 | 問題データ（(−3)² と −3²） | 何を何回かけるのかを見よう |
| 計算の順序 | 問題データ | 累乗 → かけ算・わり算 → たし算・ひき算 |
| 通分 | 問題データ（分母どうしをたした） | 分母をそろえてから分子をたす |
| 逆数 | 問題データ（逆数にしないでかけた） | わる数の逆数をかける |
| 分配法則・分配法則の符号 | 問題データ | かっこの中のすべての項にかける |
| 移項 | 問題データ | 移項すると符号が変わる |
| 代入・傾きと切片・変化の割合・座標 | 問題データ（中2） | ― |
| √のたし算・ひき算 | 問題データ（√12+√27＝√39 など） | √ の中どうしはたせない |
| 乗法公式・因数分解・解の公式 | 問題データ（中3） | (a+b)² ＝ a²+2ab+b² など |
| 解のわすれ | 解が足りない（x＝±3 に x＝3 など） | 解はもう1つあります |
| 約分わすれ・√の簡約・有理化・小数で答えた・計算のとちゅう | 値は合っているが形がちがう（△ おしい） | 約分できます／√ の中を小さく／分母を有理化しよう など |
| 同類項・展開・文字式の書き方・答えの書き方 | 文字式の形がちがう（△ おしい） | 同類項をまとめよう／2x のように書こう／「y＝」をつけよう |

- 結果の画面の「類題」で、同じ型の問題を出します。類題は「その型のまちがいがのっている問題」と「tags にその型がある問題」です。
- 一度まちがえた問題（×・△・なおして正解）は「まちがえた問題」に残り、**2回つづけて正解すると消えます**。

## 問題の足し方

`minitest-data/中1.js` の先頭に、書き方の説明があります。単元のまとまりの中に1行足すだけで、出題と単元の一覧に反映されます。

```js
{ id: '1-加減-006', q: '(-5)-(+3)', a: '-8',
  mistakes: { '-2': ['ひき算の符号', 'ひく数の符号を変えて、たし算に直しましょう'] },
  hint: '…', explain: '(−5)+(−3)＝−8' },
```

- `id` は一度決めたら変えないでください（記録が問題の id で残るため）。
- 答え `a` は「いちばん簡単な形」で書きます。
- `type: 'choice'` と `choices` で、選ぶ問題にもできます。
- `form: 'factor'` で因数分解の形、`sys: [...]` で連立方程式、`q: ''` でことばだけの問題にできます。
- 足したら、正しい答えを入力して ○ になるか、まちがいの答えで × になるかを確かめてください。

## ※じっさいとのちがい

- 答えは「いちばん簡単な形」（約分ずみ・√ の中を小さく・分母に √ なし・同類項をまとめる）だけを ○ にしています。教科書で同じ値の答えでも、形がちがうと「△ おしい」になります。
- 小数の答えは、問題データに `decimal: true` がないかぎり「分数で答えよう」になります。
- 文字式の分数の係数は `5x/6` と `5/6 x` のどちらも ○ です。ただし `5/6x` と続けて書くと 5/(6x) の意味になるので、入力のしかたを教えるお知らせを出します（まちがいの回数には数えません）。
- 記録はその端末のブラウザに残ります。1人1台のタブレットなら個人の記録、共用の PC ならその PC を使った全員の記録になります。名前など個人情報は扱いません。

## 動作確認の方法

| 確かめること | 操作 | 期待される結果 |
|---|---|---|
| おしい → なおす | 中3「平方根」の √72 に `√72` | 「△ おしい：√ の中を小さく」→ なおして `6√2` で「○ なおして正解」 |
| よくあるまちがい | 中1「(−2/5)÷4/15」に `-8/75` | 「× わる数の逆数をかけましょう」と正しい答え −3/2 |
| 方程式 | 中3「x²＝9」に `x=3` | 「× (−3)² も 9 です…」 |
| 連立方程式 | 中2 の連立方程式に `y=2, x=3` の順で | ○（順番は自由） |
| 因数分解 | 中3「2x²−8」に `2(x^2-4)` | 「△ まだ因数分解できます」 |
| 全体モード | `?mode=all&grade=1&min=1&start=1` で開く | 5問が並び、1分で「時間です」と音。「答えを見せる」で答えと解説 |
| 記録 | 個人モードで1問まちがえて「終わる」 | はじめの画面の「きろく」に、まちがえた問題 1問・つまずき・正答率が出る |
| 先生モード | `?teacher=1` で個人モード | 左下に答えが小さく出る |
