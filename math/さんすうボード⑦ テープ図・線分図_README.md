# 📏 さんすうボード⑦ テープ図・線分図

文章題の数量の関係（あわせて・のこり・ちがい・何こ分・何倍）を、子どもが自分で **テープ図・線分図** にかいて説明するためのボードです。決まった問題や正解はありません。

- 参考にしたもの：Brainingcamp「Bar Models」の紹介動画（3種類のテープ・はしを引っぱってのばす・さかい目を動かす・かっこ・中に数を書く）。
- 企画メモ：脳メモ `教材開発/企画/2026-11-18_さんすうボード⑦ テープ図・線分図.md`
- **1・2年（さんすうセット ていがくねん から開いたとき）はテープ図だけ**。線分図は3年から使えます。
- テープの長さは **自由にのばします**（数に合わせて自動で長さを決めることはしません）。どれくらいの長さにするかを考えること自体が学習なので。

## 基本情報

- **ファイル**：`さんすうボード⑦ テープ図・線分図.html`。この1ファイルだけで動きます（ネット接続・外部ライブラリ・画像ファイルは不要）。
- **対応する機器**：タッチできる Chromebook（主に想定）、電子黒板、マウス・トラックパッド。何人かの指で同時に動かせます。
- **外わく**（✋うごかす・✏️かく・📏ちょくせん・ペンの色・もどる・はいけい・しゃしん・ひらく・かたづける・先生モード）は さんすうボード①〜⑥ と同じです。

## 道具箱

| タブ | 中身 |
|---|---|
| テープ図（ていがくねんでは「テープ」） | テープ（1本）・2つに わかれた テープ・おなじ 大きさ（3つに等分）・かっこ ｛・かっこ ┌┐・ことば |
| 線分図（3年から） | 線分・2つに 分かれた 線分・等分した 線分・かっこ・ことば |
| カード | 0〜9、＋ − × ÷（÷は3年から） ＝ ？ □ の数字カード |

- **タップ**すると、あいている場所に出ます。テープは左はしをそろえて上から順に並びます。
- **テープをえらんでから かっこ をタップ**すると、そのテープの上に、テープと同じ長さで出ます（上があいていなければ下）。
- **テープをえらんでから テープ をタップ**すると、そのすぐ下に左をそろえて出ます（くらべる図が作りやすい）。
- **引っぱる**と、すきな場所に置けます。

## テープ・線分の操作

| 操作 | どうなるか |
|---|---|
| テープを引っぱる | 動く。左はし・右はしが、ほかのテープのはし・さかい目に近づくと **すいついてそろう**（緑の点線が出る） |
| 右はしの青いつまみ | 長さをかえる（ほかのテープのはし・さかい目にすいつく） |
| 下のオレンジのつまみ | さかい目を動かして、分かれたところの大きさをかえる |
| テープの中を**タップ** | 「かずや ことばを かこう」の画面が開く（タップした ところに書く） |
| ➖ ➕ | 分ける数をへらす・ふやす（1〜20） |
| ⚖️ おなじ | ぜんぶ同じ大きさにする（等分。オレンジのつまみは出ない） |
| 〰 せん ／ ▭ テープ | テープ図 ⇄ 線分図 を切りかえる（3年から。ていがくねんでは出ない） |
| 📄 ／ 🗑 | コピー ／ けす（ごみばこ・道具箱にもどしても消える。Delete キーでも消える） |

## かっこ・ことば

- **かっこ**：両はしのつまみで長さをかえる（テープのはしにすいつく）。タップで「ぜんぶで」「ちがい」などを書く。**↻ むき** で 上 → 右 → 下 → 左 にまわる（左右むきは、2本のテープをまとめる たてのかっこ）。**｛ ⇄ ┌┐** で形をかえる。
- **ことば**：テープの名前（「あかい ペン」「たかしさん」など）。出すとすぐ書く画面が開く。

## かずや ことばを かく 画面

- 数字キー（0〜9・小数点・⌫・けす）、ことばのチップ、単位のチップをタップすると、うしろに足されます。キーボードで直接打ってもかまいません（Enter で「できた」）。
- ことばのチップ：ていがくねんは「？ ぜんぶで あわせて のこり ちがい はじめ ふえた へった あと まえ」、3年からは「？ □ ぜんぶで のこり ちがい 1つ分 いくつ分 ばい もとにする くらべる はじめ ふえた へった」。
- **いろ**（7色）を、分かれたところ1つずつにつけられます。
- **▨ しま**（線分図では **┄ てんせん**）：へった・つかった ところを、色だけでなく模様でも表せます（色覚のちがいへの配慮）。
- **🔁 ぜんぶの ところに**：分かれたところ ぜんぶに同じ数・色を入れる（12が5つ分 など）。

## くらべる わく（2026-11-18 追加）

道具箱の「カード」タブのいちばん下にあります（ていがくねん版にもあります）。

- 左右2つの大きな**へや**と、下に**数を書く しかく**2つ・まん中に**まる**がついた わくです。2本のテープ図を左右に分けて置き、数と記号で比べるときに使います。
- 下の **しかくをタップ** → 数字ボタン（0〜9・⌫・ぜんぶけす）で数を書けます（5けた＝99999 まで）。
- まん中の **まるをタップ** → 「＝」「＞」「＜」「けす」から選べます。
- わくは **いつも いちばん下** に表示されます（テープ・かっこ・ことばを かくさない）。
- へやの上にある部品（まんなかが わくの中にあるもの）は、わくを動かすと **いっしょに動きます**。ごみばこに入れると、のっているものも いっしょに消えます。
- 正しいかどうかの判定はしません。書いた数・記号は、もどる・しゃしん・💾くばる・つづきから にも入ります。
- 部品のコードは さんすうボード①②③ と ほぼ同じです（⑦は 部品の位置が左上なので、のせる・動かす部分だけ ⑦用にしています）。

## 先生用（🧑‍🏫 せんせい ボタン、または `?teacher=1`）

- **📝もんだい**：もんだいカードを作る（文字の大きさ3つ。子どもは動かせるが、書き直し・消すことはできない）。
- **💾くばる**：いまのボード（もんだいカード・テープ・かっこ・ことば・カード・ペンの線・はいけい）を入れた PNG を作る。子どもは「📂ひらく」で開くと、動かせるボードにもどる。しくみは①〜⑥と同じ（PNG の中の名前は `sansuset7-board`）。
- 「途中まで作ったテープ図」を配って、？のところを考えさせる使い方ができます。

## 授業での使い方（例）

**2年 たし算とひき算（あわせて）**
1. 先生が 📝もんだい で「あかい ペンが 23本、あおい ペンが 27本 あります。ぜんぶで 何本ですか。」を出す。
2. 子どもは「2つに わかれた」テープを出し、さかい目を動かして 23本 と 27本 を書く。
3. テープをえらんで かっこ ｛ をタップ → 上に出たかっこに「ぜんぶで ？本」と書く。
4. 📷しゃしん → ロイロノートで提出し、何人かの図をくらべる。

**2年 かけ算（何こ分）**：「おなじ 大きさ」を ➕ で5つにし、🔁 ぜんぶの ところに で「12」を入れる → かっこで「？こ」。

**3年 何倍**：テープ図で 1つ分 と 3つ分 のテープを2本ならべ（はしがすいつく）、「〰 せん」で線分図に変えて、図のちがいを話し合う。

**ちがい**：2本のテープを左をそろえて並べ、短いほうの右はしからかっこを たて にして「ちがい」と書く（または かっこ を右はしから右はしにのばす）。

## つまずき（この教材でねらうもの）

- **ばらばら型**：2本のテープの左はしがそろっていないので、ちがいが見えない → はしがすいついてそろう。
- **全体と部分の取りちがえ**：「ぜんぶ」を部分の1つに書いてしまう → かっこで全体をはっきり表す。
- **長さを気にしない型**：大きい数のほうを短くかく → 自由にのばせるので、話し合いで「長さが合っている？」と問い返す（自動ではそろえない）。

## つづきから（自動保存）

- うごかす・かく たびに、その端末（localStorage、キー `ikechan-math-さんすうボード⑦ テープ図・線分図`）に自動で保存。次に開いたとき「つづきから／あたらしく」を聞きます。
- ていがくねんから開いたときは `-ていがくねん`、算数セット 中高学年から開いたときは `-中高学年` がキーの最後につき、べつべつに保存されます。

## しくみ（コードのつくり）

- ボードはよこ1200×たて720。画面に合わせて `transform: scale()` で拡大・縮小（①〜⑥と同じ）。
- 部品は `items` の配列。位置 `x, y` はどれも **左上のかど**。
  - `tape`：`w`（長さ）、`parts`（分かれたところ。`r`＝くらべた大きさ、`l`＝ことば、`c`＝色、`h`＝しま）、`eq`（等分）、`line`（線分図の見た目）
  - `brace`：`len`（長さ）、`dir`（u 上・d 下・l 左・r 右）、`shape`（c ｛・s ┌┐）、`l`（ことば）
  - `word`：`text`、`c`
  - `text`：先生のもんだいカード ／ `n0`〜`n9`・`plus` など：数字カード
- 絵はすべてコードで作る SVG（`tapeSvg`・`braceSvg`・`wordSvg`）。しゃしんは、部品ごとの SVG を画像にして1まいにかき直す。
- えらんだ部品の **つまみ** と **ミニツールバー** は別の層（`#ui`）にあり、しゃしんには写りません。
- 道具箱の中身は `TOOLS`（あたらしい部品の中身）と `GROUPS`（タブ）の表で決まります。

## 動作確認の方法

1. `さんすうボード⑦ テープ図・線分図.html` を Chrome で開く。
2. テープを出して、右はしのつまみでのばす・オレンジのつまみでさかい目を動かす・タップして数を書く。
3. テープをえらんでから かっこ をタップ → テープの上に同じ長さで出るか。2本目のテープのはしが1本目のはし・さかい目にすいつくか。
4. 「〰 せん」で線分図に変わるか。`?low=1` をつけて開くと、線分図のタブと「〰 せん」が出ないか。
5. 📷しゃしん、先生モードの 📝もんだい → 💾くばる → 📂ひらく で元にもどるか。
