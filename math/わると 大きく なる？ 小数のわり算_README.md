# わると 大きく なる？ 小数のわり算

小学5年生の算数「小数のわり算」（東京書籍 新しい算数 5上 52〜63ページ）と、そのあとの「小数の倍」（64〜69ページ）で使う教材です。次のことを体験します。

- 小数でわる意味：「0.8m で 72円のリボン、1m のねだんは？」を、**0.1m 分（9円）の 10こ分** や **わられる数とわる数を10倍しても商は同じ（72÷0.8＝720÷8）** で考える
- **1より小さい数でわると、商はわられる数より大きくなる** こと
- 小数でわる筆算：**わる数の小数点を右へうつして整数にし、わられる数の小数点も同じだけうつす**。商の小数点は、うつしたあとの小数点にそろえる
- **あまりの小数点は、もとのわられる数の小数点にそろえる** こと
- 商を概数（1/10の位まで）で表すこと、小数倍（何倍か・○倍の大きさ・もとにする大きさ）

## 基本情報

- **ファイル**：`わると 大きく なる？ 小数のわり算.html`。共通ファイル `worksheet.js`・`worksheet.css`・`math-render.js` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。面積図・数直線・線分図は SVG で描いています。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。ボタンは48px以上。スマホのたて向きでも画面がはみ出しません。
- **漢字**：小数・小数点・筆算・商・概数・四捨五入 などの算数のことばと、5年でまだ習っていない漢字にふりがなをつけています。「せってい」で消せます。
- **保存**：ワークシートと「せってい」を、このブラウザの localStorage（キー：`ikechan-math-わると 大きく なる？ 小数のわり算`）に保存します。もんだいの成績は保存しません。

## 3つの画面

### 🎀 わけて 考える

- 「□m で 72円のリボン。1m のねだんは？」の場面です。長さは、答えが整数になるもの（0.4・0.5・0.6・0.8・0.9・1・1.2・1.5・1.6・1.8・2・2.4・3m）のボタンからえらびます。1m より短い長さのボタンは点線です。
- **面積図**：面積（代金 72円）を同じにしたまま、よこ（長さ）を変えます。たて（1m のねだん）がのびちぢみし、1m のときの大きさ（点線のわく）とくらべられます。たての線で 0.1m ずつに分けてあります。
- **二本の数直線**（上：代金、下：長さ）で、□m ↔ 72円、1m ↔ ？円 の関係を見せます。
- 「考え方」には、0.1m 分の代金から考える方法（わり切れるときだけ）と、「わられる数とわる数を10倍しても商は同じ」の方法を出します。
- 1 より小さい長さでわると「⬆ 72円より 大きく なった！」と出ます。「ひとつ もどす」「もういちど」あり。

### 🧮 筆算で 小数点を うつそう

- 「つぎへ」で1ステップずつ進みます。
  1. 問題（わる数 ）わられる数 の形）
  2. わる数の小数点を右へうつして整数にする（もとの小数点はうすい丸で残る）
  3. わられる数の小数点も同じだけうつす（子どもが数字のすきまをタップ。足りないところには 0 をつける）
  4. 整数のわり算と同じように計算（たてる → かける → ひく → おろす。わり進むときにつける 0 はうすく表示）
  5. 商の小数点を、うつしたあとの小数点にそろえる
  6. （あまりの問題だけ）あまりの小数点を子どもがタップ。もとのわられる数の小数点にそろえるのが正解
- 最後に「たしかめ：わる数 × 商（＋ あまり）＝ わられる数」を出します。
- わる数は小数第一位まで、商は1以上にしています。

### ✏️ 小数のわり算 もんだい

- 5種類がまざって出ます（5問なら1つずつ、10問なら2つずつ）。
  - **わり算**：わり切れるまで計算（例 9.8÷3.5＝2.8）
  - **あまりの ある わり算**：商は整数、あまりも出す（例 10.3÷1.5＝6 あまり 1.3）。答えのわくは「商」「あまり」の2つで、タップで切りかえ（PCは Tab キーでも可）
  - **商を 概数で**：1/10の位までの概数（例 4.7÷2.8＝1.67… → 1.7）。四捨五入で切り上げになる問題だけを出し、切りすてた答えには「1/100の位を見て四捨五入」と声をかけます
  - **大きい？小さい？**：「6.3÷0.2 の答えは 6.3 より大きい？小さい？」
  - **小数の 倍**：線分図つき。「赤は白の何倍？」「白の 1.5倍は？」「白の 1.5倍が 赤。白は？」の3つの形
- 答えは数字ボタン（PCはキーボードの数字・`.`・Backspace・Enter も可）で入れます。

## つまずき検知

| 型の名前 | 見つけ方 | 例 | 出す声かけ |
|---|---|---|---|
| わられる数を うつさない | わり算の答えが、正しい商の 1/10（わる数の小数点だけうつした答え）。筆算画面では、わられる数の小数点をうつさずにタップしたとき | 9.8÷3.5 → 0.28 | わる数の小数点をうつしたら、わられる数も同じだけうつそう。どちらも10倍すれば商は変わらない |
| あまりの 小数点 | 商は合っているのに、あまりが正しいあまりの10倍（うつしたあとの小数点で書いた）。筆算画面では、あまりの小数点を「いらない」にしたとき | 2.6÷0.5 → 5 あまり 1 | あまりの小数点は、もとのわられる数の小数点にそろえよう。たしかめ：わる数×商＋あまり＝わられる数 |
| わると いつも 小さく なる | 1より小さい数でわったのに「小さい」を選んだ | 6.3÷0.2 は 6.3 より小さい | 1より小さい数でわると、商はわられる数より大きくなる。0.8m で 72円なら 1m はもっと高い |

- 見つけた型は「あなたの つまずき」として出し、次にその型の「にた もんだい」を1問足します。
- 終わりの画面に、型ごとの回数を出します。

## 先生モード（アドレスの最後に `?teacher=1`）

- わけて 考える：代金を 10〜500円で変えられます。長さのボタンは、1m のねだんが整数になるものだけに自動で変わります。
- 筆算：「▶ じどうで すすめる」で、小数点のタップもふくめて最後まで自動で進めます。
- もんだい：「💡 こたえ」で答えを表示します。ワークシートに、先生用のヒントと解答例が出ます。

## 授業での使い方の例（1時間目・意味）

1. **導入（5分）**：「0.8m で 72円のリボン、1m のねだんは？」。ワークシートの「よそう」で「72÷□ はいつも 72 より小さい？」を選ばせる。
2. **やってみる（20分）**：「わけて 考える」で 2.4m・1.5m・0.8m・0.5m を試す。0.1m 分の代金から考える方法と、10倍して整数でわる方法をくらべる。1m のねだんが 72円より高くなるときを記録する。
3. **まとめ（10分）**：「1より小さい数でわると、商はわられる数より大きくなる」を書く。
4. **練習（10分）**：「もんだい」の「大きい？小さい？」。

筆算の時間は「🧮 筆算で 小数点を うつそう」を全体で1問ずつ進め、あまりの時間は「あまりの小数点」をタップでたしかめさせます。

## 正しさと、じっさいとのちがい

- 小数は「数字のならび（整数）」と「小数点より下のけた数」の組で持ち、計算はすべて整数で行っています。小数のまま計算したときの誤差は起きません。
- 筆算の問題は、「わる数×商（＋あまり）＝わられる数」になることを、ランダムな2000問で確かめています。
- ※じっさいとのちがい：リボンはどの長さでも、1m あたりのねだんが同じものとしています。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| 1m より短い長さ | — | ボタンのわくが点線 |
| 大きくなる／小さくなる | オレンジ／青 | ⬆・⬇ の記号、わくの線（実線／点線） |
| もとの小数点／うつした小数点 | 灰／赤 | 白ぬきの丸／ぬりつぶした丸 |
| つけたした 0 | うすい灰色 | 数字のこさ |
| 赤いテープ／白いテープ（線分図） | 赤／青 | 「赤」「白」の文字、わくの線（実線／点線） |
| 正解／まちがい | 緑／赤むらさき | ◎・△ の記号 |
