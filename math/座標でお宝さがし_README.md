# 座標でお宝さがし（座標で船を動かして、象限と対称な点を見つける）

中学1年「比例と反比例」の入り口、**座標**の学習用アプリです。島のかたちをした座標平面で、点の位置を (x, y) で表して船を動かし、宝を集めます。
第1〜4象限・x軸・y軸・原点、対称な点の座標のきまり、方眼にそった道のりを、4つのパートで体験します。

## 基本情報

- **ファイル**：本体 `座標でお宝さがし.html`、共通部品 `math-render.js`・`graph-engine.js`（座標平面）・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中1）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン・スマホ。広い画面は 左＝地図・右＝入力、せまい画面は上下に並びます。
- **色のきまり**：正の向き（右・上）＝オレンジの実線の矢印、負の向き（左・下）＝青の点線の矢印、正解＝緑の「○」、まちがい＝赤紫の「×」と ✕ 印。ヒントの補助線は紫の点線。
- **URL の設定**
  - `?teacher=1` … 先生モード（答え・つぎの1手を自動で・最後まで自動で見せる・この端末のきろく・ワークシートのヒントと解答例）
  - `?ws=0` … ワークシートをとじて開く

## 使い方

座標は右のキーパッドで入れます。`x`・`y` の欄をタップすると入れる欄がかわり、**−（符号）** で符号がかわります。キーボードの数字・`-`・Tab（欄の切りかえ）・Enter（決定）も使えます。
「📍 地図をタップして入力」にチェックすると、地図をタップした点の座標が欄に入ります（③ でははじめからオン。①②④ では座標を読む練習のためオフ）。
右の小さな図は「x が負なら左、y が負なら下」のめやすです。

### ① 象限めぐり

1. 島に宝箱が4つ（象限ごとに1つ）。⭐ と黄色い輪の宝の座標を入れて「⛵ 出航」。
2. 船は港（原点 O）から **よこ（x）→ たて（y）** の順に進み、「右へ4」「上へ1」の矢印が残ります。
3. 宝を取ったら「第1象限／第2象限／第3象限／第4象限／軸の上（どの象限でもない）」から答えます。正解すると、その象限の名前と符号 (−, ＋) が地図に出ます。
4. 🦈 サメは、**x と y を入れかえた点**と**符号をまちがえた点**にいます（危険な場所）。サメに着くと港へもどります。
5. 📜 ヒント札の座標に行くと、ヒントが読めます。
6. 2つめの島からは、x軸・y軸の上の宝も出ます（どの象限にも入らない点）。

### ② 対称な点

1. 🗿 P(3, 2) から出発。「宝は P と **x軸** について対称な点」の座標を答えます。折り目（x軸）が黄色で光ります。
2. 正解すると、P との間に点線・直角の印・同じ長さの印が出て、「x はそのまま、y の符号がかわる」のきまりが出ます。
3. つづけて **y軸**、**原点** について対称な点。3つとも見つけると、4つの点を結ぶ長方形と、まとめの表が出ます。
4. 「🎲 つぎの問題へ」で、ほかの点 P（乱数）でも同じように。

### ③ 2点を通る道

1. 🏁 A から B（2回に1回は A → B → C）へ。**たて・よこ だけ**に進むので、曲がる点の座標も入れます（ななめは「進めない」と出ます）。
2. 🪨 岩のある道は通れません（L字の道の1つの角に岩がある）。
3. 船が通ったあとが茶色の線で残ります。ゴールしたら「通ったあとの線の長さ（道のり）は何目もり？」に答えます。
4. 正解すると、線の1本ずつに長さが出て「3 ＋ 8 ＝ 11」の式と、いちばん短い道のりかどうかが出ます。
5. 0 をまたぐ部分（x が −5 から 3 まで など）が出やすいようにしています。

### ④ 宝の地図クイズ（10問チャレンジ）

- 「よむ」：地図の ✖ の座標を入れる。
- 「うめる」：示された座標の場所を地図でタップする。
- まちがえたら1回なおせます（△）。2回目もちがうと答えと矢印が出ます（×）。10問で「1回目で正解した数」とベスト記録が出ます。
- ④ では「ひとつもどす」は使えません（記録が変わってしまうため）。「⟲ もういちど」で 10問をはじめからやりなおせます。

ボタン：🎲 新しい問題／↶ ひとつもどす（①〜③）／⟲ もういちど（いまの問題をはじめから）／💡 ヒント（押すたびにくわしく：ことば → 軸へおろした紫の点線 → x 座標などの答えの一部）／📄 ワークシートの問題（② の P(3, 2)、x軸）

## 授業での使い方（例）

- **導入（5分）**：① を電子黒板で。「(4, 1) と (1, 4) は同じ点？」と聞いてから出航し、サメの場所を見せる。x軸・y軸・原点・座標のことばを確認。
- **展開①（10分）**：各自で ①。宝を取ったら象限を答える。「象限の名前を出す」で4つの象限と符号 (＋, ＋)(−, ＋)(−, −)(＋, −) を確認。
- **展開②（15分）**：ワークシートの予想「(3, 2) を x軸で折り返すと？」を挙手で集め、「📄 ワークシートの問題」で確かめる。y軸・原点についても見つけるたびに「＋ 記録する」。ほかの P でも記録して、きまりを (a, b) の文字でまとめる。
- **練習（10分）**：④ の10問チャレンジ。早く終わった生徒は ③ で道のりを。
- **まとめ（5分）**：ワークシートの④に「点 (a, b) と x軸について対称な点は (a, −b)、y軸については (−a, b)、原点については (−a, −b)」。

## つまずき検知の一覧

| 型 | どこで見つけるか | 練習するパート |
|---|---|---|
| x と y の入れかえ | ①②④ で、正しい点の x と y を入れかえた座標を入れた（符号もちがう場合もふくむ）。① ではその点にサメがいる | ④（x と y の大きさがちがう点が出る） |
| x の符号の読みまちがい | ①②④ で、x の符号だけが反対の座標を入れた | ④（x が負の点が出る） |
| y の符号の読みまちがい | ①②④ で、y の符号だけが反対の座標を入れた | ④（y が負の点が出る） |
| 目もりの数えまちがい | ①②④ で、正しい点のとなり（1目もりずれ）を入れた | ④ |
| 象限の番号のまちがい | ① で、ちがう象限の番号を選んだ（時計回りに数えた など） | ① |
| 軸の上の点と象限 | ① で、軸の上の点に象限の番号を答えた、または象限の中の点に「軸の上」と答えた | ①（軸の上の宝が2つ出る） |
| 対称の種類のとりちがえ | ② で、x軸対称なのに y軸対称（や原点対称）の点を答えた など | ② |
| 原点対称で片方だけ符号をかえた | ② の原点対称で、x軸対称か y軸対称の点を答えた | ②（原点対称から出る） |
| 負の数をまたぐ長さのまちがい | ③ で、0 をまたぐ部分を「4−3＝1」のようにひき算した道のりを答えた | ③（0 をまたぐ道が出る） |
| 道のりの数えまちがい | ③ で、正しい道のりと 1〜2 ちがう数を答えた | ③ |

「🔎 あなたのつまずき」に、この時間に出た型と説明が出ます。「🔁 この型を練習」を押すと、その型が出やすい問題のパートへ移ります（上に「練習中」と出ます。「おわる」でふつうにもどる）。
記録は、この端末の localStorage（キー `ikechan-math-座標でお宝さがし`、ワークシートと同じ）に入ります：つまずきの型ごとの回数・見つけた宝の数・④ のベスト・ヒントの回数。先生モードで合計を見たり消したりできます。

## 正しさとじっさいとのちがい

- 座標はすべて整数（−6〜6）です。宝などは −5〜5 におきます。
- ① と ④ で船・矢印が「よこ → たて」の順に進むのは、座標の読み方を見せるためです（本当の船はまっすぐ進めます）。② の船は P からまっすぐ進みます。
- ③ の道のりは、方眼にそって たて・よこ だけに進んだ長さ（1目もり＝1）です。ななめの長さ（三平方の定理）はあつかいません。
- 乱数の問題は、同じ点が続けて出ないようにしています。① の宝は x と y の大きさがちがう点を出やすくして、入れかえのまちがいが見分けられるようにしています。
- マウスを重ねても座標は表示しません（答えが見えてしまうため）。

## 先生がかえやすいところ

- ヒント札のことば：`CARDS` の配列に1行足すと増えます。
- つまずきの型：`TRIPS` に名前・説明・練習するパートを書きます。
- 島の大きさ・形：`drawIsland()` の数字（6.05 が大きさ、sin・cos の項がでこぼこ）。
