# 三平方の定理の利用（a² ＋ b² ＝ c² を使って、辺の長さ・2点間の距離・立体の対角線を求める）

中学3年「三平方の定理」のアプリです。今ある「しきつめてたしかめよう（三平方の定理）」で確かめた定理を、いろいろな場面で使いこなすための教材です。直角三角形の辺の長さ、直角三角形かどうかの判定（定理の逆）、座標平面上の2点間の距離、特別な直角三角形（1 : 1 : √2、1 : 2 : √3）、空間図形の対角線・高さ・体積を1つのページで学べます。いちばんのねらいは、**図の中から直角三角形を見つけて、どの辺が斜辺かを見きわめること**です。

## 基本情報

- **ファイル**：本体 `三平方の利用.html`、共通部品 `math-render.js`・`graph-engine.js`（③ の座標平面）・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3・図形）の「三平方の定理の利用」から開けます。
- **画面のならび**：広い画面は 左＝図・右＝操作と答える欄 の2列（図は上に止まったまま）。スマホはたて1列。
- **記録**：この端末の localStorage（保存キー `ikechan-math-三平方の利用`）に、ワークシートといっしょに入れます。
- **URL の設定**：`?teacher=1` … 先生モード、`?part=1〜5` … そのパートから始める、`?ws=1`／`?ws=0` … ワークシートをひらいて／とじて始める、`?debug=1` … 動作確認用（`window.__dbg`）
- **答えの入れ方**：長さは「□√□」の2つの箱に入れます（√ がつかないときは右の箱を空に）。値は合っているのに √ の中が小さくなっていないとき（√50 など）は「あと一歩」と出ます。

## パート

| パート | すること |
|---|---|
| ① 辺を求める | 「斜辺 c を求める」「辺 a を求める」「辺 b を求める」をえらび、のこりの2辺をスライダー・数・図の ●（A＝たての辺、B＝よこの辺）で変える。計算の流れ（c² ＝ a² ＋ b² → √ → √ の中を簡単に）が連動し、√ を簡単にする行は黄色。「■ 正方形を見せる」で3つの辺の上の正方形の面積をくらべる。「×2 2倍にする」、整数の組（3:4:5・5:12:13・8:15:17・7:24:25）のボタン。3辺が整数になると「見つけた整数の組」にたまる（斜辺 25 以下は 8 組）。 |
| ② 直角三角形か？ | 3辺の長さを入れる（3、2.5、√5、2√3 のような形。「√ を入れる」ボタンもある）。いちばん長い辺をさがして紫にし、のこりの2辺の2乗の和とくらべる（＝・＞・＜）。図はいちばん長い辺を下にして実際の形でかき、向かいの角を「約 ○°」で見せる（＝ のときだけ直角のしるし）。「🔀 ならびをかえる」で AB 以外がいちばん長い場合も。三角形ができない組（2, 3, 6 など）は、短い2本がとどかない絵になる。 |
| ③ 座標の距離 | 座標平面（graph-engine.js）で ● A・B をドラッグ（座標の箱でも入力）。「📐 直角三角形をかく」で、AB を斜辺・横 \|x₂ − x₁\|・たて \|y₂ − y₁\| を2辺とする直角三角形が出る。「🔁 A と B を入れかえる」、ためす2点（原点からもふくむ）。 |
| ④ 特別な三角形 | **⬜ 正方形と対角線**（45°・45°・90°、1 : 1 : √2）と **🔺 正三角形と高さ**（30°・60°・90°、1 : 2 : √3）。「1辺がわかる」「対角線がわかる」「高さがわかる」を切りかえ、長さを変える。図はいつも同じ大きさ（相似なので比は変わらない）。「🔢 比で見る」で辺の文字が比の数になる。計算は三平方の定理と比の両方。対角線・高さから1辺を求めるときは有理化、正三角形の面積も。 |
| ⑤ 空間 | **🧱 直方体**：「① 底面の対角線 EG」→「② 空間の対角線 AG」の順に直角三角形が光る。「🎲 立方体にする」。**🍦 円錐**：半径・母線 → 高さ・体積（○π）。**🔺 正四角錐**：底面の1辺・辺 → 対角線の半分 AH → 高さ OH・体積。**🐜 最短経路（発展）**：A から G まで表面を通る3通りの道 Ⅰ・Ⅱ・Ⅲ をくらべ、いちばん短いものに ◀。「📄 展開図で見る」で2つの面とまっすぐな線。図の何もないところをドラッグすると立体が回る（「🔄 向きをもどす」でもとの向き）。 |

### 練習問題（「✏️ 練習問題」）

答えがいつも「整数 × √整数」（体積は「整数 × π」）になるように、答えを先に決めてから問題と図をつくります。同じ問題が続けて出ないようにしています。

- ①：斜辺を求める／斜辺でない辺を求める。図は直角の頂点と向きをばらばらにしてかき、まず「斜辺はどれ？」（3択）→ x を □√□ で。
- ②：3本の「棒」の絵（角が見えないように）で、いちばん長い辺 → 直角三角形？（はい／いいえ）。または4つの組から直角三角形になるものをえらぶ。答えると三角形の形が出る。
- ③：2点の座標（負の座標を1つはふくむ）→ 横とたての長さ（2つの箱）→ 距離を □√□。
- ④：正方形の対角線、対角線から1辺、正三角形の高さ、正三角形の面積、45° の直角三角形、30°・60° の直角三角形（図は回してかく）。
- ⑤：直方体・立方体の対角線、円錐の高さ（直径で出すことも）、円錐の体積、正四角錐の高さ、発展 最短経路。

## つまずき検知の一覧

| 型 | 検出のしかた | もどる先 |
|---|---|---|
| 斜辺のとりちがえ | ① で斜辺をまちがえてえらんだ、斜辺を求めるのにひき算・ほかの辺を求めるのにたし算をした。② でいちばん長い辺をまちがえた、AB 以外がいちばん長い直角三角形を「いいえ」とした。円錐・正四角錐で斜辺の2乗にたした | ① の「辺 a を求める」（5・12・13） |
| 2乗のわすれ | a ＋ b や c − b をそのまま答えた。② で 3, 4, 7 のような「長さをたした組」をえらんだ | ① の正方形（3 ＋ 4 ＝ 7 なのに 5） |
| √ のつけわすれ | c² の値（25 など）をそのまま答えた | ① の正方形（25 は面積） |
| √ の簡約ミス | 値は合っているが √ の中が小さくなっていない（「あと一歩」）、2乗の数のまま外に出した（√50 → 25√2）、かけ算に分けただけ（√12 → 2√6） | ① の 5・5（√50 ＝ 5√2 の黄色の行） |
| 逆の判定のまちがい | ② で直角三角形かどうかを反対に答えた、ちかい組（4, 5, 6 など）をえらんだ | ② の 3, 4, 6 と正方形 |
| 負の数のひき算のまちがい | ③ で 3 − (−2) を 1 のように計算した（横・たての長さ、距離の両方で見分ける） | ③ の A(−2, 1)・B(3, 4) |
| 座標そのものを長さに使った | ③ で座標の値を横・たての長さにした、x² ＋ y² だけで距離にした | ③ の A(1, 2)・B(4, 6) |
| 特別な比の位置のとりちがえ | ④ で 1 : 2 : √3 の 2 と √3 を入れかえた値、わる・かけるを反対にした値、1 : 1 : √2 とまぜた値を答えた | ④ の正三角形を「比で見る」 |
| 面の対角線で止めた | ⑤ で直方体の対角線に、面の対角線の長さを答えた | ⑤ の直方体（① ② の手順） |
| 直径と半径のとりちがえ | ⑤ で直径のまま三平方の定理を使った | ⑤ の円錐 |
| 底面の対角線の半分を使わなかった | ⑤ で正四角錐の高さに、1辺や1辺の半分を使った値を答えた | ⑤ の正四角錐（AH が光る） |
| 母線を高さに使った | ⑤ で円錐の体積に母線を使った | ⑤ の円錐 |
| 立体の中を通る長さにした（発展） | ⑤ の最短経路で空間の対角線を答えた | ⑤ の最短経路の展開図 |
| いちばん短い道ではなかった（発展） | ⑤ の最短経路で、いちばん短くない展開の長さや、辺を通る長さを答えた | ⑤ の最短経路（Ⅰ・Ⅱ・Ⅲ） |
| 計算まちがい | 上のどれにも当てはまらないまちがい（面積の ½、体積の ⅓ のわすれは、そのことを伝える） | ― |

回数は「🔎 あなたのつまずき」に出ます。「🔁 この型の類題」でその型の問題が出て、「🖼 元の図で見る」でその型が見える図にもどります。先生モードでは、この端末の合計回数も見られます。

## ワークシート

- ①予想「3 cm、4 cm、6 cm の3つの辺でできる三角形は、直角三角形だろうか？」（なる・ならない・わからない）→ ②「📄 ワークシートの問題」で ② を開く（はじめは数値をかくしてある）。計算してから「👀 数値を出す」でたしかめ、「＋ 記録する」（a・b・c・a² ＋ b²・c²・直角三角形？）。3, 4, 5 やほかの組、① の直角三角形も記録できる → ③気づき → ④まとめ（三平方の定理の逆）。

## 授業例

1時間めから順に、パートを1つずつ進める例です。

1. **辺を求める**（①）：「2辺が 3 と 4 のとき、斜辺は 7？」から始めて、正方形の面積で確かめる。1 と 1 で √2、5 と 5 で 5√2。斜辺でない辺はひき算。整数の組さがし。
2. **定理の逆**（②）：ワークシートの問題 3, 4, 6。ならびをかえても判定できるか。√ をふくむ組。
3. **2点間の距離**（③）：「AB の長さは、ものさしなしでどう求める？」直角三角形をかいて、負の座標で練習。
4. **特別な直角三角形**（④）：1辺 1 の正方形・1辺 2 の正三角形から比を見つける。対角線・高さから1辺を求める（有理化の復習）。
5. **空間図形**（⑤）：直方体の対角線（2回使う）→ 円錐・正四角錐の高さと体積。時間があれば発展の最短経路（実物の箱と糸でもためす）。

## 正しさ・じっさいとのちがい

- 計算はすべて分数と √ で正確に行います（長さは 0.5 きざみなので「長さ × 2」の整数や分数で持っています）。「約」の数だけ小数第2位までの四捨五入です。
- 辺の長さは「すいつく」がオンのとき 1 きざみ、オフのとき 0.5 きざみです。
- ① ② の図は、長さが変わると画面におさまるように大きさを変えています。④ の図はいつも同じ大きさです（相似なので比は同じ）。
- ② の角の大きさは小数第1位までの四捨五入です（直角三角形かどうかは、角度ではなく2乗の計算で判定しています）。a² ＋ b² と c² の大小で鋭角・鈍角がわかることは高校の内容（発展）です。
- ⑤ の立体は遠近のない形（正射影）でかいています。直角のしるしは、見た目では直角に見えないことがあります。最短経路は発展の内容です。
