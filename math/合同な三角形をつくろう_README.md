# 合同な三角形をつくろう

小学5年生の算数「合同な図形」（東京書籍 新しい算数 5上 72〜83ページ）で使う教材です。中2の「三角形の合同条件」の導入にも使えます。次のことを体験します。

- ぴったり重なる2つの図形は **合同**（うら返して重なるものもふくむ）
- 合同な図形では、**対応する辺の長さ・対応する角の大きさは等しい**
- **3つの辺**、**2つの辺とその間の角**、**1つの辺とその両はしの角** がわかれば、合同な三角形がかける
- 合同な **四角形** は、対角線で2つの三角形に分けるとかける

## 基本情報

- **ファイル**：`合同な三角形をつくろう.html`。共通ファイル `worksheet.js`・`worksheet.css`（ワークシート）を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。部品・図形・作図はすべて SVG でかいています。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます（5〜8年）。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。ドラッグは pointer events でマウスでもタッチでも動きます。本文20px以上・ボタン48px以上。スマホのたて向きでも画面がはみ出しません（部品をならべる板だけは、せまい画面では横にスクロールします）。
- **漢字**：合同・辺・角・頂点・対応・部品・弧・分度器・対角線 などにふりがなをつけています。中学生が使うときは「せってい」で消せます。SSS・SAS・ASA の記号は小さく残しています。
- **ワークシート**：よそう → やってみる → わかったこと → まとめ（小学生向け）。板を広く使うため、はじめは閉じています（右はしの「ワークシート」で開く）。「三角形を つくろう」ではつくり方・辺の長さ・角の大きさ・重なったか、「対応を 見つけよう」ではむすんだ対応を記録します。
- **保存**：ワークシートと「せってい」を、このブラウザの localStorage（キー：`ikechan-math-合同な三角形をつくろう`）に保存します。もんだいの成績は保存しません。
- **せってい**：もんだいの数（5・10）・ふりがな・こうかおん・うごき（「へらす」で、じどうで重ねるがすぐ重なる）。

## 3つの画面

### 🔺 三角形を つくろう（もとからある画面）

- 「3つの辺」「2つの辺とその間の角」「1つの辺とその両はしの角」から選びます。左に赤、右に青の、まったく同じ寸法の部品（辺＝太いぼう、角＝細いV字）が出ます。
- 部品のまんなかをドラッグで移動、はしの丸をドラッグで回転。つなぐところを近づけるとくっつき、そろうと三角形になります。
- 赤と青の三角形を重ねて、ぴったり重なれば合同。重ならないときは「うらがえす」。「じどうで重ねる」でコンピュータが重ねて見せます。
- 「かき方を見る」で、コンパス・分度器を使った作図の手順を4ステップで見られます。
- 「↩ ひとつ もどす」で、部品の移動・くっつけ・はずし・うらがえし・じどうで重ねる を1つずつ取り消せます。「🔄 もういちど」で部品を最初の場所にもどします。

### 🔗 対応を 見つけよう（新しく足した画面）

- **対応を さがす**：左の図形（頂点 A〜D）と、それを回したり うら返したりした右の図形（頂点 E〜H）。名前の順と対応の順はずらしてあります。三角形・四角形を選べ、「🎲 べつの 形」で新しい形になります。
- 左の頂点 → 右の頂点の順にタップ。正しいと点線でむすばれ、対応する辺に同じ色・同じ本数のしるし、対応する角に同じ数の弧がつきます。表に対応する頂点・辺・角と、その長さ・大きさ（等しいこと）が出ます。「長さ」「角度」で図に数も出せます。
- **四角形の かき方**：対角線 AC で分け、三角形 ABC → 三角形 ACD の順に、コンパスの弧で頂点を決める手順を4ステップで見せます。

### ✏️ もんだい（新しく足した画面）

| 種類 | 内容 |
|---|---|
| 合同かな？ | 回した・うら返した・大きさがちがう・形がちがう 2つの図形 |
| 対応する頂点 | 頂点 A に対応する頂点は？ |
| 対応から求める | 左の長さ・角から、右の辺の長さや角の大きさ |
| かくための条件 | 合同な三角形がかならずかけるのは、どれがわかったとき？ |
| 四角形と対角線 | 平行四辺形・長方形・ひし形・台形・ふつうの四角形を対角線で分けた2つの三角形は合同？ |

- どれも えらんで答えます（1回）。答えると理由が出ます。「💡 ヒント」で考え方が出ます。

## つまずき検知

| 型の名前 | 見つけ方 | 出るところ |
|---|---|---|
| うら返しは 合同で ない | うら返して重なる2つを「合同でない」とした | もんだい |
| 対応の とりちがえ | 名前の順（A→E、B→F…）で対応を決めた | 対応を 見つけよう・もんだい |
| かく ための 条件の まちがい | 「3つの角の大きさ」がわかればかけるとした | もんだい |

- もんだいでは、見つけた型を「あなたの つまずき」として出し、次にその型の「にた もんだい」を1問足します。終わりに型ごとの回数と、練習できるモードを知らせます。

## 先生モード（アドレスの最後に `?teacher=1`）

- 題名の横に「先生モード」のしるしが出ます。ワークシートに先生用のヒントと解答例が出ます。
- 三角形を つくろう：「▶ かき方を じどうで」で作図の手順を自動で進めます。
- 対応を 見つけよう：「💡 こたえ」ですべての対応をむすびます。
- もんだい：「💡 こたえ」。

## 授業での使い方の例

1. **合同の意味（1時間）**：「三角形を つくろう」で赤と青をつくって重ね、うら返して重なるものも合同であることを確かめる。
2. **対応する頂点・辺・角（1時間）**：「対応を 見つけよう」で三角形・四角形の対応をむすび、対応する辺・角が等しいことを表で確かめる。
3. **合同な三角形のかき方（2〜3時間）**：3つのつくり方をそれぞれ試し、「かき方を見る」で作図の手順を確かめる。3つの角だけではかけないことを話し合う。
4. **合同な四角形のかき方（1時間）**：「四角形の かき方」で対角線で分ける考え方を見る。
5. **まとめ**：「もんだい」で練習し、つまずきの型をふりかえる。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| 赤の部品・図形／青の部品・図形 | 赤／青 | 左がわ／右がわ、文字 |
| 対応する辺 | 4色 | しるしの本数（1〜4本） |
| 対応する角 | 4色 | 弧の数 |
| 正解／まちがい | 緑／赤むらさき | ◎・✖・△ の記号 |
