# 変化の割合と平均の速さ

中学3年「関数 y＝ax²」で、**変化の割合が一定でない**こと、x が p から q まで増えるときの変化の割合が **a(p＋q)** になること、そして**平均の速さ**を学ぶアプリです。
中2「変化の割合実験機」（一次関数）の発展です。放物線の上の2点 P・Q を動かして、2点を結ぶ直線（割線）の傾きを見ます。

## 基本情報

- **ファイル**：本体 `平均の速さ.html`、共通部品 `graph-engine.js`（座標平面・グラフ・ドラッグできる点）、`math-render.js`（式の表示・分数）、`worksheet.js`・`worksheet.css`（ワークシート）。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3・割合・関数）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）・スマホ。広い画面では「グラフ｜表・操作」の2列、せまい画面では縦に並びます。
- **記録**：この端末の localStorage（保存キー `ikechan-math-平均の速さ`）に、ワークシートといっしょに入れます。
- **URL の設定**：`?teacher=1` … 先生モード、`?part=1〜5` … そのパートから始める、`?ws=1`／`?ws=0` … ワークシートをひらいて／とじて始める

## パート

| パート | すること |
|---|---|
| ① 測る | 関数（一次関数 y＝2x＋1・y＝x²・y＝½x²・y＝−x²）をえらび、点 P・Q をドラッグ。割線（むらさきの点線）、x の増加量（オレンジ）、y の増加量（青の点線）、変化の割合の式が動く。「📌 記録する」を3回 → 「いつも同じ？」に答える。 |
| ② 公式 | y＝ax² の a をえらび、4つの区間（p→q）の変化の割合を計算して入れる。全部正解すると p＋q と a(p＋q) の列が出て、変化の割合と同じことが分かる（因数分解の説明つき）。「🎲 区間を変える」。 |
| ③ ボールの落下 | 落下距離 y＝4.9x²（m）。区間（0〜1秒、2〜3秒 など）をえらび、平均の速さ（m/秒）を入れる。正解すると、道のり÷時間の式・1秒ごとの棒グラフ（9.8 m/秒 ずつ速くなる）が出る。1秒ごとのボールの位置の図つき。 |
| ④ くらべる | y＝x² の P・Q と同じ x の点 P′・Q′ が y＝2x² にも出る。変化の割合は p＋q と 2(p＋q)（2倍）。問題「x が 1 から 4 まで増えるときの y＝2x² の変化の割合」。 |
| ⑤ 発展 | Q と P の x の差を 2 → 1 → 0.5 → 0.1 → 0.01 と小さくする（「▶ Q を P に近づける」で自動）。割線の傾きが 2ap に近づき、割線が接線に近づく（高校の微分の入口）。P はドラッグで動かせる。 |

## 授業での使い方（例）

- **導入（ワークシート）**：「2秒〜3秒の平均の速さは？」と予想させる。③ の「📄 ワークシートの問題」で計算 → 24.5 m/秒。44.1÷3＝14.7 とした生徒には、それが 0〜3秒の平均の速さであることを割線で見せる。
- **変化の割合**：① で一次関数と y＝x² をくらべ、「一定なのは一次関数だけ」をおさえる。② で表を作って a(p＋q) を見つける。
- **くらべる**：④ で y＝2x² は y＝x² の2倍になることを確認。
- **発展**：⑤ で、Q を P に近づけると割線が接線に近づくようすを見せる。

## 先生モード（`?teacher=1`）

- 答えの表示（変化の割合・a(p＋q)・平均の速さ・接線の傾き）。
- 「★ 答え（先生）」：そのパートの答えを入れて、たしかめまで進めます（① は記録3回、⑤ は近づけるアニメ）。
- この端末のつまずきの合計。ワークシートに、先生用のヒントと解答例が出ます。

## 正しさについて（じっさいとのちがい）

- 計算は分数で厳密に行っています（4.9 も 49/10 として計算し、見せるときだけ小数）。
- ③ のボールは空気の抵抗を考えていません。図のボールは、時間のようすが分かるように横に少しずつずらしてかいています。
- ⑤ の接線・微分は高校の内容です（画面に「発展」と表示）。差 0.1 以下で接線を表示しています。
