# 反比例の曲線（表・式・グラフで反比例を見る）

中学1年「比例と反比例」の反比例 y ＝ a/x を、**表・式・グラフ（双曲線）**で学ぶアプリです。x × y が一定であること、x ＝ 0 のときの扱い、グラフが軸にくっつかないこと、比例とのちがい、a が負のときを、4つのパートで確かめます。

| 関数グラフツール（`関数グラフ.html`） | 比例・反比例・一次関数・二次関数を、スライダーで自由に動かす道具 |

- **公開ページ**：トップページ「算数・数学」（中1）から開けます。

- **色のきまり**：反比例のグラフ＝紫、比例＝オレンジ、x が正の点＝オレンジ・負の点（④ では a が負の曲線）＝青、正解＝緑の「○」、まちがい＝赤紫の「×」。グラフがくっつかない軸は、赤紫の点線で強調します（チェックで消せます）。

## 使い方

答えはキーパッドで入れます。分数は **／**、小数は **．**、負の数は **−**（符号の切りかえ）。キーボードも使えます。

### ① 点を打つ

1. y ＝ 12/x（ほかに 6・8・10・16・18）。表の x ＝ 1, 2, 3, 4, 6, 12 のときの y を順に答えます。正解するたびに点が打たれ、表に「x × y ＝ 12」が出ます。
2. 表がうまったら「x ＝ 0 のとき、y は？」（y ＝ 0／y ＝ 12／ない）。0 でわれないので「ない（決まらない）」が正解。
3. 「点の結び方」のスライダー：点だけ → 1 きざみで結ぶ（折れ線）→ 0.5 → 0.25 → 0.1 きざみ → なめらかな曲線。きざみは数でも入れられます（0.05〜1）。
4. 「🔍 x を 0 に近づける」：x ＝ 2, 1, 0.5, 0.2 … 0.001 と点が動き、表に y ＝ 6000 のような値がふえます（y はどんどん大きくなるが、y軸 にはくっつかない）。「🔍 x を大きくする」は y が 0 に近づく様子（x軸 にくっつかない）。
5. 「x が負のときも」にチェックすると、第3象限の枝も出ます。

### ② 面積一定

1. 原点 O と点 P を向かい合う角とする緑の長方形。P をドラッグすると、x × y ＝ a（面積）のまま P が曲線の上を動き、通ったあとに点が残ります。
2. 「たて × よこ ＝ 2 × 6 ＝ 12」が式の欄に大きく出ます。
3. 「📌 長方形を残す」で、形のちがう同じ面積の長方形を重ねて見られます（表にも行がふえる）。「〰 曲線を見せる」で双曲線。
4. a（面積）はスライダーと数で 1〜24。「x が負も」で第3象限へ（x ＝ 0 はこえられません）。
5. 🎯 チャレンジ：「面積 12 のまま、P を点線（y ＝ 2）の高さに合わせよう」。
6. すいつく（整数）／すいつかない（0.01 きざみ）はグラフの上のボタンで切りかえ。

### ③ 比例とくらべる

1. はじめは y ＝ 2x と y ＝ 6/x（スライダーで 比例 a 0.5〜4、反比例 b 1〜24）。交点が2つ出ます。y ＝ 2x と y ＝ 8/x なら交点は (2, 4) と (−2, −4)。
2. 表は x ＝ 1, 2, 3, 4, 6, 12 の比例と反比例の y をならべたもの。行を2つタップすると「x：1 → 3（3倍）、比例の y：3倍、反比例の y：1/3倍」とくらべられます。
3. 問題「反比例で、x が 3倍になると、y は？」（1/3倍・3倍・3へる・かわらない）。

### ④ a が負

1. y ＝ −6/x（ほかに −4・−8・−12）。表の x ＝ −6〜6 のうち、黄色の行の y を3つ答えます（正と負の x をまぜる）。
2. 「グラフはどの象限にある？」→ 第2象限と第4象限。
3. 「符号を反対にした曲線もかく」で y ＝ 6/x と重ね、軸について対称なことを見ます。a のスライダー（−12〜12）で正・負を行き来できます。

ボタン：🎲 新しい問題／↶ ひとつもどす（② のドラッグも1回分もどせる）／⟲ もういちど／💡 ヒント（押すたびにくわしく）／📄 ワークシートの問題（① を y ＝ 20/x で開く。x ＝ 1 と 10、2 と 20 がくらべられる）

## 授業での使い方（例）

- **導入（5分）**：ワークシートの予想「x が 10倍になったら y は？」を挙手で集める。
- **展開①（15分）**：「📄 ワークシートの問題」（y ＝ 20/x）で表をうめ、1行ごとに「＋ 記録する」。x ＝ 1 → 10 で y ＝ 20 → 2（1/10倍）を確かめる。x ＝ 0 の問いから「0 でわれない」を確認し、きざみのスライダーで点 → 折れ線 → 曲線を見せる。「🔍 x を 0 に近づける」で軸にくっつかないことを見せる。
- **展開②（10分）**：② で P を動かし、面積が一定のまま曲線ができることを見る。
- **練習（10分）**：③ で比例とのちがい、④ で a が負のとき。
- **まとめ（5分）**：ワークシートの④に「x × y が一定。x が k倍 → y は 1/k倍。グラフは双曲線で、軸とは交わらない」。

## つまずき検知の一覧

| 型 | どこで見つけるか | 練習するパート |
|---|---|---|
| 比例とまぜた（a × x にした） | ①④ で、y に a × x の値を答えた | ① |
| わる数とわられる数が逆 | ① で、x ÷ a の値を答えた | ① |
| ひき算にした | ① で、a − x の値を答えた | ① |
| x ＝ 0 のときの y | ① で、x ＝ 0 のとき「y ＝ 0」「y ＝ a」を選んだ | ① |
| 反比例も「x が2倍→y も2倍」とした | ③ で「x が k倍 → y は k倍」を選んだ | ③ |
| a が負のときの y の符号 | ④ で、符号だけが反対の y を答えた | ④（負の x が多く出る） |
| a が負のときのグラフの象限 | ④ で「第1象限と第3象限」を選んだ | ④ |

「🔎 あなたのつまずき」に、この時間に出た型と説明が出ます。「🔁 この型を練習」で、その型の問題があるパートへ移ります。
記録は、この端末の localStorage（キー `ikechan-math-反比例の曲線`、ワークシートと同じ）に入ります：つまずきの型ごとの回数・パートごとの正解の数・ヒントの回数。先生モードで合計を見たり消したりできます。

## 正しさとじっさいとのちがい

- 表の y・x × y・交点（ぴったり表せるとき）は分数（Fraction）で厳密に計算しています。答えは 3/2 でも 1.5 でも正解です。
- ③ の交点は x² ＝ b/a で求めます。分数でぴったり表せないとき（y ＝ 2x と y ＝ 6/x など）は「約(1.7, 3.5)」と小数で出します（ぴったりの値は中3 の平方根で表せます）。
- グラフは画面の中だけ描いています。本当の曲線は、軸に近づきながらどこまでも続きます。
- 「漸近線」は高校で学ぶことばなので、説明に「発展」と書いています。
- ② の P は、すいつかないとき 0.01 きざみ、x は 0.3 より 0 に近づけません（長方形が細くなりすぎて見えなくなるため）。

## 先生がかえやすいところ

- ① の比例定数の候補：`POOL1`、④：`POOL4`、③ の表の x：`XS3`。
- きざみの段階：`STEPS`。
- つまずきの型：`TRIPS` に名前・説明・練習するパートを書きます。
