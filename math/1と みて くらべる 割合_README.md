# 1と みて くらべる 割合

小学5年生の算数「割合」（東京書籍 新しい算数 5下 64〜80ページ）で使う教材です。**もとにする量を1とみたとき、くらべる量がどれだけにあたるか**を、テープ図・数直線・100マスの方眼・二重数直線で見ていきます。

- 割合＝くらべる量÷もとにする量（もとの量がちがうときは、差ではなく倍でくらべる）
- 小数・**百分率**（％）・**歩合**（割・分・厘）は、もとにする量を 1・100・10 とみたちがい
- くらべる量＝もとにする量×割合、もとにする量＝くらべる量÷割合（どれも同じ二重数直線で考える）
- **わりびき・わりまし**（20％引き＝0.8倍、20％増量＝1.2倍）

今までの「割合トレーニング」（`割合.html`）・「割合ドリル」（`割合ドリル.html`）は、練習用として残しています。

## 基本情報

- **ファイル**：`1と みて くらべる 割合.html`。共通ファイル `worksheet.js`・`worksheet.css` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。図はすべて SVG。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」（5年）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。本文20px以上・ボタン48px以上。スマホのたて向きでも画面がはみ出しません。
- **漢字**：割合・倍・百分率・歩合・量・定員 などにふりがなをつけています。「せってい」で消せます。
- **ワークシート**：よそう → やってみる → わかったこと → まとめ（小学生向け）。「きろくする」で、場面・もとにする量・くらべる量・割合を記録します。
- **保存**：ワークシートと「せってい」を、このブラウザの localStorage（キー：`ikechan-math-1と みて くらべる 割合`）に保存します。もんだいの成績は保存しません。

## 4つの画面

### 🏀 何倍かな

- **シュートの きろく**：A 10回中6回、B 8回中6回、C 10回中7回。「A と C」（投げた数が同じ）、「A と B」（入った数が同じ）、「B と C」（どちらもちがう）、「ぜんぶ」を選びます。
- テープ図の上が入った数（くらべる量・オレンジ）、下が投げた数（もとにする量・青のしま）、その下が0〜1の数直線です。「📏 投げた 数を 1と みる」で青いテープの長さがそろい、「1」の位置がそろいます。
- 入った数が投げた数の何倍かを入れ、いちばんよく入った人をえらびます（入った数だけでくらべたときは声かけ）。「✏️ 回数を かえる」で数を変えられます（ひとつ もどす・もういちど あり）。
- **差と 倍**：2本のゴム（のびた長さの差は同じで、倍がちがう組）。予想 → 「➖ 差で くらべる」「✖️ 倍で くらべる」（もとの長さを何本分ならべられるか）。「🎲 べつの ゴム」で5組から出ます（A・B はランダムに入れかわる）。

### 💯 百分率と 歩合

- **1・10・100と みる**：数直線（小数）・10マスのテープ（歩合）・100マスの方眼（百分率）を上下にならべます。テープの1マスと方眼のたて1れつは同じはばで、0.1＝1割＝10％ が見えます。
- −0.1・−0.01・＋0.01・＋0.1 か数の入力で、割合を0〜1.5（1/100の位まで）にします。1をこえると方眼が2つめにはみ出します。
- 場面：シュート（20回中13回）・たねの発芽（50こ中41こ）・バスの定員（40人に46人＝115％）。「数を かくす」で表と図の数を「？」にできます。
- **なおして みよう**：小数→百分率、百分率→小数、小数→歩合（厘まで）、歩合→百分率。2回まちがえると答えと図が出ます。

### 📏 二重数直線

- **3つの もとめ方**：割合（定員・シュート・テスト）→ くらべる量（ちょ金・花だん・歩いて来る人）→ もとにする量（めがね・ジュース・本）の順にくり返し出ます。
  - ① 「もとにする量は どれ？」をえらぶ（毎問ここから）→ ② 二重数直線（上＝量、下＝割合。もとにする量はいつも割合の1の上）を見て式をえらぶ → 答えと ×割合・÷割合 の矢印。公式（くもわ）は使いません。
- **わりびき・わりまし**：シャツ・本の○％引き、ジュース・おかしの○％増量。テープ図（もとの量＝1、引く分・ふえる分）と二重数直線。① 何％にあたるか（100−○、100＋○）→ ② 式（正しい式は2つ：a×(1−0.2) と a−a×0.2）。

### ✏️ もんだい

| 種類 | 例 | 答え方 |
|---|---|---|
| 割合を もとめる | 50回中15回 → 何倍？／定員40人に30人 → 何％？ | 数字ボタン（2回まで） |
| 百分率・歩合 | 0.93 を百分率で／7％ を小数で／6割3分 を百分率で | 数字ボタン（2回まで） |
| くらべる量を もとめる | 500円の 40％は？ | 数字ボタン（2回まで） |
| もとにする量を もとめる | 4人がクラス全体の 10％。全体は？ | 数字ボタン（2回まで） |
| わりびき・わりまし | 1000円の 30％引き／400mLの 50％増量 | 数字ボタン（2回まで） |

- 5問なら1つずつ、10問なら2つずつ（「せってい」でえらべます）。PCはキーボードの数字・「.」・Backspace・Enter も使えます。

## つまずき検知

| 型の名前 | 見つけ方 | 出るところ |
|---|---|---|
| もとにする量の とりちがえ | わる数とわられる数が逆（8÷6、50÷15）、もとにする量の選びまちがい、もとにする量を求めるのに ×割合 | 何倍かな・二重数直線・もんだい |
| 百分率の なおし方の まちがい | ×100・÷100 のずれ（0.67→6.7％、62％→6.2）、％のままかけた（500×40） | 百分率と歩合・二重数直線・もんだい |
| わりびきの まちがい | 20％引きを20％とした、引かれる分（×0.2）を答えにした、1500−0.2 とした | 二重数直線・もんだい |

- もんだいでは、見つけた型を「あなたの つまずき」として出し、次にその型の「にた もんだい」を1問足します。終わりに型ごとの回数と、練習できる画面へのボタンを出します。

## 先生モード（アドレスの最後に `?teacher=1`）

- 題名の横に「先生モード」のしるし。シュートの きろく・なおして みよう・二重数直線・もんだい：「💡 こたえ」。ワークシートに先生用のヒントと解答例が出ます。

## 授業での使い方の例

1. **割合の意味（2時間）**：「何倍かな」のシュートで、投げた数が同じ・入った数が同じ組から、どちらもちがう組へ。「1と みる」でテープをそろえ、割合＝くらべる量÷もとにする量 をまとめる。「差と 倍」で、倍でくらべるよさを確かめる。
2. **百分率と歩合（2時間）**：「1・10・100と みる」で 0.1＝1割＝10％ を確かめ、「なおして みよう」で練習する。定員の場面で100％をこえる割合も見る。
3. **割合を使った問題（3時間）**：「二重数直線」の3つの もとめ方。毎問「もとにする量はどれ？」から入り、同じ図で3つの求め方を考える。
4. **わりびき・わりまし（1時間）**：テープ図で、20％引きは0.8倍、20％増量は1.2倍になることを確かめる。2つの式をくらべる。
5. **まとめ**：「もんだい」で練習し、つまずきの型をふりかえる。

## 正しさと、じっさいとのちがい

- シュートの記録・ゴムの長さ・ねだん・人数などは作った数です。
- 割合は1000倍した整数で計算しているので、小数の誤差は出ません。わりきれない割合は、1/100の位までのがい数でも正解にしています。
- 「1・10・100と みる」の入力は1/100の位（1分）までです（方眼で表せるため）。厘は「なおして みよう」で練習します。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| もとにする量／くらべる量 | 青／オレンジ | しま模様／ぬりつぶし、「もとにする量」「くらべる量」の文字 |
| 引く分／ふえる分（わりびき・わりまし） | 灰色／緑 | 点線のわく／点の模様、「−20％」「＋25％」 |
| わからない数 | 赤むらさき | 「？」の箱 |
| 正解／まちがい | 緑／赤むらさき | ◎・△ の記号 |
