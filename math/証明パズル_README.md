# 証明の組み立てパズル（カードをならべて、図形の証明の流れを学ぶ）【パート1】

中学2年「図形の調べ方（三角形の合同と証明）」のアプリです。証明の「仮定 → 根拠 → 結論」の流れを、カードを正しい順にならべて組み立てます。合同条件（3組の辺／2組の辺とその間の角／1組の辺とその両端の角）の使い分けも練習します。

## 基本情報

- **ファイル**：本体 `証明パズル.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中2）から開けます。
- **画面のならび**：上＝図（点を動かせる）。広い画面は 左＝仮定・結論とヒント／中央＝証明の欄／右＝証明のカード の3列。タブレットは「仮定・証明」と「カード」の2列（カードの列はスクロールしても見えたまま）。スマホは1列。
- **URL の設定**
  - `?teacher=1` … 先生モード（「▶ 答えを自動で組み立てる」、自分で書くモードのお手本がすぐ見られる、ワークシートのヒントと解答例）
  - `?q=2` … 2番目の問題から開く（1〜4）
  - `?ws=1` … ワークシートをひらいて開く

## 問題（パート1）

| 問題 | 仮定 | 結論 | 合同条件 | 見落としやすいところ |
|---|---|---|---|---|
| ① 二等辺三角形の底角 | AB＝AC、BD＝CD（D は BC の中点） | ∠ABD＝∠ACD | 3組の辺 | AD は**共通** |
| ② 平行四辺形の対辺 | AB∥DC、AD∥BC | AB＝CD、BC＝DA | 1組の辺とその両端の角 | 対角線 AC が**共通**、平行線の**錯角** |
| ③ AB＝AC、BD＝CE | AB＝AC、BD＝CE（D、E は BC 上） | △ABD≡△ACE | 2組の辺とその間の角 | ∠B＝∠C は①の性質（底角）から。AD＝AE は使えない |
| ④ 直角三角形の斜辺と鋭角 | ∠C＝∠F＝90°、AB＝DE、∠A＝∠D | △ABC≡△DEF | 1組の辺とその両端の角 | ∠B＝∠E を内角の和から導く。∠C＝∠F では両端の角にならない |

問題は、ファイルの中の `PROBS` に1つ足すとふえます（図の点・ドラッグのきまり・仮定・結論・カード）。

## 使い方

### 🧩 カードでならべる
- 右のカードを、証明の欄の行へ**ドラッグ**します。カードを**タップ**すると、あいている行のいちばん上に入ります。置いたカードをタップすると、もどせます。
- 行の役割は「はじめ（△…と△…で）→ 根拠①②③ → 合同 → 結論」の順に決まっています（①②③はどの順でもよい）。上の「流れ」の帯で、今どこまで進んだかが分かります。
- カードの種類：緑＝はじめ、黄＝根拠（〜より・〜から）、青むらさき＝合同（〜から、△…≡△…）、茶＝結論。使わない（まちがいの）カードもまざっています。
- 根拠を置くと、その辺・角が**図の中で行の色で光ります**（①オレンジ・印1本、②青・印2本、③むらさき・印3本。辺は線の色、角は弧の色）。行の番号をタップすると、もう一度光らせられます。
- 「△…と△…で」を置くと、2つの三角形にうすく色がつきます。
- **✂ 2つの三角形に分けて見る**：重なっている2つの三角形を少しはなして表示します。共通の辺は両方に出てくるので、見落としに気づけます。
- 図の ○ の点をドラッグすると形が変わります（「方眼にすいつく」の切りかえあり）。形が変わっても証明がなりたつことを確かめます。

### ✏ 自分で書く
- 各行に文字で入力し、「✔ 答え合わせ」で行ごとに ○／✖ と理由が出ます。記号（△ ∠ ＝ ≡ ∥ °）とよく使うことば（（仮定）・（共通）・合同条件など）はボタンで入れられます。
- 読みとるもの：三角形の組と対応の順、等式（AB＝AC、∠ABD＝∠ACE など）とその理由（仮定・共通・錯角・底角・内角の和）、合同条件のことば、≡ の対応、結論と「対応する辺／角」。
- ∠B と ∠ABD のように同じ角を別の名前で書いても、図の座標で同じ角かを調べて正解にします。全角・半角、「三組」「3組」、「90度」「90°」、「AB//DC」なども受けつけます。
- 1回答え合わせをすると「📖 お手本を見る」が出ます。

### 💡 ヒント（3段階・順番に）
1. 図に仮定の印（灰色）をつける。共通の辺は点線と「共通」の文字で見せる。
2. 使う合同条件と、見るべきところを教える。
3. 最初の行（△…と△…で）を置く。

### ▶ 読み上げ・🖨 印刷
- 完成した（または途中の）証明を、仮定から結論まで1行ずつ光らせながらたどります。「🔊 声も出す」にすると、ブラウザの読み上げ機能で声も出ます（声の有無・声の種類はブラウザによります）。
- 印刷は、図・仮定・結論・証明の行（空の行は書きこむ線）・「自分のことばで」の線を A4 に出します。

### ワークシート
- ①予想「二等辺三角形を折って重なるとき、合同になるのはどの条件？」→ ②証明を完成させて記録（問題・やり方・合同条件・ヒント数・まちがい数）→ ③気づき → ④自分のことばで証明を書く。
- 保存キーは `ikechan-math-証明パズル`。完成した問題には ✅ がつきます。

## つまずき検知の一覧

| 型 | 検出のしかた | もどる先 |
|---|---|---|
| 🔃 順序が逆 | カードの種類と行の役割が合わない（根拠より先に合同、合同より先に結論 など） | ― |
| 🧱 根拠が足りない | 根拠が3つそろう前に合同のカードを置いた | 図に仮定の印 |
| 👀 「共通」を見落とした | 根拠が足りず、足りないものが共通の辺 | 印＋2つに分けて見る |
| 📏 合同条件に当てはまらない | ①②③の組み合わせ（辺・角）と、えらんだ合同条件が合わない。2辺と間でない角、辺と両端でない角は、その理由を出す | ヒント②（合同条件） |
| ❓ 根拠のないことを使った | 仮定にない・まだ分かっていないこと（∠BAD＝∠CAD、AD＝AE など） | 図に仮定の印 |
| 🔁 結論を根拠に使った | 証明したいことを根拠の行に置いた | 仮定と結論を見くらべる |
| 🏷 理由がちがう | 共通なのに（仮定）、錯角なのに同位角、底角・内角の和を（仮定）、角なのに「対応する辺」 | ― |
| 🔀 対応の順がちがう | △ABD と △ADC のように頂点の対応がずれている | 2つに分けて見る |

回数は「📒 つまずきの記録」に残ります（「記録を消す」で消せます）。

## 授業例（1時間）

1. 紙の二等辺三角形を折って重ね、「なぜ重なるといえる？」と問う。ワークシートの予想。
2. ①をカードで組み立てる。∠BAD＝∠CAD（仮定）のカードをえらぶ生徒が多いので、「見た目で等しい」と「根拠がある」のちがいを話し合う。
3. ②・③で、共通の辺・錯角・①で証明した性質を根拠に使う経験をする。④は発展的に「なぜ直角三角形の合同条件がなりたつのか」を考える。
4. 「自分で書く」モードか、印刷したプリントで、①の証明を自分のことばで書く。

## 正しさ・じっさいとのちがい

- 証明の書き方（「〜より」「〜から」、①②③の付け方、「△ABD と △ACD において」など）は教科書や先生によって少しちがいます。このアプリの書き方は一例です。
- 根拠の行①②③は、どの順にならべても正解にしています。
- 自分で書くモードは、キーワードと等式を読みとる方式です。ことばの言いかえ（「同じだから」など）は、正しくても ✖ になることがあります。最後は先生の目で確かめてください。
- 図を見て「等しそう」なことは根拠にならない、ということを大事にしています（図を動かせるのはそのため）。
