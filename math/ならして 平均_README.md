# ならして 平均（でこぼこを ならすと、どれも 同じ 大きさ）

小学5年生の算数「平均」で使う、「ならす」動きで平均を体感するシミュレーション教材です。次のことを体験します。

- 平均は「**でこぼこをならして同じ大きさにしたもの**」で、**合計÷個数** で求められる
- **0のデータも個数に入れる**
- 平均から合計を求める（**平均×個数＝合計**）、歩はばを使った長さの見積もり
- 人数など本来は小数にならない量でも、**平均は小数になることがある**

## 基本情報

- **ファイル**：`ならして 平均.html`。この1ファイルだけで動きます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。絵とグラフはすべて SVG（エスブイジー：線や図形を式で描く画像）で描いています。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。
  - 画面の幅に合わせて、図とパネルの並び方が変わります（広い画面は横、せまい画面は縦）。ボタンは48px以上です。
- **漢字**：5年生までに習う漢字にふりがなをつけています。「均」は小学校で習わないので、ふりがなOFFでも「平均（へいきん）」のふりがなは残します。「幅」「廊」「距離」は使わず「歩はば」「ろう下」「きょり」と書いています。
- **記録**：保存されるのは「せってい」だけです。児童の名前など個人情報は扱いません。

## モード

| モード | 内容 |
|---|---|
| 🥤 ならして みよう | コップとブロックを切りかえ。「〰 ならす」で水面が動いてそろう（いっきに／1つずつ）。ブロックは高い列から低い列へドラッグ（タップで選んで置くでも可）。平均の線で、はみ出たぶん＝足りないぶん。データの数（2〜8こ）と量（0〜10dL）を編集できる |
| 🧮 計算で もとめよう | 合計 → 個数 → 合計÷個数 の順に答える（5問）。正かいのあと「ならして たしかめる」で計算とならした高さが同じになる |
| 0️⃣ 0が あるとき | 欠席者数（木よう日0人）など。0を個数に入れる／ぬかすでならし方と結果をくらべる |
| 🍊 平均から 合計へ | みかん65g×40こ→約2.6kg など4問。大きさのちがう絵が「ならす」でそろう |
| 👣 歩はばで はかろう | 先生が入れた10歩の記録5回 → 平均 → 1歩の歩はば → ろう下の長さを見積もる |
| 📏 かりの 平均（発展） | 緑の線（かりの平均）を決め、線より多いぶん・少ないぶんだけで平均を求める |
| 🧑‍🏫 先生モード | データを入れて大きく表示。データ → 合計 → 個数 → 平均の線 → 移しかえ1回ずつ → まとめ をステップ再生（じどうもあり） |

## つまずきへの対応

| つまずき | 教材の反応 |
|---|---|
| 0の日を個数に入れ忘れる（7÷4など） | 空のコップを光らせ「0人の日も、空のコップがならんでいるよ。個数は5日」。くらべる表が出る |
| 平均が最大値より大きい・最小値より小さい | 「ならすと、いちばん多い○といちばん少ない○の間になるはず」。その2つの列を光らせる |
| わる数とわられる数が逆 | 「合計÷個数だよ」 |
| 四捨五入の位がちがう | 「○の位まで出そう」 |
| 平均から合計をわり算・たし算で出す | 「わり算（たし算）ではなく、かけ算」 |
| g で答えて kg に直していない | 「1000g＝1kg だから、kgになおそう」 |
| 10歩分を1歩分とまちがえる | 「それは10歩分のきょり。1歩分は÷10」 |
| ブロックを低い列から高い列へ移す | 「高いところから低いところへうつそう」 |

## しくみ（コードのつくり）

- **データは数の配列**：たとえば `[6, 2, 5, 3]`。コップ・ぼう・ブロックの絵は、この配列から毎回描き直します（`drawChart`）。
- **ならすアニメ**（`mkLev`・`levRun`）：はじめの配列 `from` と、ならしたあとの配列 `to` を持ち、そのあいだを 0→1 の割合 `p` で計算（補間）して描きます。どれだけ移すかは `planMoves` が「いちばん多いところ → いちばん少ないところ」をくり返して決めます。この移し方は、矢印の表示や「1つずつ」・先生モードのステップ再生にも使います。
- **答えの判定**（`matchAns`）：正しい値と同じか、入れた位で四捨五入した値と同じなら正かいです。
- **小数の処理**：せっていの「整数で／1/10の位まで／1/100の位まで」で、わり切れない平均を四捨五入して「約」をつけます。
- **ブロックの色**：もとの列ごとに色を変え、①②…の番号も書きます。ほかの列へ移したブロックは点線のわくになります（色だけで区別しないため）。

## 色と形（色だけで区別しない）

| もの | 色 | ほかの区別 |
|---|---|---|
| 平均の線 | ピンク | 太い実線と「へいきん」の札 |
| かりの平均の線 | 緑 | 点線と「かりの へいきん」の札、左はしの ↕ |
| はみ出たぶん | 赤 | ななめの線（斜線）と「＋2」 |
| 足りないぶん | 青 | 点線のわくと「−1」 |
| 光らせる列 | 黄色 | 点めつ（動きを減らす設定では点めつしない） |

## 動作確認の方法

1. `ならして 平均.html` をブラウザ（Chrome・Edge・Safari）で開きます。
2. 🥤 ならして みよう：
   - 「〰 ならす」を押す → 4つのコップが 4dL にそろい、「そろった！」と出る。
   - 「1つずつ」にしてから押す → 1回目は ①→② 2dL、2回目は ③→④ 1dL で、そろう。
   - 「🧱 ブロック」にして、①のブロックを②へドラッグ → 5,3,5,3 になる。
   - 「― 平均の 線」 → 斜線と点線が出て、右のパネルに「はみ出たぶん 3dL ＝ 足りないぶん 3dL」。
   - 「れい5」→ ブロックの「おてほん」を数回 → 「わらないとそろわない」。コップで ならすと 約3.7dL。
3. 🧮 計算で もとめよう：16 → 4 → 7 と入れると「間になるはず」と出て、6と2の列が光る。4 で正かい。「ならして たしかめる」で 4dL にそろう。
4. 0️⃣ 0が あるとき：1.75 と入れると木よう日のコップが光る。1.4 で正かい。
5. 🍊 平均から 合計へ：2600 → 次の問いで 2600 と入れると「kgになおそう」。2.6 で正かい。
6. 👣 歩はばで はかろう：6.1 → つぎへ → 0.61 → つぎへ → 32 で「約32m」。
7. 📏 かりの 平均：「▶ つぎ」を4回 → 平均 29m。線を ▼ で動かすと「どこに線をひいても答えは同じ」。
8. 🧑‍🏫 先生モード：「▶ つぎ」で 6 ステップ進み、最後に 平均 4dL。データを「3 0 2.5 4.5」に変えて「✔ ひょうじ」でも動く。
9. ⚙️ せってい：ふりがな OFF、動きを減らす（アニメがなくなりすぐ切りかわる）、小数の処理を変えて表示が変わること。

## 授業例

### 1. 平均の意味（1時間目）

1. 🥤 ならして みよう「れい1」を電子黒板に出し、「平均の数：かくす」にする。「どのコップも同じ量にするには？」と問う。
2. 「🧱 ブロック」で、児童に前に出てブロックを動かしてもらう。低い列から高い列へ動かした場合のことばも全体で共有する。
3. 「― 平均の 線」で、はみ出たぶん（斜線）と足りないぶん（点線）が同じ量になることを確かめる。
4. 「🥤 コップ」→「1つずつ」で、移しかえを1回ずつ見せ、「ならす」ということばをおさえる。
5. 🧮 計算で もとめよう で、合計÷個数の式にまとめ、ならした高さと一致することを確かめる。図書室の人数（21.4人）で、平均は小数になってもよいことに気づかせる。

### 2. 0を含む平均

1. 0️⃣ 0が あるとき の問題1（欠席者数）で、まず個人で答えさせる。
2. 7÷4＝1.75 と答えた児童がいたら、そのまま入力して、木よう日のコップが光る様子を見せる。
3. 「0を ぬかして ならす」と「0も 入れて ならす」をくらべ、ぬかすと木よう日のコップが空のまま残る（ならしたことにならない）ことを話し合う。
4. 問題2・3（シュート・読んだ本）で、0が2つ・3つある場合も確かめる。

### 3. 歩はばの活用

1. 事前に、児童がろう下などで10歩の距離を5回はかる（記録はグループごとに先生が入力）。
2. 👣 歩はばで はかろう の上のらんに記録を入れ、10歩の平均 → 1歩の歩はば を求める。
3. ろう下を歩いた歩数を ＋− で入れ、長さを見積もる。実際にメジャーではかった長さとくらべる。
4. 🍊 平均から 合計へ で、「平均×個数」で全体を見積もる考え方につなげる。
