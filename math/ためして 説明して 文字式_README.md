# ためして 説明して 文字式（数でためす → 文字式で説明する → 反例をあげる）

中学2年「文字式の利用（式による説明）」の入口になるアプリです。
「2つの偶数の和は偶数」「連続する3つの整数の和は3の倍数」のようなことがらを、まず**数でためし**、何組ためしても「ぜんぶ」とは言えないことを体験してから、**文字式で説明**します。成り立たないことがらには**反例**をあげます。

## 基本情報

- **ファイル**：本体 `ためして 説明して 文字式.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中2）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）・スマホ。
- **画面のならび**：左に「ことがら」、中央に「実験（数でためす）」、右に「文字式で説明」。タブレットの横向きで3列になり、せまい画面では上から ことがら → 実験 → 説明 の順に並びます。
- **URL の設定**
  - `?teacher=1` … 先生モード（③ の「▶ 説明を自動で組み立てる」・ワークシートのヒントと模範解答）
  - `?mode=exp`・`tool`・`build`・`cex` … はじめに開くタブ
  - `?ws=0` … ワークシートをとじて開く

## あつかうことがら

| ことがら | 文字での表し方 | 説明の中心の式 |
|---|---|---|
| 2つの偶数の和は、偶数である | 2*m*, 2*n* | 2*m*＋2*n*＝2(*m*＋*n*) |
| 2つの奇数の和は、偶数である | 2*m*＋1, 2*n*＋1 | 2*m*＋2*n*＋2＝2(*m*＋*n*＋1) |
| 偶数と奇数の和は、奇数である | 2*m*, 2*n*＋1 | 2*m*＋2*n*＋1＝2(*m*＋*n*)＋1 |
| 連続する3つの整数の和は、3の倍数である | *n*, *n*＋1, *n*＋2 | 3*n*＋3＝3(*n*＋1) |
| 連続する2つの奇数の和は、4の倍数である | 2*n*＋1, 2*n*＋3 | 4*n*＋4＝4(*n*＋1) |
| 2けたの整数と、十の位と一の位を入れかえた数の和は、11の倍数である | 10*a*＋*b*, 10*b*＋*a* | 11*a*＋11*b*＝11(*a*＋*b*) |

④ 反例：2つの奇数の和は奇数？／2つの偶数の和は4の倍数？／連続する2つの整数の和は偶数？／連続する3つの整数の和は6の倍数？／3つの偶数の和は偶数？（最後の1つだけは、いつも成り立ちます）

## 使い方

### ① 実験（中央・どのタブでも使える）
- 数を入れて「✔ ためす」。▲▼ は、偶数・奇数のところでは 2 ずつ動きます（種類がかわらないように）。偶数のところに奇数を入れると、⚠ が出てためせません。
- 「🎲 数をえらぶ」「🔟 10組ためす」「🐘 大きな数で」（6けたの数）。
- **おはじきの図**：それぞれの数を 2列（3の倍数なら3列…）にならべ、合わせたものもならべ直します。ちょうど長方形になれば ✅、あまりが出れば赤紫の点線で ✖。1つめの数＝オレンジの丸、2つめ＝青の四角、3つめ＝緑の三角です。
- 下の表に記録がたまり、「ためした組：○組」と出ます。ぜんぶ ✅ のときも「整数は限りなくあるので、何組ためしても『ぜんぶ』をためしたことにはならない」と出ます。
- 右の「わかったこと」：3組以上ためすと「これで『どんな数でも』〜と言える？」。「言える」をえらぶと、つまずき「数でためしただけで『ぜんぶ』と言った」になります。
- 「↶ ひとつもどす」（最後にためした組・10組をまとめて取り消す）、「⟲ もういちど」（そのことがらの記録を消す）。

### ② 式の道具
- 上の**道具カード**（偶数 2*m*・奇数 2*n*＋1・連続する整数・連続する奇数・2けた 10*a*＋*b*・3けた 100*a*＋10*b*＋*c*・○の倍数）をタップすると、短い説明が出ます。
- 「〜の数を、文字でどう表す？」の選択肢から正しい表し方をえらびます。まちがいはつまずきとして出ます（2*m* と 2*m*、*m*＋1 と *n*＋1、*ab* と *ba* など）。
- 正しくえらぶと、文字のスライダー（数の入力つき）が出て、2*m*＝14 のように値が変わります。「🧪 この数で実験する」で中央の実験に送れます。

### ③ 説明の組み立て
- 4まいのカード（文字で表す・式を変形する・倍数の形に整理する・結論）をタップして、①〜④ の場所に順に入れます。入れたカードをタップすると下にもどります。
- 「✔ 順番をたしかめる」。結論が最後でないと、つまずき「結論を先に書いた」になります。
- 順番が合うと □ が入力らんになります。「✔ 穴うめをたしかめる」（Enter でも可）。
  - 1つめの □（かっこをはずしてまとめた式）：等しい式で、かっこがなく同類項がまとまっていれば正解。
  - 2つめの □（○×(整数) の形）：もとの和と等しく、○(…) の形（偶数と奇数の和は 2(…)＋1）なら正解。*m*＋*n* と *n*＋*m* のような書き方のちがいは正解にします。3*n*＋3 のままだと、つまずき「○×(整数) の形に整理していない」になります。
- できあがると、説明の全文が緑のわくで出て、左の一覧に ✅ がつきます。

### ④ 反例
- 左の一覧が「成り立つ？ 成り立たない？」に変わります。中央で数をためして、✖ が出るかさがします。
- 右で「いつも成り立つ」か「成り立たないことがある」をえらびます。
- 「成り立たないことがある」→ 反例の数を書いて「✔ 反例か たしかめる」。表に ✖ の組があれば「表の ✖ の組を使う」でも入れられます。成り立つ例や、条件にあわない数（奇数のところに偶数）をあげると、つまずき「反例になっていない例をあげた」になります。
- 「3つの偶数の和は偶数」は反例がなく、「いつも成り立つ」をえらぶと文字式の説明が出ます。

## ワークシート

- もんだい：「奇数＋奇数 は、いつも偶数になるだろうか？」
- ① 予想：いつも偶数／いつも奇数／偶数のときも奇数のときもある／わからない
- ② 操作：「2つの奇数の和は、偶数である」で数をためして「＋ 記録する」（いちばん新しい1組：ことがら・ためした計算・成り立つ？）。
- ④ まとめ：説明を自分で書く。先生モードでは模範解答が出ます。
- 保存キーは `ikechan-math-ためして 説明して 文字式`（つまずきの記録・できたことがらもこの中）。

## 授業での使い方の例（50分）

1. **予想（5分）**：「奇数＋奇数は？」ワークシートで予想と理由。
2. **実験（10分）**：① で「2つの奇数の和は、偶数である」。「🔟 10組ためす」「🐘 大きな数で」。おはじきの図で、あまりの1こどうしが組になることに注目。「これで、どんな奇数でも言える？」で話し合う。
3. **文字で表す（10分）**：② で表し方をえらぶ。2*m*＋1 と 2*m*＋1 をわざとえらんで、つまずきを見せるとよい（同じ数しか表せない）。スライダーで 2*m*＋1 がいろいろな奇数になることを確かめる。
4. **説明の組み立て（15分）**：③ でカードを並べ、穴うめ。2*m*＋2*n*＋2 のままではなく 2(*m*＋*n*＋1) にする理由を話す。早く終わった生徒は連続する3つの整数・2けたの整数へ。
5. **反例・まとめ（10分）**：④ で「2つの奇数の和は奇数？」の反例。ワークシートに説明を書く。

## 正しさについて（※じっさいとのちがい）

- 計算はすべて整数で、ふつうの数の計算で厳密に行います。穴うめの式は1次式として読み、式が等しいかどうかで判定します。
- おはじきの図は、数が大きいとき（合計 220 こより多い）や負の数のときは表示しません。
- 説明の文は教科書の書き方の一例です。ほかの書き方でも正しい説明はあります（ワークシートで自由に書けます）。
- 2けたの整数の実験では、入れかえた数が 1けたになる場合（10 → 01＝1）もふくめています（10*a*＋*b* で *b*＝0 のとき）。

## つまずき検知の一覧

| 型 | 見つけ方 | 例 |
|---|---|---|
| 🔤 別の数を、同じ文字で表した | ② の選択肢 | 2つの偶数を 2*m* と 2*m* |
| 1️⃣ 奇数を *n*＋1 と表した | ② の選択肢 | 2つの奇数を *m*＋1 と *n*＋1 |
| ⚖ 偶数・奇数の表し方のまちがい | ② の選択肢 | 偶数を *m* と表した |
| 🔗 「連続する」数の表し方のまちがい | ② の選択肢 | *n*, *m*, *k*／2*n*＋1, 2*n*＋2 |
| 🔟 2けたの整数を *ab* や *a*＋*b* と表した | ② の選択肢 | *ab* と *ba* |
| 🔀 結論を先に書いた | ③ の順番 | 「したがって〜」が最後でない |
| 📦 ○×(整数) の形に整理していない | ③ の穴うめ（式は等しいが、くくっていない） | 3*n*＋3 のまま |
| 🔢 数でためしただけで「ぜんぶ」と言った | ① の「言える？」で「言える」 | 10組ためして ✅ → 言える |
| 🔍 反例になっていない例をあげた | ④ で成り立つ例・条件にあわない数 | 1＋2＋3＝6（6の倍数）を反例にした |

つまずきは右の列に「あなたのつまずき」として出て、「▶ もどって見る」でそのパートにもどれます。回数は右下の「つまずきの記録」に残ります。
