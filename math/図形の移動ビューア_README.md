# 図形の移動ビューア（平行移動・対称移動・回転移動）

中学1年「平面図形」の図形の移動を、座標平面の上で動かして調べるアプリです。1つの移動で対応する点と座標のきまりを見つけ、3つの移動の性質をならべてくらべ、2つの移動を続けたら1回の移動にできるかを考え、最後に「どんな移動？」を逆向きに答えます。

## 使い方

### ① 1つの移動
- **平行移動**：右へ・上へ（スライダーと数、−10〜10）。対応する点を結ぶ矢印と「｜」の印。
- **対称移動**：軸は y軸・x軸・直線 x＝a・直線 y＝b・自由な直線（2点をドラッグ）。「🔃 うらがえす」で折るアニメ。直角の印と、軸までの長さの印。
- **回転移動**：角度（0〜360°、90°・180°（点対称移動）・270° のボタン）、反時計回り／時計回り。中心 O はドラッグ。中心からの円・まわした角の弧。
- 頂点 A・B・C はドラッグで動かせます（「すいつく」で整数／0.01 きざみ）。
- **📋 座標の変化**：移動前と移動後の座標、かわった座標に黄色の下線、いちばん下に**きまり**（(x＋4, y＋1)、(−x, y)、(x, −y)、(6 − x, y)、(−y, x)、(−x, −y)、直線 y＝x で (y, x) など）。「移動後の座標をかくす」で、予想してからタップして見られます。

### ② 3つをくらべる
同じ △ABC を、平行移動（左へ 6、下へ 3）・y軸で対称移動・原点中心に 90° の回転移動でならべます。三角形の中の矢印が「A→B→C のまわる向き」。頂点はどの平面でもドラッグでき、3つとも一緒に変わります。下の表で、対応する点を結ぶ線分・動かない点・図形の向き（うらがえるのは対称移動だけ）・座標のきまりをくらべます。

### ③ 2つの移動を続けて
1回目のあと △A′B′C′（灰色）、2回目のあと △A″B″C″（水色）。「▶ 1回目」「▶ 2回目」「▶ 続けて動かす」。そのあと「1回の移動で同じ結果にできる？」に、移動の種類と中身（または「1回ではできない」）で答えます。答えた移動で動かした図形が赤紫で重なるので、ずれ方を見て直せます。

| 組み合わせ | 1回の移動にすると |
|---|---|
| 平行 → 平行 | ずらす量をたした平行移動 |
| 対称 → 対称（軸が平行、x＝a と x＝b） | 軸の間の長さの2倍の平行移動 |
| 対称 → 対称（軸が交わる、x軸と原点を通る直線 ℓ。30°・45°・60°・90°） | 原点を中心に、軸の間の角の2倍の回転移動 |
| 回転 → 回転（同じ中心） | 角度をたした回転移動 |
| x軸で対称 → y軸で対称（ワークシート） | 原点中心 180° の回転移動（点対称移動） |
| 対称 → 軸にそって平行 | 1回ではできない |
| 平行 → 回転（**発展**） | 中心をうつした回転移動（中心は AA″ と BB″ の垂直二等分線の交点） |

### ④ どんな移動？
移動前と移動後の三角形を見て、移動の種類（平行・対称・回転）と、ずらす量／軸（x軸・y軸・x＝□・y＝□・y＝x・y＝−x）／中心と角度・向きを答えます。三角形は3辺の長さがちがい、座標は整数、回転は 90°・180°・270° で作ります。正解すると、移動のようすを動かして見せます。
- 💡 ヒント：1回目＝A→B→C のまわる向きの矢印、2回目＝対応する点を結ぶ線、3回目＝平行移動ならずらす量の数え方、対称移動なら中点と垂直な直線、回転移動なら AA′・BB′ の垂直二等分線。

ボタン：🎲 新しい問題（④）／▶ もう一度動かす／↶ ひとつもどす（①②③）／⟲ もういちど／💡 ヒント（③④）／📄 ワークシートの問題（③ の「x軸で対称 → y軸で対称」を開く）

## 授業での使い方（例）

- **1時間目**：① で3つの移動を1つずつ動かし、「見つけよう！移動のきまり」を確認。表の「かくす」で座標を予想させる。② で3つをならべ、表に性質を整理する。
- **2時間目**：ワークシートの予想「x軸で対称移動したあと y軸で対称移動すると？」→ ③ で確かめ、表を記録 → 原点中心 180° の回転移動と同じ。ほかの組み合わせ（軸が平行・軸が交わる・1回ではできない）も試す。
- **練習**：④ どんな移動？ を5問。つまずきが出たら「🔁 この型を練習」。

## つまずき検知の一覧

| 型 | どこで見つけるか | 練習するモード |
|---|---|---|
| うらがえるかどうかの見落とし（対称移動と回転・平行移動の取りちがえ） | 向きが反対になる移動（対称）と、向きが同じ移動（平行・回転）を取りちがえた | ④（対称移動の問題） |
| 回転の向きの取りちがえ | 中心は合っていて、角度が反対向き（反時計回り 90° と 時計回り 90° など） | ④（回転移動の問題） |
| 回転の中心の取りちがえ | 角度は合っていて、中心がちがう | ④（回転移動の問題） |
| 対称の軸の位置のずれ | 軸の向きは合っていて、位置がちがう（x＝2 を x＝4 にした など） | ④（対称移動の問題） |
| 平行移動の向き（符号）の取りちがえ | ずらす量の符号が反対・x と y の入れかえ | ④（平行移動の問題） |
| 対応する頂点の取りちがえ | 形は重なるのに、A・B・C の対応がずれている | ④ |
| 2回の対称移動で「2倍」を忘れた | ③ で、軸の間の長さ・角をそのまま答えた | ③（軸が平行） |
| 1回ではできない組み合わせ | ③ の「対称 → 軸にそって平行」で、1回の移動を答えた | ③（対称 → 平行） |

「🔎 あなたのつまずき」に、この時間に出た型と説明が出ます。「🔁 この型を練習」で、その型の問題へ移ります（④ はその種類の移動が出ます）。
記録は、この端末の localStorage（キー `ikechan-math-図形の移動ビューア`、ワークシートと同じ）に入ります：つまずきの型ごとの回数・③④ の正解の数・ヒントの回数。先生モードで合計を見たり消したりできます。

## 正しさとじっさいとのちがい

- 座標は分数（Fraction）で厳密に計算しています。回転が 90° の倍数でないとき、軸が 30° などの直線のとき、分母が 12 より大きい分数のときは、小数第1位の「約」で出します。
- 長さは、整数でないとき「約」で出します（√ は中3 で学ぶため）。
- 答えの判定は、答えた移動で動かした3つの頂点が、目あての頂点とすべて重なるか（誤差 0.000001）で見ます。べつの言い方でも、同じ結果になる移動なら正解です（反時計回り 270° と時計回り 90° など）。
- ③ の「平行 → 回転」は、回転の中心を作図（垂直二等分線）で見つけるので「発展」としています。

## 先生がかえやすいところ

- 2つの移動の組み合わせ：`PRESETS`（1回目・2回目・1回でできる移動・理由・座標のきまり）。
- ② の3つの移動：`CMP_T`。④ の問題の作り方：`gen4`。
- つまずきの型：`TRIPS` に名前・説明・練習するモードを書きます。
