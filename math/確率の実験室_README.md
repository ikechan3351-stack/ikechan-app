# 確率の実験室（多数回の試行と確率）

コイン・サイコロ・袋の玉・くじ・びんのふたを、1回から10万回まで投げたり引いたりして、**実験の回数をふやすと相対度数が理論上の確率に近づく**こと（大数の法則）を、いろいろな場面で体験するアプリです。「確率は1回の結果を予言するものではない」「続いても次の確率は変わらない（ギャンブラーの誤り）」もあつかいます。

## 今ある教材との役割分担

| 教材 | 役割 |
|---|---|
| サイコロ1万回ふってみた（`サイコロ1万回ふってみた.html`） | サイコロ1つで、相対度数が 1/6 に近づくのを見る（そのまま残す） |
| **確率の実験室（これ）** | いろいろな実験で同じことを確かめ、一般化する。少ない回数のばらつき・クラスの合算・理論でわからない確率（びんのふた）・ギャンブラーの誤り。つまずき検知・ワークシートつき |
| 樹形図で確率（`樹形図で確率.html`） | 場合の数を数えて確率を求める |

## 基本情報

- **ファイル**：本体 `確率の実験室.html`、共通部品 `worksheet.js`・`worksheet.css`・`math-render.js`。ネット接続・外部ライブラリは不要です。
- **画面**：横向きタブレット（1024×768）では 左＝実験・右＝グラフと表 の2列。スマホは たて1列。
- **色のきまり**：★ 注目する結果・今の実験＝オレンジ（★・太い線・●）、理論の確率＝緑の点線、前の実験＝灰色の細い点線、まちがい＝赤紫の「×」、正解＝緑の「✓」。色だけでなく、記号・線の種類でも区別しています。
- **URL の設定**
  - `?teacher=1` … 先生モード（答え・自動で1ステップ・発問の例・びんのふたの値・この端末のきろく）
  - `?seed=1234` … 種（実験番号）を決めて開く（クラス全員で同じ実験をするとき）
  - `?part=1〜4` … はじめに開くパート
  - `?ws=1` … ワークシートをひらいて開く

## 使い方

### 実験の種類（①〜③ で共通）
- 🪙 コイン／🎲 サイコロ1個／🎲🎲 2個の和／🔴 袋の玉（赤・白・青を 0〜10 個。取り出したらもどす）／🎫 くじ（2〜30本、当たりの本数を決める。引いたらもどす）／🍶 びんのふた（王冠・プラスチック。理論では確率がわからない）
- 「★ 注目する結果」（表・1の目・和7・赤玉・当たり・上向きなど）を選ぶと、グラフや表はその結果の相対度数になります。結果の表の行をタップしてもかえられます。

### ① 実験する
1. 「1回」「10回」「100回」「1000回」「▶ 連続」で実験します（1つの実験は 10万回まで）。1回・10回は絵が動きます。
2. 右のグラフは ★ の相対度数の折れ線（縦軸 0〜1）。「📏 理論の確率の線」で緑の点線を出す・消す。「↔ 横の目もり」を「10倍ずつ」にすると、はじめの少ない回数のばらつきも広げて見られます。グラフをさわると、その回数までの相対度数が読めます。
3. 「⟲ もういちど」は新しい種ではじめから。前の実験は灰色の点線でのこり（6本まで）、くらべられます。「🔁 同じ種で再現」は同じ種ではじめから。同じボタンを押すと、まったく同じ結果になります。
4. 「確率どおりなら ○回 → 回数のずれ／相対度数のずれ」で、回数のずれは大きくなっても相対度数のずれは小さくなることが見えます。「🔢 回数と ★ の相対度数」の表は 10・50・100・500・1000 … 回のときの値です。

### ② ばらつきをくらべる
- 予想（ちらばりが大きいのは 10回？ 1000回？）をえらび、10回・100回・1000回の実験を「＋1人」「＋10人」でふやします。1つの点が1人分の相対度数（ドットプロット）。オレンジの点線のわくが範囲です。
- 表に 最小・最大・範囲（ちらばり）・確率との差が 0.05 以下の人の数。10回と1000回が10人以上そろうと、気づきが出ます。

### ③ クラスで合算
- ①で実験 →「👥 合算に入れる」→「⟲ もういちど」… をくり返すと、1台で何人分でも積み上がります。
- 「🤖 自動で1人分」（10・50・100・1000回）、「✍ 数で入れる」（ほかのタブレットや本物のコインの結果）。
- グラフは 1人ずつの ◆ と、そこまでの合算の線。合算のデータは実験と ★ ごとにこの端末に保存されます（300人分まで）。

### ④ 次はどっち？
- 「表が k 回続いたあとの1回」を、1000〜10万回の中から数えます。続いたあとでも表の割合は 0.5 くらいのまま。
- クイズ 13問（ギャンブラーの誤り・必ず起こる？・少ない回数・回数のずれ・同様に確からしくない場合など）。

### 共通
- 「↶ ひとつもどす」「⟲ もういちど」「📄 ワークシートの問題」。

## 授業例（1時間）

1. 予想：「コインを10回投げると、表は5回？ 1000回では？」をワークシートに。
2. ① のコインで、数人が「10回」→ 相対度数を板書（0.3〜0.7 とばらつく）。続けて「1000回」を板書（0.5 の近く）。
3. ② で 30人分を一度に見せ、範囲をくらべる。
4. ③ でクラスの結果を合算。種を黒板に書いて全員で同じ実験をすると、同じ結果になることも確かめられる。
5. びんのふたで「理論でわからないときは、多数回の実験の相対度数を確率と考える」。
6. ④ で「次の1回」を考え、まとめを書く。

## 正しさのちがい（※じっさいとのちがい）

- 結果はコンピューターの計算（乱数）です。種（4けたの実験番号）は Math.random で決め、i 回目の結果は「種と i」から計算で決めています（同じ種なら同じ結果になるため）。乱数のかたよりは 60万回の実験と「表のあとに表が出る割合」で確かめました。
- コイン・サイコロ・玉・くじは、どの結果も同じ程度に起こるものとしています。
- びんのふたが上向きになる割合は架空の値です（王冠 0.42、プラスチック 0.63。先生モードだけ表示）。
- 相対度数は小数第3位まで四捨五入して表示しています（計算は整数で行うので、表示のずれはありません）。理論の確率は分数で表示します。
- 学習指導要領では、多数回の試行による確率は中1「データの活用」、場合の数による確率は中2 です。この教材は両方の学年で使えます。

## つまずき検知の一覧

| 型 | どこで見つける | 練習・確かめ |
|---|---|---|
| ギャンブラーの誤り（続いたから、次は反対が出やすい） | ④ のクイズ | ④ で表が5回続いたあとを10万回から調べる |
| 「流れ」があると考えた（続いたから、次も同じ） | ④ のクイズ | 同上 |
| 確率を「必ずその回数だけ起こる」と考えた | ④ のクイズ | ① でサイコロを6回 |
| 少ない回数の結果で確率を決めた | ④ のクイズ | ① でコインを10回 |
| 回数のずれと相対度数を取りちがえた | ④ のクイズ | ① でコインを1万回、ずれの行を見る |
| 回数をふやしても、ばらつきは同じと考えた | ② の予想・④ のクイズ | ② で 30人分ずつ |
| 同じ程度に起こらない結果を同じとして数えた | ④ のクイズ | ① でサイコロ2個の和を 3600回 |

「🔁 この型を練習」でその型が出るクイズだけを出し、「👀 実験で確かめる」でその型が見える実験を開きます。記録はこの端末に保存されます（`ikechan-math-確率の実験室`）。

## 改造のしかた

- 実験をふやす：`EXPS` に1つ足す（`outs` に結果と理論の確率、`gen` に i 回目の結果）。設定があるときは `expKey`・`expLabel`・`settingsHTML` にも足す。
- クイズをふやす：`QUIZ` に1行足す（`ch` の2つめが まちがえたときの型。正解は `null`）。
- びんのふたの値：`CAPS`。
