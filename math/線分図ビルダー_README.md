# 線分図ビルダー（文章題を線分図にして、方程式を立てる）

中学1年「一次方程式の利用」で、文章題の数量の関係を**線分図**に表し、「同じ長さ」から方程式を立てて解くアプリです。
棒（線分）を自分でならべ、長さを表す式を書きます。上の段と下の段の右はしがそろえば、それが方程式になります。最後に、方程式の解が**問題に合うか**（人数が小数・負の数になっていないか、範囲をこえていないか）をたしかめます。

## 基本情報

- **ファイル**：本体 `線分図ビルダー.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中1）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチでドラッグ）・パソコン・スマホ（たてにならびます）。
- **画面**：広い画面では 左＝問題、中央＝線分図、右＝式と答え の3列。タブレット横向きでは 左＝問題・右＝線分図、その下に式と答えが横にならびます。
- **色のきまり**：たす棒（＋）＝オレンジ・実線、ひく棒（−、たりない など）＝青・点線、正解＝緑の「○」、まちがい＝赤紫の「×」。長さが負になる棒は、赤紫のしま模様。
- **URL の設定**
  - `?teacher=1` … 先生モード（つぎの問題を「合う／合わない」で選べる・図の自動組み立て・最後まで自動・答え・この端末のきろく・ワークシートのヒントと解答例）
  - `?ws=0` … ワークシートをとじて開く

## 使い方

1. 上のチップで問題の型を選びます（🎲 新しい問題 で数がかわります）。
2. **① 何を x にする？**：問題ごとに2〜3通りの x の置き方が出ます（例：子どもの人数／あめの全部の数）。どれを選んでも立式できます。
3. **② 線分図をつくろう**：たなの部品を段（上の段・下の段）にドラッグします。
   - **＋ たす棒**・**− ひく棒**：置くとまどが開くので、長さを表す式を書きます（`x`、`3x`、`120`、`80(15-x)`、`(x-5)/3`、`x/60`、`0.2x`、`2/3x` など。キーボタンでも入力可）。たす棒／ひく棒は、まどの中でも切りかえられます。
   - **目もり**：棒の上にドラッグすると、棒を等分する線が入ります（比や「〜倍」に便利）。
   - **ふきだし**：棒の上にドラッグして、ことば（りんごの代金、あまり など）を付けます。
   - 置いた棒は、タップで直す、ドラッグで並べかえ・別の段へ、🗑 にドラッグで消す。たなの棒をタップすると、えらんでいる段（見出しをタップで切りかえ）の最後に入ります。
   - 棒の長さは本当の答えで描くので、式が合っていると上下の右はし（▼）がそろいます。
4. **③ 方程式**：「⇔ 上と下は同じ長さ → 方程式にする」で、上の段＝下の段 の方程式ができます。同じ意味の方程式なら、形がちがっても正解（例 3x＋5＝4x−4 と 4x−4＝3x＋5）。
5. **④ 解く**：x の値を入れて「たしかめる」（分数 7/2、小数 3.5、負の数 −2 も入力できます）。まちがえると、その値を代入した左辺・右辺の値が出ます。「📝 解き方を見る」で、整理 → 移項してまとめる → 係数でわる の式が出ます。
6. **⑤ 答えは問題に合う？**：x から求めた量（人数・個数・追いつく地点 など）を見て、「合う」か「合わない（小数・分数／負の数／範囲をこえた）」を選びます。
7. **⑥ 答え**：合う問題は答えの文、合わない問題は「この問題に合う答えはない」と理由が出ます。

ボタン：🎲 新しい問題／↶ ひとつもどす（棒を置く・直す・方程式・解く・判定、どれでももどせる）／⟲ もういちど（同じ問題をはじめから）／💡 ヒント（3段階）／📄 ワークシートの問題

### ヒント（3段階）

1. **図の形**：上の段・下の段がそれぞれ何を表すかと、棒の数・たす／ひく・目もりを、式を「？」にした図で見せる。
2. **関係**：ことばの式（例「3こずつ配った数 ＋ あまり ＝ 4こずつ配るのに必要な数 − たりない数」）。
3. **式**：方程式そのもの。

## 問題の型（どれも「合う問題」と「合わない問題」の両方が出ます）

答えを先に決めてから数を作っています。型ごとに「合う」「合わない」が袋から交互に（順番はランダムで）出るので、2問続けると必ず両方に出会います。先生モードでは、つぎの問題を「合う／合わない」で選べます。

| 型 | 問題の例 | x の置き方 | 合わない問題 |
|---|---|---|---|
| ① 代金・個数 | 1こ120円のりんごと80円のみかんを、あわせて15こ買って1500円 | りんごの数／みかんの数 | 個数が ○.5こ になる・片方が負の個数（あわせた数をこえる） |
| ② 過不足（配る） | 1人3こずつだと5こあまり、4こずつだと4こたりない | 子どもの人数／あめの全部の数 | 人数が小数（3.5人 など） |
| ③ 速さ・時間・道のり | 弟が分速60mで出発、8分後に兄が分速80mで追いかける。駅まで1.8km | 兄が歩いた時間／弟が歩いた時間／追いつく地点までの道のり | 追いつく地点が駅をこえる（範囲外） |
| ④ 割合（〜割引） | 定価の2割引で960円 | 定価／引かれた金額 | 定価が 1212.5円 のように1円未満になる |
| ⑤ 比例配分 | 60まいを 兄：弟＝3：2 に分ける | 比の「1」にあたる数／兄のまい数 | まい数が小数（カードは切らない） |
| ⑥ 年れい算 | 父42才・子6才。父が子の4倍になるのは何年後 | 何年後／そのときの子の年れい | 何年後が負（「2年前」なら合うが、「何年後」の答えとしては合わない） |

## 授業での使い方（例）

- **導入（5分）**：ワークシートの予想「x に何をおくと立式しやすい？」を挙手で集める。
- **展開（20分）**：「📄 ワークシートの問題」（あめを配る問題）で、x を「人数」にした線分図（3x＋5＝4x−4）と、「あめの数」にした線分図（(x−5)/3＝(x+4)/4）の両方をつくらせ、式の簡単さを比べる。先生モードの「▶ 図を自動で組み立てる」で、線分図を1本ずつ見せながら発問する。
- **練習（15分）**：各自で①〜⑥の型。合わない問題では「なぜ合わないか」を隣どうしで説明させる。「🔎 あなたのつまずき」に出た型の「🔁 この型の類題」で練習。
- **まとめ（5分）**：ワークシートの④に「線分図の上と下は同じ量を2通りに表している → ＝で結ぶと方程式」「解が問題に合うかを必ずたしかめる」を書く。

## つまずき検知の一覧

方程式は「A x ＝ B」の形にして比べるので、どんな書き方でも同じ意味なら同じ式と判定します。まちがいの式は問題ごとに登録してあり、同じ意味の式を作ったときに型の名前が出ます。

| 型 | どこで見つけるか | おもな問題 |
|---|---|---|
| あまり・たりないの符号 | 3x−5＝4x＋4、3x＋5＝4x＋4 など | ② |
| 残りの個数の表し方 | 120x＋80x＝1500、120x＋80(x−15)＝1500 など | ① |
| ちがう種類の量をまぜた | x が消えてしまう式（個数＝代金 など） | ①・ほか |
| 先に進んだ分を入れわすれ | 80x＝60x（弟が先に出た分がない） | ③ |
| 時間のたし・ひきが逆 | 80x＝60(x−8) など | ③ |
| 時間と道のりをたした | 80x＝60x＋8 | ③ |
| 引かれた金額を代金にした | 0.2x＝960 | ④ |
| 割を「0.○円」や「○円」にした | x−0.2＝960、x−2＝960 | ④ |
| 割引なのにたした | x＋0.2x＝960 | ④ |
| 比の一方を全体にした | 3x＝60 | ⑤ |
| 比の数をそのまま使った | x＋2x＝60、x＋2＝60 | ⑤ |
| 片方だけに年数をたした | 42＋x＝24、42＝4(6＋x) | ⑥ |
| かっこのつけわすれ | 42＋x＝24＋x | ⑥ |
| x にしたものとちがう式 | 別の x の置き方のときの正しい式を作った | すべて |
| 図の長さがそろっていない | 上のどれにもあてはまらず、右はしがずれている | すべて |
| 方程式の計算のまちがい | ④ で解をまちがえた | すべて |
| 合わない答えを「合う」とした | ⑤ で、合わない問題に「合う」 | すべて |
| 合う答えを「合わない」とした | ⑤ で、合う問題に「合わない」 | すべて |
| 合わない理由のとりちがえ | ⑤ で、理由がちがう（小数なのに「範囲をこえた」など） | すべて |

つまずきは「🔎 あなたのつまずき」に回数と説明が出て、「🔁 この型の類題」（同じ問題の型の新しい問題）と「↩ 図にもどる」ボタンがあります。記録はワークシートと同じ保存キー（`ikechan-math-線分図ビルダー`）の appData に入ります。

## ワークシート

- **問い**：文章題で方程式を立てるとき、x に何をおくと立式しやすいだろうか？
- **予想**：たずねられているものを x にする／ほかの数量（1つ分・全体など）を x にする／どちらでも同じくらい／わからない
- **記録**（⑤ まで進むと「＋ 記録する」）：問題の型・x にしたもの・方程式・解・問題に合う？

## 正しさについて（じっさいとのちがい）

- 計算はすべて分数（Fraction）で厳密に行い、見せるときだけ小数にしています。
- 棒の長さは、本当の答えを x に入れたときの長さで描いています（式がまちがっていると右はしがずれるので、それが手がかりになります）。じっさいのノートの線分図は、だいたいの長さでかまいません。
- 一次式だけを扱います（x×x、x でわる式は入力できません）。
- 速さの問題は「弟は駅に着いたら止まる」として、追いつく地点が駅をこえたら「合わない」としています。
- 人名・品物・ねだんは架空のものです。
