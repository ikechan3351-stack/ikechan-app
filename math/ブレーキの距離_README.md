# ブレーキの距離（関数 y＝ax² の利用）

中学3年「関数 y＝ax²」の利用で、**身のまわりの y＝ax²**（車のブレーキの制動距離・ボールの落下・円の面積・風圧）を、表・グラフ・式で予測するアプリです。
「**速さが2倍になると、止まるまでの距離は4倍**」を実験で見つけ、交通安全につなげます。

## 基本情報

- **ファイル**：本体 `ブレーキの距離.html`、共通部品 `graph-engine.js`（座標平面・グラフ）、`math-render.js`（式の表示・分数）、`worksheet.js`・`worksheet.css`（ワークシート）。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3・割合・関数）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）・スマホ。広い画面では「ようす｜グラフ」の2列、せまい画面では縦に並びます。
- **記録**：この端末の localStorage（保存キー `ikechan-math-ブレーキの距離`）に、ワークシートといっしょに入れます。
- **URL の設定**：`?teacher=1` … 先生モード、`?part=1〜4` … そのパートから始める、`?ws=1`／`?ws=0` … ワークシートをひらいて／とじて始める

## この教材の数（目安）

| 量 | 式 | 備考 |
|---|---|---|
| 制動距離（ブレーキがきいてから止まるまで） | y＝ax²（x：時速 km、y：m） | a＝かわいた道路 1/200、ぬれた道路 1/100、雪の道路 1/50 |
| 空走距離（気づいてからブレーキがきくまで） | y＝(5/24)x | 0.75 秒として計算（時速 x km は 秒速 x/3.6 m） |
| 停止距離 | 空走距離＋制動距離 | |
| 落下距離 | y＝4.9x²（x：秒、y：m） | 空気の抵抗は考えない |
| 風圧（発展） | y＝0.6x²（x：風速 m/秒、y：N/m²） | |

※ 係数は目安で、教材用に単純化しています（じっさいはタイヤ・車の重さ・道路のようすで変わります）。画面の「※じっさいとのちがい」にも書いています。

## パート

| パート | すること |
|---|---|
| ① ブレーキ | 路面と時速（10〜100km）を決めて「🛑 ブレーキ！」。上から見た道路で車が止まり、止まるまでの距離が物差しでわかる。「📌 記録する」で表とグラフの点がふえる。「〰 放物線を重ねる」で、点が y＝ax² にのることを確認。2倍の組（30 と 60 など）ができると「何倍？」、そのあと a を求める。 |
| ② 安全な距離 | 路面・時速・歩行者までの距離（15〜45m）をえらび、停止距離（空走＋制動）を計算して入れる。正解すると、止まれるかどうか・その道路で止まれる時速の上限・かわいた道路と雨の日のくらべが出て、アニメでたしかめられる。グラフは空走距離（比例）・制動距離（y＝ax²）・停止距離の3本。 |
| ③ 落下 | ビルの高さ（4.9m・19.6m・44.1m・78.4m・122.5m・30m）から落としたボールが地面に着くまでの時間を求める。「⬇ 落とす」でアニメ。1秒ごとの位置つき。答えが √ になるときは、簡単な形（10√3/7 など）と小数で表示。 |
| ④ そのほか | 円の面積 S＝πr²・正方形の面積 y＝x²・風圧 y＝0.6x²（発展）。x を 2倍・3倍にすると y は何倍？（4択） |

## 授業での使い方（例）

- **導入（ワークシート）**：「時速が2倍になると、止まる距離は？」と予想させる（2倍が多い）。① の「📄 ワークシートの問題（30 と 60）」か、自分でブレーキをかけて記録し、4倍になることを確かめる。
- **グラフ**：記録の点に放物線を重ねて、y＝ax² で表せることを見る。a を求め、「すべりやすさ」であることをまとめる。
- **安全**：② で雨の日・雪の日、歩行者の飛び出しを考える。「速さを半分にすると制動距離は 1/4」「雨の日はもっとゆっくり」「車はすぐには止まれない」を話し合う。
- **ひろげる**：③ の落下、④ の円の面積・風圧で、いろいろな y＝ax² を見つける。

## 先生モード（`?teacher=1`）

- 答えの表示（a・距離・停止距離・時間・何倍）。
- 「★ 答え（先生）」：① は 30・40・50・60km の記録と放物線を一度に出す。②③④ は答えを入れて、たしかめまで進めます。
- この端末のつまずきの合計。ワークシートに、先生用のヒントと解答例が出ます。

## 正しさについて（じっさいとのちがい）

- 計算は分数で厳密に行い、見せるときだけ小数（第1位まで）にしています。答えは小数第1位まで合っていれば正解です。
- 係数は目安で、教材用に単純化しています（上の表）。
- 車のアニメは、ブレーキの間ずっと同じ割合でおそくなる（等加速度）として動かしています。
