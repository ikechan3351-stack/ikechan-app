# 平方根の数直線（正方形の1辺から、√ の位置と大きさを見る）

中学3年「平方根」のアプリです。
面積 *a* の正方形の1辺の長さ（√*a*）をコンパスで数直線にうつし、√2 を 10 等分ずつズームして「終わらない・くり返さない小数（無理数）」を体験します。
そのあと、2乗してくらべる大小くらべ、平方根の性質（±、√ は正の方、負の数の平方根はない）、有理数・無理数の仕分けへ進みます。
小学校の「数直線ツール」の見た目（数直線・目もり・ピン）を参考にしています。

## 基本情報

- **ファイル**：本体 `平方根の数直線.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3）から開けます。
- **URL の設定**
  - `?teacher=1` … 先生モード（① 2〜10 を自動で、② √ の位置をはじめから表示、③ 解き方の自動再生、④⑤ ★答えを見る、ワークシートのヒントと解答例）
  - `?part=1`〜`5` … はじめに開くパート
  - `?ws=0` … ワークシートをとじて開く
- **保存**：つまずきの記録とワークシートは localStorage（キー `ikechan-math-平方根の数直線`）。

## 使い方

### ① 正方形（1辺を数直線へ）
- 面積 1〜20 をスライダーか数の入力でえらぶと、面積がその数の正方形が出ます。
  - 2・5・8・10・13・17・18・20 は、方眼の点を結んで **かたむけて** かけます。「🔍 どうして面積が○？」で、外の大きな正方形 − 4つの直角三角形 の計算を見せます。
  - 1・4・9・16 は ふつうの正方形（1辺が整数）。3・6・7 などは方眼の点ではかけないので、計算で長さを決めた正方形です。
- 予想「どの整数の間？」をえらんでから、緑の点（コンパスの先）をドラッグして数直線まで回します（「🧭 コンパスで回す」でも動く）。数直線の近くまで来ると すいつきます。
- うつした √ は数直線に残り、右の表（面積・1辺・小数でおよそ）にたまります。

### ② ズーム
- √2・√3・√5・√7・√10（くらべる用に √4）。√ がある目もりの間をタップすると、その間が 10 等分されて広がります（1 → 1.4 → 1.41 → …）。
- まちがえた間をタップすると、2乗した数で理由を出します（例：1.5² ＝ 2.25 は 2 より大きい → √2 は 1.5 より左）。
- 「2乗を目もりの下に出す」（はじめの2回だけ。そのあとは長くなるので説明だけ）。
- 「⏩ 自動で 10回ズーム」：どこまで進めても終わらない・くり返さないことを見せます。右に わかった小数（5けたずつ区切り）と、はさまれる範囲の表（さいごの8回）。1/4（終わる）・1/7（くり返す）とくらべます。

### ③ 大小くらべ
- √5 と 2.3、3 と √8、√7 と √11 など。「負の数も」で −√5 と −2.3 なども出ます。
- ① 予想：√ の数の ▽ を数直線にドラッグ（「0.1 にすいつく」の切りかえ）→ ② ＜ ＝ ＞ をえらぶ → 「✔ 2乗してたしかめる」で、2乗した数のくらべと、本当の位置（緑の ▼）と予想のずれが出ます。

### ④ 性質
- **2乗の機械**：上の数直線の *x* を動かすと、*x* と −*x* の2つが同じ *x*² に行くのが矢印で見えます。「下から」にすると、*x*² をえらんで ±√ の2つをさがせます。負の数をえらぶと「2乗してここに来る数はない」。ドラッグと数の入力、整数にすいつく切りかえつき。
- **性質クイズ**（11 種類）：○○ の平方根・√○○・−√○○・√(−○○)・負の数の平方根・(√*b*)²・(−√*b*)²・√(*n*²)・√((−*n*)²)・0 の平方根・√0.○○。

### ⑤ 仕分け
- 8〜9 まいのカード（√9、0.333…、1.414、3.14、22/7、π、√10 など）を「有理数」「無理数」の箱へドラッグ（タップでえらんで箱をタップしても可。箱の中のカードをタップすると下にもどる）。
- 「✔ 答え合わせ」で ○✖ と、1まいずつのわけ（√9 ＝ 3 ＝ 3/1 など）。

### 共通
- どのパートにも「↶ ひとつもどす」「⟲ もういちど」。②③⑤ には べつの問題・カード。

## 授業例（50分）

1. （5分）ワークシートの予想「√2 は分数で表せる？」
2. （10分）① で面積 2・5・8 の正方形 → √2・√5・√8 を数直線へ。3・6・7 は「方眼ではかけない」。
3. （15分）② で √2 を 4 回ズーム → ⏩ で 20 回以上。1/7 とくらべ、無理数ということばを知る。ワークシートに記録。
4. （10分）③ 大小くらべ（正の数 → 負の数も）。
5. （10分）④ 性質クイズ → ⑤ 仕分け。まとめ。

## 正しさとじっさいとのちがい

- √*a* の小数は、BigInt の整数平方根で求めた「切り捨て」の値で、何けたでもずれません。大小くらべも、両方を2乗した数（100 倍した整数）でくらべています。
- 図の位置（正方形・ピン・▽）は画面の上での およその位置です。
- ③ の小数は小数第1位までです。④ のクイズの数は答えを先に決めてから作ります。同じ問題は続けて出ません。
- 「√2 が分数で表せない」ことの証明は高校の内容なので、アプリでは「どこまでズームしても終わらない・くり返さない」ことの体験にとどめています。

## つまずき検知の一覧

| 型 | どこで検出するか | 例 |
|---|---|---|
| ± √ に ± をつけた | ④ クイズ | √16 ＝ ±4 |
| 🚫 負の数の平方根を求めようとした | ④ クイズ | √(−4) ＝ 2、−4 の平方根は ±2 |
| ½ 平方根の負の方をわすれた | ④ クイズ | 16 の平方根は 4 |
| ÷ 2 でわった | ④ クイズ | √16 ＝ 8 |
| ↩ √((−5)²) を −5 とした | ④ クイズ | √((−5)²) ＝ −5 |
| ⚖ 2乗しないで √ の中の数とくらべた | ③ | √5 と 2.3 で 5 ＞ 2.3 だから √5 ＞ 2.3 |
| ↔ 負の数の大小を逆にした | ③（負の数も） | −√5 ＜ −2.3 |
| √ √ がつけば無理数と考えた | ⑤ | √9 を無理数に |
| 🔁 小数・くり返す小数を無理数とした | ⑤ | 1.414、0.333…、22/7 を無理数に |
| π π を有理数とした | ⑤ | π を有理数に |
| ❓ 無理数を有理数とした | ⑤ | √10 を有理数に |

- 「あなたのつまずき」に 型の名前・あなたの答え・直し方と、「🔁 この型を練習」（その型が出る問題・カード）、「👀 ○○で確かめる」（2乗の機械・ズーム・正方形・数直線）のボタンが出ます。
- 型ごとの回数は「つまずきの記録」にのこります（「記録を消す」で消せます）。
