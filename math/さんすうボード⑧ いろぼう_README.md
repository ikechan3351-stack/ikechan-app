# 🌈 さんすうボード⑧ いろぼう（キュイジネール棒）

1〜10の長さの色つきの棒（キュイジネール棒）を、子どもが指でならべて、**数の分け方・合わせ方・何倍・分数の大きさ**をくらべるボードです。決まった問題や正解はありません。

- 参考にしたもの：Brainingcamp「Cuisenaire Rods」の紹介ページと動画（1〜10の色の棒・のびる棒・数の表示の切りかえ〔整数・小数・分数・文字〕・マス目・めもり）。
- 棒の色は、キュイジネール棒の昔からの色に合わせています（1 白・2 赤・3 黄緑・4 むらさき・5 黄・6 こい緑・7 灰色・8 茶・9 青・10 オレンジ）。

## 基本情報

- **ファイル**：`さんすうボード⑧ いろぼう.html`。この1ファイルだけで動きます（ネット接続・外部ライブラリ・画像ファイルは不要）。
- **対応する機器**：タッチできる Chromebook・電子黒板・マウス。スマホのたて向きでも使えます。
- **外わく**（✋うごかす・✏️かく・ペンの色・せんをけす・もどる・やりなおす・しゃしん・かたづける）は さんすうボード①〜⑦ と同じです。

## さんすうセットから ひらいたとき

- **さんすうセット ていがくねん**（`?low=1`）：「0.1〜1」「もじ」「やくぶん」をかくします（1・2年で使わないため）。左上は「🏠 ボードえらび」になります。
- **算数セット 中高学年**（`?high=1`）：ぜんぶ使えます。左上は「🏠 ボードえらび」になります。
- ボードの ようすは、ふつうの ⑧・ていがくねん・中高学年 で べつべつに ほぞんされます。

## 棒の操作

| 操作 | どうなるか |
|---|---|
| 道具箱の棒を**引っぱる** | ボードに置ける。マス目に すいつく |
| 道具箱の棒を**タップ** | あいている場所に出る |
| ボードの棒を**タップ** | たて ⇄ よこ |
| ボードの棒を**長おし** | すぐ下（たてなら右）にコピー |
| 棒を**道具箱にもどす** | 消える |
| ピンクの「のびる ぼう」の **○** を引っぱる | 長さをかえる（1〜30） |
| 🪜 かいだん | 1〜10を かいだんの形に ならべる |

## 上のボタン

| ボタン | はたらき |
|---|---|
| ぼうの かず：なし／1〜10／0.1〜1／ぶんすう／もじ | 棒に書く数を切りかえる。道具箱の棒も同じに変わる |
| 「1」に する ぼう（ぶんすうのとき） | どの棒を1にするかえらぶ。たとえば 4の棒を1にすると、2の棒は 2/4、8の棒は 2 になる |
| やくぶん | 分数を約分して表す（5年）。切っていると 2/4 のまま |
| マスめ | ボードの方眼を出す・消す |
| めもり | 棒に1ずつの線を出す（いくつ分かを数えるとき） |

- もじ は 1〜10 を a〜j、のびる棒を x で表します（「a が 2つで b」「e＋e＝j」など、文字で関係を表すとき）。

## 授業での使い方の例

- **1年 いくつと いくつ**：10の棒（オレンジ）の下に、2本の棒をならべて ぴったりの組み合わせを全部さがす（1と9、2と8…）。
- **1・2年 たし算・ひき算**：3の棒と5の棒をつなげて、同じ長さの棒をさがす。ちがいは「何の棒がうまるか」で見る。
- **2年 かけ算**：2の棒を4本ならべて、8の棒と同じ長さになることを見る（何こ分）。
- **2・3年 分数**：「1」にする棒をえらび、半分・4つに分けた1つ分を棒で見つける。
- **4年 小数**：0.1〜1 にして、10の棒を1とみたときの 0.3＋0.5 など。
- **5年 分数の大きさ・約分**：10の棒を1にして、5の棒（5/10）と 2の棒2本分の関係や、やくぶん を入れたときの 1/2 を くらべる。
- **3〜6年 何倍**：「ある棒の何倍がこの棒か」を、のびる棒やならべた棒で考える。
