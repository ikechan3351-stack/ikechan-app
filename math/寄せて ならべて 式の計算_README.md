# 寄せて ならべて 式の計算（タイルと面積図で、中2の式の計算を見える化）

中学2年「式の計算」で、項を**タイル**にして、多項式の加減・単項式の乗除・多項式と数の乗除を目で見て確かめるアプリです。
(3*x*²＋2*x*−1)＋(*x*²−5*x*＋4) で *x*² と *x* がまとめられないこと、(2*a*＋3*b*)−(*a*−4*b*) で −4*b* が ＋4*b* になること、3*a*×2*b* が「たて 3*a*・横 2*b* の長方形」で 6*ab* になること、(6*x*＋9)÷3 で**すべての項**をわることを、タイルを動かして確かめます。
中1「同類項タイル」と同じタイル・同じ操作の流れにしてあります。

## 基本情報

- **ファイル**：本体 `寄せて ならべて 式の計算.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中2）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）・スマホ。
- **タイルの形**
  - 1＝**小さい正方形**、*x*＝**長い棒**、*y*（2つめの文字）＝**中くらいの棒＋しま模様**
  - *x*²＝**大きい正方形**（*x*×*x*）、*xy*＝**長方形＋ななめのしま**（*x*×*y*）、*y*²＝**中くらいの正方形＋しま模様**
  - 正の項＝**オレンジ・実線のふち**、負の項＝**青・点線のふち＋「−」**。色だけでなく、形・線の種類・模様・文字でも見分けられます。ひっくり返したタイルには「↺」の印がつきます。
- **画面のならび**：左に「タイルの置き場」（② は「長方形の面積」）、右に「式の変化」と「答えの式を書こう」（せまい画面では 式 → タイル → 答え の順）。
- **URL の設定**
  - `?teacher=1` … 先生モード（手順の自動再生・★答えを見る・ワークシートのヒントと解答例）
  - `?mode=add`・`mono`・`dist`・`free` … はじめに開くタブ
  - `?ws=0` … ワークシートをとじて開く

## 使い方

右の「式の変化」には、操作のたびに `=` でつないだ式が1行ずつ増えます。最後の行は「？」になり、生徒がタイルを見て答えの式を書きます。

### ① 多項式の加減
- 「ためしてみよう」：(3*x*²＋2*x*−1)＋(*x*²−5*x*＋4)、(2*a*＋3*b*)−(*a*−4*b*)、(5*x*²−3*x*)−(2*x*²＋*x*−4)、(2*xy*＋3*x*)−(*xy*−*x*)、4*x*²＋2*x*−3*x*²−5*x*、(*a*＋2*b*−3)−(2*a*−*b*＋1)。「🎲 べつの問題」で新しい問題が出ます。
- ひき算は「🔄 −( ) の中をぜんぶひっくり返す」（タイルを1枚ずつタップしてもよい）→「✂ かっこをはずす」。一部だけ裏返したままはずそうとすると、つまずき「−( ) のうしろの符号を変え忘れた」になり、残ったタイルが光ります。
- 「🧲 同類項を寄せる」で、タイルが種類ごとの場所（*x*² の項・*x* の項・数の項…）に集まります。同じ種類のタイルは同じ形なので、＋の列と−の列のゼロ対がたてに並びます。
- ゼロ対は**タップ**（＋ → − の順に1枚ずつ）か**ドラッグ**（重ねる）で消えます。形のちがうタイル（*x*² と *x* など）を組にすると、つまずき「種類のちがう項をまとめた」になります。

### ② 単項式の乗除（長方形の面積）
- 「ためしてみよう」：3*a*×2*b*、2*x*×3*x*、(−4*x*)×5*y*、4×3*x*、6*ab*÷3*a*、8*x*²÷2*x*、(−12*xy*)÷4*y*、6*x*÷(−2)。
- − のついた単項式があるときは、先に「± 符号を決める」。− の個数が奇数なら −、偶数なら ＋ と符号カードに出ます。
- **かけ算**：「▦ しきつめる」で、たて 3*a*（*a* が 3 こ）・横 2*b*（*b* が 2 こ）の長方形にタイルがしきつまります。「🔢 タイルを数える」で「*ab* のタイルが 3×2＝6 枚」。2*x*×3*x* ではタイル1枚が *x*×*x* の正方形（*x*²）になります。
- **わり算**：わられる式のタイル（6*ab* なら *ab* のタイル 6 枚）を「▦ たて 3*a* にならべる」で長方形にならべ、「🔢 横の長さを読む」で 横＝2*b* がわかります。式の変化には、分数の形（6*ab*/3*a*）と約分（6×*a*×*b* / 3×*a*）が出ます。

### ③ 多項式と数
- 「ためしてみよう」：2(3*x*−1)、3(*x*²−2*x*＋1)、−2(*x*＋3)、4(*a*−2*b*)、(6*x*＋9)÷3、(8*a*−4*b*)÷4、(6*x*²−9*x*)÷(−3)。
- **× 数**：「📑 ○ 段に重ねる」で、かっこの中のタイルが**ぜんぶ** ○ 段に重なります（2(…) は (…) の 2 つ分）。「🔢 列ごとに数える」で、項ごとの合計が出ます。
- **÷ 数**：タイルを**タップ**すると、その項のタイルが 1組目 → 2組目 → … の順にくばられます。「🃏 のこりを ぜんぶ くばる」でもくばれます。「🔢 1組分を見る」で 1組分（答え）が光ります。
- 前の数（わる数）が − のときは、重ねた（くばった）あとに「🔄 ぜんぶひっくり返す」。ひっくり返さずに数えようとすると、注意が出ます。

### ④ じゆう
- 式を入れて「🧱 タイルにする」。式の形を見て、①②③ のどの見せ方にするかを自動で決めます。例：(2*a*＋3*b*)−(*a*−4*b*)、3(*x*＋2*y*)−2(*x*−*y*)、(−3*a*)×4*b*、18*xy*÷(−6*x*)、5(2*x*²−*x*)、(10*a*−15*b*)÷5。
- 書けるもの：整数の係数、文字 2 種類まで、2次まで（*x*² は `x^2`・`x²`・`xx` のどれでも可）。読めない式には理由が出ます（*x*(*x*＋1) や (…)(…) は中3、答えが分数になるわり算はあつかわない、など）。

### 答えの式を書く
- 下のキー（数字・文字・＋・−・²・⌫・C）か、キーボードで書いて「たしかめる」（Enter でも可）。`-` は自動で −、`^2` は ² になります。
- 値が合っていても、同類項が残っている・1*x* と書いた・*xx* と書いた・*ba* と書いた（アルファベット順でない）ときは、書き方のきまりを知らせます。
- タイルの操作をとちゅうまでしかしていなくても答えられます。正解すると、式の変化のいちばん下に答えが出ます。

### そのほか
- 「↶ ひとつもどす」：1つ前の操作にもどします。「⟲ もういちど」：同じ問題をはじめから。
- 「動くはやさ」：ゆっくり・はやい・アニメなし。
- 先生モード：「▶ 手順を自動再生」（いまのタブの手順をはじめから順に）、「★ 答えを見る」。

## ワークシート

- もんだい：「(2*a*＋3*b*)−(*a*−4*b*) は、どんな式になるだろうか？」
- ① 予想：*a*−*b*／*a*＋7*b*／3*a*＋7*b*／わからない
- ② 操作：答えの式を書いて正解したら「＋ 記録する」。式・答え・ふりかえり（「1回で正解」か、その問題で出たつまずきの名前）が表に入ります。
- ④ まとめ：ミスしやすいポイントを3つ（「−( ) をはずすときは〜」「÷ 数 のときは〜」「単項式のかけ算は〜」の形で）。
- 保存キーは `ikechan-math-寄せて ならべて 式の計算`（つまずきの記録もこの中）。

## 授業での使い方の例（50分）

1. **予想（5分）**：「(2*a*＋3*b*)−(*a*−4*b*) は？」ワークシートで予想と理由。*a*−*b* を選ぶ生徒が多ければ、そこが今日のポイント。
2. **多項式の加減（15分）**：① で (3*x*²＋2*x*−1)＋(*x*²−5*x*＋4)。寄せると *x*² と *x* が別の場所に集まる → まとめられないことを確認。続けて (2*a*＋3*b*)−(*a*−4*b*)。1枚だけ裏返して「かっこをはずす」を押すと、つまずきが出る（わざと見せるとよい）。
3. **単項式の乗除（15分）**：② で 3*a*×2*b* をしきつめて「6*ab*（5*ab* ではない）」。2*x*×3*x* でタイルが正方形 → *x*²。6*ab*÷3*a* はならべて横を読む → 2*b*。(−4*x*)×5*y* で符号カード。
4. **多項式と数（10分）**：③ で 2(3*x*−1) を 2 段に重ねる、(6*x*＋9)÷3 を 3 組にくばる。「2*x*＋9 ではない」ことを 1組分で確かめる。
5. **まとめ（5分）**：ミスしやすいポイントをことばで。

## 正しさについて（※じっさいとのちがい）

- 係数はすべて整数で、ふつうの数の計算で厳密に行います（小数は使いません）。
- タイルにできるのは 2次まで（*x*²・*xy*・*y*²）、文字は2種類までです。
- ② のかけ算は、たて・横 が文字1つまでの単項式（3*a*×2*b*、2*x*×3*x*、4×3*x* など）です。3つ以上の単項式の乗除、累乗（(−2*a*)² など）、2*x*²×3 のような式はあつかいません。
- ② のわり算・③ のわり算は、答えが整数係数の式になるものだけです（6*a*÷4 のように答えが分数になる式はあつかいません）。
- 負の長さは図にできないので、② の図は長さ（符号をとった大きさ）でかき、符号は「符号カード」で先に決めます。
- *x* や *y* のタイルの長さは決まっていません（文字はいろいろな数を表すので、1 のタイル何個分とは決められない）。
- 1つの種類のタイルは 24 枚まで（2次のタイルは 12 枚まで）です。

## つまずき検知の一覧

| 型 | 見つけ方 | 例 |
|---|---|---|
| 🔄 −( ) のうしろの符号を変え忘れた | ① で一部だけ裏返してかっこをはずそうとした／わなの答えと同じ | (2*a*＋3*b*)−(*a*−4*b*) → *a*−*b* |
| 🔃 前の数が − のとき、うしろの項の符号を変え忘れた | ③ で一部の項の符号だけが反対 | −2(*x*＋3) → −2*x*＋6、(6*x*−9)÷(−3) → −2*x*−3 |
| ✂ ÷ 数 で、うしろの項をわり忘れた | ③ でわっていない項がある | (6*x*＋9)÷3 → 2*x*＋9 |
| 📑 × 数 で、うしろの項にかけ忘れた | ③ でかけていない項がある | 2(3*x*−1) → 6*x*−1 |
| 🧱 種類のちがう項をまとめた | ① で形のちがうタイルを組にした／係数の合計は同じで項の種類がへった／3次の項を書いた | 3*x*²＋2*x* → 5*x*²、5*x*³ |
| ➕ 単項式のかけ算で、係数をたした | ② で係数が「たした数」 | 3*a*×2*b* → 5*ab* |
| ² *x*×*x* を *x*² にしていない | ② で同じ文字どうしのかけ算の答えが *x* のまま | 2*x*×3*x* → 6*x* |
| 🔤 単項式のわり算で、文字を約分していない | ② で答えの文字がわられる式のまま | 6*ab*÷3*a* → 2*ab* |
| ± かけ算・わり算の符号のまちがい | ② で答えの符号だけが反対 | (−4*x*)×5*y* → 20*xy* |
| ± 符号のまちがい | どこか1つの項の符号だけが反対 | 6*x*−2 → 6*x*＋2 |

どの型も「あなたのつまずき」として出て、「🔁 類題」（その型が出やすい問題）と「▶ タイルで見る」（手順の自動再生）にもどれます。回数は右下の「つまずきの記録」に残ります。
