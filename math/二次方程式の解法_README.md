# 二次方程式の解き方えらび（平方根・因数分解・解の公式）

中学3年「二次方程式」の3つの解き方（**平方根の考え・因数分解・解の公式**）を、「次の一手」のカードをえらびながら1ステップずつ練習するアプリです。
④では式を見て**どの解き方で解くか**をえらび、⑤ではほかの人の答えを**検算**して、まちがいを見つけます。
「どっちで解く？ 連立方程式」（2-04）と同じ形です。

## 基本情報

- **ファイル**：本体 `二次方程式の解法.html`、共通部品 `math-render.js`（式の表示・分数・√ の簡約）、`worksheet.js`・`worksheet.css`（ワークシート）。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）・スマホ。
- **記録**：この端末の localStorage（保存キー `ikechan-math-二次方程式の解法`）に、ワークシートといっしょに入れます（できた問題の数・まちがえたカードの数・ヒントの数・つまずきの回数）。
- **URL の設定**：`?teacher=1` … 先生モード、`?part=1〜5` … そのパートから始める、`?ws=1`／`?ws=0` … ワークシートをひらいて／とじて始める

## パート

| パート | レベル | 例 |
|---|---|---|
| ① 平方根 | x²＝k | x²＝7、x²＝12（→ ±2√3）、x²＝49 |
| | ax²＝k | 3x²＝21、2x²−18＝0、4x²＝9（→ ±3/2） |
| | (x＋p)²＝k | (x−3)²＝5（→ 3±√5）、(x＋2)²＝16（→ 2、−6） |
| ② 因数分解 | x²＋bx＋c＝0 | x²−5x＋6＝0 |
| | くふうする形 | x²−4x＝0、x²−9＝0、x²−6x＋9＝0（解は1つ）、x²＝4x |
| | 右辺が0でない・共通な数 | x²＋3x＝10、2x²−10x＋12＝0 |
| ③ 解の公式 | そのまま | 2x²−3x−1＝0 |
| | √を簡単に・約分 | x²−4x＋1＝0（→ 2±√3） |
| | √がはずれる | 2x²−5x＋2＝0（→ 2、1/2） |
| | 発展 解が1つ・ない | 4x²−12x＋9＝0、x²＋2x＋3＝0 |
| ④ えらぶ | いろいろな式 | ①〜③の式が、まざって出ます（解のない式は出ません） |
| ⑤ 検算 | この答え、正しい？ | 「x²＝81 の答えは x＝9」→ 代入して判定 |

## 使い方

1. 上のボタンでパートとレベルをえらびます。「🎲 新しい問題」で問題が変わります。
2. 「👇 次の一手はどれ？」のカードから、つぎにすることをえらびます。まちがったカードは赤紫の × と理由が出ます。
3. 変形するカード（移項・平方根をとる・因数分解・代入・約分 など）をえらぶと、**変形したあとの式を3択**でえらびます（下のチェックを外すと3択なしで進みます）。まちがえた選択肢は「あなたのつまずき」に記録されます。
4. 解が出たら**検算**。解をもとの式に代入して、左辺・右辺の値を入れ、「✔ たしかめる」。**どちらの解も**代入します。√ をふくむ解を ax²＋bx＋c に代入するときは「🧮 計算を見る」で計算が表示されます。
5. まちがえたら「↶ ひとつもどす」、はじめからは「⟲ もういちど」。「💡 ヒント」は1回目がことば、2回目は使えるカードが光ります。

### ② 数直線のカード（かけて0なら、どちらかが0）

因数分解して (x−2)(x−3)＝0 になると、数直線のカードが出ます。x の目印をドラッグ（または ◀▶・数値入力）すると、
**(x−2) の値・(x−3) の値・かけ算の答え**が出ます。正の数はオレンジ（＋）、負の数は青（点線のわく）、0 は緑（✓）です。
かけ算が 0 になった x には緑の ● が残ります。「整数にすいつく」を外すと 0.1 ずつ動きます。

### ③ 解の公式のカード（発展：解の個数の予告）

a・b・c を読みとると、「b²−4ac の値で解の個数を予告しよう」のボタン（解は2つ／1つ／ない）が出ます。
√ の中を計算すると、b²−4ac の値と「正 → 2つ、0 → 1つ、負 → ない」が表示され、予告の答え合わせができます。

### ④ えらぶ

はじめに「平方根の考え／因数分解／解の公式」から解き方をえらびます。

- 使えない方法（x の項があるのに平方根、因数分解できないのに因数分解）は × と理由が出ます。
- **使えるけれど楽ではない方法**（因数分解できるのに解の公式 など）は ○ で進めます。そのとき「でも、因数分解なら もっと楽」と、楽な方法とそのわけを紹介します。解き終わったあとにも、もう一度紹介します。
- 楽な方法の目安：x の項がない・(　)²＝数 → 平方根、かけて c・たして b の2数がある → 因数分解、どちらもだめ → 解の公式。

### ⑤ 検算

「Aさんの答え：x＝3」のような答えを、もとの式に代入してたしかめます。
左辺の値を入れると「成り立つ（解）／成り立たない（解ではない）」が出ます。さいごに、**正しい／解でない数がまじっている／解がたりない** から判定をえらびます。
答えのまちがいは、± わすれ・解の符号・x でわった・公式の分母を 2 にした・−b の符号・移項の符号 の型から作っています（正しい答えのときもあります）。

## 授業での使い方（例）

- **導入（ワークシート）**：「x²＝9 の解はいくつ？」と予想させてから「📄 ワークシートの問題」で解く。「x＝3 の1つ」という予想が多いので、検算で x＝−3 も成り立つことを確かめる。
- **①〜③**：解き方ごとに、まず先生モードの「▶ 最後まで自動で見せる」で流れを見せ、そのあと生徒が自分でカードをえらんで解く。② では数直線のカードで「かけて0なら、どちらかが0」を見せる。
- **④**：同じ式を ちがう方法で解かせて、手数（「○手」）をくらべる。「どの式なら、どの方法が楽か」をことばでまとめる。
- **⑤**：まとめや ふりかえりで。まちがいの理由を説明させる。
- **ふりかえり**：「🔎 あなたのつまずき」に出た型の「この型を練習」で、その型が出やすいレベルへ移れる。

## 先生モード（`?teacher=1`）

- 「▶ 最後まで自動で見せる」「⏭ つぎの1手」「■ とめる」：楽な方法で、3択・数直線・検算まで自動で進みます（④では楽な方法をえらびます）。
- 答えと楽な解き方の表示。⑤ では、その答えのつまずきの型も表示します。
- この端末のつまずきの合計と、きろくを消すボタン。
- ワークシートに、先生用のヒントと解答例が出ます。

## 正しさについて（じっさいとのちがい）

- 計算は分数と √（p＋q√r の形）で厳密に行っています。検算も同じ形で計算するので、小数の誤差はありません。
- 問題は**解を先に決めてから**式を作っています（①は x²＝k の k、②は2つの整数の解、③は a・b・c の範囲を決めて、解が √ をふくむ／ふくまない を選んでいます）。同じ問題は続けて出ません。
- 因数分解は、x² の係数が 1 の形（共通な数でわったあと）だけにしています（2x²−5x＋2＝(2x−1)(x−2) のような形は高校で習います）。
- 教科書では「平方根をとる」「移項する」などを1行で書くことも多いけれど、ここでは1手ずつに分けています。
- ① の 4x²＝9 のような分数の形は、分母が 2乗の数（4・9・16・25）のときだけ出しています（有理化が必要にならないように）。
- b²−4ac による解の個数（判別式）と「解はない」は**発展**です（画面に「発展」と表示）。「解はない」は、中学で習う数の中に解がないという意味です。
