# 平方完成タイル（発展）

中学3年「二次方程式」で、x²＋bx＋c＝0 を **(x＋p)²＝q の形**にして解く「平方完成」の意味を、面積図（タイル）で見る**発展**のアプリです。
x²＋bx を L 字の形にならべると、右下の角が欠けています。そこに **(b の半分)²** のタイルを足すと、(x＋b の半分)² の正方形になります。
この手順を文字で行うと**解の公式**になることも見られます。タイルの見た目は「乗法公式タイル」（3-01）とそろえています。

## 基本情報

- **ファイル**：本体 `平方完成タイル.html`、共通部品 `math-render.js`（式の表示・分数・√ の簡約）、`worksheet.js`・`worksheet.css`（ワークシート）。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）・スマホ。広い画面では「図｜式・操作」の2列、せまい画面では縦に並びます。
- **記録**：この端末の localStorage（保存キー `ikechan-math-平方完成タイル`）に、ワークシートといっしょに入れます（解けた数・まちがえた数・ヒントの数・つまずきの回数）。
- **URL の設定**：`?teacher=1` … 先生モード、`?part=1〜4` … そのパートから始める、`?ws=1`／`?ws=0` … ワークシートをひらいて／とじて始める

## パート

| パート | 内容 | 操作 |
|---|---|---|
| ① 足りない角 | x²＋bx（b＝2〜10 の偶数）に何を足すと正方形になる？ | 「▶ つぎへ」で x の棒を右と下に半分ずつならべる → 欠けた角をタップ（または ＋1・−1・数の入力）で 1 のタイルを置く → 「これで正方形？」 |
| ② 方程式をとく | x²＋6x＋4＝0 → x²＋6x＝−4 → 両辺に 9 → (x＋3)²＝5 → x＋3＝±√5 → x＝−3±√5 | 次の一手のカード ＋ 変形したあとの式の3択。問題は「b が正の偶数／負の偶数／奇数（分数）」 |
| ③ いろいろな b | b が奇数（x²＋5x → 足す数は 25/4）・負の数（x²−6x → 9） | b のスライダー（−9〜9）。まん中の1本を ✂ 半分に切って、右と下に1本ずつ。足す数を分数で入れる |
| ④ 解の公式へ（発展） | ax²＋bx＋c＝0 を、同じ手順で文字のまま平方完成 → x＝(−b±√(b²−4ac))/2a | 文字の列と、a・b・c に数を入れた列が同時に進む |

### 面積図の見方

- **x²**：大きい正方形（オレンジ）。**x**：長い棒（はば 1）。**1**：小さい正方形。
- x² ＋ 6x は、x の棒 6 本。右に 3 本・下に 3 本ならべると L 字になり、右下に たて 3・横 3 の角が欠ける → 9 を足すと (x＋3)² の正方形。
- b が奇数のときは、まん中の1本を たてに半分に切って（はば 1/2）、右と下に1本ずつ。角は 1・1/2・1/4 のタイルでうまる（x²＋5x なら 4＋1/2×4＋1/4＝25/4）。
- b が負のときは、x の棒は青い点線（−x）。タイルの符号は「たての符号 × 横の符号」なので、欠けた角は (−3)×(−3)＝＋9 でオレンジ（正）。
- ② では、図の下に「⚖ 左辺」「⚖ 右辺」が出ます。右辺の −4 と、足した ＋9 はゼロ対（✕）で打ち消しあって 5 になります。

## 授業での使い方（例）

- **導入（ワークシート）**：「x²＋8x に何を足すと正方形になる？」と予想させる（8・32 などが出やすい）。① の「📄 ワークシートの x²＋8x」で棒をならべ、欠けた角が 4×4＝16 であることを確かめる。
- **きまりを見つける**：① で b をいくつか変えて、「見つけた正方形」の表から「足す数＝(b の半分)²」に気づかせる。③ で奇数・負の数でも同じか確かめる。
- **方程式**：② で、面積図と式・天秤を見ながら1手ずつ解く。「両辺に足す」ことを天秤で確認する。
- **発展**：④ で、文字の手順と数の例をならべて見せ、解の公式がどこから出てくるかを説明する。「🪜 解の公式で解いてみる」から 3-07 へ。

## 先生モード（`?teacher=1`）

- 「▶ 自動で見せる（先生）」：① ③ は棒がならぶ → タイルが置かれる → 正方形、② ④ は正しいカードと3択を順にえらんで最後まで進みます（もう一度押すと止まります）。
- 答え（足す数・解・数の例の解）の表示、この端末のつまずきの合計。
- ワークシートに、先生用のヒントと解答例が出ます。

## 正しさについて（じっさいとのちがい）

- **発展**の教材です。教科書では平方完成は「二次方程式の解き方」や解の公式の説明の中で出てきます（画面とタイトルに「発展」と表示）。
- 計算は分数と √ で厳密に行っています。② の問題は (x＋p)²＝q の p・q を先に決めて作っています（奇数のときは b・c を決めて、b²−4c が正になるものだけ）。q が 2乗の数なら √ がはずれて、整数や分数の解になります。
- x の長さは決まっていません（図では 1 の何こ分でもない長さ）。負の数の長さは図にできないので、− の辺は青い点線のタイルで表しています。
- ④ の解の公式は a＞0 として説明しています（√(4a²)＝2a）。b²−4ac が負のときは「解はない」と表示します。
