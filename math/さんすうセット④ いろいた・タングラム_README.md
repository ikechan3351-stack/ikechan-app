# 🔷 さんすうセット④ いろいた・タングラム

小学1〜3年向けの、**色板（いろいた）とタングラムを画面で動かすボード**です。算数セットの色板の代わりに使えます。シルエット（「この かたちを つくろう」）を、ピースを回したり裏がえしたりしてうめます。

- 「さんすうセット①〜③」と同じつくりです。ペン・もどる・📷しゃしん・💾くばる・📂ひらく は ①〜③ と同じ使い方です。
- 企画メモ：脳メモ `教材開発/企画/2026-11-12_さんすうセット④ いろいた・タングラム.md`
- 単元（東京書籍）：1年「かたちづくり」、2年「三角形と四角形」（しきつめ）。タングラムは発展や、すきま時間に使います。
- ゲームの棚にある「図形パズルをつくってあそぼう」（`think/Tangram.html`）は、自由に遊ぶためのタングラムです。④は、授業で書きこんで提出するためのボードです。

## 基本情報

- **ファイル**：`さんすうセット④ いろいた・タングラム.html`。この1ファイルだけで動きます（ネット接続・外部ライブラリ・画像ファイルは不要）。
- **対応する機器**：タッチできる Chromebook（主に想定）、電子黒板、マウス・トラックパッド。
- **マルチタッチ**：指1本ずつ別々に追いかけるので、何人かで同時に動かせます。

## 2つのモード（道具箱のいちばん上）

| モード | 中身 |
|---|---|
| 📘 きょうかしょ 1ねん | 1年「かたちづくり」の色板（直角二等辺三角形）。いろいたボタンで1まいずつ出して、シルエットをうめる。8問＋じゆう |
| 📘 きょうかしょ 2ねん | 2年「三角形と四角形」。教科書のパズル（あ〜く）5問＋なかまわけ、しきつめ（正方形・長方形・直角三角形・いろがみ）15問＋じゆう |
| 🧩 タングラム | ふつうの7まい（大きい三角形2・中くらいの三角形1・小さい三角形2・正方形・平行四辺形）。★〜★★★ の12問＋じゆう |

- 3ねんのボタンは「じゅんびちゅう」です（3年：三角のマスと正三角形のしきつめ を、あとで足します）。
- URL で最初の画面を決められます：`?mode=tangram`（タングラムから）、`?g=2`（2年のしきつめから）、`?p=sakana`（問題を決める）。

## 2年 きょうかしょの パズル（あ〜く）

教科書の単元のはじめにある「正方形を8まいに切ったパズル」と同じ切り方です（もとの正方形を 8×8 マスとみると、どの頂点もマスの点にのります）。

- あ・か：直角三角形（直角をはさむ辺が 2 と 4）　い：平行四辺形　う・え：三角形　お：長方形（2×4）　き：台形　く：正方形（4×4）
- 8まいが ぜんぶ右の おきばに出ます。**どれを使うか、子どもが えらびます**（教科書の「どの形を つかえば いいかな」）。ピースには あ〜く の字が出ます（回しても字はまっすぐ）。
- 回るのは 45°ずつ です（さかなの からだは、正方形を ななめにして使うため）。

| もんだい | 使うピース（答えの一つ） |
|---|---|
| もとの せいほうけい | 8まい ぜんぶ |
| ロケット | あ・か・お・う |
| さかな | く（45°まわす）・え |
| いえ | あ・か・く |
| ふね | く・き・い・あ・か |
| なかまわけ | シルエットなし。ピースが上にならび、はいけいが「ふたつに わける」（下に はこ2つ）になる。三角形と四角形に分けて、ペンで名前を書く |

## 2年 しきつめ の もんだい

ピースの大きさ：正方形 2×2、長方形 3×2、直角三角形（直角をはさむ辺が 3 と 2。長方形を ななめに 半分に したもの）、いろがみの さんかく（2と2）、いろがみの 長方形（4×2）。1めもり＝50px。

| 見出し | もんだい | まい数 | ポイント |
|---|---|---|---|
| 正方形で | おおきな せいほうけい／ちょうほうけい | 4／6 | 同じ向きで ならべるだけ（はじめの1問） |
| 長方形で | おおきな ちょうほうけい／せいほうけい | 4／6 | 同じ向きで ならべる |
| 長方形で | たてと よこ | 5 | たてと よこを まぜないと うまらない（回す） |
| 直角三角形で | ちょうほうけい | 2 | 1まいを 半回転（タップ2回） |
| 直角三角形で | おおきな さんかく | 4 | まん中の 1まいだけ 半回転 |
| 直角三角形で | ダイヤ | 4 | 2まいは 裏がえさないと 入らない |
| 直角三角形で | おおきな ちょうほうけい | 8 | 2まいずつ 長方形を つくって ならべる |
| まぜて | いえ | 6 | 屋根の 直角三角形 1まいは 裏がえす |
| いろがみの さんかくで | おおきな しかく／おおきな さんかく | 8／9 | 教科書の 青・みどりの さんかく（正方形を ななめ半分）。裏がえすと 青⇔みどり になり、もようが 作れる |
| いろがみの 長方形で | れんが／れんがの かべ／かいだん | 4／6／6 | 教科書の ピンク・きいろの 長方形（たて1・よこ2）。かべ は たてと よこを まぜる |

- 道具箱には、その問題で使うピースだけが出ます（「じゆうに」では3しゅるい ぜんぶ）。
- 正方形・長方形も、裏がえすと色がかわります（色板と同じく、紙の おもて・うら）。

## 使い方

| 操作 | どうなるか |
|---|---|
| **いろいた**ボタン（2年は 正方形・長方形・直角三角形のボタン）を タップ | 1まい出る（右がわの あいている場所） |
| いろいたボタンから **引っぱる** | すきな場所に置ける |
| ピースを **引っぱる** | 動く。はなすと、近くの かど・へり に「カチッ」と弱くすいつく |
| ピースを **タップ** | 回る（きょうかしょは90°、タングラムは45°ずつ） |
| ピースを **長おし**（オレンジの わ がいっぱいになるまで） | 裏がえる。色板は表と裏で色がかわる（オレンジ⇔青） |
| ごみばこ・道具箱に もどす | 消える（きょうかしょの ピースだけ。タングラムの7まいは消えない） |
| 💡 ヒント（タングラム） | まだ置けていないピースの場所を1つ、白い点線で見せる。大きいピースから順 |
| 🔄 ならべなおす（タングラム） | ピースを右の おきばに もどす |
| 道具箱の シルエット | 問題をかえる（ピースとペンの線は かたづく。「もどる」でもどせる） |

## 🖼️ はいけい（かみ）

ツールバーの 🖼️はいけい で、ボードの下にしく紙をえらべます。

| かみ | えらべるもの |
|---|---|
| むじ | — |
| ほうがんし | ピースに あわせる（いまの問題の1めもり：色板80px・しきつめ50px・パズル40px・タングラム70px）／こまかい（25px） |
| さんすうノート | 12マス／15マス／18マス（マスの中に十字の点線） |
| ふたつに わける | 上がピースのおき場、下に はこが2つ（なかまわけ用） |

- 紙の色は しろ・クリーム・こくばん（緑）の3つです。
- 「ピースに あわせる」方眼では、マスの大きさが問題ごとに自動でかわり、シルエットのへりと方眼の線がぴったり重なります（タングラムも）。ピースの かども 方眼の点に すいつきます（ほかのピースや シルエットの かどが近くにないとき）。
- 📷しゃしん・💾くばる の画像にも紙が入ります。URL でも決められます：`?bg=grid&size=A&color=cream`（size は A・S、ノートは 12・15・18）。

## 「ぴったり！」のきまり

- シルエットが**ぜんぶうまって、はみ出しも、重なりもない**ときだけ、「🎉 ぴったり！」と出て、シルエットのふちが金色に光ります。道具箱の その問題に ⭐ がつきます。
- **1まいずつの正解・不正解は出しません。** 当たるまでタップで回すだけにならないようにするためです。
- 答えの置き方とちがっても、うまっていれば「ぴったり」です（タングラムは答えがいくつもある形があります）。
- しくみ：シルエットとピースを小さな絵にぬって、うまっていない点・はみ出した点を数えます。少しのずれ（すいつきでそろう程度）は ゆるします。全問で、どのピースを上下左右に 6px ずらしても「ぴったり」にはならないことを確かめてあります（大きなシルエットでも ゆるす量が ふえすぎないよう上限あり）。

## すいつき

- ピースをはなしたとき・回したとき・裏がえしたとき、自分の かど（頂点）と、ほかのピースや シルエットの かど が 18px より近ければ、そこにぴたっと合います。かどが近くになければ、へり（辺）にそってすべらせて合わせます。
- シルエットの中の さかいめ（答えの線）には すいつきません。答えが分かってしまうからです。

## 先生用（`?teacher=1`）

- まとめのことばに「直角が あるから すきまなく ならぶ」「おなじ 長方形を ならべると、大きな 長方形が できる」を足しました。

- 📝 もんだい：もんだいカードを作る。**まとめのことば**のボタン（「さんかく 2まいで しかくが できた」など）で、すぐに入れられます。
- 💾 くばる：今のボード（もんだい・ピースの位置と向き・カード・ペンの線）を入れた PNG 画像を保存します。子どもは 📂ひらく で選ぶと、動かせるボードにもどります。①〜③の画像をまちがえて開いたときは「そちらで ひらいてね」と出ます。

## 授業での使い方（例：1年 かたちづくり）

1. 単元のはじめの1回は、本物の色板をさわる。
2. 2時間目から ボード。先生が電子黒板で「タップで回る・長おしで裏がえる」をやって見せる。
3. 「この さかなは、いろいた なんまいで できるかな？」と予想してから、うめる。
4. ぴったりになったら、ペンで「さんかく2まいで しかく」などを囲んで書き、📷しゃしん でロイロに提出。
5. うめ方のちがう子を2〜3人、電子黒板でくらべる。
6. 早く終わった子は 🧩タングラム の★から。

## 問題の足し方

- 2年：`G2_PROBS` に1行足します。`sol` は答えの置き方（1めもり＝50px の座標、`sq`・`re`・`rt`）、`grp` は見出し（`sq`・`re`・`rt`・`mix`）。足したら、答えどおりに置いて `isPitta()` が true になるか確かめてください。
- 色板：`IRO_PROBS` に1行足します。`g` は1マス（色板2まい分の正方形）ごとの記号です。`#` はマスいっぱい（2まい）、`◤◥◢◣` は色板1まい（三角の向き）、空白はなし。
- タングラム：`TAN_PROBS` に1行足します。`sol` は答えの置き方（1めもり＝70px の座標）です。**足したら、すき間・重なりがないか必ず確かめてください**（ブラウザのコンソールで答えどおりに置いて `isPitta()` が true になるか）。
