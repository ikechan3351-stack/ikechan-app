# 📍 さんすうボード⑩ 数直線

小学1年〜中学1年向けの、**数直線の上で ジャンプ・おび・やじるし・ピンを動かす**ボードです。たし算・ひき算・かけ算を「とぶ」動きで表したり、小数・分数・負の数の位置を確かめたりします。決まった問題や正解はありません。

- Brainingcamp の「Number Lines」（数直線のデジタル教具）を参考に、さんすうボード①〜⑨ と同じ外わく（ペン・もどる・しゃしん・くばる・つづきから）で作りました。
- すでにある「数直線ツール」（1本の数直線を くわしく見る道具）とのちがい：こちらは **ボード型** です。数直線を何本でも置け、ジャンプなどを自由に置き、書きこんで📷しゃしんで提出できます。

## 基本情報

- **ファイル**：`さんすうボード⑩ 数直線.html`。この1ファイルだけで動きます（ネット接続・外部ライブラリ・画像ファイルは不要）。
- **対応する機器**：タッチできる Chromebook（主に想定）、電子黒板、マウス・トラックパッド。何人かで同時に動かせます（マルチタッチ）。

## 部品

| 部品 | 形 | 何ができるか |
|---|---|---|
| 数直線 | めもりのついた線 | 1めもりの大きさ（1・2・5・10・100・1000・1万・0.1・0.01・½〜1/12）、はじめの数、めもりの数・はば、数の見せかたを変えられる |
| 白紙の数直線 | めもりのない線 | 「ふだ」に数を書いて置く（オープン数直線） |
| ＋ジャンプ／−ジャンプ | 青／赤の弧 | めもりにすいつき、上に「+25」「−4」のように自動で数が出る |
| おび（あお・あか） | 長方形 | 2つの数のあいだの大きさ（ちがい）を表す |
| ＋やじるし／−やじるし | 青／赤の矢印 | 正負の数のたし算などを矢印で表す（中学） |
| ピン | むらさきのしるし | さしたところの数が出る |
| ふだ | 黄色い札 | 数を書く。白紙の数直線では、ふだの数からジャンプの数が計算される |
| ことば | 点線のカード | 「はじめ」「のこり」などを書く |

- **色だけで区別しない**：＋は青で矢じりが右、−は赤で矢じりが左。数にも「+」「−」がつきます。

## 使い方

| 操作 | どうなるか |
|---|---|
| 道具箱を **タップ** ／ **引っぱる** | 1こ出る ／ すきな場所に置ける |
| ジャンプを **タップで出す** | えらんでいる数直線の 0 のめもりから出る。ジャンプをえらんでから出すと、**その先から続けて**出る |
| ジャンプのはしの **つまみを引っぱる** | めもりにすいつきながら のびちぢみし、上の数が変わる |
| ジャンプ・ピンを **えらんで もう一度タップ** | 数 ⇔「？」が切りかわる（答えをかくして考えさせる） |
| ジャンプの **➕つぎ** | 同じ長さのジャンプを先に続ける（5×(−4) のようなくり返し） |
| ジャンプの **⇄** | ＋ ⇔ − を切りかえる |
| ジャンプ・ピンの **✏️** | 🔢じどう ／ ？ ／ なし ／ 自分で書く（「□」「ア」「3/4」など）をえらぶ |
| 数直線の **⚙️めもり** | 1めもりの大きさ・はじめの数・めもりの数・数の見せかた・仮分数／帯分数・＋をつけるか を変える |
| 数直線の **◀ ▶** ・ **🔍− 🔍＋** | はじめの数を1めもりずらす ・ めもりのはばを変える |
| 数直線の右はしの **つまみ** | めもりの数をふやす・へらす |
| 数直線を **動かす** | のっているジャンプ・ピン・ふだも いっしょに動く。ほかの数直線と左はしがそろう（二重数直線） |
| ごみばこ・道具箱へ運ぶ | 消える（数直線を消すと、のっていたものも消える） |
| **👁️ひょうじ** | 数直線の数・ジャンプの数・ピンの数を まとめて見せる／かくす |

- めもりのはばや1めもりの大きさを変えても、のっているジャンプなどは **同じめもり** についていきます。
- 数直線の数が重なるときは、自動で 5ごと・10ごと などにまびいて表示します。

## 学年での使い分け

| 入り口 | 開き方 | ちがい |
|---|---|---|
| さんすうセット ていがくねん | `?low=1` | 整数（1・2・5・10・100・1000）と白紙だけ。分数・小数・＋の記号は出ない |
| 算数操作ボードセット | `?high=1` | ぜんぶ使える。もどる先が入り口になる |
| 数学操作ボード 中学 | `?jh=1` | 道具箱の最初が負の数の数直線になる |
| トップページから | なし | ぜんぶ使える |

## 授業での使い方（例）

- **1年 たし算・ひき算**：0〜20 の数直線で「8＋5」を、8 から＋ジャンプ（えらんで2回）。答えのピンを「？」にして予想させる。
- **2年 たし算（2けた）**：0〜100 で「50＋25」を、＋50 と ＋25 のジャンプで。白紙の数直線で「100−40」を、ふだ 100・60 と −ジャンプで。
- **3年 小数**：0〜3（0.1）で、0.1 のいくつ分かをジャンプで数える。
- **3〜4年 分数**：4等分の数直線で、1/4 ずつジャンプ。仮分数⇔帯分数を切りかえて 5/4＝1¼ を確かめる。
- **4〜5年 分数のかけ算**：1/5 の数直線で「4×3/5」を、+3/5 のジャンプを ➕つぎ で4回。
- **中1 正負の数**：−5〜5（+のしるしつき）で、(−3)＋(+5) をやじるし2本で。5×(−4) を −4 のジャンプ5回で。
- 先生は **🧑‍🏫せんせい** → **📝もんだい** で問題カードを置き、**💾くばる** で盤面ごと画像にして配れます（①〜⑨ と同じ）。

## 正しさについて

- 数は「めもりの番号 × 1めもりの大きさ」を整数の分数で計算するので、0.1 や 1/3 でもずれません。
- 分数は約分しません（2/4 は 2/4 のまま）。等しい分数を見つける学習のためです。
- 白紙の数直線では、ふだに書いた数（整数・小数・a/b）どうしのひき算でジャンプの数を出します。ふだの数が読めないときは何も出ません。
- **※じっさいとのちがい**：白紙の数直線のジャンプの長さは、数の大きさとは関係ありません（オープン数直線なので、だいたいの位置で表します）。

## つまずき検知について

- 自由なボードなので、正しいかどうかの判定やつまずき検知は付けていません。
- 「？」にかくす・👁️でまとめてかくす を使い、子どもに数を予想させてから見せる使い方をおすすめします。
