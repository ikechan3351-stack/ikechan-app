# まぜて のばして 比と比例（同じ味のひみつと、ともなって変わる2つの量）

小学6年生の算数「比」「比例」で使う、**混ぜる・のばす操作**で比と比例を体感するシミュレーション教材です。次のことを体験します。

- 比 a：b は2つの量の割合を表し、**両方に同じ数をかけても、わっても等しい比**になる（味や色が変わらない）
- **比の値**（a÷b）、**比を簡単にする**こと、**比を使って全体を分ける**こと
- 比例：xが2倍、3倍になると、yも2倍、3倍になる。**表・式（y＝きまった数×x）・グラフ（0を通る直線）**の3つで表せる
- 比例を使って問題を解く（紙の枚数を重さから求める など）

## 基本情報

- **ファイル**：`まぜて のばして 比と比例.html`。この1ファイルだけで動きます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。コップ・テープ・表・グラフはすべて SVG（エスブイジー：線や図形を式で描く画像）で描いています。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。
  - 画面の幅に合わせて、図とパネルの並び方が変わります（広い画面は横、せまい画面は縦）。ボタンは48px以上です。
- **漢字**：6年生までに習う漢字を使い、ふりがなをつけています（せっていで OFF にできます）。小学校で習わない「酢」はふりがなを残します。「傾き」「年齢」「水槽」は「かたむき」「年れい」「水そう」と書いています。
- **記録**：保存されるのは「せってい」だけです。児童の名前など個人情報は扱いません。

## 動作確認の方法

1. `まぜて のばして 比と比例.html` をブラウザ（Chrome・Edge・Safari）で開きます。ダブルクリックで開けます。
2. 次の順に操作して、エラーや表示のくずれがないかを確かめます。

| 確かめること | 操作 | 期待される結果 |
|---|---|---|
| 同じ味 | 「同じ 味を つくろう」で お酢6・油9 を入れ「同じ味かな？」 | 自動で混ざり「せいかい！ 2：3 の両方に ×3」。2つのコップが同じ色、メーターの針が同じ位置 |
| たし算の誤り | 「からにする」→ お酢4・油5 で「同じ味かな？」 | 「両方に2ずつたしたね」。あなたのコップが光り、メーターの針がずれ、かけ算の表（ヒント）が出る |
| 比を簡単に | 12：18 で「÷5」→「÷2」→「÷3」 | ÷5 は「12は5でわりきれない」。2：3 で「できた！」。テープの長さは変わらず目もりだけ変わる |
| 小数・分数 | 問題のしゅるい「小数」で ×10 → ÷3、「分数」で ×12 | 0.6：1.5＝2：5、2/3：3/4＝8：9 |
| 比で分ける | はさみをドラッグして 50cm で「切る」→ 40cm で「切る」 | 50cm は「はんぶんにしたね」と5こに分ける線。40cm で「せいかい」、式が出る |
| 比例の表とグラフ | 「比例を 見つけよう」で「▶ つぎ」を4回 | 水がたまり、表が1列ずつうまり、グラフに点が打たれる |
| ×2・×3 の矢印 | 表の x＝2 と x＝6 の列をタップ | 上下に「×3」の矢印、y÷x＝2 |
| 比例でない例 | 場面「年れいと身長」で「ぜんぶ」→「比例している」 | 「ふえているけど2倍になっているかな？」。光る列（6さい・12さい）をタップすると「約1.31倍」 |
| 式とグラフ | 「式と グラフ」でスライダーを動かす | 直線のかたむきが変わる。「この線をのこす」で点線が残る。グラフをタップするとその時間の深さ |
| 比例を使って | 「何倍かで」→ 20 → 200 | 二重数直線に ×20 の矢印、答え 200まい |
| 先生モード | 「すすむ ▶」をくり返す | 見本 → ×3 → たし算 の3つのコップが順にでき、最後に色とメーターのずれ |
| せってい | ふりがな OFF・動きを減らす・音 OFF | それぞれ反映される |

## モード

| モード | 内容 |
|---|---|
| 🥗 同じ 味を つくろう | 見本（例：お酢：油＝2：3）と同じ味を、量を増やして作る。「＋大さじ1」で入れると、しま模様（お酢）と水玉模様（油）の層が重なる。「まぜる」で1つの色に。1問目は自由、2問目からは「お酢を大さじ6にすると油は？」。場面（お酢と油・カルピスと水・赤と白の絵の具）と見本の比を選べる |
| 🔢 比を 簡単に | 「両方を わる（÷2〜÷10）」「両方に かける（×2〜×100）」で比を変える。テープの長さは変えずに「1こ分」の目もりだけが大きく（小さく）なる。比の値はずっと同じ。整数・小数・分数・ミックス |
| 🎀 比で 分けよう | リボン・ひも・カード・ジュースなど8問。はさみをドラッグ（◀ ▶ でも可）して切る。正かいのあと「全体を（2＋3）こ分に分ける → 1こ分 → 2こ分・3こ分」と「全体の 2/5」の式 |
| 🔍 比例を 見つけよう | 8つの場面で表を作って比例か判断する。比例：水そう・正三角形の周り・くぎの重さ・歩く道のり。比例でない：年れいと身長・正方形の面積・ろうそくの残り・ふくろ代のあるあめの代金 |
| 📈 式と グラフ | きまった数をスライダーで変える（水そう・正多角形の周り・くぎ・分速）。「水を入れる」で時間が進み、グラフ上の点が直線にそって動く。周りの長さでは、きまった数＝辺の数（正三角形〜正八角形） |
| 📄 比例を 使って | 紙10まいで40g→800gは何まい？など8問。「何倍かで」（800÷40＝20倍 → 10×20）か「1あたりで」（40÷10＝4g → 800÷4）を選んで解く。二重数直線と表を切りかえ |
| 🧑‍🏫 先生モード | 比：a・b・何倍かを決め、見本 → ×k → たし算の誤り の3つのコップをステップ再生。比例：場面を選び、表 → y÷x → ×2の矢印 → グラフの線をステップ再生。じどう再生あり |

## つまずきへの対応

| つまずき | 教材の反応 |
|---|---|
| 比の両方に同じ数をたす（2：3→4：5） | 「両方に2ずつたしたね」。2つのコップの色、くっつけた円、味メーターの針のずれを見せ、「かけ算でふやす」表（2：3、4：6、6：9…）と自分の 4：5 をならべる |
| 片方だけ何倍かにする（6：5） | 「お酢は2の3倍。油も3倍にすると…？」 |
| 同じ味だが条件ちがい | 「同じ味になったね！でもお酢を大さじ6にしよう」 |
| 比を簡単にするとき、わりきれない数でわる | 「12は5でわりきれないね」 |
| 小数・分数のままわろうとする | 「まず両方にかけて整数にしよう」。ヒントで ×10・×100、分母の最小公倍数 |
| 比で分けるとき半分にする・全体÷2 | 「はんぶんにしたね」「100÷2ではないよ。全体で5こ分」。5こに分ける線を出す |
| 比を逆にして分ける | 「姉と妹が反対になっているよ」 |
| 「ふえる＝比例」と考える | 「ふえているね。でも2倍になっているかな？」。2倍になる2列を光らせ、タップすると「約1.31倍。同じ倍になっていない」 |
| 「へる」ものを比例と答える | 「xがふえると、yはへっているね」 |
| 比例の問題でわる数・わられる数が逆 | 「わる数とわられる数が反対かも」 |
| ①の答え（何倍か・1あたり）を最後の答えにする | 「それは①の答え」 |

## しくみ（コードのつくり）

- **比は整数の組**：`[2, 3]` のように持ち、最大公約数（`gcd`）でわって簡単にします（`simp`）。等しい比かどうかは「a×d＝b×c」で判定します（`sameRatio`）。小数・分数の比は分数 `{n: 分子, d: 分母}` の組で持ち、×・÷ のたびに約分します。
- **混ぜた色**（`mixOf`）：2つの液体の色（赤・緑・青の量）を a：b の割合で計算します。だから**等しい比ならまったく同じ色**になります。色の差が小さいときは「ほんの少しちがう → メーターでたしかめよう」と表示し、色だけにたよりません。
- **コップ**（`mkCup`）：入れた順の列 `['A','B',…]` と、混ぜおわった数を持ちます。混ぜていない層は液体の色＋模様、混ぜた部分は1つの色で描きます。
- **比例の場面**（`SCENES`）：x の値の並び・y を求める式（または身長のようなデータ）・比例かどうか・きまった数を持ちます。表（`tableSvg`）・グラフ（`graphSvg`）・場面の絵（`SCENE_DRAW`）は、このデータから別々に描きます（データと描画の分離）。
- **何倍か**（`timesText`）：整数・小数ならそのまま、きれいな分数なら分数、そうでなければ「約1.31」のように表示します。

## 色と形（色だけで区別しない）

| もの | 色 | ほかの区別 |
|---|---|---|
| 1つめの液体（お酢・カルピス・赤） | うすい黄・白・赤 | しま模様、左側の数 |
| 2つめの液体（油・水・白） | こい黄・水色・白 | 水玉模様、右側の数 |
| 味メーターの針 | 見本＝緑、あなた＝ピンク | 見本は上から▼、あなたは下から▲、名前の文字 |
| 比例の点・線 | 緑 | 比例でない場面はオレンジ。グラフの0の点に丸 |
| 選んだ列 | 黄色 | ×○ の矢印と文字 |

## 授業例

### 1. 比の導入（1時間）

1. **先生モード（比）**で、お酢と油のドレッシングを見せる。「お酢大さじ2、油大さじ3。この味を、もっとたくさん作りたい」
2. 予想を出させる（「4：5」「6：9」などが出る）。**先生モード**で ×3（6：9）と たし算（6：7）のコップを順に作り、混ぜた色とメーターを比べる。「たしたほうは、油の割合が変わってしまった」
3. 児童が「同じ 味を つくろう」で取り組む。たし算で作った児童には教材がずれを見せるので、ペアで「なぜちがうか」を説明させる。
4. ヒントの表（2：3、4：6、6：9…）から「両方に同じ数をかける」とまとめ、**比の値**（2÷3＝2/3）が同じことを確かめる。
5. 発展：場面を「赤と白の絵の具」に変えて、同じ色を作る。

### 2. 比例の表とグラフ（2時間）

1. 「比例を 見つけよう」の水そうを電子黒板で見せる。「▶ つぎ」で1分ずつ水を入れ、表がうまるのを見る。
2. 表の x＝2 と x＝6 をタップ → 「×3」の矢印が上下に出る。いくつかの組で確かめ、「xが2倍・3倍になるとyも2倍・3倍」をまとめる。「y÷x」でいつも2になることから、**y＝2×x** を導く。
3. 比例でない場面（年れいと身長、正方形の面積）を児童が調べる。「ふえる＝比例」と答えると教材がヒントを出すので、表で2倍になっているかを確かめさせる。
4. 2時間目：「式と グラフ」でスライダーを動かし、「きまった数が大きいほど直線が急」「どの直線も0を通る」をまとめる。ろうそくやあめの代金のグラフ（0を通らない）とくらべる。

### 3. 比例の活用（1時間）

1. 「紙を1まいずつ数えずに、800gの紙が何まいか分かるかな？」と問う。
2. 「比例を 使って」で、まず「何倍かで」解く（800÷40＝20倍 → 10×20＝200まい）。二重数直線の ×20 の矢印で、上も下も同じ倍になることを確かめる。
3. 「1あたりで」も解いてみる（40÷10＝4g → 800÷4＝200まい）。2つの方法をくらべ、表に切りかえて説明させる。
4. 残りの問題（くぎ・針金・水そう・ガソリン など）を個人で解く。
