# ならべて くらべて データの調べ方（ドットプロット・代表値・柱状グラフ）

小学6年生の算数「データの調べ方」で使う、**ドットプロット・代表値・度数分布表と柱状グラフ**のシミュレーション教材です。次のことを体験します。

- ドットプロットで、データの**散らばりの様子**を表すこと
- 代表値（**平均値・中央値・最頻値**）の意味と、データによってどれが適しているかがちがうこと
- 度数分布表と柱状グラフ（ヒストグラム）。**階級の幅を変えると見え方が変わる**こと
- 問題 → 計画 → データ → 分析 → 結論（**PPDAC**）の流れで調べ、結論を批判的に見直すこと

## 基本情報

- **ファイル**：`ならべて くらべて データの調べ方.html`。この1ファイルだけで動きます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。グラフはすべて SVG（エスブイジー：線や図形を式で描く画像）で描いています。
  - データの配列から代表値・度数分布を計算する部分（`Stats`）と、グラフを描く部分を分けてあります。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。
  - 広い画面は「入力｜グラフ｜まとめ」の3列、せまい画面はグラフを上にした縦1列になります。ボタンは48px以上です。
- **漢字**：6年生までに習う漢字を使い、ふりがなをつけています（せっていで OFF にできます）。「最頻値」の「頻」は小学校で習わないので、OFF にしても いつも ふりがなをつけます。
- **個人情報**：児童の名前は扱いません。数だけを入れます（CSVに名前の列があっても読みこみません）。
- **保存**：保存されるのは「せってい」だけです。データ・意見・PPDACノートはページを閉じると消えます（閉じるときに確認が出ます）。のこすときは「CSVで ほぞん」「PNG」「いんさつ」を使います。
- **サンプル**：架空のソフトボール投げの記録（1組21人・2組20人）です。画面にも「架空の数」と表示します。1組は平均値が高い（約25.8m）のに中央値は低い（23m）、2組は散らばりが小さい（18m〜33m）という、くらべがいのある数にしています。

## 動作確認の方法

1. `ならべて くらべて データの調べ方.html` をブラウザ（Chrome・Edge・Safari）で開きます。ダブルクリックで開けます。
2. 次の順に操作して、エラーや表示のくずれがないかを確かめます。

| 確かめること | 操作 | 期待される結果 |
|---|---|---|
| 点を積む | 「ドットプロット」でキーパッドの 2・5 →「⬇ つむ」 | 点が上から落ちてきて 25 の上に積まれる。「25mは 1人」 |
| サンプル | 「🧪 サンプルを 1つずつ」 | 21こ の点が1つずつ落ちる。「架空の数」の表示 |
| 代表値のカード | 「代表値」で右のカード「？」をタップ | 平均値 約25.8m（541÷21）、中央値 23m（11番目）、最頻値 22m（3人） |
| てんびん | 「てんびんで 平均値」→ 下の ▲ を右へドラッグ | うでがかたむき、左右のきょりの合計のバーが変わる。約25.8m で「つり合った！」 |
| 中央値（奇数） | 1組で「並べて 中央値」 | 小さい順に1列 → 両はしから消える → 11番目の 23m が光る |
| 中央値（偶数） | 2組にして「並べて 中央値」 | 10番目 25m と 11番目 26m がのこり「(25＋26)÷2＝25.5m」 |
| とびぬけた値 | 1組で「とびぬけた 値を 入れる」 | 69m の点。平均値 約25.8→約27.7（＋1.9m）、中央値 23→23.5（＋0.5m）の表 |
| 柱状グラフ | 「柱状グラフ」 | 上にドットプロット、下に柱状グラフ。はば5m で 4・8・3・2・2・2 |
| 階級の幅 | スライダー・＋－ | 表とグラフが変わる。はば1m・2m では「階級が多すぎて でこぼこ」、20m では「少なすぎて」 |
| 境目 | 右の「さかい目」で「◀ 15以上 20未満」→「20以上 25未満 ▶」 | 「未満はその数をふくまない」→ 点が右の箱に入るアニメと「せいかい」 |
| 2つを比べる | 「2つを 比べる」で 平均値・中央値をON、柱状グラフに切りかえ | 1組・2組が上下に並び、▲と中央値の線。柱状グラフの階級はそろっている |
| 意見の見直し | 1組を選び、理由に平均値だけ →「意見を 見直そう」 | 「平均値で見ると1組、中央値で見ると2組」「1つの見方だけで…」などの問いかけ |
| PPDACノート | 「例を入れる」→「いまのグラフと代表値をはる」→「いんさつ」 | 5つの欄に例が入り、グラフと表がはられる。印刷プレビューにボタンが出ない |
| 先生モード | 「すすむ ▶」（または →キー）をくり返す | 数直線 → 点が落ちる → 最頻値 → 中央値（並べかえ）→ てんびんが平均値でつり合う → 柱状グラフ → 2つの比べ |
| CSV | 「📂 CSV」で `番号,名前,1組,2組` のようなCSVを読む | 番号と名前の列はとばし、1組・2組に数だけが入る |
| せってい | ふりがな OFF・動きを減らす・音 OFF・平均値を小数第2位まで | それぞれ反映される |

## モード

| モード | 内容 |
|---|---|
| ⚫ ドットプロット | キーパッド（またはキーボードの数字と Enter）で数を1つずつ入れると、点が落ちてきて数直線の上に積み上がる。「1つ もどす」「サンプルを 1つずつ」。平均値・中央値・最頻値の印も出せる |
| ⚖️ 代表値 | 右の代表値カードは「？」で、タップすると数と印が出る（予想してから確かめる）。「てんびんで 平均値」（数直線をうでにして ▲ をドラッグ、左右のきょりの合計を表示）、「並べて 中央値」（小さい順に並べて両はしから消す）、「いちばん 多い 値」（最頻値の列を光らせる）、「とびぬけた 値を 入れる」（平均値と中央値の動きをくらべる表） |
| 📶 柱状グラフ | ドットプロットと柱状グラフを同じ数直線で上下に描き、階級の帯でつなぐ。階級の幅スライダー・区切りをずらす・表の行や柱をタップで階級を光らせる。度数がいちばん多い階級と、中央値が入る階級を表示。境目のデータの拡大図 |
| 👥 2つを 比べる | 1組（青・●）と2組（オレンジ・▲）を上下に並べる。ドットプロット／柱状グラフの切りかえ、平均値・中央値・最頻値の印。代表値の表、問い（書きかえ可）、どちらと言えるか・理由にしたこと・自分の意見の欄、「意見を見直そう」 |
| 📝 PPDACノート | 問題・計画・データ・分析・結論を書くワークシート。データの欄は自動でまとめが出る。グラフと代表値の表をはる、比べるモードの意見をうつす、結論の見直しチェック、つぎに調べたいこと。印刷（PDF保存）可。記入例あり |
| 🧑‍🏫 先生モード | 電子黒板向けに文字を大きくし、入力らんをかくす（「📥 データ」で出し入れ）。7つの手順を「すすむ」で1つずつ見せる。→キー・スペースですすむ、←キーでもどる。じどう再生あり |

## つまずきへの対応

| つまずき | 教材の反応 |
|---|---|
| データが偶数個のときの中央値がわからない | 「並べて 中央値」で両はしから1こずつ消していき、真ん中に2つのこるところを見せる。「10番目 25m と 11番目 26m → (25＋26)÷2＝25.5m」。とびぬけた値を入れて奇数個→偶数個になるときも説明する |
| 平均値は「真ん中の値」だと思う | てんびんで、平均値は「左右のきょりの合計が等しくなる点」であることを見せる。とびぬけた値を入れると、平均値だけが大きく動く |
| 階級の「以上・未満」の境目のデータをどちらに入れるか迷う | 境目のデータにはオレンジのわく。拡大図で「どちらの階級に入るかな？」。未満を選ぶと「未満はその数をふくまない」、正しいと点が「以上」の箱に入るアニメ。数直線に ○（ふくまない）と ●（ふくむ）をかく |
| 階級の幅をどう決めればよいかわからない | 幅を変えると階級の数に応じて「多すぎて でこぼこ」「少なすぎて 散らばりがわからない」「山の形が見えるかな？」とひとこと |
| 1つの代表値だけで結論を出す | 「意見を見直そう」で、平均値と中央値で結論が変わること、散らばり、とびぬけた値、人数のちがい、データの数は十分か、を問いかける |
| 人数のちがう組を合計でくらべる | 人数がちがうときは「合計ではなく代表値で比べているかな？」と問いかける |

## 授業での使い方の例（ソフトボール投げの記録の比較・PPDAC）

全6時間の単元の流れの例です。サンプルの架空の記録のかわりに、クラスの実際の記録（数だけ）を使うこともできます。

| 時 | PPDAC | 学習活動 | 使うモード |
|---|---|---|---|
| 1 | 問題・計画 | 「1組と2組では、どちらのほうがソフトボールを遠くまで投げたと言えるか」という問いを立てる。どんなデータを、どう集めればよいかを話し合う（同じ日・同じ場所、記録の取り方をそろえる） | PPDACノート（問題・計画） |
| 2 | データ | 記録をドットプロットに表す。点が多く集まっているところ、散らばりの様子を話し合う。最頻値を知る | ドットプロット（1つずつ入れる）、先生モード（手順1〜3） |
| 3 | 分析 | 平均値（てんびん）・中央値（並べて）を求める。偶数個のときの中央値を確かめる。とびぬけた値を1つ入れて、平均値と中央値の動き方のちがいを見る | 代表値、先生モード（手順4・5） |
| 4 | 分析 | 度数分布表と柱状グラフに表す。階級の幅を変えて、特徴がいちばんわかる幅を考える。境目のデータの入れ方を確かめる | 柱状グラフ |
| 5 | 分析・結論 | 2つの組を代表値と分布の両方から比べ、自分の意見を書く。「意見を見直そう」で別の見方を考え、友だちと意見を交流する | 2つを 比べる、先生モード（手順7） |
| 6 | 結論・つぎの問題 | PPDACノートにまとめる（グラフをはる・意見をうつす）。結論を見直しのチェックで確かめ、つぎに調べたいことを書く。印刷してふり返る | PPDACノート |

**話し合いのポイント（サンプルの場合）**：平均値では1組（約25.8m）が2組（25.6m）より少し大きいが、中央値では2組（25.5m）が1組（23m）より大きい。1組は遠くまで投げた何人かに平均値が引っぱられ、半分以上の人は23m以下。2組は18m〜33mにまとまっている。「どの代表値で比べるか」で結論が変わることに気づかせ、理由をつけて説明させます。
