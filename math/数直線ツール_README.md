# 📏 数直線ツール

小学校の算数で、学年を問わず使える数直線です。整数・小数・分数を同じ数直線で扱い、次のことができます。

- 数の大きさと位置の関係をつかむ（ピンを立てる・数字を □ にかくす）
- たし算・ひき算を「ジャンプ」、かけ算を「同じはばのジャンプのくり返し」として見る
- 目もりの大きさ（1目もりがいくつか）を読み取る
- つまんで拡大すると、目もりの間がさらに10等分される（1 → 0.1 → 0.01）
- 上下2本の「二重数直線」で、割合・分数のかけ算わり算・比例を考える

## 基本情報

- **ファイル**：`数直線ツール.html`。この1ファイルだけで動きます（ネット接続・外部ライブラリ・画像ファイルは不要。数直線はすべてSVGで描いています）。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）・スマートフォン。画面の幅に合わせて文字と線の太さが変わります。
- **ふりがな**：「⚙️ せってい」で消せます。
- **姉妹教材**：「小数の 数直線」（3年の小数専用）、「分数ピザ」（3年の分数）、「大きな数の 位取り表」（4年）、「まぜて のばして 比と比例」（6年）。

## しくみ（コードのつくり）

- **数の持ち方**：すべての数を「分子と分母の整数の組」で持っています（例：0.1 → 1/10、2.5 → 5/2）。
  - 整数には JavaScript の **BigInt**（どんなに大きな整数でも正確に計算できるしくみ）を使っています。1兆（1000000000000）や分数どうしのかけ算でも桁があふれません。
  - そのため、0.1＋0.2 が 0.30000000000000004 になるような **誤差は出ません**。画面に出すときだけ、小数・分数・帯分数・万億兆の書き方に変えます。
- **状態（state）と描画を分けています**：
  ```
  state = {
    double: 二重数直線か,
    lines:  [ { はじめ, おわり, 1目もり, 数字の出し方, 表し方, 線のなまえ, □にした目もり } ],
    pins:   [ { どの線, 値, ラベル, 対応する数を見せるか } ],
    hops:   [ { どの線, 出発, 着地, ジャンプの番号 } ],
    jp:     { はじめ, はば, まとめての回数, 10でくぎる },
    approx: がい数の位,  hideUnit: 1目もりをかくす,  view: { ズーム倍率, 左はしの位置 }
  }
  ```
  ボタンやタップは state を書きかえるだけで、`draw()` が state を読んで SVG をかき直します。
- **URL に保存**：state を短い文字にして、URL の「#n=」より後ろに自動で書きこみます。同じ URL を開くと同じ数直線になります。入るのは数直線の設定・ピン・ジャンプだけで、個人情報は入りません（ピンのラベルに名前を書かないように気をつけてください）。

## 色と形のきまり

色だけにたよらず、形・線の種類・記号でも区別しています（色覚の多様性への配慮）。

| 意味 | 色 | 形・線・記号 |
|---|---|---|
| ピン | 青・朱・緑・むらさき… | ▼ ● ■ ◆ の形が順にかわる。ピンカードにも同じ形が出る |
| 対応する数（二重数直線） | ピンと同じ色 | 白ぬきの形・点線のわく・「？」 |
| すすむジャンプ（たし算） | オレンジ | 実線の弧と矢じり・「＋3」 |
| もどるジャンプ（ひき算） | 青 | 点線の弧と矢じり・「－3」 |
| ジャンプの「はじめ」 | オレンジ | 線の上の ○ |
| がい数のさかい目 | むらさき | 点線と「まん中」の文字 |
| かくした数字 | 黒 | □（タップすると赤い点線のわくで答え） |

## 画面と機能

### 目もり（下の「📏 目もり」カード）

- **はじめ・おわり・1目もり**を自由に入れられます。入れ方の例：`12`、`0.1`、`1/4`、`1と1/2`（帯分数）、`3億`、`1兆`、全角数字もOK。
- 1目もりのチップ：1・2・5・10・100・1000・0.1・0.01・1/2・1/3・1/4・1/5・1/10。分数のチップをおすと表し方が「分数」になります。
- はじめ・おわりは「1目もりのちょうどいくつ分」にします。1目もりを変えたときは、外がわのいちばん近い数に自動でそろえます。目もりは1000こまで。
- **数字**：じどう（重ならない間かくで出す）・長い目もりだけ・りょうはしだけ・0だけ・なし。
- **表し方**：じどう・小数・分数・帯分数・万億兆。1目もりが 1/4 のような分数の線では、目もりの数字を 2/4・3/4・4/4… ではなく **2/4・3/4・1・5/4**（1目もりの分母にそろえる、整数は整数）で出します（約分して 1/2 にはしません）。
- **1目もりを かくす**：上の「1目もり＝」が「？」になります。タップで答え。

### 📍 ピン

- 「📍 ピン」を選んで数直線をタップすると、いちばん近い目もりに立ちます。ドラッグで動かせます。
- 選んだピンは「ピン」カードでラベル（数・ア／イ…・？・自由な文字12字まで）を変えられます。キーボードの ← → で1目もりずつ動き、Delete で消えます。

### 🐸 ジャンプ

- 「はじめ」「はば」を決めて「すすむ ➡」「⬅ もどる」。弧の矢印がのびて、ボールがとびます。
- 「まとめて ○回 すすむ」で同じはばをくり返します。0から同じはばで進むと **「3 × 4 ＝ 12」** と、下に「3＋3＋3＋3＝12（3の4回ぶん）」が出ます。
- 「10で くぎる」をONにすると、10をまたぐジャンプを2回に分けます。
  - 8＋5 → 8＋2＝10、10＋3＝13（くり上がり：10をつくる）
  - 13－5 → 13－3＝10、10－2＝8（くり下がり：減減法）
- 「🐸 ジャンプの はじめ」を選んで数直線やピンをタップすると、そこが「はじめ」になります。
- 「↩ 1つ けす」「🧹 ぜんぶ けす」。

### 🙈 数字を かくす

- 「🙈 数字を かくす」を選んで目もりをタップすると、その数字が □ になります（数字が出ていない目もりでも □ にできます）。
- ほかの道具のときに □ をタップすると、答えが赤い点線のわくで出ます。もう一度でかくれます。

### 🔍 ズーム

- 2本の指でつまんで広げる・マウスのホイール・「＋」「－」・キーボードの ＋ － で拡大します。ドラッグで左右に動かせます。下のむらさきのバーが、いま見ている場所です。
- 1目もりが 1・10・0.1 などのとき、目もりの間が広がると **10等分の目もり** が出てきます（1 → 0.1 → 0.01 → 0.001）。1目もりが 2・5 のときは、まず 1 に分かれます。上に「🔍 ズームで 1目もり＝0.1」と出ます。
- 分数で表す線は10等分しません（1/5 → 1/50 は分数の学習に合わないため）。拡大だけします。

### ═ 二重数直線

- 「目もり」カードで「2本」にすると、上下に2本の線が並びます。「どの線？」で上の線・下の線を切りかえて、それぞれのはじめ・おわり・1目もり・なまえ（例：ねだん(円)・割合）を決めます。
- 2本は左はしと右はしの位置がそろっていて、比例の関係になります。
- ピンを立てると、もう一方の線の同じ位置に **対応する数** が出ます。はじめは「？」で、タップすると答え（分数・小数でも正確）。「対応する数を ぜんぶ 見せる」もあります。

### 🎯 がい数（1本のとき）

- 「ピン」カードで「千の位まで」などを選ぶと、ピンの両どなりの目もり・**まん中（四捨五入のさかい目）**・どちらに近いかを数直線の下に表示します。ちょうど真ん中のときは大きいほうになります（四捨五入）。

### そのほか

- **🔗 URL**：いまの数直線の URL をコピーします。
- **🖼️ PNG**：数直線を画像で保存します（ダウンロードフォルダ）。上に「1目もり」とジャンプの式が入ります。
- **⛶ ぜんがめん**、**⚙️ せってい**（数字の大きさ：ふつう／大きい（電子黒板）、ふりがな、こうかおん、うごき：じどう／へらす／ふつう）。
- 「うごき：へらす」では、ジャンプの矢印がすぐにかかれ、点めつも止まります。

## 動作確認方法

1. `数直線ツール.html` をブラウザ（Chrome・Edge・Safari）で開きます。0〜20 の数直線が出ます。
2. **ピン**：数直線の 7 のあたりをタップ → 7 にピンが立つ。ピンをドラッグして 12 にすると、ピンカードの「いまの場所」が 12 になる。← → キーで1ずつ動く。
3. **ジャンプ（1年）**：「1年」→「8＋5（10を つくって）」→「すすむ ➡」。10で止まってから13にとび、上に「8 ＋ 5 ＝ 13（8 ＋ 2 ＝ 10、10 ＋ 3 ＝ 13）」が出る。「13−5」で「⬅ もどる」をおすと、青い点線で 13 → 10 → 8。
4. **かけ算（3年）**：「3年」→「かけ算 3×4」→「⏩ 4回 すすむ」で「3 × 4 ＝ 12」。
5. **数字をかくす（2年）**：「2年」→「□に あてはまる 数」。□ をタップすると 300 が赤いわくで出る。「🙈 数字を かくす」で別の目もりをタップすると □ になる。
6. **分数（3年）**：「3年」→「分数（1/5）」。目もりの数字が 1/5・2/5…4/5・1・6/5… と出る。
7. **ズーム（4年）**：「4年」→「兆（0〜1兆）」→「＋」を何回かおす。上に「🔍 ズームで 1目もり＝100億」→「10億」と出て、目もりが10等分される。「⟲ もとの大きさ」でもどる。タッチ画面では2本指でつまんで広げる。
8. **小数の誤差**：「まっさら」で 1目もりに 0.1 を入れ、ジャンプのはばを 0.1 にして「すすむ」を3回。式が「0.1 × 3 ＝ 0.3」、下に「0.1 ＋ 0.1 ＋ 0.1 ＝ 0.3」になる（0.30000000000000004 にならない）。
9. **がい数（4年）**：「がい数（四捨五入）」で、3700 は「4000に ちかい」、4320 は「4000に ちかい」と出る。
10. **二重数直線（5・6年）**：「5年」→「割合（600円の0.4）」で、上の「？」をタップすると 240。「6年」→「分数×分数」で、3/4m の上の「？」が 3/10。
11. **URL**：ピンを立ててから「🔗 URL」→ 新しいタブにはりつけて開くと、同じ数直線・ピン・ジャンプになる。
12. **PNG**：「🖼️ PNG」でダウンロードフォルダに画像ができる。
13. **せってい**：「数字の大きさ：大きい」で文字が大きくなる。「ふりがな：つけない」でルビが消える。「うごき：へらす」でジャンプがすぐにかかれる。
14. スマートフォンの幅（たて持ち）でも、横にはみ出さずに表示されること。

## 授業での使い方の例

### 1年：くり上がりのあるたし算（8＋5）

- **ねらい**：「10をつくってから、のこりをたす」方法を、数直線のジャンプで見る。
- **進め方**
  1. 「8＋5（10を つくって）」を電子黒板に映します。「8から5すすむと、どこかな？」と予想させます。
  2. 「すすむ ➡」をおす前に「10まであといくつ？」と問います。おすと 8 → 10 で一度止まり、「＋2」「＋3」の2つの弧が出ます。
  3. 式の下の「（8 ＋ 2 ＝ 10、10 ＋ 3 ＝ 13）」を、ブロック操作（さくらんぼ計算）と結びつけます。
  4. はじめ・はばを変えて（9＋4、7＋6 など）、子どもがタブレットで試します。「13−5（10に もどって）」でひき算（減減法）も同じように見せられます。

### 2年：1000までの数の目もりを読む

- **ねらい**：1目もりの大きさに注意して、数直線の目もりを読む。
- **進め方**
  1. 「□に あてはまる 数」で、100 の間が10に分かれていることから 1目もり＝10 を見つけます。
  2. □ を予想してからタップで確かめます。ア（450）・イ（820）は、100 のまとまりと 10 のいくつ分で説明させます。
  3. 「🙈 数字を かくす」で別の目もりを □ にして、子ども同士で問題を出し合います。1目もりを 100 に変えると、同じ □ でも読み方が変わることにも気づかせます。

### 3年：かけ算をジャンプで見る・小数と分数

- **ねらい**：3×4 は「3の4つ分」。数直線では「3ずつ4回とぶ」と表せる。
- **進め方**
  1. 「かけ算 3×4」で「すすむ ➡」を1回ずつおし、3・6・9・12 と言いながら進みます。式が「3 × 4 ＝ 12」と「3＋3＋3＋3＝12」の2行で出ます。
  2. はばを 4 にして「3回 すすむ」と 4×3＝12。同じ12に着くことから、かけ算のきまり（交換法則）を話し合います。
  3. 「小数（0.1）」「分数（1/5）」では、1を10等分・5等分した1つ分であることをピンで確かめます。「1目もりは いくつ？」で、上の「？」をかくしたまま目もりを読む練習をします。

### 4年：億・兆、がい数

- **ねらい**：大きな数も、1目もりの大きさに着目すれば数直線で表せる。四捨五入は「どちらの目もりに近いか」。
- **進め方**
  1. 「兆（0〜1兆）」で 1目もり＝1000億 を確かめ、ズームで 100億・10億 の目もりが出てくる様子を見せます（10倍ごとに位が1つ下がる）。
  2. 「がい数（四捨五入）」で、3700 は 3000 と 4000 のどちらに近いか、「まん中（3500）」より右か左かで考えます。ピンをドラッグして 3500 ちょうどにすると、四捨五入では大きいほうになることを確かめます。
  3. 「千の位まで」を「百の位まで」に変えると、同じ数でもさかい目が変わることを見せます。

### 5年：割合の二重数直線

- **ねらい**：もとにする量を 1 とみたとき、くらべる量がいくつにあたるかを二重数直線で表す。
- **進め方**
  1. 「割合（600円の0.4）」で、下の割合の線の 1 と上のねだんの線の 600 が対応していることを確かめます。
  2. 0.4 の上の「？」を予想させ、式（600×0.4）を考えてからタップで確かめます（240）。
  3. ピンを 1.2 などに立てて「1より大きい割合」も扱います。「分数と小数」では、2/5 と 0.4 が同じ位置にあることをピンで確かめます。

### 6年：分数のかけ算・わり算、比例

- **ねらい**：1mあたりの重さと長さの関係を二重数直線に表し、かけ算になるか・わり算になるかを判断する。
- **進め方**
  1. 「分数×分数」：1m ↔ 2/5kg を確かめ、3/4m は 1m より短いので答えは 2/5 より小さいと見通します。式 2/5×3/4 を立ててから「？」で 3/10 を確かめます。
  2. 「分数÷分数」：3/4m ↔ 3/5kg から 1m の重さを求めます。1m は 3/4m より長いので答えは 3/5 より大きいと見通し、式 3/5÷3/4 を立てます（答え 4/5）。
  3. 「比例（1分で3L）」：4分・7分の「？」を求め、時間が2倍・3倍になると水の量も2倍・3倍になることを、ピンを動かしながら確かめます。

## 注意

- 状態は URL にだけ保存されます（ブラウザには、ふりがな・音などの「せってい」だけを保存します）。URL を保存しないでページを閉じると、ピンやジャンプは消えます。
- ピンのラベルは URL に入るので、児童の名前などは書かないでください。
