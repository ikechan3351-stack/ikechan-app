# 因数分解パズル（タイルをしきつめて、多項式を因数分解する）

中学3年「多項式の因数分解」のアプリです。
*x*²＋5*x*＋6 のタイルを長方形にしきつめると、縦と横の長さが因数になること（(*x*＋2)(*x*＋3)）を見てから、
「かけて *q*、たして *p*」の2つの数さがし → どの方法を使うかの判断（共通因数 → 公式 → *x*²＋(*a*＋*b*)*x*＋*ab*）→ 展開による検算 → 応用（共通因数＋公式・おきかえ）へ進みます。
展開の「乗法公式タイル」（3-01）と対にして使います（画面の下にリンクがあります）。

## 基本情報

- **ファイル**：本体 `因数分解パズル.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）・スマホ。
- **URL の設定**
  - `?teacher=1` … 先生モード（各パートの「▶ 解き方を自動再生」・ワークシートのヒントと解答例）
  - `?part=1`〜`5` … はじめに開くパート
  - `?ws=0` … ワークシートをとじて開く
- **保存**：つまずきの記録とワークシートは localStorage（キー `ikechan-math-因数分解パズル`）。

## 使い方

### ① タイル（長方形にしきつめる）
- *x*² のタイル（大きな正方形）1まい、*x* のタイル（しま模様の長い棒）*p* まい、1 のタイル（小さな正方形）*q* まい。
- *x* のタイルを **x² の右（たて）** か **x² の下（よこ）** へドラッグ（タップでえらんでから場所をタップ、または「→ *x* を右へ」「↓ *x* を下へ」ボタンでも可）。
- 右に *R* まい・下に *B* まい置くと、右下のすみに *R*×*B* マスができます。「▦ 1 をしきつめる」（または 1 のタイルをドラッグ・タップ）でうめます。
  - ぴったり → 緑のわくの長方形。縦 *x*＋*B*、横 *x*＋*R* → 因数分解した式。縦と横が同じなら **正方形**（(*x*＋2)² など）。
  - たりない／あまる → ✖ と赤紫の点線で表示。ためした分け方は「右・下・いる 1 のタイル（右×下）」の表にのこります（② 和と積 へのかけはし）。
- 置いたタイルをタップ（またはトレイへドラッグ）すると、もどります。
- 式は 8 つ＋「ちょうせん *x*²＋4*x*＋5」（しきつめられない式。「🙅 しきつめられない」で判定）。🎲 でべつの式。
- 「*x* の長さ」スライダー（数の入力つき）：長さを変えてもしきつめ方は同じ → どんな *x* でも成り立つ。
- 広い画面ではトレイ（のこりのタイル）は図の右、せまい画面では図の下に出ます。

### ② 和と積
- *x*²＋*p**x*＋*q* について、かけて *q* になる整数の組を **ぜんぶ**（負の数もふくめて）表に出します。
- 「たすと？」で和を出し、*p* になる組の「これ！」を押す → (*x*＋*a*)(*x*＋*b*) ができる。符号が逆の組をえらぶと「符号が逆」と出て、符号のきまり（*q* が＋なら同じ符号…）を表示。
- 右の欄で因数分解した式を書いて「たしかめる」と、展開した検算の式も出ます。
- 数：ぜんぶ＋／−もある／まぜる。

### ③ 型えらび
- 式を見て「共通因数／2乗の差／完全平方式／*x*²＋(*a*＋*b*)*x*＋*ab*」からえらぶ → 理由と公式が出る → 答えを書く。
- *x*²−9 や *x*²＋6*x*＋9 で「*x*²＋(*a*＋*b*)*x*＋*ab*」をえらぶと「△ それでもできる。でも公式の方がすぐ書ける」。
- 右上に正解数（その回の答えで1問と数える）。

### ④ チェック（展開して検算）
- 式と、答えの候補3つ（正しいもの1つ＋よくあるまちがい2つ）。「🔍 検算する」で分配法則 → 同類項をまとめる → 「もとの式にもどった／ちがう」。
- 下の「自分の答えを検算する」では、もとの式と因数分解した式を自由に入れて検算できます。

### ⑤ 応用
- **共通因数＋公式**（例 2*x*²−8）：① くくり出す（2(*x*²−4)）→ ② かっこの中を公式で（2(*x*＋2)(*x*−2)）。いきなり最後まで書いても正解。
- **おきかえ**（例 (*x*＋1)²＋5(*x*＋1)＋6）：① *x*＋1 を *M* とおく → ② *M* の式を因数分解 → ③ *M* をもどして整理。おきかえる部分は黄色でしめします。

### 共通
- どのパートも「↶ ひとつもどす」「⟲ もういちど」「🎲 べつの式」があります。
- 答えの欄の下にキーボード（*x*・²・かっこ・数）。× は書かなくてよい。*x*² は `x^2` でも `x²` でも。

## 授業例（50分）

1. （5分）ワークシートの予想「*x*²＋4*x*＋4 は何の2乗？」
2. （10分）① で *x*²＋5*x*＋6 → 長方形。*x*²＋4*x*＋4 → 正方形 (*x*＋2)²。「1 のタイル＝右×下」「*x* のタイル＝右＋下」をことばにする。
3. （10分）② 和と積：−もある で符号のきまりを見つける。
4. （15分）③ 型えらびを5問 → まちがえたら ④ で検算。
5. （10分）⑤ 応用。ワークシートのまとめ。

## 正しさとじっさいとのちがい

- 係数はすべて整数で、計算はふつうの整数の計算（小数を使わない）なので、厳密です。
- 問題は答え（因数分解した形）を先に決めてから式を作ります。同じ問題は続けて出ません。
- 「正解」は、①展開するともとの式にもどる、②かけ算の形、③どの因数にも共通因数が残っていない・2次の因数が残っていない、のすべてを満たすとき。因数の順番や (*x*＋3)(*x*＋3) と (*x*＋3)² のちがいは問いません。
- タイル（①）は係数がすべて正、*x*² が1まいの式だけ（負のタイル・ゼロ対は使わない）。*x* のタイルの長さは決まっていない（スライダーで変えられる）。
- 文字は *x*（おきかえでは *M*）の1種類だけ。*x*²−9*y*² のような2文字の式はあつかいません。

## つまずき検知の一覧

| 型 | 検出のしかた | 例 |
|---|---|---|
| 🧺 共通因数のくくり出し忘れ | 展開するともとの式なのに、かっこの中に共通な数や *x* が残る | 2*x*²−2*x*−12 → (2*x*＋4)(*x*−3) |
| ± 和と積の符号まちがい | 2次の係数と定数項の大きさは合うのに符号がちがう／② で和が −*p* の組をえらんだ | *x*²−*x*−6 → (*x*＋3)(*x*−2) |
| 🫥 くくり出した係数の落とし | 展開すると、もとの式の整数分の1 | 2*x*²−8 → (*x*＋2)(*x*−2) |
| 🔁 2乗の差と完全平方式のとりちがえ | 定数項の大きさは合うのに、*x* の項がある／ない がちがう。③ で2つをとりちがえた | *x*²−9 → (*x*−3)² |
| ⏸ まだ因数分解できる | 展開すると合っているが、かっこの中に因数分解できる2次式が残る | 2(*x*²−4) |
| 🔎 型のえらびまちがい | ③ で使えない型をえらんだ | *x*²−81 に「共通因数」 |
| ✏️ 計算・書きまちがい | 上のどれでもないまちがい | |

- 「あなたのつまずき」に、型の名前・あなたの答え・直し方と、「🔁 この型を練習」（その型が出やすいパート・問題）、「👀 タイル／表／検算で確かめる」ボタンが出ます。
- 型ごとの回数は「つまずきの記録」にのこります（「記録を消す」で消せます）。
