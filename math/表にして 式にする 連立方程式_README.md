# 表にして 式にする 連立方程式（x・y をきめる → 関係を2つ見つける → 表 → 式 → 解く → 合うか）

中学2年「連立方程式の利用（文章題の立式）」のアプリです。中1「線分図ビルダー」（`線分図ビルダー.html`）の作り（何を x にする？・答えを先に決めて作る合う／合わない問題・「答えは問題に合う？」・3段階のヒント）を引きつぎ、線分図のかわりに**表**で整理します。

## 基本情報

- **ファイル**：本体 `表にして 式にする 連立方程式.html`、共通部品 `math-render.js`（数式・分数）・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中2）から開けます。
- **画面のならび**：広い画面は 左＝問題・x と y・関係／中央＝表と式／右＝解く・合うか・答え の3列。タブレット横向きは2列（その下に解く・答え）、スマホは1列。
- **URL の設定**
  - `?teacher=1` … 先生モード（つぎの問題を 合う／合わない でえらぶ・最後まで自動で見せる・答え・この端末のつまずきの合計）
  - `?ws=0` … ワークシートをとじて開く
  - `?debug=1` … 動作確認用（`window.__dbg`。授業ではつかわない）

## 問題の型（答えを先に決めて作る。型ごとに「合う」「合わない」が交互に出る）

| 型 | 問題 | x・y | 2つの式 | 合わない問題 |
|---|---|---|---|---|
| ① 代金・個数 | 1個120円と1個80円をあわせて12個、1160円 | それぞれの個数 | *x*＋*y*＝12、120*x*＋80*y*＝1160 | 個数が ○.5 個／負の個数 |
| ② 速さ・時間・道のり | 分速60mで歩き、分速200mで走って、全部で D m・T 分 | 歩いた・走った**道のり**（または**時間**。どちらでも正解） | *x*＋*y*＝D、*x*/60＋*y*/200＝T | 走った時間が負 |
| ③ 割合・増減 | 昨年 N 人、男子 a% 増・女子 b% 減で全体 d 人増減 | 昨年の男子・女子の人数 | *x*＋*y*＝N、0.05*x*−0.1*y*＝d | 増えた・減った人数が小数 |
| ④ 食塩水（発展） | a% と b% をまぜて c% を W g | それぞれの食塩水の重さ | *x*＋*y*＝W、0.05*x*＋0.08*y*＝食塩の重さ | 重さが負（c が a と b の間にない） |
| ⑤ 整数の桁 | 各位の数の和 S、入れかえると D 大きい | 十の位の数・一の位の数 | *x*＋*y*＝S、(10*y*＋*x*)−(10*x*＋*y*)＝D | 位の数が小数／一の位が 10 以上 |
| ⑥ つるかめ | あわせて N 匹、足の数 L 本 | つるの数・かめの数 | *x*＋*y*＝N、2*x*＋4*y*＝L | 0.5 匹／つるが負の数 |

## 使い方

1. **① x・y をきめる**：「x にするもの」「y にするもの」をそれぞれえらびます。
   - 「りんご」のように、ものの名前だけをえらぶとつまずきになります。数量（〜の数）をえらびます。
   - わかっている数（1個の値段・合計）をえらぶと、「もうわかっている数」と説明が出ます。
   - x と y がちがう種類の量のとき（時間と道のり）も注意が出ます。
   - きまると「りんごの数を x 個、みかんの数を y 個 とする」と出ます。
2. **② 等しい関係を2つ見つける**：問題文の語句をタップします。
   - 合計・全体の語句なら ①（オレンジ・実線）・②（青・点線）の色がつき、ことばの式（りんごの数＋みかんの数＝12）が出ます。
   - 「1個120円」のような材料の語句をタップすると、「1個あたりの値段。個数をかけると代金になる材料」と説明が出ます。
3. **③ 表で整理**：たてに もの（りんご・みかん・合計）、横に 1つの値段・数・代金（単位つき）をならべます。
   - 問題にある数は、はじめから入っています。空いたところに 120*x*・*x*/60・0.05*y* などを入れて「✔ 表をたしかめる」（Enter でも可）。
   - 同じ行のほかの列の量を入れると、「単位がちがう」のつまずきになります。
4. **④ 2つの式**：式1・式2 に書きます（キーボードか、下の x・y・数字のボタン）。
   - 順番がちがっても、両辺を何倍かしても、左右を入れかえても正解にします。
   - 2つとも合うと、連立方程式が大かっこで出ます。
5. **⑤ 解く**：*x*、*y* の値を入れます。まちがえると、代入してどちらの式が成り立たないかを出します。2回まちがえると「答えを見る」が出ます。
6. **⑥ 答えは問題に合う？**：量（人数・個数・位の数 など）を見て、合う／整数にならない／負の数／範囲をこえる をえらびます。
7. **⑦ 答え**：合わない問題では「連立方程式の解は〜だけれど、〜なので、この問題に合う答えはない」と出ます。

- **ヒント3段階**（💡）
  - ① 表：表がうまります。
  - ② 関係：2つの関係に色がつき、ことばの式が出ます。
  - ③ 式：2つの式が出ます。
  - x・y をきめる前は「たずねられている2つの数量を x・y にしよう」と出ます。
- 「↶ ひとつもどす」「⟲ もういちど」「🎲 新しい問題」。

## ワークシート

- もんだい：「1個120円のりんごと1個80円のみかんを、あわせて12個買ったら、代金は1160円でした。」x と y を何にすると、連立方程式を立てやすいだろうか？
- ① 予想：りんごの数を x 個、みかんの数を y 個／りんごの代金を x 円…／りんごを x、みかんを y／わからない
- ② 操作：「📄 ワークシートの問題」で ⑥ まで進めて「＋ 記録する」（問題の型・x・y にしたもの・連立方程式・解・問題に合う？）。
- 答え：りんご5個、みかん7個。先生モードではヒントと解答例が出ます。
- 保存キーは `ikechan-math-表にして 式にする 連立方程式`（できた問題・つまずきの回数もこの中）。

## 授業での使い方の例（50分）

1. **予想（5分）**：ワークシートの問題で「りんごを x」と「りんごの**数**を x 個」のちがいを話し合う。
2. **関係と表（15分）**：② で語句をタップして関係を2つ見つける。③ の表を全体でうめ、列ごとに単位を言わせる。個数の列 → *x*＋*y*＝12、代金の列 → 120*x*＋80*y*＝1160。
3. **個人で練習（20分）**：① ⑥ → ② ③ → ⑤。合わない問題（0.5匹・人数が小数）では、⑥ で「解けても答えにならない」ことを体験させる。速い生徒は ④ 食塩水（発展）。
4. **まとめ（10分）**：ワークシートに「x・y のおき方」「表の同じ列から式」「答えのたしかめ」を書く。

## 正しさについて（※じっさいとのちがい）

- 計算はすべて分数（Fraction）で厳密に行います。% の係数は小数（0.05）で見せます。
- 式は1次式だけ読みます（数・x・y・＋−×÷・かっこ・小数・x/60）。x×y や文字でわる式はエラーにします。
- 速さの問題は「道のりを x・y」「時間を x・y」のどちらでも正解にしています。ほかの型は、たずねられている数量を x・y にする置き方だけを正解にしています（ほかの置き方でも解けることはあります）。
- 人名・品物・ねだんは架空のものです。食塩水は発展の内容です。

## つまずき検知の一覧

| 型 | 見つけ方 | 例 |
|---|---|---|
| x・y の意味を決めずに式をつくった | ① をきめないまま、表や式を「たしかめる」 | |
| x・y を、ものの名前にした | ① で「りんご」「つる」などをえらんだ | |
| 単位がちがう数を、同じ式に入れた | 式：個数の和＝代金 など／表：代金の列に x | *x*＋*y*＝1160 |
| x と y を、決めたものと逆に使った | 式・表が、x と y を入れかえたものと同じ | 80*x*＋120*y*＝1160 |
| 時間＝道のり÷速さ を、かけ算にした | ② 速さで、道のりを x にしたのに 60*x*＋200*y*＝T | |
| % を小数（分数）にしわすれた | ③④ で 5*x*−10*y*＝d、表に 5*x* | |
| 減ったのにたした（増減の表し方） | ③ で 0.05*x*＋0.1*y*＝d や 1.05*x*＋0.9*y*＝d | |
| ひき算の順番が逆 | ⑤ で (10*x*＋*y*)−(10*y*＋*x*)＝D | |
| 計算・式のまちがい | ⑤ 解く でまちがえた／⑤ 整数の桁で *x*＋*y*＝D | |
| 合わない答えを「合う」とした（その逆・理由のとりちがえ） | ⑥ | 0.5 匹を「合う」 |

つまずきは「あなたのつまずき」に回数と説明が出て、「この型の類題」で同じ型の問題になります。
