# 平行線と角（対頂角・同位角・錯角を動かして確かめる）

中学2年「平行と合同」のアプリです。2本の直線 ℓ・m に1本の直線 n（横断線）が交わる図で、8つの角 ∠a〜∠h を動かしながらくらべます。対頂角が等しいこと、平行線の同位角・錯角が等しいこと、その逆（同位角・錯角が等しければ平行）を確かめ、最後に補助線を引いて角度を求めます。

## 基本情報

- **ファイル**：本体 `平行線と角.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中2・図形）から開けます。
- **画面のならび**：広い画面は 左＝図・右＝パネル の2列。せまい画面は1列（図の下にパネル）。
- **URL の設定**
  - `?teacher=1` … 先生モード（答え・自動で見せる・つまずきの合計・ワークシートのヒントと解答例）
  - `?ws=0` / `?ws=1` … ワークシートをとじて／ひらいて開く

## 角の名前

- 上の交点（ℓ と n）のまわりに ∠a（右上）・∠b（左上）・∠c（左下）・∠d（右下）、下の交点（m と n）に同じ位置で ∠e・∠f・∠g・∠h。
- **対頂角**：a と c、b と d、e と g、f と h（X の形・紫のあみ目）
- **同位角**：a と e、b と f、c と g、d と h（F の形・オレンジのしま）
- **錯角**：c と e、d と f（Z の形・青の水玉）
- 色だけでなく、模様・太線の形（F・Z・X）・「同」「錯」「対」の文字でも区別しています。

## 使い方

### 上の道具（どのパートでも）
- **🔍 角を調べる**：オンにして角をタップすると、その角が黄色になり、対頂角・同位角・錯角の関係にある角が光ります（下に ことばでも出ます）。
- **📐 分度器**：タップした角に分度器を当てて読みます（④ では正解したあと x に当たります）。
- **🔢 角度の数**：図の中の数を見せる／かくす（予想させるときはかくす）。
- **すいつく あり／なし**：つまみとスライダーが 5° ごと／1° ごと。④ の補助線は「あり」のとき平行と折れ曲がった点にすいつきます。
- **↶ ひとつもどす／⟲ もういちど**、**📄 ワークシートの問題**（② の錯角 ∠d・∠f にしてワークシートをひらく）。

### ① 対頂角
- n のつまみ（オレンジ）・ℓ のつまみ（灰色）、またはスライダー／数で角を変えます。∠a＝∠c、∠b＝∠d がいつも表示されます。
- 「🤔 なぜ等しい？」：① ∠a＋∠b＝180° ② ∠b＋∠c＝180° ③ どちらも 180°−∠b なので ∠a＝∠c、を順に色で見せます。

### ② 同位角・錯角
- 「同位角／錯角／対頂角」と組（∠a と ∠e など）をえらぶと、その2つの角に模様と F・Z・X の太線がつき、大きさをくらべます。
- **m の傾き（ℓ とのずれ）**：0° のとき平行（＞＞ の印）。平行でないときは「この先で交わる」「ここで交わる」が出て、同位角・錯角は等しくなりません。
- 「📏 平行にする」「🎲 ばらばらにする」、n の向き、図全体を回す（平行＝水平 と思いこまないように）。8つの角の表もあります。

### ③ 平行と言える？（逆）
- **🔧 そろえてみる**：m のつまみ（青）を回して、同位角（または錯角）を等しくします。そろった瞬間に平行になり、「きまり（平行線になる条件）」が出ます。
- **❓ 言える？ クイズ**（6問）：2つの角の大きさを見て「言える（同位角が等しい）／言える（錯角が等しい）／言えない」をえらびます。対頂角が等しいだけの「わな」の問題も入っています。答えると F・Z の形と、交わる場所が出ます。

### ④ 角度を求める
| 種類 | 図 | 答え |
|---|---|---|
| 基本 | ℓ // m と n。1つの角から x | 対頂角・同位角・錯角は等しい／となりは 180°− 。理由もえらぶ |
| 折れ線（くの字） | A（ℓ 上）→ P → B（m 上） | x ＝ α ＋ β |
| 折れ線（2回折れる） | A → P → Q → B | P の下の部分 ＝ ∠P − α、x ＝ その角 ＋ β |
| ブーメラン形 | P が ℓ・m の外がわ（「く」の字が外に出た形） | x ＝ β − α |
| 三角定規 | 45° と 30°・60° の三角定規を ℓ・m にあわせる | x ＝ 三角定規の角の和（C・P・D が一直線なので 180° からひいても求まる） |

- 図の上でドラッグすると補助線が引けます。ℓ に平行で、折れ曲がった点を通ると緑の点線になり、x が2つに分かれます。
- 分かれた角ごとに「○○の角との関係は？（同位角／錯角／対頂角）」をえらぶと、大きさが図に書きこまれます。
- 「∠x ＝ □°」に入れて「✔ こたえ合わせ」。補助線なしで答えてもかまいません。
- 💡 ヒント（3段階）：どこに引くか → 灰色の点線で場所を見せる → 補助線を自動で引く（基本は 形を見せる → 答えを入れる）。
- 問題は角を 5° ごとに決めてから図を作るので、答えはいつも整数です。左右反転もまじります。同じ問題は続けて出ません。

## 授業での使い方（例）

1. ① で対頂角。n を回しても ∠a＝∠c。「なぜ？」で一直線（180°）から理由を説明（証明の入口）。
2. ワークシートの予想「平行でないとき、錯角は等しい？」を書かせる。
3. ② でずれを 15°→10°→5°→0° と変えて記録。∠d と ∠f の差が「ずれ」と同じになることにも気づかせる。
4. ③ のそろえてみる → クイズで「逆」と対頂角のわなを確認し、ワークシートにきまりをまとめる。
5. ④ で補助線。くの字 → ブーメラン形 → 2回折れる と進め、「なぜその位置に引くのか」を話し合う。

## 先生モード（`?teacher=1`）

- 各パートの答え・見せ方のめやすを表示します。
- **▶ 自動で見せる**：① n を回し、理由を3段階で表示 ② m を平行までゆっくり動かす ③ 同じく平行まで動かす／クイズの答えを出す ④ 補助線を引き、分かれた角を書きこみ、答えを出す。
- 「この端末のきろくを消す」で、つまずき・正解の数をリセットします。

## つまずき検知（あなたのつまずき）

| 型 | 見つけるところ | 練習へ |
|---|---|---|
| 同位角と錯角の取りちがえ | ③ クイズで理由を逆にえらんだ／④ 関係・理由で逆をえらんだ | ② 錯角をくらべる |
| 等しい角と「180° −」の取りちがえ | ④ 答えが 180° − 正しい値／一直線の関係のえらびまちがい | ④ 基本 |
| 平行でないのに 平行と考えた | ③ クイズで、等しくないのに「言える」 | ② 平行でない図 |
| 対頂角が等しいから平行、と考えた | ③ クイズの対頂角の問題で「言える」 | ③ クイズ |
| 等しいのに 平行と言えなかった | ③ クイズで、等しいのに「言えない」 | ③ そろえてみる |
| 補助線の位置 | ④ 平行だが、折れ曲がった点を通らない補助線 | ④ くの字 |
| 補助線が平行になっていない | ④ ななめの補助線 | ④ くの字 |
| たす・ひくの取りちがえ | ④ くの字で差、ブーメランで和、2回折れるで符号ちがい | ④ ブーメラン形 |
| 関係・計算のまちがい | 上のどれにも当てはまらないまちがい | 同じ型の問題 |

記録は `localStorage` の `ikechan-math-平行線と角`（ワークシートと同じ保存キー）に入ります。

## ※じっさいとのちがい

- 角度は 1° ごとの整数で動かし、計算もすべて整数の度で正確に行っています。
- 直線は画面の中だけかいています。「どこまでのばしても交わらない」ようすは、画面のはしの「この先で交わる」表示で代わりに見せています。
- 「同側内角（合わせて 180°）」ということばは使っていません（④ では一直線の 180° として扱います）。

## 改造のしかた

- ④ の問題は `genBasic`・`genKuno`・`genZig`・`genBoom` で作っています。角の範囲は `range(25, 70)` などの数を変えます。
- つまずきの型は `TRIPS`、クイズの種類は `genQuiz` の `kinds` にあります。
