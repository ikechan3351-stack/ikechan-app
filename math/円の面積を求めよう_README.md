# 円の面積を 求めよう

小学6年生の算数、東京書籍「新しい算数」6年「円の面積」で使う教材です。次のことを体験します。

- 円の面積は「半径×半径」の正方形の **約3.14こ分**（2こ分より大きく、4こ分より小さい）
- 方眼を数える・おうぎ形に分けてならべかえる・ぐるぐる円をひらく、どの方法でも **円の面積＝半径×半径×3.14**
- 半径・直径から円の面積を求める。半円・円の4分の1・組み合わせた形の面積を求める

## 基本情報

- **ファイル**：`円の面積を求めよう.html`。共通ファイル `worksheet.js`・`worksheet.css` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。図はすべて SVG。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」（6年）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。本文20px・ボタン48px以上。せまい画面では図の板だけ横にスクロールします（ページははみ出しません）。
- **漢字**：説明の文に出る 円周・直径・半径・面積・正方形・長方形・三角形・公式・底辺・予想・方眼 に自動でふりがなをつけます。図の中のふりがなもふくめ、「せってい」で消せます。
- **ワークシート**：よそう → やってみる → わかったこと → まとめ（小学生向け）。図の板を広く使うため、はじめは閉じています。「きろくする」で、方法・半径・面積・わかったことを記録します。
- **保存**：ワークシートと「せってい」を、このブラウザの localStorage（キー：`ikechan-math-円の面積を求めよう`）に保存します。もんだいの成績は保存しません。
- **せってい**：もんだいの数（5・10）・ふりがな・こうかおん・うごき（「へらす」で、数える・ならべかえる・ひらく がすぐ終わる）。
- `円の面積を求めよう.html#guruguru` で開くと、④ ぐるぐる円を ひらこう から始まります。

## 5つの画面

### ① 正方形で はさんで 見当を つけよう

- 「半径×半径」の正方形（赤）で、外がわの正方形（4こ分）と内がわの正方形（2こ分）で円をはさみ、約3.14こ分にたどりつきます。「▶ つぎへ」「◀ もどる（ひとつ もどす）」で1ステップずつ。

### ② 方眼を 数えよう

- 半径10cmの円の4分の1を、マスの大きさ（1cm・5mm・2mm）をえらんで数えます（ふちのマスは0.5）。「⚡ いっきに」で結果だけ、「🔄 もどす」で数える前に。マスを小さくすると314cm²に近づきます。

### ③ おうぎ形に 分けよう

- 分ける数（8〜64）をえらんで「▶ ならべかえる」。たて＝半径、横＝円周の半分＝半径×3.14 の長方形に近づきます。「⏪ 円に もどす（ひとつ もどす）」。

### ④ ぐるぐる円を ひらこう

- 半径・本数をえらんで「▶ ひらく」。円をトイレットペーパーのように切ってひらくと、底辺＝円周、高さ＝半径 の三角形になります（円周×半径÷2）。「⏪ まきもどす（ひとつ もどす）」。

### ✏️ もんだい（新しく足した画面）

| 種類 | 例 | 答え方 |
|---|---|---|
| 半径から | 半径7cmの円の面積 | 数を入れる（2回まで） |
| 直径から | 直径20cmの円の面積 | 数を入れる（2回まで） |
| 半円 | 半径6cmの半円の面積 | 数を入れる（2回まで） |
| 円の 4分の1 | 半径4cmの円の4分の1（おうぎ形） | 数を入れる（2回まで） |
| 組み合わせた 形 | 1辺10cmの正方形から、半径10cmの円の4分の1を切りとった形 | 数を入れる（2回まで） |

- 図の板に問題の形が出て、せいかいすると面積の「？」に答えが入ります。5問なら1つずつ、10問なら2つずつ（「せってい」でえらべます）。

## つまずき検知

| 型の名前 | 見つけ方 |
|---|---|
| 直径と 半径の とりちがえ | 直径のまま 直径×直径×3.14 とした、半径を直径とみて ×2 してから計算した |
| 円周の 公式と まちがえる | 半径×2×3.14 や 直径×3.14（円周）を答えた |
| 半円の ÷2 わすれ | 半円・4分の1で円ぜんぶの面積を答えた、4分の1なのに ÷2 にした、組み合わせた形で円ぜんぶや半分をひいた |

- もんだいでは、見つけた型を「あなたの つまずき」として出し、次にその型の「にた もんだい」を1問足します。終わりに型ごとの回数と、「③ おうぎ形に 分けよう」へのボタンを出します。

## 先生モード（アドレスの最後に `?teacher=1`）

- 題名の横に「先生モード」のしるし。①〜④に「⏩ じどうで さいごまで」、もんだいに「💡 こたえ」。ワークシートに先生用のヒントと解答例が出ます。

## 授業での使い方の例

1. **見当をつける（1時間）**：「① 正方形で はさんで」で、円は「半径×半径」の正方形の2こ分より大きく4こ分より小さいことを確かめ、予想を立てる。「② 方眼を 数えよう」で約3.1こ分を確かめる。
2. **公式を導く（1〜2時間）**：「③ おうぎ形に 分けよう」で長方形（たて＝半径、横＝半径×3.14）、「④ ぐるぐる円を ひらこう」で三角形（円周×半径÷2）にして、半径×半径×3.14 を導く。
3. **いろいろな形の面積（1〜2時間）**：「✏️ もんだい」で、直径から・半円・4分の1・組み合わせた形を練習し、つまずきの型をふりかえる。

## 正しさと、じっさいとのちがい

- 円周率は 3.14 で計算しています（答えは小数第3位まで）。
- ② の方眼では、ふちにかかるマスを0.5として数えるので、本当の面積（314cm²）とは少しちがいます。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| 半径・直径 | 赤 | 線と「半径」「直径」の文字 |
| 円 | 緑 | 円の線 |
| 組み合わせた形の求める部分 | オレンジ | 色のついた面、のこりは白。切りとる円は点線 |
| 正解／まちがい | 緑／赤むらさき | ◎・△・✖ の記号 |
