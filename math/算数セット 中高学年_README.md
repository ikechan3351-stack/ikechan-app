# 📐 算数セット 中高学年

さんすうボード④⑤ と「方眼ボード」から、**小学3〜6年の図形で使うものだけを集めた入り口**です。最初にボードを選ぶだけで使えます。「さんすうセット ていがくねん」の中・高学年版です。

- 2026-11 に「算数セット 高学年」から名前をかえ、3年（④いろいたの 二等辺三角形・正三角形のしきつめ）を入れました。前のアドレス `算数セット 高学年.html` は新しいページへ自動で移ります。

- 新しいアプリではありません。中身はそれぞれの元のアプリと同じで、元のアプリもこれまでどおり残っています。
- **ファイル**：`算数セット 中高学年.html`（入り口）。ボードは同じフォルダの元のファイルを使います。ネット接続・外部ライブラリは不要です。
- 入れていないもの：①おはじき・②かぞえぼう・③おかね・⑥とけい（1・2年の内容のため）。

## 使い方

1. 入り口のカード（🔷色板・タングラム／🟠ジオボード／✂️方眼ボード）をタップする。
2. ボードが開く。使い方は元のアプリと同じ。
3. 左上の **🏠 ボードえらび** で入り口にもどる。

## しぼっているところ（中高学年モード）

入り口からは、ボードを `?high=1` をつけて開きます。この合図があるときだけ、つぎのように変わります。

| ボード | 中高学年モードでの変化 |
|---|---|
| ④ いろいた・タングラム | 学年は **3ねん**（二等辺三角形・正三角形のしきつめ）・**4ねん**（平行四辺形・台形・ひし形のしきつめ）・**5ねん**（合同な図形のしきつめ）だけ。3ねんから始まる。タングラムはそのまま使える |
| ⑤ ジオボード | いつも **高学年用**（きる・はる、長さ・角度・面積）。「だれ むけ」の切りかえと、はじめの「えらんでね」画面を出さない |
| 方眼ボード | いつも **小学生**。せっていの「学年（小学生／中学生）」の切りかえを出さない。📚お題の目次には **小学生のお題だけ**（いまは4〜6年）が出る |

どのボードでも、左上の「← トップ」が「🏠 ボードえらび」に変わります。

## 先生モード

- 入り口の右上の **🧑‍🏫 せんせい** を押すと、選んだボードが先生モードで開きます（アドレスに `?teacher=1` が入る）。
- ボードの中で先生モードを切りかえても、中高学年モードはそのまま続きます。

## つづきから（自動保存）

- ④⑤ のボードのようすは、ふつうの ④⑤ やていがくねん版とは**べつに**保存されます（保存のキーの最後に `-高学年` がつく。名前をかえる前のデータを引きつぐため、キーは前のまま）。
- そのタブで1回目に開いたときは「つづきから／あたらしく」を聞き、2回目からは聞かずに続きを開きます。
- 方眼ボードは、もともと自動保存をしないアプリです（お題を選んで使う）。

## しくみ（コードのつくり）

- 入り口：ボードの表 `BOARDS` からカードを作ります。ボードを足すときは、ここに1行足します。
- ④⑤：`const HIGH = …get('high') === '1'` で合図を読みとります。もどる先は `HUB`（ていがくねん・中高学年で切りかわる）。④は学年ボタンの `gList` と「3ねんから はじめる」行、⑤は `if (HIGH) LEVEL = 'high';` でしぼっています。
- 方眼ボード：`const HIGH = Q.get('high') === '1';` と `applySettings()` の中の「高学年（?high=1）から ひらいた とき」の部分です。
