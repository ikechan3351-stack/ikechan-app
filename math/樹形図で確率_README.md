# 樹形図で確率（場合の数と確率）

中学2年「確率」のアプリです。すべての場合を **樹形図** や **表** に整理して数え、**確率 ＝（条件に合う場合の数）÷（すべての場合の数）** を求めます。「同様に確からしい」の意味、取り出したものを「もどす／もどさない」のちがい、「起こらない確率」と「少なくとも〜」（発展）まで、5つのパートで学びます。

## 今ある教材との役割分担

| 教材 | 役割 |
|---|---|
| 小6 えだを のばして 並べ方と組み合わせ方（`えだを のばして 並べ方と組み合わせ方.html`） | 樹形図で場合の数を数える（この教材の前提） |
| サイコロ1万回ふってみた（`サイコロ1万回ふってみた.html`） | 何千回も投げて、相対度数が確率に近づく様子を見る |
| **樹形図で確率（これ）** | 樹形図・表で数えて確率を求める。練習問題・つまずき検知・ワークシートつき |
| 確率の実験室（2-18、予定） | コイン・くじ・袋・サイコロの多数回の実験 |
| 場合の数と確率ドリル（`確率ドリル.html`） | 場合の数と確率の10問ドリル。この教材の「つながる教材」と、練習問題の正解のあとからリンクしている |

## 基本情報

- **ファイル**：本体 `樹形図で確率.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **画面**：広い画面は2列（樹形図と表・実験など）、スマホはたて1列。
- **色のきまり**：自分でつけた ✓＝こい灰色、正しい ✓＝緑、もれ＝緑の点線の「!」、よけい＝赤紫の「×」、実験の結果＝金色。⑤ は「起こる」＝緑のしま＋✓、「起こらない」＝青の水玉＋◆。色だけでなく、記号ともようでも区別しています。
- **URL の設定**
  - `?teacher=1` … 先生モード（答え・自動で1ステップ進める・発問の例・この端末のきろく・ワークシートのヒントと解答例）
  - `?ws=0` … ワークシートをとじて開く
  - `?part=1`〜`5` … そのパートを開く（確率ドリルからのリンクで使う）

## 使い方

### ① 同様に確からしい
- **袋の玉**：赤・白・青の玉の数を −／＋ で変えられます。「赤か白の2通りだから 1/2？」を予想 → 「⚡ 100回」で実験 → 「🔢 1つ1つ区別して数える」で、玉に番号がついて 5通りが同じ程度に起こることがわかります。
- **コイン2枚**：「表表・表裏・裏裏の3通り → 1/3？」→ A・B と名前をつけると 4通り（樹形図）→ 1/2。
- **どちらのくじ？**：A（当2・は3）と B（当3・は5）。当たりの本数ではなく、2/5 と 3/8 を分母をそろえてくらべます。
- 実験のグラフに、予想（オレンジの点線）と確率（緑の線）が出ます。

### ② 樹形図で数える
- 問題：カードで整数・くじを同時に2本・玉を同時に2個・くじを順に2本（もどさない）・コインを3回。
- 条件をえらび、樹形図の右の「結果」をタップして ✓ → 「✔ 答え合わせ」。もれ・よけいがわかります。正しければ確率が分数で出ます（約分も）。
- 「🎲 実際に引いてみる」でカードがまざって引かれ、結果のルートが金色に光ります。「⚡ 10回まとめて」で記録をふやせます。

### ③ もどす・もどさない
- 玉3個（赤2・白1）／くじ5本（当2・は3）。左右に2つの樹形図がならびます。
- もどさないほうでは、同じものを2回取り出す枝が点線と × で消えます（「🙈 引けない枝をかくす」で、消したあとの樹形図にもなります）。
- 下の表で、すべての場合（3×3 と 3×2）と確率をくらべます。

### ④ 表で数える
- 2つのサイコロ（大・小）の 6×6 の表、2枚のコイン（A・B）の 2×2 の表。
- 表のマスと樹形図の結果は同じものです。どちらをタップしても ✓ がつきます。サイコロの樹形図は大の目ごとにたたんであり、大の目をタップするとその枝がひらきます。
- 「🎲 投げてみる」「⚡ 36回まとめて」で、結果が表と樹形図の両方で光ります。

### ⑤ 起こらない確率
- コイン3回・くじを同時に2本・サイコロ2つ（6の目／偶数）。
- ① 直接数える → ② 「1つも〜ない」を数える → ③ 1 − で求める（**発展**）の順にボタンを押します。（起こる確率）＋（起こらない確率）＝ 1 も表示します。

### ✏️ 練習問題
- 今のパートの問題が出ます。分子と分母をキーパッド（またはキーボード）で入れて「こたえる」。
- 「💡 ヒント」は3段階、「👀 図で確かめる」でその問題の場面を樹形図や表で見られます。

## つまずき検知の一覧

| 型 | 見つけ方 | もどる場所 |
|---|---|---|
| 同じに見えるものを区別しないで数えた | 色の数・表裏の数などで数えた答え（例：赤3白2 で 1/2、コイン2枚で 1/3） | ① コイン2枚（区別あり） |
| 同時に取り出すのに、順番ありの数え方とまぜた | 分子は順番なし・分母は順番あり（またはその逆）で数えた答え | ② くじを同時に2本 |
| 数えもれ・数えすぎ | 樹形図・表の答え合わせで もれ・よけいがある／どの型にも当てはまらないまちがい | ② カードで整数 |
| 約分していない | 値は合っているが約分していない | （説明だけ） |
| もどす・もどさないの取りちがえ | もう一方（もどす⇔もどさない）の答え | ③ 玉3個 |
| 大小2つのサイコロの目を区別しなかった | (1,6) と (6,1) を同じとして数えた答え。表で、片方だけに ✓ をつけた | ④ サイコロ 和が7 |
| 起こらない確率をそのまま答えた | 「1つも〜ない」確率を答えた | ⑤ コイン3回 |

きろくは localStorage の `ikechan-math-樹形図で確率` に、ワークシートといっしょに保存されます。

## 授業での使い方（例）

1. **導入（①）**：コイン2枚の問題で予想を挙手（1/3 が多い）。100回の実験を数回 → 1/2 に近づく → A・B と区別して 4通り。「同様に確からしい」をおさえる。
2. **展開（② ④）**：樹形図に自分で ✓ をつけて数える。サイコロ2つは表で。和が7のマスがななめにならぶことに気づかせる。
3. **くらべる（③）**：もどす／もどさないで、すべての場合と確率がどう変わるか予想してから確かめる。
4. **発展（⑤）**：「少なくとも」を直接数える → 起こらない方を数える → 1 − で求める。
5. **まとめ**：ワークシートに記録し、「確率は〜」の形でまとめる。練習問題で つまずきの型を確認。

## ※じっさいとのちがい

- 実験の結果はコンピューターの乱数で決めています。コイン・サイコロ・くじ・玉は、どの結果も同じ程度に起こるものとしています（本物は形のゆがみなどで少しずれることがあります）。
- ④ の樹形図は 36 本あると長すぎるので、大の目ごとにたたんで表示しています。
- 「少なくとも〜」を 1 − で求める方法は「発展」と表示しています（起こらない確率 ＝ 1 − 起こる確率 は教科書本文の内容です）。
