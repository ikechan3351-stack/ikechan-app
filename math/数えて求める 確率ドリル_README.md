# 数えて求める 確率ドリル（場合の数と確率）

中学2年「確率」の練習用ドリルです。1回 10問。すべての場合を樹形図や表で数えて、**確率 ＝（条件に合う場合の数）÷（すべての場合の数）** を求めます。まちがえ方から「つまずきの型」を見つけ、考え方を学ぶ教材「樹形図で確率」の、その場面にもどれます。

## 今ある教材との役割分担

| 教材 | 役割 |
|---|---|
| 小6 えだを のばして 並べ方と組み合わせ方 | 樹形図で場合の数を数える（前提） |
| 樹形図で確率（`樹形図で確率.html`） | 考え方を学ぶ（同様に確からしい・樹形図・もどす/もどさない・表・起こらない確率） |
| **数えて求める 確率ドリル（これ）** | 練習。10問・つまずき検知・問題番号でクラス全員が同じ問題 |

## 基本情報

- **ファイル**：本体 `数えて求める 確率ドリル.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **URL の設定**
  - `?teacher=1` … 先生モード（答え・自動で1ステップ進める・問題番号を決める・この端末のきろく）
  - `?unit=1`〜`5` または `?unit=mix` … その単元をえらんだ状態で開く
  - `?ws=0` … ワークシートをとじて開く

## 使い方

1. 単元をえらぶ：① 同様に確からしい／② 樹形図／③ もどす・もどさない／④ 表（サイコロ2つ）／⑤ 少なくとも（**発展**）／🔀 ミックス（①〜④。チェックを入れると ⑤ も入る）。
2. 「▶ 10問 スタート」。確率の問題は 分子と分母、「何通り？」の問題は数を1つ、キーパッド（またはキーボード）で入れて「こたえる」。
3. まちがえると、つまずきの型と説明が出て、もう1回答えられます。2回まちがえると答えが出て次へ進みます。点数は「1回目で正解した数」です。
4. 「💡 ヒント」は3段階。「👀 樹形図・表で確かめる」で「樹形図で確率」のその単元が別のタブで開きます。
5. 「↶ ひとつもどす」で前の問題を見なおせます（答えはかえられません）。「⟲ もういちど」で同じ10問をはじめから。
6. 結果の画面：問題ごとの ○×・自分の答え・正しい答え・つまずきの型。「🔁 まちがえた問題だけ もう一度」ができます。

### 問題番号（クラスで同じ問題）

先生モードの「🔢 問題番号を決める」で4けたの番号が出ます。黒板に書いて、生徒に「問題番号」の欄へ入れさせると、同じ単元ならクラス全員が同じ10問になります。空のままなら毎回ちがう問題です。

## つまずき検知の一覧

| 型 | 見つけ方 | 練習・もどる場所 |
|---|---|---|
| 同じに見えるものを区別しないで数えた | 色の数・表裏の出方などで数えた答え（赤3白2で 1/2、コイン2枚で 1/3 など） | ① ／ 樹形図で確率 ① |
| 同時に取り出すのに、順番ありの数え方とまぜた | 分子と分母で数え方（順番あり・なし）がちがう答え | ② ／ 樹形図で確率 ② |
| 数えもれ・数えすぎ | どの型にも当てはまらないまちがい | ② ／ 樹形図で確率 ② |
| 約分していない | 値は合っているが約分していない（2回までの答える回数には数えず、もう一度答えられる） | ― |
| もどす・もどさないの取りちがえ | もう一方（もどす⇔もどさない）の答え | ③ ／ 樹形図で確率 ③ |
| 大小2つのサイコロの目を区別しなかった | (1,6) と (6,1) を同じとして数えた答え（和が7 → 3/36 など） | ④ ／ 樹形図で確率 ④ |
| 起こらない確率をそのまま答えた | 「1つも〜ない」確率を答えた | ⑤ ／ 樹形図で確率 ⑤ |

「あなたのつまずき」の「🔁 この型を10問練習」で、その型が見分けられる問題を多めにした10問が出ます。きろく（つまずきの回数・最高点など）は localStorage の `ikechan-math-数えて求める 確率ドリル` に保存されます。10問おわるたびに、ワークシートの表に「単元・点数・つまずきの型」が記録されます。

## 授業での使い方（例）

- **授業の終わり10分**：「樹形図で確率」で学んだあと、その単元の10問。
- **全体の答え合わせ**：問題番号をそろえて解き、まちがいの多かった問題を全体で。先生モードの「自動で1ステップ」で答えを順に見せられます。
- **ふりかえり**：ワークシートの記録から、自分のつまずきの型をまとめる。

## ※じっさいとのちがい

- コイン・サイコロ・くじ・玉は、どの結果も同じ程度に起こるものとしています。
- 問題は乱数で作り、答えが 0 や 1 にならないものだけを出しています。同じ10問の中に同じ問題は入りません。
