# わけて あつめて 分数のわり算

小学6年生の算数「分数÷分数」（東京書籍 新しい算数 6年 50〜65ページ）と「分数の倍」（66〜69ページ）で使う教材です。次のことを体験します。

- 分数÷分数は、**わる数の分母をかけて、分子でわる**（面積図で「わける → あつめる」）
- それは、**わる数の逆数をかける** ことと同じ（二重数直線と、わり算のきまり）
- 整数÷分数、小数・整数がまじった **3つの数の計算**（わり算を逆数のかけ算にして、とちゅうで約分）
- 1より小さい数でわると、答えは**わられる数より大きくなる**こと
- **分数の倍**（何倍・くらべる量・もとにする量）

## 基本情報

- **ファイル**：`わけて あつめて 分数のわり算.html`。共通ファイル `math-render.js`（分数の表示と Fraction による正確な計算）・`worksheet.js`・`worksheet.css` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。面積図・テープ・数直線はすべて SVG でかいています。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」（6年）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。ボタンは48px以上。スマホのたて向きでも画面がはみ出しません。
- **漢字**：分数・分子・分母・整数・約分・逆数・倍 などにふりがなをつけています。「せってい」で消せます。
- **保存**：ワークシートと「せってい」を、このブラウザの localStorage（キー：`ikechan-math-わけて あつめて 分数のわり算`）に保存します。もんだいの成績は保存しません。

## 3つの画面

### ✂️ わけて あつめて（面積図）

- 「c/d dL で a/b m² ぬれるペンキ。1dLでは？」（はじめは 3/4 dL で 2/5 m²）。上のテープが dL、下の面積図が m²。
- **① わける**：オレンジの a/b m² を青い点線で c つに分け、1/d dL 分（青・しま）を出します。1m² が b×c マスに分かれ、1/d dL 分は a マス → a/(b×c) m²（式：a/b÷c）。
- **② あつめる**：1/d dL 分（a マス）を d こ集めて 1dL 分にします。1/d dL 分ごとに色と模様をかえて1m²の中にならべ、a×d マス → (a×d)/(b×c) m²（式：×d）。
- 式全体は a/b÷c/d ＝ a/b÷c×d ＝ (a×d)/(b×c)。わる数の分子（青）がわり算、分母（緑）がかけ算になることを色で見せます。
- 分子・分母は −・＋ か数の入力で変えます（分母2〜9、ぬれる広さは1m²より小さい分数、ペンキは2dLまで。1dLより多いときはテープを2dLまでのばします）。ちがう式を3つためすと、きまりのまとめが出ます。

### 📏 数直線と きまり

- **数直線と きまり**：二重数直線（上＝dL、下＝m²）で、c/d dL → 1dL を ×d/c の矢印で見せます。「つぎへ」で1行ずつ：
  1. a/b ÷ c/d ＝ ？
  2. ＝ (a/b × d/c) ÷ (c/d × d/c)（わられる数とわる数に同じ数をかけても答えは同じ）
  3. ＝ (a/b × d/c) ÷ 1
  4. ＝ a/b × d/c（わる数の逆数をかければよい）
- 分母を1にすると整数÷分数になります（わる数は 1/3〜3）。
- **答えの大きさ**：わられる数と答えを帯でくらべ、「わる数が1より小さいと、答えはわられる数より大きくなる」を出します。
- **3つの数の計算**：5つの式（0.6÷4/5×2/3、6÷0.4×2/9 のような小数・整数まじりもふくむ）と「🎲 べつの式」。「つぎへ」で、小数・整数を分数に → わり算を逆数のかけ算に（緑の字）→ 1つの分数にして、分子の数と分母の数をタップしてとちゅうで約分 → 答え、と進みます。

### ✏️ もんだい

5種類がまざって出ます（5問なら1つずつ、10問なら2つずつ。「せってい」でえらべます）。

| 種類 | 例 | 答え方 |
|---|---|---|
| 分数÷分数 | 6/7÷9/7 | 分子・分母のわく（2回まで） |
| 整数÷分数 | 3÷5/3 | 分子・分母のわく（2回まで） |
| 3つの数の計算 | 9/2÷6/5÷3/5 | 分子・分母のわく（2回まで） |
| 答えの大きさ | 2/5÷1/3 は 2/5 より大きい？小さい？ | 2つからえらぶ（1回） |
| 分数の倍（テープ図つき） | 赤は青の何倍？／赤は何m？／青は何m？ | 分子・分母のわく（2回まで） |

- 答えは分子・分母のわくに数字ボタンで入れます（整数のときは分母を空ける。PCは数字・Backspace・Enter、`/` か Tab で分子⇔分母）。
- 大きさは合っていても約分していないときは「約分して入れよう」と出し、まちがいの回数に数えません。
- 分数の倍のテープ図は、もとにする量（青・しま）に「1 と みる」と書き、わからない長さは「？」にしています。

## つまずき検知

| 型の名前 | 見つけ方 | 例 | 出す声かけ |
|---|---|---|---|
| 逆数の しわすれ・まちがい | 逆数にしないでかけた答え、わられる数を逆数にした答えを入れた（3つの数では ÷ を × のまま計算した答え） | 2/5÷3/4 → 3/10 | わる数の逆数をかける。わられる数はそのまま |
| わると いつも 小さく なる | 1より小さい数でわるのに「小さくなる」をえらんだ | 2/5÷1/3 → 小さくなる | 1より小さい数でわると大きくなる。1/2でわるのは「1/2がいくつ分」 |
| もとにする量の とりちがえ | 分数の倍で、何倍を逆にした／もとにする量を くらべる量×倍 で出した／くらべる量を ÷ で出した | 赤4/3m・青4/7m の何倍 → 3/7 | 「〇は△の何倍」の△がもとにする量。テープ図で1とみるほうを確かめる |

- 見つけた型は「あなたの つまずき」として出し、次にその型の「にた もんだい」を1問足します。
- 終わりの画面に型ごとの回数を出し、「📏 数直線と きまり」または「✂️ わけて あつめて」へもどるボタンを出します。

## 先生モード（アドレスの最後に `?teacher=1`）

- わけて あつめて：「▶ じどうで 見せる」で ① わける → ② あつめる を順に見せます。
- もんだい：「💡 こたえ」。ワークシートに、先生用のヒントと解答例が出ます。

## 授業での使い方の例

1. **分数÷分数の意味と計算（2時間）**：「わけて あつめて」で、1/4 dL 分を出してから1dL分に集める2段階を確かめ、マスの数から (a×d)/(b×c) を見つける。
2. **逆数をかける理由（1時間）**：「数直線と きまり」で、二重数直線の矢印と、わり算のきまりの4ステップを順に見せる。
3. **整数÷分数・3つの数（1〜2時間）**：分母を1にした整数÷分数、「3つの数の計算」でとちゅうの約分。
4. **答えの大きさ・分数の倍（2時間）**：帯のくらべで「わると大きくなる」場合を確かめ、「もんだい」の分数の倍でテープ図を読む。
5. **まとめ**：「もんだい」で練習し、つまずきの型をふりかえる。

## 正しさと、じっさいとのちがい

- 分数の計算は `math-render.js` の Fraction で正確に行っています（小数を使わないので誤差は出ません）。小数は分数になおしてから計算します。
- 式のとちゅうは約分しないで見せ（例：(2×4)/(5×3)）、そのあとに約分した答えを出します。
- ペンキは、どこも同じあつさでぬれるものとしています。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| わる数の分子／分母 | 青／緑 | 式の中の位置（わり算／かけ算） |
| 1/d dL 分 | 青 | しま模様、「1/d dL」の文字 |
| 1/d dL 分ごと（あつめる） | オレンジ・青・緑・むらさき… | ぬりつぶし・しま・点・こうし の模様 |
| もとにする量／くらべる量（テープ図） | 青／オレンジ | しま／ぬりつぶし、「1 と みる」の文字 |
| 約分した数 | 赤むらさき | もとの数に打ち消し線、上に新しい数 |
| 正解／まちがい | 緑／赤むらさき | ◎・✖・△ の記号 |
