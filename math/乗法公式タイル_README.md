# 乗法公式タイル（面積図で、展開の公式を見つける）

中学3年「式の展開」で、(*x*＋*a*)(*x*＋*b*)、(*x*＋*a*)²、(*x*−*a*)²、(*x*＋*a*)(*x*−*a*) を**長方形・正方形の面積図**で展開し、乗法公式を自分で導くアプリです。
タイルの見た目は中2「寄せて ならべて 式の計算」とそろえてあります。

## 基本情報

- **ファイル**：本体 `乗法公式タイル.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン・スマホ。
- **タイルの形**：1＝小さい正方形、*x*＝長い棒、*y*（2つめの文字）＝しま模様の棒、*x*²＝大きい正方形、*xy*＝ななめしまの長方形、*y*²＝しま模様の正方形。正＝オレンジ・実線、負＝青・点線＋「−」。
- **画面のならび**：左に面積図、右に「式の変化」と「展開した式を書こう」（せまい画面では 図 → 式 → 答え の順）。
- **URL の設定**
  - `?teacher=1` … 先生モード（①〜③ の手順の自動再生・★答えを見る・ワークシートのヒントと解答例）
  - `?part=1`〜`5` … はじめに開くパート
  - `?ws=1` … ワークシートをひらいて開く（ふだんはとじている）

## 使い方

### ① (x＋a)(x＋b)
- *a*・*b* をスライダー・数の入力・−／＋ボタンで変えます（−8〜8）。たて (*x*＋*a*)、横 (*x*＋*b*) の長方形が 4つの部分（*x*²・*ax*・*bx*・*ab*）に分かれ、式の変化 *x*²＋*ax*＋*bx*＋*ab* が連動します。
- 「🧲 *x* の項をまとめる」で、*ax* と *bx* のタイルが集まり (*a*＋*b*)*x* になります（符号がちがうときはゼロ対が ✕）。
- 部分をタップすると、同じ種類の部分が緑で光り、「3*x*＋2*x*＝5*x*」と出ます。

### ② (x±a)²
- (*x*＋*a*)²：1辺 *x*＋*a* の正方形。*ax* の長方形が 2つ あることが見えます。「⚖ *x*²＋*a*² とくらべる」で、*x*²＋*a*² だと たりない2つの長方形が赤紫になります。
- (*x*−*a*)²：*x*² の正方形から、たての帯（*ax*）→ 横の帯（*ax*）をひく → 右下の *a*² を **2回ひいた** → たしてもどす、の4手順（▶ つぎへ）。*x*²−2*ax*＋*a*² になります。
- 「📄 ワークシートの (*x*＋3)² をひらく」でワークシートの問題に。

### ③ (x＋a)(x−a)
- ✂ 切って並べかえる：*x*² の正方形から *a*² を切りとり、のこりの L 字を「あ」「い」に分け、「い」を 90°回して右につけると、たて *x*−*a*・横 *x*＋*a* の長方形（アニメ）。
- 🧱 タイルで見る：＋*ax* と −*ax* がゼロ対で消えて *x*²−*a*²。

### 🔢 x に数を入れてたしかめる（①〜③）
- *x* をその数の長さにして目もり（1 のタイル）を入れ、もとの式と展開した式の値をくらべます。② では *x*²＋*a*² の値（いくつたりないか）、まちがえた答えの値も出ます。

### ④ 公式えらび
- 式を見て、公式カード4まい（公式1〜4）から使うものをえらび、展開した式を書きます。公式1 は 2乗の形にも使えるので受けつけ、「専用の公式のほうが速い」とヒントを出します。「🙈 公式の右がわをかくす」でテストのように。正解すると面積図と、公式を使った式が出ます。
- 問題は答えの形（和と積・2乗・和と差）を先に決めて作り、同じ問題は続けて出しません。

### ⑤ 応用（文字が2つ・おきかえ）
- ためしてみよう：(*a*＋*b*)²、(*a*−*b*)²、(*a*＋*b*)(*a*−*b*)、(*x*＋2*y*)²、(3*x*−*y*)²、(2*x*＋3)(2*x*−5)、(2*x*＋1)²、(*x*＋*y*＋1)²、(*a*＋*b*−3)(*a*＋*b*＋5)、(*x*−*y*＋2)(*x*−*y*−2)。式を入れて「🟦 図にする」もできます（(…)(…) か (…)²、かっこの中は1次の式、文字2種類まで）。
- おきかえの式では、正解すると「*x*＋*y* を M とおく → (M＋1)² → M²＋2M＋1 → (*x*＋*y*)²＋2(*x*＋*y*)＋1 → …」の流れが出ます。

### 答えの式を書く
- 下のキー（数字・文字・＋・−・²・⌫・C、おきかえの問題では M）か、キーボードで書いて「たしかめる」（Enter でも可）。`^2` は ² になります。
- 同類項が残っているときは、まとめるように知らせます。1*x*・*xx*・*ba* と書いたときは、正解にしたうえで書き方のきまりを知らせます。

### そのほか
- 「↶ ひとつもどす」（スライダーを続けて動かした分は1回にまとめる）、「⟲ もういちど」（いまのパートをはじめに）、「動くはやさ」。

## つまずき検知の一覧

| 型 | 例 | もどる図 |
|---|---|---|
| まん中の項をわすれた | (*x*＋3)² → *x*²＋9、(*x*＋3)(*x*＋2) → *x*²＋6 | ② くらべる |
| まん中の項を 2倍 していない | (*x*＋3)² → *x*²＋3*x*＋9 | ② くらべる |
| (*x*−*a*)² のまん中の項の符号 | (*x*−3)² → *x*²＋6*x*＋9 | ② (*x*−*a*)² |
| (*x*−*a*)² の最後の項を −*a*² | (*x*−3)² → *x*²−6*x*−9 | ② (*x*−*a*)² |
| (*x*＋*a*)(*x*−*a*) の符号 | → *x*²＋*a*²、*x*²−2*ax*−*a*² | ③ |
| 和と積を入れかえた | (*x*＋3)(*x*＋2) → *x*²＋6*x*＋5 | ① |
| 数の項 *ab* の符号 | (*x*＋3)(*x*−5) → *x*²−2*x*＋15 | ① |
| *x* の係数 *a*＋*b* の符号 | (*x*＋3)(*x*−5) → *x*²＋2*x*−15 | ① |
| (2*x*)² を 2*x*² にした | (2*x*＋3)² → 2*x*²＋12*x*＋9 | ⑤ |
| まん中の項で係数をかけわすれた | (2*x*＋3)² → 4*x*²＋6*x*＋9 | ⑤ |
| おきかえた文字をもどしていない | 答えに M が残る | — |
| 公式のえらびまちがい | (*x*＋5)(*x*−5) に公式2 | — |
| 計算のまちがい（そのほか） | 上のどれにも当てはまらない | — |

- 1問ごとに「まちがえ方」で計算した答え（わな）を先に作り、生徒の答えと同じものの型にします。「🔁 類題」でその型が出やすい問題、「👀 面積図で見る」でその型が見える図にもどります。記録は端末に保存され、「記録を消す」で消せます。

## ワークシート

- もんだい：「(*x*＋3)² は *x*²＋9 になるだろうか？」
- ① 予想：*x*²＋9 になる／ならない（*x*²＋3*x*＋9）／ならない（*x*²＋6*x*＋9）／わからない
- ② 操作：正解したら「＋ 記録する」。式・展開した式・*x* に数を入れたときの値（*x*＝5：64 と 64、*x*²＋9＝34 など）・ふりかえり（1回で正解か、出たつまずき）。
- ④ まとめ：まちがえやすいところ（(*x*＋*a*)² のまん中の項、(*x*−*a*)² の符号、(*x*＋*a*)(*x*−*a*)）。
- 保存キーは `ikechan-math-乗法公式タイル`（つまずきの記録・見つけた公式もこの中）。

## 授業での使い方の例（50分）

1. **予想（5分）**：「(*x*＋3)² は *x*²＋9？」ワークシートで予想と理由。
2. **① で長方形（12分）**：*a*・*b* を変えて4つの部分を観察 → *x* の項をまとめて (*a*＋*b*)*x* → 公式1。和と積の役わりを確認。
3. **② で正方形（13分）**：(*x*＋3)² を開き「くらべる」で 2つの長方形がたりないことを見る。*x*＝5 で 64 と 34。(*x*−*a*)² は 4手順で「2回ひいた *a*² をたしてもどす」。
4. **③ 和と差（8分）**：切って並べかえるアニメ → *x*²−*a*²。
5. **④ 公式えらび（10分）**：式の形を見て公式をえらぶ練習。早く終わった生徒は ⑤。
6. **まとめ（2分）**：まちがえやすいところをことばで。

## 正しさについて（※じっさいとのちがい）

- 係数はすべて整数で、ふつうの数の計算で厳密に行います（小数は使いません）。
- *x* の長さは決まっていないので、図では 1 の何こ分でもない長さでかいています（「*x* に数を入れる」のときだけ、その数の長さ）。
- 負の数の長さは図にできないので、① ④ ⑤ の図では − の辺を青い点線のタイルで表し、できるタイルの符号は「たての符号×横の符号」で決めます（中2「寄せて ならべて 式の計算」と同じ考え）。② の (*x*−*a*)² と ③ は、*x* が *a* より大きいとして、ほんとうの長さで図にしています。
- 図にできるのは、文字2種類まで・2次まで・かっこの中の数が小さいとき（文字の係数の合計 3 まで、数の合計 9 まで）です。それより大きい式は、式の変化と答えだけ出します。
