# 天秤で方程式（等式の性質から移項まで）

中学1年「一次方程式」で、式を**天秤**にのせて解くアプリです。
**箱**（おもり＝正の数）と**風船**（うかせる＝負の数）を左右の皿にならべ、「両辺に同じことをすれば天秤はつり合ったまま」という**等式の性質**を確かめます。そのうえで、**移項**（項を反対の辺へうつすと符号がかわる）がなぜ成り立つのかを、天秤の動きで見せます。
解いた手順は「式のきろく」に、式の書き方で1行ずつ残ります（1-08 方程式ステップへのつなぎ）。

## 基本情報

- **ファイル**：本体 `天秤方程式.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中1）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）・スマホ。
- **パーツ**（色だけでなく、形・線の種類・文字でも区別）
  - 📦 *x* の箱＝**横長**、📦 1 の箱＝**小さい正方形**。どちらも正の数で、**オレンジ・実線**。
  - 🎈 −*x*・−1 の風船＝負の数で、**青・点線**、「−」の字つき。
  - 同じ皿の箱と風船は「**0 のペア**」（(＋1)＋(−1)＝0）。正負の数チップのゼロ対と同じ考え方です。

## 使い方

画面の上で、学ぶ順に3つのモードをえらびます。どのモードも「①ならべる → ②とく」の順です。

1. **ならべる**：式のとおりに、左右の皿にパーツをおきます（まちがえると天秤がかたむく）。「🪄 自動でならべる」もあります。
2. **とく**：x の箱が1こだけ（x ＝ ○）になったらクリアです。わり切れないときは、x ＝ 5/2 のように分数で答えが出ます。

### ① 等式の性質

- 🗑 **両辺から同じものをすてる**（両辺から同じ数をひく）。皿のパーツをタップしても、両方の皿から1こずつすてます。
- 式にマイナスがあるときは、**両辺に同じものをたす**ボタンと「0 のペアをけす」が出ます。
- **両辺を同じ数でわる**（÷2〜÷9。わり切れるときだけ押せる）。

### ② 移項

- 皿のパーツを**タップ**するか、**反対の皿へドラッグ**すると、その項（同じ種類のパーツぜんぶ）が反対の辺へうつります。箱は風船に、風船は箱にかわります＝**符号がかわる**。
- 「**移項のしくみをゆっくり見る**」がオンだと、2つの動きに分けて見せます。
  1. 両辺に反対の符号のパーツをたす（＝両辺から同じ数をひく。天秤はつり合ったまま）
  2. もとの皿で 0 のペアが消える → 項が反対の辺へうつって、符号がかわったように見える
- うつしたあとは「**計算する**（0 のペアを消す）」、「両辺をわる」で仕上げます。

### ③ x が両辺

- 3*x*＋2＝*x*＋8 のような問題です。「🗑 両辺から *x* をひく」（1こずつ。続けると「両辺から 2*x* をひく」と1行にまとまる）か、*x* の項を移項して、*x* を片方の辺に集めます。
- *x* の係数がマイナスになったら「✖ **両辺に −1 をかける**」が出ます（箱と風船がぜんぶ入れかわる）。

### 式のきろく

- 操作するたびに、理由つきで式が1行ずつ残ります。「=」の位置を縦にそろえています。
- 書き方を切りかえられます。
  - **等式の性質で**：とちゅうの式もぜんぶ（例：3*x*＋2−2＝8−2）。
  - **移項で**：教科書の書き方（例：3*x*＝8−2）。
- 移項の行は「＋2 を右辺へ移項（符号がかわって −2）」のように書きます。反対の辺の同じ種類の項とまとまったとき（7＋3 → 10）は、つぎに「計算する」の行が入ります。

### 予想の3択「つぎの式はどれ？」

- 「🤔 動かす前に『つぎの式』を予想する」がオンのとき、移項・計算・わる・−1 をかける の前に3択が出ます（②③は最初からオン、①はチェックでオン）。
- まちがいの選択肢は、よくあるまちがい方から作っています。まちがえると「あなたのつまずき」と説明が出て、天秤で正しい式を確かめます。

### そのほか

- **↶ ひとつもどす**・**↺ もういちど**（ならべる・とくの両方）。
- **🎲 ランダム**：答え（正の整数）を先に決めてから式を作ります。同じ問題は続けて出ません。
- **✏️ つくる**：*a x*＋*b*＝*c x*＋*d* の数（−9〜9）を入れて、自分の問題を作れます。

## ワークシート

右の「ワークシート」で、①予想 → ②操作 → ③気づき → ④まとめ を書きます。

- **問い**：方程式の項を反対の辺へうつす（移項する）と、その項の符号はどうなるだろうか？
- **予想**：符号はそのまま／符号が反対になる／項によってちがう／わからない
- **記録**：問題をクリアしてから「＋ 記録する」。はじめの式・最初に移項した式・答え が表に入ります。
- 保存はこの端末の localStorage（キー `ikechan-math-天秤方程式`）。モードごとのクリア数・予想の正解数・つまずきの回数も同じキーの中に入ります。

## 先生モード（`?teacher=1`）

URL のうしろに `?teacher=1` を付けると、先生用のパネルが出ます。

- **▶ 解き方を自動再生**／**⏭ つぎの1手**／**■ とめる**：ならべるところから、そのモードの解き方で1手ずつ天秤を動かします（移項はゆっくり2段階で）。
  - ①：両辺からひく・たす → 0 のペアを消す → わる
  - ②：数の項（*x* の項）を移項 → 計算する → わる
  - ③：両辺から *x* をひく → 数の項を移項 → 計算する → わる
- **ヒントをえらんで出す**（つぎの1手について）
  - ヒント① 天秤の図で（動かすパーツが点めつする）
  - ヒント② 等式の性質で（「両辺から 2 をひく」など）
  - ヒント③ 移項で（つぎの式まで見せる）
- **途中の式を1行ずつ出す**：はじめの式から答えまでを「つぎの行 ▶」で1行ずつ、または「ぜんぶ出す」。書き方は「式のきろく」の切りかえと同じです。
- **この端末のつまずきの合計**と「記録を消す」。
- ワークシートの先生用ヒント・解答例。

## 授業での使い方の例（50分）

1. （5分）「① 等式の性質」で *x*＋2＝5 を天秤にならべ、両辺から 2 をすてて解く。「両辺に同じことをすれば、つり合ったまま」を確認。
2. （5分）ワークシートの問い「移項すると符号はどうなる？」を予想させる。
3. （15分）「② 移項」で、先生モードの自動再生（しくみをゆっくり見る）を見せる。そのあと、生徒が3択で予想しながら問1〜問7を解く。
4. （10分）「③ x が両辺」で 3*x*＋2＝*x*＋8。「両辺から *x* をひく」と「*x* を移項する」をくらべ、同じ式になることを確かめる。
5. （10分）式のきろくを「等式の性質で」と「移項で」で切りかえて、移項はとちゅうの式を省いた書き方であることをまとめる。ワークシートの④まとめを書く。
6. （5分）「あなたのつまずき」を見て、その型の練習をする。

## つまずき検知の一覧

予想の3択で、えらんだまちがいの選択肢から型を決めます。

| 型 | 出る場面 | まちがいの選択肢の例 | 練習にもどるモード |
|---|---|---|---|
| 符号をかえずに移項した | 移項 | 3*x*＋2＝8 → 3*x*＝8＋2 | ② 移項 |
| 片方の辺だけ計算した | 移項・わる | 3*x*＋2＝8 → 3*x*＝8／3*x*＝6 を ÷3 → *x*＝6 | ② 移項 |
| わるとき、一部の項だけわった | わる | 4*x*＋2＝6 を ÷2 → 2*x*＋2＝6 | ① 等式の性質 |
| 係数をひいてしまった | わる | 3*x*＝6 → *x*＝3（6−3） | ① 等式の性質 |
| わる数とわられる数が逆 | わる | 3*x*＝6 → *x*＝3/6 | ① 等式の性質 |
| −1 を片方の辺にだけかけた | −1 をかける | −*x*＝−3 → *x*＝−3 | ③ x が両辺 |
| 正負の計算で符号をまちがえた | 計算する | 3*x*＝8−2 → 3*x*＝10 | ② 移項 |
| *x* の項と数の項をまとめた | 計算する | 2*x*＋3 → 5*x* | ③ x が両辺 |
| 計算ミス | どこでも（選択肢が足りないとき） | 数を ±1 ずらしたもの | — |

## 正しさについて（※じっさいとのちがい）

- 答えがマイナスになる問題（「✏️ つくる」で作ったとき）でも、*x* の箱は箱の形のままかいています。本当なら *x* の箱も浮きます。天秤のかたむきの計算は、本当の値で行っています。
- 天秤のかたむきは、左右の重さの差に合わせて最大 10° までにしています。
- 答えが分数のときは、約分した分数で正確に出します（小数は使いません）。たしかめ（代入）も分数で計算しています。
- 乱数の問題・用意した問題は、答えが正の整数か簡単な分数になるようにしています。
