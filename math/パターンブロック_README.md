# 🔷 パターンブロック

6しゅるいのパターンブロックを画面で動かすボードです。小学1〜6年の図形（かたちづくり・しきつめ・角）と分数で使えます。

- **ファイル**：`パターンブロック.html`。この1ファイルだけで動きます（ネット接続・外部ライブラリ・画像ファイルは不要）。
- **対応する機器**：タッチできる Chromebook、電子黒板、マウス。指1本ずつ別々に動くので、何人かで同時に動かせます。
- **算数セットから**：「さんすうセット ていがくねん」（`?low=1`）と「算数セット 中高学年」（`?high=1`）のボード一覧にも入っています。セットから開くと、左上が「🏠 ボードえらび」になり、セットにもどれます。
- **つづきから**：ならべたブロックとペンの線は、この端末に自動でほぞんされ、次に開いたときにそのまま出ます（セットから開いたときは、べつにほぞん）。🧹かたづける で消えます。
- 参考にしたもの：Brainingcamp の Pattern Blocks（しくみだけ参考。絵・問題はオリジナル）。

## ブロック

| ブロック | 色 | 三角形 何こ分 |
|---|---|---|
| 六角形 | 黄 | 6 |
| 台形 | 赤 | 3 |
| ひし形 | 青 | 2 |
| 三角形 | 緑 | 1 |
| 正方形 | オレンジ | ― |
| ほそいひし形 | うすい茶 | ― |

辺の長さはみんな同じ（台形の長い辺だけ2つ分）です。

## 使い方

- **出す**：左の道具箱からボードへひっぱる。タップすると、ボードのまんなかあたりに出ます。
- **動かす**：ブロックをひっぱる。はなすと、近くのブロックの角（頂点）にぴったりすいつきます。
- **えらぶ**：ブロックをタップすると、上に ↺↻まわす（30°ずつ）・⇋うらがえす・⧉ふやす・🗑️けす が出ます。キーボードは ←→ で回す、F でうらがえす、Delete でけす。
- **けす**：道具箱へもどしてもきえます。🧹かたづける で全部きえます（↩️もどる で取り消せます）。
- **ボードを動かす**：ブロックのないところをひっぱると、ボード全体が動きます。➖➕で大きさを変えます。
- **✏️かく**：ペン（赤・青・黒）で書きこみ。🧽せんをけす。
- **∴てん**：三角のマスの点を出します。ブロックが点にすいつきます。
- **📷がぞう**：今のボードを PNG で保存します（ロイロなどで提出）。

## 🧩 かげパズル

黒いかげをブロックでうめます。ぴったりうまると「🎉できた！ ○この ブロックで うめたよ」と出ます。

- はみ出し・すきま・重なりがあると「できた」になりません。
- できた数は「できた かず：6こ・12こ」と記録されるので、「ちがう数でもできるかな？」「いちばん少ない数は？」と考えられます。
- 🔍ヒント：かげの中に三角形の線を出します（1年生や、つまずいている子に）。
- 問題（★はむずかしさ）：大きな さんかく★・大きな ひし形★・ほし★★・ロケット★★・ながい へいこうしへんけい★★・大きな 六角形★★★・はな★★★
- かげはどれも三角形のマスでできているので、三角形だけを使えば必ずうめられます。

## ½ ぶんすう

ブロックの上に、「1 と する ブロック」を1としたときの大きさが出ます。下のバーで「ぜんぶで ○」も出ます。

- 六角形を1 → 台形 1/2、ひし形 1/3、三角形 1/6
- 台形を1 → 六角形 2、ひし形 2/3、三角形 1/3 など、1にするブロックを変えられます。
- 正方形・ほそいひし形は三角形でできていないので、数を出しません。

## 先生モード（🧑‍🏫せんせい）

- **🌑かげに する**：ならべたブロックを、そのままかげの問題にします（正方形・ほそいひし形も使えます）。道具箱の問題の一覧に「先生の かたち 1」として入ります（ページを閉じると消えます）。
- URL：`?teacher=1` で先生モードから、`?p=hoshi` で問題を決めて開けます（sankaku・hishi・hoshi・roket・para・rokkaku・hana）。

## 授業での使い方の例

- **1年「かたちづくり」**：かげパズル★を三角形・ひし形でうめる。「同じかげを ちがうブロックで」。
- **2年「三角形と四角形」**：台形・ひし形・正方形・三角形をなかま分け。
- **3年「分数」・5年「分数のたし算」**：½ぶんすうで、六角形を台形2こ・ひし形3こ・三角形6こでうめて 1/2・1/3・1/6 を確かめる。1にするブロックを変えると、同じブロックの大きさが変わることに気づける。
- **4年「角」・5年「図形の角」**：1つの点のまわりに集まる角（60°×6・90°×4・120°×3 など）をしきつめて確かめる。

## ※じっさいとのちがい

- 本物のパターンブロックの大きさ（1辺 約2.5cm）とはちがいます。画面の大きさで変わります。
- できたの判定は、画面の中で小さな絵にかいて、うまった点を数えています。ほんのわずかなすき間は「うまった」とみなします。
