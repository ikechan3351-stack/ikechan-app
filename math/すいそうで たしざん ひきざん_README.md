# すいそうで たしざん ひきざん

小学1年生の算数「たしざん」「ひきざん」で使う教材です。
水そうに魚が「はいってくる」「でていく」動きを見て、たし算・ひき算の意味を体感します。
特に、1年生で学ぶ次の4つの場面のちがいを、動きで区別できるようにしています。

| 場面 | 例 | 水そうの動き |
|---|---|---|
| ふえると（増加） | 3びき いる → 2ひき はいってくる → ぜんぶで？ | いけの魚が水しぶきを上げて飛びこむ |
| あわせると（合併） | 左に3びき、右に2ひき → いっしょにすると？ | 水そうのしきりが上がり、左右の魚がまざる |
| のこりは（求残） | 5ひき いる → 2ひき でていく → のこりは？ | 魚があみですくわれて外へ出ていく |
| ちがいは（求差） | 赤5ひき、青3びき → ちがいは？ | 魚は出ていかない。2列に並べて1ぴきずつ線でつなぎ、あまりが光る |

## 基本情報

- **ファイル**：`すいそうで たしざん ひきざん.html`。この1ファイルだけで動きます（ネット接続・外部ライブラリ・画像ファイルは不要）。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。横に広い画面では、左におはなしと水そう、右にボタンが並びます。スマートフォンでは水そうが上、いけとあみが下になります。
- **姉妹教材**：「ぼうとばらでかぞえよう」「くり上がり・くり下がりを ブロックで」。10のまとまりの考え方を、ここでは10ぴきの「むれ」で見せています。

## 魚の見た目

| 魚 | 色 | 模様 | 出てくる場面 |
|---|---|---|---|
| はじめからいる魚 | だいだい | なし | ふえると・あわせると（左）・のこりは・じゆうに あそぶ |
| あとから入る魚 | 青 | 水玉 | ふえると・あわせると（右）・じゆうに あそぶ |
| ちがいはの赤 | 赤 | しま | ちがいは |
| ちがいはの青 | 青 | 水玉 | ちがいは |

色だけでなく模様でも見分けられるようにしています（色覚の多様性への配慮）。

## モード

1. **じゆうに あそぶ**：「さかなを いれる（＋1）」「さかなを だす（−1）」、または指で魚をドラッグして出し入れします。式が自動で「3」→「3＋1＝4」→「3＋2＝5」と組み立ちます。ひき算に切りかえると、そこから新しい式になります。「ここから しき」で、今の数から式を始め直せます。
2. **おはなし もんだい**：おはなしを読む →「おはなしを すすめる」で動きを見る → 答えを数字ボタンで選ぶ。
3. **しきを つくろう**：動きを見たあと、「＋か−か」「数はいくつか」を児童が組み立てます。たし算は「2＋3」のような入れかえも正解にしています。ひき算で「3−5」のように逆に書いたときは「おおきい かずから ちいさい かずを ひくよ」と知らせます。
4. **おはなしを つくろう**：式（例 7−3）を見て、児童が魚を動かして場面を作ります（逆思考）。①はじめの数だけ入れる →②式に合わせて入れる・出す →「できた！」で、作ったお話が文章で出てきます。
5. **先生モード**：場面の種類と数（0〜20）を指定して、電子黒板に出します。
   - 「すすめる／もどる」、またはキーボードの ← → で1ステップずつ進む・戻る。
   - 右の「ステップ」一覧を押すと、その場面へとびます。
   - 「こたえを かくす」にすると式の答えが「？」になり、押すと表示されます。

## 場面のステップ

それぞれの場面は「導入 → 動き → 式 → 答え」の順に進みます。

- **ふえると**：はじめ → はいってくる → しき（3＋2＝？）→ こたえ
  - レベル3（8＋5 など）は「10になるまで入る（むれができる）→ のこりが入る」の2段階にして、くり上がりを見せます。
- **あわせると**：はじめ（しきりあり）→ いっしょにする → しき → こたえ
- **のこりは**：はじめ → でていく → しき → こたえ
  - レベル3（13−7 など）は「むれを ばらす → むれから でていく」にして、減加法（10から引いて、のこりとたす）を見せます。並べると、10のわくに3びき、となりのわくに3びきが残ります。
- **ちがいは**：はじめ → 2れつに ならべる → 1ぴきずつ せんで つなぐ → あまりを 見る → しき → こたえ
  - 並べたあと、児童が赤い魚から青い魚へ指でなぞって線をつなぐこともできます。

## 10の「むれ」

- 水そうの魚が10ぴきそろうと、10ぴきの「むれ」にまとまり、泳ぐときもいっしょに動きます（まわりにオレンジの輪が出ます）。
- 「かぞえる」を押すと、魚が5ひきずつの列（10のわく）に並び、1ぴきずつ番号がつきます。むれのわくはオレンジ色です。
- もう一度押すと、泳ぎにもどります。

## 難易度

| レベル | 内容 | 例 |
|---|---|---|
| 1 | 答えが10までのたし算・ひき算 | 3＋4、8−5 |
| 2 | 答えが20まで、くり上がり・くり下がりなし | 12＋3、15−2 |
| 3 | くり上がり・くり下がりあり | 8＋5、13−7 |

「せってい」の「0の もんだい」を「まぜる」にすると、「1ぴきも はいって こなかった」「ぜんぶ でて いった」「おなじ かず」のような0の問題がまざります。

## つまずきへの対応

- **ことばの強調**：「ぜんぶで」「あわせると」「のこりは」「ちがいは」「はいって きました」「でて いきました」を、色と下線の形（実線・二重線・点線・波線など）で区別して強調しています。
- **のこりは と ちがいは の区別**：ちがいはでは魚が出ていかず、並べてくらべる動きにしています。
- **まちがえたとき**：「もういちど さかなを かぞえて みよう」と出して、魚を並べて番号をつけ、数え直しをうながします（責めない表現）。たし算なのにひき算の答えを選んだときは「ふえたかな？ へったかな？」と声をかけます。
- **ヒント（3段階）**：①「どの ことばが だいじかな？」（ことばが光る）→ ②動きをもう一度見る → ③1ぴきずつ数える。

## 先生向け設定（⚙️ せってい）

- おと（あり／なし）、ふりがな（あり／なし）
- うごき：「へらす」にすると、魚が泳がず、いつも並んだ表示になります。しぶきやキラキラも出ません。
- かずの ひょうじ：「かくす」にすると、水そうの数が「なんびき かな？」になり、数の番号も出ません。表示を押すと3秒だけ見えます。
- レベル、もんだいの かず（5・10・15もん）、「いろいろ」で出す場面（チェック）、0の もんだい
- 設定はこの端末のブラウザに保存されます。問題の結果（正解数・ヒントの回数・場面ごとの正答状況）は終了画面に出るだけで、保存しません。
- 右上の「ぜんがめん」で全画面表示にできます。

## 動作確認方法

1. `すいそうで たしざん ひきざん.html` をブラウザ（Chrome・Edge・Safari）で開く。
2. **じゆうに あそぶ**：「さかなを いれる」を何回か押す → 魚がいけから水しぶきを上げて飛びこみ、式が「3＋1＝4」「3＋2＝5」と変わるか。「さかなを だす」で、あみですくわれて式が「5−1＝4」になるか。10ぴきになると「むれ」ができるか。魚を指（マウス）でいけ→水そう、水そう→あみへドラッグできるか。
3. **かぞえる**：5ひきずつ並び、1から順に番号がつくか。もう一度押すと泳ぎにもどるか。
4. **先生モード**：4つの場面それぞれで「すすめる／もどる」と ← → キーが使えるか。「のこりは 13−7」で、むれをばらして減加法の形で残るか。「ちがいは」で線がつながり、あまりの魚が光るか。「こたえを かくす」で答えが「？」になり、押すと出るか。
5. **おはなし もんだい**：わざとまちがえると、魚が並んで数え直しのメッセージが出るか。ヒントが3段階で変わるか。5問終えると結果が出るか。
6. **しきを つくろう／おはなしを つくろう**：式を組み立てて「こたえあわせ」、魚を動かして「できた！」で、それぞれ判定されるか。
7. **せってい**：「うごきを へらす」で魚が並んだままになるか、「かずを かくす」で「なんびき かな？」になるか。
8. 電子黒板（横長）・タブレット・スマートフォンで、ボタンが押しやすく、はみ出しがないか。

## 授業での使い方の例

### 1. たし算の導入（「ふえると」と「あわせると」）

1. **先生モード**で「ふえると 3＋2」を出す。「すいそうに 3びき います」で止め、「このあと どうなるかな？」と予想させる。
2. 「すすめる」で2ひきが飛びこむ動きを見せる。式が「3＋2」と組み立つのを確認し、「ぜんぶで」ということばに注目させる。
3. 「かぞえる」で並べて番号をつけ、全員で数えて答えを確かめてから「こたえ」へ進む。
4. 同じ数で「あわせると」も見せ、「入ってくる」と「いっしょにする」は動きがちがうけれど、どちらも たし算になることを話し合う。
5. 残りの時間は、児童が**じゆうに あそぶ**で魚を入れて式を作ったり、**おはなし もんだい**（場面を「ふえると」「あわせると」にしぼる）に取り組んだりする。

### 2. ひき算の導入（「のこりは」）

1. **先生モード**で「のこりは 5−2」を出す。あみで魚がすくわれて出ていく動きを見せ、「でて いきました」「のこりは」のことばに注目させる。
2. 「もどる」で出ていく前にもどし、もう一度見せる。「へった かずは？」「のこった かずは？」を区別して言わせる。
3. **しきを つくろう**で「＋か−か」を選ばせ、「へる ときは −」を確かめる。
4. 慣れてきたらレベル3の「13−7」を先生モードで見せ、「3びきからは 7ひき だせないね → むれを ばらそう」の流れで、くり下がり（減加法）の考え方につなげる。

### 3. 場面のちがいを考える授業（「のこりは」と「ちがいは」）

1. 同じ数で2つの場面を出す。先生モードで「のこりは 5−3」と「ちがいは 赤5・青3」を順に見せる。
2. 「どちらも 5−3 だけど、水そうの動きは どうちがう？」と問う。のこりは「魚が出ていく」、ちがいは「出ていかずに、ならべて くらべる」ことに気づかせる。
3. ちがいはでは、2列に並べたところで止め、代表の児童に電子黒板で赤から青へ線をつながせる。あまった魚が「ちがい」になることを確認する。
4. **おはなし もんだい**で場面を「いろいろ」にして出題し、「どのことばが だいじかな？」とことばに注目しながら解く。
5. まとめに**おはなしを つくろう**で式からお話を作らせ、「5−3 は どんな おはなしに なるかな？」と、のこりは・ちがいはの両方のお話を発表させる。
