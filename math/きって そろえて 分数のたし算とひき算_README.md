# きって そろえて 分数のたし算とひき算

小学5年生の算数「分数のたし算とひき算」（東京書籍 新しい算数 5下 2〜17ページ）で使う教材です。次のことを体験します。

- **等しい分数**：分母と分子に同じ数をかけても、同じ数でわっても、分数の大きさは変わらない（テープを細かく切る・まとめる）
- **約分**：分母と分子を公約数でわって、かんたんな分数にする（12/18 → 2/3）
- **通分**：分母のちがう分数を、分母の最小公倍数などにそろえる（1/2・1/3 → 3/6・2/6）
- **分母のちがう分数のたし算・ひき算**：通分してから分子どうしを計算し、答えは約分する
- 分数と小数のまじった計算（0.3＋1/4）、時間の分数表示（40分＝2/3時間）

## 基本情報

- **ファイル**：`きって そろえて 分数のたし算とひき算.html`。共通ファイル `worksheet.js`・`worksheet.css`・`math-render.js` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。テープ図は SVG で描いています。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。ボタンは48px以上（分数をえらぶ −・＋ は44px）。スマホのたて向きでも画面がはみ出しません。
- **漢字**：分数・分子・分母・約分・通分・公約数・最小公倍数 などの算数のことばと、5年でまだ習っていない漢字にふりがなをつけています。「せってい」で消せます。
- **保存**：ワークシートと「せってい」を、このブラウザの localStorage（キー：`ikechan-math-きって そろえて 分数のたし算とひき算`）に保存します。もんだいの成績は保存しません。
- **範囲**：答えは仮分数（17/12 など）で書きます。帯分数（1と5/12）はあつかっていません（5-10 の指導内容の一覧に帯分数の計算がないため）。発展（カードの分数づくり・音符の長さ）は入れていません。

## 3つの画面

### ✂️ きって まとめて

- 分数（1/2・2/3・3/4・2/5・3/5・5/6 と、約分の練習用の 6/8・4/6・9/12・8/12・10/15・12/16・6/9・12/18）をえらびます。
- テープ図は2本です。上は「もと」の分数、下は「いま」の分数で、ぬった長さの終わりに赤い点線をひきます。
- 「細かく 切る ×2・×3・×4」で、テープの1つ1つが2つ・3つ・4つに分かれ、分母と分子に同じ数をかけた分数になります（分母は24まで）。
- 「まとめる ÷2・÷3・÷5」で、分母と分子を同じ数でわった分数になります（約分）。わり切れないときは「3でわれないので、3こずつまとめられない」と出します。
- 分母と分子の公約数が1だけになると「これ以上 まとめられない。約分 できた！」と出ます。たどった分数を「12/18 ＝ 6/9 ＝ 2/3」のようにならべます。
- 「ひとつ もどす」「もういちど」あり。

### 🧩 そろえて たそう

- ア（オレンジ・ぬりつぶし）と イ（青・しま）の分数を、分子・分母の −・＋ でえらび（分母 2〜10 の真分数）、＋ か − をえらびます。
- 「✂️ 切り方を そろえる」で、どちらのテープも分母の最小公倍数の数に切り直します（通分）。「2 と 3 の 最小公倍数 6 に そろえた。1/2 は 分子も分母も ×3」と出ます。
- 「たす」で、アのあとにイをつないだ答えのテープを出します。1 をこえるときは 2 までの目もりで見せます。「ひく」で、アからイの分をとったテープ（とったところは × 模様）を出します。ひかれる数が小さいときは理由を出して止めます。
- 答えが約分できるときは「まとめる（約分）」で、太い線で約分した目もりを重ねます。
- 式は「1/2 ＋ 1/3 ＝ 3/6 ＋ 2/6 ＝ 5/6」のように、とちゅうの式もならべます。通分をとばして「たす」を押すと「先に 切り方を そろえよう」と出ます。
- ワークシートの「＋ きろくする」で、しき・とちゅう（通分）・答え を記録します。

### ✏️ もんだい

- 6種類がまざって出ます（6問なら1つずつ、12問なら2つずつ）。
  - **約分**：18/30 → 3/5
  - **通分して くらべる**：7/8 と 4/9 → ＞・＝・＜
  - **たし算**・**ひき算**：分母のちがう真分数（答えが整数にならないもの）
  - **小数まじり**：0.5 ＋ 3/4 ＝ 5/4（分数で答える）
  - **時間と 分数**：12分は何時間？（1/5）、2/3 時間は何分？（40分）
- 答えは約分した形で入れます。分子・分母のわくはタップで切りかえます（PCは Tab キーか / キーでも切りかえ）。

## つまずき検知

| 型の名前 | 見つけ方 | 例 | 出す声かけ |
|---|---|---|---|
| 分母どうし・分子どうしを 計算 | 答えが（分子＋分子）/（分母＋分母）になっている（ひき算も同じ） | 2/3＋1/9 → 3/12 | 分母がちがうと1こ分の大きさがちがう。1/2＋1/3 が 2/5 だと 1/2 より小さくなってしまう |
| 通分で 分子を そのまま | 答えが（分子＋分子）/ 最小公倍数 になっている | 1/4＋9/10 → 10/20 | 通分するときは、分母にかけた数を分子にもかける（1/2＝3/6） |
| 約分わすれ | 大きさは合っているが約分していない（とちゅうまでの約分もふくむ） | 18/30 → 9/15 | 答えが約分できるときは、公約数でわって、いちばんかんたんな分数にしよう |

- 「約分わすれ」のときは「おしい！ 大きさは合っているよ。約分しよう」と出し、回数に数えずにもう一度答えてもらいます。
- 見つけた型は「あなたの つまずき」として出し、次にその型の「にた もんだい」を1問足します（「約分わすれ」のたし算・ひき算の にた もんだい は、答えが約分できる問題にします）。
- 終わりの画面に、型ごとの回数を出します。

## 先生モード（アドレスの最後に `?teacher=1`）

- きって まとめて：分数を直接入力できます（分母24までの真分数、例 16/24）。
- そろえて たそう：「▶ じどうで すすめる」で、通分 → 計算 → 約分 を順に見せます。
- もんだい：「💡 こたえ」で答えと考え方を表示します。ワークシートに、先生用のヒントと解答例が出ます。

## 授業での使い方の例

1. **等しい分数・約分（2〜3時間）**：「きって まとめて」で 3/4 を細かく切り、長さが変わらないことを確かめる → 12/18 をまとめて約分 → 「もんだい」の約分。
2. **通分（2時間）**：「そろえて たそう」の「切り方を そろえる」で通分 → 5-08 の最小公倍数とのつながりを話し合う → 「もんだい」の大小くらべ。
3. **たし算・ひき算（3〜4時間）**：「1/2＋1/3 は？」とワークシートの「よそう」（2/5 と考える子が多い）→ テープで確かめる → ひき算・答えの約分 → 「もんだい」。
4. **小数まじり・時間（1〜2時間）**：「もんだい」の小数まじり・時間と分数。

## 正しさ

- 分数の計算は共通ファイル `math-render.js` の Fraction で、分子と分母を整数のまま正確に行っています。子どもの入れた分子・分母は約分しないままでも調べるので、「約分わすれ」を正しく見分けられます。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| ア／イ の分数 | オレンジ／青 | ぬりつぶし／しま模様、「ア」「イ」の文字 |
| ひき算でとった部分 | 赤むらさき | × 模様、「とる」の文字 |
| 約分した目もり | 緑 | 太い線 |
| 約分できた／まだできる | 緑／むらさき | 実線／点線のわく |
| 正解／まちがい | 緑／赤むらさき | ◎・△ の記号 |
