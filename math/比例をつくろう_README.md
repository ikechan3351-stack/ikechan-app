# 比例をつくろう（表・式・グラフがつながって動く）

中学1年「比例と反比例」の比例 y ＝ ax を、**表・式・グラフ**の3つで行き来するアプリです。比例定数 a の意味、a が負のとき、変域（x のはんい）、身近な場面（水を入れる・同じ速さで歩く）を、5つのパートで学びます。

## 今ある教材との役割分担

| 教材 | 役割 |
|---|---|
| 関数グラフツール（`関数グラフ.html`） | 比例・反比例・一次関数・二次関数を、スライダーで自由に動かす道具 |
| 関数の箱（`関数の箱.html`） | 数を入れると変身する機械から、きまり（式）を見やぶる |
| **比例をつくろう（これ）** | **比例だけ**にしぼって、表・式・グラフの連動と、課題（答える問題）・つまずき検知・ワークシートで授業に使う |

## 基本情報

- **ファイル**：本体 `比例をつくろう.html`、共通部品 `math-render.js`・`graph-engine.js`（座標平面）・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中1）から開けます。
- **画面**：広い画面（電子黒板・横長の画面）は 左＝表・中央＝グラフ・右＝式 の3列。タブレットの横向きは グラフが上、その下に 表 と 式。スマホは グラフ・式・表 の順にたてに並びます。
- **色のきまり**：正の数＝オレンジ、負の数＝青、正解＝緑の「○」、まちがい＝赤紫の「×」。変域は紫（x）と緑（y）の帯、端の点は ●（ふくむ）と ○（ふくまない）。
- **URL の設定**
  - `?teacher=1` … 先生モード（答え・答えを入れて進める・この端末のきろく・ワークシートのヒントと解答例）
  - `?ws=0` … ワークシートをとじて開く

## 使い方

答えは式の欄の下のキーパッドで入れます。分数は **／**、小数は **．**、負の数は **−**（符号の切りかえ）。キーボードの数字・`-`・`/`・`.`・Tab・Enter も使えます。

### ① 表から式

1. x ＝ −4〜4 の表のうち、2つの行（黄色）だけ y が見えています。グラフにもその2点が出ます。
2. 「比例定数 a は？」に答えます（a は 2、−3、1/2、−3/2、2/3 などが出ます）。
3. 正解すると、表の残りのマスが順にうまり、「y÷x」の列（どの行も a）と、式・グラフ（直線と表の点）が出ます。
4. a が大きいときは、表の y がぜんぶ入るようにグラフの y のはんいを広げます（このとき x と y の1目もりの長さはちがいます）。

### ② 式からグラフ

1. a のスライダー（−5〜5、0.5 きざみ）か数の入力（2、−1.5、3/4 など）で a を変えると、原点を通る直線が回ります。表（x −3〜3 と y÷x）・式もいっしょに変わります。
2. グラフの点 P（x ＝ 1 の線の上だけ動く）をドラッグしても a が変わります。P の y 座標が a。「右へ1・上へ a」の紫の線も出ます。すいつく（0.5 きざみ）／すいつかない（0.1 きざみ）はグラフの上のボタンで切りかえます。
3. 「📌 この直線を残す」で灰色の点線として残し、急さをくらべられます（4本まで）。
4. 🎯 チャレンジ：「直線が点 (2, −1) を通るように a を決めよう」。通ると次の点が出ます。
5. a ＝ 0 にすると「比例とはいわない」と出ます。

### ③ グラフから式

1. 2本の直線 ℓ（オレンジ・実線）と m（青・点線）が出ます。
2. ℓ、m の順に比例定数 a を答えます。格子点（x も y も整数の点）をさがして y ÷ x を計算します。
3. 2本とも答えたら「どちらが急？」（ℓ／m／同じ急さ）。急さは a の**絶対値**でくらべます。

### ④ 変域

1. 「y ＝ −2x、−1 ≦ x ＜ 3」のような問題が出ます。グラフは 変域の部分だけ太い線で、端は ●（ふくむ）・○（ふくまない）。x軸の上に x の変域の紫の帯。
2. 「□ ≦ y ＜ □」の形で答えます。記号のボタンを押すと ≦ と ＜ が切りかわります。
3. 正解すると、y軸の上に y の変域の緑の帯（端は ●・○）と、x の端から直線・y軸への点線が出ます。
4. a が負のときは、x の右はしが y の小さいほうの端になる（記号もいっしょに入れかわる）ことを確かめます。

### ⑤ 場面

- 💧 水を入れる：毎分 a L（1〜5）で水そうに水を入れる。x ＝ 時間（分、0〜10）、y ＝ 水の量（L）。
- 🚶 速さ（歩く）：時速 a km（2〜6）で歩く。x ＝ 時間（0〜5 時間）、y ＝ 道のり（km）。
- ▶ スタートで動画が動き、グラフの点・表（通りすぎた x の行がうまる）・動画の数字がいっしょに動きます。x はスライダーと数の入力でも動かせます。
- 「x ＝ 8 のとき、y は何 L？」に答えると、動画とグラフの点がその時間に移ります。

ボタン：🎲 新しい問題／↶ ひとつもどす／⟲ もういちど（いまの問題をはじめから）／💡 ヒント（押すたびにくわしく）／📄 ワークシートの問題（② を開いて a ＝ −2 をためす）

## 授業での使い方（例）

- **導入（5分）**：⑤ の水そうを電子黒板で動かし、表と点がいっしょに動くことを見せる。「y は x に比例している？」と聞く。
- **展開①（10分）**：① で表から比例定数を求める。「y ÷ x」の列が全部同じになることを確認する。
- **展開②（15分）**：ワークシートの予想「a ＝ −2 のグラフは右上がり？右下がり？」→ ② で a を −2 に。正・負のいろいろな a で「＋ 記録する」。「📌 残す」で急さをくらべ、a の符号と向き・絶対値と急さをまとめる。
- **練習（10分）**：③ でグラフから式、④ で変域。
- **まとめ（5分）**：ワークシートの④に「a ＞ 0 なら右上がり、a ＜ 0 なら右下がり。|a| が大きいほど急」。

## つまずき検知の一覧

| 型 | どこで見つけるか | 練習するパート |
|---|---|---|
| x÷y と y÷x のとりちがえ | ①③ で、比例定数の逆数（x÷y）を答えた（符号もちがう場合もふくむ） | ① |
| 比例定数の符号のまちがい | ①③ で、符号だけが反対の数を答えた | ① |
| 急さを a の大きさ（符号つき）でくらべた | ③ の「どちらが急？」で、符号つきの a が大きいほうを選んだが、絶対値はもう一方が大きかった | ③（符号がちがう2本が出る） |
| 変域の端の記号（≦ と ＜） | ④ で、数は合っているが ≦・＜ がちがう | ④（＜ が多く、a が負の問題が出る） |
| a が負のときの y の変域の大小 | ④ で、左右の数が逆（大きいほう ≦ y ≦ 小さいほう） | ④（a が負の問題が出る） |
| y の変域の値のまちがい | ④ で、端の値がちがう | ④ |

「🔎 あなたのつまずき」に、この時間に出た型と説明が出ます。「🔁 この型を練習」で、その型が出やすい問題のパートへ移ります。
⑤ では、わり算した答え（x ÷ a）・たし算した答え（a ＋ x）に、それぞれ短い説明を出します（つまずきの型としては数えません）。
記録は、この端末の localStorage（キー `ikechan-math-比例をつくろう`、ワークシートと同じ）に入ります：つまずきの型ごとの回数・パートごとの正解の数・ヒントの回数。先生モードで合計を見たり消したりできます。

## 正しさとじっさいとのちがい

- 比例定数・表の値・変域の判定は、すべて分数（Fraction）で厳密に計算しています。答えは 3/2 でも 1.5 でも正解です。
- ② の点 P のドラッグは 0.1 きざみ（すいつくときは 0.5 きざみ）です。
- ⑤ の水そうは、水が毎分同じ量ずつ入りこぼれないもの、歩く速さは、とちゅうで止まらずずっと同じものとしています。⑤ のグラフは変域 0 ≦ x ≦ 10（5）の部分だけ描いています。
- 乱数の問題は、同じ問題が続けて出ないようにしています。① の見せる行は ±1 以外（a がすぐにわからないように）、③ の直線は格子点を通るものだけです。

## 先生がかえやすいところ

- ① の比例定数の候補：`POOL1`、③：`POOL3`、④：`POOL4`、② のチャレンジ：`TGT_A`。
- ⑤ の場面：`SC`（名前・a のはんい・x と y の最大・ことばの式）。
- つまずきの型：`TRIPS` に名前・説明・練習するパートを書きます。
