# おって まわして 対称な図形（折ると ぴったり、回すと ぴったり）

小学6年生の算数「対称な図形」で使う、線対称・点対称のシミュレーション教材です。次のことを体験します。

- **線対称**：対称の軸で折ると、ぴったり重なる。対応する点を結ぶ線は**軸と垂直に交わり**、軸から対応する点までの**長さが等しい**
- **点対称**：対称の中心のまわりに180°回すと、ぴったり重なる。対応する点を結ぶ線は**対称の中心を通り**、中心から対応する点までの**長さが等しい**
- この性質を使って、対称な図形をかく
- いろいろな多角形を対称の観点で整理する（**正多角形の軸の数＝辺の数**、**辺の数が偶数の正多角形は点対称**）

## 基本情報

- **ファイル**：`おって まわして 対称な図形.html`。この1ファイルだけで動きます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。方眼と図はすべて SVG（エスブイジー：線や図形を式で描く画像）で描いています。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。
  - 画面の幅に合わせて、図とパネルの並び方が変わります（広い画面は横、せまい画面は縦）。ボタンは48px以上です。
- **漢字**：6年生までに習う漢字にふりがなをつけています。「称」「軸」は小学校で習わないので、ふりがなOFFでも「対称（たいしょう）」「軸（じく）」のふりがなは残します。
- **記録**：保存されるのは「せってい」だけです。児童の名前など個人情報は扱いません。

## モード

| モード | 内容 |
|---|---|
| ✏️ うつして かこう | 方眼の点をタップして線をかくと、軸（または中心）の反対側に自動でうつる。「📖 折る」で紙を折る3D風アニメ、「🔄 180° 回す」でトレーシングペーパーを回すアニメ。「👆 しらべる」で対応する点に同じ色・形の印、直角の印、等しい長さの印、マスの数。軸はたて・よこ・ななめ、中心は方眼の点・マスのまん中・辺のまん中に置ける。じどうでうつすOFFで、自分でかいて「✔ たしかめる」 |
| 🔍 対称かな？ | 文字8こ・オリジナルのマーク6こ・多角形4この18こ。①線対称？点対称？を選ぶ → ②軸をドラッグで引いてぜんぶさがす → ③対称の中心をタップ |
| ✂️ 半分から かこう | 半分の図と軸（中心）から、残りの頂点をタップで置いて完成させる（線対称4問・点対称4問） |
| 🔷 多角形の なかま分け | 正三角形〜正八角形・長方形・ひし形・平行四辺形・台形・二等辺三角形の11こを、折る・回すで調べて表にまとめる。全部正かいで「きまり」と正十角形・正九角形の問題 |
| 🧑‍🏫 先生モード | 図形とやり方（軸で折る・180°回す・対角線で折る（まちがい））を選び、1ステップずつ再生（じどうもあり） |

## つまずきへの対応

| つまずき | 教材の反応 |
|---|---|
| 平行四辺形を線対称だと考える | 対角線で折るアニメを見せ、ずれて重ならない様子（はみ出た部分）を見せる。「でも 回すと…？」と点対称へつなげる。先生モードにも「対角線で 折る（まちがい）」がある |
| 対応する点をとるとき、マスを数えまちがえる | もとの頂点を光らせ、軸までのマスに 1・2・3 の番号をつけて「軸から 左に 3マス → 右に 3マス」。2回目は置く場所も光らせる |
| 点対称の対応する点を、同じ向きにとってしまう | 中心から頂点までの道すじ（よこ→たて）と「右1・上3」、反対側は「左1・下3」と、向きが逆になることを見せる |
| 軸を1本見つけて終わりにする | 「✔ もう ない」で、まだあれば「まだ あるよ」。軸の本数は先に教えない |
| 軸ではない線で折る | その線で実際に折って、ずれる様子を見せる |
| 対称の中心の場所がわからない | 「💡 ヒント」で、対応する点を結んだ線2本が交わるところが中心だと見せる |
| 線対称・点対称の両方なのに片方だけ選ぶ | 選ばなかった方の動き（折る・回す）で、ぴったり重なることを見せる |

## しくみ（コードのつくり）

- **図形は点と線の配列**：かいた図は `{ pts: [点…], segs: [[点の番号, 点の番号]…], dots: [点の番号…] }`。文字・マーク・多角形は、まん中からの座標の配列（`SHAPES`）です。
- **座標変換の関数**：鏡うつしは `reflect`（方眼にそろえる）・`reflectAny`（どんな向きの軸でも）、180°回転は `rotate180`。うつした図は `mapFig` でまるごと計算します。
- **線対称・点対称かの判定**（`analyze`）：
  - 軸も中心も、図形の重心（辺のまん中を長さで平均した点）を通ります。
  - 重心から頂点・辺のまん中・2つの頂点のまん中へ向かう向きを軸のこうほにし、すべての辺がうつした先でも辺になっているかを調べます。正五角形・正七角形のような方眼にのらない図形でも同じ計算で調べられます。
  - かいた図の判定（`symmetryMisses`）は、線を1マスぶんの小さな線（かけら）に分けてくらべます。A–B–C と A–C を同じ線として扱うためです。
- **折るアニメ**（`foldSceneSVG`）：軸から折る側の点は、軸にそった長さはそのままで、軸からのきょりを cos(角度) 倍にします。持ち上がった高さのぶんだけ遠近法で大きく見せ、3D風にしています。紙のうらが見えたら、うすい黄色ですけるようにして、下の線と重なる様子を見せます。
- **回すアニメ**（`rotSceneSVG`）：SVG の `rotate` で、うすい紙ごと中心のまわりに回します。回った角度を弧と数で表示します。

## 色と形（色だけで区別しない）

| もの | 色 | ほかの区別 |
|---|---|---|
| かいた線・もとの図 | 青 | 実線、頂点は ● |
| うつった線・置いた頂点 | オレンジ | 点線、頂点は ◆ |
| 対称の軸 | ピンク | 一点鎖線と「対称の軸」の札 |
| 対称の中心 | ピンク | ◎ と「対称の中心」の札 |
| 対応する点（3組） | 赤・緑・むらさき | ● ▲ ■ の形、等しい長さの印は ｜ ‖ ⦀ の本数 |
| 重ならないところ | 赤 | 点めつ（動きを減らす設定では点めつしない） |
| 折った・回した図形 | オレンジ（すける） | 点線のふち |

## 動作確認の方法

1. `おって まわして 対称な図形.html` をブラウザ（Chrome・Edge・Safari）で開きます。
2. ✏️ うつして かこう（線対称）：
   - 方眼の点を3つタップし、最後の点をもう一度タップ → 軸の反対側にオレンジの点線でうつる。
   - 「📖 折る」→ 紙が持ち上がって重なり、「ぴったり 重なったね！」と出る。「📖 ひらく」でもどる。
   - 「👆 しらべる」で点をタップ → 同じ印の点、直角の印、「3マス」「3マス」が出る。
   - 「📏 軸」で、ななめにドラッグ → ななめの軸になり、うつる場所が変わる。
   - 上の「じどうで うつす」を OFF →「👉 れい」→「✔ たしかめる」→ 反対側がないので赤く光る。
3. ✏️ うつして かこう（点対称）：上の「点対称」→「👉 れい」→「🔄 180° 回す」→ 紙が回って、180°で「ぴったり」。「📍 中心」でマスのまん中をタップすると、中心が動く。
4. 🔍 対称かな？：「平行四辺形」で「線対称だけ」→ 対角線で折ってずれる。「点対称だけ」→ 中心をタップ → 回って「平行四辺形は 点対称」。「H」で「両方」→ たて・よこにドラッグ →「✔ もう ない」→ 中心をタップ。
5. ✂️ 半分から かこう：わざとちがう点をタップ →「軸から 左に 3マス…」とマスに番号が出る。もう一度まちがえると置く場所が光る。全部置いて「📖 折る」。
6. 🔷 多角形の なかま分け：正六角形で「📖 軸で 折って みる」→ 6本数える。「🔓 こたえを 見る」→ きまりと正十角形の問題が出る。
7. 🧑‍🏫 先生モード：平行四辺形の「対角線で 折る（まちがい）」を「▶ つぎ」で進める → ずれる。「180° 回す」に切りかえて6ステップ進める → 対応する点ときまり。
8. ⚙️ せってい：方眼の大きさ、じどうで うつす、ふりがな OFF（「対称」「軸」のふりがなは残る）、動きを減らす（アニメがなくなりすぐ結果が出る）。

## 授業例

### 1. 線対称の性質（1〜2時間目）

1. 🔍 対称かな？ で「A」「やじるし」「ハート」などを電子黒板に出し、「2つに折るとぴったり重なる」形を集める。軸をドラッグで引いて折ってみせ、「線対称な図形」「対称の軸」ということばをおさえる。
2. 「H」「X」「ほし」で、軸が2本・4本ある図形があることに気づかせる（「✔ もう ない」で本当に全部か確かめる）。
3. ✏️ うつして かこう（線対称）で、児童が自由に模様をかく。「👆 しらべる」で対応する点を3組出し、「結ぶ線と軸はどうなっている？」「軸からの長さは？」と問う。直角の印と、マスの数が同じことから性質をまとめる。
4. 🧑‍🏫 先生モードの「ひし形」「軸で折る」をステップ再生し、6ステップ目で性質を全体で確認する。
5. ✂️ 半分から かこう の線対称4問で、性質を使ってかく。まちがえた児童には、マスを数えるヒントを見ながら説明させる。

### 2. 点対称の性質（3〜4時間目）

1. 🔍 対称かな？ で「平行四辺形」を出す。「線対称？」と問い、線対称だと答えたらそのまま選んで、対角線で折ってずれる様子を見せる。
2. 「でも 回すと…？」で「点対称だけ」を選び、中心をタップして180°回す。「点対称な図形」「対称の中心」ということばをおさえる。「N」「S」「Z」「かざぐるま」でもためす。
3. ✏️ うつして かこう を「点対称」にして模様をかき、「🔄 180° 回す」で確かめる。「👆 しらべる」で、結ぶ線が中心を通ること、中心からの長さが等しいことを見つける。
4. 🧑‍🏫 先生モードの「平行四辺形」で「対角線で 折る（まちがい）」→「180° 回す」と続けて見せ、2つの対称のちがいをまとめる。
5. ✂️ 半分から かこう の点対称4問。「中心から 右1・上3 なら、反対は 左1・下3」と、向きが逆になることをおさえる。

### 3. 多角形と対称（5時間目）

1. 🔷 多角形の なかま分け を開き、グループごとに担当の図形を決めて、折る・回すで調べる（タブレットなら各自で）。
2. 結果を表に書き、「✔ こたえあわせ」。まちがえた所は、もう一度折ったり回したりして確かめる。
3. 全部正かいすると、偶数の正多角形の行が黄色になる。「正多角形の軸の数は？」「点対称になるのはどんなとき？」と問い、きまりを見つける。
4. 「使って みよう」の正十角形・正九角形の問題で、図をかかなくてもきまりで分かることを確かめる。
5. 長方形・ひし形・平行四辺形・台形のちがいを、軸の数と点対称かどうかで整理する（4年「四角形」とのつながり）。
