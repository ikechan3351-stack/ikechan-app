「小数の あつかい」は、平均が わり切れない ときに、どの 位まで 出すかです（その 下の 位を 四捨五入して「約」を つけます）。「じどう」は パソコンの「視差効果を 減らす」などに あわせます。「へらす」に すると、水面が 動く・ブロックが とぶ などの アニメが なくなり、すぐに 切りかわります。

❓ 先生へ（つかい方）

5年「平均」の教材です。でこぼこな量を「ならして」同じ大きさにしたものが平均であり、合計÷個数で求められることを、動きで体感します。

🥤 ならして みよう

  • 「🥤 コップ」と「🧱 ブロック」を切りかえられます。どちらも同じデータ（1こ＝1dL）です。
  • コップ：「〰 ならす」で、多いコップの水面が下がり、少ないコップの水面が上がって、同じ高さになります。上に出る矢印が「どこから どこへ 何dL」を表します。「1つずつ」にすると、1回おすごとに1つの移しかえだけが動きます（説明しながら進めたいとき）。
  • ブロック：高い列のブロックを、低い列へドラッグして移します（タップで「えらぶ → 置く列をタップ」でも動かせます）。移したブロックは、点線のわくになり、もとの列の番号が書いてあります。「👉 おてほん」で1こずつ自動で移します。
  • 「― 平均の 線」を出すと、線より上の「はみ出た ぶん」（赤・斜線）と、線より下の「足りない ぶん」（青・点線のわく）が色と模様で表示され、右のパネルで同じ量であることが分かります。
  • 右の「データを かえる」で、コップの数（2〜8こ）と量（0〜10dL）を変えられます。合計・個数・平均は自動で変わります。上の「れい」から用意したデータを選べます。
  • 「平均の 数：かくす」にすると、平均の数が「？」になります（先に予想させたいとき）。ならし終わると表示されます。
  • 平均がわり切れないデータ（れい5）では、ブロックはそろいきらないので、コップでならすと小数になることを見せられます。

🧮 計算で もとめよう

  • 合計 → 個数 → 平均（合計÷個数）の順に、下のキーで答えを入れます。5問（ジュース・たまご・図書室の人数・ボール投げ・りんご）。
  • 平均が最大値より大きい／最小値より小さい答えには、「ならすとその間になるはず」と出し、いちばん大きい・小さい列を光らせます。わる数とわられる数の逆、四捨五入の位のちがいにもことばを返します。
  • 正かいのあと「〰 ならして たしかめる」で、計算の答えとならした高さが同じになることを確かめます。図書室の人数（21.4人）では、人数でも平均は小数になってよいことをおさえます。

0️⃣ 0が あるとき

  • 欠席者数（木曜日0人）など、0をふくむデータの平均を答えます。0を個数に入れ忘れた答え（7÷4など）を見つけると、空のコップを光らせて知らせます。
  • 「0も 入れて ならす」「0を ぬかして ならす」で、2つの結果をくらべます。ぬかすと0の日のコップは「かぞえない」になり、空のまま残ります。

🍊 平均から 合計へ

  • みかん（65g×40こ→約2.6kg）、読んだページ、欠席（3.4人×5日＝17人）、たまご（3kgは何こ分？：合計÷平均）の4問。
  • 大きさのちがう絵が「〰 ならす」で同じ大きさにそろい、「平均が個数分」と考えられることを見せます。わり算・たし算にした誤り、gとkgのまちがいにことばを返します。

👣 歩はばで はかろう

  • 上のらんに、10歩の距離を5回はかった記録（m）を先生が入れます。ろう下の歩数も ＋− で変えられます。
  • ①10歩の平均 → ②1歩の歩はば（1/100の位まで）→ ③ろう下の長さ（歩はば×歩数）の順に答えます。

📏 かりの 平均（発展）

  • 緑の線（かりの平均）をドラッグか ▲▼ で決め、「▶ つぎ」で、線より多いぶん・少ないぶんの合計 → その差を個数でわる → かりの平均にたす・ひく、と進みます。負の数は使わず「多い・少ない」で表しています。
  • 最後まで進めたあと線を動かすと、どこに線を引いても平均は同じになることが分かります。

🧑‍🏫 先生モード

  • データ（2〜10こ、小数も可）を入れて「✔ ひょうじ」。単位とコップ／ぼうを選べます。
  • 「▶ つぎ」で、データ → 合計 → 個数 → 平均の線 → 移しかえを1回ずつ → まとめ、とステップ再生します。「⏯ じどう」で自動で進みます。平均の数はまとめまで「？」です。
