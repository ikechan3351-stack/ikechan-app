# 🟧 分数学習ボード

4年「分数」（大きさの等しい分数・仮分数と帯分数）で、子どもが**自分で分数タイルをならべて見つける**ための自由な板です。正解・まちがいの判定はしません。そろっているかは、子どもが「たての線」で自分でたしかめます。

- **ファイル**：`分数学習ボード.html`（1つのファイルだけで動きます。ネット接続・外部ライブラリは不要）
- **企画メモ**：脳メモ `教材開発/企画/2026-11-18_分数学習ボード.md`
- **状態**：テープ（3番目の段階まで）＋ ●円（えん）モードの最小版（2026-11-18）＋ たし算・ひき算のカード・わく・はいけい（2026-11-21）

## 使い方

1. 左の道具箱のタイル（1・½〜1/12）を**タップ**すると、あいている列の左はしに1まい出ます。同じタイルを続けてタップすると、右どなりにつながります（¼を4回タップ → 1と同じ長さ）。
2. タイルは**ひっぱって**すきな列に置けます。列の左はしや、同じ列のとなりのタイルの端にぴたっとすいつきます（ほかの列のタイルにはすいつきません。そろっていないものが、そろって見えないようにするため）。
3. **↕️たての線**を出して ↔ を動かすと、タイルの端がそろうかたしかめられます。線はタイルの端と 1・2・3 にすいつきます。
4. **1のながさ**：「1まで」は1を大きく（1/12 も約80px）、「3まで」は 7/4 のような仮分数をならべるとき。1をこえて並んでいるときは「1まで」にもどせません。
5. ✏かく・📏ちょくせん で書きこみ、📷しゃしん でロイロにはりつけて提出します。
6. ごみばこ、または道具箱にもどすとタイルが消えます。↩もどる・↪やりなおす・🧹かたづける は ①〜⑥ と同じです。
7. **わくだけタイル**：タイルを**長おし**（動かさずに約0.5秒）すると「⬚わくだけ／🗑けす」のメニューが出ます。わくだけにすると色がぬられない点線のわくになり、中にほかのタイルを入れられます（「½のわくに ¼は何まい入る？」）。わくは上下に少し大きいので、中にタイルを入れてもわくが見えます。もう一度長おしすると「いろを ぬる」でもどせます。
8. **まとめて動かす**：タイルのない所からひっぱって、四角でかこむと、中のタイルがえらばれます（オレンジのふち）。えらんだタイルのどれかをひっぱると、いっしょに動きます。何もない所をタップすると、えらぶのをやめます。
9. **☰せってい**：
   - **タイルの字**：分数（ふつう）／小数／百分率／かくす。わりきれないものは「0.33…」「33.3…%」のように切りすてて「…」をつけます。ほそいタイルで字が横に入らないときは、たてに書きます。「かくす」にすると色と長さだけになり、「このタイルは何分の1？」と考えさせられます（道具箱の字も消えます）。
   - **つかう分母**：道具箱に出すタイルをえらびます（例：½・¼・⅛ だけ）。ボードにあるタイルはそのまま残ります。
   - アドレスの最後に `?den=2,4,8&label=hide` のようにつけても選べます。ブックマークして配れます（アドレスの指定が、保存された設定より優先）。
   - ☰ は**先生モードだけ**に出ます。子どもは字や分母を変えられません（先生が 💾くばる で配った設定、またはアドレスの設定が使われます）。

## ●円（えん）モード（4年 仮分数・帯分数）

ツールバーの **▬テープ｜●円（えん）** で切りかえます（だれでも切りかえられます）。ボタンの小さな数字は、それぞれに置いてあるピースの数です。テープと円の盤面・ペンの線は別々に覚えています。アドレスに `?board=circle` をつけると円で開きます。

1. 上に円のわく（**大きく2つ／ふつう3つ** で切りかえ。3つめの円にピースがあるときは2つにできません）、下が **おきば** です。12時の位置に ▼ の印があります。
2. 道具箱の扇形（1・½〜1/12）を**タップ**すると、**おきば**に出ます（円には入りません。どの円に入れるかは子どもが決めます）。道具箱から円の上へ直接ひっぱって入れることもできます。
3. ピースを円の上ではなすと、その円の**12時から時計まわりに、すでにあるピースのつづき**にぴたっと入ります。
4. 円からピースを取り出すと、残りのピースが12時からつめて並びなおします。
5. **入りきらない**ときは、おきばにもどって「この 円には もう 入らないよ」と出ます（自動で次の円には行きません。ピースを切ることもしません）。
6. **とりかえ**（1＝4/4）：うまった円のまわりをかこんでピースをえらび、ごみばこへ → 「1」のピースを入れる。アプリは自動でまとめません。
7. 長おしメニュー（わくだけ・けす）、☰の字の切りかえ・使う分母、ペン、もどる、📷しゃしん（いま見えている方）、💾くばる（テープと円の両方と、どちらで開くか）、つづきから はテープと同じです。分数のかべ・1のながさ・たての線はテープだけです。

## たし算・ひき算（カード・わく・はいけい）2026-11-21

3・4年の「分母が同じ分数のたし算・ひき算」（4年は仮分数・帯分数も）と、大きさくらべに使います。さんすうボード①②③⑦・⑩と同じ形にそろえました。判定はしません。

道具箱の上の **タブ**（タイル〔円のときは ピース〕・わく・カード）で中身を切りかえます。

### わく（道具箱の「わく」タブ）

- **タップ**するとボードいっぱいに しかれます（はいけいの ように いちばん下）。わくは1つだけで、ちがう わくを おすと とりかわります。**同じ わくを もう一度おすと とれます**（のっているタイルは のこります）。テープと円で べつべつに持ちます。
- **あわせる わく**（たし算・ひき算）
  - テープ：上から「ぶぶん」（列1〜2）・「ぶぶん」（列3〜4）・「ぜんぶ」（列6〜7）の帯。1のものさしと左はしがそろったままなので、ぜんぶが1をこえたかも見えます。
  - 円：「ぶぶん」「ぶぶん」「ぜんぶ（円2つ）」の4つの円。ぜんぶは円2つなので、¾＋½ のように1をこえる答えも 1と¼ で表せます。
  - 子どもが ぶぶん の タイル・ピースを「ぜんぶ」へ**ひっぱって**あわせます（自動で集めるボタンはありません）。ひき算は ぜんぶ から ぶぶん へ動かします。
- **くらべる わく**（大きさくらべ・等しい分数）
  - テープ：上下2本の帯。円：左右2つの円。
  - まん中（テープは左はし）の **まる** をタップすると「＝ ＞ ＜ けす」が出ます。
- わくが あるあいだ、円の数（大きく2つ・ふつう3つ）のボタンは かくれます。わくで 円が へって 入らなくなったピースは おきばへ もどります。

### カード（道具箱の「カード」タブ）

- **数字カード** 0〜9、**きごうカード** ＋ − ＝ ＞ ＜ ？、**分数カード**。
- タップすると あいている所（上の左から）に出ます。ひっぱって どこにでも置けます。ごみばこ か 道具箱へ もどすと消えます。テープと円で べつべつに持ちます。
- **分数カード**：出すと すぐ「数を入れる画面」が出ます。**分母から**入れます（しかくを えらんで 数字をおす。キーボードの数字・Tab・Enter も使えます）。帯分数のときは左の「せいすう」にも入れます。あとで カードを タップすると 書きなおせます。数字カードを上下に重ねると ずれやすいので、1まいにまとめました。

### 🖼 はいけい（だれでも）

- **かみ**：むじ／ほうがんし（30px のマス）／さんすうノート（15マス）。**いろ**：しろ／クリーム／こくばん。色は さんすうボード⑩・方眼ボードと同じです。
- こくばんのときは、ものさしの数字・点線・円の▼・目もりの輪 を白っぽくし、タイルに白いふちをつけ、**くろのペンは白いチョークの色**で かきます（ほぞんの中身は くろのまま）。
- アドレスに `?bg=note&color=cream` のようにつけても選べます（bg＝plain・grid・note、color＝white・cream・green）。はいけいは ↩もどる には入りませんが、つづきから・💾くばる には入ります。

### 授業での使い方（例）

- 3年「2/5＋1/5」：あわせるわく → ⅕を2まい（ぶぶん）・1まい（ぶぶん） → 「ぜんぶ」へ ひっぱって 3まい → 分数カード 3/5 と ＋・＝ カードで式に。
- 4年「¾＋2/4」：円の あわせるわく → ぜんぶの円が1つうまって ¼ のこる → 「5/4＝1と¼」をペンで書く。
- くらべるわく：⅔ と ¾ をならべて、まるを ＜ に。たての線で 端をたしかめる。

## 先生モード

- **🎯目もり**（円のときだけ）：円のまわりに目もりの輪を出します。こまかさは ☰せってい で 2〜12とうぶん・百分率（10%ずつ）から選びます。数字はタイルの字（分数・小数・百分率）に合わせます。輪があるときは、数字が重ならないよう円を少し小さく・下にします。保存も配布もしません。

右上の **🧑‍🏫せんせい** を押すと先生モードになります（アドレスに `?teacher=1` が入ります。ボードはそのまま続きます）。「せんせい おわる」で子ども用にもどります。

- **🧱かべ**：つかう分母の 1/□ を 0〜1 にうすくならべた「分数のかべ」を、タイルの列と同じ高さで背景に出します（分母が9こ以上のときはつめてならべます）。まとめで電子黒板に映し、たての線で「みんなの発見と同じかな」とたしかめます。かべは保存も配布もしません（子どもには見えません）。
- **📝もんだい**：ボードのいちばん上にもんだいカード（2行まで）を出します。子どもは動かしたり消したりできません（子どもの 🧹かたづける でも残ります）。
- **💾くばる**：いまのボード（タイル・ペン・たての線・1のながさ・もんだいカード）と設定（タイルの字・つかう分母）が入った PNG 画像を作ります。Classroom などで配り、子どもは **📂ひらく** で選ぶと、動かせるボードにもどります。**⟲はじめに** で配られたときの形にもどせます。
  - JPG にしたり、スクリーンショットにしたりすると、ボードが消えます。
  - ほかのさんすうボードの画像を開くと「そちらでひらいてね」と出ます。
- **☰せってい**：タイルの字・つかう分母（上の 9.）。

## 算数操作ボードセット から ひらいたとき

- 「算数操作ボードセット」のカードから開くと（`?high=1`）、左上が「🏠 ボードえらび」になり、入り口にもどれます。そのタブで2回目からは「つづきから？」を聞かずに続きを開きます。

## 画面のつくり

- いちばん上に**1のものさし**（0・1・2・3 の目もり）。1・2・3 のところから下へうすい点線がのびていて、「いくつの1か」がいつも見えます（つまずき「もとの1をわすれる型」への対策）。
- タイルの列は8列。上の余白は予想やメモを書く場所です。
- 色は分母ごとにちがいます。色だけで区別しないよう、どのタイルにも分数を字で書いています。

## しくみ（コードのつくり）

- タイルの位置は「1を **27720**（1〜12の最小公倍数）目もりに分けた、いくつ分か」の整数で持っています。どの分数の端もぴったり整数になるので、⅙×3 と ½ の端が完全に同じ値になり、「1のながさ」を切りかえてもならびがくずれません。
- タイル1まい＝ `{ d: 分母, t: 左はしの目もり, r: 列, o: わくだけ }`。わくだけタイルとは重なってよく（`overlaps()`）、わくの左はし・右はしにもすいつきます。まとめて動かすときは、つかんだタイルを `settle()` し、ずれた分だけほかのタイルも動かします。字の大きさは `textFont()` が実際の字の幅を測って決めます。すいつきは `settle()`、タップで出す場所は `tapSpot()`、たての線のすいつきは `snapVline()`。
- 1のながさは `LENS`（1まで＝1000px、3まで＝350px）。分母の色は `COLORS`。
- カード＝ `{ k: しゅるい（n0〜n9・plus・minus・eq・gt・lt・q・fr）, x, y, v: tape|circle, a: 分子, b: 分母, c: 帯分数の整数 }`。形は `cardLayout()` が決め、画面（SVG）と しゃしん（canvas）で同じものを使います。わく＝ `frame.tape`／`frame.circle` に `{ t: awase|kurabe, s: まるの きごう }`。テープの帯は `TAPE_BANDS`、円の数は `nC()`（わくがあるときは わくで決まる）。はいけいは `bg`（`BG_KINDS`・`BG_COLORS`）、こくばんの色の切りかえは `onBg()`・`inkCol()`。
- 円のピース＝ `{ d, c: 円の番号（-1はおきば）, s: 円の中の始まりの目もり, x, y: おきばでの中心, o }`。円の中の位置もテープと同じ「1周＝27720目もり」なので、入るかどうか（`tryInsert()`）・つめなおし（`repack()`）が整数で計算できます。扇形は SVG の path で描き、色のついた所だけがさわれます。
- くばる画像：PNG の中に文字の箱（tEXt、キー `fraction-board`）を足し、盤面を圧縮して入れています（さんすうボード①〜⑦と同じしくみ）。
- つづきから：localStorage のキー `ikechan-math-分数学習ボード` に自動保存。
