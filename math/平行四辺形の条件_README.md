# 平行四辺形の条件

中学2年「図形の性質と証明」の平行四辺形を学ぶアプリです。頂点をドラッグして、**平行四辺形の性質**（2組の対辺・対角がそれぞれ等しい、対角線がそれぞれの中点で交わる）を測定値で確かめ、**平行四辺形になるための条件5つ**を「条件を守ったまま動かす」ことで確かめます。さらに、あやしい条件で**反例**をつくり、「1組の対辺が平行で、もう1組の対辺が等しい」が条件にならないこと（等脚台形）を見つけます。長方形・ひし形・正方形の条件と、発展として中点を結んだ四角形も扱います。

## 基本情報

- **ファイル**：本体 `平行四辺形の条件.html`、共通部品 `worksheet.js`・`worksheet.css`（`math-render.js` も読みこむ）。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中2・図形）から開けます。
- **画面**：広い画面は 左＝図・右＝ボタンと表 の2列。スマホは たて1列。
- **色と印のきまり**（色だけで区別しない）
  - 辺：AB・DC＝オレンジ、AD・BC＝青。**平行**の印は ＞（AB・DC）と ≫（AD・BC）、**等しい長さ**の印は 辺の上の短い線 1本（AB・DC）と 2本（AD・BC）。
  - 角：∠A・∠C＝赤むらさき（弧1本）、∠B・∠D＝緑（弧2本）。等しくない角は灰色。直角は四角の印。
  - 対角線：AC＝むらさきの点線（半分が等しいと ○ の印）、BD＝こげ茶の点線（× の印）。
  - 印は、**測った値が本当に等しい（平行な）ときだけ**出ます。
  - 平行四辺形でない形（③）はピンクのしましま、中点を結んだ四角形（⑤）は緑のしましま。正解＝緑の「○」、まちがい＝赤紫の「×」。
- **URL の設定**
  - `?teacher=1` … 先生モード（答え・自動で1ステップ進める・発問の例・この端末のきろく・ワークシートのヒントと解答例）
  - `?ws=0` … ワークシートをとじて開く

## 使い方

図の ● （頂点）をドラッグすると形が変わり、辺の長さ・角の大きさ（測定値）が図と右の表に出ます。○ は条件で決まる点です。「方眼にすいつく」「辺の長さ」「角の大きさ」「対角線」で表示を切りかえられます。辺が交わる形・つぶれる形にはなりません。

### ① 性質

1. 平行四辺形の頂点をドラッグすると、動かした頂点の**向かいの頂点**もいっしょに動いて、平行四辺形のままになります。「🎲 形をかえる」でも形が変わります。
2. 右の表で AB と DC、AD と BC、∠A と ∠C、∠B と ∠D、OA と OC、OB と OD が いつも「＝」になることを確かめます。∠A ＋ ∠B ＝ 180° も出ます。
3. 「なぜ？（証明のすじみち）」をひらくと、対角線で分けた三角形の合同による説明が出ます。
4. 「✏️ 練習問題」：対辺の長さ・対角／となりの角・対角線の半分 を求める（答えをえらぶ）。

### ② 条件をたしかめる

1. 5つの条件から1つえらびます。①2組の対辺がそれぞれ平行 ②2組の対辺がそれぞれ等しい ③2組の対角がそれぞれ等しい ④対角線がそれぞれの中点で交わる ⑤1組の対辺が平行でその長さが等しい。
2. 予想（いつでもなる／ならないこともある）をえらんでから、頂点をドラッグします。**その条件を守ったまま**頂点が動きます。
   - ① は、向かいの頂点が「となりの頂点を通り、辺に平行な直線」の交点になるようすを点線で見せます。
   - ② は、コンパスで長さをうつした2つの円の交点。もう1つの交点（辺が交わってしまう点）も × で見せます。
   - ③ は、2a＋2b＝360° から a＋b＝180° になるよう向かいの頂点が決まります。
   - ④ は、頂点を動かすと向かいの頂点が O をはさんで反対がわへ。O も動かせます。
   - ⑤ は、BC を平行にずらしたものが AD になります。
3. 3回以上動かすと「✅ いつでも平行四辺形」が押せて、一覧に ✅ がつきます。「なぜ平行四辺形になる？」で証明のすじみちも見られます。
4. 「✏️ 練習問題」：「四角形ABCDで ○○ のとき、平行四辺形といえる？」→「いえる（どの条件か）」か「いえない」をえらぶ。図には条件の印をかいた およその形が出ます。

### ③ ならない例

1. あやしい条件を えらびます：あ 1組の対辺が平行で、もう1組の対辺が等しい（AD∥BC、AB＝DC）／い 1組の対辺が平行（だけ）／う 1組の対辺が等しい（だけ）／え 2本の対角線の長さが等しい。
2. 予想をえらび、A・B・C をドラッグします。D（○）は条件の点線の上だけを動きます。
   - 「あ」では、D は「A を通り BC に平行な直線」と「C を中心に半径 AB の円」の交点で、**交点は2つ**あります。D をドラッグすると もう1つの点にうつり、**等脚台形**（反例）になります。
3. 条件を守っているのに平行四辺形でない形になると「🎉 反例 発見！」。続けて「平行四辺形にするには何をたすとよい？」に答えます（正しいものをぜんぶ）。
4. 「✏️ 練習問題」：② と同じ形の問題で、あやしい条件が多めに出ます（とくに「1組平行＋もう1組等しい」）。答えたあと「👀 反例を図でつくる（③）」で、その条件の図にうつれます。

### ④ 特別な平行四辺形

1. 平行四辺形に条件をたします。長方形の条件：「1つの角が直角」か「対角線の長さが等しい」。ひし形の条件：「となり合う辺が等しい」か「対角線が垂直に交わる」。両方の組からえらぶと正方形。もう一度おすと外れます。
2. たした条件を守ったまま頂点が動きます（まん中の ● で全体を動かす）。右に いまの形の名前、仲間の図（★ が いまの形）、成り立つことの表（○／－）が出ます。
3. 「✏️ 練習問題」：「平行四辺形ABCDに ○○ をたすと？」→ 長方形／ひし形／正方形／平行四辺形のまま。

### ⑤ 中点を結ぶ（発展）

1. 四角形 ABCD の頂点を自由にドラッグします（へこんだ形もOK）。4つの辺の中点 P・Q・R・S を結んだ四角形 PQRS がいつも平行四辺形になることを確かめます。
2. 「ふつう・へこんだ形・長方形・ひし形・正方形・等脚台形・平行四辺形」のボタンで ABCD を変えると、PQRS の名前が変わります。対角線 AC・BD を表示して、PQ∥AC、PQ＝AC÷2 をくらべます。
3. 「✏️ 練習問題」：PQ の長さ（対角線の半分）・PQ と平行な線・ABCD が○○のときの PQRS の形。

ボタン：✏️ 練習問題／↶ ひとつもどす（ドラッグ・ボタン操作も1回分もどせる。パートごと）／⟲ もういちど（そのパートをはじめの形に。✅ や見つけた反例は残る）／💡 ヒント（押すたびに次のヒント）／📄 ワークシートの問題（③ の「あ」を開く）。練習問題は「✖ 問題をおわる」で図にもどります。

## 授業での使い方（例）

- **導入（5分）**：① で平行四辺形の性質をふりかえる（小学校のなかま分け → 測定値で確かめる）。
- **展開①（15分）**：② で5つの条件を1つずつえらんで動かす。「この条件だけで向かいの頂点の場所は決まる？」「平行四辺形にならない形はつくれる？」。証明のすじみちを1つ、ノートで書かせてもよい。
- **展開②（15分）**：ワークシートの予想「1組の対辺が平行で、もう1組の対辺が等しいと、いつでも平行四辺形？」を挙手で集める → 「📄 ワークシートの問題」で ③「あ」。D を動かして等脚台形（反例）を見つけ、記録する。「何が足りない？」で ⑤ の条件とくらべる。
- **練習（5分）**：② ③ の練習問題。つまずきが出たら「🔁 この型を練習」「👀 元の図で確かめる」。
- **まとめ**：ワークシートの④に「平行な組と等しい組が同じなら平行四辺形、ちがうと等脚台形の反例がある」。
- **別の時間に**：④ で長方形・ひし形・正方形の条件と仲間の図、⑤ で中点連結（発展）。

## じっさいとのちがい（かんたんにしたところ）

- 方眼の1目もりを 1cm として、長さは小数第1位まで、角は 1° より小さいところを四捨五入して表示しています。合計が 360° からずれないよう、端数の大きい角で調整しています（等しい角は同じ数になるようにしています）。
- 「平行」「等しい」は、画面の上で測った値がほぼ同じ（長さは 0.03cm 以内、向きは約 0.2° 以内）のときとしています。
- ② ③ ④ で条件から決まる点は、方眼にすいつかないことがあります。
- 辺が交わる形（ねじれた形）・つぶれる形にはなりません。② の「2組の対辺が等しい」で、ねじれた形になるもう1つの交点は × の印で見せるだけです。
- 練習問題の図は およその形です（印で条件を表しています）。
- 「等脚台形」「たこ形」は、教科書によっては出てこない名前です（画面の下に説明があります）。
- ⑤ の中点連結定理は中学3年の内容です（発展）。

| どの線と平行かの取りちがえ | ⑤ の練習問題で、PQ と平行な線に BD・AB・BC をえらんだ | ⑤ |
| 計算・読みとりのまちがい | 上のどれにもあてはまらないまちがい | いまのパート |

「🔎 あなたのつまずき」に、この時間に出た型と説明が出ます。「🔁 この型を練習」でその型の問題があるパートへ移り、「👀 元の図で確かめる」で、その型が見える場面（例：③「あ」の反例づくり、対角線を表示した平行四辺形、長方形の中点を結んだ図）を出します。
記録は、この端末の localStorage（キー `ikechan-math-平行四辺形の条件`、ワークシートと同じ）に入ります：つまずきの型ごとの回数・パートごとの正解の数・見つけた反例の数・ヒントの回数。先生モードで合計を見たり消したりできます。

## ワークシート

- 問題：「1組の対辺が平行で、もう1組の対辺が等しい四角形は、いつでも平行四辺形になるだろうか？」
- 予想：いつでも平行四辺形になる／平行四辺形にならないこともある／わからない
- 記録する列：条件・できた形・AB・DC・AD・BC・平行四辺形？（① 〜 ④ で記録できる。⑤ は記録しない）
- まとめのヒント：「1組の対辺が平行で、もう1組の対辺が等しいとき、〜になることがある（反例）。平行四辺形の条件は、1組の対辺が〜」
- 先生用の解答例：いつでも平行四辺形になるとはかぎらない（等脚台形が反例）。平行四辺形になるのは「1組の対辺が平行でその長さが等しい」とき。

## 先生が改造するとき

- つまずきの型は `TRIPS`、パートの名前と説明は `PARTS`、② ③ の条件（動かし方・説明・「何をたす？」の選択肢）は `CONDS`、④ のたす条件は `EXTRA`、練習問題は `makeQ`（② ③ の問題文は `stmtBank`、④ は `BANK4`、⑤ の形は `MID_SHAPES`）にまとまっています。
- 「平行」「等しい」とみなす はばは `PAR_TOL`・`LEN_TOL`、図の大きさは `W`・`H`、方眼の1目もりは `G`、はじめの平行四辺形は `PG0`、⑤ の形の例は `MID_EX`。
- 色は CSS の `--p1` などと、JS の `COL` の両方にあります（同じ値にそろえてください）。
