# 🧮 ブロック・おはじき操作盤

算数セットの代わりに、画面上で自由に使える教具です。**決まった問題や正解はありません。** 先生が授業の場面に合わせて使ったり、子どもが自分の考えをブロックや図で表して説明したりするための「操作盤」です。

## 基本情報

- **ファイル**：`ブロック・おはじき操作盤.html`。この1ファイルだけで動きます（ネット接続・外部ライブラリ・画像ファイルは不要。素材の絵はすべてSVGで描いています）。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。画面がせまいとき（たてのタブレット・スマホ）は、パレットが上に横並びになります。
- **マルチタッチ**：指1本ずつ別々に追いかけるので、何人かで同時に別の素材を動かせます。

## 素材（左のパレットから引っぱって出す／タップで出す）

| 素材 | できること |
|---|---|
| ブロック ばら（1）・ぼう（10）・いた（100） | ばら10こを選んで「まとめる」→ぼう1本。ぼうを「ばらす」→その場でばら10こ。いた⇔ぼう10本も同じ。数えると「いた1まい・ぼう2本・ばら3こ → 123」 |
| おはじき 4色 | あか（まる）・あお（しま）・きいろ（てん）・みどり（わ）。**色と模様の両方**で区別できます |
| 数え棒 | 15°ずつ回せます |
| 数字カード 0〜9、記号カード ＋ − × ÷ ＝ ＜ ＞ | 式をつくって説明に使えます |
| 分数ピース（円・テープ） | 分母 1〜12 をパレットの上で選びます。円は中心が自動でそろい、回すと 1/d ずつ回ります。テープは横につなげたり、下に重ねてくらべたりすると、ぴったりくっつきます。数えると「1/4 が 3こ あわせて 3/4」 |
| 図形ピース | 直角二等辺三角形・直角三角形・正三角形・正方形・長方形・平行四辺形・台形・ひし形。15°ずつ回す・うらがえす |
| お金 | 1・5・10・50・100・500円玉、1000・5000・10000円札（実物ではなく、かんたんなデザイン）。合計金額を表示 |
| 時計 | 長いはり（青・細い）、短いはり（赤・太い）を指で回せます。長いはりを1周すると、短いはりも1時間進みます。「じこくを みせる」で「3じ 15ふん」と表示 |

## 操作盤の機能

- **はいけい**：むじ・方眼・点の格子・位取り表（千〜一、小数第一位）・10フレーム（2×5 を2つ）・数直線（0〜20）
  - 方眼・点の格子のときは、ブロックと図形ピースがマスにそろいます（せっていで切れます）
- **えらぶ**：何もないところを指でぐるっと囲む。素材をタップすると1つずつ選べます
- **えらんだものへの操作**：グループにする／とく、ふくせい、5こずつ・10こずつ ならべる、まとめる・ばらす、まわす、うらがえす、けす
- **消し方**：素材をパレットの上まで引っぱってもどすと消えます。選んで「🗑 けす」でも消せます
- **🔢 かず**：盤面の素材を自動で数えて下に表示します（選んでいるときは選んだものだけ）。ボタンで表示・非表示を切りかえます
- **✏ ペン**：5色（名前つき）・太さ3種類・けしゴム（さわった線をまるごと消す）。何本の指でも同時に書けます
- **↩ ひとつもどす**（最大50回）・**🧹 ぜんぶけす**（もどせます）
- **⚖ くらべる**：盤面を左右に分け、「こうした 人」「ああした 人」の考えを並べます。名前は書きかえられます。数は左右別々に出ます。「左を 右に コピー」で、同じところから別のやり方を試せます
- **💾 ほぞん**
  - 画面を **PNG** で保存（下に日付と数が入ります）。発表の記録や、学習支援ソフトへの提出に使えます
  - 置き方を **JSON ファイル** に書き出す・読みこむ。授業の前に盤面を準備しておけます
- **⚙ せってい**：ふりがな、動きを減らす、マスにそろえる、**先生用：パレットに出す素材**（1・2年／3・4年／5・6年／ぜんぶ の切りかえ、1つずつ選ぶこともできます）、素材の最大数（初めは300こ）。この設定はブラウザに覚えておきます
- **⛶**：フルスクリーン
- **キーボード**：Ctrl+Z（Mac は ⌘+Z）でもどす、Delete で消す、矢印キーで動かす、Esc で選ぶのをやめる

## しくみ（コードのつくり）

- **すべての素材を1つの配列で持っています**：
  ```
  state.items = [ { id, type, x, y, rot, flip, props, group }, ... ]
    type  … 素材の種類（定義表 MATERIALS の名前）
    x, y  … 中心の位置（盤面は よこ1400 × たて880 の座標）
    rot   … 角度   flip … うらがえし   props … 色・数字・分母・時刻などの状態   group … グループ番号
  state.strokes = [ { color, width, pts: [[x, y], ...] }, ... ]   … ペンの線
  ```
  - 「ひとつもどす」は、操作の前にこの2つの配列のコピーをとっておき、それを戻すしくみです。
  - JSON の書き出し・読みこみも、この配列をそのまま使います。読みこむときは、知らない種類を捨て、数値を確かめてから取りこみます。
- **素材の定義表 `MATERIALS`**：1種類ごとに、名前・大きさ・絵（SVG）・回す角度・数え方・まとめる／ばらすのきまりを書きます。**ここに1つ足すだけで、パレット・数える・ならべる・保存に自動でつながります。** 背景も `BACKGROUNDS` に足すだけで増やせます。
- **学年ごとの素材の組み合わせ**は `PRESETS` で変えられます。

## 動作確認の方法

1. `ブロック・おはじき操作盤.html` をブラウザ（Chrome・Edge・Safari）で開く。
2. パレットの「ばら」を12回タップ → 左上から順に並ぶ。下の数が「ばら 12こ → 12」になる。
3. 何もないところを指（マウス）でぐるっと囲んでばらを選び、「🧱 まとめる」→ ぼう1本とばら2こになる（→ 12 のまま）。
4. ぼうを選んで「💥 ばらす」→ その場でばら10こに分かれる。
5. 「↩ ひとつもどす」を押すと、1つ前にもどる。
6. タブレットで、2本の指で別々のおはじきを同時に動かせる。
7. 分数ピースで分母「4」を選び、円を2こ出す。1つを「↻ まわす」→ もう1つの近くに置くと、中心がそろってくっつく。下の数が「あわせて 1/2」。
8. 時計を出して長いはりを1周回すと、短いはりが1時間分進む。
9. 「⚖ くらべる」→ 左に並べてから「左を 右に コピー」→ 下の数が左右別々に出る。
10. 「💾 ほぞん」→ PNG・JSON を保存。JSON を「よみこむ」と同じ盤面にもどる。
11. 「⚙ せってい」→「1・2年」を押すと、パレットから分数ピースが消える。

## 授業での使い方の例

### 1. 自分の考えを説明する（1年「くり上がりのあるたし算」）
- はいけいを「10フレーム」にする。子どもは 9＋4 を、おはじき（あか9こ・あお4こ）で表す。
- あおを1こ上のフレームに動かして「10と3で13」と説明する。ペンで矢印や「10」と書きこむ。
- 「💾 ほぞん」→ PNG で保存し、学習支援ソフトに提出する。全員の考えを先生が一覧で見られる。

### 2. 複数の解き方をくらべる（2年「たし算の筆算」・3年「かけ算」・4年「面積」など）
- 「⚖ くらべる」にして、左に「さくらさん」、右に「たけるさん」と名前を書く。
- 例：38＋25 を、左は「ばらどうしを先にまとめる（くり上がり）」、右は「40＋25−2 と考える」。それぞれの子どもに前でブロックを動かしてもらう。
- 下の数で、どちらも 63 になることを確かめ、「どこがちがう？」「どちらが分かりやすい？」と話し合う。
- 「左を 右に コピー」を使うと、同じ出発点から別の動かし方を見せられる。
- 図形ピース（4年「面積」）なら、L字の形を「たてに切る」「よこに切る」「大きな長方形からひく」で並べてくらべられる。

### 3. 教具が足りないときの代わり（算数セットを忘れた・数が足りない・片付けが大変）
- 電子黒板で先生が操作して、全員で同じブロックを見る。100や1000の大きな数も、いた・ぼうで出せる（実物の算数セットでは数が足りない場面）。
- 時計やお金は、実物を全員分そろえるのが難しいので、タブレットで1人1つ使える。
- 授業の前に盤面をつくって JSON で書き出しておくと、授業ですぐ同じ盤面を出せる（例：位取り表の上に 1234 をブロックで置いた盤面）。
- 「⚙ せってい」で学年に合う素材だけにしぼると、低学年でも迷わず使える。

## 注意

- 記録（どの子が何をしたか）は保存しません。保存したいときは PNG か JSON を使ってください。
- 先生用の設定は、ブラウザに覚えておきます。プライベートブラウズでは覚えません（毎回はじめの設定になります）。
