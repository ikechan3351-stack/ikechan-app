# データを比べて説明しよう（箱ひげ図の読み取り）

中学2年「データの分布」の教材です。四分位数・四分位範囲を求めて箱ひげ図をつくり、2つ以上のデータを比べて、**根拠（中央値・四分位範囲・範囲・最大値・最小値）をもって説明する** 練習をします。

## 今ある教材との役割分担

| 教材 | 役割 |
|---|---|
| 小6 ならべて くらべて データの調べ方 | ドットプロット・代表値（前提） |
| 中1 区切って数えて ヒストグラム／動かして くらべて 代表値 | 度数分布・ヒストグラム・代表値 |
| 箱ひげ図とヒストグラム（`箱ひげ図とヒストグラム.html`、そのまま残す） | 点を動かして、箱ひげ図とヒストグラムが連動するのを見る |
| **データを比べて説明しよう（これ）** | 四分位数を手順で求める・箱ひげ図を自分で作る・読み取って説明する・判断する |

## 基本情報

- **ファイル**：本体 `データ比較.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **URL の設定**
  - `?part=1`〜`5` … そのパートを開く
  - `?teacher=1` … 先生モード（答え・自動で1ステップ進める・この端末のきろく）
  - `?ws=0` … ワークシートをとじて開く

## 使い方（5パート）

1. **① 求める**：小テスト（20点満点）のデータを小さい順にタップして並べる → まん中のカードをタップ → 中央値 → 前半・後半に分ける（奇数個のときは「中央値を入れない」をえらぶ）→ 第1・第3四分位数 → 範囲・四分位範囲。「奇数個／偶数個／おまかせ」でデータの数をえらべます。終わると5つの値の表と箱ひげ図が出ます。「➕ 1こ足す」で奇数個⇔偶数個にして分け方のちがいをくらべます。2回まちがえると「👀 答えを見て次へ」。
2. **② 箱ひげ図を作る**：最小値・第1四分位数・中央値・第3四分位数・最大値の5つの札を数直線にドラッグ。5つそろって順番が正しいと箱ひげ図がかかれます。「5つの値を見せる」を外すと、データから自分で求めて置く練習になります。すいつく（0.5／1／なし）を切りかえられます。
3. **③ 比べる**：2つのクラスの箱ひげ図。「全体として高いのは？」「ばらつきが大きいのは？」に、結論と根拠（1つか2つ）をえらぶと、グラフの数を使った説明文が自動でできます。場面は 小テスト／ハンドボール投げ（範囲と四分位範囲で答えが逆になる）／読書時間（中央値が同じ 📄）。
4. **④ ヒストグラム**：5つの値がまったく同じ3クラス（山が1つ・山が2つ・平ら）。予想 → ヒストグラムと平均値を見る → 「箱ひげ図だけで分かる？」の仕分け → 「長い区間ほど人数が多い？」のクイズ。
5. **⑤ 判断**：問1「新しい薬は効果がある？」問2「どちらのチームを選ぶ？」は結論と理由をえらぶ。問3〜5 は「約4分の1・約半分・約4分の3 以上いるといえるのは？」をすべてえらぶ（📏 線つき）。
- 共通：🔢 値（5つの値の数を出す）、📏 線を引く（グラフをタップ・ドラッグで縦の線）、↶ ひとつもどす、⟲ もういちど。
- 正しい説明文は「📝 わたしの説明文」にたまり、コピーできます（ワークシートのまとめに使う）。

## ワークシート

- 予想：「中央値が同じなら、2つのデータは『同じ』と言えるだろうか？」
- 確認：③ の「読書時間（中央値が同じ）📄」や ④ を開いて「＋ 記録する」。グループごとに 場面・データ・中央値・四分位範囲・範囲・山の形 が1行ずつ入ります（① ② ⑤ でも記録できます）。
- まとめ：「中央値が同じでも、〜がちがうと…。だから、データを比べるときは〜も見る」の形で説明文をつくる。

## つまずき検知の一覧

| 型 | 見つけ方 | 練習する場所 |
|---|---|---|
| 四分位数で、中央値を前半・後半にふくめた | ① の分け方で「入れる」をえらんだ／中央値をふくめて求めた第1・第3四分位数の値（②で置いた位置も） | ①（奇数個のデータ） |
| まん中が2つあるのに、平均をとらなかった | まん中の2つのどちらかの値を答えた | ①（偶数個のデータ） |
| 第1四分位数と第3四分位数の取りちがえ | 第1と第3を逆に答えた・置いた | ① |
| 範囲と四分位範囲の取りちがえ | ① で2つを逆に答えた／③⑤ で四分位範囲と答えが逆になる「範囲」を根拠にした | ③ ハンドボール投げ |
| 箱ひげ図の5つの値の位置の取りちがえ | ② でほかの値の位置に置いた | ② |
| 「高い・低い」と「ばらつき」の根拠をまぜた | 高い・低いを四分位範囲や範囲で、ばらつきを中央値や箱の位置で説明した | ③ 小テスト |
| 1人の値（最大値・最小値）だけで全体を判断した | 最大値・最小値を根拠にした | ③ 小テスト |
| 箱ひげ図だけで分布の形まで分かると考えた | ④ の予想「同じ形」／山の数・平均値などを「分かる」にした | ④ |
| 箱やひげが長いほど人数が多いと考えた | ④ のクイズで長い区間をえらんだ | ④ |
| 「約半分」「約4分の1」の読みまちがい | ⑤ 問3〜5 のまちがい | ⑤ 問4 |
| 小さい方がよいデータの読みまちがい | ⑤ 問1 で「時間が大きい方がよい」をえらんだ | ⑤ 問1 |
| 言いすぎ（全員・必ず） | ⑤ 問1 で「全員が必ず」をえらんだ | ⑤ 問1 |
| 計算・読みとりのまちがい | どの型にも当てはまらないまちがい | ① |

「あなたのつまずき」の「🔁 この型を練習」で、その型が出やすい問題が開きます。四分位数の型では「👀 箱ひげ図とヒストグラムで確かめる」も出ます。つまずきの回数・説明文・できたパートは localStorage の `ikechan-math-データ比較` に保存されます。

## 授業での使い方（例）

- **1時間目**：① で奇数個・偶数個の両方を求め、② で箱ひげ図をつくる。「中央値を前半に入れる？」を全体で話し合う。
- **2時間目**：ワークシートの予想 → ③ の3場面で説明文づくり → ④ で「箱ひげ図で分からないこと」を確かめる → まとめ。
- **活用**：⑤ の判断問題をペアで話し合い、えらんだ理由を発表する。
- 先生モード（`?teacher=1`）では答えと話し合いの問いが出て、「⏭ 自動で1ステップ」で手順を順に見せられます。

## ※じっさいとのちがい

- データはすべて架空のもの（薬・チームも架空）です。
- 四分位数は教科書と同じく「奇数個のときは中央値を前半にも後半にも入れない」方法で求めています。表計算ソフトなど、ほかの求め方をするものもあります。
- ③⑤ の箱ひげ図は5つの値だけで作っています。人数は「約4分の1」「約半分」として考えます。
- 本当の薬の効果は、もっと多くの人で、くらべ方をきちんと決めて調べます。
