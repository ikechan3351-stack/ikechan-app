# すばやく解いて 連立方程式バトル（タイムアタック・2人でバトル・宿題を減らせ）

中学2年「連立方程式」の計算練習をゲームにしたアプリです。ひとりでタイムアタック、1台の画面で2人バトル、むずかしさをえらんで宿題を減らすモードがあります。通信はしません（1台で遊ぶ形）。

## 基本情報

- **ファイル**：本体 `すばやく解いて 連立方程式バトル.html`、共通部品 `math-render.js`（数式・分数）・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中2）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）・スマホ。
  - 横に広い画面では、式（左）と数字キー（右）をならべます。
  - 式が入りきらないときは、文字を小さくします。
- **URL の設定**
  - `?teacher=1` … 先生モード（レベル固定・宿題を減らせの時間・バトルの1問の時間・クラス用の大画面表示・この端末のつまずきの合計）
  - `?ws=1` … ワークシートをひらいて開く
  - `?debug=1` … 動作確認用（`window.__dbg`。授業ではつかわない）

## レベル（答え x, y を先に決めて、整数の答えになるように作る。同じ問題は続けない）

| レベル | 形 | 例 |
|---|---|---|
| ① そのまま消える | 係数の絶対値が同じ文字がある | 2*x*＋*y*＝7, *x*−*y*＝2 |
| ② 一方を何倍か | 片方の式を何倍かするとそろう | 3*x*＋2*y*＝8, *x*＋*y*＝3 |
| ③ 両方を何倍か | 両方の式を何倍かしないとそろわない | 3*x*＋2*y*＝12, 2*x*−3*y*＝−5 |
| ④ 代入法向き | *y*＝*px*＋*q*（*x*＝*py*＋*q*）の形の式がある | *y*＝2*x*−1, 3*x*＋2*y*＝12 |
| ⑤ まぜる | ①〜④がまざる | |

問題の作り方は「どっちで解く？ 連立方程式」（2-04）のレベル①②③⑤と同じです。

## モード

### ⏱ タイムアタック（ひとり）
- 10問を解きます。まちがえたら、同じ問題をやり直します。
  - 「パス」はミス1回あつかいで、つぎの問題へ進みます。
- **ランク**：タイム＋ミス×10秒 を、目安の時間とくらべて決めます。
  - 目安の時間は、1問の目安×10問です。1問の目安は ①25秒・②35秒・③50秒・④35秒・⑤40秒 です。
  - 比べた割合が 0.45 以下で1級、0.55 以下で2級 … 2.0 をこえると10級です。
  - 割合が 0.4 以下で、しかもミスが0なら「名人」です。
- レベルごとのベスト記録を、この端末に保存します。

### ⚔️ 2人でバトル（1台）
- 画面を左右に分け、ひだり（オレンジ・●）と みぎ（青・■）に、それぞれ x・y のらん・数字キー・決定ボタンがあります。
- 同じ問題を同時に解き、先に正解したほうが1点です。**5点先取**で勝ちです。
- まちがえた人は、決定ボタンが **3秒** 押せなくなります（もう1人は続けられます）。
- 2人ともわからないときは「2人ともパス」。答えを見せて、つぎの問題へ進みます。
- 先生モードで1問の制限時間（30〜120秒）を決めると、時間切れでつぎの問題になります。

### 📚 宿題を減らせ（ひとり）
- 宿題の山 100ページ、制限時間 3分（先生モードで 60〜600秒）です。
- 問題ごとにむずかしさをえらびます。正解するとページが減ります（①5・②10・③15・④10ページ）。
  - はやく解くとボーナスがあります。30秒より10秒はやいごとに1ページです。
  - ミスすると5ページふえます。
- 0ページになったらクリア（かかった時間を記録）。時間切れのときは、減らしたページ数を記録します。

## 入力
- x・y のらんをタップしてえらび、数字キーで入れます（⌫・−（符号を入れかえ）・C・x↔y）。**決定**を押すまで判定しません。
- キーボード：数字・−・Backspace・Tab（x と y の切りかえ）・Esc（消す）・Enter（決定）。ひとりのときだけ使えます。
- まちがえると、決定ボタンが少しのあいだ押せなくなります（ひとり 1.5秒・バトル 3秒、のこり時間を表示）。ミスの連打や、でたらめ入力で進めないようにするためです。

## ふくしゅう（終わったあと）
- まちがえた・パスした・時間切れの問題ごとに、答えた値と**つまずきの型**を表示します。
- 「解き方のステップを見る」で、楽な方法の解き方が出ます。
  - y＝… の形の式があるときは代入法、ないときは何倍する式が少ないほうの文字を消す加減法です。
  - ステップの中の式は、どれも答えを入れると成り立つことを確かめてあります。
- 「🪜「どっちで解く？」で1ステップずつ解く」で、`どっちで解く？ 連立方程式.html?q=…` をその問題で開きます。

## ワークシート
- もんだい：「連立方程式を すばやく・正確に解くには、どうするとよいだろうか？」
- 予想：決定する前に両方の式で検算する／とにかく速く入力する／楽な方法をえらぶ／わからない
- 記録：モード・レベル・タイム・ミス・結果（ランク）。作戦を変えて記録をくらべます。
- 保存キーは `ikechan-math-すばやく解いて 連立方程式バトル`（ベスト記録・つまずき・先生モードの設定もこの中）。

## 授業での使い方の例（20〜30分）
1. 予想を書いてから、タイムアタック（レベル①）を1回。
2. ミスが多い生徒には「決定の前に両方の式へ代入して検算」をすすめ、2回目とくらべさせる（ミス1回は10秒分）。
3. ペアで「2人でバトル」（レベル②③）。先生モードの大画面表示で、代表どうしの対戦を前で見せてもよい。
4. ふくしゅうの「どっちで解く？」で、まちがえた問題を1ステップずつ解きなおす。

## 正しさについて（※じっさいとのちがい）
- 答えはすべて整数です（答えを先に決めて作っています）。判定は分数（Fraction）で厳密に行います。
- 入力できるのは整数だけです（3けたまで）。
- 2人でバトルは1台の画面で遊ぶ形で、通信はしません。

## つまずき検知の一覧（まちがえた答えから見分ける）

| 型 | 見つけ方 |
|---|---|
| x と y を逆に入れた | 答えが (y の値, x の値) |
| 符号のまちがい | 片方の値の符号だけが逆 |
| 片方の式にしか合っていない | 入れた値を代入すると、①か②の一方だけ成り立つ |
| もう一方の文字を求めるところのまちがい | x か y の一方だけが合っている |
| 計算のまちがい | そのほか |

まちがえたときにその場で「〜？ 検算してみよう」と出し、ふくしゅうと はじめの画面の「あなたのつまずき」に回数を残します。
