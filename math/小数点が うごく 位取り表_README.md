# 小数点が うごく 位取り表

小学5年生の算数「整数と小数」（東京書籍 新しい算数 5上 8〜15ページ）で使う教材です。次のことを体験します。

- 整数も小数も、**10 集まると 1つ上の位に進むしくみ**（十進位取り記数法）で表されていること
- 数は **0.001 がいくつ分** と見られること（2.345 は 0.001 が 2345こ）
- **10倍・100倍・1000倍すると数字が上の位へ、1/10・1/100・1/1000にすると下の位へうつる** こと。そのとき **小数点が右・左にうつったように見える** こと
- 発展：数字カードを使って、条件に合う数（いちばん大きい・小さい・○に近い）をつくる

## 基本情報

- **ファイル**：`小数点が うごく 位取り表.html`。共通ファイル `worksheet.js`・`worksheet.css`・`math-render.js` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。ボタンは48px以上。スマホのたて向きでは、表のカードを小さくして7つの位が1画面に入るようにしています。
- **漢字**：算数のことば（小数点・位取り表・倍・整数・小数 など）と、5年でまだ習っていない漢字にふりがなをつけています。「せってい」で消せます。
- **保存**：ワークシートと「せってい」を、このブラウザの localStorage（キー：`ikechan-math-小数点が うごく 位取り表`）に保存します。もんだいの成績は保存しません。

## 3つの画面

### 🧱 じゆうに うごかす

- 位取り表（千の位〜1/1000の位）の数字カードをタップ（または ▲▼）して数をつくります。
- 「10倍」「100倍」「1000倍」「1/10」「1/100」「1/1000」を押すと、数字がとなりの位へスライドします。**小数点（赤い丸）は動きません**。下の大きな数字で「2.345 → 23.45　小数点が右へ1けたうつる」と見せます。
- 右の欄には「0.001 が いくつ分」と「10が2こ、1が3こ、0.1が4こ…あわせた数」を同時に出します。
- 「ひとつ もどす」「もういちど」あり。ワークシートの「＋ きろくする」で、さいごの操作（もとの数・しかた・けっか・小数点のうごき）を記録します。

### ✏️ 10倍・1/10 もんだい

- 「2.35 を 10倍 した 数は？」のような問題に、数字ボタン（PCはキーボードの数字・`.`・Backspace・Enter も可）で答えます。問題数は5問か10問（せってい）。
- 問題は、もとの数も答えも表（千の位〜1/1000の位）におさまり、かならず小数が出てくるように作ります。同じ問題は続けて出ません。10問のときは6種類（10倍・100倍・1000倍・1/10・1/100・1/1000）がかならず1回は出ます。5問のときは、1000倍か1/1000のどちらか1つがまざります。
- 正解すると「📋 表で たしかめる」で数字のスライドを見られます。1回まちがえたときは、答えがそのまま見えてしまわないよう表は動かさず、つまずきの声かけだけでもう一度考えます。2回まちがえると答えを表で示します。
- 「23.50」のように、おしりに0をつけた正しい答えは正解にして、「23.5 と書くよ」と声をかけます。

### 🃏 カードで 数づくり（発展）

- 4まいの数字カードを □.□□□・□□.□□・□□□.□ のわくに入れて、「いちばん大きい数」「いちばん小さい数」「○にいちばん近い数」をつくります。
- 答えは、ならべ方24通りをすべて調べて決めています。整数の部分が2けた以上のわくでは、いちばん上の位に0は入れられません。

## つまずき検知（もんだい画面）

| 型の名前 | 見つけ方 | 例 | 出す声かけ |
|---|---|---|---|
| 0を つけるだけ | 答えの大きさが、もとの数と同じ | 2.5×10 → 2.50 | 小数のおしりに0をつけても大きさは変わらない。10倍すると、どの数字も1つ上の位へ |
| むきが ぎゃく | 10倍なのに1/10にした数（またはその反対） | 3.6×10 → 0.36 | 10倍・100倍・1000倍は大きくなる → 数字は左、小数点は右へ。1/10・1/100・1/1000はその反対 |
| うごかす けたが ちがう | 正しい向きでも、うごかしたけた数がちがう（×10000・1/10000 までしらべる） | 1.69 の 1/10 → 0.0169 | 10倍・1/10は1けた、100倍・1/100は2けた、1000倍・1/1000は3けた。100倍は「10倍の10倍」 |

- 見つけた型は「あなたの つまずき」として出し、次の問題にその型の「にた もんだい」（同じ操作）を1問足します（にた もんだいからは、さらには足しません）。
- 終わりの画面に、型ごとの回数を出します。

## 先生モード（アドレスの最後に `?teacher=1`）

- じゆうに うごかす：数を直接入力できます（全角数字も可）。「▶ じどうで 見せる」で、10倍をくり返し → 1/10をくり返す様子を自動再生します（もう一度押すと止まります）。
- もんだい・カード：「💡 こたえ」で答えを表示します。
- ワークシートに、先生用のヒントと解答例が出ます。

## 授業での使い方の例（1時間）

1. **導入（5分）**：「2.345 を 10倍 すると？」と問い、ワークシートの「よそう」をえらばせる（「0がつくだけ」と考える子が出やすい）。
2. **やってみる（15分）**：「じゆうに うごかす」で、2.345・0.6・15.8 などを 10倍・100倍・1000倍・1/10・1/100・1/1000 して、ワークシートに記録する。
3. **わかったこと（10分）**：記録をくらべて、数字の動きと小数点の動きを言葉にする。「0.001 が いくつ分」も確かめる。
4. **練習（10分）**：「10倍・1/10 もんだい」。つまずきの型が出た子は、その数を「じゆうに うごかす」でもう一度動かす。
5. **まとめ（5分）**：「10倍すると小数点は右へ1けた、1/10にすると左へ1けたうつる」をまとめに書く。時間があれば「カードで 数づくり」（発展）。

## 正しさと、じっさいとのちがい

- 数は「0.001 がいくつ分か」の整数で持っています（2.345 → 2345）。小数のまま計算すると出る誤差（0.1＋0.2＝0.30000000000000004 など）が起きません。子どもの答えは、1億分の1を単位にした整数にして比べるので、0.0169 のような表にない数でも正しく判定できます。
- ※じっさいとのちがい：表は千の位から1/1000の位までです。教科書の範囲（0.001を単位とした小数）に合わせ、それより大きい位・小さい位にはみ出すときは、理由を出して動かせないようにしています。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| 整数の位／小数の位 | だいだい／水色 | 見出しとカードのわくの形（実線／点線） |
| 10倍・100倍・1000倍／1/10・1/100・1/1000 | オレンジ／青 | ボタンの ▲・▼ と文字 |
| とちゅうの0／使っていない0 | 黄色いカード／うすい灰色 | カードのふちの色・数字のこさ |
| 正解／まちがい | 緑／赤むらさき | ◎・△ の記号 |
