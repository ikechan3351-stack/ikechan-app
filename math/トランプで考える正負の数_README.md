# トランプで考える正負の数（学ぶ場面）

中学1年「正負の数」の加法・減法を、**トランプ** と **数直線** と **式** を行き来しながら考えるアプリです。
黒（♠♣）は正の数、赤（♥♦）は負の数。カードを「**合わせる**」とたし算、「**取られる**」とひき算と考えます。
遊んで練習するゲームは [正負の数トランプ](正負の数トランプ.html)（ゼロ対ババ抜き・得点ババ抜き）です。

## 基本情報

- **ファイル**：本体 `トランプで考える正負の数.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中1）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）・スマホ。
- **カードの約束**：黒＝＋、赤＝−、A＝1、ジョーカー＝0。カードの絵は市販のトランプと同じで、カードに ＋− は書いていません（黒か赤かで読みとる）。式・マークのチップ・数直線は ＋＝オレンジ／−＝青。
- **マーク（チップ）**：カードの数だけ、＋は丸・−は四角のチップを2列にならべます（♠5 なら ＋のチップ5こ）。＋と−の1組（ゼロ対）は 0 なので、うすくして「0」と書きます。
- **URL の設定**
  - `?teacher=1` … 先生モード（数字ボタンをかくし、答え・数直線の終点は「答えを見せる」まで出さない。カードと文字が大きい）
  - `?scene=intro`・`add`・`sub`・`practice` … はじめに開く場面
  - `?scene=practice&lv=1〜4` … 練習のレベル（1 たし算2まい／2 ひき算／3 たし算3〜4まい／4 まぜて）
  - 例：`トランプで考える正負の数.html?teacher=1&scene=sub`
- **記録**：この端末の localStorage（保存キー `ikechan-math-トランプで考える正負の数`）に、ワークシート・つまずきの回数・練習の結果を入れます。

## 4つの場面

| 場面 | すること | ねらい |
|---|---|---|
| ① カードの約束 | 1まい引いて、値と数直線の位置を見る。2まいくらべて「どちらが大きい？」（発展：絶対値が大きい方） | 正負の数の大小・絶対値 |
| ② 合わせる＝たし算 | 5つの型を順に（＋どうし → −どうし → ゼロ対 → ＋が大 → −が大）。「ゼロ対を消す」「数直線で見る」で確かめる。5つそろうと くらべる表が出る | 加法のきまり（符号と絶対値） |
| ③ 取られる＝ひき算 | 手札からカードを取られる。打ち消し合っていた相手のマークが「復活」する。式を `(−2)−(+5)` → `＝(−2)+(−5)` → `＝−7` と1段ずつ | 減法＝反数の加法 |
| ④ 練習 | 5問ずつ。まちがえるたびにヒントが1段ずつ（カードの色 → 数直線 → 答え） | 加減の計算（3〜4項・混合まで） |

- ③のはじめの4問は決まった問題です：①♠5・♥5・♥2 から ♠5 を取られる（−2 → −7）②♠A・♠3・♥3 から ♥3 を取られる（+1 → +4）③♠6・♥2 から ♥2（+4 → +6）④♥7・♠2 から ♠2（−5 → −7）。そのあとはランダムです。

## 授業での使い方（例）

- **加法の導入（15分）**：先生モードで②を映し、型1〜5を順に。型3（ゼロ対）で「＋と−の1組は 0」を確認し、型4・5で「マークが多く残った方の符号」「残ったマークの数＝絶対値の差」に気づかせる。くらべる表を見て、きまりをことばにする。
- **減法の導入（15分）**：③の1問目で「♠5 を取られたら、合計は上がる？下がる？」と予想させる（ワークシートの①予想）。取られると ♥5 が復活することから、`(−2)−(+5)＝(−2)+(−5)` を導く。2問目で「赤を取られると上がる」を確かめる。
- **練習（10分）**：④を1人1台で。そのあと [正負の数トランプ](正負の数トランプ.html) の得点ババ抜きで遊ぶ。

## つまずき検知の一覧

| 型の名前 | まちがいの例 | 画面に出すことば |
|---|---|---|
| 絶対値でくらべた型（①） | −7 と −2 で −7 をえらぶ | 負の数は、絶対値が大きいほど小さい。数直線で右にある方が大きい |
| くらべまちがい型（①） | そのほかのくらべまちがい | 2つの数を数直線に置いてみよう |
| 符号えらび型 | (+3)+(−5) を +2 | 符号のちがう数の和は、絶対値の大きい方の符号になる |
| 絶対値たし型 | (+3)+(−5) を −8 | 符号のちがう数は打ち消し合う。絶対値の「差」を求める |
| ひき算そのまま型 | (−2)−(+5) を +3、(+4)−(−3) を +1 | ひくときは、ひく数の符号を変えてたす。赤を取られると点数は上がる |
| 計算ミス型 | そのほか | 数直線の矢印を、0 から順にたどってたしかめよう |

## ※じっさいとのちがい

- 本物のトランプのマークの数（♠5 のマーク5こ）を、＋のチップ5この形にかえて見せています。
- 同じ値のカードは2まいまで（♠5 と ♣5）しか出しません。
- 練習の答えは −10 〜 +10、カードは A〜10 だけです（絵札は使いません）。

## 先生向けメモ（改造するとき）

- 計算の部分（カードの値・5つの型の問題・取られる問題・練習問題の作り方・つまずきの型）は、HTML の中の「ロジック ここから／ここまで」の間にまとめています。
- ③の決まった問題は `SUB_FIXED`、つまずきのことばは `TRIP` を書きかえると変わります。
- もとになった実践：和歌山県立桐蔭中の自習教材（取られる＝減法）、富山県「自主学習のすすめ」（たし算の型の並び）、埼玉県「数学通信」（大小・絶対値くらべ）。
