# かけると 小さく なる？ 小数のかけ算

小学5年生の算数「小数のかけ算」（東京書籍 新しい算数 5上 40〜51ページ）で使う教材です。次のことを体験します。

- 小数をかける意味：「1m 80円のリボンを 2.3m 買う」を、**0.1m 分（8円）の 23こ分** と考える
- **1より小さい数をかけると、答え（積）はかけられる数より小さくなる** こと
- 小数のかけ算の筆算：小数点がないものとして計算し、**積の小数点は、かけられる数とかける数の小数点より下のけた数をたした数だけ、右から数えてうつ** こと
- 小数でも計算のきまりが使えること（80×2.3＝80×2＋80×0.3）

## 基本情報

- **ファイル**：`かけると 小さく なる？ 小数のかけ算.html`。共通ファイル `worksheet.js`・`worksheet.css`・`math-render.js` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。数直線と面積図は SVG で描いています。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。

- **漢字**：小数・小数点・筆算・面積図・数直線 などの算数のことばと、5年でまだ習っていない漢字にふりがなをつけています。「せってい」で消せます。

## 3つの画面

### 🎀 わけて 考える

- 「1m 80円のリボンを □m 買うと、代金は？」の場面です。□ は 0.1〜3.0（0.1きざみ）。−1・−0.1・＋0.1・＋1 のボタンか、数の入力で変えます。
- **二本の数直線**（上：代金、下：長さ）と **面積図**（たて：1mのねだん、よこ：長さ、0.1mずつの帯）が同時に動きます。面積図は、整数の部分（ぬりつぶし）と小数の部分（しま模様）を分けてぬり、「80×2」「80×0.3」と書きます。
- 「考え方」に「0.1m 分は 80÷10＝8円 → 2.3m は 0.1m の 23こ分 → 8×23＝184円」と、分けて計算した式（80×2＋80×0.3）を出します。
- □ が 1 より小さいと「80円より 小さく なった！」（⬇）、1 より大きいと「80円より 大きく なる」（⬆）と出ます。
- 「ひとつ もどす」「もういちど」あり。ワークシートの「＋ きろくする」で、しき・答え・かけられる数とくらべてどうか を記録します。

### 🧮 筆算で 小数点を うとう

- 「つぎへ」で1ステップずつ進みます。
  1. 小数点の位置は気にしないで、右にそろえて書く
  2. 小数点をとって整数のかけ算（23×16）と考える（それぞれ10倍・100倍した数）
  3. 整数のかけ算をする（かける数が2けたなら部分積も出す）。これは本当の答えの100倍
  4. 積の数字のすきま（点線の丸）をタップして小数点をうつ
  5. おしりの0を消す（あるときだけ）
- 問題は3種類がまざって出ます。
  - ふつう：0.18×6.4＝1.152 など
  - 0を書き足す：0.3×0.3＝0.09、0.14×0.2＝0.028 など。書き足す0は、小数点をうつまでかくしておきます（先に見えると「0を書き足す」ことがわかってしまうため）。数字の左の空いたますにも小数点をうてて、正しくうつと0が出てきます。
  - おしりの0を消す：2.5×0.4＝1.00→1 など
- 「ひとつ もどす」「ちがう もんだい」あり。小数点をうったあとに「＋ きろくする」で記録できます。

### ✏️ 小数のかけ算 もんだい

- 計算の答えを入れる問題と、「80×0.8 の答えは 80 より大きい？小さい？」を選ぶ問題が半分ずつ出ます（5問か10問）。
- 答えは数字ボタン（PCはキーボードの数字・`.`・Backspace・Enter も可）で入れます。「17.40」のようにおしりに0をつけた正しい答えは正解にして、「17.4 と書くよ」と声をかけます。

## つまずき検知

| 型の名前 | 見つけ方 | 例 | 出す声かけ |
|---|---|---|---|
| 小数点の 位置ちがい | 数字のならび（0をのぞく）は合っているのに、値がちがう答え。筆算画面では、かけられる数かかける数の片方のけた数だけで小数点をうったとき | 3.5×0.2 → 7、0.14×0.2 → 0.28 | 答えの小数点より下のけた数は、かけられる数とかける数のけた数をたした数。たりないときは0を書き足そう |
| かけると いつも 大きく なる | 1より小さい数をかけたのに「大きい」を選んだ | 78×0.9 は 78 より大きい | 1より小さい数をかけると、答えはかけられる数より小さくなる。80×0.8 は「80円の 0.8こ分」 |

- 見つけた型は「あなたの つまずき」として出し、次にその型の「にた もんだい」を1問足します（「位置ちがい」のにた もんだいは、0を書き足す問題もまざります）。
- 終わりの画面に、型ごとの回数を出します。

## 先生モード（アドレスの最後に `?teacher=1`）

- わけて 考える：1mのねだんを 10〜500円（10円きざみ）に変えられます。代金が整数になるよう、10の倍数にしています。
- 筆算：「▶ じどうで すすめる」で最後まで自動で進めます。
- もんだい：「💡 こたえ」で答えと考え方を表示します。ワークシートに、先生用のヒントと解答例が出ます。

## 授業での使い方の例（1時間）

1. **導入（5分）**：「1m 80円のリボンを 2.3m 買うと？」。ワークシートの「よそう」で「80×□ はいつも 80 より大きい？」を選ばせる。
2. **やってみる（15分）**：「わけて 考える」で 2.3m・1.5m・0.8m・0.5m を試し、0.1m 分の代金から考える。代金が 80円より小さくなるときをさがして記録する。
3. **筆算（15分）**：「筆算で 小数点を うとう」で、小数点をとって計算し、けた数をたして小数点をうつ流れを確かめる。
4. **まとめ（5分）**：「1より小さい数をかけると、答えはかけられる数より小さくなる」「積の小数点より下のけた数は、かけられる数とかける数のけた数の和」を書く。
5. **練習（5〜10分）**：「小数のかけ算 もんだい」。

## 正しさと、じっさいとのちがい

- 小数は「数字のならび（整数）」と「小数点より下のけた数」の組で持ち、かけ算は「整数どうしをかけて、けた数をたす」で計算しています。小数のまま計算したときの誤差（0.1×3＝0.30000000000000004 など）は起きません。
- 問題の答えは小数第三位までにしています（教科書の範囲）。
- ※じっさいとのちがい：リボンは 0.1m きざみで、何m でも買えるものとしています。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| 長さ（かける数）／代金（答え） | 青／オレンジ | 数直線の上・下の位置と「長さ」「代金」の文字 |
| 面積図の整数の部分／小数の部分 | うすいオレンジ | ぬりつぶし／しま模様 |
| 大きくなる／小さくなる | オレンジ／青 | ⬆・⬇ の記号、わくの線（点線／実線） |
| 小数点 | 赤 | 数字の右下の丸 |
| 正解／まちがい | 緑／赤むらさき | ◎・△ の記号 |
