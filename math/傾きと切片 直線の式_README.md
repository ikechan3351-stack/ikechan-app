# 傾きと切片 直線の式（a と b を動かす → グラフから式 → 条件から式 → 表から式）

中学2年「一次関数」の、**直線の式を求める**練習のアプリです。傾き *a*（*x* が 1 増えたときの *y* の増加量）と切片 *b*（*y* 軸との交点）の意味を見てから、グラフ・傾きと1点・2点・表から *y*＝*ax*＋*b* を求めます。

ほかの教材との役割分担：
- 「関数グラフツール」：グラフをかいて見る
- 「変化の割合実験機」：2点を動かして変化の割合を求める
- 「一次関数ゲーム」：遊びながら
- この教材：**条件から式を求める**

## 色と線のきまり

| もの | 見え方 |
|---|---|
| 直線 | オレンジの実線 |
| 答えの直線（できたとき） | 緑の点線 |
| 傾きの三角形 | 横（*x* の増加量）＝オレンジの実線、たて（*y* の増加量）＝青の点線、中は うすい黄色 |
| 切片 | 黒の大きな点（「切片」の文字） |
| ドラッグできる点 | 緑青の点（P・A・B） |

## 使い方

### ① a と b を動かす
- *a*（傾き）・*b*（切片）を、スライダーか数の入力で変えます。
  - *a* のスライダーは、分母 1〜4 の分数を −4〜4 まで順にならべた目もりです。
  - 数の入力には 2/3 のような分数も書けます。
  - *a*＝1/2・2・−1・−2/3・0 のボタンもあります。
- **傾きの三角形**：*x* が 1 増えると *y* が *a* 増えるようすを、三角形で見せます。*a* が分数のときは、分母の数だけ横に進む三角形（*x* が 3 増えると *y* が 2 増える）です。
- 三角形は直線の上の点 P から出ます。P をドラッグすると直線にそって動くので、どこでも同じ傾きだとわかります。
  - 「すいつく／すいつかない」は、グラフの上のボタンで切りかえます。
- 右上がり／右下がり／水平 と、切片（*y* 軸と (0, *b*) で交わる）も、ことばで出ます。

### ② グラフから式
- 格子点を通る直線が出ます。*a*・*b* を入れて「✔ たしかめる」（Enter でも可）。
  - 「傾きが整数」と「傾きが分数」の問題があります。どちらも切片は整数で、答えを先に決めて作ります。
- 「📐 三角形のヒント」で、切片から横に 1（分数なら分母）進む三角形が出ます。2回まちがえると、自動で出ます。
- 正解すると、答えの直線と三角形・切片が重なります。

### ③ 条件から式
- 「傾きと1点」「2点」の問題を、次のステップで解きます。
  1. **傾きを求める**：「傾きと1点」なら問題に書いてあります。「2点」なら、わくに *y* の増加量（分子）と *x* の増加量（分母）を入れます。どちらの点からひいても、順番がそろっていれば正解です。
  2. **b を求める**：点の座標を *y*＝*ax*＋*b* に代入した式（3＝2×1＋*b*）を見て、*b* を入れます。
  3. **式を書く**：*y*＝*ax*＋*b* が出て、グラフに答えの直線（緑の点線）が2点を通るようすが出ます。もう1つの点を代入した検算も出ます。
- 「✋ 自分で点を動かす」：点 A・B をドラッグして、自分で問題を作れます。
  - すいつかない設定なら 0.1 きざみで、分数の傾きも分数のまま計算します。
  - 2点の *x* 座標が同じになったときは、「*y*＝*ax*＋*b* の形の直線にならない」と出します。
- 「↶ ひとつもどす」「⟲ もういちど」「▶ つぎの問題」。

### ④ x、y の値から
- 「*x*＝−1 のとき *y*＝2、*x*＝3 のとき *y*＝6」のような問題を、表で出します。
- 傾きを求めると、表の下に「*x* の増加量 ＋4」「*y* の増加量 ＋4」の矢印が出ます。そのあとは ③ と同じステップです。

## ワークシート

- もんだい：「2点 (1, 3) と (4, 9) を通る直線の傾きは、いくつだろうか？」
- 予想：2／1/2／3／6／わからない
- 操作：③「2点」か「✋ 自分で点を動かす」で A(1, 3)・B(4, 9) にして解き、「＋ 記録する」（問題・傾き・切片・式）。
- 答え：傾き 2、式 *y*＝2*x*＋1。
- 保存キーは `ikechan-math-傾きと切片 直線の式`（つまずきの記録もこの中）。

## 授業での使い方の例（50分）

1. **予想（5分）**：ワークシートの問題で 2 と 1/2 のどちらかを予想。
2. **a と b の意味（10分）**：① で *a* を 2 → 1/2 → −1 と変え、三角形のたて・横を読ませる。*b* を動かして、*y* 軸との交点が動くことを確かめる。
3. **グラフから式（10分）**：② で数問。切片 → 三角形 の順に読む。
4. **条件から式（20分）**：③ で「傾きと1点」→「2点」。ワークシートの (1, 3)・(4, 9) を「自分で点を動かす」で作って解く。④ の表の問題も。
5. **まとめ（5分）**：「①傾き ②代入して b ③式」の手順をワークシートに書く。

## 正しさについて（※じっさいとのちがい）

- 計算はすべて分数（Fraction）で厳密に行います。表示も分数のままです。
- 直線は画面のはしで切れていますが、本当はどこまでものびています。
- ② は格子点を通る直線だけ、③④ の問題は座標が整数になるものだけを作ります（自分で点を動かすときは、0.1 きざみの座標も使えます）。
- ③ の傾きは、増加量そのもの（*y* の増加量と *x* の増加量）を入れる形にしています。約分した値（6/3 を 2/1 など）だけを入れたときは「増加量そのものを書こう」と出ます。
