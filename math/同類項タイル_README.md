# 同類項タイル（タイルを寄せて、文字式の計算の意味を見る）

中学1年「文字式の計算」で、項を**タイル**にして、同じ形のタイル（**同類項**）を寄せてまとめるアプリです。
3*x*＋5*x* が 8*x*（8*x*² ではない）になること、3*x*＋5 がまとめられないこと、−(2*x*−3) のかっこをはずすと符号がぜんぶ変わること、2(3*x*−1) が (3*x*−1) の 2 つ分であることを、タイルを動かして確かめます。

## 基本情報

- **ファイル**：本体 `同類項タイル.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中1）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）・スマホ。
- **タイルの形**
  - *x* のタイル＝**長い棒**、2つめの文字（2*a*＋3*b* の *b* など）のタイル＝**中くらいの棒＋しま模様**、1 のタイル＝**小さい正方形**。
  - 正の項＝**オレンジ・実線のふち**、負の項＝**青・点線のふち＋「−」**。色だけでなく、形・線の種類・文字でも見分けられます。
  - ひっくり返したタイルには「↺」の印がつきます。
- **画面のならび**：左に「タイルの置き場」、右に「式の変化」と「答えの式を書こう」（せまい画面では 式 → タイル → 答え の順）。
- **URL の設定**
  - `?teacher=1` … 先生モード（手順の自動再生・★答えを見る・ワークシートのヒントと解答例）
  - `?mode=sum`・`neg`・`dist`・`frac`・`free` … はじめに開くタブ
  - `?ws=0` … ワークシートをとじて開く

## 使い方

どのタブも、タイルの流れは同じです。

> （③ 写す）→（② ひっくり返す）→ ✂ かっこをはずす → 🧲 同類項を寄せる → ✨ ゼロ対を消す → ✏️ 答えの式を書く

右の「式の変化」には、操作のたびに `=` でつないだ式が1行ずつ増えます（例：(3*x*＋2)＋(2*x*−5) ＝ 3*x*＋2＋2*x*−5 ＝ 3*x*＋2*x*＋2−5 ＝ ？）。最後の行は「？」になり、生徒がタイルを見て答えの式を書きます。

### ① まとめる
- 「ためしてみよう」：(3*x*＋2)＋(2*x*−5)、3*x*＋5*x*、2*a*−3*a*＋1、3*x*＋5、4*x*−7＋2*x*＋3、2*a*＋3*b*−*a*＋*b*。「🎲 べつの問題」で新しい問題が出ます。
- ＋( ) のかっこは「✂ かっこをはずす」でそのままはずれます。
- 「🧲 同類項を寄せる」で、タイルが文字ごとの場所（*x* の項・1 の項）に集まります。＋の列と−の列がそろうので、ゼロ対がたてに並びます。
- ゼロ対（*x* と −*x*、1 と −1）は、**タップ**（＋ → − の順に1枚ずつ）か**ドラッグ**（重ねる）で消えます。「✨ ゼロ対をぜんぶ消す」は1組ずつ、間に「0」を出して消します。

### ② −( ) をはずす
- −(2*x*−3)、(5*x*＋1)−(2*x*−3) など。−( ) のまとまりはむらさきの枠で出ます。
- 「🔄 −( ) の中をぜんぶひっくり返す」で、中のタイルがくるっと裏返り、符号が変わります。タイルを**1枚ずつタップ**して裏返すこともできます。
- 裏返していないタイルが残ったまま「かっこをはずす」を押すと、つまずき「−( ) のうしろの符号を変え忘れた」になり、残ったタイルが光ります。

### ③ 分配法則
- 2(3*x*−1)、−2(*x*＋3)、2(*x*＋1)＋3(*x*−2) など。
- 「📑 2 つ分に写す」で、かっこの中のタイルが**ぜんぶ** 2 つ分に増えます（式は (3*x*−1)＋(3*x*−1)、−2(*x*＋3) は −(*x*＋3)−(*x*＋3)）。
- 前の数がマイナスのときは、写したあとに ② と同じようにひっくり返します。

### ④ わって見る（発展）
- *x* のタイル1本を等分したかけらで、分数の係数を見ます。*x*/2（*x* を 2 つにわった 1 つ分）と (1/2)*x* が同じことを、2つの書き方を並べて見せます。
- 2つの項の符号・分子（1〜9）・分母（1〜6）を ▼▲ か数字で決めます。分母がちがうときは「✂ 同じ大きさに切りそろえる」（分母を最小公倍数にそろえる）→「🧩 まとめる」。
- 「ためしてみよう」：*x*/2＋*x*/2、*x*/2＋3*x*/2、*x*/3＋2*x*/3、*x*/2＋*x*/3、2*x*−*x*/2、3*x*/4−*x*/2。
- 計算は分数（Fraction）で厳密に行い、約分した答えを出します。

### ⑤ じゆう
- 式を入れて「🧩 タイルにする」。例：(3*x*＋2)−(2*x*−5)、2(*x*＋1)＋3(*x*−2)、5*a*−2*b*−3*a*＋4*b*、−3(*x*−2)＋*x*。
- 書けるもの：整数の係数（12 まで）、文字 2 種類まで、かっこの前の数（5 まで、2×(…) も可）。読めない式には理由が出ます（分数・わり算は ④ へ、*x*²・*ab*・かっこの中のかっこはあつかわない、など）。

### 答えの式を書く
- 下のキー（数字・文字・＋・−・⌫・C）か、キーボードで書いて「たしかめる」（Enter でも可）。- は自動で − になります。
- 値が合っていても同類項がまだ残っている（3*x*＋2*x*−3 など）ときは「まだまとめられる」、1*x* と書いたときは「*x* と書くのがきまり」と出ます。
- タイルの操作をとちゅうまでしかしていなくても答えられます。正解すると、式の変化のいちばん下に答えが出ます。

### そのほか
- 「↶ ひとつもどす」：1つ前の操作にもどします（「ぜんぶ消す」「ぜんぶひっくり返す」などは、まとめて1回）。
- 「⟲ もういちど」：同じ問題をはじめから。
- 「動くはやさ」：ゆっくり・はやい・アニメなし。
- 先生モード：「▶ 手順を自動再生」（写す → ひっくり返す → かっこをはずす → 寄せる → ゼロ対を消す → 答え）、「★ 答えを見る」。

## ワークシート

- もんだい：「3*x*＋5*x* は 8*x* だろうか？ 8*x*² だろうか？」
- ① 予想：8*x*／8*x*²／15*x*／わからない
- ② 操作：答えの式を書いて正解したら「＋ 記録する」。式・まとめた式・消したゼロ対の数が表に入ります。
- ④ まとめ：「同類項は、文字の部分はそのままで、係数どうしを〜」の形で。*x* と数の項がまとめられない理由も書く。
- 保存キーは `ikechan-math-同類項タイル`（つまずきの記録もこの中）。

## 授業での使い方の例（50分）

1. **予想（5分）**：「3*x*＋5*x* は 8*x*？ 8*x*²？」ワークシートで予想と理由。
2. **確かめる（10分）**：① で 3*x*＋5*x*。タイルが 8 本 → 8*x*。*x*² は *x*×*x* のときであることを話す。続けて 3*x*＋5 で「形がちがうタイルは寄せても1つにならない」。
3. **(3*x*＋2)＋(2*x*−5)（10分）**：かっこをはずす → 寄せる → ゼロ対を消す → 5*x*−3 を書く。式の変化の行と、教科書の計算の行を見くらべる。
4. **−( ) と分配法則（15分）**：② で −(2*x*−3)。1枚だけ裏返して「かっこをはずす」を押すと、つまずきが出る（わざと見せるとよい）。③ で 2(3*x*−1)、「6*x*−1 ではない」ことを、写したタイルで確かめる。
5. **まとめ（10分）**：「同類項のまとめ方」「−( ) のはずし方」をことばで。発展として ④ を見せてもよい。

## つまずき検知の一覧

| 型 | どんなとき（検出のしかた） | 出る説明・もどり先 |
|---|---|---|
| 🧱 文字の項と数の項をまとめた | 3*x*＋5 を 8*x* と答えた（答えが項1つで、係数が全部の係数の合計）。または *x* のタイルと 1 のタイルを組にしようとした | 形がちがうタイルはまとめられない。類題は文字の項と数の項がまざった問題 |
| ² たし算で *x*² にした | 答えに *x*²（*x*^2・*xx* も）がある | *x* のタイルが 3 本と 5 本で 8 本 → 8*x*。類題は 4*a*−*a* のような文字だけの問題 |
| 🔄 −( ) のうしろの符号を変え忘れた | −( ) の中を一部だけ裏返して「かっこをはずす」を押した（残ったタイルが光る）。または −(2*x*−3) を −2*x*−3 と答えた（2つめの項から符号を変えずに計算した答えと同じ） | 中の項の符号をぜんぶ変える。類題は (a*x*＋b)−(c*x*＋d) |
| 📑 かっこの1つめの項にしかかけていない | 2(3*x*−1) を 6*x*−1 と答えた（1つめの項にだけかけた答えと同じ） | (3*x*−1) が 2 つ分。類題は ③ の問題 |
| ± 符号のまちがい | ある文字（または数の項）の係数の符号だけが反対 | ＋と−のタイルの枚数をくらべる。類題は同じタブの問題 |

- そのほか、同じ符号どうしを組にしようとしたとき・裏返す前にかっこをはずそうとしたとき・写す前に裏返そうとしたときは、つまずきの記録には入れずに、ヒントだけを出します。
- 「🔁 類題」でその型の問題へ、「▶ タイルで見る」で今の問題の手順を自動再生します。
- 記録は「答えの式を書こう」の下に回数で出ます（「記録を消す」あり）。

## 正しさについて（※じっさいとのちがい）

- タイルの係数は整数だけです（④ をのぞく）。1つの列（ある文字の＋または−）は 24 枚まで、文字は 2 種類までです。
- *x* のタイルの長さは決まっていません（*x* はいろいろな数を表すので、1 のタイル何個分とは決められない）。画面では見分けやすい長さにしています。
- ゼロ対を消すのは「たして 0 になる組を消しても、式の値は変わらない」ことを見せるためで、教科書の計算では (3−2)*x* のように係数を計算します。
- ④ の切りそろえは、分母を最小公倍数にそろえる（通分）ことを、かけらを細かく切ることで見せています。
