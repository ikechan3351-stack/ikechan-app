# ✂️ きって うごかして かさねて 方眼ボード

小学4年〜中学2年向けの、**方眼紙と色紙とハサミのデジタル版**です。方眼の上で色板（いろいた）をつくり、**切る・動かす・はる・重ねる**ことで、次のことを自分の手で確かめます。

- 切って動かしても **面積は変わらない**（等積変形）
- ぴったり重なる形は **合同**（裏がえして重なるものも合同）
- **平行移動・回転移動・対称移動** と、対応する点の関係

ジオボード（`さんすうセット⑤ ジオボード.html`）は輪ゴムで「線（輪郭）」をつくる道具です。このボードは「面のある紙」を切ってはる道具です。

## 基本情報

- **ファイル**：`きって うごかして かさねて 方眼ボード.html`。共通部品の `worksheet.js`・`worksheet.css`・`math-render.js` を読みこみます（ネット接続・外部ライブラリ・画像ファイルは不要）。
- **対応する機器**：タブレット（タッチ）、Chromebook、電子黒板、マウス。何本かの指で、別々の色板を同時に動かせます。
- **単元**（東京書籍）：4年「面積」、5年「合同な図形」「四角形と三角形の面積」、6年「対称な図形」、中1「平面図形（図形の移動）」、中2「図形の合同」。

## 道具（左の帯）

| 道具 | できること |
|---|---|
| ✏️ つくる | 格子点（マス目の交わる点）を順にタップし、最初の点にもどると色板ができる。点から指をすべらせると長方形 |
| 👆 うごかす | 引っぱると1マスずつ動く（平行移動）。選ぶと出るボタンで 90°まわす・左右／上下にうらがえす・コピー・けす。色をタップすると色が変わる |
| ✂️ きる | 格子点から格子点へ線を引くと、線が通った色板が切れる（ななめもOK。重なった板はいっしょに切れる）。線とへりが交わる点が格子点でないときは切らない |
| 🧩 はる | 1まい目をタップ（オレンジ）→ くっつけられる相手に緑の＋ → タップで1まいになる。へりがぴったりくっついている2まいだけはれる |
| 🔍 かさねる | 1まい目 → 2まい目をタップすると、2まい目が（必要なら裏がえってから）回って1まい目に重なる。「✔ 合同（うらがえすと重なる／うらがえさずに重なる）」「✖ 合同ではない」と、対応する頂点 A↔A′ を表示 |

## 上の帯

| ボタン | 中身 |
|---|---|
| 📚 お題 | お題の目次（下の表）。じゆう（白い方眼）もここから |
| 🎓 せってい | 学年（小学生／中学生）、マスの大きさ（大・中・小）、つかう人（子ども／先生） |
| 📏 長さ・📐 角度・🟦 面積 | はじめはかくれている。小学生はななめの辺を「やく4.5」、面積を「7½マス」。中学生は「√10」「5.5 cm²」。直角には□のしるし |
| ⬚ もとの形 | 切ったり動かしたりする前の形を灰色の点線で残す（はじめは ON） |
| 🧭 移動 | 動かす前の形・対応する点（A→A′）・矢印（平行移動）・中心Oと角（回転移動）・軸ℓ（対称移動）を表示。小学生は「ずらす・まわす・うらがえす」 |
| 📷 しゃしん | ボードを画像に（お題の名前と日付つき）。📋コピー で ロイロ・クラスルームにはりつけ、💾ほぞん |

下の帯：色・もどる・やりなおす・ぜんぶけす（お題のときは「はじめから」）。右はしの「ワークシート」で、よそう → やってみる → わかったこと → まとめ を書けます。

## お題（`?scene=○○` で直接ひらける）

| 学年 | お題 | `scene` | 答え方 | おもなつまずき検知 |
|---|---|---|---|---|
| 4年 | L字の面積 | `l4` | 数（20マス） | — |
| 5年 | 平行四辺形の面積 | `para5` | 数（12マス） | 半マスの数え方 |
| 5年 | 三角形の面積 | `tri5` | 数（12マス） | 半マスの数え方・÷2 わすれ（24 と答えたとき） |
| 5年 | 台形の面積 | `trap5` | 数（16マス） | 半マスの数え方 |
| 5年 | ひし形の面積 | `rhom5` | 数（12マス） | 半マスの数え方 |
| 5年 | 合同な形さがし | `cong5` | えらぶ（い・う・お） | うらがえす |
| 6年 | 線対称な図形をつくる | `sym6` | つくって たしかめる | うらがえす |
| 中1 | 回転移動した図形をつくる | `rot7` | つくって たしかめる | 回転の中心（向きの反対も知らせる） |
| 中1 | どの移動で重なる？ | `which7` | えらぶ（対称移動） | うらがえす |
| 中2 | 三角形の合同条件 | `cong8` | えらぶ（合同といえる） | — |

- お題の帯：💡ヒント（1つずつ）・👀答え・◀▶（前後のお題）・⟲はじめから。
- 動かせない色板（お題の図）は、⧉コピーだけできます。
- お題の形が画面に入りきらないときは、マスが自動で小さくなります。
- お題は `<script>` の中の `const SCENES = [...]` に1つずつ書いてあります。座標・問題文・ヒント・答えを書きかえれば、先生が自分でお題を足せます。

## 2つのモード

| | 子ども（1人で） | 先生（電子黒板・`?teacher=1`） |
|---|---|---|
| 文字・ボタン | ふつう | 大きい（マスも1.25倍） |
| まちがえたとき | ヒントを1つ自動で出す | 結果だけ出す（ヒントは先生がタップ） |
| 👀 答え | 2回まちがえるか、ヒントをぜんぶ見たあとに出る | いつでも出せる。つくるお題では答えの形を緑の点線で表示 |
| ワークシート | — | 先生用のヒントと解答例が出る |

- 起動したときは目次が出ます（`?scene=free` で目次なしの じゆう）。URL の例：`?scene=para5&teacher=1`、`?level=chu`、`?cell=L`、`?record=1`（🧭移動を ON）。

## つまずき検知の一覧

| 型 | 見つけ方 | 出すもの |
|---|---|---|
| 半マスの数え方 | 面積の答えが「ななめに切れたマスも1と数えた数」か「切れたマスを数えなかった数」と同じ | 切れたマスにしまもよう。「切って動かすと半分どうしで1マスになる」 |
| うらがえす | 合同さがしで、裏がえすと重なる「う」だけ選ばなかった／線対称で、ずらしただけの形を置いた／「どの移動」で対称移動以外を選んだ | 「🔍 かさねるで重ねてみよう」「↔️ でうらがえしてみよう」 |
| 回転の中心 | つくった形が、正しい答えを平行移動した形（向きは合っているが中心がずれている） | 点Oから、もとの形とつくった形の頂点へ点線。「OA と OA′ をくらべよう」 |

どのつまずきにも「⟲ もとの図にもどる」ボタンがつきます。

## 正しさについて

- 色板の頂点は、いつも格子点（整数の座標）にあります。面積は 0.5マスきざみ、長さは √(整数) で、小数の誤差なしで計算しています。
- 合同の判定は、頂点ごとに「辺の長さの2乗・となりの辺との内積・外積」（すべて整数）をくらべています。90°ずつでない向き（ななめ）に置いた合同な形も見つけます。
- **※じっさいとのちがい**：回す角度は 90°ずつだけです（ほかの角度で回すと頂点が格子点からはずれるため）。回転の中心は「色板の重心にいちばん近い格子点」です。切る線は格子点を通る所だけです。
- 角度は小数第1位までの表示です（例：63.4°）。

## 保存

- ワークシートは localStorage に自動保存（キー `ikechan-math-きって うごかして かさねて 方眼ボード`）。
- ボードの色板は保存しません。残したいときは 📷 しゃしん を使います。

## 授業での使い方（例）

- **5年 平行四辺形の面積（導入）**：先生モードで `para5` を出し、「マスを数えると？」→ 半分のマスが出てくることに気づかせる → 高さの線で切って動かし、長方形にする。灰色の点線（もとの形）とくらべて、面積が変わらないことを確かめる。
- **5年 合同（展開）**：子どもが1人1台で `cong5`。「か」は面積が同じでも合同ではない、を話し合う。
- **中1 図形の移動（練習）**：`rot7` で作図のかわりに色板で回転移動。🧭移動を ON にして、↻ のボタンで中心Oと角の大きさを確かめる。
- **まとめ**：📷 しゃしん でボードを提出、ワークシートに「切って動かしても、面積は〜」と書く。
