# ならして そろえて 単位量あたりの大きさ

小学5年生の算数「単位量あたりの大きさ」（東京書籍 新しい算数 5下 26〜41ページ・人口密度と速さをふくむ）で使う教材です。2つの量の組み合わせでくらべるとき、どちらかを **1あたり** にそろえる考え方を、ならす操作・二重数直線・走る車で見ていきます。

- 広さも人数もちがうときは、**1m²あたりの人数**（または **1人あたりの広さ**）にそろえてくらべる
- **人口密度**＝人口÷面積（1km²あたりの人口）
- 1あたりの量で **くらべる・全体を求める（1あたり×いくつ分）・いくつ分を求める（全体÷1あたり）**
- **速さ**＝道のり÷時間、道のり＝速さ×時間、時間＝道のり÷速さ
- **時速・分速・秒速** のなおし方（×60・÷60、km と m）

教科書と同じく「時速60km」のように書き、km/h などの記号は使いません（記号の練習は、今までの「単位あたり量トレーニング」「速さくらべ＆単位チャレンジ」を練習用として残しています）。

## 基本情報

- **ファイル**：`ならして そろえて 単位量あたりの大きさ.html`。共通ファイル `math-render.js`・`worksheet.js`・`worksheet.css` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。図はすべて SVG（子ども・車などは絵文字）。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」（5年）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。本文20px以上・ボタン48px以上。スマホのたて向きでも画面がはみ出しません。
- **漢字**：混む・人口密度・面積・時速・分速・秒速 などにふりがなをつけています。「せってい」で消せます。
- **ワークシート**：よそう → やってみる → わかったこと → まとめ（小学生向け）。「きろくする」で、場面・広さ・人数・1あたりの量などを記録します。
- **保存**：ワークシートと「せってい」を、このブラウザの localStorage（キー：`ikechan-math-ならして そろえて 単位量あたりの大きさ`）に保存します。もんだいの成績は保存しません。

## 4つの画面

### 🧍 混みぐあいを くらべよう

- **マットで 混みぐあい**：マット（1まい＝1m²）A 8m²・12人、B 8m²・10人、C 6m²・10人。「A と B」（広さが同じ）、「B と C」（人数が同じ）、「A と C」（どちらもちがう）、「ぜんぶ」を選びます。
- 「〰 ならす」で、子どもを1m²ずつのマスに同じ人数ずつならし、「1m²あたり 1.5人」のように出します。「1m²あたりの人数」と「1人あたりの広さ」を切りかえられ、表に両方の計算が出ます（わりきれないときだけ「約」）。
- 「いちばん混んでいるのは？」に答えます。「✏️ 広さと人数を かえる」で数を変えられます（ひとつ もどす・もういちど あり）。
- **人口密度**：作った町（みなみ町 42km²・16800人、きた町 28km²・12600人）。地図は1マス1km²、点1こが100人。人口密度を入れて、どちらが混んでいるかくらべます。

### ⚖️ 1あたりで くらべよう

- 場面は3つ：車のガソリン（1Lあたりの道のり）、リボンのねだん（1mあたりのねだん）、畑のとれ高（1aあたりのとれ高）。「🎲 べつの 数」で、全体だけでくらべると答えが逆になる組が出ます。
- 二重数直線で、上下を ÷○ して1にそろえることを見せます（目もりの間の長さはめやす）。① 1あたりを求める → ② どちらがよいか（ねだんは小さいほうが安い）→ ③ 1あたりを使って全体・いくつ分を求める。

### 🚗 速さ

- **走らせて くらべる**：A 150km・3時間、B 200km・5時間（10km・1時間ずつ変えられる）。「▶ スタート」で2台が走り、1時間ごとに色と模様を変えた帯がのびて「帯1本の長さ＝時速」を見せます。時速を入れて、どちらが速いかえらびます。
- **速さ・道のり・時間**：どれかが「？」の問題を二重数直線（上＝時間、下＝道のり）で考えます。はじき・みはじは使いません。
- **時速・分速・秒速**：時速 km → 分速 m → 秒速 m の箱と ×1000・÷60・×60 の矢印（36km・600m・10m など、わりきれる組）。

### ✏️ もんだい

| 種類 | 例 | 答え方 |
|---|---|---|
| 混みぐあい | A 7m²に11人、B 6m²に6人。混んでいるのは？（1人あたりの広さを見せる問題もあり） | A・B をえらぶ（1回） |
| 人口密度 | 30km²・10800人 | 数字ボタン（2回まで） |
| 1あたりで くらべる | 2mで280円 → 1mあたり／1Lあたり15km → 20Lでは | 数字ボタン（2回まで） |
| 速さ・道のり・時間 | 160km を 4時間 → 時速 | 数字ボタン（2回まで） |
| 時速・分速・秒速 | 時速36km は 分速何m？ | 数字ボタン（2回まで） |

## つまずき検知

| 型の名前 | 見つけ方 | 出るところ |
|---|---|---|
| わる数と わられる数の 逆 | 面積÷人口、L÷km、時間÷道のり のように逆にわった | 人口密度・1あたり・速さ・もんだい |
| 1あたりの 大小の 読みちがい | 1人あたりの広さが大きいほうを「混んでいる」とした／ねだんの高いほうを「安い」とした | マット・1あたり・もんだい |
| 時速と 分速の なおし方の まちがい | 分速にするのに ×60 した など | 時速・分速・秒速・もんだい |

- もんだいでは、見つけた型を「あなたの つまずき」として出し、次にその型の「にた もんだい」を1問足します。終わりに型ごとの回数と、練習できる画面へのボタンを出します。

## 先生モード（アドレスの最後に `?teacher=1`）

- 人口密度・1あたりで くらべよう・速さ・もんだい：「💡 こたえ」。ワークシートに先生用のヒントと解答例が出ます。

## 授業での使い方の例

1. **混みぐあい（2時間）**：「A と B」「B と C」でそのままくらべられる場合を確かめ、「A と C」で「そろえないとくらべられない」必要感をもたせる → ならす → 2つの見方を表でくらべる。
2. **人口密度（1時間）**：地図の点の混み方を見てから、人口÷面積で求める。
3. **単位量あたりの大きさ（2時間）**：「1あたりで くらべよう」の3つの場面で、二重数直線を使って1にそろえる → 全体・いくつ分を求める。
4. **速さ（3〜4時間）**：「走らせて くらべる」で時速の意味 → 「速さ・道のり・時間」で3つの関係 → 「時速・分速・秒速」でなおし方。
5. **まとめ**：「もんだい」で練習し、つまずきの型をふりかえる。

## 正しさと、じっさいとのちがい

- 町の名前・面積・人口、ねだんなどは作った数です。
- マットの上の人は、どこも同じようにならべられるものとしています（ならした人数は、わりきれないとき「約」をつけて小数第2位まで）。
- 車は、とちゅうで速さが変わらないものとしています（どの1時間も同じ道のりを進む）。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| マット A・B・C | オレンジ・緑・青 | A・B・C の名前 |
| 1時間ごとの帯 | オレンジ・青・緑・むらさき… | ぬりつぶし・しま・点・こうし の模様、「○時間目」 |
| 表で見ている見方 | 黄 | 列の見出し |
| 正解／まちがい | 緑／赤むらさき | ◎・✖・△ の記号 |
