# 平行四辺形と 三角形の 面積（切って、動かして）

小学5年生の算数「図形の面積」で使う、図形を切って動かして面積の公式を導くシミュレーション教材です。次のことを体験します。

- 平行四辺形を切って移すと長方形になる（**等積変形**）ことから、「**底辺×高さ**」を導く
- 三角形を2つ並べると平行四辺形になる（**倍積変形**）ことから、「**底辺×高さ÷2**」を導く
- 台形・ひし形も、知っている図形に変えて公式を導く
- 高さが図形の外にある場合もあること、底辺と高さが同じなら形が違っても面積は同じこと、高さと面積が比例すること

## しくみ（コードのつくり）

- **図形は多角形の頂点の配列**：どの図形も `[[x, y], ...]`（1目もり＝1cm、上が＋）で持っています。切れた部分も、それぞれが頂点の配列です。
- **切る**（`splitConvex`）：はさみの線で、へこみのない多角形を2つに分けます。線のはしは、方眼の点・頂点・辺の真ん中に吸い付きます。線が中を通っている部分だけが切れます。
- **動かす・回す**（`translate` / `rot90`）：回すのは90°ずつです。cos・sin が 0・1・−1 なので誤差が出ません。回す中心は重心を0.5目もりにそろえるので、回したあとも頂点が方眼からずれません。はなすと、ほかの部分の頂点か方眼の点に吸い付きます。
- **面積**（`polyArea`）：頂点の座標から計算します（靴ひも公式）。切っても動かしても同じ数になります。
- **できた形の判定**（`classify`）：部分どうしが重なっていないか（`clipConvex` で重なりの面積を計算）を調べたあと、全体を囲む最小の多角形（凸包）の面積が部分の面積の合計と同じなら「1つの形になった」と判定します。頂点が4つなら、向かい合う辺が平行か・直角かで、長方形・平行四辺形などを決めます。
- **マスを数える**（`countCells`）：マスごとに、図形と重なる面積を計算します。まるごとのマスは1つずつ番号をつけます。半端なマスは、合わせてちょうど1になる2つを探し、かたほうを動かす（またはまわす）アニメを見せます。
- **式**（`evalExpr`）：＋ − × ÷ とかっこの式を、`eval` を使わずに計算します。

## 色と模様（色だけで区別しない）

| もの | 色 | 形 |
|---|---|---|
| 底辺・下底・よこ | 青 | 太い実線 |
| 高さ・たて | オレンジ | 点線（できた長方形のたては太い実線）＋直角の印 |
| 上底 | 青緑 | 太い実線 |
| 切った部分 | 黄・青・緑・ピンク・むらさき・オレンジ | 無地・しま・水玉・こうし・なみ・いちまつ |

## モード

### 1. ▱ 平行四辺形

- 5つの形から選びます。はさみで切り、切った部分を動かして長方形にします。
- 長方形になると、たて（オレンジ）とよこ（青）が出て、「たて＝高さ、よこ＝底辺 → 底辺×高さ」のまとめを出します。
- 「💡 ヒント」1回目で切る線、2回目で「おてほん」を再生します。
- **つまずき**：ななめの辺の長さ（5cm など）を使った式には「高さは底辺に垂直」と知らせ、高さの線と直角の印を光らせます。

### 2. △ 三角形

- 方法を2つから選びます。
  - **もう1つ つける**：コピーして回し、くっつけて平行四辺形にします（直角三角形なら長方形）。
  - **高さの 半分で 切る**：高さの半分で切り、上の三角形を回して長方形にします。たてに「（高さの 半分）」と出ます。
- **つまずき**：÷2 をわすれた式には、同じ三角形をもう1つ重ねて平行四辺形を見せ、「三角形はその半分」と知らせます。

### 3. 台形・ひし形

- 台形2つ・ひし形2つから選びます。児童が自分で、切る・コピー・回すを組み合わせます。
- 正しい式は「📝 きろく」で、そのときの図の小さな絵といっしょに残ります。
- 「🔗 公式と むすびつける」で、式の中の数が 上底・下底・高さ・対角線 のどれかを色の札で示し、公式を出します。
- 「💡 アイデア」からおてほんを選べます（台形：コピーして平行四辺形／対角線で2つの三角形／高さの半分。ひし形：切って長方形／対角線で2つの三角形）。
- **つまずき**：÷2 わすれには、台形はもう1つ重ねた平行四辺形、ひし形はまわりの長方形を見せます。ひし形で「辺×辺」の式には、対角線を光らせます。

### 4. 高さが 外に ある

- 黄色い丸（三角形は頂点、平行四辺形は上の辺の左はし）をドラッグします。高さの足が外に出ると、底辺をのばした点線と直角の印が出ます。
- 「▶ ななめに 引っぱる」で自動で動かせます。三角形では「2つ 合わせると」で、平行四辺形の半分であることを重ねて見せます。

### 5. 底辺と 高さが 同じなら

- 黄色い丸は、底辺と平行な点線の上だけを動きます。面積の数字は変わりません。
- 「📌 スタンプ」で形の輪郭を残してくらべます。「▶ 動かして みる」で、頂点が左から右まで動きます。

### 6. 高さと 面積の 比例

- 底辺（3〜6cm）を決め、高さを1cmずつ変えると、表に面積が入ります。
- 「高さが2倍→面積も2倍」「面積÷高さはいつも同じ」「面積は高さに比例する」を表示します。

### 7. ✏️ もんだい

| 種類 | 例 | 答え方 |
|---|---|---|
| 平行四辺形 | 底辺6cm・高さ4cm（ななめの辺は5cm） | 数字ボタン（2回まで） |
| 三角形 | 高さが外にある形もふくむ | 数字ボタン（2回まで） |
| 台形 | 上底3cm・下底7cm・高さ4cm | 数字ボタン（2回まで） |
| ひし形 | 対角線8cm・6cm | 数字ボタン（2回まで） |
| 面積から高さ | 面積12cm²・底辺6cmの三角形の高さ | 数字ボタン（2回まで） |

- 5問なら1つずつ、10問なら2つずつ（「せってい」でえらべます）。PCはキーボードの数字・Backspace・Enter も使えます。

## つまずき検知

| 型の名前 | 見つけ方 | 出るところ |
|---|---|---|
| 公式の ÷2 わすれ | 三角形・台形・ひし形で2でわらなかった／面積から高さで ×2 をわすれた | 三角形・台形とひし形・もんだい |
| 高さの とりちがえ | ななめの辺の長さを高さとして使った（ひし形では辺×辺） | 平行四辺形・三角形・台形とひし形・もんだい |

## 先生向け設定（⚙️ せってい）

- **公式・面積の数**：「かくす」にすると、いまの面積の数とまとめの公式がかくれます（導入で児童が先に考えるため）。児童が正しい式をたしかめると、まとめは出ます。
- **ふりがな**・**こうかおん**・**うごき**（じどう／へらす／ふつう）。「へらす」にすると、アニメがすぐ終わります。
- 上の段の「⛶ ぜんがめん」で、フルスクリーンにできます。

## 動作確認の方法

1. `平行四辺形と 三角形の 面積.html` をブラウザ（Chrome・Edge・Safari）で開きます。
2. ▱ 平行四辺形：「✂️ はさみ」で、上の頂点から真下へ線をひく → 「✋ 動かす」で左の三角形を右はしへドラッグ →「長方形に なった！」と、たて・よこの表示が出ることを確かめます。
3. 式に `6×5` を入れて「＝ たしかめる」→ 高さの線と直角の印が光ることを、`6×4` で正解になることを確かめます。
4. 「🔢 マスを 数える」で、数えた数が面積と同じになることを確かめます。
5. △ 三角形：「⧉ もう1つ つける」で「💡 ヒント」を2回押し、おてほんで平行四辺形になることを確かめます。式に `6×4` を入れて、もう1つの三角形が重なって表示されることを確かめます。
6. 台形・ひし形：「💡 アイデア」からおてほんを再生し、式を入れて「📝 きろく」→「🔗 公式と むすびつける」で、数の札が出ることを確かめます。
7. 高さが 外に ある・底辺と 高さが 同じなら・高さと 面積の 比例：黄色い丸をドラッグして、表示や面積の数が変わる（変わらない）ことを確かめます。
8. ⚙️ せってい で「公式・面積の数：かくす」「ふりがな：つけない」を選び、表示が切りかわることを確かめます。

## 授業での使い方の例

### 例1：平行四辺形の公式づくり（1〜2時間）

1. 「せってい」で「公式・面積の数」を **かくす** にします。
2. ▱ 平行四辺形の形1を電子黒板に出し、「長方形なら面積を求められるのに…」と問いかけます。「🔢 マスを 数える」で、半端なマスがあって数えにくいことを確かめます。
3. 児童がタブレットで、はさみで切って長方形にします。切る場所は、頂点からでも真ん中からでもよいことを話し合います（垂直に切れば、どこでも長方形になります）。
4. できた長方形の **たて（オレンジ）** と **よこ（青）** が、もとの平行四辺形のどこの長さかを話し合います。そのあと、「底辺」「高さ」という言葉と、直角の印を確認します。
5. 式をつくってたしかめます。`6×5` とした児童には、光る高さの線を見せて「高さは底辺に垂直」を確認します。
6. 形2〜5でも、同じように「底辺×高さ」で求められるかを確かめます。

### 例2：三角形の面積の多様な求め方（2時間）

1. △ 三角形を出し、「どうすれば知っている形にできるかな」と考えさせます。
2. 「もう1つ つける」：コピーして回し、平行四辺形にします。「三角形は平行四辺形の半分 → 底辺×高さ÷2」を導きます。
3. 「高さの 半分で 切る」：切って回して長方形にします。「たてが高さの半分 → 底辺×（高さ÷2）」と、1の式が同じ答えになることをくらべます。
4. ÷2 をわすれた式には、重ねた平行四辺形の表示で「半分」を確認します。
5. 「高さが 外に ある」で、頂点を引っぱって高さが外に出る三角形を見せます。「2つ 合わせると」で、それでも平行四辺形の半分であることを確認します。

### 例3：等積変形（底辺と高さが同じなら）（1時間）

1. 「底辺と 高さが 同じなら」で、三角形の頂点を平行な点線の上で動かします。
2. いろいろな形で「📌 スタンプ」を押し、形はちがっても面積は同じことを確かめます（「公式・面積の数」を見せる設定にします）。
3. 「▶ 動かして みる」で、頂点が平行な線の上を動いても面積が変わらない様子を見せます。
4. 「高さと 面積の 比例」で、高さを1cmずつふやして表をつくり、「高さが2倍、3倍…になると面積も2倍、3倍…」を確認します。

### 例4：台形・ひし形の公式（2時間）

1. 台形・ひし形で、児童が自分で切る・コピー・回すを試し、式をつくって「📝 きろく」します。
2. いろいろな式を「みんなの式」にためたら、「🔗 公式と むすびつける」を押します。数の札（上底・下底・高さ）を見ながら、どの式も「（上底＋下底）×高さ÷2」と同じ計算になっていることを話し合います。
3. 先生モードで、台形の3とおりのやり方をステップ再生し、ふり返ります。
