# ぬって ならべて 倍数と約数

小学5年生の算数「偶数と奇数、倍数と約数」（東京書籍 新しい算数 5上 94〜107ページ）で使う教材です。次のことを体験します。

- **偶数と奇数**：2でわり切れる整数が偶数、わり切れない整数が奇数。1の位でわかる。0 は偶数
- **倍数・公倍数・最小公倍数**：数の表に2つの数の倍数をぬり、両方にぬられた数（公倍数）と、いちばん小さい公倍数を見つける。最小公倍数は、2つの数をかけた数になるとはかぎらない
- **約数・公約数・最大公約数**：タイルを長方形にならべて約数のペアを見つける。ベン図で公約数と最大公約数を見つける
- 長方形のタイルで正方形をつくる（最小公倍数）／長方形を正方形でしきつめる（最大公約数）

## 基本情報

- **ファイル**：`ぬって ならべて 倍数と約数.html`。共通ファイル `worksheet.js`・`worksheet.css`・`math-render.js` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。タイル・ベン図は SVG で描いています。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。ボタンは48px以上（スマホのたて向きでは、数の表のマスだけ小さくなります）。スマホでも画面がはみ出しません。
- **漢字**：偶数・奇数・倍数・約数・公倍数・公約数・最小公倍数・最大公約数・正方形・長方形 などの算数のことばと、5年でまだ習っていない漢字にふりがなをつけています。「せってい」で消せます。
- **保存**：ワークシートと「せってい」を、このブラウザの localStorage（キー：`ikechan-math-ぬって ならべて 倍数と約数`）に保存します。もんだいの成績は保存しません。

## 4つの画面

### 🎨 数の表で ぬろう

- 0〜99 の数の表（1の位ごとにたての列）です。
- **偶数・奇数**：「偶数を ぬる」「奇数を ぬる」で、偶数（オレンジのぬりつぶし）と奇数（青のしま）にぬり分けます。偶数は 0・2・4・6・8 の列にたてにならびます。数をタップすると「2でわり切れる偶数」などと出ます。
- **倍数・公倍数**：2〜9 から ○（1つめ）と □（2つめ）の数をえらぶと、○の倍数に ○ の印、□の倍数に □ の印がつきます。両方の数（公倍数）は黄色、最小公倍数に ★。下に公倍数の一覧と「最小公倍数は 12（4×6＝24 ではない！）」のように出ます。□は「なし」にもできます。
- **じぶんで さがす**：答えをかくして、子どもが ○ の数の倍数をタップしてぬります。「こたえあわせ」で、ぬりわすれ（紫のわく・？）とまちがい（しま）を出します。
- 「ひとつ もどす」「もういちど」あり。

### 🧩 約数を さがそう

- **約数のペア**：□ こ のタイル（6・8・12・16・18・20・24・30・36）を、たて ○ こ ずつにならべます。○ が □ をわり切れると長方形（緑）になり、「たて 3こ × よこ 4こ」→ 3 と 4 が約数のペアとして下にたまります。わり切れないと、たりない所を点線で見せます。はじめの「たて1こ」で 1 と □ も見つけたことになります。約数がぜんぶ見つかると、小さい順にならべてペアを弧でつなぎます。
- **ベン図**：○ と □ の2つの数をえらび、「ベン図に 入れる」で約数を小さい順に1つずつ入れます。重なった所が公約数、★が最大公約数です。「公約数は最大公約数の約数になっている」と出ます。

### 🟦 タイルで 正方形

- **公倍数（正方形を つくる）**：たて○cm・よこ□cm の長方形のタイルを「1まい ならべる」「正方形に なるまで ならべる」でならべます。いちばん小さい正方形の1辺が最小公倍数です。よこの長さ・たての長さの列（4、8、12…／6、12、18…）で同じ数に ★ がつきます。
- **公約数（正方形で しきつめる）**：よこ□cm×たて○cm の紙を、えらんだ1辺の正方形でしきつめます。ぴったりなら ✔、はみ出すと点線で ✖。いちばん大きい正方形の1辺が最大公約数です。

### ✏️ もんだい

- 5種類がまざって出ます（5問なら1つずつ、10問なら2つずつ）。
  - **偶数？奇数？**（0 や 3けたの数も）
  - **倍数**：□の倍数を小さい順に3つ、数の表からえらぶ
  - **約数**：□の約数をぜんぶ、数の表からえらぶ
  - **最小公倍数・最大公約数**
  - **文章題**：同時に出るバス（最小公倍数）、えんぴつとノートを同じ数ずつ分ける（最大公約数）
- 2つの数の問題は、最小公倍数がかけ算の答えとちがうもの（4と6 など）を多めに出します。

## つまずき検知

| 型の名前 | 見つけ方 | 例 | 出す声かけ |
|---|---|---|---|
| 約数の 書きもれ | えらんだ数はぜんぶ約数なのに、足りない | 30 の約数で 30 をえらばない | 約数は「かけてその数になる2つの数」のペアでさがそう。1 とその数自身も約数 |
| 公倍数と 公約数の とりちがえ | 最小公倍数を聞かれて最大公約数を答えた（その反対も） | バス 9分・12分 → 3分後 | 倍数はもとの数より大きく、約数は小さい。「同時にまた出る」は公倍数、「同じ数ずつ分ける」は公約数 |
| かけ算だけで 最小公倍数 | 最小公倍数を、2つの数をかけた数で答えた（最大公約数が1でないとき） | 4と8 → 32 | かけた数は公倍数だけど、いちばん小さいとはかぎらない。大きい方の数の倍数を順にしらべよう |

- 見つけた型は「あなたの つまずき」として出し、次にその型の「にた もんだい」を1問足します。
- 終わりの画面に、型ごとの回数を出します。

## 先生モード（アドレスの最後に `?teacher=1`）

- 数の表：「▶ じどうで ぬる」で、0 から順に倍数をぬっていきます。
- 約数：2〜100 の数を直接入力できます。「▶ じどうで さがす」で、たての数を 1 から順にためします。
- タイル：「▶ じどうで ならべる」。もんだい：「💡 こたえ」。ワークシートに、先生用のヒントと解答例が出ます。

## 授業での使い方の例

1. **偶数と奇数（1時間）**：数の表で偶数・奇数をぬり分け、1の位のきまりを見つける。
2. **倍数・公倍数（2〜3時間）**：「じぶんで さがす」で3の倍数をぬる → 3と4、4と6 の公倍数を表で見つける → ワークシートの「よそう（最小公倍数はかけた数？）」→ 「タイルで 正方形」で確かめる。
3. **約数・公約数（2〜3時間）**：「約数を さがそう」でタイルをならべて約数のペア → ベン図で公約数 → 「正方形で しきつめる」で最大公約数。
4. **練習・文章題（1時間）**：「もんだい」。

## 正しさ

- 倍数・約数・最小公倍数・最大公約数は、整数の計算（ユークリッドの互除法）で求めています。
- この アプリでは、0 は偶数に入れ、倍数には入れていません（教科書と同じ）。数の表は 0〜99 です（画面下にも書いています）。
- 教科書にある「プログラミングを体験しよう」への誘導と、発展（公倍数の性質を使う問題）は入れていません。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| 偶数／奇数 | オレンジ／青 | ぬりつぶし／しま模様 |
| ○ の倍数／□ の倍数 | オレンジ／青 | 丸い印／四角い印 |
| 公倍数・公約数 | 黄色 | 2つの印の重なり、ベン図の重なり |
| 最小公倍数・最大公約数 | オレンジ | ★ の印 |
| ベン図の2つの円 | オレンジ／青 | 実線／点線 |
| ならべられる／ならべられない | 緑／オレンジ | たりない所の点線、✔・✖ |
| 正解／まちがい | 緑／赤むらさき | ◎・△、しま模様、？ |
