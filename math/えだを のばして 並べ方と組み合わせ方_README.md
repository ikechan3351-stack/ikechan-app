# えだを のばして 並べ方と組み合わせ方（樹形図・表・点と線の図）

小学6年生の算数「並べ方と組み合わせ方」で使う、**樹形図と表を自動で作る**シミュレーション教材です。次のことを体験します。

- **並べ方**（順番がある）と**組み合わせ方**（順番は関係ない）のちがい
- 樹形図・表・図を使って、「**落ちなく、重なりなく**」調べる方法
- 樹形図の枝の数から、**かけ算で求められる**こと（3×2×1＝6）
- 組み合わせでは、並べ方の中の「**同じもの**」を消していく考え方（12÷2＝6）

## 基本情報

- **ファイル**：`えだを のばして 並べ方と組み合わせ方.html`。この1ファイルだけで動きます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。樹形図・表・図はすべて SVG（エスブイジー：線や図形を式で描く画像）で描いています。
  - プログラムは「数え上げ（順列・組合せを全部つくる）」「樹形図の形と置き場所の計算」「描画」に分けてあります。カードの数を変えても、同じ計算から図が作られます。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。
  - 広い画面は「カードと記録｜図」の2列、せまい画面は縦1列になります。ボタンは48px以上です。
  - 枝が多いとき（5まいで120通りなど）は、「＋」「－」で拡大・縮小し、スクロールして見ます。
- **カード**：色だけでなく文字でも区別できます（色の場面では「赤」「青」と書いてあります）。樹形図や一覧では名前の1文字目を使い、図の上に「あ＝あおい」の見本を出します。
- **漢字**：6年生までに習う漢字を使い、ふりがなをつけています（せっていで OFF にできます）。
- **保存**：保存されるのは「せってい」（ふりがな・音・動き・「じぶんで」のカード）だけです。見つけた並べ方はページを閉じると消えます。
- **登場する名前**：あおい・けんた・さくら・だいち・えみ は架空の名前です。

## 動作確認の方法

1. `えだを のばして 並べ方と組み合わせ方.html` をブラウザ（Chrome・Edge・Safari）で開きます。ダブルクリックで開けます。
2. 次の順に操作して、エラーや表示のくずれがないかを確かめます。

| 確かめること | 操作 | 期待される結果 |
|---|---|---|
| カードを置く | 「並べ方」→「リレー3人」で、カードを □ にドラッグ／タップ | □ に入り、使ったカードはうすくなる。□ の中をタップするともどる |
| 記録 | 3つの □ をうめて「きろくする」 | 一覧に追加。「見つけた 1通り」 |
| 重なり | 同じ並べ方をもう一度「きろくする」 | 「もう あるよ！○つ目に見つけているよ」。前の記録が光る |
| 落ちのヒント | あけさ → けあさ → あさけ の順に記録 | 「最初を ○ に決めて、全部さがそう」と「最初のカードで分ける」ボタン |
| 樹形図 | 「えだを のばす」を3回 | 1番目 3通り → それぞれ 2通り → それぞれ 1通り。下に 3 × 2 × 1 ＝ 6 |
| まだの並べ方 | 樹形図をのばしきる | 見つけた並べ方は金色と ✔、まだのものは うすい字と「まだ」 |
| 大きな樹形図 | 「じぶんで」でカード5まい・5まい →「ぜんぶ」 | 5 × 4 × 3 × 2 × 1 ＝ 120。スクロールと ＋－ で見られる |
| 組み合わせの誤り | 「組み合わせ方」→「4チームの試合」で ライオン・パンダ を記録 → パンダ・ライオン を記録 | 「ライオンとパンダの試合と、パンダとライオンの試合は ちがう 試合？」と ちがう／同じ のボタン |
| 並べ方から消す | 「✂️ 並べ方から 消す」→「1組ずつ 消す」 | 「ラパ」と「パラ」が線で結ばれ「パラ」に×。「ぜんぶ」で 12 ÷ 2 ＝ 6 |
| 表 | 「▦ 表」でマスをタップ | ○が2か所につく。全部うまると ○12こ ÷ 2 ＝ 6。「ななめ半分を消す」で下半分が灰色 |
| 点と線の図 | 「🔺 点と線の図」で点を2つタップ | 線が引ける。「のこりの線」で点線。全部で 4 × 3 ÷ 2 ＝ 6 |
| 組み合わせの樹形図 | 「🌳 樹形図」→「ぜんぶ」 | 前に出たカードにはもどらない樹形図。3 ＋ 2 ＋ 1 ＝ 6 |
| どちらかな？ | 問題1で「組み合わせ」→「並べ方」 | まちがいには「入れかえてみよう」。正解で「あおい けんた ≠ けんた あおい」と理由 |
| カードでしらべる | 答えたあと「カードで しらべる」 | その問題のまま並べ方（または組み合わせ方）のモードに移る |
| きまり | 「きまりを 見つけよう」で 2〜5人の「しらべる」→「きまりを 見る」 | 2・6・24・120 と ×3・×4・×5。6人に 720 で正解 |
| きまり（組み合わせ） | 「組み合わせ（2人を選ぶ）」で同じように | 1・3・6・10 と ＋2・＋3・＋4。6人に 15 で正解 |
| 先生モード | 「▶ のばす」を数回（キーボードの → でも可） | 1本ずつ枝がのび、「ア → イ → ウ『アイウ』で 1通り目」 |
| 設定 | ⚙️ でふりがな OFF・動きを へらす | ふりがなが消える。アニメなしで すぐに結果が出る |

## 授業での使い方の例

### 1時間目：並べ方の導入（リレーの走る順番）

1. **問題をつかむ**：「リレー3人」の問題を電子黒板に出し、「走る順番は何通りあるかな？」と予想させます。
2. **自由に調べる**：児童がタブレットでカードを並べて記録します。思いついた順に記録すると、重なり（「もう あるよ」）や落ちが出やすいことを体験させます。
3. **順序よく調べる**：ヒントの「最初を あおい に決めて全部さがそう」を取り上げ、「最初のカードで分ける」で一覧を整理します。「あおいから始まるのは2通り。けんたからは？」と、決めて調べるよさを話し合います。
4. **樹形図でたしかめる**：「えだを のばす」を1回ずつおし、「1番目は3通り」「それぞれ2通り」…と確かめます。光っていない「まだ」があれば、落ちていた並べ方です。
5. **かけ算に気づく**：下の式「3 × 2 × 1 ＝ 6」に注目させ、「リレー4人」で 4 × 3 × 2 × 1 ＝ 24 を確かめます。先生モードで1本ずつのばしながら説明するのも効果的です。

### 2時間目：組み合わせとの比較（チームの試合）

1. **前の時間とくらべる**：「4チームの試合」で、児童に試合の組み合わせを記録させます。並べ方のように「ライオン・パンダ」「パンダ・ライオン」を両方記録しようとすると、「ちがう試合？」と問いかけが出ます。
2. **同じものを消す**：「並べ方から 消す」で、並べ方12通りを全部出し、同じ組み合わせを1組ずつ線で結んで消します。「同じものが2つずつ → 12 ÷ 2 ＝ 6」。3つ選ぶ場面（くだもの3つ）では、同じものが 3×2×1＝6 こずつになることも見せられます。
3. **表や図でも**：「表」（対戦表）では○が2か所につくこと、「ななめ半分」で同じ試合を消せることを確かめます。「点と線の図」では、線1本が1試合になること、1つの点から3本ずつ出ていることから 4 × 3 ÷ 2 を考えます。
4. **どちらかな？**：文章題を読んで、並べ方か組み合わせかを判断します。「2つを入れかえると、ちがうものになる？」を見分け方として確かめ、「カードで しらべる」で実際に数えます。

### 3時間目：きまりの発見（人数がふえると？）

1. 「きまりを 見つけよう」で、2人・3人・4人・5人の樹形図を順にのばし、表に 2・6・24・120 が入っていく様子を見ます。
2. 「何倍になっているかな？」と問い、「きまりを 見る」で ×3・×4・×5 と式（3×2×1 など）を確かめます。
3. 「6人なら？」を予想して入力し、「たしかめる」で 720 を確かめます。樹形図をかかなくても、かけ算で求められるよさを話し合います。
4. 発展として「組み合わせ（2人を選ぶ）」に切りかえ、1・3・6・10 と ＋2・＋3・＋4 でふえるきまりを見つけます。

## 先生向けの設定

- **せってい（⚙️）**：「じぶんで」の場面のカードの文字（5まいまで）、ふりがな、効果音、動きを減らす。
- **じぶんでの場面**：カードの数（並べ方は2〜5まい、組み合わせは3〜5まい）と、並べる・選ぶ数をえらべます。
- **全画面（⛶）**：電子黒板で大きく見せるときに使います。
