# いれて さがして 文字と式

小学6年生の算数「文字と式」（東京書籍 新しい算数 6年 24〜31ページ）で使う教材です。次のことを体験します。

- いろいろな数のかわりに **x** を使うと、式が1つですむこと
- x に数をあてはめて **式の値** を求めること
- x と y の関係を **x×4＝y** のような式に表すこと
- y の値から x を求めること（矢印の図を **ぎゃくにたどる「もどり道」**）
- 式の数や記号が、場面のどこにあたるかを **よむ** こと

6年なので × ははぶかずに x×4 と書きます（はぶく書き方は中1）。

## 基本情報

- **ファイル**：`いれて さがして 文字と式.html`。共通ファイル `worksheet.js`・`worksheet.css`・`math-render.js` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。絵と矢印の図は SVG と HTML でかいています（クッキーやえんぴつは絵文字）。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」（6年）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。ボタンは48px以上。スマホのたて向きでも画面がはみ出しません。
- **漢字**：式・値・辺・代金・面積 などにふりがなをつけています。「せってい」で消せます。
- **保存**：ワークシートと「せってい」を、このブラウザの localStorage（キー：`ikechan-math-いれて さがして 文字と式`）に保存します。もんだいの成績は保存しません。
- **範囲**：数は整数と、1/10 の位までの小数（2.5cm など）です。

## 3つの画面

### ✋ x に いれて みよう

場面は3つ：正方形のまわりの長さ（x×4）／テープをつなぐ（x＋25）／ケーキ5こと箱代80円（x×5＋80）。−・＋ボタン、スライダー、数の入力で x を変えると、絵・式・表がいっしょに動きます。上のステップを順にすすみます（先生モードではどれでもえらべます）。

1. **① 数で 書こう**：数を変えるたびに「3×4＝12」のような数の式がたまります。ちがう数で3つ書くと「式の形はいつも同じ。かわる数を x にすると式は1つですむ」とまとめが出ます。このステップでは、まだ x を見せません。
2. **② x で まとめよう**：式は x×4 のまま。数を変えると「x に 6 を いれると 6×4＝24」と、x の場所に数が入ります。表には「式の値」として記録します。
3. **③ x と y**：答えのほうも y にして x×4＝y。x と y の表をつくります。
4. **🔍 x を さがす**：「y が 1330円になる x は？」。x をためすと「大きすぎ／小さすぎ」が出ます。「💡 もどり道」で、矢印の図に逆向きの点線（−80、÷5）と、とちゅうの数が出ます。絵は「ためした」数でかくので、ためす前に答えは見えません。

「ひとつ もどす」「もういちど」「べつの もんだい」あり。ワークシートの「＋ きろくする」で、場面・式・x・y を記録します。

### 🔗 式を よもう

- **👀 式を よむ**：えんぴつとノート（x×3＋120）／クッキーのふくろとばら（x×4＋5）／のこりのお金（x−150）／リボンを分ける（x÷4）／長方形の面積（x×6）。式を「x」「×3」「＋120」のようなかけらに分けて出し、タップすると絵のどこにあたるかが光って、いみが出ます。ぜんぶタップすると、式全体のいみのまとめが出ます。
- **🔗 場面と 式を むすぶ**：場面3つと式4つ（1つはまちがいの式）を、タップで線でむすびます。場面からでも式からでもえらべます。むすび終わったら「あまった式は、どんな場面の式かな？」と出ます。

### ✏️ もんだい

5種類がまざって出ます（5問なら1つずつ、10問なら2つずつ。「せってい」でえらべます）。

| 種類 | 例 | 答え方 |
|---|---|---|
| 場面を 式に | えんぴつ3本と120円のノートの代金 | 3つからえらぶ（1回） |
| 式の 値 | x が 9 のとき x×7＋30 の値 | 数字ボタン（2回まで） |
| x を もとめる | x×4＋30＝78 のときの x | 数字ボタン（2回まで） |
| 式から 場面 | x×4＋5 にあう場面 | 3つからえらぶ（1回） |
| 式を よむ | x×3＋120 の「×3」は何を表す？（絵つき） | 3つからえらぶ（1回） |

- 問題は答えを先に決めてから式をつくるので、答えはいつも整数です。同じ問題は続けて出ません。
- 「💡 ヒント」：x をもとめる問題では、矢印の図（もどり道）が出ます。
- PCはキーボードの数字・Backspace・Enter も使えます。

## つまずき検知

| 型の名前 | 見つけ方 | 例 | 出す声かけ |
|---|---|---|---|
| かける数の いちちがい | 場面を式にする問題・場面と式をむすぶで、かっこの式をえらんだ／式の値で、たしてからかけた答えを入れた | x×5＋80 の場面で (x＋80)×5、x が 9 の x×7＋30 で 273 | かけるのは「いくつもあるもの」だけ。1つしかない数（箱代など）は、かけ算のあとでたす |
| もどすとき 同じ計算 | x をもとめるとき、行きと同じ計算をした答え（順番を入れかえたもの・一部だけのものもふくむ） | x×4＝36 で 144、x×5＋80＝830 で 4230 | 矢印をぎゃくにたどる。×のもどりは÷、＋のもどりは− |
| x と y の とりちがえ | x をもとめるとき、y の数をそのまま答えた | x×4＝28 で 28 | 右がわの数は x に数を入れたあとの答え（y）。さがしているのは x |

- 見つけた型は「あなたの つまずき」として出します。もんだいでは、次にその型の「にた もんだい」を1問足します。
- 終わりの画面に型ごとの回数を出し、「🔗 式を よもう」または「✋ x に いれて みよう」へもどるボタンを出します。
- 「✋ x に いれて みよう」の「🔍 x を さがす」でも、あとの2つの型を見つけます。

## 先生モード（アドレスの最後に `?teacher=1`）

- x に いれて みよう：「▶ じどうで いれる」で数を順に入れます。ステップはどれでもえらべます。さがすでは「💡 こたえ」で答えともどり道の計算を出します。
- 式を よむ：「▶ じどうで よむ」でかけらを順に光らせます。むすぶ：「💡 こたえ」でぜんぶ線でむすびます。
- もんだい：「💡 こたえ」。ワークシートに、先生用のヒントと解答例が出ます。

## 授業での使い方の例

1. **x を使った式（1〜2時間）**：「x に いれて みよう」の①で数の式を3つ書き、かわる数とかわらない数に気づかせる → ②で x を使った式と式の値 → テープ・ケーキの場面でも確かめる。
2. **x と y（1時間）**：③で x×4＝y の表をつくる → 「🔍 x を さがす」で、ためしてから「もどり道」で計算して求める。
3. **式のよみ方（1時間）**：「式を よもう」でかけらと絵を対応させる → 「むすぶ」であまった式の場面を話し合う。
4. **まとめ**：「もんだい」で練習し、つまずきの型をふりかえる。

## 正しさと、じっさいとのちがい

- 小数のずれが出ないように、数は10倍した整数（2.5 → 25）で計算し、見せるときだけもとにもどしています。
- ケーキのねだんや箱代などは作った数です。
- 式は左から計算し、かけ算・わり算を先にするきまりの範囲だけを使っています（かっこの式はまちがいの選択肢としてだけ出します）。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| x／y | 青／オレンジ | 四角いわく／丸いわく、x・y の文字 |
| 行きの矢印／もどり道 | 紺／赤むらさき | 実線／点線、上／下 |
| 大きすぎ／小さすぎ／ぴったり | 赤むらさき／青／緑 | ⬆・⬇・◎ の記号と文字 |
| 正解／まちがい | 緑／赤むらさき | ◎・✖・△ の記号 |
