# 一次方程式のステップ（次の一手を選んで、1ステップずつ解く）

中学1年「一次方程式」で、等式の性質と移項を使って、方程式を**1ステップずつ**解くアプリです。
いまの式を見て「次に何をするか」を生徒が自分でカードから選びます。正しければ式が変形し、まちがえるとその理由（どうなってしまうかの式つき）が出ます。

## 基本情報

- **ファイル**：本体 `方程式ステップ.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中1）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン・スマホ（式が長いときは文字が小さくなります）。
- **色のきまり**：正（＋）＝オレンジ・実線の下線、負（−）＝青・点線の下線、正解＝緑の「○」、まちがい＝赤紫の「×」。
- **URL の設定**
  - `?teacher=1` … 先生モード（最後まで自動で見せる・つぎの1手・答え・この端末のきろく・ワークシートのヒントと解答例）
  - `?ws=0` … ワークシートをとじて開く

## 使い方

1. 上のチップでレベルを選びます。
   - ① ax＋b＝c（例 3x＋5＝14）
   - ② x が両辺（例 3x−5＝x＋7）
   - ③ かっこ（例 2(x−3)＝10、5x−2(x＋1)＝7、3(x＋1)＝2(x−2)）
   - ④ 小数・分数（例 0.3x＋1.2＝0.5x−0.4、x/2＋1＝x/3＋2、(x＋1)/2＝(x−2)/3）
2. 「👇 次の一手はどれ？」のカード（4〜6まい）から1つ選びます。カードの例：両辺に5をたす／両辺から5をひく／＋5 を右辺へ移項する／まとめて移項する／同類項をまとめる／かっこをはずす／分母をはらう（両辺に6をかける）／両辺を10倍する／両辺を3でわる。
3. **天秤アイコン**：両辺に同じ操作をすると、両方の皿に同じ札（−5・×6・÷3）がのり、つり合ったまま。「右辺だけに5をたす」のような片方だけの操作では、天秤がかたむきます。
4. **移項の矢印**：移項を選ぶと、うつす項に色がつき、反対の辺へ矢印がのびて「＋5 → −5」と符号のかわり方が出ます。うつった先でも色がつきます。
5. 移項・かっこをはずす・分母をはらう（10倍）を選んだときは、**変形したあとの式**を3つから選びます（チェックを外すと選ばずに進みます）。
6. 「x ＝ 数」になったら**検算**。もとの式の左辺と右辺に解を代入した式が出るので、それぞれの値を入力して「たしかめる」。2回まちがえると「答えを見る」が出ます。
7. 「📝 式のきろく」には、操作ごとに式が1行ずつ（＝の位置をそろえ、右に何をしたか）残ります。等式の性質で解いたときは、とちゅうの式（3x＋5−5＝14−5）と計算した式の2行が残ります。

ボタン：🎲 新しい問題／↶ ひとつもどす（3択の途中ならカード選びにもどる）／⟲ もういちど／💡 ヒント（1回目はことば、2回目は使えるカードが光る）／📄 ワークシートの問題（3x−5＝x＋7）

## 正しいとする一手（解き方の順）

1. 小数がある → 両辺を10倍（小数第2位まであれば100倍）
2. 分数がある → 分母の最小公倍数を両辺にかける（分母をはらう）
3. かっこがある → かっこをはずす（m(x＋p)＝d で d が m でわりきれるときは「両辺を m でわる」も正解）
4. x の項は左辺、数の項は右辺へ（移項／「両辺から5をひく」などの等式の性質。どちらも正解）・同類項をまとめる
5. ax＝b → 両辺を x の係数 a でわる

まちがいのカードには、それぞれ理由が出ます（例：両辺に5をたすと 3x＋10＝19 になって遠ざかる／x の係数をひいても x は1こにならない／10倍しても小数が残る／かっこの中の項はそのままでは移項できない など）。

## 授業での使い方（例）

- **導入（5分）**：ワークシートの予想「3x−5＝x＋7 の解は偶数？奇数？」を挙手で集める。
- **展開（20分）**：「📄 ワークシートの問題」を全員で解き、検算まで。先生モードの「⏭ つぎの1手」で1手ずつ見せ、「次は何をする？」と発問する。
- **練習（15分）**：各自でレベル①→④。「🔎 あなたのつまずき」に出た型の「この型を練習」で類題に取り組む。
- **まとめ（5分）**：ワークシートの④に、解き方の順（かっこ・分母をなくす → 移項 → まとめる → 係数でわる）を書く。

## つまずき検知の一覧

| 型 | どこで見つけるか | 練習のレベル |
|---|---|---|
| 移項で符号を変え忘れた | 移項のあとの3択で、符号をかえないままの式を選んだ | ② |
| 移項した項を書き忘れた | 移項のあとの3択で、うつした項が消えた式を選んだ | ② |
| 分母をはらう（10倍する）とき、かけ忘れた項がある | 3択で、整数の項・右辺・最後の項にかけていない式、分子にかっこをつけずにかけた式を選んだ | ④ |
| かっこの前の − の処理ミス | 3択で −2(x−3) → −2x−6、−(x−3) → x−3 のような式を選んだ | ③（ax−n(x＋p) の形） |
| かっこの中の一部の項にしかかけていない | 3択で 2(x＋3) → 2x＋3 のような式を選んだ | ③ |
| 片方の辺だけに計算した | 「右辺だけに5をたす」などのカード（天秤がかたむく） | ① |
| x の係数をひいた | 3x＝12 で「両辺から3をひく」のカード | ① |
| x の項と数の項をまとめた | 「3x＋5 をまとめる」のカード | ② |
| 計算のまちがい | 3択で、数が1つずれた式を選んだ | ② |

記録は、この端末の localStorage（キー `ikechan-math-方程式ステップ`、ワークシートと同じ）に入ります：レベルごとのクリア数・まちがえたカードの数・ヒントの回数・つまずきの型ごとの回数。先生モードで合計を見たり消したりできます。

## 正しさとじっさいとのちがい

- 計算はすべて分数（Fraction）で行い、小数は見せるときだけ小数にしています。
- 問題は答え（整数）を先に決めてから作り、同じ問題が続けて出ないようにしています。
- 教科書では「3x＝14−5」の計算を同じ行ですることも多いですが、ここでは「移項」と「計算する（同類項をまとめる）」を別の一手にしています。
- x の項を左辺、数の項を右辺に集める解き方を正解にしています（右辺に x を集めても解けますが、このアプリではまちがいのカードとして理由を出します）。
- 分母をはらうときは最小公倍数をかける一手だけを正解にしています（ほかの公倍数でも解けます）。
