# 場合の数と確率ドリル

中学2年「確率」のレベル別ドリルです。1回 10問。1問ごとに **① 場合の数**（すべての場合・条件に合う場合）→ **② 確率**（分子と分母を別に入れる）の順に答えます。樹形図や表を書く習慣をつけるため、ヒントで「🌳 樹形図をかく」「🔲 表をつくる」を選べ、答えたあとは数え方を1つずつ再生できます。

## ねらい

- 場合の数（並べ方・選び方）と確率を求める練習。
- 樹形図や表を書いて、もれなく・重なりなく数える習慣をつける。

## レベル

| レベル | 内容 | おもな問題 |
|---|---|---|
| ① サイコロ1個・コイン | 同様に確からしい | サイコロ1個の目、コイン2枚（A・B）、袋の玉 |
| ② サイコロ2個・コイン3枚 | 表と樹形図 | サイコロ2つ（表がおすすめ）、コイン3枚（樹形図） |
| ③ カードを引く | もどす・もどさない | 2枚引いて2けたの整数（もどす 4×4／もどさない 4×3） |
| ④ くじ引き | 当たりは順番に関係しない | A・B（・C）が順に引く、同時に2本 |
| ⑤ 並べ方・代表の選び方 | 順列・組み合わせの入口 | 1列にならぶ、委員長と副委員長（順番あり）、代表2人（順番なし） |
| ⑥ 少なくとも1つ | 余事象 | ① で「1つも〜ない」場合を数え、② で 1 − で求める |
| 🔀 ミックス | ①〜⑥ をまぜる | |

## 基本情報

- **ファイル**：本体 `確率ドリル.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **URL の設定**
  - `?teacher=1` … 先生モード（答え・自動で1ステップ進める・問題番号を決める・この端末のきろく）
  - `?lv=1`〜`6` または `?lv=mix` … そのレベルをえらんだ状態で開く（「樹形図で確率」からのリンクで使う）
  - `?ws=0` … ワークシートをとじて開く

## 使い方

1. レベルをえらんで「▶ 10問 スタート」。問題番号を入れると、同じ番号・同じレベルなら同じ問題になります。
2. **① 場合の数**：「すべての場合」と「条件に合う場合」（⑥ は「1つも〜ない場合」）を入れて「こたえる」。「⇥ つぎの欄」で欄を移ります。
3. **② 確率**：分子と分母を別に入れます。**約分した形だけが正解**です。
4. まちがえると、つまずきの型と説明が出て、もう1回答えられます。2回まちがえると答えが出ます。
5. 記録：○＝1回で正解、△＝2回目で正解、×＝答えを見た。点数は ○ の数です。
6. ヒント：
   - 「🌳 樹形図をかく」「🔲 表をつくる」で、その問題の樹形図・表が出ます（✓ は自分でつけて数える）。
   - 3つ以上を順に決める問題で「表」を押すと「表にしにくい。樹形図をかこう」と出ます。サイコロ2つで「樹形図」を押すと「36通りもあるので表の方が楽」と出ます。
   - もどさない・同時に のときの表は、ありえないマスに ×（同じものは2回引けない）や —（同じ組）が入ります。
7. 答えたあと「▶ 数え方を再生」：すべての場合を1つずつ数え（番号と「すべての場合 ○通り」が増えていく）、つぎに条件に合うものに ✓（⑥ は ◆）をつけて数え、最後に確率の式を出します。
8. 「↶ ひとつもどす」で前の問題を見なおし（答えはかえられない）、「⟲ もういちど」で同じ10問をはじめから。結果の画面で「まちがえた問題だけ もう一度」ができます。

## 印刷（A4 20問と解答）

「🖨 A4 20問と解答を印刷」で、えらんだレベルの 20問（1ページ10問 × 2ページ、樹形図・表を書くわく と 答えの欄つき）と、解答（1ページ）を印刷します。問題番号が空なら番号を自動で決めて入れるので、同じ番号でもう一度印刷すると同じプリントになります。

## つまずき検知の一覧

| 型 | 見つけ方 |
|---|---|
| 並べ方で順番を無視した | 順番のある場合（順に引く・委員長と副委員長・2けたの整数）を、順番なしで数えた数・確率 |
| 選び方なのに順番を区別した | 同時に取り出す・代表を選ぶ場合を、順番ありで数えた数・確率 |
| 同様に確からしくない場合で数えた | 2枚のコインの「表1枚・裏1枚」を1通りとした、サイコロ2つの (1,6) と (6,1) を同じとした、玉を色だけで数えた 数・確率 |
| 約分していない | 確率の値は合っているが約分していない |
| もどす・もどさないの取りちがえ | もう一方（もどす⇔もどさない）で数えた数・確率 |
| 起こらない確率をそのまま答えた | ⑥ で「1つも〜ない」確率を答えた |
| 数えもれ・数えすぎ | どの型にも当てはまらないまちがい |

「あなたのつまずき」の「🔁 この型を10問練習」で、その型が見分けられる問題を多めにした10問が出ます。きろくは localStorage の `ikechan-math-確率ドリル` に保存されます。10問おわるたびに、ワークシートの表に「レベル・点数・つまずきの型」が記録されます。

## 授業での使い方（例）

- **「樹形図で確率」のあとの練習**：「樹形図で確率」の練習問題に正解すると、このドリルの同じ内容のレベルへのリンクが出ます。
- **全体の答え合わせ**：問題番号をそろえて解き、△・× の多い問題を全体で。先生モードの「自動で1ステップ」と「▶ 数え方を再生」で説明できます。
- **宿題・テスト前**：印刷のプリント（20問と解答）。

## ※じっさいとのちがい

- コイン・サイコロ・くじ・カード・玉・くじ引きの順番は、どの結果も同じ程度に起こるものとしています。
- 問題は乱数で作り、確率が 0 や 1 にならないものだけを出しています。同じ10問（20問）の中に同じ問題は入りません。
- サイコロ2つ・4人の並び方の樹形図は長くなるので、行の高さをせまくしています。
