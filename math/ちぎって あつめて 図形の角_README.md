# ちぎって あつめて 図形の角

小学5年生の算数「図形の角」（東京書籍 新しい算数 5上 84〜93ページ）で使う教材です。次のことを体験します。

- **三角形の3つの角の大きさの和は 180°** であること（どんな形でも）
- 四角形・五角形・六角形を **1つの頂点からの対角線で三角形に分けて**、角の和を求めること。**三角形の数は頂点の数より2少ない** → ○角形の角の和は 180×（○−2）
- **合同な四角形で平面をしきつめられる** こと（1つの点のまわりに4つの角が集まって 360°）

## 基本情報

- **ファイル**：`ちぎって あつめて 図形の角.html`。共通ファイル `worksheet.js`・`worksheet.css`・`math-render.js` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。図はすべて SVG で描いています。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）。頂点のドラッグは pointer events で、マウスでもタッチでも動きます。ボタンは48px以上。スマホのたて向きでも画面がはみ出しません。
- **漢字**：図形・角・和・頂点・対角線・三角形・四角形 などの算数のことばと、5年でまだ習っていない漢字にふりがなをつけています。「せってい」で消せます。
- **保存**：ワークシートと「せってい」（方眼にすいつく、もふくむ）を、このブラウザの localStorage（キー：`ikechan-math-ちぎって あつめて 図形の角`）に保存します。もんだいの成績は保存しません。

## 3つの画面

### ✂️ ちぎって あつめよう

- 三角形の頂点（丸）をドラッグして形を変えます。3つの角に ア（オレンジ・ぬりつぶし）・イ（青・しま）・ウ（緑・水玉）の扇形の印がつき、角の大きさと和が出ます。
- 「✂️ ちぎって あつめる」で、3つの角がちぎれて下の1点に集まり、ならんで一直線（180°）になるアニメーションが流れます。「もとに もどす」で三角形にもどります。
- ほそすぎる三角形（角が8°未満・辺が短すぎる）にはなりません。
- 「方眼に すいつく」をONにすると、頂点が方眼の点（20px ごと）にすいつきます。
- 「ひとつ もどす」「もういちど」あり。ワークシートの「＋ きろくする」で、形・角の大きさ・和を記録します。

### 🔷 三角形に わけよう

- 四角形・五角形・六角形をえらび、頂点をドラッグします。へこんだ形やねじれた形にはなりません。
- 「🔷 三角形に わける」で、1つの頂点（ア）から対角線をひき、三角形に番号をつけて色分けします。「三角形 3こ → 180×3＝540°」のように出ます。
- 右の表は、分けた形の行がうまります（三角形の行ははじめからうまっています）。四・五・六角形がうまると、七・八角形の行と「三角形の数は頂点の数より2少ない」「角の和＝180×（頂点の数−2）」のきまりが出ます。
- 四角形のときは「🧩 しきつめ」で、同じ四角形（と、辺の真ん中で 180° 回した四角形）で平面をしきつめた図を出します。どの点のまわりにも ア・イ・ウ・エ が1つずつ集まり、○の点に「ア＋イ＋ウ＋エ＝360°」と出ます。いま動かしている四角形の形でしきつめるので、どんな四角形でもしきつめられることが確かめられます。

### ✏️ 角を もとめよう

- 5種類がまざって出ます（5問なら1つずつ、10問なら2つずつ）。
  - **三角形の 角**：2つの角から、のこりの角（例 40°・30° → 110°）
  - **二等辺三角形**：底の角から上の角、または上の角から底の角（等しい辺に印）
  - **外がわの 角**：辺をのばしたところの角（となりの角を出してから 180° からひく）
  - **四角形の 角**：3つの角から、のこりの角（360° からひく）
  - **角の 和**：「八角形の角の和は何度？」
- 図は、問題の角の大きさで正しくかいています（三角形は5°きざみ、四角形は図から計算して1°きざみ）。
- 答えは数字ボタン（PCはキーボードの数字・Backspace・Enter も可）で入れます。

## つまずき検知

| 型の名前 | 見つけ方 | 例 | 出す声かけ |
|---|---|---|---|
| 四角形も 180° | 四角形ののこりの角で、答えが「180 −（ほかの角のどれか、またはいくつかの和）」になっている。または四角形の角の和を 180° と答えた | 75°・120°・102° の四角形で 105° | 180° は三角形の角の和。四角形は対角線で三角形2こに分けられるから 360° |
| 三角形の 数を 頂点の 数に する | ○角形の角の和を 180×○ や 180×（○−1）と答えた | 八角形 → 1440° | 1つの頂点から対角線をひくと、三角形の数は頂点の数より2少ない |

- 見つけた型は「あなたの つまずき」として出し、次にその型の「にた もんだい」を1問足します（「四角形も 180°」の にた もんだい は、四角形の角の和の問題も出ます）。
- 終わりの画面に、型ごとの回数を出します。

## 先生モード（アドレスの最後に `?teacher=1`）

- 「角の 数字を かくす」で、図と表の角の大きさを「？」にできます（「和はいくつになると思う？」と予想させてから見せるとき）。
- 三角形に わけよう：「▶ じどうで わける」で、四・五・六角形を順に分けて表をうめます。
- 角を もとめよう：「💡 こたえ」で答えと式を表示します。ワークシートに、先生用のヒントと解答例が出ます。

## 授業での使い方の例

1. **三角形（1時間）**：「三角形の3つの角をたすと？」とワークシートの「よそう」をえらばせる → 「ちぎって あつめよう」で、とがった三角形・平たい三角形・直角三角形などをつくって「ちぎって あつめる」 → いつも一直線になることを記録 → 「角を もとめよう」で三角形・二等辺三角形・外がわの角。
2. **四角形・多角形（1〜2時間）**：「四角形の角の和は？」と予想 → 「三角形に わけよう」で四・五・六角形を分けて表をうめる → きまりを見つけて七・八角形を予想 → 「しきつめ」で 360° を確かめる → 「角を もとめよう」で四角形の角・角の和。

## 正しさと、じっさいとのちがい

- 角の大きさは、頂点の座標から計算しています。表示は1°きざみに四捨五入し、合計が 180°（○角形なら 180×（○−2））になるように、はしたの大きい角から1°ずつ調整しています（最大でも1°のちがい）。この調整は画面下の「※じっさいとのちがい」に書いています。
- しきつめの図は、四角形を辺の真ん中で 180° 回した形と組にし、「A−C」「B−D」の向きにずらしてならべています（数学的に正しいしきつめ方です）。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| ア・イ・ウ・エ・オ・カ の角 | オレンジ・青・緑・むらさき・水色・茶 | 模様（ぬりつぶし・しま・水玉・×・横線・たて線）と、カタカナの名前 |
| 分けた三角形 | 青・オレンジ（交互） | 三角形の中の番号 ①②③ |
| 求める角 | むらさき | 「？」の文字 |
| 正解／まちがい | 緑／赤むらさき | ◎・△ の記号 |
