# 🔺 二等辺三角形の性質（中2・図形）

二等辺三角形を動かしても変わらない性質（底角が等しい・頂角の二等分線が底辺を垂直に2等分する）を見つけ、折って合同を確かめ、その逆（2つの角が等しければ二等辺三角形）を調べます。直角三角形の合同条件と、垂直二等分線・角の二等分線の性質（利用）までをあつかいます。

- ファイル：`math/二等辺三角形の性質.html`（共通部品 `worksheet.js`・`worksheet.css`・`math-render.js` を使用）
- 先生モード：`二等辺三角形の性質.html?teacher=1`
- パートを指定して開く：`?part=1`〜`?part=5`（例：`?part=4` で直角三角形の合同から）
- 計画表の番号：2-15。「証明パズル」（2-14）・「作図ツール」（1-14）とつながっています。

## 使い方（5つのパート）

| パート | できること |
|---|---|
| ① つくって調べる | ● をドラッグしても AB＝AC のまま（A は BC の垂直二等分線の上だけを動く）。頂角・底角はスライダーと数の入力でも変えられる。「線 AM」で頂角の二等分線・底辺の垂直2等分、「コンパスの円」で AB＝AC を確かめる。正三角形・直角二等辺三角形にするボタンつき。 |
| ② 折って確かめる | 頂角の二等分線（緑の点線）を折り目にして「▶ 折る」。ぴったり重なると、合同条件をえらぶ問題が出る（2組の辺とその間の角）。正解すると、∠B＝∠C、BD＝CD、∠ADB＝90° が表示され、「証明パズル ①」へ進める。「ふつうの三角形」では B が C に重ならないことをくらべられる。 |
| ③ 逆 | ∠B・∠C をつまみやスライダーで決めて三角形をつくる。∠B＝∠C のとき AB＝AC になる（コンパスの円でも確かめられる）。「わけを考える」で ∠A の二等分線をひき、1組の辺とその両端の角で合同になる説明を表示。3つの角を 60° にすると正三角形。 |
| ④ 直角三角形の合同 | 🔍 斜辺 AB をそのままに、C を半円の上で動かす。「📌 のこす」→ C を動かすと、斜辺が等しいのに合同でない三角形（反例）ができる。「＋ ∠A も等しく」「＋ BC も等しく」で C の場所が1つに決まり、合同になる。❓ クイズでは、2つの三角形のしるしを見て合同条件をえらぶ（「合同とはいえない」もある）。 |
| ⑤ 利用 | 📏 点 P を動かして PA＝PB になる点に印をつけると、垂直二等分線の上にならぶ。📐 PH＝PK（角の2辺までの距離）になる点に印をつけると、角の二等分線の上にならぶ。わけ（④ の合同条件）も表示。作図ツールへのリンクつき。 |

共通のボタン：✏️ 練習問題／↶ ひとつもどす／⟲ もういちど／💡 ヒント（3段階）／📄 ワークシートの問題。図の下の「すいつく」で、方眼の点・整数の角にすいつくかを切りかえられます。

## 授業での使い方の例（50分）

1. （5分）ワークシートの予想「底角が 60° の二等辺三角形は？」を挙手で集める。
2. （10分）① で A をいろいろ動かし、変わらないことを見つける。底角を 60° にして確かめ、記録する。
3. （10分）② で折って重ね、合同条件をえらぶ。「定義」と「定理」のちがいを確認し、証明パズル ① で証明を組み立てる。
4. （10分）③ で逆を調べ、練習問題で「逆のつくり方」「逆はいつも正しいか（反例）」を練習する。
5. （10分）④ で斜辺だけでは合同にならない反例をつくり、直角三角形の合同条件をまとめる。
6. （5分）⑤ は次の時間の導入や、作図（中1）のふりかえりに使う。

④ ⑤ だけで1時間にしてもよいです（`?part=4` で開く）。

## 正しさとじっさいとのちがい

- 方眼の1目もりを 1cm としています。長さは 0.1cm の位までの四捨五入です。
- ① ② の角は、頂角を整数に四捨五入し、底角はそこから (180° − 頂角) ÷ 2 で出すので、底角が 0.5° になることがあります（底角が等しいことがくずれないようにするため）。
- ③ は BC＝12cm、∠B・∠C は 15°〜70°。長さは正弦定理で計算しているので、∠B＝∠C のとき AB と AC はぴったり同じ値になります。
- ④ の「C が動ける道（半円）」は、中3で学ぶ円周角の定理（直径に対する円周角は 90°）を使っています。
- ⑤ の「等しい」は、表示した長さ（0.1cm の位）が同じかどうかで決めています。
- 練習問題は答えを先に決めてから図をつくります（頂角は偶数にして底角を整数に、など）。同じ種類の問題が続けて出ないようにしています。

## つまずき検知の一覧

| 型 | 見つけ方の例 | 練習するパート |
|---|---|---|
| 底角が2つあることをわすれた | 頂角 a° から底角を求めて 180 − a と答えた／底角 b° から頂角を求めて 180 − b と答えた | ① |
| 頂角と底角のとりちがえ | 頂角と底角を逆にして計算した | ① |
| 底角の場所のとりちがえ | 「PQ＝PR のとき等しい角は？」で ∠P をふくむ組をえらんだ | ① |
| 頂角の二等分線の性質の使いまちがい | ∠ADB を 90° 以外、BC を BD と同じ、∠BAD を頂角のまま答えた | ② |
| 合同条件のとりちがえ | 折ったときの合同条件・クイズの合同条件をまちがえた | ④ |
| 逆のつくり方のまちがい | 「でない」をつけた文や元の文を逆とした | ③ |
| 逆が正しいかの判断のまちがい | 反例がある逆を「正しい」とした（またはその反対） | ③ |
| 斜辺の見まちがい | 斜辺がふくまれないのに「斜辺と〜」をえらんだ | ④ |
| 条件が足りないのに合同とした | 斜辺だけ・角だけ等しいのに合同条件をえらんだ | ④ |
| 直角がないのに直角三角形の合同条件を使った | 直角のない「2辺と間でない角」で「斜辺と他の1辺」をえらんだ | ④ |
| 垂直二等分線と角の二等分線のとりちがえ | 「2点から等しい距離」「2辺から等しい距離」の線をとりちがえた | ⑤ |
| 計算まちがい | 上のどれにもあてはまらない数の答え | — |

「あなたのつまずき」から「🔁 この型を練習」（その型の問題だけが出る）と「👀 元の図で確かめる」に進めます。記録はこの端末の localStorage（キー `ikechan-math-二等辺三角形の性質`）に保存され、先生モードで合計を見たり消したりできます。
