# 相似比と面積比・体積比（拡大すると、面積は2乗、体積は3乗でふえる）

中学3年「図形と相似」のアプリです。相似比が m：n のとき、面積比（表面積の比）は m²：n²、体積比は m³：n³ になることを、タイルと積み木で数えて見つけます。ピザ・卵・巨人など身のまわりの例でくらべ、相似比 → 面積比 → 体積比の計算と、その逆（面積比・体積比から相似比）を練習します。

## 基本情報

- **ファイル**：本体 `相似比と面積比.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3・図形）から開けます。
- **画面のならび**：広い画面は 左＝図・右＝操作と表 の2列（図は上に止まったまま）。スマホはたて1列。
- **記録**：この端末の localStorage（保存キー `ikechan-math-相似比と面積比`）に、ワークシートといっしょに入れます。
- **URL の設定**：`?teacher=1` … 先生モード、`?part=1〜5` … そのパートから始める、`?ws=1`／`?ws=0` … ワークシートをひらいて／とじて始める、`?debug=1` … 動作確認用（`window.__dbg`）

## パート

| パート | すること |
|---|---|
| ① 面積比 | 正方形・直角三角形・円・自由な図形をえらび、2倍・3倍・4倍に拡大。「🔢 数える」で、拡大した図形に**もとの図形と同じタイル**（点線）がいくつ入るかを1つずつ数える → 4・9・16 こ。直角三角形は上向き・下向きのタイルでしきつめる。円は「半径×半径の正方形」が k² こ（面積 π×半径²）。自由な図形は ×1 の 3×3 の方眼のマスをタップしてつくり、どのマスも k×k マスになることを見る。表に 1：1〜1：4 の数をならべる。 |
| ② 体積比 | 1cm³ の積み木（見取り図）で、立方体・直方体（1×1×2）・L字の形を 2倍・3倍・4倍にする。「🧱 積む」で1こずつ積んで数える → 8・27・64 倍。表で表面積（k² 倍）と体積（k³ 倍）をくらべる。 |
| ③ くらべる | 🍕 ピザ（M 直径 24cm・1,200円。L の直径 30・36・48cm と値段をスライダーで変える → 面積比と「M と同じお得さの値段」、1cm² あたりの値段）、🥚 卵（長さ 5cm・50g の卵と、長さ 5〜7.5cm の卵 → 殻の面積と重さ）、🧍 巨人（身長 1〜5倍 → 足のうらの面積 k²、体重 k³、足のうら 1cm² あたりの重さ k 倍）。 |
| ④ 計算 | m・n（1〜6）と A の面積のスライダー・数の入力。相似比 → 面積比 → 体積比の流れと、B の面積の式（比の式も）を出す。図は m×m と n×n のタイル、m×m×m と n×n×n の積み木。 |
| ⑤ 逆 | 面積比（1：4、4：9、9：16 …）または体積比（1：8、8：27 …）をえらぶ → 「2乗して（3乗して）その数になる数」で相似比にもどし、体積比（表面積の比）を出す。 |

### 練習問題（「✏️ 練習問題」）

- ①：相似比 1：k の面積比、1辺を k 倍したときの面積の倍
- ②：立方体の体積の倍、表面積の比、体積比
- ③：ピザの面積の倍、卵の重さ、巨人の体重、足のうら 1cm² あたりの重さ
- ④：A の面積 → B の面積、B の面積 → A の面積（小さくなる）、A の体積 → B の体積（答えが整数になるように、先に答えを決めてから数をつくる）
- ⑤：面積比 → 相似比、表面積の比 → 体積比、体積比 → 相似比、体積比 → 表面積の比

回数は「🔎 あなたのつまずき」に出ます。「🔁 この型を練習」でその型の問題が出て、「👀 元の図で確かめる」でその型が見える図にもどります。先生モードでは、この端末の合計回数も見られます。

## ワークシート

- ①予想「身長が2倍の巨人（人と相似）の体重は、人の何倍？」（2倍・4倍・8倍・わからない）→ ②「📄 ワークシートの問題」で ③ の巨人を開き、身長の倍を 2・3・4 にして「＋ 記録する」（くらべたもの・長さ・面積・体積の倍）→ ③気づき → ④まとめ。
- ① ② の図や、③ のピザ・卵でも記録できます。

## 授業例（1〜2時間）

1. 小6の拡大図・縮図をふり返り、ワークシートの予想（巨人の体重）。2倍と答える生徒が多い。
2. ① で正方形・三角形・円・自由な図形をタイルで数え、面積は k² 倍になることを見つける。
3. ② で積み木を積み、体積は k³ 倍、表面積は k² 倍になることを確かめる。巨人の予想にもどって記録する。
4. ③ のピザ・卵で「どちらがお得？」「思ったより重い」を話し合う。巨人の足のうらの話で、大きな動物の足が太いわけにふれる。
5. ④ ⑤ の練習問題で、相似比 ⇔ 面積比 ⇔ 体積比の計算に慣れる。

## 正しさ・じっさいとのちがい

- 方眼の1目もりを 1cm としています（画面の大きさは実物とはちがいます）。
- 計算は整数と分数で行い、答えは約分した分数か整数で出します。小数は見せるときだけで、小数第3位（ピザの値段・1cm² あたりは小数第2位、円は整数）までの四捨五入です。
- ③ のピザの値段は架空です。卵・人のからだは本当は相似ではありませんが、相似とみなして計算しています（じっさいの大きい動物は、体重をささえるために足が太くなっています）。人の体重 60kg・足のうら 300cm²、卵の重さは目安の数です。
