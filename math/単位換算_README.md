# 単位換算トレーニング

長さ・かさ・重さ・時間・面積・体積の単位の換算（へんしん）を練習する、10問チャレンジの教材です。2〜5年で学んだ単位のふりかえりと、6年「算数のしあげ」の「量の単位のしくみ」（東京書籍 新しい算数 6年 196〜219ページ）で使います。次のことを練習します。

- 大きい単位から小さい単位へは数が大きくなり（かけ算）、小さい単位から大きい単位へは数が小さくなる（わり算）
- キロ（k）・ヘクト・デカ・デシ（d）・センチ（c）・ミリ（m）の「単位のはしご」で、となりへ1つ動くごとに ×10
- 「1km 200m ＝ ？m」「3.5km ＝ ？m」「4500m ＝ ？km」のような、まじった単位や小数の換算

## 基本情報

- **ファイル**：`単位換算.html`。共通ファイル `worksheet.js`・`worksheet.css` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。本文20px・ボタン48px以上。キーボードの数字・Enter・Backspace・スペースでも操作できます。
- **漢字**：ふりがなをつけています（題名・しゅもく・問題の「時間・分・秒」・ヒント など）。「せってい」で消せます。
- **ワークシート**：よそう → やってみる → わかったこと → まとめ（小学生向け）。はじめは閉じています。「きろくする」で、さいごに答えた問題（しゅもく・問題・答え・ヒント）を記録します。
- **保存**：ワークシートと「せってい」を、このブラウザの localStorage（キー：`ikechan-math-単位換算`）に保存します。10問の成績は保存しません。
- **せってい**：ヒント（まちがえたら出す／はじめから出す）・ふりがな・こうかおん・うごき（「へらす」で、まちがえたときに画面がゆれない）。

## ✏️ トレーニング

| えらぶもの | 内容 |
|---|---|
| しゅもく | 長さ（mm・cm・m・km）、かさ（mL・dL・L）、重さ（g・kg・t）、時間（秒・分・時間）、面積（cm²・m²・a・ha・km²）、体積（cm³・dL・L・m³。1mL＝1cm³）、ミックス |
| やさしい | となりどうしの単位で、答えは整数（例：3 km ＝ ？ m） |
| ふつう | はなれた単位も出る（例：2 m ＝ ？ mm）。数は30まで |
| むずかしい | まじった単位（1 km 200 m ＝ ？ m）、小数の問題（3.5 km ＝ ？ m）、答えが小数（4500 m ＝ ？ km） |

- しゅもく・レベルをえらぶか、「🔄 さいしょから」で10問が始まります。
- 数字キーで答えて「OK」。「⌫」で1つけせます。
- まちがえると、ヒント（1 km ＝ 1000 m など）と単位のはしご（長さ・かさ・重さのとき）が出ます。3回まちがえると答えが出て次の問題へ進みます。
- 最後に、タイム・ミス・せいかくりつ・星と、まちがえた問題の「ふりかえり」が出ます。
- 「🎵 おぼえうた」で「キロキロと、ヘクトデカけたメートルが デシに追われてセンチミリミリ」と単位のはしごを出せます（長さ・かさ・重さを切りかえ）。

## つまずき検知

| 型の名前 | 見つけ方 |
|---|---|
| かける・わるの 逆 | 大きい単位→小さい単位でわった、小さい単位→大きい単位でかけた（3km を 0.003m、2000m を 2000000km） |
| 0の 数の まちがい | 答えが10倍・10分の1にずれた（1km を 100m、30mm を 0.3cm）。時間（60ずつ）はのぞく |
| 面積・体積を 長さと 同じ 倍に する | 面積・体積を長さの倍で計算した（5m² を 500cm²、25L を 250cm³、17m³ を 1700cm³）。体積は cm³ と L・m³ の問題だけ |

- まちがえた答えから型を見つけると、問題の下に「あなたの つまずき」とヒントを出し、10問のあとに、その型の「にた もんだい」を1問足します（型ごとに1問まで。最大13問）。
- 最後のふりかえりに型ごとの回数と「🧩 単位の しくみ で たしかめる」ボタンを出します（面積・体積の型があれば「長さ・面積・体積」、それ以外は「k・c・m の ひみつ」が開きます）。
- 1つの答えが2つの型にあてはまるとき（面積で10倍ずれたとき など）は、「面積・体積を 長さと 同じ 倍に する」→「かける・わるの 逆」→「0の 数の まちがい」の順に優先します。

## 🧩 単位の しくみ（6年「算数のしあげ」）

| 画面 | 内容 |
|---|---|
| k・c・m の ひみつ | 長さ（m）・かさ（L）・重さ（g）の表。上の k・d・c・m をタップすると意味（k は1000倍、d は10分の1、c は100分の1、m は1000分の1）と、その列の単位（1km＝1000m、1kL＝1000L、1kg＝1000g）が出る。単位のますをタップすると、1つの関係（1m＝100cm など）が出る。小学校で使わない組み合わせは「―」 |
| 長さ・面積・体積 | 1辺1cmと1辺10cmで、長さ ×10 → 面積 ×100（方眼100こ）→ 体積 ×1000（立方体1000こ、1000cm³＝1L）を1ステップずつ。まとめの表に 1m²＝10000cm²、1m³＝1000000cm³ も。「◀ ひとつ もどす」「▶ つぎへ」「🔄 はじめから」。先生モードでは「⏩ さいごまで」 |
| 体積・かさ・重さ | 1cm³＝1mL（水1g）、100cm³＝1dL（水100g）、1000cm³＝1L（水1kg）、1m³＝1000L（水1t）の表。行をタップすると図（立方体・うすい板）が変わる |

- ワークシートの「きろくする」で、いま見ている表や図のようす（例：k は 1000倍 → 1km＝1000m）を記録します。

## 先生モード（アドレスの最後に `?teacher=1`）

- 題名の横に「先生モード」のしるし。トレーニングの「💡 こたえ」で、いまの問題の答えとヒントを出せます。「単位の しくみ」の「長さ・面積・体積」に「⏩ さいごまで」が出ます。ワークシートに先生用のヒントと解答例が出ます。

## 授業での使い方の例

1. **ふりかえり（5〜10分）**：単元の最初や朝学習で、しゅもくを1つえらんで「やさしい」から取り組みます。
2. **単位のしくみ（6年「算数のしあげ」）**：「🧩 単位の しくみ」の「k・c・m の ひみつ」を電子黒板に出し、k（キロ）は1000倍・c（センチ）は100分の1・m（ミリ）は1000分の1 が、長さ・かさ・重さのどれでも同じ意味であることを確かめます。「長さ・面積・体積」で、1辺が10倍になると面積は100倍・体積は1000倍になることを見て、「体積・かさ・重さ」で 1000cm³＝1L＝（水）1kg をまとめます。そのあと「✏️ トレーニング」の「ミックス」で練習します。
3. **ふりかえり**：最後の「ふりかえり」に出た問題をワークシートに記録し、まちがえた理由を書かせます。

## 正しさと、じっさいとのちがい

- 答えが小数になるのは「むずかしい」だけで、小数第1位までです。
- 「体積・かさ・重さ」の重さは、水のときの重さです（温度などで少しかわります）。
- 時間は60ずつ（1時間＝60分、1分＝60秒）なので、単位のはしごは出ません。面積は100ずつ・10000ずつなどなので、はしごは出ません。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| せいかい／まちがい | 緑／赤むらさき | ⭕・❌ の記号と文字 |
| はしごの はじめと おわりの単位 | 青緑 | 白い文字。間の部屋は黄色、使わない矢印はうすい灰色 |
