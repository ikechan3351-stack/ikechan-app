# コンパスで 円を かこう ― コンパスを使おう！

小学3年生の算数「円と球」「三角形」で使う、円とコンパスのシミュレーション教材です。次のことを体感します。

- 円は「**1つの点（中心）から同じ長さにある点の集まり**」であること
- **中心・半径・直径**の意味と、**直径 ＝ 半径 × 2**
- コンパスの使い方（**半径に開く → 中心に針をさす → 回す**）と、**長さを写し取る**使い方
- コンパスを使った**二等辺三角形・正三角形**のかき方
- 球を切った切り口は円になり、**真ん中で切るといちばん大きい**こと

## 基本情報

- **ファイル**：`円とコンパス.html`。この1ファイルだけで動きます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。
  - 方眼・コンパス・球の絵は、すべてSVGで描いています。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）・スマートフォン。
  - 画面が広いときは作図エリアと操作パネルが左右に、せまいときは上下にならびます。
- **長さの単位**：方眼の1マスを 1cm として扱います。画面の 1cm は実物の 1cm ではありません（画面にも注意書きがあります）。
  - 3年生は小数をまだ習っていないので、長さは「2cm5mm」のように cm と mm で表示します。
- **漢字**：3年生までに習う漢字を使います。ふりがなは「せってい」で消せます。
  - 4年生以上で習う漢字（半径・直径の「径」、二等辺三角形の「辺」）は、ふりがなを消しても残します。

## しくみ（コードのつくり）

- **長さの持ち方**：作図エリアの中では、長さや位置をすべて **cm** で持ちます。SVG にかくときだけ 40 倍します（1cm ＝ 40）。
- **描いた図形の一覧**：円・円の一部（弧）・点・残した半径／直径・三角形の辺を、配列 `state.shapes` にためていきます。
  - 「↩ ひとつ もどす」は最後の1つを取りのぞき、「🗑 ぜんぶ けす」は一覧を空にします（2回押しで消えます）。
  - 「じゆうに かく」の図は、ほかのモードに行ってもどってきても残ります。
- **コンパスの絵**：針（N）と鉛筆（P）を結ぶ線の横に、ちょうつがい（H）を置きます。H は2本の足の長さが同じ（6.5cm）になる位置です。
  - つまみが作図エリアからはみ出すときは、コンパスを反対側に倒して表示します。
- **吸いつき**：「目もりに すいつく」が「あり」なら、針の位置と開きが 5mm ずつ、「なし」なら 1mm ずつ動きます。
  - 線のはし・点ア／イ／ウ・★ の近く（4.5mm 以内）では、どちらの設定でもそこに吸いつきます。
- **円が点を通るか**：中心からの距離が半径と同じで、弧の範囲にその向きが入っているかで判定します（三角形の点ウの判定に使います）。

## コンパスの操作（どのモードも共通）

| 操作 | 動き |
|---|---|
| **はり**（とがった足）をドラッグ | 円の中心を決めます。コンパス全体が動きます（開きは変わりません） |
| **えんぴつ**の足をドラッグ | 開き（＝半径）を決めます。はりは動きません。開きの長さが右のパネルに大きく出ます |
| **🔄 まわす** | コンパスが1回転し、線がのびていくように円がかけます |
| **つまみ**（上のオレンジの丸）をドラッグ | 自分でまわせます。とちゅうで止めると円の一部（弧）が残ります。1周すると円になります |
| **📏 ものさし** | はりの位置を 0 にしたものさしを、コンパスの足にそって表示します |

## 色と形のきまり

色だけでなく、線の太さと形、文字でも区別できるようにしています（色覚の多様性への配慮）。

| 意味 | 色 | 形 |
|---|---|---|
| 半径 | 赤（オレンジより） | ふつうの太さの実線。ラベル「半径 3cm」 |
| 直径 | 青 | 太い点線。ラベル「直径 6cm」 |
| 問題でまちがえた円 | 灰色 | 細い点線（正しい円と大きさをくらべられます） |
| 線 あ・い | むらさき・青緑 | 名前の札「あ」「い」 |
| 三角形の同じ長さの辺 | オレンジ | 辺のまん中に同じ印（｜） |

## モード

### 1. じゆうに かく

- コンパスで自由に円をかきます。中心をずらした円を重ねると、模様づくりができます。ペンの色は4色です。
- **━ 半径 ／ ┅ 直径**：選んでいる円（最後にかいた円。円の線をタップすると選べます）に、半径・直径を表示します。
  - 線の先の ○ をドラッグすると、向きが変わります。直径は、中心を通ったまま回ります。長さは変わりません。
  - 「📌 線を のこす」で何本も残せるので、どの向きの半径・直径も同じ長さであることを比べられます。
  - 半径と直径を両方出すと「直径 6cm ＝ 半径 3cm × 2」と表示します。
- **📍 点を うつ**（円の定義の導入）
  - コンパスの針の位置を中心、開きを長さとして、ものさしが表示されます。
  - 画面をさわってものさしを回し、はなすと、中心からその長さのところに点が打たれます。「✨ まとめて 12こ うつ」もあります。
  - 点が増えると、だんだん円の形になります（8こ・24こで声かけが変わります）。
  - そのあと「🧭 コンパス」にもどって「まわす」と、円がすべての点を通ることを確かめられます。

### 2. この 円を かこう

- 「半径 3cm の円」「直径 8cm の円」を、★を中心にかきます。
  - 半径は 2〜6cm、直径は 4〜12cm（偶数）で出題します。
  - 出題は「半径で／直径で／まぜる」から選べます。問題の数は設定で 3・5・8 問から選べます。
- 正しくかけると、その円に半径と直径を表示し、「直径 8cm ＝ 半径 4cm × 2」を見せます。
- 「💡 ヒント」は2段階です。直径の問題では「直径 8cm ＝ 半径 □ × 2」→ □ の答え、の順に出ます。
- 最後に「○問中 ○問 1回で かけた」を表示します（記録は保存しません）。

### 3. 長さを うつす

- ななめの2本の線 **あ・い** のどちらが長いかを、コンパスで写し取ってくらべます。
  - 線は、方眼のマス目を数えてもくらべにくいように、ななめにしてあります。
  - コンパスの開きの長さは「？」で隠してあります。ものさしは使いません。
- 手順
  1. はりを あ のはしにさす
  2. えんぴつを あ のもう一方のはしに合わせる（長さを写し取る）
  3. 開きを変えずに、はりを い のはしにさす
  4. い の線の上に円の一部をかいて、い のはしが内側か外側かをくらべる
- それぞれの手順が終わると声かけが出ます。「💡 やりかた」で手順を表示できます。
- 答え（あ／い／同じ）を選ぶと正誤が出て、正解すると線の長さが表示されます。

### 4. 三角形を かこう

- 「二等辺三角形／正三角形」と、辺の長さ（辺アイ 3〜8cm、二等辺三角形の残りの辺 3〜8cm）を選びます。
  - 三角形ができない長さや、正三角形になってしまう長さは、選べないようにしています。
- 右の「かき方の じゅんばん」に、いまの手順が ▶ で、終わった手順が ✔ で表示されます。
  1. 「📏 辺アイを ひく」ボタンで、もとの辺をひく
  2. コンパスを指定の長さに開く（正三角形は、はりをア・えんぴつをイに合わせて辺アイの長さを写してもよい）
  3. はりをアにさして、円の一部をかく
  4. はりをイにさして、円の一部をかく
  5. 2つが交わった点がウになる（自動で表示）
  6. 「📏 アウ・イウを むすぶ」ボタンで、直線で結ぶ
- できあがると三角形に色がつき、辺の長さと、同じ長さの辺の印が表示されます。

### 5. 球

- **✂️ 切って みよう**
  - 球を「横に／たてに／ななめに」切り、上のかたまりを持ち上げて切り口を見せます。
  - 切る位置は、スライダー・ボタン・球の絵のドラッグで変えられます。真ん中に近づくと真ん中に吸いつきます。
  - 右に「切り口を まっすぐ 見ると」の円を出し、いちばん大きい切り口（点線）とくらべます。
  - 真ん中で切ると「いちばん 大きい！」と出て、球の中心と直径を表示します。
- **📦 直径を はかろう**
  - 球を2つの箱ではさみ、箱と箱の間の長さが球の直径（10cm）になることを、ものさしで見せます。半径（5cm）も表示します。

### 6. 先生モード

- 作図の手順を、上の大きな文字とアニメで1ステップずつ見せます。
- 見せるもの
  - **円って なに？**：中心から 4cm の点を1こ → 12こ → たくさん打ち、最後にコンパスでかいた円が全部の点を通ることを見せます。
  - **円の かき方**：ものさしで 4cm に開く → 針を中心にさす → 1回りさせる → 半径と直径を表示
  - **長さの うつし方**：あ の長さを写し取り、い の上に円の一部をかいてくらべる
  - **二等辺三角形**（辺アイ 6cm・残りの辺 5cm）、**正三角形**（5cm）：三角形をかこうと同じ7つの手順
- 「つぎ ▶」「◀ まえ」「↺ もう一度」、または手順の一覧を押して、好きな手順から見せられます。キーボードの ← → でも進めます。
- アニメのあとでも、コンパスを手で動かして続きを見せられます。

## つまずきへの対応

- **直径で出題されたのに、そのまま開く誤り**（例：直径 8cm で 8cm に開く）
  - えんぴつをはなした時点で「まって！ コンパスで ひらくのは 半径だよ。直径は 半径の 2つ分」と知らせます。
  - そのままかいた場合は「直径 8cm の 半分は 何cm かな？」と声をかけ、ヒントを1段階進めます。かいた円は灰色の点線で残るので、正しい円と大きさをくらべられます。
- **半径で出題されたのに半分に開く誤り**：「半径は 中心から まわりまでの 長さ」と声をかけます。
- **★ に針をささずにかいた場合**：「★が 円の 中心に なるよ」と声をかけます。
- **三角形で、開き・針の位置・円の一部の長さがちがう場合**：それぞれに合わせて声をかけます（「コンパスの ひらきが 4cmだよ。5cmに ひらいてから かこう」など）。

## 動作確認方法

1. `円とコンパス.html` をブラウザ（Chrome・Edge・Safari）で開きます。
2. **じゆうに かく**
   1. はりをドラッグしてコンパス全体が動くこと、えんぴつをドラッグして「いまの ひらき」が変わることを確認します。
   2. 「🔄 まわす」で、線がのびるように円がかけることを確認します。
   3. つまみをドラッグして半周で止め、円の一部が残ること、1周すると円になることを確認します。
   4. 「━ 半径」「┅ 直径」を押し、線の先の ○ を動かしても長さが変わらないこと、「📌 線を のこす」で線が残ることを確認します。
   5. 「📍 点を うつ」→「まとめて 12こ うつ」を2回押して 24こになり、声かけが変わることを確認します。
   6. 「↩ ひとつ もどす」で最後の図形が消えること、「🗑 ぜんぶ けす」を2回押すと全部消えることを確認します。
3. **この 円を かこう**：「直径で」を選び、はりを ★ にさして、直径の数のままに開くと「まって！」と出ること、そのまま回すと灰色の点線の円が残り、ヒントが出ることを確認します。半径に開き直して回し、「できた！」と出ることを確認します。
4. **長さを うつす**：はりとえんぴつを あ の両はしに合わせると「うつしとったよ！」と出ること、はりを い のはしに移して円の一部をかき、答えを選ぶと長さが表示されることを確認します。
5. **三角形を かこう**：手順どおりに進め、▶ と ✔ が変わっていくこと、できあがると色と印がつくことを確認します。開きをまちがえて円の一部をかくと、声かけが出ることも確認します。
6. **球**：「真ん中で 切る」で「いちばん 大きい！」と出ること、「たてに／ななめに」でも切り口が円になることを確認します。「直径を はかろう」で箱がはさみに来ることを確認します。
7. **先生モード**：5つの見せるものそれぞれで「つぎ ▶」を押して最後まで進めること、手順の一覧を押すとそこから見せられることを確認します。
8. 「せってい」で「うごき：へらす」にすると、すぐに円がかけることを確認します。

## 授業での使い方の例

### 1. 円の定義（中心から同じ長さの点の集まり）

- **ねらい**
  - 円は、1つの点（中心）から同じ長さにある点の集まりであることを知る。
  - 中心・半径・直径の意味を知る。
- **進め方**
  1. 「輪投げの的のまわりに、みんなが同じ近さで立つには、どう並べばよい？」と問いかけます（教科書の玉入れ・輪投げの場面）。
  2. 先生モード「円って なに？」を電子黒板で見せます。① で中心から 4cm の点を1こ打ち、② で12こに増やしたところで、「もっと打つと、どんな形になる？」と予想させます。
  3. ③ でたくさん打ち、④ でコンパスの円が全部の点を通ることを見せます。「円は 中心から 同じ長さの 点の 集まり」とまとめます。
  4. 子どもはタブレットの「じゆうに かく」→「📍 点を うつ」で、自分で点を打って確かめます。
  5. 「━ 半径」「┅ 直径」で用語を確かめます。線の先の ○ を動かし、「どの向きでも同じ長さ？」と問い、「📌 線を のこす」で何本も残して比べさせます。両方出したときの「直径 ＝ 半径 × 2」に気づかせます。

### 2. コンパスの練習（半径に開く → 中心に針をさす → 回す）

- **ねらい**
  - コンパスを使って、決められた大きさの円をかく。
  - 直径で言われたときは、半径を考えて開く。
- **進め方**
  1. 先生モード「円の かき方」で手順を確かめます。① のものさしの場面で、実物のコンパスの開き方（針を 0 に合わせる）を見せます。
  2. 「じゆうに かく」で、はり・えんぴつ・つまみを動かして、操作に慣れさせます。中心をずらした円を重ねる模様づくりをすると、楽しく練習できます。
  3. 「この 円を かこう」の「半径で」→「まぜる」の順に取り組みます。直径の問題で直径の数のままに開く子には、アプリが「開くのは 半径だよ」と声をかけます。灰色の点線で残った円を見せて、「大きすぎたのはなぜ？」と話し合わせるのも効果的です。
  4. 最後に実物のコンパスとノートで、同じ問題をかかせます。

### 3. 長さを写し取る

- **ねらい**
  - コンパスを使うと、長さを写し取ってくらべられることを知る。
- **進め方**
  1. 「長さを うつす」の画面を見せ、「あ と い、どちらが長い？ ものさしは使えません」と問いかけます。マス目を数えようとしても、ななめなのでうまくいかないことに気づかせます。
  2. 先生モード「長さの うつし方」で、写し取る手順を見せます。
  3. 子どもは「長さを うつす」で問題に取り組みます。開きの長さは「？」で隠れているので、コンパスで比べるしかありません。
  4. 実物では、ノートにかいた折れ線の長さをコンパスで1本の直線に写し取る活動に広げられます。

### 4. 三角形の作図（二等辺三角形・正三角形）

- **ねらい**
  - コンパスを使って、二等辺三角形・正三角形をかく。
  - 円の一部の交わった点が、2つの点からそれぞれ同じ長さにある点であることに気づく。
- **進め方**
  1. 「辺の長さが 6cm・5cm・5cm の三角形をかこう。ものさしだけでかける？」と問い、ものさしだけでは3つ目の点が決めにくいことに気づかせます。
  2. 先生モード「二等辺三角形」で、手順を1ステップずつ見せます。⑤ で「この点ウは、アからもイからも 5cm の点」であることを、円の定義（中心から同じ長さ）とつなげて話し合います。
  3. 子どもは「三角形を かこう」で、同じ三角形をかきます。右の「かき方の じゅんばん」を見ながら進められるので、自分のペースで取り組めます。
  4. 正三角形は「辺アイと同じ長さに開く」ことを確かめてからかかせます。辺の長さを変えて、いろいろな三角形をかかせます。
  5. 最後に実物のコンパスとノートでかかせ、できた三角形の辺の長さをものさしで確かめます。

### 5. 球（まとめ）

- 「球」の「切って みよう」で、どこで切っても切り口は円になること、真ん中で切るといちばん大きいことを確かめます。真ん中で切ったときの円の中心・半径・直径を、球の中心・半径・直径とよぶことを押さえます。
- 「直径を はかろう」で、箱ではさんで直径をはかる方法を見せたあと、実物のボールで同じようにはからせます。
