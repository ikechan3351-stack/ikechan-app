# 平行線と線分の比（平行線で切ると比が等しい。中点を結ぶと半分）

中学3年「図形と相似」のアプリです。「相似条件ビルダー」（3-14）の続きで、三角形の1辺に平行な線分が他の2辺を同じ比に分けること（AD：AB＝AE：AC＝DE：BC、AD：DB＝AE：EC）、平行線にはさまれた線分の比、中点連結定理を、図を動かして確かめます。いちばんのねらいは、**AD：DB（部分：部分）と AD：AB（部分：全体）の区別**です。

## 基本情報

- **ファイル**：本体 `平行線と線分の比.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3・図形）から開けます。
- **画面のならび**：広い画面は 左＝図・右＝操作と表 の2列（図は上に止まったまま）。スマホはたて1列。
- **記録**：この端末の localStorage（保存キー `ikechan-math-平行線と線分の比`）に、ワークシートといっしょに入れます。
- **URL の設定**：`?teacher=1` … 先生モード、`?part=1〜5` … そのパートから始める、`?ws=1`／`?ws=0` … ワークシートをひらいて／とじて始める、`?debug=1` … 動作確認用（`window.__dbg`）

## パート

| パート | すること |
|---|---|
| ① 平行線 | タテ型・砂時計型。● A・B・C で形を変え、● D を AB の上でドラッグ（またはスライダー）すると、E は DE∥BC になる位置に自動で動く。表で AD：AB＝AE：AC＝DE：BC（部分：全体）と、AD：DB＝AE：EC（部分：部分）をならべ、「DE：BC は AD：DB とはちがう」と注意する。図でも AD・AE（オレンジ）と DB・EC（緑の点線）を色分け。「🔁 逆」では E も別に動かし、AD：AB＝AE：AC のときだけ DE∥BC になることを見る。「✂ D を AB の中点に」で ③ につなぐ。 |
| ② 3本の平行線 | 平行線 ℓ・m・n（右はしの ● で上下）と2本の直線（両はしの ●）を動かす。長さは変わっても AB：BC＝DE：EF は変わらず、平行線の間かくの比と同じになる。 |
| ③ 中点連結 | 三角形：M、N は AB、AC の中点。MN∥BC、MN＝½BC（MN÷BC はいつも 0.50）。四角形（発展）：各辺の中点 P・Q・R・S を結ぶといつも平行四辺形。「／ 対角線をひく」で PQ＝SR＝½AC、QR＝PS＝½BD のわけを見る。対角線が等しい → ひし形、垂直 → 長方形 も表示。 |
| ④ 比の利用 | 練習問題が中心（①②③の型と、角の二等分線）。図は（発展）角の二等分線と比：BD：DC＝AB：AC。「💡 わけを見る」で、C を通り AD に平行な補助線と AE＝AC の二等辺三角形を見せる（このあいだは図を縮めてかき、● は動かせない）。 |
| ⑤ 証明 | 「三角形と比の定理」（2組の角 → 相似 → 比）と「中点連結定理」（2組の辺の比とその間の角 → 相似 → 同位角 → 平行・半分）を「▶ つぎの行」で1行ずつ。今の行で使う角・辺が赤く光る。相似条件ビルダーの「④ 証明パズル」「⑤ 平行線と相似」へのリンク。 |

### 練習問題（「✏️ 練習問題」）

答えが整数になるように、答えを先に決めてから数をつくります。図は書いてある長さに合わせてかきます。

- ①：タテ型の EC（AD：DB＝AE：EC）、DE（DE：BC＝AD：AB）、AD（比例式）、砂時計型の DE
- ②：3本の平行線の EF
- ③：中点連結の MN、BC、四角形 PQRS のまわりの長さ
- ④：①〜③ の型と、（発展）角の二等分線の BD
- ⑤：証明で使う相似条件・角の名前（同位角・錯角・対頂角・共通）

## つまずき検知の一覧

| 型 | 検出のしかた | もどる先 |
|---|---|---|
| 全体と部分の取り違え（AD：DB と AD：AB） | EC・AD・EF を求めるのに、部分：全体 の比を使った答えをえらんだ | ① の表（2：3 と 2：5） |
| DE：BC に AD：DB を使った | DE を求めるのに AD：DB（砂時計型では AD：(AD＋AB)）を使った答えをえらんだ | ① の表 |
| 比の順序（対応）のまちがい | 比例式の左右を入れかえた答え（x：○ と ○：x）をえらんだ | ① の表 |
| 中点連結定理の「半分」のまちがい | MN を BC と同じ・2倍、BC を MN の半分、まわりの長さを2倍・半分にした | ③ の三角形 |
| 角の二等分線の比のまちがい（発展） | D を BC の中点とした、AB：AC を逆にした | ④ の補助線 |
| 証明の根拠のまちがい | 相似条件や角の名前（同位角・錯角など）をまちがえた | ⑤ の三角形と比の定理 |
| 計算まちがい | 上のどれにも当てはまらないまちがい | ― |

回数は「🔎 あなたのつまずき」に出ます。「🔁 この型を練習」でその型の問題が出て、「👀 元の図で確かめる」でその型が見える図にもどります。先生モードでは、この端末の合計回数も見られます。

## ワークシート

- ①予想「D が AB の中点のとき（DE∥BC）、DE の長さは BC の何倍？」（半分・同じ・2倍・わからない）→ ②「📄 ワークシートの問題」で ① を開き、D を動かして「＋ 記録する」（D の場所・AD÷AB・AD÷DB・DE÷BC）。中点（0.5）でも記録 → ③気づき → ④まとめ。
- ③ の三角形でも記録できます。

## 授業例（1〜2時間）

1. 相似条件ビルダーの「⑤ 平行線と相似」をふり返り、ワークシートの予想。
2. ① で D を動かして記録し、AD÷AB＝DE÷BC、AD÷DB はちがうことを確かめる。中点のときを記録して予想を確かめる。「🔁 逆」も試す。
3. ② で直線を動かしても比が変わらないことを見る（① の図と同じしくみ）。
4. ③ で中点連結定理。四角形の中点を結ぶと平行四辺形（中2 平行四辺形の条件とつなぐ）。
5. ④ の練習問題で比例式。⑤ で証明を1行ずつ確かめ、相似条件ビルダーの証明パズルで自分でならべる。

## 正しさ・じっさいとのちがい

- 方眼の1目もりを 1cm としています（画面の大きさは実物とはちがいます）。長さは 0.1cm、比の値は小数第2位までの四捨五入です。
- 「すいつく」がオンのとき、D・E は AB・AC の 1/20 きざみにすいつき、比は整数の比で出します。オフのときは四捨五入した値なので「約」をつけています。
- 練習問題の図は、書いてある長さに合わせてかいていますが、画面に合わせて縮めています。
- ④ の「角の二等分線と比」と ③ の「四角形の中点を結ぶ」は発展の内容です。
