# 放物線をつくろう（y＝ax²）

中学3年「関数 y＝ax²」で、**表・式・グラフ（放物線）**の特徴を見つけるアプリです。
表から点を打ってなめらかにつなぎ、a を変えてグラフの開き方を見て、比例 y＝ax とくらべ、変域と式の決め方まで練習します。
いろいろな関数を描く「関数グラフツール」（`関数グラフ.html`）とは役割を分けて、y＝ax² の学習に特化しています。

## 基本情報

- **ファイル**：本体 `放物線をつくろう.html`、共通部品 `graph-engine.js`（座標平面・グラフ・ドラッグできる点）、`math-render.js`（式の表示・分数）、`worksheet.js`・`worksheet.css`（ワークシート）。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3・割合・関数）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）・スマホ。広い画面では「グラフ｜表・操作」の2列、せまい画面では縦に並びます。
- **記録**：この端末の localStorage（保存キー `ikechan-math-放物線をつくろう`）に、ワークシートといっしょに入れます。
- **URL の設定**：`?teacher=1` … 先生モード、`?part=1〜5` … そのパートから始める、`?ws=1`／`?ws=0` … ワークシートをひらいて／とじて始める

## パート

| パート | すること |
|---|---|
| ① 表からグラフ | 式（y＝x²・2x²・1/2x²・−x²・−2x²）をえらび、x＝−3〜3 の表の y を入れて「✔ たしかめる」。グラフの、表の点のところをタップして7この点を打つ（「📍 点をぜんぶ打つ」も）。「📏 直線でつないでみる」「〰 なめらかにつなぐ」をくらべ、「🔍 とちゅうの点」で x＝0.5 ごとの点が<b>曲線の上</b>にあることをたしかめる。 |
| ② a をかえる | a のスライダー（−4〜4、0.1 ずつ）・数の入力（1/3 のような分数も）・チップで a を変える。「−a のグラフ」で x 軸について対称なこと、「y＝x²」の点線とくらべて開き方を見る。放物線の上の点P を動かすと、y 軸の反対がわに同じ高さの点P′ が出る。見つけた特徴5つにチェック。 |
| ③ 比例とくらべる | y＝ax と y＝ax² の表とグラフを同時に。x を 2倍・3倍・4倍にすると、y は何倍？（比例なら n 倍、y＝ax² なら n² 倍） |
| ④ 変域 | x の変域（−2≦x≦3 など）から y の変域を求める。🎲 で問題、または a・x の変域を自分で入れる。グラフの太い部分と y 軸の範囲で答えをたしかめる。 |
| ⑤ 式をきめる | 通る点から a を求める。「✋ 点を動かして式をつくる」では、点A（整数にすいつく）をドラッグすると、A を通る放物線と a が変わる。 |

### 見つける特徴（②）

1. 頂点は原点 (0, 0)
2. y 軸について対称
3. a＞0 なら上に開く、a＜0 なら下に開く
4. a の絶対値が大きいほど、グラフの開き方は小さい（細い）
5. y＝ax² と y＝−ax² は、x 軸について対称

## 授業での使い方（例）

- **導入（ワークシート）**：「y＝x² で x が 3倍になると y は？」と予想させる（3倍が多い）。③ の「📄 ワークシートの問題（3倍）」で比例 y＝x と表をならべて、9倍になることをたしかめる。2倍→4倍、4倍→16倍も見つけさせる。
- **グラフをかく**：① で表 → 点 → つなぐ。直線でつなぐ生徒が多いときは「📏 直線でつないでみる」と「🔍 とちゅうの点」で、曲線になるわけを見せる。
- **特徴をまとめる**：② で a を変えて、特徴5つを見つけさせる。
- **変域**：④ で、x の変域に 0 がふくまれる問題（最小値 0）とふくまれない問題をくらべる。
- **式をきめる**：⑤ で代入して a を求める。「✋ 点を動かして」で、点の位置と a の関係を見る。

## 先生モード（`?teacher=1`）

- 答えの表示（表の y・特徴・何倍・y の変域・a）。
- 「★ 答え（先生）」：そのパートの答えを入れて、たしかめまで進めます。
- この端末のつまずきの合計。ワークシートに、先生用のヒントと解答例が出ます。

## 正しさについて（じっさいとのちがい）

- a や y の値は分数で厳密に計算し、グラフに描くときだけ小数にしています。
- ① の「とちゅうの点」は 0.5 ごとです。② のスライダーは 0.1 ずつです（数の入力では 1/3 のような分数も入れられます）。
- グラフの方眼は、x と y で目もりの大きさがちがうことがあります（② は −5〜5、−10〜10 で固定して、くらべやすくしています）。
- ② で a＝0 にすると、y＝0（x 軸）になり、放物線にならないことを表示します。

## つまずき検知の一覧

| 型 | 見つけるところ | 練習へ |
|---|---|---|
| 変域で、両はしの値だけで y の範囲を出した | ④ x の変域に 0 があるのに、両はしの y だけで答えた（最小値・最大値が 0 にならない） | ④ |
| 最小値と最大値を逆にした | ④ □≦y≦□ の左右が逆 | ④ |
| 負の数の2乗を負にした | ① x が負のとき y を −a x² とした | ① |
| ax² を (ax)² と計算した | ① 2x² で x＝3 を 36 とした | ① |
| x² を 2x と計算した | ① x＝3 を 6（a 倍）とした | ① |
| x が n 倍のとき、y も n 倍とした | ③ 「何倍？」で n 倍をえらんだ | ③ |
| a を求めるとき、y を x でわった | ⑤ a＝y÷x | ⑤ |
| a を求めるとき、わり算を逆にした | ⑤ a＝x²÷y | ⑤ |
| 計算のまちがい | そのほか | — |
