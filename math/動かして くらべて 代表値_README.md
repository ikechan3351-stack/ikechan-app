# 動かして くらべて 代表値（代表値と外れ値）

中学1年「データの活用」で、**平均値・中央値・最頻値・範囲**の意味と、**外れ値**が代表値にあたえる影響を学ぶアプリです。ドットプロットの点を動かして代表値の変わり方を見て、場面に合わせて**どの代表値を使うべきか**を説明できるようにします。

| 区切って数えて ヒストグラム（`区切って数えて ヒストグラム.html`） | 度数分布表・ヒストグラム・相対度数 |
| 箱ひげ図とヒストグラム（`箱ひげ図とヒストグラム.html`） | 四分位数・箱ひげ図（中2） |
| **動かして くらべて 代表値（これ）** | 点を自由に動かして代表値の変わり方を見る。外れ値の影響を数でくらべる。場面に合わせた代表値の使い分け・だまされる数字とグラフ。度数分布表からの最頻値。平均値が同じでも散らばりがちがうこと |

## 基本情報

- **ファイル**：本体 `動かして くらべて 代表値.html`、共通部品 `worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中1）から開けます。
- **画面**：上にドットプロット（横いっぱい）、その下に 左＝代表値・つまずき、右＝並べたデータ・度数分布表。練習問題とクイズは、いちばん上に出ます。スマホは たて1列（ドットプロットの文字と点を大きくしてかきます）。
- **色のきまり**：平均値＝オレンジの ▲、中央値＝紫の ◆ と点線、最頻値＝緑の ★、範囲＝青の ↔、外れ値＝赤紫のふちと「！」、正解＝緑の「○」、まちがい＝赤紫の「×」。色だけでなく、印の形・線の種類でも区別しています。
- **URL の設定**
  - `?teacher=1` … 先生モード（答え・答えを入れて進める・発問の例・この端末のきろく・ワークシートのヒントと解答例）
  - `?ws=1` … ワークシートをひらいて開く（ふだんは、ドットプロットを広く見せるため、とじて開きます）

## 使い方

### ① 点を動かす

1. データを選びます：通学時間（15人）・読書時間（14人）・小テスト（20人）。
2. 点をドラッグすると、平均値・中央値・最頻値・範囲が同時に変わります（図の ▲ ◆ ★ ↔ と、右のカード）。「整数にすいつく」を外すと 0.1 きざみで動きます。
3. 点をタップすると「えらんだ点」（黄色）になり、「🗑」で消せます。「＋ 点を足す」で個数をふやせます（偶数個・奇数個を切りかえられる）。
4. 「⚖️ やじろべえで平均値」：数直線が棒になり、下の ▲（支点）をドラッグすると棒がかたむきます。左右のきょりの合計が同じになるところ（平均値）で「つり合った！」。
5. 「▶ 小さい順に並べる」：データのカードが小さい順に動き、まん中（偶数個なら2つ）が光ります。並べる前は「このままでは中央値はわからない」と出ます。
6. 「✏️ 練習問題」：中央値（奇数個・偶数個）・平均値・最頻値・範囲。答えを先に決めてからデータを作っています。

### ② 外れ値

1. 通学時間 または 読書時間。「＋ 外れ値を1つ足す」で、赤紫の「！外れ値」が足されます（通学時間は 120分）。
2. 外れ値の大きさは、スライダー・数の入力・点のドラッグで変えられます（最大 300分）。数直線は外れ値まで広がります。
3. 右の表で「外れ値なし／あり／かわった量」をくらべます。かわった量は棒の長さでも表します。
   - 通学時間：外れ値 120分 で 平均値 18.2 → 約24.56分（＋6.36）、中央値 15 → 16.5分（＋1.5）。300分 にすると平均値は 約35.81分 になるのに、中央値は 16.5分 のまま。

### ③ どれを使う？

11問のクイズです（順番はばらばら）。答えるまで、ドットプロットの代表値の印はかくれています。

| 種類 | 問題 | 答え |
|---|---|---|
| どの代表値？ | 社員10人の給料（社長 2400万円） | 中央値 |
| どの代表値？ | 町の家9けんの値段（おやしき 15000万円） | 中央値 |
| どの代表値？ | 班12人の通学時間（1人だけ 90分） | 中央値 |
| どの代表値？ | 11人のおこづかい（1人だけ 30000円） | 中央値 |
| どの代表値？ | くつ屋さんで、いちばん多く仕入れるサイズ | 最頻値 |
| どの代表値？ | 外れ値のないテストの点で、全体の成績をくらべる | 平均値（中央値も ○） |
| 数字にだまされない？ | 平均年収 600万円 → 半分以上が 600万円以上？ | 正しいとはかぎらない |
| 数字にだまされない？ | 通学時間の平均 20分 → 20分の人がいちばん多い？ | 正しいとはかぎらない |
| 数字にだまされない？ | 中央値 15分 → 長い人と短い人は同じくらい？ | 正しい |
| 数字にだまされない？ | 1組の平均 70点・2組 65点 → 1組はみんな2組の平均より上？ | 正しいとはかぎらない |
| グラフにだまされない？ | たて軸が 95人 から始まる棒グラフ（104人と98人）→ 約3倍？ | 正しくない（「たて軸を 0 から」で確かめる） |

### ④ 度数分布表と最頻値

1. 階級の幅をスライダーか数で変えると、度数分布表（以上〜未満・階級値・度数）が変わり、ドットプロットに階級の帯がかかります（度数がいちばん多い階級は緑）。
2. 「表からの最頻値」（いちばん多い階級の階級値）と「データの最頻値」をくらべます。
   - 通学時間：幅 5分 では 表から 17.5分・データでは 15分（ちがう）。幅 10分 では どちらも 15分。
3. 「✏️ 練習問題」：度数分布表から最頻値（階級値）を求めます。

### ⑤ 平均値が同じクラス

1. A組と B組（どちらも 15人・平均 6点・中央値 6点）のドットプロットを上下に並べます。範囲は A組 2点、B組 9点。
2. 「点数がそろっているのは、どちらのクラス？」に答えると、散らばりの説明が出ます。
3. 点をドラッグすると、平均値が同じかどうかがメッセージに出ます。

ボタン：✏️ 練習問題（① ④）／↶ ひとつもどす（ドラッグ・スライダーも1回分もどせる）／⟲ もういちど／💡 ヒント（練習問題では押すたびにくわしく）／📄 ワークシートの問題（② の通学時間をひらき、ワークシートをひらく）

## 授業での使い方（例）

- **導入（5分）**：① で点を動かし、平均値・中央値・最頻値・範囲の意味を確かめる。偶数個にして中央値の求め方も。
- **展開①（15分）**：ワークシートの予想「外れ値を足すと、平均値・中央値はどうなる？」を集める。「📄 ワークシートの問題」で 外れ値なし → 120分 → 300分 を記録（平均値は大きく変わり、中央値はほとんど変わらない）。
- **展開②（15分）**：③ のクイズで使い分けを考える（給料・家の値段・くつのサイズ・平均年収・グラフ）。
- **練習（5分）**：① の練習問題。つまずきが出たら「🔁 この型を練習」。
- **まとめ（5分）**：ワークシートの④に使い分けを書く。
- **別の時間に**：④ 度数分布表の最頻値（「区切って数えて ヒストグラム」のあと）、⑤ ばらつき（中2 の箱ひげ図への入口）。

## つまずき検知の一覧

| 型 | どこで見つけるか | 🔁 この型を練習 |
|---|---|---|
| 並べかえずに中央値を求めた | ① 中央値で、書いてある順のまん中（偶数個ならまん中2つの平均や片方）を答えた | ① 中央値（奇数個） |
| 偶数個なのに、まん中の1つだけを答えた | ① 中央値（偶数個）で、並べたまん中2つのどちらかを答えた | ① 中央値（偶数個） |
| 何番目か（順番）を答えた | ① 中央値で、まん中の番号（例 5）を答えた | ① 中央値（奇数個） |
| 平均値で、わる数をまちがえた | ① 平均値で、合計 ÷（個数±1）を答えた | ① 平均値 |
| 合計のまま答えた | ① 平均値で、合計を答えた | ① 平均値 |
| 最頻値で、個数（何人か）を答えた | ① 最頻値で、いちばん多い値の個数を答えた | ① 最頻値 |
| 範囲で、最大値だけを答えた | ① 範囲で、最大値を答えた | ① 範囲 |
| 表からの最頻値で、階級のはしの値を答えた | ④ 練習問題で、いちばん多い階級の「以上」か「未満」の値を答えた | ④ 表からの最頻値 |
| 表からの最頻値で、度数を答えた | ④ 練習問題で、いちばん多い度数を答えた | ④ 表からの最頻値 |
| 外れ値があるのに平均値で説明した | ③ 給料・家・通学時間・おこづかい で平均値をえらんだ | ③ その型が出る問題だけ |
| 最頻値を使えない場面で最頻値をえらんだ | ③ 最頻値が向かない問題で最頻値をえらんだ | ③ |
| 「いちばん多いもの」を知りたいのに、最頻値を使わなかった | ③ くつのサイズで平均値・中央値をえらんだ | ③ |
| 平均値より上の人が半分いると考えた | ③ 平均年収の問題で「正しい」 | ③ |
| 平均値の人がいちばん多いと考えた | ③ 通学時間の平均の問題で「正しい」 | ③ |
| 中央値の意味（半分ずつ）を使えなかった | ③ 中央値の問題で「正しくない」 | ③ |
| 平均値だけで、全員をくらべた | ③ 1組・2組の平均点の問題で「正しい」 | ③ |
| たて軸が 0 から始まらないグラフにだまされた | ③ グラフの問題で「正しい」 | ③ |

「🔎 あなたのつまずき」に、この時間に出た型と説明が出ます。記録は、この端末の localStorage（キー `ikechan-math-動かして くらべて 代表値`、ワークシートと同じ）に入ります：つまずきの型ごとの回数・問題の型ごとの正解の数・ヒントの回数。先生モードで合計を見たり消したりできます。

## 正しさとじっさいとのちがい

- データはすべて、この教材のために作った**架空のデータ**です（会社・町・お店の名前も出しません）。
- 値は 10 倍した整数で持ち、平均値は「合計 ÷ 個数」を分数のまま計算しています。わりきれないときは小数第2位までの「約」で表示します。中央値（偶数個）も整数のまま計算しています。
- 最頻値は、いちばん多い値が2つ以上あるときはぜんぶ出します（4つ以上は「など」）。どの値も1こずつのときは「なし」。
- 度数分布表の始まりは数直線の左はし（0）で、「以上〜未満」です。
- やじろべえのかたむきは、わかりやすいように大きさを決めています（じっさいの重さのつり合いの角度ではありません）。支点は平均値の近く（0.3 以内）ですいつきます。
- 値の大きいデータ（給料など）や外れ値があるときは、点が重ならないように上に積んでいます。点の位置は少しずれて見えることがあります。
- ② の「かわった量」の棒は、平均値と中央値の変わった量に合わせた長さです（範囲は大きく変わるので、長さに上限があります）。
- 練習問題の場面（けんすいの回数など）の数は、答えを先に決めてから作っています。まちがいの型を見分けられるように、「並べずに答えた値」と「正しい答え」などが同じ数にならないようにしています。

## 先生がかえやすいところ

- データ：`PRESETS`（`main: true` で ① ② ④ のボタンになる。`out` は ② の外れ値、`widths` は ④ の階級の幅のはんい）。⑤ のクラスは `twoA`・`twoB`。
- ③ のクイズ：`QUIZ` に1つ足すと問題がふえます（`kind`・`t`・`vals`・`ans`・`trip`・`why`）。
- 練習問題の場面：`SCENES`。表の問題の場面：`makeTblQ` の中。
- つまずきの型：`TRIPS`。
