✂ わって見る（発展）：分数の係数

x のタイル1本を等分して、かけらの数で分数の係数を見よう。x/2（x を 2 つにわった 1 つ分）と (1/2)x は同じ。数×文字は 3×x＝3x（× をはぶいて数を前）。

動くはやさ：
項
＋ で結んだ1つ1つの部分。3x−5 ＝ 3x＋(−5) の項は 3x と −5。
係数
文字にかけてある数。3x の係数は 3、−x の係数は −1。
同類項
文字の部分が同じ項。3x と 5x は同類項（タイルの形が同じ）。3x と 5 は同類項ではない。
ゼロ対
x と −x、1 と −1 の1組。たすと 0 なので、いっしょに消しても式の値は変わらない。
分配法則
2(3x−1) ＝ 2×3x ＋ 2×(−1)。かっこの中の項のぜんぶに、前の数をかける。

※じっさいとのちがい：タイルの係数は整数だけ（④ をのぞく）、1つの列に24枚まで、文字は2種類までです。x のタイルの長さは決まっていません（x はいろいろな数を表すので、1 のタイル何個分とは決められない）。

小学校の「十のまとまり」と「ばら」を分けて数える → くり上がり・くり下がりをブロックで ➕ 正負の数チップ（ゼロ対） 🍎 文字式の立式（書き方のきまり）
