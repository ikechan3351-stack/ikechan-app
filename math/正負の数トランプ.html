🃏 正負の数トランプ

黒（♠♣）は ＋、赤（♥♦）は −。たして 0 になる組を すてる「ゼロ対ババ抜き」

👩‍🏫 先生モード

📜 カードの約束

  • 黒（♠ スペード・♣ クラブ）は 正の数。♠7 は ＋7
  • 赤（♥ ハート・♦ ダイヤ）は 負の数。♥7 は −7
  • A は 1。絵札をいれると J＝11・Q＝12・K＝13
  • ジョーカーは「ババ」。最後まで持っていた人の負け

🎴 ゼロ対ババ抜きのルール

  1. カードを全員に配る
  2. たすと 0 になる2枚（ゼロ対）を すてる。例：(+7)+(−7)=0
  3. つぎの人の手札から1枚引く。ゼロ対ができたら すてる
  4. 手札がなくなったら あがり。ジョーカーが残った人の負け

※ふつうのババ抜きとちがい、♠7 と ♣7（どちらも ＋7）は組にならない。
