# 🟠 さんすうセット⑤ ジオボード

小学1〜4年向けの **デジタルジオボード** です。ピンに輪ゴムをかけるように、指でゴムをのばしてピンにかけ、図形をつくります。正解・不正解は出しません。自由にさわって、必要なときだけ長さ・角度・面積を出して、気づきを支えます。

- 「さんすうセット①〜④」と同じつくりです。📷しゃしん・💾くばる・📂ひらく は ①〜④ と同じ使い方です。
- 単元（例）：1年「かたちづくり」、2年「三角形と四角形」（辺・頂点・直角）、3年「三角形と角」（二等辺三角形・正三角形）、4年「垂直・平行と四角形」「面積」（複合図形）。
- 仕様書：`~/Downloads/ジオボード.md`（開発の引き継ぎ用）。

## 基本情報

- **ファイル**：`さんすうセット⑤ ジオボード.html`。この1ファイルだけで動きます（ネット接続・外部ライブラリ・画像ファイルは不要）。
- **対応する機器**：iPad Safari、Chromebook、Windows の Edge・Chrome、電子黒板。タッチ・ペン・マウスのどれでも動きます。
- **2本指**：盤の拡大（1〜3倍）・移動。えらんだ形を1本の指でつかんだまま2本目の指をおいてひねると、形がまわります。

## 道具（左の たての 帯）

| 道具 | できること |
|---|---|
| 🟠 ゴム | ピンから指をすべらせると、ゴムがのびて、はなしたピンにかかる。そのまま次のピンへ。はじめのピンにもどすと形がとじる。ピンを順にタップしてもつなげる。ゴムの辺のとちゅうをつまんで引っぱると頂点がふえる（2本のピンにかけたゴムは、もう1本がピンの間にのこる）。頂点をつまむと別のピンにかけ直せる。ピンのない所ではなすと、ゴムはちぢんでもどる |
| 👆 えらぶ | 形をタップしてえらぶ。引っぱると動いてピンに吸いつく。↻ のつまみで回す（15°ずつ／じゆう）。下のボタンで 90°回転（三角の盤は60°、まるい盤はとなりのピンまで）・左右反転・上下反転・コピー・わける・けす |
| 🪣 ぬる | 「なか」：とじた形の中をタップしてぬる（うすい／こい、斜線の丸で ぬりを消す）。「ゴム」：ゴムの色をかえる |
| ✂️ きる | 形のへりのピンから、べつのへりのピンまで線を引くと2つに分かれる（ななめもOK）。分かれた直後、ピースが少しはなれてからもどる |
| 🧩 はる | ピースをタップ（オレンジ）→ はれる相手がみどりに光る → タップで1つの形になる。ピースは引っぱって動かせる。はった形は「えらぶ」の「わける」でもとの2つにもどせる |
| ✏️ かく | ペン（手がき）・もじ（タップした所に入力。引っぱると動く・タップで直す）・けしゴム |

- 下の帯：色のパレット（ゴムの道具では、つぎにかけるゴムの色。虹色は1本ずつかわる）、道具ごとの切りかえ、もどる・やりなおす・ぜんぶけす。

## 盤（上の帯の「ばん」）

| 盤 | 中身 |
|---|---|
| たて 5だん／7だん／11だん | 正方形の格子。**よこは画面のはばに入るだけピンがふえる**（横1366pxの画面で 10×5／14×7／22×11）。もうかかっているゴム・もじがある列までは、せまい画面でもピンをのこす |
| 三角 | 正三角形の格子（8だん。よこは画面に合わせてふえる）。となりのピンとのきょりはどこも1 |
| まる12／まる24 | 円周を12・24とうぶん＋中心のピン。回転・反転は盤の中心が基準 |

- 動かす・回す・反転・コピー・切る・はるのあとは、ピンにいちばん近い頂点がピンにのります（マス目にそって動かせば、頂点はぜんぶピンにのる）。自由な角度で回したときは、ピンからはずれる頂点もあります。

## はかる（上の帯の 📏長さ・📐角度・🟦面積・⚙️）

はじめはすべて OFF です。ゴムを動かしている最中も、値は毎回かわります。

- **長さ**：辺の外がわに出る。ピン1つ分＝1。ななめの辺は「かかない（1〜3年）」か「約2.8（4年）」。√ の表記は入れていません（小1〜4年向けのため）。
- **角度**：頂点の内がわに弧と「45°」「約34°」。直角は □（⚙️ で「90°」とも書ける）。へこんだ形の 270° なども正しく出る。
- **面積**：形の中に「面積 6」（マス1つ分＝1、座標の公式で計算。半分のマスは 7.5 のように）。三角の盤は「△ 4こ分」（小さい正三角形の数）。
- ⚙️：まわりの長さ・角の和・マスを見せる（方眼を点線で）・頂点の名前 A, B, C…・すべての形／えらんだ形だけ。
- **数をタップすると「？」になって かくれる**（もう一度タップで見える）。先生モードでは、はじめから全部「？」。

| 学年 | 道具 | はかる | さいしょの盤 | ななめの辺 |

| 1年 | ゴム・えらぶ・ぬる | なし | たて5だん | かかない |
| 2年 | ＋かく | 長さ | たて7だん | かかない |
| 3年 | ＋かく | 長さ | 三角 | かかない |
| 4年 | ぜんぶ（きる・はるも） | 長さ・角度・面積・⚙️ | たて11だん | 約2.8 |

- **先生モード**（電子黒板用）：ピン・ゴム・文字・ボタンが大きく、吸いつく範囲が広くなり、数はタップするまで「？」。学年にかかわらず道具はぜんぶ出ます。
- 1・2年と先生モードは、ピンに吸いつく範囲が広め（ピンの間かくの50%、ほかは40%）。
- 「うごきを 少なく」：ばねの動きをはぶいて、すぐ吸いつきます（OS の「視差効果を減らす」でも同じ）。
- URL で開いたときに学年もモードも決まっていなければ、はじめにこの画面が出ます。

## URL

設定・盤・はかる表示を変えると、アドレスも書きかわります。そのアドレスをそのまま子どもに配れます。

| パラメータ | 値 |
|---|---|
| `mode` | `teacher`（先生モード。なければ子ども） |
| `grade` | `1`〜`4` |
| `board` | `square5`／`square7`／`square11`／`tri`／`circle12`／`circle24` |
| `show` | `length,angle,area`（はじめから出す はかる表示） |
| `motion` | `less`（うごきを少なく） |

例：`さんすうセット⑤ ジオボード.html?mode=teacher&grade=4&board=square11&show=area`

## 保存

- **📷 しゃしん**：プレビューを出して、「📋 コピー」（ロイロに はりつけ）か「💾 ほぞん」（PNG）。ボタンで保存できない機器では、プレビューの画像を長おしして保存します。
- **💾 くばる（先生）・📂 ひらく**：画像（PNG）の中に盤（ゴム・もじ・手がき）が入っています。子どもは画像を保存して「📂 ひらく」でえらぶと、動かせる盤にもどります。ひらいたあとは「⟲ はじめに」で、くばられたときの状態にもどせます。①〜④の画像をまちがえてひらいたときは「そちらで ひらいてね」と出ます。
- **つづきから**：盤をかえるたびに、その端末（localStorage、キー `ikechan-math-さんすうセット⑤ ジオボード`）に自動で保存します。次に開いたとき「つづきから／あたらしく」を聞きます。保存できない環境でもアプリは動きます。

## 授業での使い方（例：4年 面積「複合図形」）

1. 先生が電子黒板（先生モード・4年）で、L字の形をゴムでつくる。「面積は いくつかな？」と予想させる。
2. 子どもはタブレットで同じ形をつくり、✂️きる で2つの長方形に分けて考える。
3. 🟦面積 をONにして、分けた形の面積をたしかめる。⚙️「マスを 見せる」で数えてたしかめてもよい。
4. 先生は「？」の面積をタップして答えを見せる。ちがう分け方をした子の盤を📷しゃしんでくらべる。
