「方眼の 大きさ」を かえると、かいた 図は 消えます。「じどうで うつす」を OFF に すると、反対側は うつらないので、子どもが 自分で かいて「✔ たしかめる」で 調べます。「じどう」は パソコンの「視差効果を 減らす」などに あわせます。「へらす」に すると、折る・回す アニメが なくなり、すぐに 結果が 出ます。

❓ 先生へ（つかい方）

6年「対称な図形」の教材です。線対称（軸で折ると重なる）・点対称（中心のまわりに180°回すと重なる）を、うつす・折る・回す動きで確かめ、対応する点を結ぶ線の性質を見つけます。

✏️ うつして かこう

  • どうぐ「✏️ 線」：方眼の点をタップしていくと、線がつながります（ドラッグでも引けます）。今の点をもう一度タップすると、線が切れます。
  • どうぐ「● 点」：点だけを打ちます。「🧽 けす」：線や点をタップして消します（うつった方をタップしても、もとの線が消えます）。
  • どうぐ「📏 軸」：ドラッグすると、その向き（たて・よこ・ななめ2とおり）の軸が引けます。タップすると、向きはそのままで軸がその点に動きます。右の ｜ ― ／ ＼ でも向きを変えられます。
  • かいた線は青の実線、うつった線はオレンジの点線です（色と線の形の両方で区別）。
  • 「📖 折る」で、軸から片側の紙が持ち上がって折り重なります。うつした側が、かいた側に重なるように折ります。「ひらく」でもどります。
  • どうぐ「👆 しらべる」：点をタップすると、対応する点が同じ色・同じ形の印（● ▲ ■）で出ます。結ぶ線と軸のところに直角の印、軸からの長さに同じ数の印（｜・‖・⦀）とマスの数がつきます。3組まで同時に出せます。
  • ⚙️ せっていの「じどうで うつす」を OFF にすると、反対側を自分でかき、「✔ たしかめる」で線対称になっているかを調べます。ちがう所は赤でしめします。
  • 「👉 れい」で、いえ・ちょう などの半分を出せます（うつす OFF のときは、続きをかく練習になります）。
  • 上の「種類」で 線対称 ⇔ 点対称 を切りかえます。かいた図はそのまま残るので、同じ図で2つをくらべられます。

✏️ うつして かこう（点対称）

  • かいた線が、対称の中心（◎）のまわりに180°回した位置に、オレンジの点線で現れます。
  • どうぐ「📍 中心」：方眼の点だけでなく、マスのまん中・辺のまん中にも中心を置けます。「◎ まん中に もどす」で方眼のまん中へ。
  • 「🔄 180° 回す」：うすい紙（トレーシングペーパー）にうつしとった図が、中心を画びょうでとめたように回ります。回った角度が弧と数で出ます。「🔄 もどす」でもどります。
  • 「👆 しらべる」：対応する点を結ぶ線が中心を通ること、中心から等しい長さ（同じ数の ｜ の印）を表示します。中心から「左3・上3」⇔「右3・下3」のように、マスを数える道すじもうすく出ます。
  • 「👉 れい」：Z・かざぐるま・平行四辺形・リボン。

🔍 対称かな？

  • アルファベット（A・H・N・S・Z・X・E・F）、オリジナルのマーク（やじるし・ほし・かざぐるま・ハート・はた・いしころ）、多角形（平行四辺形・ひし形・等脚台形・正六角形）の18こ。「📚 図を えらぶ」で選べます。
  • ①「線対称だけ／点対称だけ／両方／どちらでもない」を選ぶ → ② 軸をさがす → ③ 対称の中心をさがす、の順に進みます。
  • まちがえたときは、その考えをためすアニメが出ます。平行四辺形を線対称と答えると、対角線で折ってずれる様子を見せます（「でも 回すと…？」と点対称へつなげます）。
  • 軸は、図の上をはしからはしまでドラッグして引きます。その線で折って、重なれば「○本目」、重ならなければずれる様子を見せます（向き8°・中心から0.5マス以内なら軸とみなします）。「✔ もう ない」で全部見つけたかを確かめます。軸の本数は先に教えません。
  • 中心は、タップしたところを中心に180°回して確かめます。「💡 ヒント」で、対応する点を結んだ線（2本）が交わることを見せます。

✂️ 半分から かこう

  • 線対称4問・点対称4問。半分の図と軸（中心）から、残りの頂点をタップして置きます。順番は自由です。
  • まちがえると、対応するもとの頂点を光らせ、「頂点エは 軸から 左に 3マス。対応する頂点は 右に 3マス」のように、マスを1つずつ数える番号を出します。2回まちがえると、置く場所も光ります（点対称は「中心から 右1・上3 → 左1・下3」の道すじ）。
  • 完成したら「📖 折る／🔄 180° 回す」で重なることを確かめます。

🔷 多角形の なかま分け

  • 正三角形〜正八角形、長方形、ひし形、平行四辺形、台形、二等辺三角形の11こ。表の図形名をタップすると、その図形が出ます。
  • 「📖 軸で 折って みる」で軸を1本ずつ折って数え、「🔄 180° 回す」で点対称かを確かめます。ドラッグで自分で引いた線でも折れます。
  • 表の ○×（タップで ？→○→×）と軸の本数（−＋）を書いて「✔ こたえあわせ」。全部正かいすると、偶数の正多角形の行が黄色になり、きまり（正多角形の軸の数＝辺の数、辺の数が偶数なら点対称）と、正十角形・正九角形の問題が出ます。「🔓 こたえを 見る」で表をうめられます。

🧑‍🏫 先生モード

  • 図形（20こ）とやり方（軸で折る・180°回す。平行四辺形などは「対角線で折る（まちがい）」も）を選び、「▶ つぎ」で1ステップずつ見せます。図をタップしても進みます。
  • 折る：図 → 軸 → 90°まで折る → ぴったり折る → ひらいて対応する点 → 対応する点のきまり（直角・等しい長さ）。回す：図 → 中心 → 90° → 180° → もどして対応する点 → きまり（中心を通る・等しい長さ）。
  • 「⏯ じどう」で自動で進みます。ステップ名をタップすると、そのステップへとびます。

そのほか

  • ⚙️ せってい：方眼の大きさ、じどうで うつす、ふりがな、効果音、動きを減らす。せっていだけは このブラウザに保存されます。児童の名前など個人情報は扱いません。
