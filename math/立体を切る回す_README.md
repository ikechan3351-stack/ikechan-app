# 立体を切る・回す（断面・回転体・投影図）

中学1年「空間図形」で、立体を平面で切ったときの**断面**、平面図形を回してできる**回転体**、立体を正面と真上から見た**投影図**を学ぶアプリです。外部の3Dライブラリは使わず、点の座標を計算して SVG で見取図を描いています（見えない辺は点線）。

| おうぎ形の弧と面積（`おうぎ形の弧と面積.html`）④ | 円錐の側面（おうぎ形）と展開図 |
| **立体を切る・回す（これ）** | 中1 の内容：断面の形（立方体を3点で切る）、回転体、投影図（正面図・平面図）。予想クイズ・つまずき検知・ワークシートつき |

## 基本情報

- **ファイル**：本体 `立体を切る回す.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中1）から開けます。
- **画面**：広い画面は 左＝見取図（ドラッグで回せる。「ななめから・真上から・正面から」ボタン）・右＝スライダーと断面・投影図 の2列。スマホは たて1列。
- **色のきまり**：立体＝青むらさき、切り口・回す図形＝オレンジの格子もよう、切る面＝黄色の点線、回転の軸＝赤むらさきの一点鎖線、正解＝緑の「○」、まちがい＝赤紫の「×」。
- **3Dが苦手な生徒のために**：① ② では右に「上から見た図」「正面から見た図」をいつも出しています。
- **URL の設定**
  - `?teacher=1` … 先生モード（答え・答えを入れて進める・発問の例・この端末のきろく・ワークシートのヒントと解答例）
  - `?ws=0` … ワークシートをとじて開く

## 使い方

### ① 切断

1. 立方体・正四角錐・円柱・円錐・球をえらびます。
2. 切る面を「傾き（0°＝水平〜90°＝垂直）」「向き（0〜359°）」「位置（中心からのきょり cm）」のスライダーと数で動かします。手前の部分は自動でうすくなり、切り口が見えます。「✂ 切りはなす」で2つに分けて見られます。
3. 右に、断面の名前と、断面をまっすぐ見たほんとうの形（等しい辺の印・直角の印つき）、上から見た図・正面から見た図（切り口はオレンジ）が出ます。
4. 名前：正三角形・二等辺三角形・直角三角形・正方形・長方形・ひし形・平行四辺形・台形・五角形・六角形・正六角形・円・だ円・だ円の一部と直線・放物線と直線（中3 の予告）・双曲線の一部と直線（反比例のなかま）。スライダーで正六角形・正三角形・正方形にとても近いときは「〜にとても近い」と出ます。
5. 🤔 予想クイズ（16問）：切り方を見て、断面の形を4択で予想します。答えるまで断面はかくれています。
6. 🎯 立方体を3点で切る：頂点 8こ と辺の真ん中 12こ から3点をタップすると、その3点を通る面で切れます。お題は 正三角形・長方形・台形・ひし形・五角形・正六角形。

### ② 回転体

1. 長方形・直角三角形・半円・台形・軸からはなれた長方形（発展）をえらびます。「↔ 軸にする辺をかえる」で、長方形・直角三角形の軸を短い辺にかえられます。
2. まず「何ができる？」を4択で予想します。答えると、自動で1回転します。回転角のスライダー（0〜360°）や「▶ 1回転させる」で、立体ができていく様子を見られます。回しているとちゅうは、もとの図形と今の図形がオレンジで見えます。
3. できる立体：円柱・円錐・球・円錐台・穴のあいた円柱（発展）。
4. 🤔 どの図形を回した？：できた立体を見て、回した図形を4つの絵からえらびます（軸にする辺のちがいもまぎらわしい選択肢にしています）。

### ③ 投影図・見取図

1. 立方体・直方体・三角柱・円柱・円錐・四角錐・三角錐・球をえらぶと、左に見取図、右に投影図（上に正面図、下に平面図。見えない辺は点線）が出ます。
2. 🤔 投影図クイズ：投影図だけを見て立体を当てます（見取図はかくれています）。選択肢は、正面図や平面図が同じ形のまぎらわしい立体からえらびます。

ボタン：↶ ひとつもどす／⟲ もういちど／💡 ヒント（押すたびにくわしく）／📄 ワークシートの問題（① の立方体をななめに切る）

## 授業での使い方（例）

- **導入（5分）**：ワークシートの予想「立方体を斜めに切ると、できる形は？」を挙手で集める（「四角形まで」が多い）。
- **展開①（15分）**：「📄 ワークシートの問題」で、位置を動かしながら 三角形 → 六角形 → 三角形 と変わるのを記録する。「切る面が通る面の数 ＝ 辺の数」に気づかせる。
- **展開②（10分）**：「🎯 立方体を3点で切る」で正六角形・正三角形などを作る。
- **別の時間に**：② 回転体（予想 → 回して確かめる → どの図形を回した？）、③ 投影図（投影図クイズ）。

## つまずき検知の一覧

| 型 | どこで見つけるか | 練習するパート |
|---|---|---|
| 立方体の断面は三角形か四角形だけ、と思った | ① 予想クイズで、答えが五角形・六角形なのに三角形・四角形をえらんだ | ①（五角形・六角形の問題） |
| 「正」がつく形かどうかの見落とし | ① 予想クイズで、同じ角数の形（正方形と長方形、正六角形と六角形など）をまちがえた | ①（立方体・正四角錐の問題） |
| ななめに切っても円のまま、と思った | ① 円柱・円錐をななめに切った問題で「円」をえらんだ | ①（円柱・円錐の問題） |
| 球の切り口を だ円 と思った | ① 球の問題で「だ円」をえらんだ | ① |
| 円錐を頂点を通って切った形 | ① 円錐を頂点を通って切った問題でまちがえた | ① |
| 切る向きと切り口の形の結びつけ | ① 円・長方形・三角形が答えの問題でまちがえた | ① |
| 回転体の予想ちがい | ② 予想で、ちがう立体をえらんだ／どの図形？でまちがえた | ② |
| 回転体に角柱・角錐をえらんだ | ② 予想で四角柱・三角錐をえらんだ | ② |
| 軸からはなれた図形の回転体 | ② 軸からはなれた長方形で穴のない立体をえらんだ | ②（穴のあく図形） |
| 軸にした辺のとりちがえ | ② どの図形？で、同じ図形の軸がちがう方をえらんだ | ②（どの図形？） |
| 平面図の円と多角形のとりちがえ | ③ 正面図が同じで、平面図が円か多角形かがちがう立体をえらんだ（円柱と三角柱、円錐と四角錐など） | ③ |
| 正面図と平面図のとりちがえ | ③ えらんだ立体の正面図が、答えの平面図と同じ形だった | ③ |

「🔎 あなたのつまずき」に、この時間に出た型と説明が出ます。「🔁 この型を練習」で、その型の問題があるパートへ移ります。
記録は、この端末の localStorage（キー `ikechan-math-立体を切る回す`、ワークシートと同じ）に入ります：つまずきの型ごとの回数・パートごとの正解の数・ヒントの回数。先生モードで合計を見たり消したりできます。

## 正しさとじっさいとのちがい

- 立体はすべてへこみのない形（凸）なので、切り口は「切る面と立体の辺との交点」を角度の順にならべた1つの凸多角形として計算しています。立方体・正四角錐の断面は正確です。
- 円柱・円錐・球は細かい多角形の面で近づけています（円は 48 角形、球は 16 × 32 の面）。断面の円・だ円もわずかに角ばっています。曲面のある立体の断面の名前は、切る面の傾きと、底面にとどくかどうかで決めています。
- 断面の名前は辺の長さ・平行・直角を小数で計算して決めています（ぴったりのときだけ「正」がつきます）。3点で切るミッションは点が決まっているので、正六角形もぴったりになります。
- 円錐の断面で、放物線になるのは母線と平行に切ったときだけです（傾き 63.4° の前後 0.3° を放物線としています）。放物線・双曲線は中学1年の範囲をこえるので、名前の説明に「中3」「高校」と書いています。
- 回転体も 48 こに分けて回しています。円錐台は教科書によっては名前が出てきません。

## 先生がかえやすいところ

- 予想クイズ：`QUIZ`（立体・切る面の法線 n・位置 s・選択肢）。答えの名前は計算で決まります。
- 3点で切るお題：`MTARGETS`。答えの3点は総あたりで自動で見つけます。
- 回す図形：`SHAPES`（(r, z) の点の列・できる立体・選択肢・説明）、どの図形？のまぎらわしい組み合わせ：`REV_DIST`。
- 投影図の立体：`SOLIDS3`（正面図・平面図の形のなかま）。
- つまずきの型：`TRIPS`。
