# ならべて 交わって 連立方程式（解をならべる → 2本の直線の交点 → 平行・重なり → 計算とつなぐ）

中学2年「連立方程式とグラフ」のアプリです。
二元一次方程式 *ax*＋*by*＝*c* の解を**点にしてならべる**と直線になること、2本の直線の**交点の座標が連立方程式の解**になることを、グラフと代入の計算で確かめます。直線が平行（解なし）・重なる（解は無数）場合も調べます。発展として、加減法・代入法の1ステップごとに、直線が交点のまわりを回るようすを見ます。

## 基本情報

- **ファイル**：本体 `ならべて 交わって 連立方程式.html`、共通部品 `math-render.js`（数式・分数）・`graph-engine.js`（座標平面）・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中2）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）・スマホ。
- **画面のならび**：左にグラフ、右に式・表・説明。タブレットの横向きで2列になり、せまい画面ではグラフ → 説明 の順に並びます。ワークシートは右はしの「📝 ワークシート」でひらきます。
- **URL の設定**
  - `?teacher=1` … 先生モード（① の表に答えのうすい表示・② の交点の座標がはじめから出る・れんしゅうの「答えを見る」・④ の「▶▶ 自動再生」・ワークシートのヒントと解答例）
  - `?mode=sol`・`cross`・`para`・`calc` … はじめに開くタブ
  - `?ws=1` … ワークシートをひらいて開く

## 色と線のきまり

| もの | 見え方 |
|---|---|
| 式① | オレンジの実線（━）、ラベル ① |
| 式② | 青の点線（┅）、ラベル ② |
| 計算でできた式（④） | 緑の一点鎖線、ラベル ③④… |
| 交点 | 黒の大きな点（タップ前は「？」） |
| 解になる点（①） | 緑の ● |
| 解にならない点（①） | 赤紫の ○ と ✕ |

## 使い方

### ① 解をさがす
- 式（*x*＋*y*＝5、2*x*＋*y*＝6、*x*−2*y*＝4）をえらびます。
- 表のます目（*x*＝−1〜6）に *y* の値を入れて Enter か「✔ たしかめる」。正しければ緑の ●、まちがいは赤紫の ○✕ がグラフに出ます。分数（3/2）・小数（1.5）・負の数も入れられます。*x*−2*y*＝4 では *y* が分数になるます目があります。
- 「じぶんで」のます目には、*x*＝1.5 のような好きな *x* も入れられます。
- グラフのどこかをタップすると点を打ち、その点が解かどうか（代入した計算）を下に出します。
- 解を4組見つけると「点はどのようにならんでいる？」→「一直線」で直線を引きます。直線の上の点 P をドラッグすると、どこでも解になることが確かめられます（すいつく／すいつかないの切りかえはグラフの上のボタン）。
- 「解はぜんぶでいくつある？」→「数えきれないほど」で、二元一次方程式の解が無数にあり、そのグラフが直線になることをまとめます。

### ② 2直線の交点
- 2つの式の *x* の係数・*y* の係数（−10〜10）・右辺の数（−20〜20）を、スライダーか数の入力で変えます（数の入力なら −99〜99）。
- 「整数の交点」「分数の交点」「画面の外の交点」「🎲 ほかの式」のひな形があります。
- グラフの **●？（交点）をタップ**すると、交点の座標を分数のまま表示し、①・② の両方に代入した計算を出します → 「交点の座標は連立方程式の解」。
- 交点でない場所をタップすると、その点 Q を①・② に代入し、「片方の式だけ」なら解ではないことを示します。
- **交点が画面の外のとき**は、自動で縮尺を変えて交点が見えるようにします（もどれるようになったら、もとの大きさにもどります。⟲ でもどすこともできます）。交点がとても遠いとき（座標が 300 をこえる）は、座標だけを出します。
- 「📝 交点を求める れんしゅう」：答えを先に決めて作った連立方程式の解を答えます。整数の問題（グラフから読める）と分数の問題（計算で求める）を切りかえられます。同じ問題は続けて出ません。

### ③ 解けない・たくさん
- **🎯 チャレンジ**：① *x*＋2*y*＝4 は動かさず、② の係数を変えて「交わらない（平行な）2本にしよう」「ぴったり重なる2本にしよう」。できると、加減法で *x* と *y* が両方消えて 0＝6（成り立たない → 解なし）や 0＝0（いつも成り立つ → 解は無数）になる計算を見せます。「💡 ヒント」あり。
- **❓ 見分けクイズ**：6つの連立方程式（平行2・重なる2・1点で交わる2）を見て、「解は1つ／ない／無数／*x*＝0, *y*＝0」をえらびます。答えるとグラフが出ます。数えるのは1回目で正解した問題だけです。

### ④ 計算とつなぐ（発展）
- 4つの問題：加減法（たす）・加減法（ひく）・加減法（何倍かしてから）・代入法。
- 「▶ つぎのステップ」で計算が1つ進み、新しい式の直線（緑）が出ます。式をたす・ひく・代入するステップでは、**直線が交点を中心に回って**たての直線（*x*＝3）や横の直線（*y*＝2）になるアニメが出ます。両辺を何倍かするステップでは、直線は動きません。
- 最後に「どのステップの直線も同じ交点を通っていた」理由（交点の (*x*, *y*) は①も②も成り立たせるので、たしたりひいたりした式も成り立たせる）をまとめます。
- ステップは `P4` のデータに書いてあり、問題を足すときは op（たす式・かける数）と calc（表示する計算）・say（説明）を書きます。

## ワークシート

- もんだい：「2本の直線が平行になる連立方程式では、解はどうなるだろうか？」
- ① 予想：解は1つ／解は *x*＝0, *y*＝0／解はない／解は無数にある／わからない
- ② 操作：② か ③ で式をつくって「＋ 記録する」（式①・式②・2本の直線（1点で交わる／平行／重なる）・解）。
- ④ まとめ：「連立方程式の解＝2つの式のグラフの交点の座標」、平行なら解なし、重なるなら解は無数。先生モードで解答例が出ます。
- 保存キーは `ikechan-math-ならべて 交わって 連立方程式`（つまずきの記録・③ のチャレンジのできたかどうかもこの中）。

## 授業での使い方の例（50分）

1. **予想（5分）**：ワークシートで「平行なときの解は？」を予想。
2. **解をならべる（10分）**：① で *x*＋*y*＝5 の解を表で見つけ、点を打つ。「じぶんで」に *x*＝1.5 を入れたり、点 P を動かしたりして「解は無数・グラフは直線」をおさえる。
3. **交点＝解（15分）**：② で「整数の交点」の交点をタップし、両方の式に代入。交点でない点（片方の直線の上の点）もタップして比べる。「分数の交点」でグラフから読めないことを見て、計算の必要性に気づかせる。れんしゅうを数問。
4. **平行・重なり（12分）**：③ のチャレンジで平行・重なりをつくり、0＝6・0＝0 の計算を見る。見分けクイズ。ワークシートに3つの場合を記録する。
5. **まとめ（8分）**：ワークシートのまとめを書く。時間があれば ④ を先生モードの自動再生で見せる（発展）。

## 正しさについて（※じっさいとのちがい）

- 交点・代入の計算は、すべて分数（Fraction）で厳密に行います。表示するときも分数のまま（3/5 など）出します。グラフの位置を描くときだけ小数にします。
- 直線は画面のはしで切れていますが、本当はどこまでものびています。
- 係数は整数だけにしています（スライダーは *a*・*b* が −10〜10、*c* が −20〜20）。
- グラフをタップした点は、すいつく設定なら整数、すいつかない設定なら 0.1 きざみに丸めて読みます。
- ④ のアニメの途中の直線は、①＋*t*×② のように式を少しずつ変えたものです（*t* を 1/60 きざみの分数にしているので、途中の直線もかならず交点を通ります）。
- 中2のこの時点では一次関数の「傾き」を習っていないので、平行は「向きが同じ」「どこまでのばしても交わらない」と説明しています。

## つまずき検知の一覧

| 型 | 見つけ方 | 例 |
|---|---|---|
| ↔ 移項や符号のまちがい | ① の表で、*y*＝(*c*＋*ax*)÷*b* や 正しい値の符号ちがいを入れた | *x*＋*y*＝5、*x*＝2 で *y*＝7 |
| ✖ 係数のかけ忘れ・わり忘れ | ① の表で、*x* の係数をかけ忘れた値・*y* の係数でわり忘れた値を入れた | 2*x*＋*y*＝6、*x*＝1 で *y*＝5 |
| ♾ 二元一次方程式の解を「数えられる」と考えた | ① の「解はいくつ？」で「9組」「整数の組だけ」 | |
| 🔄 座標の *x* と *y* を逆にした | ② のれんしゅうで (*y*, *x*) を答えた | 解 (2, 4) に *x*＝4, *y*＝2 |
| ± 座標の符号のまちがい | ② のれんしゅうで、片方か両方の符号が逆 | 解 (−3, 1) に (3, 1) |
| 👀 分数の交点を、グラフの目分量で読んだ | ② の分数の問題で、正しい値に近い整数を答えた | 解 (−7/2, 0) に (−3, 0) |
| ☝ 片方の式しか成り立たない点を答えた | ② のれんしゅうで、①か②の一方だけを成り立たせる点 | |
| 0️⃣ 「解がない」を「解は 0」と考えた | ③ のクイズで、平行なのに「*x*＝0, *y*＝0」 | |
| 〓 重なる直線なのに「解はない」と考えた | ③ のクイズで、重なるのに「解はない」か「*x*＝0, *y*＝0」 | |
| ✕ 平行・重なる直線でも交点が1つあると考えた | ③ のクイズで、平行・重なるのに「解は1つ」 | |

つまずきは右の列に「あなたのつまずき」として出て、ちがうパートのつまずきなら「▶ もどって見る」でそのパートにもどれます。① のつまずきには、その *x* のときの正しい計算（3−2*y*＝4 → −2*y*＝4−3 → …）も出ます。回数は右下の「つまずきの記録」に残ります。
