# 正負の数ドリル（レベル別・つまずき別の計算練習）

中学1年「正負の数」の四則計算を、**レベル別に10問ずつ**練習するアプリです。
まちがえた答えの数から「どこでつまずいたか（つまずきの型）」を見つけて記録し、**その型の問題だけをふくしゅう**できます。

## 基本情報

- **ファイル**：本体 `正負の数ドリル.html`、共通部品 `math-render.js`（式の表示）。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中1）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）・スマホ。
  - 横長の広い画面では「問題｜キーパッド」の2列、せまい画面では縦に並びます。
- **キーボード**：数字・「-」「+」で入力、Backspace＝1文字けす、Enter＝答え合わせ／つぎへ、Esc＝やめる。
- **記録**：この端末の localStorage（保存キー `ikechan-math-正負の数ドリル`）に、解いた問題・答え・つまずきの型を入れます（新しい3000問まで）。
- **URL の設定**：`?teacher=1` … 先生モード

## レベル

| レベル | 内容 | 例 |
|---|---|---|
| ① | 加法・減法（2つの数の符号が同じ） | (−5)+(−3)、(−9)−(−4) |
| ② | 加法・減法（2つの数の符号がちがう） | (+3)+(−8)、(+3)−(−5) |
| ③ | 乗法・除法（2〜3つの数） | (−6)×(+3)、(−24)÷(+6)、(+12)÷(−4)×(−2) |
| ④ | 累乗と四則（かっこ・指数） | −2²+(−3)×2、(−2)³÷4、(−3)×(4−9) |
| ⑤ | かっこのない加減の式（項だけの式） | 4−9+2−6 |
| 🎲 | ミックス | ①〜⑤から2問ずつ（順番はばらばら） |

## 使い方

1. レベルをえらんで「10問チャレンジ」。
2. 式が大きく出ます。キーパッド（0〜9・−・＋・けす）で答えを入れて「こたえる」。
   - **○ せいかい**：つぎの問題へ。
   - **× のとき**：つまずきの型に合わせた一言（例「ひく数の符号を変えて、たし算にしたかな？」）が出て、**1回だけなおせます**。なおして正解なら **△**。
   - **2回目もまちがい**：正しい答えと**解き方の手順**（例：累乗を先に計算 → かけ算・わり算 → 答え）が出ます。
3. 10問おわると結果の画面。
   - ○・△・× の数と、問題ごとの「あなたの答え → 正しい答え」とつまずきの型。
   - **あなたのつまずき**：型の名前・回数・説明・実際にまちがえた例。
   - 「この型をふくしゅう（5問）」：その型のまちがいが起きる問題だけを5問出します。
   - 「図でたしかめる」：数直線ジャンプ・正負の数チップへのリンク（加法・減法の型のとき）。
- はじめの画面の「この端末のつまずき（さいきん100問）」からも、ふくしゅうを始められます。
- 「さいしょから」：同じレベルで新しい10問をやり直します（もういちど）。「けす」で1文字ずつもどせます（ひとつもどす）。

### 🖨 プリント（A4・20問＋答え）
- レベル（①〜⑤・ミックス）と**シード番号**をえらんで「印刷する」。1ページめが問題（月日・組・番・名前・点数の欄つき）、2ページめが答え（赤字）です。
- 同じレベル・同じシード番号なら、何度印刷しても同じ問題になります（右下にシード番号が入ります）。

## 先生モード（`?teacher=1`）

- 問題の画面の左下（スマホでは右上）に**答え**が出ます。「解き方 ▶」で手順が1.5秒ずつ順に出ます（電子黒板での説明用）。
- はじめの画面の「クラスのつまずきを黒板に出す」：**この端末で解いた記録**を集めて、大きな文字で出します。
  - 今日／この1週間／ぜんぶ を切りかえ。
  - 解いた問題の数・1回で正解した割合・つまずいた問題の数。
  - **多かったつまずき**：型ごとの回数の棒グラフ（多い順）、実際のまちがいの例（新しい2つ）、説明。
  - レベル別の「1回で正解した割合」。
  - 「この端末の記録をぜんぶ消す」（確認してから消します）。
- 1台の端末を回して使う／先生の端末で全体練習をする、などの使い方を考えています。ほかの端末の記録とはつながりません。

## 授業例（中1・正負の数の計算のまとめ）

1. **ふりかえり（5分）**：先生モードでレベル②を電子黒板に出し、全員で1問。まちがえやすい答え（例 (+3)−(−5) に −2）をわざと入れて、つまずきの一言を見せる。
2. **個人練習（15分）**：各自のタブレットで、自分に合うレベルの10問チャレンジ → 結果の「あなたのつまずき」から、ふくしゅう5問。
3. **共有（10分）**：先生の端末で集めた「クラスのつまずき」を黒板に出し、多かった型の例を1つ取り上げて、なぜその答えになるのかを話し合う（加減の型は数直線ジャンプ・正負の数チップで図にもどす）。
4. **家庭学習**：同じシード番号のプリントを配り、次の時間に同じ問題で答え合わせ。

## つまずき検知の一覧

1問ごとに「こうまちがえると、この答えになる」という数を先に計算しておき、生徒の答えがどれと同じかで型を決めます。上の型ほど先に当てはめます。

| 型の名前 | どんなまちがいか（例） | 出るレベル |
|---|---|---|
| −2² と (−2)² の取りちがえ | −3² を 9、(−3)² を −9 とした | ④ |
| 累乗をかけ算にした | 2³ を 6、(−3)² を −6 とした | ④ |
| 乗除の符号のきまり | (−4)×(−3) を −12、(−2)³ を 8 とした（③と、④の負の数の累乗） | ③④ |
| ひく数の符号を変え忘れた | (+3)−(−5) を −2、(−7)−(+6) を −1 とした（x−y を x+y にした） | ①②④ |
| 計算の順序 | 2+3×(−4) を −20（左から計算）、(−3+9)×2 を 15（かっこを無視） | ④ |
| 符号が同じなのに絶対値をひいた | (−5)+(−3) を −2 や 2 とした | ① |
| 符号がちがうのに絶対値をたした | (+3)+(−8) を −11 や 11 とした | ② |
| 項の符号の読みまちがい | 4−9+2 を 4−9−2 のように、どれか1つの項の符号を反対にして計算した | ⑤ |
| 符号を落とした（答えの符号がぎゃく） | 正しい答えの符号だけが反対（−7 を 7） | ①②④⑤ |
| 絶対値の計算ミス | 符号は合っているが、数がちがう（上のどれにも当てはまらない） | すべて |
| そのほか | 上のどれにも当てはまらない | すべて |

- 1問で2回まちがえたときは、2つの答えの型を両方記録します（同じ型は1回）。
- 「ふくしゅう」は、その型のまちがいが起きる問題だけを作って出します（「絶対値の計算ミス」「そのほか」は、まちがえたレベルから出します）。

## 正しさ・じっさいとのちがい

- 答えはすべて整数です。わり算は「商とわる数」を先に決めてから式を作るので、かならず割り切れます。④の答えは −100〜100 にしています。
- 計算は整数だけなので誤差はありません。プリント20問の答えも同じ計算で出しています。
- 同じ回の中で同じ式は出ません。さいきん解いた40問と同じ式も、なるべくさけます。
- つまずきの型は、答えの数から「たぶんこうまちがえた」と**推測**したものです。ちがう考え方で同じ数になることもあります（画面にも「※じっさいとのちがい」として書いています）。
- 指数は 2〜4、累乗の底は 2〜5 です。分数・小数の正負の数は出ません。

## 問題の作り方を変えるには（先生向け）

- `genL1`〜`genL5`（レベルごとの問題を作る関数）の `ri(1, 15)` などの数のはんいを変えると、数の大きさが変わります。
- つまずきの型の名前・一言・説明は `TYPES` にまとめてあります。
- 1回の問題数は `ROUND_N`（10）、ふくしゅうは `REVIEW_N`（5）、プリントは `PRINT_N`（20）です。
