# 🟨 さんすうボード⑨ かずのブロック

小学2〜4年向けの、**1・10・100・1000 のタイル**（十進位取りのブロック）を画面で動かすボードです。タイルを並べたり、ばらしたり、まとめたりして、数のしくみ（位取り・くり上がり・くり下がり）を目で確かめます。決まった問題や正解はありません。

- 「さんすうボード② かぞえぼう・タイル」をもとに、**タイルだけ**にして、次の機能を足しました（段階①）。
  - **しゅるいごとの いろ**（1＝きいろ・10＝あお・100＝オレンジ・1000＝みどり。1いろにも できる）
  - **タイルの上の数（ラベル）**：なし ／ 1こずつ ／ くっついた ものを まとめて
  - **ぜんぶの数**：かくす ／ ぜんぶで ／ くわしく（「1000が 1こ・100が 2こ…」）
  - **まとめる うごき**：10こが できあがりの形に ならんでから 1つのタイルになる
- 低学年で「自分で数える」学習をするときは ②、位取りや筆算の説明・確かめに使うときは ⑨、と使い分けます。

## 基本情報

- **ファイル**：`さんすうボード⑨ かずのブロック.html`。この1ファイルだけで動きます（ネット接続・外部ライブラリ・画像ファイルは不要）。
- **対応する機器**：タッチできる Chromebook（主に想定）、電子黒板、マウス・トラックパッド。
- **マルチタッチ**：指1本ずつ別々に追いかけるので、何人かで同時に動かせます。

## 部品

| タイル | 形 | いろ（しゅるいごと） |
|---|---|---|
| 1 | 正方形 1マス | きいろ |
| 10 | 1×10 の 細長い形（たて・よこ） | あお |
| 100 | 10×10 の 正方形 | オレンジ |
| 1000 | 100の板を10まい かさねた 立体 | みどり |

- 大きさのつり合いは正しい形です（10は1の10こ分、100は10の10本分）。
- **※じっさいとのちがい**：1000のタイルは、ボードに入るように **本当より小さく** かいています。小さくても1000だと分かるように「1000」の札を付けています。
- いろだけでなく、**形と大きさ** でも区別できます（色の見え方がちがう子にも分かるように）。
- タイルの中の線は5マスごとに太くして、5のまとまりが見えるようにしています。

## 使い方

| 操作 | どうなるか |
|---|---|
| 道具箱の上の **タブ**（🟦タイル・🔢カード） | 道具箱の中身を切りかえる |
| 道具箱を **タップ** ／ **引っぱる** | 1こ出る ／ すきな場所に置ける。「でる かず」5こ・10こ で 1のタイルを まとめて出せる |
| ボードの上のタイルを **タップ** | 10のタイルの向きが かわる（たて ⇔ よこ） |
| ボードの上のタイルを **長押し** | **ばらす**（10 → 1が10こ、100 → 10が10本、1000 → 100が10まい） |
| **🔗まとめる** で同じタイルを **10こ えらぶ** | 1こずつタップ、または ゆびで かこむ。10こ そろうと、**できあがりの形に ならんでから** 1つ上のタイルになる |
| **👁️ひょうじ** | ラベル・ぜんぶの数・タイルの いろ を えらぶ（下の表） |
| ごみばこ（右下）か道具箱にもどす | 消える |
| ✏かく・📏ちょくせん・🧽せんを けす・↩もどる・🖼はいけい・📷しゃしん・📂ひらく・🧹かたづける | ② と同じ |

### 👁️ ひょうじ

| えらぶもの | せんたくし | ようす |
|---|---|---|
| タイルの上の数 | **なし**（はじめ）／ **1こずつ** ／ **くっついた ものを まとめて** | まとめて：同じタイルが くっついて（16px より せまい すきまで）並んでいると、1つの札にまとめる。10を3本ならべると「30」、100を2まいで「200」 |
| ぜんぶの数 | **かくす**（はじめ）／ **ぜんぶで** ／ **くわしく** | ボードの下に「ぜんぶで 1234」。くわしく は「1000が 1こ　100が 2こ　10が 3こ　1が 4こ　→　ぜんぶで 1234」。いちばん上の くらいから1まで、**0こ の くらいも出す**（空位の0に気づけるように） |
| タイルの いろ | **しゅるいごとの いろ**（はじめ）／ **1いろ（あお）** | 1いろ は ② と同じ見た目 |

- **はじめは数を出していません**。自分で数えたあとに、先生が「ぜんぶで」を出して確かめる、という使い方を考えています。
- 1のタイルを12こ置くと「1が 12こ」と出るので、**まとめる（くり上がり）が必要なこと** に気づけます。
- ひょうじの選び方は、📷しゃしん・💾くばる・つづきから にも入ります。
- URL でも決められます：`?label=group&total=detail&color=one`（label は off・each・group、total は off・sum・detail、color は multi・one）。

## くらべる わく・あわせる わく・はいけい・先生用

② と同じです（🔢カード タブの くらべる わく・あわせる わく、くらいどりひょう 2〜4けた・1〜4だん、ほうがんし の「タイルの マス」で すいつく、📝もんだい・💾くばる）。

- ①②の画像を ⑨ で開くと「その ボードで ひらいてね」と出ます（箱の名前は `sansuset9-board`）。

## 授業例

**2年「1000までの 数」**
1. はいけいを くらいどりひょう（3けた）にして、100・10・1のタイルで 324 を作る。
2. 👁️ひょうじ →「くっついた ものを まとめて」で「300」「20」「4」と出し、324 ＝ 300＋20＋4 を確かめる。
3. 100を10まい まとめて1000にし、「100が10こで1000」を見る。

**2年「たし算の ひっ算」（くり上がり）**
1. くらいどりひょう（2けた・3だん）にし、38 と 25 をタイルで作る。
2. 1のタイルを答えのだんに集め、ぜんぶの数を「くわしく」にすると「1が 13こ」。10こを🔗まとめる で10にして十のくらいへ（くり上がり）。

**3年「大きい 数」・4年 のふり返り**
- 「1000が 2こ・100が 0こ・10が 5こ・1が 0こ」のように0のくらいがある数を作り、「くわしく」で 2050 と出るのを確かめる。

## しくみ（コードのつくり）

- 部品の表 `PIECES` の各タイルに `val`（あらわす数）を足しました。ラベル・ぜんぶの数はこの値で計算します。
- いろは表 `PALETTES`（`multi`・`one`）にあり、`svgTiles()`・`svgTile1000()` が 今の いろ `tileColors` で絵を作ります。いろを変えると `paintTiles()` で絵を作りなおし、ボード・道具箱をかきなおします（`setTileColors()`）。
- ラベルは `computeLabels()`、ぜんぶの数は `computeTotal()` で作り、`drawInfo()` で画面に、`drawInfoOn()` でしゃしんにかきます。タイルが動く・消えるたびに `scheduleInfo()` で1コマに1回だけ かきなおします。
- 「まとめて」のラベルは、同じ種類で、ふち（8pxずつ広げた四角）が重なるタイルを1つのまとまりにしています（`computeLabels()` の中）。
- まとめる うごき：`tieItems()` で、10このタイルを できあがりの形の中の場所（1→1れつ、10→となりあう10本、100→少しずつ重ねる）へ CSS の transition で動かし、0.43秒後に1つのタイルに取りかえます。取りかえたタイルは少し光ります（`.glow`）。
- 保存の中身 `stateData()` に `o: [ラベル, ぜんぶの数, いろ]` を足しています。

## 算数セットの入り口から開いたとき

- 「さんすうセット ていがくねん」からは `?low=1`、「算数セット 中高学年」からは `?high=1` をつけて開きます。
- 左上が「🏠 ボードえらび」になり、そのセットのページにもどれます。
- 保存は入り口ごとにべつです（キーの後ろに `-ていがくねん`・`-中高学年` がつく）。同じタブで2回目からは「つづきから？」を聞かずに続けます。
- しぼっている機能はありません（どちらの入り口でも、1〜1000のタイル・ひょうじ をすべて使えます）。

## これからの予定（段階②〜⑤）

1. **段階②** くらいどりひょうと小数：表の中で10こそろうと知らせる。「1」にするタイルを切りかえて、0.1・0.01 を表す。
2. **段階③** 筆算のわく（たし算・ひき算）：くり上がり・くり下がりを動きで見せる。
3. **段階④** かけ算の面積モデル（23×25 を4つに分ける）・わり算・約数。
4. **段階⑤** 100マスで小数・先生用のお題カード・タイルのロック。

## 動作確認の方法

1. Chrome で開き、4つのタイルをタップで出す・引っぱって置く・ごみばこで消す。
2. 長押しで ばらす、🔗まとめる で10こ えらんで まとめる（ならんでから1つになる）、もどるで もどることを確かめる。
3. 👁️ひょうじ で ラベル（なし・1こずつ・まとめて）、ぜんぶの数（かくす・ぜんぶで・くわしく）、いろ（2しゅるい）を切りかえる。
4. 📷しゃしん に ラベル・ぜんぶの数が入ることを確かめる。
