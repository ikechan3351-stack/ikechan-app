# 🕐 さんすうセット⑥ とけいと じかん

小学1〜2年向けの、**時計のはりを画面で動かすボード**です。算数セットの模型時計の代わりに使えます。決まった問題や正解はありません。はりを自分で動かし、「短いはりが…、長いはりが…だから○時○分（○分間）」と、**はりと目もりを指して説明する**ための道具です。

- 「さんすうセット①〜⑤」と同じつくりです。ペン・もどる・はいけい・📷しゃしん・先生用（もんだい・💾くばる）・📂ひらく は ①〜⑤ と同じ使い方です。
- 企画メモ：脳メモ `教材開発/企画/2026-11-16_さんすうセット⑥ とけいと じかん.md`
- 単元：1年「とけい（なんじ・なんじはん・なんじなんぷん）」、2年「時こくと時間」。

### 時計フラッシュカードとの使い分け

| 場面 | 使うもの |
|---|---|
| はじめての1時間（回す感覚をつかむ） | 本物の模型時計 |
| 考えを説明する・友だちと比べる | **⑥ とけいと じかん** |
| 読みの練習（答えあり） | 時計フラッシュカード |

## 基本情報

- **ファイル**：`さんすうセット⑥ とけいと じかん.html`。この1ファイルだけで動きます（ネット接続・外部ライブラリ・画像ファイルは不要）。
- **対応する機器**：タッチできる Chromebook（主に想定）、電子黒板、マウス・トラックパッド。
- **マルチタッチ**：時計2つなら、2人が同時にそれぞれの時計を回せます（1つの時計は1本の指だけ）。

## アプリ全体のきまり

**時こくの答えは、ふだん見せません。** 子どもが自分で読みます。確かめたいときだけ「？」カードをめくります。

- **はりを動かすと、カードは「？」にもどります**。「めくる → ちがう → 動かす → めくる…」の当てっこにならないようにするためです。「読んで、きめてから めくる」を授業の約束にしてください。
- 正解・まちがいの判定はしません。

## 時計の見た目

| もの | 見分けるための工夫 |
|---|---|
| みじかい はり | **あお**・ふとくて みじかい |
| ながい はり | **あか**・ほそくて ながい |
| ふんの すうじ（5・10・15…） | ながい はりと同じ **あか** で、文字盤の外に出る（ながい はりで読む数だとわかるように） |
| 目もり | 1ぷんごと。5ふんごとは太い線 |

- 色だけでなく、はりの長さ・太さでも見分けられます。ことばカードの「みじかい はり」「ながい はり」も、はりと同じ色です。

## 使い方

| 操作 | どうなるか |
|---|---|
| 時計を **ひっぱる** | 時計のどこをさわっても、近いほうのはりが回る（中心に近く、みじかい はりの向きなら みじかい はり。それ以外は ながい はり）。ながい はりは 1ぷんの目もりにすいつく |
| ながい はりを回す | **みじかい はりも少しずつ動く**（1ぷんで 0.5ど）。12をこえると「じ」が1つ進む・もどる |
| みじかい はりを回す | ながい はりが12倍の速さで回る（本物の時計のつまみと同じ） |
| **ー5ふん・ー1ぷん・＋1ぷん・＋5ふん** | ひっぱるのが苦手な子も、確実に合わせられる |
| **「？」カード** をタップ | 「3じ 50ぷん」のようにめくれる。もう一度タップでかくれる |
| 🔢 **ふんの すうじ** | 文字盤の外に 0・5・10…55 を出す・けす（わからないときのヒント） |
| 道具箱の **ことば・すうじ カード** | タップで1まい出る（時計にかさならない場所）。ひっぱって時計のそばに置き、説明に使う。ごみばこか道具箱にもどすと消える |
| ✋うごかす／✏かく | ①〜⑤と同じ。かく のあいだは、はりは動かない |
| 🧹 かたづける | カードとペンの線を消す。**時計はそのまま** |

- 読み方：0ふんは「3じ」、1・3・4・6・8・10…は「ぷん」、2・5・7・9は「ふん」と出ます。12時台は「12じ」です。

## がくねん（道具箱のいちばん上）

| がくねん | 時計 | ことばカード |
|---|---|---|
| 1ねん | 1つだけ | みじかい はり・ながい はり・じ・ふん・ぷん・はん・ちょうど・まだ・すぎ |
| 2ねん | **🕐1つ／🕐🕐2つ** を上の列でえらべる。2つのときは左「はじめ」・右「おわり」 | 1ねんのことばに、はじめ・おわり・から・まで・ふんかん・ぷんかん・じかん を足す |

- 2つにすると、おわりの時計は はじめの時計と同じ時こくから始まります（そこから ながい はりを回して「何分間」を数える）。
- `?grade=2` のように URL で決めて配れます。💾くばる画像にも学年が入ります。

## 先生用（`?teacher=1`）

| ボタン | できること |
|---|---|
| ⚙️ せってい | 下の3つをきりかえる（💾くばる画像に入る） |
| 📝 もんだい | もんだいカードを作る（子どもは消せない） |
| 💾 くばる | いまのボード（時計の時こく・時計の数・学年・せってい・カード・線・はいけい）が入った画像を作る |

**せってい**

| こうもく | いっしょ・だす（ふだん） | べつべつ・ださない |
|---|---|---|
| はりを いっしょに うごかす（`?link=0`） | 本物の時計と同じ | **2本のはりが別々に動く**。「3じ50ぷんなのに みじかい はりが 4の上」のような**まちがいさがし**の問題を作れる。左上に「⚠ はりが べつべつに うごくよ」と出て、つじつまの合わない時計の「？」カードは「よめない とけい だよ」になる |
| こたえカード（`?card=0`） | 「？」カードを出す | 出さない（友だちとの話し合いで確かめさせたいとき） |
| 「ふんの すうじ」ボタン（`?minnum=0`） | 子どもが出し入れできる | ボタンごと出さない（練習の後半・まとめ） |

- はじめの時こくは、時計のはりを動かしてから 💾くばる で決めます。
- 「べつべつ」から「いっしょ」にもどすと、みじかい はりに いちばん近い「じ」に合わせます。もどる（↩）の記録はリセットされます。
- URL に `grade`・`clocks`・`link`・`card`・`minnum` のどれかが付いているときは、「つづきから」をきかずにその設定で始めます。

## 授業での使い方（例）

| 順 | 学年 | お題 | ①予想 | ②操作 | ③結果 | ④考える |
|---|---|---|---|---|---|---|
| 1 | 1年 | 何時何分かな | 自分で読む | 先生が配った時計を見る・指す | ？カードで確かめる | 短いはり・長いはりを指して理由を言う |
| 2 | 1年 | 時こくを作ろう | どこにはりが来る？ | 長いはりを回す（短いはりも動く） | ？カードで確かめる | 3時50分の短いはりは、なぜ4の手前？ |
| 3 | 1年 | まちがいさがし | どこがおかしい？ | せってい「べつべつ」の時計を見る・直す | 「よめない とけい」→直してめくる | 3時50分を4時50分と読むまちがいを説明 |
| 4 | 2年 | 何分間かな | 何分くらい？ | 2つの時計に はじめ・おわりを作る | 目もりを数える | ちょうど（9時）で区切ると数えやすい |

- 使う場面：展開（考えを説明・共有）で10〜15分。📷しゃしん → ロイロに提出 → 2〜3人の板を電子黒板で比べる。
- 例（1年）：「3じ50ぷんを作ろう」→ 長いはりを回す → 短いはりを囲んで「まだ4じゃない」と書きこむ → ？カードで確かめる → 提出。「4じ50ぷん」と作った子の板と並べて、短いはりの位置を比べる。
