# 🪙 さんすうセット③ おかね

小学1〜3年向けの、**お金（硬貨・お札）を画面で動かすボード**です。算数セットのお金の代わりに使えます。決まった問題や正解はありません。**同じ金額でも、いろいろな出し方がある**ことを、くずす・まとめる（両替）とてんびんで確かめながら見つけるための道具です。

- 「さんすうセット② かぞえぼう・タイル」をもとにしています。ペン・もどる・はいけい・しゃしん・先生用（もんだい・くばる）・ひらく は ①② と同じです。
- 企画メモ：脳メモ `教材開発/企画/2026-11-12_さんすうセット③ おかね.md`
- 問題を出して答え合わせをする練習用の教材は「おみせやさんで おかいもの」「おかいもの」「お金天秤」です。③は、自分の出し方を表して説明するための自由なボードです。

## 基本情報

- **ファイル**：`さんすうセット③ おかね.html`。この1ファイルだけで動きます（ネット接続・外部ライブラリ・画像ファイルは不要）。
- **対応する機器**：タッチできる Chromebook（主に想定）、電子黒板、マウス・トラックパッド。
- **マルチタッチ**：指1本ずつ別々に追いかけるので、何人かで同時に動かせます。

## アプリ全体のきまり

**金額の数字（合計）は、どこにも出しません。** 子どもが自分で数えます。アプリが出すのは、確かめるための手がかりだけです。

- まとめる：ちょうどのときだけまとまり、ちがうときは「おおすぎるよ／たりないよ」とだけ伝えます。
- てんびん：かたむき（3通り）と、つりあったときの「＝」だけを見せます。
- くずす：メニューにはお金の絵だけを出し、何まいになるかは書きません。

## がくねん（道具箱のいちばん上）

学年を選ぶと、道具箱に出るお金のはんいが変わります。ボードの上のお金は、学年を変えてもそのまま残ります。

| がくねん | 出るお金 |
|---|---|
| 1ねん | 1円・5円・10円 |
| 2ねん | 1円・5円・10円・50円・100円・500円 |
| 3ねん | 2ねんのお金と、1000円・5000円・10000円 |

- はじめは2ねんです。`?grade=1` のように URL で決めて配れます。💾くばる画像にも学年が入ります。

## お金の見た目

「おみせやさんで おかいもの」とそろえています。実物そっくりにはせず、色だけでなく形でも見分けられるようにしています。

| おかね | 見分けるための工夫 |
|---|---|
| 1円 | 白っぽい銀・いちばん小さい |
| 5円 | 金・**あな** |
| 10円 | 銅（茶）・ふちはなめらか |
| 50円 | 銀・**あな＋ふちのギザギザ** |
| 100円 | こい銀・ふちのギザギザ |
| 500円 | 金・いちばん大きい・ふちが**二重** |
| 1000円札 | 青・まるいまど1つ |
| 5000円札 | むらさき・まるいまど2つ |
| 10000円札 | オレンジ・ななめのしま |

- お札は、左上のすみにも金額を入れています。おさらの上で重なっても、何のお札か分かるようにするためです。

## 使い方

| 操作 | どうなるか |
|---|---|
| 道具箱の上の **タブ**（🪙おかね・🍽おさら・🔢カード） | 道具箱の中身を切りかえる |
| 道具箱を **タップ** | 1まい出る（左上から順に、あいている場所に並ぶ） |
| 道具箱から **引っぱる** | すきな場所に置ける |
| ボードの上のものを **引っぱる** | 動く。さわったものは一番前に出る |
| お金を **長押し** | オレンジのわ（🔄）がいっぱいになると「**なにに くずす？**」のメニューが出る。お金の絵をえらぶと、その場でくずれて広がる |
| **🔗まとめる** | 左の道具箱が「まとめるパネル」になる。① なにに まとめるか えらぶ → ② お金を **タップ**（番号がつく）か **ゆびで かこむ** → ③ **🔗まとめる** をおす |
| ごみばこ（右下）か道具箱にもどす | 消える |
| ✏かく・🧽せんを けす・↩もどる・🖼はいけい・📷しゃしん・📂ひらく・🧹かたづける | ①② と同じ |

### くずす（長押し）

1つ下のお金の組み合わせにくずします。今の学年のはんいにないお金にはくずしません。

| お金 | くずし先 |
|---|---|
| 5円 | 1円 |
| 10円 | 5円 ／ 1円 |
| 50円 | 10円 |
| 100円 | 50円 ／ 10円 |
| 500円 | 100円 |
| 1000円 | 500円 ／ 100円 |
| 5000円 | 1000円 |
| 10000円 | 5000円 ／ 1000円 |

- 1万円を100円玉までくずしたいときは、1000円にくずしてから、もう一度くずします（一度に100まい出すと、ボードにのりきらないため）。
- おさら・てんびんの上でくずすと、その中にのったまま並びます。

### まとめる（両替）

- **ちがう種類をまぜてもよい**です（50円＋10円×5 → 100円）。
- 合計がちょうどえらんだお金になるときだけ、まん中にあつまって1まいになります。
- ちがうときは「**おおすぎるよ**」か「**たりないよ**」とだけ出ます。何円ちがうかは言いません（自分で数えなおすため）。
- 先に「なにに まとめるか」をえらぶのは、当てずっぽうに囲むのではなく、「100円になるかな？」と予想してから確かめるためです。
- まとめるモードのあいだは、お金は動かせません（「✋うごかす」にもどすと動かせます）。

## おさら（🍽 タブ）

- **見出しつきのおさら**（お金の絵と「100円」）と、**むじのおさら**があります。
- お金をおさらの上ではなすと、おさらの中に、のせた順に **5まいずつ** 並びます。入りきらないときは、だんを少し重ねます。
- **ちがう種類のお金も入ります**（はじきません）。入れまちがいは、📷しゃしんで先生が見つけて、話し合いの材料にします。
- おさらを動かすと、のっているお金もいっしょに動きます。ごみばこに入れると、中のお金もいっしょに消えます。
- ねらい：「ばらばら数え型」（種類をまぜたまま数え、とちゅうでわからなくなる）の対策です。同じ種類をそろえて、大きいお金から数えられるようにします。

## てんびん（🍽 タブ）

- ボードに **1つだけ** 置けます。
- 左右のさらにお金をのせると、**金額の大きいほうが下がります**。かたむきは「ひだりが下・まっすぐ・みぎが下」の **3通りだけ** です（差が大きくても角度は同じ。角度からだいたいの差を当てられないようにするため）。
- 左右の金額が同じになると、まん中に **「＝」** が出ます（色だけで知らせないため）。
- のせたお金は、さらといっしょに上下します。
- **※じっさいとのちがい**：本物のてんびんは重さでかたむきますが、このてんびんは **金額で** かたむきます（本物のお金は、重さと金額が比例しません。1円玉は1g、10円玉は約4.5g）。画面のてんびんの下にも書いています。「お金天秤」と同じきまりです。

## はいけい（🖼 ボタン）

② と同じです（むじ・ほうがんし・さんすうノート・くらいどりひょう・ふたつに わける・がぞう、紙の色3つ）。ちがうところは次のとおりです。

- くらいどりひょうに **5けた（万・千・百・十・一）** を足しました（3年の1万円用）。
- 方眼紙の「タイルのマス」はありません。はじめの大きさは「ふつう」です。
- URL の例：`?bg=place&cols=3&rows=2`（くらいどりひょう 3けた・2だん。cols は 2〜5）、`?bg=split&dir=lr`（ふたつに わける）、`?grade=1`。

## 先生用（`?teacher=1`）

①② と同じです（📝もんだい・💾くばる）。くばる画像には、お金・おさら・てんびん（のっているお金も）・学年が入ります。

- ①②③の画像は区別しています。③で①②の画像を開くと「そちらで ひらいてね」と出ます。

## 授業モデル（1回の授業では1〜2つ）

| 順 | お題 | ①予想 | ②操作 | ③結果 | ④考える |
|---|---|---|---|---|---|
| 1 | **いくらあるか数える** | 「いくらかな？」 | ばらまかれたお金をおさらでそろえる | 大きい順に数えて書きこむ | そろえると数えやすい |
| 2 | **いろいろな出し方** | 「何通りできそう？」 | 同じ金額を別の出し方で作る | まとめる・てんびんで同じか確かめる | 友だちと比べて、きまりを見つける |
| 3 | **いちばん少ないまい数** | 「何まいでできる？」 | まとめる（両替）でまい数をへらす | 出し方とまい数を書きこむ | 大きいお金を使うとへる |

**例：2年「1000までの数」（10〜15分）**
1. 先生が「120円を いろいろな 出し方で 作ろう」と出す。
2. 子どもは100円・50円・10円で作り、🔗まとめるで「100円になるか」を確かめる。
3. てんびんの左右に2つの出し方をのせて、「＝」になるか確かめる。
4. ✏ペンで「100円と10円が2まいで120円」と書き、📷しゃしんでロイロに提出。電子黒板で比べる。

**例：1年「いくらあるかな」**
- 先生がお金をばらまいたボードを💾くばるで配る（`?grade=1`）。子どもは10円・5円・1円のおさらを出してそろえ、数えて書きこむ。

- はじめての時間は、タップ・長押し（くずす）・まとめるの手順を、先生が全員の前で1回やってみせるとスムーズです。
- 導入は本物のお金にさわり、そのあと③で考えを表して比べ、練習は「おみせやさんで おかいもの」などで行う、という使い分けがおすすめです。

## しくみ（コードのつくり）

- お金の絵は `moneyBody()`、大きさは `moneySize()` です。色・あな・ふちの表は `COIN` です。
- 部品の表 `PIECES`：お金は `m1`〜`m10000`（`yen` に金額）、おさらは `p1`〜`p10000` と `p0`（むじ）、てんびんは `tenbin` です。
- 学年ごとのお金は `GRADES`、くずし先は `BREAK` の表です。ここを書きかえると、はんいやくずし方を変えられます。
- **のる しくみ**：お金をおさら・てんびんの上ではなすと、お金に `hold`（のっている部品の id）・`side`（てんびんの左右）・`ord`（のせた順）が入ります（`snapItem()`）。並べ方は `relayout()` で、おさらは上から5まいずつ、てんびんはさらの上から積みあげます（`flowRows()`）。
- **てんびん**：のっているお金の金額を左右で比べて `tilt`（1・0・-1）を決め、うで・さらの向きを `setTenbinLook()` で CSS の transform で動かします。しゃしんのときは `svgTenbin(tilt, eq)` で、かたむいた絵をかきなおします。
- **くずす**：長押し → `openBreakMenu()` → `splitItem(it, to, n)`。
- **まとめる**：`tieTarget`（なにに まとめるか）と `picked`（えらんだお金）を `commitTie()` でくらべます。
- 盤面を画像に入れるしくみは ①② と同じで、箱の名前だけ `sansuset3-board` にしています。おさら・てんびんにのっているお金は、部品の番号もいっしょに入れます。

## 動作確認の方法

1. Chrome で開き、学年を切りかえて、道具箱のお金が変わることを確かめる。
2. お金をタップで出す、引っぱって置く、ごみばこで消す。
3. 長押しでメニューが出る、えらぶとくずれる、↩もどるで もどることを確かめる。
4. 🔗まとめるで、なにに まとめるかをえらび、タップ・かこみでえらぶ。ちょうどでまとまる、多い・少ないで「おおすぎるよ／たりないよ」が出ることを確かめる。
5. おさらにのせると5まいずつ並ぶ、おさらを動かすと中も動く、ちがう種類も入ることを確かめる。
6. てんびんの左右に「100円」と「50円＋10円×5」をのせて「＝」が出る、1まい取ると かたむくことを確かめる。
7. 📷しゃしん・💾くばる→📂ひらく で、かたむき・のっているお金がそのまま残ることを確かめる。
8. Chromebook 実機で、指の長押しでメニューが出るか、小さい1円玉をつかめるかを確かめる。
