# たてと よこで 分数のかけ算

小学6年生の算数「分数×整数、分数÷整数」「分数×分数」（東京書籍 新しい算数 6年）で使う教材です。1m²の正方形を分けた**面積図**で、次のことを体験します。

- 分数×整数：**分母はそのままで、分子に整数をかける**
- 分数÷整数：**分子はそのままで、分母に整数をかける**
- 分数×分数：**分子どうし・分母どうしをかける**（1m²が 分母×分母 こに分かれ、ぬったマスが 分子×分子 こ）
- **とちゅうで約分** すると計算がらくになること
- 1より小さい数をかけると、答えは**かけられる数より小さくなる**こと
- **逆数**（かけて1になる数。分子と分母を入れかえた数。整数は分母が1の分数と考える）

分数÷分数は 6-04 のアプリであつかうので、ここでは入れていません。

## 基本情報

- **ファイル**：`たてと よこで 分数のかけ算.html`。共通ファイル `math-render.js`（分数の表示と Fraction による正確な計算）・`worksheet.js`・`worksheet.css` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。面積図はすべて SVG でかいています。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」（6年）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。ボタンは48px以上。スマホのたて向きでも画面がはみ出しません。
- **漢字**：分数・分子・分母・整数・約分・逆数・面積 などにふりがなをつけています。「せってい」で消せます。
- **保存**：ワークシートと「せってい」を、このブラウザの localStorage（キー：`ikechan-math-たてと よこで 分数のかけ算`）に保存します。もんだいの成績は保存しません。

## 3つの画面

### 🎨 かけて わって（分数×整数・分数÷整数）

- 「✖ 分数×整数」：「1dLで a/b m² ぬれるペンキ。k dLでは？」。1m²の正方形をたてに b つに分けた細長いマス（1/b m²）を、1dL分ずつ色と模様をかえてぬります（オレンジ・ぬりつぶし／青・しま／緑・点／むらさき・こうし…）。図の下に「1/b m² が a×k こ」と出ます。
- 「➗ 分数÷整数」：「k dLで a/b m² ぬれるペンキ。1dLでは？」。a/b m²（オレンジ）を青い点線で横に k つに分け、1dL分を青・しまで光らせます。1m²が b×k こに分かれ、1dL分はそのうち a こ。分子が k でわりきれるときは「(a÷k)/b としても同じ大きさ」も出ます。
- 分子・分母・整数は −・＋ か数の入力で変えます（分母2〜9、分子は分母より小さい数、整数は×が1〜6、÷が2〜5）。式は「a/b × k ＝ (a×k)/b ＝ 答え」の形で、整数を青い字にして、どこにかかるかを見せます。約分できるときは約分した答えも出します。
- ちがう式を3つためすと、きまりのまとめ（▲/■×●＝(▲×●)/■ など）が出ます。

### 🟧 ぬって かさねて（分数×分数・逆数）

- **分数×分数**：たて a/b m、よこ c/d m の長方形を、1m²の正方形の上にオレンジでぬります（長さは2mまで。分母を1にすると整数）。1mをこえるときは、1m²の正方形が4つの図になります。
- **とちゅうで約分**：式の (a×c)/(b×d) の数がボタンになっていて、分子の数と分母の数を1つずつタップすると、公約数でわって約分します（もとの数に線を引き、上に新しい数）。約分できない組は「約分できないよ」と出ます。「ひとつ もどす」で約分を1つずつ取り消せます。
- **答えの大きさ**：かけられる数（オレンジ）と答え（緑・点）を帯でくらべ、「かける数が1より小さい → 答えはかけられる数より小さくなる」を出します。
- **逆数**：分数カードを「🔄 ひっくり かえす」と分子と分母が入れかわり、「3/4×4/3＝(3×4)/(4×3)＝1」の式と、ぬったマスがちょうど1m²分になる面積図が出ます（長さが2mをこえる数は図なし）。見つけた逆数を3つためるとまとめが出ます。

### ✏️ もんだい

5種類がまざって出ます（5問なら1つずつ、10問なら2つずつ。「せってい」でえらべます）。

| 種類 | 例 | 答え方 |
|---|---|---|
| 分数×整数 | 3/5×6 | 分子・分母のわく（2回まで） |
| 分数÷整数 | 2/3÷3 | 分子・分母のわく（2回まで） |
| 分数×分数 | 4/9×3/8（とちゅうで約分できる組が多め） | 分子・分母のわく（2回まで） |
| 逆数 | 2/3、5、2と2/5 | 分子・分母のわく（2回まで） |
| 答えの大きさ | 13/7×1/4 は 13/7 より大きい？小さい？ | 2つからえらぶ（1回） |

- 答えは分子・分母のわくに数字ボタンで入れます。整数のときは分母を空けます。1より大きい答えは仮分数で入れます（帯分数のわくはありません）。PCはキーボードの数字・Backspace・Enter、`/` か Tab で分子⇔分母。
- 大きさは合っていても約分していないときは「約分して入れよう」と出し、まちがいの回数に数えません。
- 「💡 ヒント」で考え方が出ます。

## つまずき検知

| 型の名前 | 見つけ方 | 例 | 出す声かけ |
|---|---|---|---|
| 分母にも かける | 分数×整数で、もとの分数と同じ大きさの答え（分母にもかけた）を入れた | 2/5×3 → 6/15 | 1/□ の小さいマスが何こ分かを考える。マスの大きさ（分母）はかわらない |
| わるのに 分子に かける | 分数÷整数で、分子に整数をかけた答えを入れた | 2/5÷3 → 6/5 | ÷整数は1つのマスをさらに小さく分けること。分母に整数をかける |
| かけると いつも 大きく なる | 1より小さい数をかけるのに「大きくなる」をえらんだ | 13/7×1/4 → 大きくなる | 1より小さい数をかけると小さくなる。1/2をかけるのは半分にすること |

- 見つけた型は「あなたの つまずき」として出し、次にその型の「にた もんだい」を1問足します。
- 終わりの画面に型ごとの回数を出し、「🎨 かけて わって」または「🟧 ぬって かさねて」へもどるボタンを出します。

## 先生モード（アドレスの最後に `?teacher=1`）

- かけて わって：「▶ じどうで ためす」で、整数を順にかえて見せます。
- ぬって かさねて：「▶ じどうで 約分」で、とちゅうの約分を順に見せます。
- もんだい：「💡 こたえ」。ワークシートに、先生用のヒントと解答例が出ます。

## 授業での使い方の例

1. **分数×整数（1〜2時間）**：「かけて わって」の×で、1dL目・2dL目…の色を数えさせ、分子にかかることを見つける → 3つためしてまとめ。
2. **分数÷整数（1〜2時間）**：÷で、オレンジを k つに分けたときのマスの大きさを考えさせる → 分子がわりきれるときの別の考え方も確かめる。
3. **分数×分数（2〜3時間）**：「ぬって かさねて」で、1m²が何マスに分かれ、何マスぬったかを数える → とちゅうで約分 → 答えの大きさ。
4. **逆数（1時間）**：カードをひっくり返して、かけて1になることを面積図で確かめる。
5. **まとめ**：「もんだい」で練習し、つまずきの型をふりかえる。

## 正しさと、じっさいとのちがい

- 分数の計算は `math-render.js` の Fraction で正確に行っています（小数を使わないので誤差は出ません）。
- 式のとちゅうは約分しないで見せ（例：6/12）、そのあとに約分した答えを出します。
- ペンキは、どこも同じあつさでぬれるものとしています。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| 1dL目・2dL目… | オレンジ・青・緑・むらさき… | ぬりつぶし・しま・点・こうし の模様 |
| ÷整数の 1dL分 | 青 | しま模様、「1dL」の文字 |
| かけられる数／答え（大きさくらべ） | オレンジ／緑 | ぬりつぶし／点模様、文字 |
| 約分した数 | 赤むらさき | もとの数に打ち消し線、上に新しい数 |
| 正解／まちがい | 緑／赤むらさき | ◎・✖・△ の記号 |
