# かぞえて ちかづけて およその面積

小学6年生の算数「およその面積と体積」（東京書籍 新しい算数 6年 142〜146ページ）で使う教材です。池や島のようなまがった形の面積を、次の2つの方法で見つもります。

- **方眼で数える**：ぜんぶ入るマス ＋ かかっているマス × 1/2（× 1マスの面積）。方眼をこまかくすると、ほんとうの面積に近づく
- **知っている形に近づける**：三角形・台形・平行四辺形・円とみて、公式で計算する
- **およその体積**：身のまわりの物を、直方体・円柱とみて計算する

## 基本情報

- **ファイル**：`かぞえて ちかづけて およその面積.html`。共通ファイル `math-render.js`・`worksheet.js`・`worksheet.css` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。形・方眼・立体はすべて SVG でかいています（物の絵は絵文字）。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」（6年）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。点のドラッグは pointer events でマウスでもタッチでも動きます。ボタンは48px以上。スマホのたて向きでも画面がはみ出しません。
- **漢字**：面積・体積・形 などにふりがなをつけています。「せってい」で消せます。
- **保存**：ワークシートと「せってい」を、このブラウザの localStorage（キー：`ikechan-math-かぞえて ちかづけて およその面積`）に保存します。もんだいの成績は保存しません。

## 3つの画面

### 🔲 方眼で かぞえよう

- 形は3つ（ひょうたん池・ほし島・はっぱ池。どれも作った形で、実在の場所ではありません）。12cm×9cm の方眼の上に出ます。
- マスをタップするたびに「なし → ぜんぶ入る（緑・ぬりつぶし）→ かかっている（黄・しま）→ なし」とかわります。「🤖 アプリが 分ける」で、アプリが1段ずつ分けます（マスの中に64この点をとって調べます）。
- 「およその面積は？」に、ぜんぶ入るマス ＋ かかっているマス×1/2 を計算して入れます。
- 「こまかく（1マス＝0.5cm）」では1マスが0.25cm²。マスが多いので「アプリが分ける」を使います。マスの数は合っていて ×0.25 をわすれたときは、それを教えます。
- 2つの方眼で正解すると、見つもり・「コンピュータで計算した面積」・ずれ（％）が表にならび、「方眼をこまかくすると、ほんとうの面積に近づく」とまとめが出ます。
- 「🗺️ 地図」をONにすると、1cm＝1km として km² で考えます。

### 📐 形に ちかづけよう

- **およその面積**：池や島の上に、三角形・台形・平行四辺形・円のどれかをオレンジの点線で重ね、●の点をドラッグして合わせます（「目もりに すいつく」で0.5cmごと、OFFで0.1cmごと）。底辺はいつも水平にし、高さの線（青い点線）も出すので、方眼から長さを読みとれます。
- 公式と長さが出るので、「面積は？」に計算した答えを入れると、ほんとうの面積とのずれ（％）が出ます（10％以内なら「よく合っているね」）。
- **およその体積**：バッグ・おべんとう箱（直方体）、かんづめ・ホールケーキ（円柱）。だいたいの長さを見ながら、スライダー（数の入力つき）で青い立体を合わせると、体積が cm³ と L で出ます。長さが1cm以内で合うと「ぴったり」。

### ✏️ もんだい

5種類がまざって出ます（5問なら1つずつ、10問なら2つずつ。「せってい」でえらべます）。

| 種類 | 例 | 答え方 |
|---|---|---|
| 方眼で 数える | マスを分けた図。ぜんぶ入る8こ・かかっている30こ → およそ何cm²？ | 数字ボタン（2回まで） |
| 近い 形 | でこぼこの池の図を見て、三角形・台形・平行四辺形・円からえらぶ | 4つからえらぶ（1回） |
| 公式で 計算 | 台形とみると 上底約2m・下底約7m・高さ約6m | 数字ボタン（2回まで） |
| 地図で 見つもる | 1マスが たて・よこ 2〜5km、ぜんぶ入るマスとかかっているマスの数 | 数字ボタン（2回まで） |
| およその 体積 | かばんを直方体、コップを円柱とみる | 数字ボタン（2回まで） |

- 数字ボタンには小数点もあります。PCはキーボードの数字・「.」・Backspace・Enter も使えます。
- 答えには式のとちゅうも出します（例：(7＋8×1/2)×5×5＝11×25＝275）。

## つまずき検知

| 型の名前 | 見つけ方 | 例 | 出す声かけ |
|---|---|---|---|
| かかっている マスの 数えまちがい | かかっているマスを1と数えた／数えなかった答え（方眼で数える画面・方眼と地図の問題） | 8＋30＝38 | かかっているマスは1/2マスと考える |
| 公式の ÷2 わすれ | 三角形・台形で2でわらなかった答え（形に近づける画面・公式の問題） | (2＋7)×6＝54 | 三角形・台形はさいごに ÷2 |
| 1マスの 面積の かんちがい | 地図で、マスの数に1辺の長さをかけた／1マスの面積をかけなかった | 1マス5km で ×5 | 1マスの面積は 5×5＝25km²。長さと面積を区別する |

- 見つけた型は「あなたの つまずき」として出します。もんだいでは、次にその型の「にた もんだい」を1問足します。
- 終わりの画面に型ごとの回数を出し、「🔲 方眼で かぞえよう」または「📐 形に ちかづけよう」へもどるボタンを出します。

## 先生モード（アドレスの最後に `?teacher=1`）

- 形に ちかづけよう：「💡 こたえ」で、いまの形の面積の計算を出します。
- もんだい：「💡 こたえ」。ワークシートに、先生用のヒントと解答例が出ます。

## 授業での使い方の例

1. **方眼で数える（1時間）**：「方眼で かぞえよう」で、まず1cm方眼で自分でマスを分けて見つもる → 0.5cm方眼に切りかえ、見つもりがほんとうの面積に近づくことを表で確かめる。
2. **形に近づける（1時間）**：「形に ちかづけよう」で、同じ池を三角形・台形・円などに近づけて見つもり、どの形がよく合うか話し合う → 地図（km²）の見つもり。
3. **およその体積（1時間）**：身のまわりの物を直方体・円柱とみて体積を見つもる → 「もんだい」で練習し、つまずきの型をふりかえる。

## 正しさと、じっさいとのちがい

- 「コンピュータで計算した面積」は、形のふちを240この点でつないだ多角形の面積（座標から計算する公式）です。ほんとうのまがった形の面積とのちがいは、とても小さいです。
- マスの分け方は、マスの中に64この点をとって、ぜんぶ入るか・少しでも入るか（またはふちが通るか）で決めています。
- 池や島、物の長さは作ったもので、実在の場所や商品ではありません。円周率は3.14。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| ぜんぶ入るマス／かかっているマス | 緑／黄 | ぬりつぶし／しま模様、表の文字 |
| 池や島／重ねる形 | 青や緑／オレンジ | 実線／点線、●の点 |
| 物／重ねる立体 | 赤・黄など／青 | 絵文字と角のまるい形／線だけの見取図（見えない線は点線） |
| 正解／まちがい | 緑／赤むらさき | ◎・✖・△ の記号 |
