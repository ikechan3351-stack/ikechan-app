# 一次関数の実験室（測定値から式を見つけて、予測する）

中学2年「一次関数の利用」のアプリです。ばね・ろうそく・水温・電車や歩く速さの実験をして、測定値（*x*, *y*）を表とグラフにためます。測定値は少しばらつくので、点の真ん中を通る直線を手で引き（直線に近似する）、その式で「まだはかっていない値」を予測し、実験で確かめます。

## 基本情報

- **ファイル**：本体 `一次関数の実験室.html`、共通部品 `math-render.js`・`graph-engine.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中2）から開けます。
- **画面のならび**：広い画面は 左＝実験・中央＝グラフ・右＝直線と予測 の3列。タブレットは2列（下に直線と予測）、スマホは1列。
- **URL の設定**
  - `?teacher=1` … 先生モード（本当のきまり・お手本の直線・予測の答え・ワークシートのヒントと解答例）
  - `?seed=1234` … 実験番号 1234 で開く（クラス全員が同じ測定値になる）
  - `?ws=1` … ワークシートをひらいて開く

## 実験

| 実験 | *x* | *y* | 種類・条件 | 本当のきまり |
|---|---|---|---|---|
| 🌀 ばね | おもりの重さ（g）0〜200 | ばねののび（cm）／ばねの長さ（cm） | ばねA・B・C | のび：*y*＝0.2*x*・0.1*x*・0.05*x*（比例）。長さ：もとの長さ 10cm をたす |
| 🕯️ ろうそく | 燃やした時間（分）0〜70 | ろうそくの長さ（cm） | 細い（12cm）・太い（15cm） | *y*＝−0.4*x*＋12、*y*＝−0.25*x*＋15（燃えつきたら 0cm） |
| 🌡️ 水温 | 加熱した時間（分）0〜20 | 水温（℃） | 水 100・200・400mL × 室温 18・28・10℃ | *y*＝8*x*・4*x*・2*x*＋室温（100℃でふっとう） |
| 🚶 電車・歩く速さ | 出発してからの時間（分） | 家からの道のり（m） | 歩く・自転車・電車 × 家から／600m の公園から | *y*＝80*x*・240*x*・1200*x*（＋600） |

実験は、ファイルの中の `EXPS` に1つ足すとふえます（傾き・切片・ばらつきの大きさ・問題の文を書く）。

## 使い方

### 左：実験
- スライダーか数の入力で *x* を決めて「📏 はかる」。実験のようすが動いて、測定値が表に1行足されます（同じ *x* は3回まで）。
- 「📋 まとめて はかる」：決まった5〜7か所を一度にはかります（授業の時間短縮）。
- 「↶ ひとつもどす」：はかる・直線を動かす・行を消す をもどします。表の「×」で1行消せます。
- **「🔁 同じ値で もういちど」**：記録を消して、はじめから。実験番号が同じなので、同じところをはかると同じ測定値になります。
- 「🎲 ちがう値で もういちど」：実験番号を変えて、はじめから。
- **実験番号**：番号を入れると、その番号の測定値になります。黒板に番号を書けば、クラス全員が同じデータで考えられます。
- 実験・種類・条件を切りかえても、それぞれの記録は残ります。

### 中央：グラフ
- ● 測定値、○★ 確かめの実験、━ わたしの直線（オレンジ）、┅ 点と直線のずれ（灰色のたての点線）。
- 点 A・B をドラッグして直線を動かします（すいつく／すいつかない、ズーム、画像保存は上のボタン）。
- 下に「△ 直線の上 ○こ ▽ 下 ○こ ― 線の近く ○こ」が出ます。

### 右：📏 直線を引いて式に
- 4回以上はかると「📏 直線を引く」。わざと点に合っていない直線が出るので、A・B を動かして合わせます。
- 式は分数で正確に出ます（分母が大きいときは「約 *y*＝…」も）。傾き・切片の意味（1あたりふえる／へる量、はじめの値）も出ます。
- 「✔ 直線をチェック」：上と下のかたより、ずれの大きさ（計算で引いた直線とくらべる）を見ます。ばねで原点をはなれたとき、水温で切片が室温からはなれたときはヒントが出ます。
- 「📐 ずれを見る」：点と直線のずれの点線を出す／消す。
- 「🙈 式を自分で求める」：式をかくし、A・B の座標から傾きと切片を入力して求めます。

### 右：🔮 予測して確かめる
- **🔮 y を予測**：「おもりが 150g のとき、のびは？」など。まだはかっていない（なるべく遠い）*x* で出ます。
- **🔮 x を予測**：「のびが 25cm になるのは何 g？」「ろうそくが燃えつきるのは何分後？」「水が 100℃ になるのは？」など。
- **⚠ 式が使えるのは？**（ろうそく・水温）：燃えつきた・ふっとうしたあとの時間を聞きます。式で計算すると負の長さや 100℃ をこえる温度になるので、答えは 0cm・100℃。変域を考えます。
- 答えは**自分の直線の式**で計算した値とくらべます（少しの四捨五入のちがいは正解）。正解するとグラフに紫の点線（*x* → 直線 → *y*）が出ます。
- 「🧪 実験で確かめる」：その *x* で実際にはかり、★ を表とグラフに足して、予測とのちがいを出します。
- 直線が点からはなれているときは、予測の前に直すように注意が出ます。

## ワークシート

- もんだい：「ばねののびは、おもりの重さに比例するだろうか？ 測定値から式を見つけて、はかっていない重さのときののびを予測しよう。」
- 予想：比例する／比例しない／重いほどのびはだんだん小さくなる／わからない
- 記録：実験・測定の数・式・予測・実験の値（🔮 で予測したあと「＋ 記録する」）。
- まとめ：「ばねののびは重さに（比例する・しない）。式は *y*＝○*x*」「測定値はばらつくので、点の真ん中を通る直線を引いた」。
- 保存キーは `ikechan-math-一次関数の実験室`（つまずきの記録もこの中）。

## 授業での使い方の例（50分）

1. **予想（5分）**：ばねののびは重さに比例するか予想。実験番号を黒板に書いて全員そろえる。
2. **測定（10分）**：ばねA（のび）を「まとめて はかる」。点がぴったり一直線に並ばないことに気づかせる。
3. **直線を引く（15分）**：A・B を動かし、上と下に同じくらい点があるように。原点を通る＝比例を確認し、式 *y*＝0.2*x* くらいを読む。「ばね全体の長さ」に切りかえて、切片 10cm の一次関数とくらべる。
4. **予測と確かめ（10分）**：150g・200g ののびを予測 → 🧪 実験で確かめる。
5. **広げる・まとめ（10分）**：ろうそく（右下がり）・水温（切片＝室温、ふっとうのあとは式が使えない）。ワークシートにまとめる。

## 正しさについて（※じっさいとのちがい）

- 測定値は、本当のきまりの値に小さな乱数のばらつきをたし、目もりのけた（0.1cm・0.1℃・1m）で四捨五入したものです。乱数は「実験番号・実験・*x*・その *x* で何回目か」から決まるので、同じ番号なら同じ値になります。
- ばねは重くしすぎると元にもどらなくなるので 200g まで。
- 水温は、実際には加熱のはじめは上がりにくく、100℃ 近くでは上がり方がゆるやかになりますが、ここでは 100℃ までまっすぐ上がり、100℃でふっとうしてそれ以上は上がらないことにしています。
- 電車は動き出しはだんだん速くなりますが、ここでは一定の速さで走っているとしています。
- わたしの直線の式は分数（Fraction）で正確に計算し、表示は小数（約）も使います。
- 先生モードの「お手本の直線」は最小二乗法（高校以上の内容・発展）で計算しています。生徒の画面には出ません。

## つまずき検知の一覧

| 型 | 見つけ方 | 例 |
|---|---|---|
| 📏 かたよった直線 | ✔ 直線をチェック で、点がぜんぶ直線の片がわ（3こ以上） | 2点だけを通して、ほかが上にある |
| ➕ 切片のたしわすれ | 予測の答えが *ax*（*b* をたしていない）／ *y*÷*a* | ばねの長さで 140g → 28cm（正しくは 38cm） |
| 🔄 x と y の取りちがえ | 予測の答えが、*x* と *y* を入れかえて計算した値 | のび 30cm → 6g |
| ↕ 傾きの符号 | 予測の答えが *b*−*ax*、または 傾きの符号が逆 | ろうそく 21分後 → 20.4cm |
| ⇄ 移項の符号 | *x* の予測で (*y*＋*b*)÷*a*、または切片の符号が逆 | 長さ 34cm → 220g（正しくは 120g） |
| ½ 傾きの分子と分母が逆 | 🙈 で、傾きを（*x* の増加量）÷（*y* の増加量）にした | 5（正しくは 0.2） |
| 📍 切片の読みちがい | 🙈 で、切片に A や B の *y* 座標（*x*≠0）を入れた | |
| ⚠ 変域をこえて式を使った | ⚠ 式が使えるのは？ で、式で計算した値（負の長さ・100℃ こえ）を答えた | ろうそく 35分後 → −2cm |
| ✏ 計算のまちがい | そのほか | |

つまずきが出たら「🔁 にた問題」（同じ型の問題）や「📐 ずれを見て引きなおす」で、もとの図にもどれます。
