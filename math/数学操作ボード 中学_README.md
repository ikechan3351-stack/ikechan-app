# 📐 数学操作ボード 中学

さんすうボード⑤ジオボード・「方眼ボード」・「代数タイルボード」・さんすうボード⑩数直線を、**中学生用に決めてまとめた入り口**です。最初にボードを選ぶだけで使えます。「さんすうセット ていがくねん」「算数操作ボードセット」の中学版です。

- 新しいアプリではありません。中身はそれぞれの元のアプリと同じで、元のアプリもこれまでどおり残っています。
- **ファイル**：`数学操作ボード 中学.html`（入り口）。ボードは同じフォルダの元のファイルを使います。ネット接続・外部ライブラリは不要です。
- 入り口は分野別に見出しをつけて並べます（「📐 図形」と「🔢 数と式」）。

## 使い方

1. 入り口のカード（🟠ジオボード／✂️方眼ボード／🟧代数タイルボード／📍数直線ボード）をタップする。
2. ボードが開く。使い方は元のアプリと同じ。
3. 左上の **🏠 ボードえらび** で入り口にもどる。

## 決めているところ（中学モード）

入り口からは、ボードを `?jh=1` をつけて開きます。この合図があるときだけ、つぎのように変わります。

| ボード | 中学モードでの変化 |
|---|---|
| ⑤ ジオボード | いつも **中学生用**（道具・はかるがぜんぶ使え、ななめの辺の長さを √ で表示。例：2√2）。「だれ むけ」の切りかえと、はじめの「えらんでね」画面を出さない |
| 方眼ボード | いつも **中学生**（面積を cm² で表示）。せっていの学年の切りかえを出さない。📚お題の目次には **中1・中2 のお題だけ** が出る |
| 代数タイルボード | もとから中学生用なので、変わるところはない |
| ⑩ 数直線 | 道具箱の最初が **負の数の数直線**（−10〜10、−5〜5 は +3 のように符号つき）になる。やじるし・ジャンプで正負の数のたし算・ひき算・かけ算を表す |

どのボードでも、左上の「← トップ」が「🏠 ボードえらび」に変わります。

## 先生モード

- 入り口の右上の **🧑‍🏫 せんせい** を押すと、選んだボードが先生モードで開きます（アドレスに `?teacher=1` が入る）。
- ボードの中で先生モードを切りかえても、中学モードはそのまま続きます。

## つづきから（自動保存）

- ジオボード・数直線のようすは、ふつうのボードやほかのセットとは**べつに**保存されます（保存のキーの最後に `-中学` がつく）。そのタブで2回目からは「つづきから？」を聞かずに続きを開きます。
- 方眼ボードは、もともと自動保存をしないアプリです（お題を選んで使う）。

## しくみ（コードのつくり）

- 入り口：ボードの表 `BOARDS` の `field`（分野）ごとに見出しをつけてカードを並べます。ボードや分野を足すときは、ここに1行足します。
- ⑤：`const JH = Q.get('jh') === '1' …` と `if (JH) LEVEL = 'jh';`。もどる先は `HUB`。
- 方眼ボード：`const JH = …`・`HUB`・`HUB_LEVEL`（お題の目次をしぼる）。高学年の `?high=1` と同じしくみです。
- ⑩：`const JH = …` で道具箱の数直線の順番を変え、`HUB`・`SAVE_KEY` の最後に `-中学`。

## これからの予定

- 中学で使える操作ボードができたら、`BOARDS` に分野の見出しつきで1行足す。
