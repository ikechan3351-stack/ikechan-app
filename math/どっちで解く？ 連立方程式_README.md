# どっちで解く？ 連立方程式（方針をえらぶ → 加減法・代入法を1ステップずつ → 検算）

中学2年「連立方程式の解き方」のアプリです。中1「一次方程式のステップ」（`方程式ステップ.html`）の作り（次の一手カード → 変形したあとの式の3択 → 検算）を引きついでいます。
はじめに**どの文字を消すと楽か**・**加減法か代入法か**を自分できめ、そのあと1ステップずつ解きます。加減法では、筆算の形で文字の列が 0 になって消えるようすを見せます。

## 基本情報

- **ファイル**：本体 `どっちで解く？ 連立方程式.html`、共通部品 `math-render.js`（数式・分数）・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中2）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）・スマホ。式が画面に入りきらないときは、文字を小さくして入れます。
- **URL の設定**
  - `?teacher=1` … 先生モード（最後まで自動で見せる・つぎの1手・答えと楽な方針・この端末のつまずきの合計）
  - `?ws=0` … ワークシートをとじて開く
  - `?debug=1` … 動作確認用（中身を `window.__dbg` から見られる。授業ではつかわない）

## レベル（答え x, y を先に決めてから式を作ります）

| レベル | 問題の形 | 例 |
|---|---|---|
| ① そのまま消える | どちらかの文字の係数の絶対値が同じ | 2*x*＋*y*＝7, *x*−*y*＝2 |
| ② 一方を何倍か | 片方の式を2倍か3倍すると、係数の絶対値がそろう | 3*x*＋2*y*＝8, *x*＋*y*＝3 |
| ③ 両方を何倍か | 両方の式を何倍かしないとそろわない | 3*x*＋2*y*＝12, 2*x*−3*y*＝−5 |
| ④ 分数・小数 | 小数の式（0.2*x*＋0.3*y*＝1.3）と分数の式（*x*/2＋*y*/3＝2） | まず整数にしてから解く |
| ⑤ 代入法が楽 | *y*＝*px*＋*q*（または *x*＝*py*＋*q*）の形の式がある | *y*＝2*x*−1, 3*x*＋2*y*＝12 |

## 使い方

### 方針えらび
- 「どの文字を消すと楽？」：*x* を消す／*y* を消す。どちらをえらんでも解けますが、えらんだあとに「*y* の係数は 1 と −1。そのままたせば消える」「②を2倍すると、絶対値が 2 にそろう」のように手間を説明します。もう一方のほうが楽なときは「でも、*x* を消すほうが楽かも」と出します（↶ でえらび直せます）。
- 「どの方法で消す？」：加減法／代入法。消す文字の係数が 1・−1 の式も、*y*＝… の形の式もないときは、代入法はまちがいのカードになります（分数が出てくるため）。*y*＝… の形があるのに加減法をえらぶと「代入法のほうが楽かも」と出ます（そのまま進めます）。
- レベル④は、方針の前に「①を10倍する」「②に分母の最小公倍数6をかける」で係数を整数にします。整数にした式を、あらためて ①・② とよびます。

### 加減法
- 「①を3倍する」「②を2倍する」で、消す文字の係数の絶対値を最小公倍数にそろえます。式の名前は ①×3 のように変わります。
- 「①×3＋②×2」「①−②」をえらぶと、**筆算の形**（1行目・＋) か −) の2行目・線）が出て、消える文字の列が黄色く光り、0 になって消えます。残った式（5*x*＝15 など）は3択でえらびます。
- 符号が同じなのにたす（ちがうのにひく）と、文字が消えない式を見せて「たすところでひいた」のつまずきにします。

### 代入法
- 消す文字の係数が 1 か −1 の式を「*y*＝… の形にする」（移項。3択）。
- 「①を②に代入する」→ 3択（正しい：3*x*＋2(2*x*−1)＝12、かっこ忘れ：3*x*＋2×2*x*−1＝12 など）。
- 「かっこをはずして整理する」→ 3択（7*x*＝14 など）。

### そのあと（どちらの方法も同じ）
- 「両辺を 5 でわる」で *x*＝3。
- 「*x*＝3 を①に代入する」「②に代入する」（どちらでもよい）→ 代入した式（2×3＋*y*＝7）を見て、*y* の値を3択でえらびます。
- **検算**：*x*, *y* をもとの式の両方に代入して、左辺・右辺の値を入れます（数だけの辺は計算ずみで表示）。2回まちがえると「答えを見る」が出ます。
- 「💡 ヒント」（1回目はことば、2回目は使えるカードが光る）、「↶ ひとつもどす」（3択の途中なら、えらぶ前にもどる）、「⟲ もういちど」、「🎲 新しい問題」。
- 「何倍する・たす／ひく・代入するときは、変形したあとの式もえらぶ」のチェックを外すと、3択なしで進みます。

## ワークシート

- もんだい：「連立方程式 2*x*＋*y*＝7、*x*−*y*＝2 の *x* の値は、いくつだろうか？」
- ① 予想：*x*＝1／2／3／4／わからない
- ② 操作：「📄 ワークシートの問題」で解いて、検算までできたら「＋ 記録する」（はじめの式・方針・解・手数）。加減法と代入法の両方で解いて、手数をくらべられます。
- 先生モードでは、ヒントと解答例（*x*＝3, *y*＝1）が出ます。
- 保存キーは `ikechan-math-どっちで解く？ 連立方程式`（クリア数・まちがえたカード・ヒント・つまずきの回数もこの中）。

## 授業での使い方の例（50分）

1. **予想（5分）**：ワークシートの問題で *x* の値を予想。
2. **方針を話し合う（10分）**：「📄 ワークシートの問題」を出し、「どの文字を消すと楽？」を全体で考える。*y* の係数が 1 と −1 → たせば消える。先生モードの「つぎの1手」で筆算のアニメを見せる。
3. **個人で練習（20分）**：レベル①→②→③。速い生徒は④⑤。同じ問題を「↶」でもどして、もう一方の文字・方法でも解き、手数をくらべる。
4. **つまずきの確認（5分）**：「あなたのつまずき」に出た型を「この型を練習」でふくしゅう。
5. **まとめ（10分）**：ワークシートに「どんなときに加減法・代入法が楽か」を書く。

## 正しさについて（※じっさいとのちがい）

- 計算はすべて分数（Fraction）で厳密に行います。小数の式は、分母が 2・5 だけの分数を小数で見せています。
- 教科書では、①×2 と ② をたすところを1行で書くことも多いですが、ここでは「何倍する」と「たす・ひく」を別の一手にしています。
- ひくときは「①−②」の順だけにしています（「②−①」でも解けます）。
- 楽かどうかの目安は「何倍する式の数（両方なら少し多め）」「*y*＝… の形があるか、係数が ±1 の式があるか」で決めています。人によって楽と感じる方法がちがうこともあるので、どちらをえらんでも解けるようにしています。

## つまずき検知の一覧

| 型 | 見つけ方 | 例 |
|---|---|---|
| ひき算で、ひく式のうしろの項の符号を変え忘れた | ①−② の3択で、残る文字の係数をたした式・右辺をたした式 | 3*x*＋2*y*＝8 から 3*x*−2*y*＝4 をひいて、4*y*＝4 を 4*y*＝12 にした |
| 代入するとき、かっこをつけ忘れた | 代入の3択 | 3*x*＋2×2*x*−1＝12 |
| 式を何倍かするとき、一部の項（右辺など）にかけ忘れた | 何倍の3択（レベル④の整数にするときも） | 2*x*＋*y*＝7 を2倍して 4*x*＋2*y*＝7 |
| たすところでひいた（ひくところでたした） | 係数がそろったあとで、反対の操作のカード | *y* と −*y* なのに ①−② |
| かっこをはずすとき、うしろの項にかけ忘れた（符号をまちがえた） | 代入法の「かっこをはずして整理する」3択 | −3(2*x*−1) を −6*x*−1 |
| 移項で符号を変え忘れた | *y*＝… の形にする3択、もう一方の文字を求める3択 | 2*x*＋*y*＝7 → *y*＝2*x*＋7 |
| 文字の係数をひいた | 「両辺から 5 をひく」のカード | 5*x*＝15 → *x*＝10 |
| 計算のまちがい | 3択の、そのほかのまちがい | |

つまずきは「あなたのつまずき」に回数と説明が出て、「この型を練習」でそのレベルの問題になります（ひき算の符号の型は、ひくと消える問題が出ます）。
