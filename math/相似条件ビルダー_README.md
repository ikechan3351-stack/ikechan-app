# 相似条件ビルダー（部品をつないで、相似になる条件を見つける）

中学3年「図形と相似」のアプリです。相似な図形の性質（対応する角は等しい・対応する辺の比は等しい）と、三角形の相似条件（3組の辺の比がすべて等しい／2組の辺の比とその間の角がそれぞれ等しい／2組の角がそれぞれ等しい）を、図を動かしたり部品をえらんだりして見つけます。証明パズル（2-14）の「カードをならべる」形を引きついだ、相似の証明パズルもあります。

## 基本情報

- **ファイル**：本体 `相似条件ビルダー.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3・図形）から開けます。
- **画面のならび**：広い画面は 左＝図・右＝操作と表 の2列（図は上に止まったまま）。スマホはたて1列。
- **記録**：この端末の localStorage（保存キー `ikechan-math-相似条件ビルダー`）に、ワークシートといっしょに入れます。
- **URL の設定**：`?teacher=1` … 先生モード、`?part=1〜5` … そのパートから始める、`?ws=1`／`?ws=0` … ワークシートをひらいて／とじて始める、`?debug=1` … 動作確認用（`window.__dbg`）

## パート

| パート | すること |
|---|---|
| ① 相似な図形 | もとの △ABC（● で形を変える）を「何倍」「回転」「↔ 裏返す」で動かして △DEF をつくる。表で 辺の比（×何倍）と角が等しいことを見る。「📐 角を重ねる」で A と D を重ねると、角がぴったり重なり、向かいの辺が平行になる。「🎯 相似の位置」では点 O を中心に拡大（O と対応する点が一直線）。∽ の読み方（そうじ）と、対応する頂点を同じ順に書くことを表示。 |
| ② 条件をつくる | △DEF の部品（辺 DE・EF・FD、∠D・∠E・∠F）をえらぶと、その部品を守ってできる三角形をかく。形が1つに決まれば「いつでも相似」、いくつもできれば「相似とはかぎらない」。「🎲 ほかの形」で別の形をさがせる（前の形は点線で残る）。2組の角だけなら「大きさはいろいろ、でも形は同じ」、2組の辺と間でない角なら「形が2通り（片方は相似でない）」。足りないときは「あと1つ足すなら」を出す。相似比は 2：3 と 1：2。 |
| ③ 条件のクイズ | 2つの三角形の図（長さ・角の数が書いてある）を見て、「相似か・どの相似条件か」を5つからえらぶ（合同条件「1組の辺とその両端の角」もまぜてある）。正解すると、つづけて ∽ の正しい書き方をえらぶ。右の三角形は回転・裏返し・名前の順番がばらばら。答えたあと「🔄 向きをそろえて見る」。 |
| ④ 証明パズル | カードを「はじめ（△…と△…で）→ 根拠 → 相似条件から ∽ →（結論）」の順にならべる。ドラッグか、タップで上からあいている行へ。置いたカードをタップするともどせる。根拠を置くと図の角・辺が行の色と本数で光る。「🔄 2つを取り出して向きをそろえる」で、対応する頂点が同じ位置にくるようにならべて見られる。 |
| ⑤ 平行線と相似 | タテ型（ピラミッド型）と砂時計型（ちょうちょ型）。● D をドラッグ（またはスライダー）すると DE が BC に平行のまま動き、AD÷AB＝AE÷AC＝DE÷BC がいつもそろう。タテ型では AD÷DB も出して「DE÷BC とはちがう」ことを注意する。「🔍 △ADE を重ねる」で、A を中心に拡大（砂時計型は 180° 回しながら）すると △ABC に重なる。「🧩 証明パズルへ」で ④ の問題に移れる。 |

### ④ 証明パズルの問題

| 問題 | 仮定 | 結論 | 相似条件 | 見落としやすいところ |
|---|---|---|---|---|
| ① 平行線（タテ型） | DE∥BC | △ABC∽△ADE、AB：AD＝BC：DE | 2組の角 | ∠A は**共通**、平行線の**同位角**。結論に DB を使わない |
| ② 平行線（砂時計型） | AB∥CD | △OAB∽△ODC | 2組の角 | O の角は**対頂角**（共通ではない）、平行線の**錯角** |
| ③ 辺の比と間の角 | AB＝8、AC＝6、AE＝3、AD＝4 | △ABC∽△ADE | 2組の辺の比とその間の角 | E は AB 上だが、対応するのは C（AB：AD＝AC：AE＝2：1） |
| ④ 直角三角形と高さ | ∠BAC＝90°、AH⊥BC | △ABC∽△HBA | 2組の角 | 直角どうし A↔H、∠B は共通 |

①の根拠は「∠A 共通」と「∠B の同位角」でも「∠C の同位角」でも正解にしています（どちらも2組の角）。問題は、ファイルの中の `PROBS` に1つ足すとふえます（図の点・仮定・結論・カード）。

### 練習問題（「✏️ 練習問題」）

- ①：対応する辺／対応する角（∽ の書き方から）、∽ の正しい書き方（弧の本数から）、相似比、対応する辺の長さ（×何倍）。もとの三角形は AB＝4、BC＝6、CA＝5（cm）、相似比は 1.5倍・2倍・0.5倍。
- ②：ことばで書いた条件（例：AB：DE＝BC：EF、∠C＝∠F）→ 相似といえるか・どの条件か。答えたあと「🧱 部品でたしかめる」で ② の部品にうつせる。
- ③：上のクイズ。型は 3組の辺の比／比が1つちがう／2組の辺の比と間の角／2組の辺の比と間でない角（形が2通りできる側をかく）／2組の角／2組の角（3つめの角を求める）／角が1組だけ等しい／1組の辺と両端の角（＝2組の角）。
- ⑤：x（DE の長さ）を求める。答えが整数になるように、答えを先に決めてから数をつくる。

## つまずき検知の一覧

| 型 | 検出のしかた | もどる先 |
|---|---|---|
| 対応する頂点の順序のまちがい | ① で対応する辺・角・∽ の書き方をまちがえた、③ の ∽ の書き方、④ で △AED・△OCD などのカード | ① の練習問題、回転・裏返しした図 |
| 相似比の向きのまちがい | 相似比を逆（3：2）にした、対応する辺の長さを ÷ で出した | ① の相似比の問題 |
| 比ではなく差で考えた | 4→6 を「＋2」と考えて、6→8 とした | ① の長さの問題 |
| 条件が足りないのに相似とした | 辺の比2組だけ・角1組だけ・比が1つちがうのに相似とした、④ で根拠が足りないのに ∽ を置いた | ② で 辺 DE・EF だけ（形がいくつもできる） |
| 大きさがちがうと相似でないと考えた | 2組の角が等しいのに「相似とはいえない」 | ② で ∠D・∠E だけ（大きさはいろいろ、形は同じ） |
| 「間の角」でない角を使った | 2辺の比と間でない角を「2組の辺の比とその間の角」とした | ③ の問題（形が2通りできる図） |
| 残りの角を求めわすれた | 3つめの角を求めれば2組の角が等しいのに「相似とはいえない」 | ③ の問題 |
| 合同条件と相似条件の混同 | 「1組の辺とその両端の角」をえらんだ、④ で ≡ のカードを置いた | ③ の問題 |
| 相似条件のえらびまちがい | 相似条件のとりちがえ、④ で根拠と合わない相似条件 | ③ の問題 |
| 根拠の理由のまちがい | ④ で 同位角⇔錯角、対頂角なのに「共通」、直角なのに「共通」 | ④ の問題 |
| 根拠のないことを使った | ④ で仮定にないこと・結論・平行と書いていないのに同位角 | ④ の問題 |
| 証明の順序のまちがい | ④ でカードの種類と行の役割が合わない | ④ の問題 |
| 平行線の比で、辺のとりちがえ | ⑤ で DE：BC に AD：DB を使った、④ ①の結論に DB を使った | ⑤ のタテ型（表で AD÷DB と DE÷BC をくらべる） |
| 計算まちがい | 上のどれにも当てはまらないまちがい | ― |

回数は「🔎 あなたのつまずき」に出ます。「🔁 この型を練習」でその型の問題が出て、「👀 元の図で確かめる」でその型が見える図にもどります。先生モードでは、この端末の合計回数も見られます。

## ワークシート

- ①予想「2つの三角形で、2組の角がそれぞれ等しいとき、対応する辺の比はどうなる？」→ ②「📄 ワークシートの問題」で ② の ∠D・∠E だけをえらんだ状態になる。「🎲 ほかの形」で大きさを変えながら「＋ 記録する」（えらんだ部品・DE÷AB・EF÷BC・FD÷CA・相似か）→ ③気づき → ④まとめ。
- ① や ⑤ の図でも記録できます。

## 授業例（1〜2時間）

1. 小6の拡大図・縮図をふり返り、① で「何倍・回転・裏返し」をしても角は等しく辺の比がそろうことを確かめる。∽ の書き方（対応する頂点の順）を練習問題で。
2. 「合同条件は3つ。相似条件は？」と問い、ワークシートの予想。② で部品をえらび、形が1つに決まる組を見つける。「2組の角だけ」で大きさが自由でも相似になることを記録してまとめる。
3. ③ のクイズで、合同条件との混同・3つめの角・間の角を確かめる。
4. ④ の証明パズル（① タテ型 → ② 砂時計型 → ③ 辺の比 → ④ 直角三角形）。⑤ で平行線と相似、AD：DB とのちがいを確かめ、3-16「平行線と線分の比」につなぐ。

## 正しさ・じっさいとのちがい

- 方眼の1目もりを 1cm としています（画面の大きさは実物とはちがいます）。長さは 0.1cm、比は小数第2位、角は 1° の位までの四捨五入です。
- ② のもとの三角形（AB＝4cm、BC＝6cm、CA＝5cm）の角はぴったりの整数ではないので「約83°」のように「約」をつけています。相似かどうかの判定は、四捨五入する前の値で行っています。
- ② で「辺をえらぶ」は「その辺を、もとの辺の 1.5倍（または 2倍）の長さにする」という意味です。辺の比の条件（AB：DE＝BC：EF など）を、長さを決めることで見せています。
- ③ の図は書いてある長さ・角のとおりにかいていますが、画面に合わせて縮めています（角は 1° の位までの四捨五入）。
- 証明の書き方（「〜より」「〜から」、①②③の付け方）は教科書や先生によって少しちがいます。このアプリの書き方は一例です。根拠の行は、どの順番にならべても正解にしています。
