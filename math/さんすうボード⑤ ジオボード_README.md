# 🟠 さんすうボード⑤ ジオボード

低学年・高学年・中学生向けの **デジタルジオボード** です。ピンに輪ゴムをかけるように、指でゴムをのばしてピンにかけ、図形をつくります。正解・不正解は出しません。自由にさわって、必要なときだけ長さ・角度・面積を出して、気づきを支えます。

- 「さんすうボード①〜④」と同じつくりです。📷しゃしん・💾くばる・📂ひらく は ①〜④ と同じ使い方です。
- 単元（例）：1年「かたちづくり」、2年「三角形と四角形」（辺・頂点。直角の□じるしは 高学年用か 先生モードで出せます）、3年「三角形と角」（二等辺三角形・正三角形）、4年「垂直・平行と四角形」「面積」（複合図形）、中学3年「三平方の定理」（中学生用で、ななめの辺を √ で表示）。
- 仕様書：`~/Downloads/ジオボード.md`（開発の引き継ぎ用）。

## 基本情報

- **ファイル**：`さんすうボード⑤ ジオボード.html`。この1ファイルだけで動きます（ネット接続・外部ライブラリ・画像ファイルは不要）。
- **対応する機器**：iPad Safari、Chromebook、Windows の Edge・Chrome、電子黒板。タッチ・ペン・マウスのどれでも動きます。
- **2本指**：盤の拡大（1〜3倍）・移動。えらんだ形を1本の指でつかんだまま2本目の指をおいてひねると、形がまわります。

## 道具（左の たての 帯）

| 道具 | できること |
|---|---|
| 🟠 ゴム | ピンから指をすべらせると、ゴムがのびて、はなしたピンにかかる。そのまま次のピンへ。はじめのピンにもどすと形がとじる。**タップでは線は引けない**（まちがって線が引かれないように）。あいたピンをタップすると、そのピンに**小さい輪ゴム**がかかり、まだのばしていないゴムがあることがわかる（そこから指をすべらせるとのびる。べつのあいたピンをタップするとうつり、同じピンをタップするとはずれる）。つくりかけのときにタップすると、そこで「せん」としておわる。**ゴムのかどをタップすると光る輪がつき、べつのピンをタップするとそこへかけかえられる**（同じピンをもう一度タップするとやめる。光ったかどから指をすべらせると、そこから新しいゴムをのばせる）。ゴムの辺のとちゅうをつまんで引っぱると頂点がふえる（2本のピンにかけたゴムは、もう1本がピンの間にのこる）。頂点をつまむと別のピンにかけ直せる。ピンのない所ではなすと、ゴムはちぢんでもどる |
| 👆 えらぶ | 形をタップしてえらぶ。引っぱると動いてピンに吸いつく。↻ のつまみで回す（15°ずつ／じゆう）。下のボタンで 90°回転（三角の盤は60°、まるい盤はとなりのピンまで）・左右反転・上下反転・コピー・わける・けす |
| 🪣 ぬる | 「なか」：とじた形の中をタップしてぬる（うすい／こい、斜線の丸で ぬりを消す）。「ゴム」：ゴムの色をかえる |
| ✂️ きる | 形のへりのピンから、べつのへりのピンまで線を引くと2つに分かれる（ななめもOK）。分かれた直後、ピースが少しはなれてからもどる |
| 🧩 はる | ピースをタップ（オレンジ）→ はれる相手がみどりに光る → タップで1つの形になる。ピースは引っぱって動かせる。はった形は「えらぶ」の「わける」でもとの2つにもどせる |
| ✏️ かく | ペン（手がき）・📏ちょくせん（引っぱると まっすぐな線。よこ・たて・ななめ45°に近いと ぴったりそろう）・もじ（タップした所に入力。引っぱると動く・タップで直す）・けしゴム |

- 下の帯：色のパレット（ゴムの道具では、つぎにかけるゴムの色。虹色は1本ずつかわる）、道具ごとの切りかえ、もどる・やりなおす・ぜんぶけす。

## 盤（上の帯の「ばん」）

| 盤 | 中身 |
|---|---|
| たて 5だん／7だん／11だん | 正方形の格子。**よこは画面のはばに入るだけピンがふえる**（横1366pxの画面で 10×5／14×7／22×11）。もうかかっているゴム・もじがある列までは、せまい画面でもピンをのこす |
| 三角 | 正三角形の格子（8だん。よこは画面に合わせてふえる）。となりのピンとのきょりはどこも1 |
| まる12／まる24 | 円周を12・24とうぶん＋中心のピン。回転・反転は盤の中心が基準 |

- 動かす・回す・反転・コピー・切る・はるのあとは、ピンにいちばん近い頂点がピンにのります（マス目にそって動かせば、頂点はぜんぶピンにのる）。自由な角度で回したときは、ピンからはずれる頂点もあります。

## はかる（上の帯の 📏長さ・📐角度・🟦面積・⚙️）

はじめはすべて OFF です。ゴムを動かしている最中も、値は毎回かわります。

- **長さ**：辺の外がわに出る。ピン1つ分＝1（まるい盤だけは、円の半径を3とした長さ）。ななめの辺は、低学年用・高学年用では「かかない」。中学生用では √ を使って「2√2」「√5」のように書く（⚙️ で「かかない」にもできる）。まわりの長さも「6＋2√2」のように同じ √ をまとめて書く。まるい盤のように √ で書けない長さは「約2.8」。
- **角度**：頂点の内がわに弧と「45°」「約34°」。直角は □（⚙️ で「90°」とも書ける）。へこんだ形の 270° なども正しく出る。
- **面積**：形の中に「面積 6」（マス1つ分＝1、座標の公式で計算。半分のマスは 7.5 のように）。三角の盤は「△ 4こ分」（小さい正三角形の数）。
- ⚙️：まわりの長さ・角の和・マスを見せる（方眼を点線で）・頂点の名前 A, B, C…・すべての形／えらんだ形だけ。
- **数をタップすると「？」になって かくれる**（もう一度タップで見える）。先生モードでは、はじめから全部「？」。

## だれむけ・モード（上の帯の 🎓）

| だれむけ | 道具 | はかる | さいしょの盤 | ななめの辺 |
|---|---|---|---|---|
| 🐣 低学年用 | ゴム・えらぶ・ぬる・かく | 長さ | たて5だん | かかない |
| 🧒 高学年用 | ぜんぶ（きる・はるも） | 長さ・角度・面積・⚙️ | たて11だん | かかない |
| 🎒 中学生用 | ぜんぶ | 長さ・角度・面積・⚙️ | たて11だん | √ で書く（2√2） |

- **先生モード**（電子黒板用）：ピン・ゴム・文字・ボタンが大きく、吸いつく範囲が広くなり、数はタップするまで「？」。どれをえらんでも道具はぜんぶ出ます。
- 低学年用と先生モードは、ピンに吸いつく範囲が広め（ピンの間かくの50%、ほかは40%）。
- 「うごきを 少なく」：ばねの動きをはぶいて、すぐ吸いつきます（OS の「視差効果を減らす」でも同じ）。
- URL で開いたときに だれむけ もモードも決まっていなければ、はじめにこの画面が出ます。

## URL

設定・盤・はかる表示を変えると、アドレスも書きかわります。そのアドレスをそのまま子どもに配れます。

| パラメータ | 値 |
|---|---|
| `mode` | `teacher`（先生モード。なければ子ども） |
| `level` | `low`（低学年用）／`high`（高学年用）／`jh`（中学生用）。むかしの `grade=1`・`2` は低学年用、`3`・`4` は高学年用として開く |
| `board` | `square5`／`square7`／`square11`／`tri`／`circle12`／`circle24` |
| `show` | `length,angle,area`（はじめから出す はかる表示） |
| `motion` | `less`（うごきを少なく） |

例：`さんすうボード⑤ ジオボード.html?mode=teacher&level=high&board=square11&show=area`

## 保存

- **📷 しゃしん**：プレビューを出して、「📋 コピー」（ロイロに はりつけ）か「💾 ほぞん」（PNG）。ボタンで保存できない機器では、プレビューの画像を長おしして保存します。
- **💾 くばる（先生）・📂 ひらく**：画像（PNG）の中に盤（ゴム・もじ・手がき）が入っています。子どもは画像を保存して「📂 ひらく」でえらぶと、動かせる盤にもどります。ひらいたあとは「⟲ はじめに」で、くばられたときの状態にもどせます。①〜④の画像をまちがえてひらいたときは「そちらで ひらいてね」と出ます。
- **つづきから**：盤をかえるたびに、その端末（localStorage、キー `ikechan-math-さんすうセット⑤ ジオボード`）に自動で保存します。次に開いたとき「つづきから／あたらしく」を聞きます。保存できない環境でもアプリは動きます。

## 授業での使い方（例：4年 面積「複合図形」）

1. 先生が電子黒板（先生モード・高学年用）で、L字の形をゴムでつくる。「面積は いくつかな？」と予想させる。
2. 子どもはタブレットで同じ形をつくり、✂️きる で2つの長方形に分けて考える。
3. 🟦面積 をONにして、分けた形の面積をたしかめる。⚙️「マスを 見せる」で数えてたしかめてもよい。
4. 先生は「？」の面積をタップして答えを見せる。ちがう分け方をした子の盤を📷しゃしんでくらべる。

## 2026-11-13 の直し（点検のあと）

- **ばんを かえる**：ゴムだけでなく、もじ・手がきも消えます（盤がかわると場所がずれるため）。もじ・手がきだけのときも、かえる前にたずねます。「もどる」で元の盤ごともどせます。
- **きる**：切り線のとちゅうに図形の頂点（へこんだ かど）がのるときは、切れません（くびれた形ができてしまうため）。へこんだ かどから切りはじめる・かどで切りおわるのは できます。
- ゴムが交わった形・つぶれた形では、面積・角の和を出さず「ゴムが かさなって いるよ」と出します。
- 回すと盤に入らないときは回さず、「ばんに 入らないので まわせないよ」と出します。

## はいけい（ばんの いろ・うすい こうし・グラフの めもり）

上の列の **🖼️ はいけい** ボタン（盤の大きさが書いてある「⚪ 11×7」などのボタンの右どなり）を押すと、えらぶ画面が出ます。

| えらぶもの | 内容 |
|---|---|
| ばんの いろ | もくめ（はじめの色）・しろ・クリーム・こくばん（緑）。①〜④と同じ色です |
| うすい こうし | なし／あり。となりのピンどうしをうすい線でむすびます。正方形の盤は方眼、三角の盤は三角の目になります。まるい盤では使えません |
| グラフの めもり | なし／0が ひだり下／0が まん中。x軸・y軸（矢印つき）と数が出ます。ピン1つ分＝1、yは上がプラス。正方形の盤だけで使えます |

- **0が ひだり下**：0から右・上だけ（小学校の比例・折れ線グラフ向き）。**0が まん中**：マイナスの数もある（中学の比例・反比例・一次関数向き）。
- ゴムを2つのピンにかけると直線になります。「長さ」「角度」「面積」の表示は、グラフのめもりを出していても今までどおりです。点の座標（2, 3）の数は出しません（子どもが自分で読みます）。
- はいけいは「もどる」の対象ではありません。「つづきから」「くばる」画像・「しゃしん」には入ります。
- アドレスでも決められます：`?color=white｜cream｜green`、`&lattice=1`、`&graph=corner｜center`。例：`?board=square11&color=green&lattice=1&graph=center`
- ※じっさいとのちがい：ゴムは盤の中のピンからピンまでなので、グラフの直線は盤のはしで止まります（本当の直線はどこまでも続きます）。ピンは整数の点だけです。


## 先生モードへの入り方（🧑‍🏫 せんせい ボタン）

- 上の列のいちばん右の **🧑‍🏫 せんせい** をタップ →「先生モードに しますか？」で **先生モードに する**。🎓せっていの「👩‍🏫 先生（電子黒板）」をえらぶのと同じです（その場で切りかわり、ゴム・もじは そのまま）。
- 先生モードのあいだは同じボタンが **🧑‍🏫 せんせい おわる** になり、タップすると子どもモードにもどります（確認なし）。
- 子どもも押せば入れます（かくしてはいません）。「先生のボタンは押さない」を授業の約束にしてください。

## ていがくねん・高学年の入り口から開いたとき

- 「さんすうセット ていがくねん」からは `?low=1`、「算数セット 高学年」からは `?high=1`、「数学操作ボード 中学」からは `?jh=1`（中学生用に決まる）をつけて開きます。学年のえらび方がしぼられ、左上が「🏠 ボードえらび」になり、保存もふつうとはべつになります。くわしくは `さんすうセット ていがくねん_README.md`・`算数セット 高学年_README.md`・`数学操作ボード 中学_README.md` を見てください。
