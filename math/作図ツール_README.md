# 作図ツール（コンパスと定規で作図する）

中学1年「平面図形」の基本の作図（垂直二等分線・角の二等分線・垂線）を、画面のコンパスと定規だけでかくアプリです。手順を1つずつ確かめながらかき、できた線が本当に垂直・二等分になっているかを分度器とものさしで確かめ、「なぜこれでできるのか」をひし形・たこ形（線対称な図形）のアニメで見ます。

## 今ある教材との役割分担

| 教材 | 役割 |
|---|---|
| 小3 コンパスで円をかこう（`円とコンパス.html`） | コンパスの使い方（はり・えんぴつ・つまみ）、円、長さを写す、二等辺三角形・正三角形 |
| 小6 おって まわして 対称な図形（`おって まわして 対称な図形.html`） | 線対称・点対称を折る・回すアニメで確かめる |
| **作図ツール（これ）** | 中1 の作図（垂直二等分線・角の二等分線・垂線）、その応用、作図の理由。自動チェック・つまずき検知・ワークシートつき |

## 基本情報

- **ファイル**：本体 `作図ツール.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中1）から開けます。
- **画面**：広い画面は 左＝作図エリア（24 cm × 16 cm の白い紙）、右＝めあてと手順リスト（いまの手順が黄色、できた手順に ✓）・確かめのボタン。せまい画面は たて1列。
- **色のきまり**：はじめの図＝黒、コンパスでかいた弧＝灰青の細い線、定規でひいた直線＝オレンジ、できた線＝緑の太い線、作図でできた点（C、D、P など）＝紫、交点＝灰色の ×、分度器・角の印＝赤紫、測った長さ＝青緑の点線。
- **URL の設定**
  - `?teacher=1` … 先生モード（いまの手順・つぎの手順を自動で・最後まで自動・この端末のきろく・ワークシートのヒントと解答例）
  - `?ws=0` … ワークシートをとじて開く

## 道具

- **🧭 コンパス**（「円とコンパス」と同じ動かし方）：はりをドラッグ → コンパスごと動く。えんぴつをドラッグ → 開き（半径）が変わる。つまみをドラッグしてまわす → まわした分だけ弧がのびる（1周で円）。「🔄 まわす」で1周の円。
- **📏 定規**：点から点へドラッグすると、その2点を通る直線（「線分」にすると線分）。目もりはありません。
- **吸いつき**：はり・えんぴつ・定規のはしは、はじめの図の点・作図でできた点・交点の近く（0.45 cm）ではなすと、そこに吸いつきます。「吸いつき なし」で切れます。
- **📐 長さを測る**：点から点へドラッグすると長さ（cm、小数第1位）。作図のとちゅうで使うと「目もりで測って作図しようとした」のつまずきになります。
- **🧽 消す**：タップした弧・直線・測った長さを消します。
- ↶ ひとつもどす／⟲ もういちど（はじめの図はそのまま）／🎲 新しい問題（図の位置・長さ・角が変わる）／💡 ヒント（1回目：いまの手順、2回目：道具の使い方、3回目：その手順をお手本として自動でかく）
- はじめの図の点（A、B、O、P など）は、かきはじめる前ならドラッグで動かせます（円や直線の上の点は、その上だけ）。

## パート

### ① 垂直二等分線
線分 AB。① A を中心に AB の半分より大きい半径で円（の一部）② 開きを変えないで B を中心に ③ 交点 C、D ④ 直線 CD。できたら「📐 分度器で角を測る」（90°）、「📏 AM と MB を測る」（中点）。「📍 線の上に点 P を置く」で、P を動かして PA と PB をくらべられます（ワークシート）。

### ② 角の二等分線
∠XOY（半直線 OX・OY）。① O を中心に円 → 交点 A、B ② A を中心に ③ 開きを変えないで B を中心に → 交点 P ④ 半直線 OP。確かめ：∠XOP と ∠POY を分度器で。

### ③ 垂線
- **外の点から**：点 P から直線 ℓ へ。① P を中心に円 → ℓ との交点 A、B ② A を中心に ③ B を中心に → 交点 Q ④ 直線 PQ。
- **直線上の点で**：ℓ 上の点 P を通る垂線。手順は同じ（① の円は P を中心に）。
- 確かめ：ℓ との交点 H で分度器（90°）。教科書のべつの方法（ℓ 上の2点を中心に P を通る円をかく）でも、正しい垂線が作図の点を通っていれば「できた」になります。

### ④ 応用
円の中心（弦 AB・BC の垂直二等分線の交点）／正三角形（半径 AB で A・B を中心に）／正六角形（円周を半径で6つに区切る）／30°（正三角形の 60° を二等分）／45°（垂線の 90° を二等分）／円の接線（**発展**：接点を通る半径 OA に垂直）。

### ⑤ 作図の理由
- **垂直二等分線**：AC ＝ BC ＝ AD ＝ BD（同じ半径）→ ひし形 → 対角線は垂直に交わり、たがいに真ん中で交わる（小4）→ CD で折ると A と B が重なる。
- **角の二等分線**：OA ＝ OB、AP ＝ BP → たこ形（OP について線対称）→ 折ると ∠BOP ＝ ∠AOP。
- **垂線**：PA ＝ PB、QA ＝ QB → たこ形 → 折ると ℓ の左右が重なり、2つの角は等しく合わせて 180° → 90°。
- 「つぎ ▶」「◀ まえ」で1つずつ進み、最後に「🔁 折ってみる」。半径 r のスライダー（数でも入れられる）で形を変えても、等しい辺の関係は変わりません。

## 授業での使い方（例）

- **導入（5分）**：ワークシートの予想「垂直二等分線上の点 P から A、B までの距離は？」を挙手で集める。
- **展開①（15分）**：先生モードの「⏭ つぎの手順を自動で」で ① の手順を見せてから、生徒が自分で作図。できたら分度器・ものさしで確かめ、「📍 点 P を置く」で PA ＝ PB を3か所以上記録する。
- **展開②（10分）**：⑤ のひし形のアニメで理由を確認。「A と B から等しい距離の点の集まり」が垂直二等分線だから、同じ半径の円の交点を結ぶ。
- **練習（15分）**：② 角の二等分線、③ 垂線、④ 応用。
- **まとめ（5分）**：ワークシートの④に手順と理由を書く。

## つまずき検知の一覧

| 型 | どこで見つけるか | 練習する問題 |
|---|---|---|
| 半径が短くて、2つの円が交わらない | 2点を中心にする円で、半径が2点の間の半分以下 | ① 垂直二等分線 |
| 2つの円の半径を変えた | 2点を中心にした円が、どれも同じ半径になっていない | ① 垂直二等分線 |
| はりが点にささっていない | 円の中心が、点・交点のどれにもない | ① 垂直二等分線 |
| 定規を交点に当てていない | ひいた直線が、作図の点を2つ以上通っていない（その直線自身がつくった交点は数えない） | ① 垂直二等分線 |
| 目もりで測って作図しようとした | 作図ができる前に「長さを測る」を使った | ① 垂直二等分線 |
| 角の辺の上に、同じ距離の点をとっていない | ② で、O を中心にした円より先に、辺の上の点を中心に円をかいた | ② 角の二等分線 |
| 垂線で、P を中心にしないで円をかいた | ③ で、P を中心にせず、P も通らない円を先にかいた | ③ 外の点から |
| 半径を辺の長さにしていない | 正三角形・正六角形・30° で、半径が辺（半径）の長さとちがう | ④ 正三角形 |

「🔎 あなたのつまずき」に、この時間に出た型と説明が出ます。「🔁 この型を練習」で、その型の問題へ移ります。
記録は、この端末の localStorage（キー `ikechan-math-作図ツール`、ワークシートと同じ）に入ります：つまずきの型ごとの回数・問題ごとのできた数・ヒントの回数。先生モードで合計を見たり消したりできます。

## 正しさとじっさいとのちがい

- 作図は円と直線の交点の計算（平方根をふくむ）なので、小数で計算し、少しの誤差をゆるして判定しています：円の中心 0.15 cm、半径の等しさ 0.12 cm、点が直線の上にあるか 0.12 cm、角 1.5°。吸いつきを使えば、ぴったりの位置になります。
- 手順の判定は「その手順の線がかいてあるか」で見ます。順番がちがっても、線がそろえば ✓ になります。教科書とべつの正しい方法でも、正しい直線が作図の点を2つ以上通っていれば「できた」とします。
- 画面の 1 目もり（40 点）を 1 cm として長さを出しています（実物の 1 cm ではありません）。
- 円の接線は中3 の内容なので「発展」と書いています。

## 先生がかえやすいところ

- 問題（はじめの図・手順・判定・自動の作図・確かめ）：`PROBS`。パートと問題のならび：`PARTS`。
- ゆるす誤差：`TOL`、吸いつく距離：`MAG`。
- ⑤ の説明文と半径のはんい：`REASONS`。
- つまずきの型：`TRIPS` に名前・説明・練習する問題を書きます。
