# まわして ひらいて 角柱と円柱

小学5年生の算数「角柱と円柱」（東京書籍 新しい算数 5下 110〜119ページ）で使う教材です。次のことを体験します。

- 角柱・円柱の **底面**（2つ・平行で合同）と **側面**（角柱は長方形、円柱は曲面）
- □角柱の **頂点の数＝□×2、辺の数＝□×3、面の数＝□＋2**
- **見取図**（見えない辺は点線）
- **展開図**：2つの底面は側面をはさんで反対がわにつく。円柱の側面は長方形になり、**横の長さ＝底面の円周（直径×3.14）**

## 基本情報

- **ファイル**：`まわして ひらいて 角柱と円柱.html`。共通ファイル `worksheet.js`・`worksheet.css`・`math-render.js` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。立体を回す・ひらく計算もふくめて、すべて SVG とコードで描いています。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。立体を回すドラッグは pointer events でマウスでもタッチでも動きます。ボタンは48px以上。スマホのたて向きでも画面がはみ出しません。
- **漢字**：角柱・円柱・底面・側面・見取図・展開図・頂点・辺・円周 などのことばと、5年でまだ習っていない漢字にふりがなをつけています。「せってい」で消せます。
- **保存**：ワークシートと「せってい」を、このブラウザの localStorage（キー：`ikechan-math-まわして ひらいて 角柱と円柱`）に保存します。もんだいの成績は保存しません。
- **範囲**：底面は正多角形です。円周率は 3.14。発展（トイレットペーパーの芯をひらいた形）は入れていません。

## 3つの画面

### 🔄 まわして しらべよう

- 三角柱・四角柱・五角柱・六角柱・円柱をえらび、図をドラッグすると立体が回ります（上下は80°まで）。
- 「底面」で上下の底面（オレンジ・ぬりつぶし）、「側面」で側面（青・しま）を光らせます。
- 「見取図」をONにすると、見えない辺を点線でかいた見取図になります。OFFにすると、見える辺だけになります。円柱は、側面のりんかくの線と、底面の円（後ろ半分は点線）でかきます。
- 表（底面の形・側面の数・頂点・辺・面）は、えらんだ立体の行がうまります。三〜六角柱がそろうと「頂点＝□×2、辺＝□×3、面＝□＋2」のきまりが出ます。円柱には頂点と（直線の）辺がなく、側面が曲面で角柱と同じようには面を数えないので、頂点・辺・面は「−」です（底面・側面のらんで「円が2つ・曲面が1つ」とわかります）。
- 「ひとつ もどす」「もういちど」あり。ワークシートの「＋ きろくする」で、立体・数・気づいたことを記録します。

### 📦 ひらいて 展開図

- 底面の1辺（円柱は直径）と高さを −・＋ で変えられます（1〜8cm、高さ1〜10cm）。
- スライダー（数値入力つき）か「📦 ひらく」「🧊 とじる」で、立体が展開図にひらいていく様子を見せます。側面はとなりの側面との辺をちょうつがいにして1まいずつひらき、底面は側面の上と下の辺から90°ひらきます。100％で正面から見た展開図になり、長さ（側面の横の長さの合計、高さ）を書きこみます。
- 円柱では「⚪ 底面を ころがす」で、底面の円を展開図の下でちょうど1回転させ、すすんだきょり（赤い線）が側面の横の長さ（円周＝直径×3.14）と同じになることを見せます。
- 「組み立てられるのは どれ？」：3つの展開図から正しいものをえらびます。まちがいの展開図は、底面が同じがわに2つある図と、側面の数がちがう図（円柱は横の長さが直径の図）です。えらぶと、組み立てられない理由を出します。「ちがう 展開図」で作り直せます。

### ✏️ もんだい

- 4種類がまざって出ます（4問なら1つずつ、8問なら2つずつ）。
  - **立体の 名前**：見取図を見て、三角柱〜六角柱・円柱からえらぶ
  - **頂点・辺・面の 数**：三角柱〜十角柱（七角柱より上は図なし）
  - **展開図の 長さ**：直径□cm の円柱の側面の横の長さ（□×3.14）
  - **組み立てられる 展開図**：3つからえらぶ
- 答えは数字ボタン（PCはキーボードの数字・`.`・Backspace・Enter も可）で入れます。

## つまずき検知

| 型の名前 | 見つけ方 | 例 | 出す声かけ |
|---|---|---|---|
| 辺・頂点の 数えまちがい | 辺を□×2（底面の辺だけ）、面を□（側面だけ）、頂点を□（片方の底面だけ）と答えた | 七角柱の辺 → 14 | 辺は上の底面・下の底面・たての3つのなかま（□×3）。頂点は2つの底面にある（□×2） |
| 側面の 横の 長さ | 円柱の側面の横の長さを、直径のまま、または半径×3.14と答えた | 直径5cm → 5cm | 側面の横の長さは底面の円周と同じ。円周＝直径×3.14 |
| 底面の いち | 2つの底面が同じがわにある展開図をえらんだ | — | 2つの底面は側面をはさんで反対がわ（上と下）につく |

- 見つけた型は「あなたの つまずき」として出し、次にその型の「にた もんだい」を1問足します（「底面の いち」のにた もんだいは角柱の展開図）。
- 終わりの画面に、型ごとの回数を出します。

## 先生モード（アドレスの最後に `?teacher=1`）

- まわして しらべよう：「▶ じどうで まわす」で立体を回し続けます（もう一度押すと止まります）。
- ひらいて 展開図：「▶ じどうで ひらく」でひらいて、円柱なら底面をころがします。
- もんだい：「💡 こたえ」。ワークシートに、先生用のヒントと解答例が出ます。

## 授業での使い方の例

1. **角柱・円柱の特徴（2時間）**：「まわして しらべよう」で立体を回し、底面・側面を光らせて名前と特徴をまとめる → 三〜六角柱の表をうめ、きまりを見つける → 「もんだい」の頂点・辺・面の数（八角柱・十角柱）。
2. **見取図（1時間）**：「見取図」のON・OFFで見えない辺を点線にする意味を確かめ、ノートに見取図をかく。
3. **展開図（2〜3時間）**：「ひらいて 展開図」で三角柱・四角柱をひらく → 「組み立てられるのは どれ？」で底面の位置を話し合う → 円柱をひらいて「底面を ころがす」で側面の横の長さを確かめる → 「もんだい」。

## 正しさと、じっさいとのちがい

- 立体の見える面・見えない面は、面の向き（外向きの向き）を計算して決めています。角柱はへこみのない立体なので、見えない辺の点線は正しく出ます。
- 円柱は、細い長方形を48まいつないだ形（48角柱）でかいています。展開図の側面の横の長さの表示は、直径×3.14 で計算した値です（画面下にも書いています）。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| 底面／側面 | オレンジ／青 | ぬりつぶし／しま模様、「底面」「側面」の文字 |
| 見える辺／見えない辺 | 黒／灰 | 実線（太い）／点線（細い） |
| 正しい展開図／まちがいの展開図 | 緑／赤むらさき | 実線／点線のわく |
| 正解／まちがい | 緑／赤むらさき | ◎・△ の記号 |
