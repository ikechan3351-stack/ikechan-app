# 正負の数チップ（ゼロ対で正負の数のたし算・ひき算）

中学1年「正負の数」の加法・減法を、**＋1 のチップ**と **−1 のチップ**で目に見えるようにするアプリです。
＋チップと−チップの1組（**ゼロ対**）は 0 なので、消しても足しても数は変わりません。これを使って、たし算は「合わせてゼロ対を消す」、ひき算は「取る（足りなければゼロ対を足してから取る）」と考えます。

## 基本情報

- **ファイル**：本体 `正負の数チップ.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中1）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）・スマホ。
- **チップの形**：＋チップ＝**オレンジの丸に「＋」**、−チップ＝**青の四角に「－」**。あとから足したゼロ対のチップは**点線のふち＋「0」の印**。色だけでなく形でも見分けられます。
- **画面のならび**：左に「チップの置き場」、右に「式」と「結果」（広い画面では 置き場｜式｜結果 の3列、せまい画面では 式 → 置き場 → 結果 の順）。
- **URL の設定**
  - `?teacher=1` … 先生モード（手順の自動再生・ワークシートのヒントと解答例）
  - `?mode=add`・`?mode=sub`・`?mode=free` … はじめに開くモード
  - `?ws=0` … ワークシートをとじて開く

## 使い方

### ➕ たし算
1. 「最初の数」「次の数」を、「＋ 正」「− 負」と ▼▲（または数字の入力、0〜15）で選びます。「ためしてみよう」のボタンでもすぐに出せます。
2. 2つの数のチップが、＋の列と−の列に並びます（ゼロ対がたてにそろうように並べています）。
3. ゼロ対を消します。
   - **タップ**：＋チップ → −チップ の順に（逆でもよい）1つずつタップ。
   - **ドラッグ**：チップを反対の符号のチップに重ねる。
   - 「✨ ゼロ対をぜんぶ消す」：1組ずつ、ゆっくり消えます（間に「0」が出ます）。
4. ゼロ対がなくなると、残ったチップが答えです。式に「＝ 答え」、結果に「のこったチップ」が出ます。

### ➖ ひき算
1. 最初の数のチップだけが並びます。ここから、ひく数のチップを**取り**ます。
2. 取りたいチップをタップ（または「取ったチップ」へドラッグ）するか、「🫳 (−3) を取る」ボタン。
3. 取るチップが**足りない**ときは「＋ 足りない分だけゼロ対を足す」（または「＋ ゼロ対を1つ足す」）。式の下に「(+2) + 0 + 0 + 0」と出て、**0 を足しても数は変わらない**ことを見せます。
4. 取りおわったら、ゼロ対を消して答えを見ます。説明に「(+2)−(−3) = (+2)+(+3) = +5。(−3) を取ることは (+3) を足すのと同じ」が出ます。

### 🧩 じゆう
- 「＋1 を置く」「−1 を置く」「ゼロ対を置く（0 を足す）」でチップを置き、ゼロ対を消して、表す数を見ます。式を先に出しません。
- 「🎲 おだい」：「チップ 9 個で −5 を作ろう」のような問題が出ます（ゼロ対を使わないと作れない数にしています）。

### そのほか
- 「↶ ひとつもどす」：1つ前の操作にもどします（「ぜんぶ消す」「足りない分だけ足す」「取る」は、まとめて1回）。
- 「⟲ もういちど」：今の式のはじめの状態にもどします。
- 「消えるはやさ」：ゆっくり／はやい／アニメなし。
- 1つの列（＋・−）には**15個まで**置けます。こえる式は注意が出て置けません。

## ワークシート

| ステップ | 内容 |
|---|---|
| ① 予想 | 「(+2)−(−3) は、いくつ？」 −1／+5／−5／わからない ＋ 理由ひとこと |
| ② 操作 | ひき算モードでチップを動かし、答えが出たら「＋ 記録する」。式・足したゼロ対の数・答えが表に入る |
| ③ 気づき | 自由に書く |
| ④ まとめ | 式で書くと？（例 (+2)−(−3)=(+2)+(+3)）／ことばで言うと？（ひき算の意味） |

保存キーは `ikechan-math-正負の数チップ`（つまずきの記録も同じキーの中に入ります）。

## 授業例（中1・正負の数の減法）

1. **ふりかえり（5分）**：たし算モードで (+3)+(−5)。ゼロ対を消すと −2 が残ることを確認。
2. **予想（5分）**：ワークシート①で (+2)−(−3) を予想させる。
3. **困らせる（5分）**：ひき算モードで「(−3) を取る」を押させる → 「取れないのに取ろうとした」が出る。
4. **ゼロ対を足す（10分）**：「0 を足しても数は変わらない」をヒントに、ゼロ対を3組足してから −チップを3個取る。残りは ＋チップ5個。
5. **比べる（10分）**：(+5)−(+2)（そのまま取れる）、(+2)−(+5)（ゼロ対が必要）もためし、「ひく＝符号を変えて足す」を④まとめに書く。
6. **じゆう（5分）**：おだいで、同じ数をいろいろなチップの置き方で作る。
- 先生モードの「▶ 手順を自動再生」で、ゼロ対を足す → 取る → 消す を続けて電子黒板に見せられます。

## つまずき検知の一覧

| 型の名前 | どんなときに出るか | 画面のことば（要点） |
|---|---|---|
| 🫳 取れないのに取ろうとした | ひき算で、取るチップが足りないのに「取る」を押した | このままでは取れない。ゼロ対を足すと、数を変えずに −チップ（＋チップ）をふやせる。足りない○個ぶん、ゼロ対を足してから取ろう |
| ± 取るチップのまちがい | ひき算で、ひく数と反対の符号のチップをタップした | 取るのは −チップ（＋チップ）。反対を取ると、符号を変えた数をひいたことになる |
| ＝ 同じ符号どうしを消そうとした | ＋と＋、−と−をゼロ対として消そうとした | ゼロ対は ＋1 と −1 の1組 |

- 「取れないのに取ろうとした」では「▶ ゼロ対を足すところを見る」（足りない分をゆっくり足す）と「🔁 類題」（答えを先に決めて作った、ゼロ対が必要なひき算）のボタンが出ます。「足りない分だけゼロ対を足す」ボタンも光ります。
- 記録は「📒 つまずきの記録」に回数で出ます（「記録を消す」で消せます）。

## 正しさ・じっさいとのちがい

- チップは整数だけ、1つの列に15個までです。ほんとうの正負の数には小数や分数、もっと大きな数もあります（画面にも「※じっさいとのちがい」として書いています）。
- 計算は整数だけなので誤差はありません。
- ひき算で取るチップは、あとから置いたチップから取ります（どのチップを取っても答えは同じです）。
