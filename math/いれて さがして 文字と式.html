❓ 先生へ（つかい方）

6年「文字と式」（東京書籍 新しい算数 6年）の教材です。いろいろな数のかわりに x を使って式に表し、x に数を入れて式の値を求めること、x と y の関係を式に表すこと、y の値から x を求めることを、場面の絵と矢印の図で見ていきます。6年なので × ははぶかずに x×4 と書きます（はぶく書き方は中1）。

✋ x に いれて みよう

  • 場面は3つ：正方形のまわりの長さ（x×4）／テープをつなぐ（x＋25）／ケーキ5こと箱代80円（x×5＋80）。
  • ステップ1「数で 書こう」：1辺の長さなどを変えるたびに、数の式（3×4＝12 など）がたまります。ちがう数で3つ書くと、ステップ2へすすむボタンが出ます。
  • ステップ2「x で まとめよう」：式は x×4 のまま。数を変えると「x に 3 を いれると 3×4＝12」と、x の場所に数が入り、式の値が出ます。
  • ステップ3「x と y」：答えの方も y にして x×4＝y。表に x と y の組がたまります。
  • 「🔍 x を さがす」：y の値（例：36）が出るので、x をためして「大きすぎ／小さすぎ」を見ながら見つけます。「💡 もどり道」で、矢印をぎゃくにたどる計算（36÷4）を見せます。
  • つまずき検知（さがすで見つける2つの型）：
    • 「もどすとき 同じ計算」… x×4＝36 で 36×4＝144 のように、もどすときも同じ計算をした（ケーキの場面では 830×5＋80、(830＋80)×5、830×5 も同じ型）
    • 「x と y の とりちがえ」… y の値をそのまま x と答えた

🔗 式を よもう

  • 👀 式を よむ：場面（えんぴつとノート／クッキーのふくろとばら／のこりのお金／リボンを分ける／長方形の面積）の式を、x・×3・＋120 のような「かけら」に分けて出します。かけらをタップすると、絵のどこにあたるかが光り、いみが出ます。ぜんぶタップすると、式全体のいみのまとめが出ます。
  • 🔗 場面と 式を むすぶ：場面3つと式4つ（1つはまちがいの式）を、タップで線でむすびます。場面からでも式からでもえらべます。むすび終わったら、あまった式がどんな場面かを話し合わせられます。
  • つまずき検知「かける数の いちちがい」… x×5＋80 の場面に (x＋80)×5 をえらぶなど、1つしかない数（箱代）までかけてしまう型。

✏️ もんだい

  • 5種類がまざって出ます：場面を式に（3つからえらぶ）／式の値（x が 9 のとき x×7＋30 など）／x をもとめる（x×4＋30＝78 など）／式から場面（3つからえらぶ）／式をよむ（「×3」は何を表す？）。問題の数は「せってい」で5か10にできます。
  • えらぶ問題は1回、数を入れる問題は2回まで答えられます。「💡 ヒント」で、x をもとめる問題では矢印の図（もどり道）が出ます。
  • つまずき検知（3つの型）：
    • 「かける数の いちちがい」… 場面を式にする問題で (x＋80)×5 をえらんだ／式の値で、たしてからかけた答え（(9＋30)×7＝273）を入れた
    • 「もどすとき 同じ計算」… x をもとめる問題で 78×4＋30 などを入れた
    • 「x と y の とりちがえ」… 式の右がわの数をそのまま答えた
    見つけた型は「あなたのつまずき」として出し、次にその型の「にた もんだい」を1つ足します。最後に回数をまとめ、もどって練習する画面へのボタンを出します。

👩‍🏫 先生モード（アドレスの最後に ?teacher=1）

  • ステップ1〜3：「▶ じどうで いれる」で数を順に入れていきます。ステップは最初からどれでもえらべます。
  • さがす：「💡 こたえ」で答えと、もどり道の計算を出します。ワークシートにもヒントと解答例が出ます。
  • 式を よむ：「▶ じどうで よむ」でかけらを順に光らせます。むすぶ：「💡 こたえ」でぜんぶ線でむすびます。
  • もんだい：「💡 こたえ」で答え（x をもとめる問題はもどり道の計算も）を出します。

ワークシートと設定は、このブラウザの localStorage（ikechan-math-いれて さがして 文字と式）に保存されます。もんだいの成績は保存しません。
