⚖️ 天秤で方程式

箱(おもり・＋)と風船(うかせる・−)で、等式の性質を体で感じよう!

✏️ じぶんで問題をつくろう(数字は −9〜9)
答えが分数になる問題もOK!
x + = x +
ここに操作のきろくが出るよ

📝 式のきろく

書き方:

🔎 あなたのつまずき

つかい方

  • 箱は重り(＋)、風船は浮かせる(−)。x の箱の重さはひみつの数だよ。
  • 📦1 の箱と 🎈−1 の風船を同じ皿にのせると、(＋1)＋(−1)＝0。重さが消える「0 のペア」だよ(正負の数と同じ)。
  • ①ならべる:式のとおりに、左右の皿にパーツをおこう(タップでおく、皿の上のパーツをタップするともどせる)。まちがえると天秤がかたむくよ!
  • ②とく:🗑ゴミばこに「両辺から同じものを1こずつ」すてられるよ(皿のパーツをタップでもOK)。式にマイナスがあるときは🎈風船も登場!正しい操作なら天秤はぜったいかたむかない!
  • 「x の箱1こ = 数字」の形になったらクリア!🎉 解いた手順は「📝式のきろく」に式で残るよ。
  • ②移項:皿のパーツをタップ(または反対の皿へドラッグ)すると、その項がまるごと反対の辺へ。箱は風船に、風船は箱にかわる=符号がかわる。「しくみをゆっくり見る」をオンにすると、「両辺から同じ数をひく → 0 のペアが消える」の2つの動きで、なぜ符号がかわるのかが見えるよ。
  • ③x が両辺:「両辺から x をひく」か、x の項を移項して、x を片方の辺に集めよう。
  • 「📝式のきろく」は、等式の性質で(とちゅうの式もぜんぶ)と移項で(教科書の書き方)を切りかえられるよ。
  • x の係数がマイナスになったら ✖ 両辺に −1 をかける。まちがえたら ↶ ひとつもどす。
  • ✏️つくるで、じぶんだけの問題も作れるよ。答えが分数になる問題もOK——「2x = 5」みたいにもうわれなくなったら、x = 5/2 と分数で答えが出るよ!

※じっさいとのちがい:答えがマイナスになる問題でも、x の箱は箱の形のままかいています(本当なら x の箱も浮きます)。
