# 🥢 さんすうセット② かぞえぼう・タイル

小学1〜3年向けの（1000までの数）、**かぞえぼう（数え棒）とタイル**を画面で動かすボードです。10のまとまり・100のまとまりを手で作ったり、ばらしたりして、数のしくみ（十進位取り）を体で感じるための道具です。決まった問題や正解はありません。

- 「さんすうセット① おはじきボード」をもとにしています。ペン・もどる・はいけい・しゃしん・先生用（もんだい・くばる）・ひらく は ① と同じです。
- わく（部品）は、あとで考えます（下の「これからの予定」）。

## 基本情報

- **ファイル**：`さんすうセット② かぞえぼう・タイル.html`。この1ファイルだけで動きます（ネット接続・外部ライブラリ・画像ファイルは不要）。
- **対応する機器**：タッチできる Chromebook（主に想定）、電子黒板、マウス・トラックパッド。
- **マルチタッチ**：指1本ずつ別々に追いかけるので、何人かで同時に動かせます。

## 部品

| 大きさ | かぞえぼう（🥢 ぼう） | タイル（🟦 タイル） |
|---|---|---|
| 1 | 1本 | 1のタイル（正方形1まい） |
| 10 | 10本たば（あかい わゴムで とめる） | 10のタイル（たて・よこ に おける） |
| 100 | 100本たば（10本たば10こを あおい 太い ひもで とめる） | 100のタイル（10×10の 正方形） |
| 1000 | 1000本たば（100本たば10こを むらさきの ひもで とめる） | 1000のタイル（100の板を10まい かさねた 立体） |

- タイルは **大きさのつり合いが正しい** 形です（10のタイルは1のタイル10こ分、100のタイルは10のタイル10本分）。
- **※じっさいとのちがい**：1000本たば・1000のタイルは、ボードに入るように **本当より小さく** かいています。小さくても1000だと分かるように「1000」の札を付けています。1000をばらすと 100が10こ出ますが、100は本当の大きさなので、ボードいっぱいに少しずつ重なって並びます。
- タイルの中の線は 5マスごとに太くして、5のまとまりが見えるようにしています。
- 棒の色はすべて同じで、わゴム（10）は あか・細め、ひも（100）は あお・太め と、色だけでなく太さでも区別できます。

## 使い方

| 操作 | どうなるか |
|---|---|
| 道具箱の上の **タブ**（🥢ぼう・🟦タイル・🔢カード） | 道具箱の中身を切りかえる。ボードの上のものは消えない（ぼうとタイルを いっしょに 置ける） |
| 道具箱を **タップ** | 1こ出る（左上から順に、あいている場所に並ぶ） |
| 道具箱から **引っぱる** | すきな場所に置ける |
| ボードの上のものを **引っぱる** | 動く。さわったものは一番前に出る |
| ボードの上のものを **タップ** | **向きが かわる**（たて ⇔ よこ）。1本・10本たば・100本たば・10のタイル |
| ボードの上のものを **長押し** | **ばらす**。オレンジの わ（✂️）が いっぱいになると、1つ下の もの 10こ に分かれて、その場で広がる。10本たば → 1本×10、100本たば → 10本たば×10、1000本たば → 100本たば×10（タイルも同じ） |
| **🔗まとめる** をおして、同じものを **10こ えらぶ** | えらび方は2つ。① **1こずつ タップ**（えらんだものに 1・2・3…と番号がつく。もう1回タップで はずす） ② **ゆびで ぐるっと かこむ**（中のものを まとめて えらぶ）。①と②はまぜて使える。10こ そろうと、まん中にあつまって ぽんっと 1つ上のたばになる（1本×10 → 10本たば、10本たば×10 → 100本たば、100本たば×10 → 1000本たば。タイルも同じ）。ボードのふちが みどりになる |
| ごみばこ（右下）か道具箱にもどす | 消える |
| ✏かく・🧽せんを けす・↩もどる・🖼はいけい・📷しゃしん・📂ひらく・🧹かたづける | ① と同じ |

- 長押しのとちゅうで指を動かすと、ばらさずに ふつうに動かせます（ばらすのは指を止めたときだけ）。
- ばらしたあとも ↩もどる で もとの たばに もどせます。
- **まとめる**は、えらんだ数が10こになったときだけ まとまります。とちゅうは「4こ。あと 6こで まとめられるよ」と出ます。11こ以上えらんだときは、タップで はずして10こにします。自分で10こを数えて えらぶことが、10のまとまりの学習になるからです。
- かこみは、とじていなくても、棒のはしが はみ出していても入ります（部品の半分くらいが入っていれば えらばれます）。
- ちがう種類をえらぶと、えらびなおしになります。なにもない所をタップしても えらびなおしになります。
- できるたばの向き：棒は たて・よこ の多いほうの向き、1のタイルは かこんだ並びが よこ長なら よこ向きの10のタイルになります。
- まとめるモードのあいだは、ものは動かせません（「✋うごかす」にもどすと動かせます）。
- **かず表示（自動で数える）はありません。** 自分で数える学習を大事にするためです。
- 安全のため、同じものは100こまで（たて・よこを合わせて）です。100こをこえるときは ばらせません。

## はいけい（🖼 ボタン）

① と同じです（むじ・ほうがんし・さんすうノート・がぞう、色は しろ・クリーム・こくばん）。ちがうところは次のとおりです。

- **くらいどりひょう**：見出しに「百の くらい・十の くらい・一の くらい」が入った表です。
  - けたの かず：**十・一（2けた）** ／ **百・十・一（3けた）** ／ **千・百・十・一（4けた）**
  - だんの かず：**1だん〜4だん**。2だんは たし算・ひき算で2つの数を上と下に分けて置くとき、3だん・4だんは 答えのだんを作るときや、いくつかの数をくらべるときに使います。
  - 4けたでも、1つのくらいの はばに 100本たば・100のタイル・1000のかたまりが入ります。だんを増やすと高さがせまくなるので、大きいたばは はみ出します。すいつきはありません（自由に置けます）。
- **ふたつに わける**：まん中に点線が1本入った紙です。**ひだり と みぎ** ／ **うえ と した** を選べます。合成・分解（いくつと いくつ）、2つの数をくらべるときなどに使います。
- **ほうがんし の「タイルの マス」**（はじめの大きさ）：マスがタイル1こと同じ大きさです。**タイルを置くと、マスにぴったり すいつきます**（かどがそろう）。10マスごとに いちばん こい線が入ります。
- 「おおきい」（70）は 数字カードがマスにすいつきます。
- URL で はじめの形を決めて配れます：`?board=tile`（タイルのタブから始める）、`?bg=grid&size=T`（タイルの マスの 方眼紙）、`?bg=place&cols=4&rows=3`（くらいどりひょう 4けた・3だん。cols は 2〜4、rows は 1〜4）、`?bg=split&dir=tb`（ふたつに わける・うえと した）、`?color=cream` など。
- くらいどりひょう・ふたつに わける の選び方も、💾くばる 画像に入ります。

## 先生用（`?teacher=1`）

① と同じです（📝もんだい・💾くばる）。くばる画像には、かぞえぼう・タイルの向きもそのまま入ります。

- ① の画像と ② の画像は区別しています。② で ① の画像を開くと「① で ひらいてね」と出ます。

## 授業例

**1年「大きい かず」（10のまとまり）**
1. 1本を 23本 タップで出す（黒板の数は先生が出す）。
2. 🔗まとめる で 10本ずつ かこんで 10本たばにし、「10が 2つと 1が 3つ」と書く。
3. 10本たばと1本で 同じ数を作って、くらべる。📷しゃしん → ロイロに提出。

**2年「たし算の ひっ算」（くり上がり）**
1. はいけいを くらいどりひょう（2けた・2だん）にし、上のだんに 38、下のだんに 25 を タイルで作る。
2. 一のくらいの1のタイルを集め、**🔗まとめる で 10こを かこんで** 10のタイルにし、十のくらいへ動かす（くり上がり）。
3. ひき算のくり下がりは、10のタイルを **長押しで ばらして** 1のタイルにし、一のくらいへ動かす。

**2年「1000までの 数」**
1. はいけいを くらいどりひょう（4けた・1だん）にする。
2. 100本たばを10こ 出して、🔗まとめる で1000本たばにし、千のくらいへ動かす。「100が10こで1000」を確かめる。

- はじめての時間は、タップ（向き）と長押し（ばらす）の ちがいを 全員でためすとスムーズです。

## しくみ（コードのつくり）

- 部品の表 `PIECES` の各行に、`turn`（タップで かわる 向きの 部品）と `split`（ばらしたときの 部品 `to` と 並べる向き `dir`）があります。向きを変えるのは「たて用の部品」と「よこ用の部品」を取りかえるしくみなので、もどる・くばる画像にもそのまま入ります。
- よこ向きの絵は、たて向きの SVG を `turned()` で 90度 まわして作っています。
- 長押しの長さは 定数 `LONG_MS`（600ミリ秒）、指のぶれの許し は `MOVE_TOL`（8px）です。
- ばらすときは、たばの中の位置に10こを置いてから、CSS の transition で広がる場所へ動かします（`splitItem()`）。ボードからはみ出すときは まとめて内側にずらします。長すぎるときは2列に おりかえします。
- 細い棒や小さいタイルは、見た目より少し広い範囲で さわれるようにしています（CSS の `.piece.pad::before`）。
- **まとめる**：表 `TIE` に「10こで なるもの（たて v・よこ h）」を書いています。えらんだものは配列 `picked` に入れ、番号のしるしを `drawMarks()` で出します。指の動いた長さが25より短ければタップ、長ければ かこみ とみます。かこみは「線を何回またぐか」で しらべ（`insidePoly()`）、部品の中心か、部品の中の9この点のうち4こ以上が入っていれば えらびます（`lassoHits()`）。10こ そろったら まん中にあつめ、0.38秒後に たばに取りかえます（`tieItems()`）。
- 1000をばらしたときなど、1れつがボードに入らないときは、少しずつ重ねて並べます（`splitItem()` の `stepA`）。
- **くらいどりひょう・ふたつに わける**は、背景のキャンバスに `drawPlace()`・`drawSplit()` で描いています。紙の色ごとの線・見出しの色は `BG_COLORS` の `strong`・`head`・`text` です。
- 盤面を画像に入れるしくみは ① と同じで、箱の名前だけ `sansuset2-board` にしています。

## 動作確認の方法

1. Chrome で開き、ぼう・タイルの各部品をタップで出す、引っぱって置く、ごみばこで消す。
2. タップで向きが変わる、長押しで わ が いっぱいになり ばらける、もどるで もどることを確かめる。
3. 🔗まとめる で、1本をタップで1こずつえらぶ（番号がつく・もう1回タップで はずれる）、ざっくり かこむ、10こで たばになる、もどるで もどることを確かめる。100本たば10こで1000本たばになることも確かめる。
4. はいけい → くらいどりひょう（けた 2〜4・だん 1〜4）、ふたつに わける（むき）、ほうがんし（タイルの マス。タイルがすいつく）を確かめる。
5. Chromebook 実機で、指で長押ししても ばらせるか（指のぶれで取り消されないか）、細い1本を つかめるかを確かめる。
