# 🟦 さんすうセット① おはじきボード

小学1・2年向けの、算数セット（数図ブロック・おはじき）の代わりに画面で使えるボードです。**決まった問題や正解はありません。** 子どもが自分の考えをブロックで表し、囲む・矢印・数字を書きこんで、「こうやって考えた」と説明するための道具です。

- 1〜6年向けで道具の多い「ブロック・おはじき操作盤」とは別のアプリです。低学年向けにしぼり、**指で動かしたときのなめらかさ**をいちばん大事にしています。
- 企画メモ：脳メモ `教材開発/企画/2026-11-11_さんすうセット ボード.md`

## 基本情報

- **ファイル**：`さんすうセット① おはじきボード.html`。この1ファイルだけで動きます（ネット接続・外部ライブラリ・画像ファイルは不要）。
- **対応する機器**：タッチできる Chromebook（主に想定）、電子黒板、マウス・トラックパッド。
- **大きさ**：ボードは画面の大きさに合わせて自動で拡大・縮小します。電子黒板ではそのまま大きく映ります（先生用モードは分けていません）。
- **マルチタッチ**：指1本ずつ別々に追いかけるので、何人かで同時に動かせます。

## 使い方

| 操作 | どうなるか |
|---|---|
| 道具箱の上の **タブ**（もの・わく・カード） | 道具箱の中身を切りかえる |
| 道具箱の「かぞえる もの」を**タップ** | 1こ出る（上から順に、あいている場所に並ぶ）。ブロック（あお／あか）・おはじき（あか／きいろ／あお）・ちょうちょ・はな・ケーキ・おとこのこ・おんなのこ |
| 道具箱の「わく・おさら」を**タップ** | 5・10・20・100の わく、おさら が、あいている場所に出る（100の わくは 大きいので、いつも まん中に出ます） |
| かぞえる ものを わくの上で はなす | あいているマスの まんなかに すいつく |
| わく・おさらを 動かす | 上にのっているものも いっしょに動く（ごみばこに入れると、のっているものも いっしょに消える） |
| 道具箱から**引っぱる** | すきな場所に置ける |
| ボードの上のものを引っぱる | 動く。さわったものは一番前に出る（重なっても取り出せる） |
| ごみばこ（右下）か道具箱にもどす | 消える |
| ✏かく／ペンの色（くろ・あか・あお・みどり・オレンジ・むらさき） | 指で書ける。ボードのふちがオレンジになる |
| 🧽せんを けす | 書いた線だけを全部消す |
| ↩もどる／↪やりなおす | 50回までもどせる（Ctrl+Z／Ctrl+Y） |
| 道具箱の「すうじ カード」 | 0〜9 と ＋・−・×・＝・＞・＜・？ のカード。わくや、方眼紙（おおきい）・さんすうノートのマスにすいつく |
| 📂ひらく | 先生が配った「ボード入りの画像」（PNG）をえらぶと、うごかせるボードとして開く。画像ファイルをボードの上にドラッグしても開ける |
| ⟲はじめに | 配られた画像を開いたあとだけ出る。配られたときの状態にもどす（もどるで戻せる） |
| 🖼はいけい | 下にしく紙を選ぶ（くわしくは下の「はいけい」） |
| 📷しゃしん | ボードを画像にしてコピー。ロイロノートなどで Ctrl+V ではりつけて提出。コピーできないときは画像ファイル（ボード入り）として保存 |
| 🧹かたづける | 確認してから全部消す（もどるで戻せる） |

- 問題文はアプリには出しません（黒板・スライド・教科書で出します）。式やメモは、ボードのあいているところにペンで書きます。
- おはじきは色だけでなく模様でも見分けられます（あか＝むじ、きいろ＝わ、あお＝白いてん3つ）。
- わくは 5こごとに 太い線が入っています（5のまとまりが見えるように）。100の わくは マスがブロックと同じ大きさなので、ボードのほとんどを使います。
- **かず表示（自動で数える）はありません。** 自分で数える学習を大事にするためです。

## はいけい（🖼 ボタン）

| かみ | えらべること |
|---|---|
| むじ | なにもない紙 |
| ほうがんし | マスの大きさ：おおきい（70。ブロックがちょうど1マスに入り、**マスにすいつく**）・ふつう（35）・ちいさい（20）。ふつう・ちいさいは5マスごとに少しこい線 |
| さんすうノート | よこに ならぶ マスの数：12マス・15マス・18マス。マスの中に十字の点線 |
| がぞう | 「📂 がぞうを えらぶ」で写真などを取りこむ。ボードに入る大きさにちぢめて、まん中におく。「うすくする」で上のブロックを見やすく（はじめはオン）。ボード入りの画像をえらんだときは、背景ではなく「📂ひらく」と同じように開く |

- **かみの いろ**：しろ・クリーム（電子黒板のまぶしさをおさえる）・こくばん（みどり）。どの紙とも組み合わせられます。
- 背景は道具の下にしく紙なので、取りかえても道具の位置は変わりません。📷しゃしんにも写ります。
- **がぞう**は、そのパソコンのブラウザの中だけで使い、どこにも送りません（ページを閉じると消えます）。子どもの顔が写った写真や教科書の挿絵は、授業の中だけで使い、しゃしんの公開はしないでください。
- **URL で はじめの背景を決めて配れます**：`?bg=grid&size=L`（方眼紙・おおきい）、`?bg=note&size=15`（ノート15マス）、`?color=cream`（クリーム）など。`bg` は plain・grid・note、`size` は方眼紙なら L・M・S、ノートなら 12・15・18、`color` は white・cream・green。がぞうは URL では指定できません。

## 先生用（`?teacher=1`）

URL のうしろに `?teacher=1` を付けて開くと、先生用のボタンが2つ増えます。子ども用の画面には出ません。（Mac で試すときは、Chrome のアドレス欄の最後に `?teacher=1` を足して Enter）

| ボタン | できること |
|---|---|
| 📝もんだい | **もんだいカード**をつくる。文を打ちこみ、文字の大きさ（おおきい・ふつう・ちいさい）を選ぶ。Enter で行を変えられ、長い文はスペース（分かち書き）の位置で自動で折り返す。ボードの上のほうに出る |
| （もんだいカードを タップ） | 書き直す・消す |
| 💾くばる | いまの盤面（もんだいカード・数字カード・ブロック・わく・おさら・ペンの線・はいけい）を入れた **ボード入りの画像（PNG）** をつくる。見本を見てから「💾ほぞんする」で `もんだい_○月○日.png` として保存 |

- 子どもは、もんだいカードを動かせますが、書き直したり消したりはできません（ごみばこに入れても元の場所にもどる）。
- 子どもは配られた盤面から自由に動かせます。散らかったら「⟲はじめに」で配られたときの状態にもどせます。
- **配りかた**：① 💾くばる で画像を保存 → ② Classroom などで配る → ③ 子どもは画像を Chromebook に保存し、ボードの「📂ひらく」でえらぶ。
- ふつうの画像ソフトで見ると、ただの問題の絵に見えます（そのまま印刷や掲示にも使えます）。
- 先生も「📂ひらく」でその画像を開けば、あとから直して配りなおせます（`?teacher=1` で開いてから）。
- 取りこんだ画像の背景は入りません（むじになります）。
- **注意**：画像を「別の形に保存しなおす」アプリ（JPG に変える・ちぢめる・スクリーンショットを撮る など）を通すと、中の盤面が消え、ただの絵になります。そのときは「この がぞうには ボードが 入っていません」と出ます。Classroom・Google ドライブはファイルをそのまま渡すので使えます。ロイロノートで配るときは、はじめに1回ためしてください。
- 盤面は画像ファイルの中だけに入れていて、ネット上のどこにも保存しません。

## 授業例（1年 たし算、10〜15分）

1. 先生が黒板に問題を出す。子どもはボードの上のほうに「5＋3」と書く。
2. ブロックを5こと3こ出して、寄せる。
3. ✏かくで、まとめて囲み「8」と書く。
4. 📷しゃしん → ロイロノートに提出。先生が2〜3人の板を電子黒板に映し、説明させる。

- はじめての時間は、うごかす／かくの切りかえと、しゃしん → ロイロにはりつける手順を全員でそろえてやるとスムーズです。
- 導入の最初の1回は本物の算数セットで手ざわりを経験させ、そのあとボードに移る使い分けをおすすめします。
- 「つかう数だけ出す」「絵をかかない」などは、授業の約束で伝えます（アプリでは制限していません）。

## つまずきへの手だて

- **ばらばら置き型**（そろえずに置くので数えまちがう）：タップで出すと横一列に並ぶ。5・10・20・100の わくに のせると マスにすいつく。
- **二度かぞえ型**：2番目の版で、タップした順に番号が出る「かぞえたしるし」を入れる予定。

## しくみ（コードのつくり）

- ボードはよこ1200×たて720の決まった大きさで作り、画面に合わせて CSS の `transform: scale()` でまるごと拡大・縮小しています。
- **なめらかさのくふう**：ブロック1こ1こを別の要素にして `transform` で位置だけ動かし、指の動きは `requestAnimationFrame` で1コマに1回だけ反映します（ボード全体を描き直さない）。`touch-action: none` でブラウザのスクロールやズームに横取りさせません。
- **手のひら除け**：さわった面が大きすぎるタッチ（45px より大きい）は、手のひら・そでとして無視します（定数 `PALM`）。
- **安全上限**：1種類100こまで（定数 `MAX_PER_TYPE`）。なめらかさを守るためです。
- **道具の表 `PIECES`**：1行足すと道具が増えます。絵はすべてコードで描いた SVG（`svgBlock`・`svgButterfly` など）。`kind` が `count`＝かぞえる もの、`frame`＝わく（マスにすいつく）、`plate`＝おさら（のせて いっしょに動かす）。
- **ボードの表 `BOARDS`**：道具箱の見出しと並べる道具を決めます。`?board=名前` で最初のボードを指定できます（今は `block` だけ）。
- **しゃしん**：素材の SVG を画像にして、1まいの絵に描き直しています。
- 状態は `items`（ブロック・おはじきの位置）と `strokes`（ペンの線）の2つの配列だけ。「もどる」はこの2つのコピーを戻すしくみです。
- 保存（localStorage）はしていません。ページを閉じるときは確認が出ます。

## 盤面を画像に入れるしくみ

- `packState()` が盤面を JSON にし、ブラウザの `CompressionStream`（deflate）でちぢめて、英数字（base64url）にします。
- PNG 画像は「チャンク」という小わけの箱がならんだファイルです。`addBoardToPng()` が、絵には関係ない文字の箱（`tEXt`、名前は `sansuset-board`）を最後の箱（IEND）の前に1つ足し、そこに盤面を入れます。
- `readBoardFromPng()` がその箱をさがし、`unpackState()` と `applyState()` で盤面にもどします。知らない種類やおかしな数は捨ててから取りこみます。
- ペンの線は、点を1つおきに間引いて小さくしています。
- 📷しゃしんのクリップボードへのコピーは、ブラウザが画像を作りなおすので盤面は入りません（提出用なので問題ありません）。

## 動作確認の方法

1. `さんすうセット① おはじきボード.html` を Chrome で開く。
2. 道具箱をタップして1こずつ出る、引っぱって置ける、ごみばこで消える、もどる・やりなおすを確かめる。
3. ✏かくで線を書き、🧽で消す。📷しゃしんでコピーし、ロイロノートにはりつけられるか確かめる（コピーは https の公開ページで動きます）。
4. Chromebook 実機で、指2本で同時に別々のブロックを動かしても引っかからないか確かめる。

## つづきから（自動保存）

- うごかす・かく たびに、その端末（ブラウザの localStorage、キー `ikechan-math-さんすうセット① おはじきボード`）に自動で保存します。
- 次に開いたとき「まえの つづきから はじめますか？」と出て、**▶ つづきから**／**あたらしく** をえらべます。「あたらしく」をえらぶと、前の保存は消えます。
- 保存されるのは、置いたもの・手がきの線・はいけいの種類です。写真のはいけいと「もどる」の記録は保存されません。
- ぜんぶ かたづけて何もなくなると、保存も消えます。保存できない端末（プライベートブラウズなど）でも、そのまま使えます。
- 同じ端末を何人かで使うときは、前の人のボードが「つづきから」に出ます。新しく始める人は「あたらしく」をえらんでください。
