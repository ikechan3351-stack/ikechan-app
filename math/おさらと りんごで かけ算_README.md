# おさらと りんごで かけ算

小学2年生の算数「かけ算」の導入で使う教材です。
お皿に同じ数ずつリンゴを並べる操作を通して、かけ算が

> **1つ分の数 × いくつ分 ＝ ぜんぶの数**

であることを体感します。特に次の3つを理解できるようにしています。

- 「同じ数ずつ」でないと、かけ算にならないこと
- かける数（いくつ分）が1ふえると、答えはかけられる数（1つ分）だけふえること
- 2×3 と 3×2 は、答えは同じでも場面（意味）がちがうこと

## 基本情報

- **ファイル**：`おさらと りんごで かけ算.html`。この1ファイルだけで動きます（ネット接続・外部ライブラリ・画像ファイルは不要。絵はすべてSVGで描いています）。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）・スマートフォン。画面の高さに合わせて、テーブルとお皿の大きさが自動で変わります。
- **漢字**：2年生までに習う漢字だけを使い、ふりがなは「せってい」で消せます。
- **姉妹教材**：「九九フラッシュカード」「九九マスター」「いくつ×いくつ？」。この教材で意味をつかんでから、九九の練習へつなげられます。

## 色と形のきまり（いちばん大事なしくみ）

かけられる数とかける数の取りちがえを防ぐため、ことば・式の数字・絵を同じきまりでつないでいます。色だけでなく、しるしと下線の形でも区別できます（色覚の多様性への配慮）。

| 意味 | 色 | しるし | 下線 | 絵の中では |
|---|---|---|---|---|
| 1つ分（かけられる数） | 赤 | ● | まっすぐな線 | お皿の上の「●3こ」、1まいめのお皿の赤いわく |
| いくつ分（かける数） | 青 | ■ | なみ線 | お皿の下の番号「■1 ■2 ■3…」 |
| ぜんぶの数（答え） | みどり | ★ | 二重線 | 「かぞえる」で出る 3、6、9、12 |

## モード

1. **じゆうに ならべる**
   - 「おさら（いくつ分）」と「1さらの りんご（1つ分）」の＋／−で数を変えると、上に「●3こずつ」→「●3こずつ ■4さら分 ➡ 3×4＝12」と出ます。
   - 左の「かご」からリンゴを指（マウス）でひっぱって、1こずつお皿にのせられます。お皿のリンゴを、かごやほかのお皿へ動かすこともできます。
   - 数がそろっていないお皿があると「おなじ数ずつ かな？」と出て、かけ算の式は消えます。かわりに「たし算で もとめよう 3＋4＋3＋3＝13」とたし算の式が出ます。ちがうお皿は点線のわくで囲まれます。
   - お皿を1まいふやすと、ふえたお皿とリンゴが光り、答えの横に「＋3」が出ます。「ぜんぶの 数は ●3こ ふえるね（9 ➡ 12）」と表示されます。
   - 「かぞえる」を押すと、お皿ごとに 3、6、9、12 と数え、式が「3＋3＋3」とのびていき、最後に「3＋3＋3＋3 ➡ 3×4＝12」にかわります（同数累加）。
2. **しきに しよう**：お皿とリンゴの絵を見て、「□こずつ □さら分 ➡ □×□＝□」の□に数字ボタンで答えを入れます。□を押すと、入れる場所をえらべます（パソコンではキーボードの数字・Enter でも入力できます）。
3. **ならべて みよう**：「4×3 の えに なるように ならべよう」と出るので、お皿とリンゴを並べて「できた！」を押します。いまの並びが「いま：●4こずつ ■2さら分」のように出るので、自分で確かめながら並べられます。
4. **ばめんを えらぼう**：文章題を読み、「6×2」「2×6」のどちらが正しい式かをえらびます。
   - 場面は、はことケーキ・車とタイヤ・花びら・ふくろとみかん・おさらとりんご・くつした（2まいで1くみ）の6種類です。
   - 「ふくろが 3つ あります。1ふくろに みかんが 4こずつ…」のように、**いくつ分が先に書かれた文**もまぜています。出てきた順に式を書くまちがいに気づかせるためです。
   - 正解すると絵が出て、「●1つ分は 4こ、■いくつ分は 3ふくろ。だから 4×3＝12」と表示されます。
5. **アレイ図（まるの ならび）**
   - 「まるに へんしん」で、お皿が消えて、リンゴが●の点のならび（1さら＝よこ1れつ）に動きます。
   - 「くるっと まわす」で全体を90度回すと、「●3こずつ ■4れつ（3×4）」が「●4こずつ ■3れつ（4×3）」になります。●の数は変わらないので、答えが同じこと（交換法則）が見えます。
   - 同時に「でも『3こずつ 4さら分』と『4こずつ 3さら分』は ばめんが ちがうよ」と表示し、意味のちがいにも気づかせます。
6. **いろいろな 1つ分**：上のボタンで、車とタイヤ・くつした・花びら・ふくろとみかん・はことケーキにきりかえて、じゆうに並べます（ことばも「4こずつ 3台分」「5まいずつ 3つ分」などに変わります）。
7. **先生モード**：下の＋／−で数を決め、「すすむ／もどる」（キーボードの ← → でも可）で1ステップずつ見せます。
   - ステップ：「ぜんぶで 何こ？」→「●3こずつ」（1まいめに赤いわく）→「■4さら分」（番号が出る）→「3＋3＋3＋3」→「3×4」→「3×4＝12」
   - 「こたえを かくす」にすると答えが「？」になり、押すとキラキラと一緒に出ます。
   - 上のボタンで、りんご以外の「1つ分」にもきりかえられます。

## つまずきへの対応

- **取りちがえ**：かけられる数とかける数を逆にしたときは、「●1つ分と ■いくつ分が いれかわって いるよ」と知らせます（しきに しよう・ならべて みよう）。文章題で逆の式をえらぶと「4×3 だと『4こずつ 3はこ分』の ばめんに なって しまうよ」と、えらんだ式の場面を言葉で返します。
- **ばらばらの数**：同じ数ずつでないときは、かけ算の式を出さず、「たし算で もとめよう」とたし算の式を見せます。「かぞえる」でも「おなじ数ずつ じゃないので、たし算で…かけ算には できないね」と表示します。
- **ヒント（3段階）**
  - しきに しよう：① 1つ分は いくつ？（1まいめのお皿に赤いわくと数が出る）→ ② いくつ分 ある？（お皿の番号が出る）→ ③ 数えるアニメ
  - ならべて みよう：① 1つ分は 4こ → ② いくつ分は 3 → ③ 正しく並べて数えるアニメ
  - ばめんを えらぼう：① 文の中の「1つ分」が赤くなる → ② 「いくつ分」が青くなる → ③ 絵が出て数えるアニメ
- **せめない表現**：まちがえたときは「おしい！」「✕の ついた □を なおそう」など、どこを見直せばよいかを伝えます。

## 先生向け設定（⚙️ せってい）

- おと（あり／なし）、ふりがな（あり／なし）
- うごき：「へらす」にすると、光る・はねる・回るなどのアニメーションを止めます（光る所はわくで表示）。「パソコンに あわせる」は、端末の「視差効果を減らす」設定に合わせます。
- もんだいに 出す だん：2・5・3・4・6・7・8・9・1 のだん（教科書で習う順）から、いくつでもえらべます。はじめは 2・5・3・4 のだんです。「□のだん」は、かけられる数（1つ分）が□の問題です。
- もんだいの かず：5・10・15もん
- 設定はこの端末のブラウザに保存されます。問題の結果（1回で正解した数・ヒントの回数）は終了画面に出るだけで、保存しません。
- 右上の「ぜんがめん」で全画面表示にできます。

## 動作確認方法

1. `おさらと りんごで かけ算.html` をブラウザ（Chrome・Edge・Safari）で開く。
2. **じゆうに ならべる**：「1さらの りんご ＋」を3回 →「●3こずつ」。「おさら ＋」を3回 →「3×4＝12」になり、ふえたお皿が光って「＋3」が出るか。かごからリンゴを1こドラッグして2まいめのお皿にのせると、「おなじ数ずつ かな？」とたし算の式になり、そのお皿が点線で囲まれるか。
3. **かぞえる**：3、6、9、12 と順に出て、式が「3＋3＋3＋3 ➡ 3×4＝12」になるか。
4. **しきに しよう**：わざと「□こずつ」と「□さら分」を逆に入れると「いれかわって いるよ」と出るか。ヒントが3段階で変わるか。
5. **ならべて みよう**：逆に並べると「ぎゃくだよ」と出るか。正しく並べると「せいかい！」になるか。
6. **ばめんを えらぼう**：逆の式をえらぶと、その式が「✕」になり理由が出るか。ヒントで文に色がつくか。
7. **アレイ図**：「まるに へんしん」でリンゴが●のならびに動くか。「くるっと まわす」で回って、式が「4×3＝12」になるか。
8. **いろいろな 1つ分**・**先生モード**：絵と単位（台・まい・つ など）が切りかわるか。先生モードの ← → と「こたえを かくす」が使えるか。
9. 5問終えると結果（1回で正解した数・ヒントの回数）が出るか。
10. 電子黒板（横長）・タブレット・スマートフォンで、ボタンが押しやすく、はみ出しがないか。

## 授業での使い方の例

### 1. かけ算の意味の導入（「1つ分」と「いくつ分」）

1. **先生モード**で「3こずつ 4さら分」を出し、ステップ0「ぜんぶで 何こ？」で止める。「どうやって 数えると はやいかな？」と問い、数え方を発表させる。
2. 「すすむ」で「●3こずつ」→「■4さら分」と進め、「1さらに 3こ」が「1つ分」、「お皿が 4まい」が「いくつ分」であることを、赤と青の色・しるしで確認する。
3. 「3＋3＋3＋3」→「3×4」と進め、「3を 4かい たすことを 3×4 と かく」とまとめる。「こたえを かくす」にしておき、答えは児童に言わせてから押す。
4. **じゆうに ならべる**で、代表の児童に電子黒板で1さらのリンゴをわざと1こだけ多くしてもらい、「おなじ数ずつ かな？」と出ることから、「かけ算は同じ数ずつのときだけ使える」ことに気づかせる。
5. 「おさら ＋」を1回ずつ押し、答えが3ずつふえる（＋3が光る）ことを見せて、「3のだんは 3ずつ ふえる」につなげる。
6. 残りの時間は、各自のタブレットで**しきに しよう**→**ならべて みよう**に取り組む（せっていで、その日に習った段だけをえらぶ）。

### 2. アレイ図で交換法則（3×4 と 4×3）

1. **アレイ図**で「3こずつ 4さら分」を出し、「まるに へんしん」でお皿をはずして●のならびにする。「よこの 1れつが 1さら分だね」と確認する。
2. 「この ならびを よこに たおすと どうなる？」と予想させてから「くるっと まわす」。
3. 「●4こずつ ■3れつ（4×3）」になっても●の数は12のままであることを確かめ、「かける数と かけられる数を 入れかえても 答えは 同じ」とまとめる。
4. ここで「でも ばめんは ちがうよ」の表示に注目させる。「3こずつ 4さら分」と「4こずつ 3さら分」の絵をそれぞれ**じゆうに ならべる**で作り、ちがいを話し合う。
5. 九九表づくりなどで「3×4 が わかれば 4×3 も わかる」と活用する。

### 3. 文章題の式えらび（6×2 か 2×6 か）

1. **ばめんを えらぼう**を電子黒板で1問いっしょに解く。「1はこ 6こ入りのケーキが 2はこ」を読み、「1つ分は どれ？」「いくつ分は どれ？」と問いながら、ヒント①②で文に赤・青の色をつける。
2. 「6×2」「2×6」の両方について、「それぞれ どんな ばめんかな？」と話し合う（2×6 は「2こずつ 6はこ分」になることを、まちがえたときの表示で確かめられる）。
3. 「ふくろが 3つ あります。1ふくろに 4こずつ…」のような、いくつ分が先に出てくる問題で、「出てきた じゅんに 書くと まちがえる」ことに気づかせる。
4. 各自で5問に取り組み、終了画面の「1かいで せいかい」と「ヒントの かず」をふり返る。ヒントを使った児童には、赤（1つ分）を先に見つけるコツを確認する。
