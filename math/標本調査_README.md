# 標本調査シミュレーター（中3 標本調査）

壺の玉・池の魚・世論調査を使って、**全数調査と標本調査のちがい、母集団と標本、無作為に取り出すこと、標本の大きさ、標本から母集団を推定すること**を体験するアプリです。

## 基本情報

- **ファイル**：本体 `標本調査.html`、共通部品 `worksheet.js`・`worksheet.css`・`math-render.js`。ネット接続・外部ライブラリは不要です。
- **画面**：横向きタブレット（1024×768）では 左＝図・操作、右＝グラフ・問題 の2列。スマホは たて1列。
- **色のきまり**：赤玉＝赤（「赤」の字）、白玉＝白（灰色のふち）、本当の値＝緑の点線、平均＝オレンジの ▲、まちがい＝赤紫の「×」、正解＝緑の「✓」。ヒストグラムは 標本の大きさごとに色と形（まる・四角）を変えています。
- **URL の設定**
  - `?teacher=1` … 先生モード（答え・自動で1ステップ・発問の例・かくした値の設定・この端末のきろく）
  - `?part=1〜5` … はじめに開くパート
  - `?red=300` … ② の壺の赤玉の数（1000個中）を決めて開く
  - `?ws=1` … ワークシートをひらいて開く

## 使い方

### ① 全数と標本
- 場面（健康診断・視力検査・缶詰・世論調査・電球の寿命・国勢調査・視聴率・入学試験・川の水質・修学旅行・お米・手荷物検査の 12場面）を読んで、「全数調査」か「標本調査」かを選びます。答えると理由が出て、右の表に仕分けられます。
- 左に ことば（全数調査・標本調査・母集団・標本・標本の大きさ・無作為に抽出）と、母集団 → 標本 → 推定 の図。

### ② 壺の中の玉
- 壺に玉が 1000個。赤玉の数はかくれています（ふだんは 150〜450個からでたらめ。先生モードで決められる）。
- 標本の大きさを 10個・30個・100個（スライダーと数で 5〜200個も）にして「🥄 1回 取り出す」。取り出した玉・赤の割合が出て、「壺全体の赤玉は およそ何個？」に答えます。答えると 計算（1000 × 割合）と 割合の帯図が出ます。
- 「🔁 10回 くり返す」「50回」で、推定した割合のちらばりが ヒストグラムになります（0.1 きざみ、▲ は平均）。表に 平均・最小〜最大・範囲・全体の推定（個）。
- 予想「10個と100個、どちらの推定が正しそう？」→ 10個と100個を それぞれ10回以上で答え合わせとまとめ。
- 「👀 壺の中を見る」で答え合わせ（本当の割合が緑の点線で出る）。

### ③ 無作為とかたより
- 玉 100個（番号 00〜99）のうち赤 30個。赤玉をあとから上に入れたので、上の段ほど赤が多い壺です。
- Ⓐ「上の方から10個」（上の2段 20個の中から取る）と Ⓑ「よく混ぜて10個」を、1回・20回でくらべます。Ⓐ は平均 0.65 くらいに かたより、Ⓑ は 0.3 くらい。
- 🔢 乱数表：始める場所をタップ →「▶ 次の2けたを読む」で番号を選ぶ（同じ番号はとばす）。混ぜていない壺でも、番号で選べば無作為になることが見えます。結果は Ⓑ のヒストグラムに入ります。
- 予想「Ⓐ で全体の割合を推定できる？」→ Ⓐ と Ⓑ を10回以上で答え合わせ。

### ④ 推定する
- 🐟 池の魚（240〜600匹からでたらめ。水がにごっていて見えない）：① 印をつけて放す（10〜100匹）→ ② よく泳がせる（放した場所の近くにいた印つきの魚が、池全体に広がる）→ ③ つかまえて印つきを数える（10〜100匹）→ 池の魚の数を推定して答える。「🔁 ③ をもう一度」で推定がふえていきます。「👀 水をすきとおらせる」で答え合わせ。
- 📖 れい：印つき 50匹・30匹つかまえて印つき 5匹 → 50 ÷ 5/30 ＝ 300匹（帯図と比の式）。
- ✏️ 練習問題 3型（答えを先に決めてから数を作るので、答えはいつも整数）
  - 割合 → 個数（生徒・製品・袋の玉・図書室の本）
  - 標識再捕法（池の魚）
  - 碁石（白い碁石に黒を入れて、はじめの白の数を求める）

### ⑤ 統計の判断（発展）
- 📰 世論調査シミュレーター：ある町（架空）で賛成の割合（30〜60%、かくれている）を、100人・400人・1000人・2500人に聞いて調べます。結果と「誤差の目安 ±100÷√人数 ポイント」、本当の割合が入りそうな幅が出ます。
- 調査を くり返すと「結果 ± 誤差の目安」の横線がならびます。「👀 本当の割合を見る」で、本当の割合をふくむ線（緑）とふくまない線（赤紫の点線）がわかります（だいたい 100回に95回 ふくむ）。
- ❓ クイズ 7問（52% と 48%、5人の調査、32% → 34%、60%±10、ウェブのアンケート、人数を4倍、58% と 42%）。選択肢のならびは毎回かわります。

## 授業例（50分）

1. （5分）① の場面クイズを全体で。「缶詰を全部開けたら？」から標本調査が必要な理由を確認。ことばを板書。
2. （15分）📄「ワークシートの問題」→ 予想を書く。② で 10個を数人に取り出させ、推定を板書（ばらばら）→ 100個でも板書 →「50回」でヒストグラム →「壺の中を見る」。
3. （10分）③ で Ⓐ と Ⓑ をくらべ、無作為の意味を確認。乱数表を1回やってみる。
4. （15分）④ の池の魚を全体で → 練習問題を各自で。
5. （5分）ワークシートのまとめ。時間があれば ⑤（発展）。

## 正しさとじっさいとのちがい

- 割合と推定は分数で計算し、見せるときだけ小数にしています（推定が整数にならないときは「約 ○」、答えは切り捨て・切り上げのどちらも正解）。
- ② の壺では、1回調べるたびに玉を壺にもどして よく混ぜるものとしています（標本の中は ちがう玉）。
- ④ の池は、魚が出入りせず、印つきの魚もそうでない魚も同じようにつかまるものとしています。
- ⑤ の誤差の目安 ±100÷√n は、割合が50%くらいのときの、おおよその目安（95% の幅）です。学習指導要領の範囲をこえるので「発展」としています。
- 町・調査はすべて架空です。

## つまずき検知の一覧

| 型 | どこで見つける | 練習・もどる先 |
|---|---|---|
| 標本の割合や個数を、そのまま全体の「個数」にした | ② の推定（10個中3個 → 3個 や 30個 と答えた）、④ 練習問題の割合 → 個数 | 割合 → 個数の練習問題／② の帯図 |
| 標本が少ないのに、全体を断定した | ② の予想（10個・同じくらい）、⑤ クイズ | ⑤ のクイズ／② で 10個と100個を30回ずつ |
| 全数調査と標本調査のえらびまちがい | ① 場面クイズ | ① のクイズ・ことば |
| かたよった取り出し方でも、全体を表すと考えた | ③ の予想、⑤ のウェブアンケートの問題 | ⑤ のクイズ／③ で Ⓐ・Ⓑ を20回ずつ |
| 比をさかさまに使った（標識再捕法） | ④ の推定（50 × 5/30 など）、練習問題 | 標識再捕法の練習問題／れい |
| あとから入れた分を ひきわすれた | ④ 碁石の練習問題（白＋黒の全体を答えた） | 碁石の練習問題／れい |

記録は `localStorage` のキー `ikechan-math-標本調査` に、ワークシートといっしょに保存されます。
