# 放物線と直線（交点・三角形の面積）

中学3年「関数 y＝ax²」で、**放物線 y＝ax² と直線 y＝mx＋n の交点**を連立方程式（二次方程式）で求め、交点を結んでできる**三角形の面積**を求めるアプリです。
点 A・B をドラッグすると、式・座標・面積がいっしょに変わります。座標が分数になっても、面積は分数のまま正確に計算します。

## 基本情報

- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）・スマホ。広い画面では「グラフ｜操作」の2列、せまい画面では縦に並びます。
- **記録**：この端末の localStorage（保存キー `ikechan-math-放物線と直線`）に、ワークシートといっしょに入れます。
- **URL の設定**：`?teacher=1` … 先生モード、`?part=1〜5` … そのパートから始める、`?ws=1`／`?ws=0` … ワークシートをひらいて／とじて始める

## 点 A・B のドラッグ

- 点 A・B は放物線の上を動きます（x は −4.5〜4.5）。
- グラフの上の「✔すいつく」を押すと、x が整数にすいつきます（y＝x² なら格子点）。すいつかないときは x が 0.01 ずつ動き、座標は分数になります。
- 放物線は y＝x²・½x²・2x²・¼x² から えらべます（①③④ で共通）。

## パート

| パート | すること |
|---|---|
| ① 直線の式 | 2点 A・B を通る直線の式 y＝mx＋n の m と n を入れる。正解すると直線が引かれ、傾き＝(y の増加量)÷(x の増加量)＝a(p＋q)、A を代入して切片、の式が出る。 |
| ② 交点を求める | 「🎲 新しい問題」で y＝ax² と y＝mx＋n。y を消して ax²＝mx＋n を解き、交点 A・B の x 座標と y 座標を入れる。「🧮 解き方を見る」で 移項 → （係数でわる）→ 因数分解 → x → y の流れ。正解すると交点が緑の点で出る。 |
| ③ 三角形の面積 | △OAB を y 軸で △OAC（オレンジ）と △OBC（青・点線）に分けて面積を求める。底辺 OC（緑の太線）は直線の切片、高さは A・B から y 軸までの距離。A・B が y 軸の同じがわにあるときは注意が出る。 |
| ④ 面積を2等分（発展） | 原点 O を通り △OAB の面積を2等分する直線を求める。辺 AB の中点 C の座標と、直線 OC の傾きを入れる。正解すると △OAC と △OBC が色分けされ、面積が等しいことが出る。 |
| ⑤ 接する直線（発展） | 傾き m をえらび、切片 n のスライダー（0.25 ずつ）・数の入力で直線を上下に動かす。b²−4ac の値と交点の数（2・1・0）が変わる。接するときの n と接点の座標を入れる。 |

## 授業での使い方（例）

- **導入（ワークシート）**：「A・B の x 座標をたして 0 のとき、直線は？」と予想させ、① の「📄 ワークシートの問題」で A(−2, 4)・B(2, 4) の直線を求める。−3 と 3 などでも傾きが 0 になることを確かめ、3-11 の a(p＋q) と結びつける。
- **交点**：② で、交点は「連立方程式の解」であることをおさえる。x だけで終わらず、y も求める。
- **面積**：③ で、y 軸で2つに分ける考え方を図で見せる。「✔すいつく」を外して、座標が分数のときも同じ考え方で求められることを示す。
- **発展**：④ の中点、⑤ の判別式（b²−4ac＝0）は、入試問題の準備に。

## 正しさについて（じっさいとのちがい）

- 座標・傾き・面積はぜんぶ分数（Fraction）で計算しています。③ の面積は「△OAC＋△OBC」と、別の方法（くつひもの公式）で同じになることを確かめています。
- ④ は「原点 O を通る直線」で2等分する問題にしています（その直線は辺 AB の中点 C を通る）。
- ④⑤ は発展です（画面に「発展」と表示）。⑤ の交点の位置は、図にするときだけ小数で計算しています。
