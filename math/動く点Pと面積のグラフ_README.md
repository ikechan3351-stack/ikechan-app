# 動く点Pと面積のグラフ（動かして見る → 区間の式 → 逆向きクイズ → 練習問題・プリント）

中学2年「一次関数の利用（動点と面積）」のアプリです。図形の辺の上を点P が動くとき、面積 *y* が時間 *x* によってどう変わるかを、図・グラフ・区間ごとの式で調べます。長方形（前からある問題）に加えて、直角三角形・台形・L字形・正方形でも練習できます。

2026年10月に、共通部品で作り直しました。前の版の機能（長方形 4cm×6cm、△APD、再生・速さ・±0.5秒・グラフのドラッグ、区間の色分け、高さの点線、通ったあとの太線）は ① に残しています。

## 基本情報

- **ファイル**：本体 `動く点Pと面積のグラフ.html`、共通部品 `math-render.js`・`graph-engine.js`・`動点エンジン.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **動点エンジン.js**：図形（頂点の座標）・点の動き（通る頂点と速さ）・面積（どの点の多角形か）をデータで書くと、面積・区間・区間ごとの式を分数で正確に計算する共通部品です。動く点を2つにすると二次式も出せるので、中3「二次方程式の利用・動点」（3-09）でも使います。
- **公開ページ**：トップページ「算数・数学」（中2）から開けます。
- **画面のならび**：左に問題と図形、右にグラフと説明。タブレットの横向きで2列、せまい画面では上から順に並びます。
- **URL の設定**
  - `?teacher=1` … 先生モード（🖨️ 問題プリント・② の「答えを入れる」・③④ の答え・ワークシートのヒントと解答例）
  - `?mode=see`・`make`・`quiz`・`prac` … はじめに開くタブ
  - `?ws=1` … ワークシートをひらいて開く

## 図形と面積

| 図形 | 決まった図形（①②） | 見る面積 |
|---|---|---|
| 長方形 | AB＝4cm、BC＝6cm、毎秒1cm | △APD（A→B→C→D）、△ABP（B→C→D→A） |
| 直角三角形 | AB＝6cm、BC＝8cm、CA＝10cm | △APC（A→B→C） |
| 台形 | AB＝4cm、BC＝8cm、CD＝5cm、DA＝5cm | △APD（A→B→C→D） |
| L字形 | 6cm×6cm から 3cm×3cm を切りとった形 | △ABP（B→C→D→E→F） |
| 正方形 | 1辺 6cm、毎秒2cm | △ABP（B→C→D→A）、△APD（A→B→C→D） |

- 乱数の問題（③④・プリント）は、辺の長さ・速さ（毎秒1cmか2cm）を変えて作ります。角に着く時刻が整数になるように作ります。
- 区間の式の係数が整数か ○/2 になる問題だけを出します（斜めの辺の上を動くと 12/5 のような係数になる面積は、中2では出さない）。

## 使い方

### ① 動かして見る
- 図形と見る面積をえらびます。
- 「▶ スタート」・スライダー・数の入力・−0.5／＋0.5・速さ（ゆっくり／ふつう／はやい）で時刻を動かします。グラフの点をドラッグしても動かせます。
  - 「すいつく」なら1秒ごと、「すいつかない」なら細かく動きます。
- 図：面積の多角形（区間の色）、点P、通ったあと、底辺（青）、高さ（オレンジの点線）。
- グラフ：全体（うすい点線）と、通ったところ（区間の色の太線）。折れ目に点線。
- 右：区間ごとのカード（①0≦*x*≦4（P は辺AB の上）、*y*＝3*x*、「面積は増える（1秒で3cm²ずつ）」）。いまの区間が光り、代入の計算が出ます。

### ② 区間の式をつくる
- 区間ごとに「*x* の変域」（はじめ・おわり）と「*y*＝の式」（3x、-3x+42、6*(14-x)/2 なども可）を入れて「✔ たしかめる」。
- 合った区間は、グラフにその区間の色でかけます。まちがえた式は、赤紫の点線でかけます。
- ぜんぶ合うと「点P が1本の辺の上を動くあいだは一次式、角を曲がると式が変わる」とまとめが出ます。

### ③ 逆向きクイズ
- グラフだけが出ます。4つの小さな図（図形・面積・P の道すじ・辺の長さ）から、そのグラフになるものをえらびます。
  - まちがいの候補は、同じ図形のべつの面積・道すじを逆にした動き・べつの図形です。
- 正解すると、グラフから「辺 BC の長さは？」「点P が頂点 C に着くのは何秒後？」を読みとります。

### ④ 練習問題
- 乱数の問題に3つ答えます。
  1. *x*＝○ のときの *y*
  2. 区間の式
  3. *y*＝○ になる時刻（ぜんぶ。「3, 11」のように）
- 正解すると答えのグラフ（*y*＝○ の横線と交点）が出て、スライダーで点P を動かせます。「① で動かして見る」でその図形を ① にうつせます。

### 🖨️ 問題プリント（先生モード）
- 乱数の問題を A4 1枚に4問（問題文・図・問い・方眼つきの空のグラフ）と、答えのページ（区間ごとの式もふくむ）を印刷します。押すたびにちがう問題になります。

## ワークシート

- もんだい：「長方形ABCD の辺の上を点P が A→B→C→D と動くとき、点P が辺BC の上にあるあいだ、△APD の面積はどうなるだろうか？」
- 予想：増えていく／変わらない／減っていく／わからない
- 記録：図形と面積・区間（P のいる辺）・変域・式（① ではいまの区間、② ではぜんぶの区間、④ では解いた区間）。
- 保存キーは `ikechan-math-動く点Pと面積のグラフ`（つまずきの記録もこの中）。

## 授業での使い方の例（50分）

1. **予想（5分）**：長方形で、P が辺BC 上のときの面積を予想。
2. **① 動かして見る（10分）**：長方形で再生し、底辺と高さに注目。区間ごとに面積の変わり方を言葉で言わせる。
3. **② 区間の式（15分）**：長方形の表をうめる（変域は角に着く時刻、③は高さ 14−*x* から）。早い生徒は台形・L字形。
4. **③ 逆向きクイズ（10分）**：グラフの折れ目と横にまっすぐな区間から、図形と動きを当てる。
5. **④・まとめ（10分）**：練習問題1問とワークシートのまとめ。宿題には 🖨️ 問題プリント。

## 正しさについて（※じっさいとのちがい）

- 面積・区間・式は、動点エンジン.js が座標から分数で正確に計算します（グラフを描くときだけ小数を使います）。
- 点は角でも止まらず、同じ速さで動き続けるものとしています。
- 区間の両はしの時刻（角に着く時刻）では、どちらの区間の式でも同じ値になります。変域はどちらにも等号を入れています（教科書によって、片方だけに等号を入れることもあります）。
- 中2では、係数が整数か ○/2 になる問題だけを出しています。

## つまずき検知の一覧

| 型 | 見つけ方 | 例 |
|---|---|---|
| ↔ 変域の両はしのまちがい | ② で変域が区間とちがう（ほかの区間の時刻など） | ②の区間を 0≦*x*≦10 |
| ± 増える・減るの向き（傾きの符号） | ②④ で *x* の係数の符号が逆 | *y*＝3*x*＋42 |
| ＋ 区間の式の定数をつけわすれた | ②④ で *x* の項だけの式 | *y*＝−3*x*（正しくは −3*x*＋42） |
| ½ 三角形の面積の ÷2 をわすれた | ②④ で式や値がちょうど2倍 | *y*＝6*x* |
| 🔀 グラフの形と、点の動きが合っていない | ③ でちがう図形・動きをえらんだ | |
| ✏ 計算・読みとりのまちがい | そのほか（③の辺の長さを時間で答えた など） | |

つまずきは右の列に「あなたのつまずき」として出て、回数が「つまずきの記録」に残ります。
