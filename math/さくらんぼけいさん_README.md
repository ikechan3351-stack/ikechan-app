# 🍒 さくらんぼけいさん（小学1年）

「10のまとまり」をつくる考え方で、くりあがりのたし算・くりさがりのひき算を解けるようにするアプリです。
さくらんぼ図・10の枠ブロック・合言葉の3つを毎問そろえて見せます。

- ファイル：`math/さくらんぼけいさん.html`（1ファイルで動く。外部ファイル・通信なし）
- 状態：**試作版（1回目）**。先生画面・称号・つまずきに合わせた出題・ワークシートは2回目で追加予定。

## 合言葉

| | 合言葉 | 画面の動き |
|---|---|---|
| たし算（加数分解・被加数分解） | さくらんぼで わけて、ソーセージを つくって ジュージュー やく！ 10が やけたら のこりと あわせて できあがり！ | 10になる2つを指でなぞってかこむ → ソーセージが焼けて「10」のこげ目 → ブロックが10の枠に入る |
| ひき算（減加法） | さくらんぼで わけて、10の パックから パクッと たべる！ のこりと バラを あわせて ごちそうさま！ | パックから食べる → 残りとバラをお皿にあつめる |
| ひき算（減減法） | さくらんぼで わけて、まず バラを たべて、たりない ぶんは パックから パクッ！ ごちそうさま！ | バラを先に食べる → 足りない分をパックから |

## 画面

1. **はじめの画面**：まなぶ／れんしゅう／チャレンジ、集めたシールの数
2. **まなぶ**：4種類（たし算・たし算（前を分ける）・ひき算（パックから）・ひき算（バラから））の手順を、声と動きで自動再生。合言葉を1フレーズずつ光らせて読む。「ちがう かず」で別の問題でも見られる
3. **ステップの地図**：7ステップ。どのステップからでも始められる。10問中8問できたら「クリア」（✅が付く）
4. **もんだい画面**：さくらんぼの枝に数字を入れる → 10の組をなぞってかこむ（ひき算は「どこから食べる？」をタップ） → 式を2段で完成
5. **けっか**：できた数・シール・つまずいた所のひとこと

## 7つのステップ

| | 内容 | 例 | やり方 |
|---|---|---|---|
| 1 | あと いくつで 10？ | 7と□で10 | 10の合成 |
| 2 | さくらんぼで わけよう | 8+3 の 3を□と□に | 分け方だけ |
| 3 | ソーセージを やこう | 9+4 | 加数分解（前の数が7〜9） |
| 4 | たしざん ぜんぶ | 3+9 | 36問。さくらんぼをつける数を子どもが選ぶ（どちらでも正解） |
| 5 | パックから パクッ | 14−8 | 減加法（36問） |
| 6 | バラから さきに たべる | 12−3 | 減減法（パックから取る数が1〜2の15問） |
| 7 | チャレンジ | 15−7、6+8 | たし算5・ひき算5。ブロックなし・タイム表示。さくらんぼの位置は自由 |

## ヒントとつまずき

- ヒントは3段階：①声かけ（どこを見るか）→ ②うすい数字・光る場所で分け方を見せる → ③ブロックを動かして一緒にやる
- まちがえると×は出さず「おしい！」と言って、止まった段階からやり直す（自動でヒントが1段進む）
- 「1回でできた」＝まちがいなし・ヒント①まで。これがシールとクリア（8/10）の数になる
- つまずき3型を記録：
  1. **わけかた**（さくらんぼの枝の数、10の合成）
  2. **10を つくる・10から とる**（かこむ組のまちがい、バラから食べようとする、①段目の計算）
  3. **のこりと あわせる**（②段目。①段目の答えや10のまま答えたら「あわせわすれ」として声をかける）

## 音声（VOICEVOX:四国めたん）

- しゃべる文は、VOICEVOX（無料の音声合成ソフト）の「四国めたん（ノーマル）」で作った音声ファイル（`math/さくらんぼけいさん_音声/`）を鳴らす。どの端末でも同じ声になる
- 文を「。！？」で区切り、1文ずつファイルを鳴らす。ファイルのない文は、ブラウザの読み上げで読む
- 画面の下に「音声：VOICEVOX:四国めたん」と出す（VOICEVOX のきまり）
- **文を足したり変えたりしたとき**：VOICEVOX を起動して、`python3 tools/さくらんぼ音声.py` を実行する。足りない文だけ作り、一覧 `list.js` を作り直す
  - しゃべる文の一覧は、アプリの中の `collectPhrases()` で集めている。新しい種類の文を足したら、そこにも足す（足りないと、ブラウザのコンソールに「音声ファイルが ない 文」と出る）
  - 読み方は `math/さくらんぼけいさん_音声/読み方チェック.tsv` で確かめられる
  - 声を変えたいときは、スクリプトの `SPEAKER`（番号）と `CREDIT` を変えて、音声フォルダの m4a を消してから実行する
