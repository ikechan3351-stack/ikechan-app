# まわりは 直径の 何ばい？

小学5年生の算数「正多角形と円周の長さ」（東京書籍 新しい算数 5下 96〜109ページ）で使う教材です。次のことを体験します。

- **正多角形**は、辺の長さがすべて等しく、角の大きさもすべて等しい多角形。円の中心のまわりの角（360°）を等分するとかける
- 正六角形は、コンパスで円周を**半径**の長さで区切るとかける（辺の長さ＝半径）
- **円周**は直径の3倍より少し長い（4倍にはとどかない）。円の大きさがかわっても **円周÷直径＝3.14…（円周率）**
- **円周＝直径×3.14**、直径＝円周÷3.14

## 基本情報

- **ファイル**：`まわりは直径の何ばい.html`。共通ファイル `worksheet.js`・`worksheet.css` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。図はすべて SVG（物の絵は絵文字）。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」（5年）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。本文20px・ボタン48px以上。せまい画面では図の板だけ横にスクロールします（ページははみ出しません）。
- **漢字**：説明の文に出る 円周・直径・半径・円周率・正多角形・正六角形・正方形・回転・予想 に自動でふりがなをつけます。図の中のふりがなもふくめ、「せってい」で消せます。
- **ワークシート**：よそう → やってみる → わかったこと → まとめ（小学生向け）。図の板を広く使うため、はじめは閉じています。「きろくする」で、場面・円や形の名前・直径・円周・円周÷直径 を記録します。

- **せってい**：もんだいの数（5・10）・ふりがな・うごき（「へらす」で、ころがす・まく などがすぐ終わる）。

## 6つの画面

### ① ころがそう

- 直径（4〜10cm）をきめ、「▶ ころがす」で円を1回転ころがして、進んだ長さ＝円周を見ます。「📏 直径で はかる」で直径のテープが3本と少しならびます。

### ② いろいろな円で はかろう

- 1円玉・ジュースのかん・CD・紙ざら・自転車のタイヤ・フラフープから選んでころがし、表（直径・円周・円周÷直径）にまとめます。3つ以上はかると「どれもだいたい3.14」のまとめが出ます。

### ③ ひもを まこう

- かんにひもをまいてのばし、直径のぼうをならべると3本おけて4本目ははみ出すことを見ます。

### ④ 正多角形で はさもう

- 内がわの正六角形（直径の3倍）と外がわの正方形（4倍）で円周をはさみ、6〜96角形まで角をふやすと、内がわと外がわのまわり÷直径が 3.14… にはさまれていきます。正六角形と正方形ではさむところまでが教科書の内容で、角をふやす（8〜96角形）ところは【発展】です（ボタンと計算らんに「発展」と出ます）。

### ⬡ 正多角形を かこう（新しく足した画面。教科書では単元のはじめ）

- **みわけよう**：正三角形・ひし形・長方形・正方形・正五角形・六角形・正六角形・正八角形から正多角形をタップでえらび「こたえあわせ」。正多角形でない形には、わけ（辺は等しいが角がちがう など）が出ます。
- **円を つかって かこう**：角の数（3・4・5・6・8・9・10・12）をえらび、中心の角（360÷角の数）を入れてから、半径をひく → 頂点をとる → むすぶ の順に進めます。
- **正六角形は 半径で**：コンパスを半径の長さにひらいて円周を区切ると、ちょうど6回で1しゅうします。辺の長さ＝半径、まわり＝直径×3（④につながる）。

### ✏️ もんだい（新しく足した画面）

| 種類 | 例 | 答え方 |
|---|---|---|
| 中心の 角 | 正六角形をかくとき、中心の角は何度ずつ？ | 数を入れる（2回まで） |
| 直径から 円周 | 直径16cmの円の円周 | 数を入れる（2回まで） |
| 半径から 円周 | 半径4cmの円の円周 | 数を入れる（2回まで） |
| 円周から 直径 | 円周47.1cmの円の直径 | 数を入れる（2回まで） |
| 正多角形を みわける | 4つの形（A〜D）から1つ | えらぶ（1回） |

- 図の板に、問題に合わせた図（直径・半径の矢印、中心の角の「？」）が出ます。5問なら1つずつ、10問なら2つずつ（「せってい」でえらべます）。

- 「↩ ひとつ もどす」「🔄 はじめから」は、①〜③と⬡にあります（②は最後にはかった行を消す、④は「◀ へらす」）。

## つまずき検知

| 型の名前 | 見つけ方 | 出るところ |
|---|---|---|
| 中心の 角の まちがい | 正多角形の中心の角を 180÷角の数、360×角の数 などにした | ⬡ 円を つかって かこう・もんだい |
| 半径と 直径の とりちがえ | 半径で円周を求めるのに ×2 をしなかった、直径を半径とみて ×2 した、直径を求めるのに半径を答えた | もんだい |
| 直径を もとめる 計算の まちがい | 円周から直径を求めるのに 円周×3.14 とした、直径から円周を求めるのに ÷3.14 とした | もんだい |

- もんだいでは、見つけた型を「あなたの つまずき」として出し、次にその型の「にた もんだい」を1問足します。終わりに型ごとの回数と、練習できる画面（⬡ 正多角形を かこう・① ころがそう）へのボタンを出します。

## 先生モード（アドレスの最後に `?teacher=1`）

- 題名の横に「先生モード」のしるし。①〜④・⬡に「⏩ じどうで さいごまで」（①③は最後のステップまで、②は3つはかる、④は96角形まで、⬡はこたえあわせ・かき終わりまで）。もんだいでは「💡 こたえ」。ワークシートに先生用のヒントと解答例が出ます。

## 授業での使い方の例

1. **正多角形（2時間）**：「⬡ 正多角形を かこう」でみわけて意味をまとめ、円の中心の角を等分してかく。正六角形は半径でかけることを確かめる。
2. **円周と直径（2時間）**：「① ころがそう」「③ ひもを まこう」で、円周は直径の3倍と少しであることを体験 → 「② いろいろな円」で、大きさがかわっても円周÷直径がほぼ同じことを表で確かめ、円周率をまとめる。
3. **円周率の考え方（1時間）**：「④ 正多角形で はさもう」で、正六角形と正方形ではさむ考えから、角をふやすと3.14…にはさまれることを見る。
4. **円周の求め方（1〜2時間）**：円周＝直径×3.14、直径＝円周÷3.14。「✏️ もんだい」で練習し、つまずきの型をふりかえる。

## 正しさと、じっさいとのちがい

- ②の円周は「ものさしで0.1cmまで読んだ長さ」として、直径×円周率を四捨五入して出しています。物の大きさはだいたいの数です。
- ②の図は、大きさのちがう物を同じくらいの大きさにそろえて見せています。
- もんだいの円周率は3.14で計算しています。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| 直径・半径／円周 | 赤／緑・青 | 矢印・まっすぐな線／円・ころがった線、文字 |
| 内がわ／外がわの正多角形（④） | 青／オレンジ | 円の内／外、表の「内がわ」「外がわ」 |
| 正多角形／ちがう形（みわける） | 緑／ピンク | ◎・✖ の記号、形の名前 |
| 正解／まちがい | 緑／赤むらさき | ◎・△・✖ の記号 |
