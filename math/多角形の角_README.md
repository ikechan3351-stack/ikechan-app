# 多角形の角（内角の和・外角の和）

中学2年「平行と合同」の多角形の角を学ぶアプリです。頂点をドラッグして形を変えながら、**三角形の内角の和は 180°**、**外角はとなりにない2つの内角の和**、**n角形の内角の和は 180° × (n − 2)**、**外角の和は何角形でも 360°** であることを見つけます。正多角形の1つの内角・外角と、発展として星形多角形の角も扱います。

## 使い方

図の ● （頂点）をドラッグすると形が変わり、角の大きさ（測定値）が自動で出ます。「方眼にすいつく」を外すと自由に動かせます（④ の星形はいつも自由）。三角形がつぶれる形や、辺どうしが交わる形にはなりません。

### ① 三角形

1. 頂点 A・B・C をドラッグ。右の表に ∠A・∠B・∠C と合計（いつも 180°）が出ます。
2. 「注目する頂点」を A・B・C から選びます。
3. 「✂ 切りとって ならべる」：のこり2つの角が切りとられて、注目する頂点に集まり、**一直線（180°）** にならびます。緑の点線は、その頂点を通って向かいの辺に平行な直線（平行線の錯角）。ならべたまま頂点を動かしても、くずれません。
4. 「↗ 外角にうつす」：辺をのばした点線と点 D が出て、となりにない2つの角が**外角にぴったり入ります**（同位角・錯角）。右に「外角 ∠ACD ＝ ∠A ＋ ∠B」の計算が出ます。
5. 「◀ もとにもどす」で、角がもとの場所へもどります。
6. 「✏️ 練習問題」：のこりの角／外角／外角から内角 の3種類。角を先に決めてから三角形をかくので、図の形も問題の角のとおりです。

### ② 内角の和

1. n のスライダー（または数の入力）で 三角形〜十角形 にします。「🎲 形をかえる」で でこぼこの形になります。
2. 「／ 対角線を1本ひく」をくり返すと、頂点 A からの対角線が1本ずつ引かれ、三角形に模様と番号がつきます（「ぜんぶひく」「消す」もあります）。
3. ぜんぶ引くと「三角形はいくつ？」→「内角の和は？」の順に答えます。正解すると、右の表のその行がうまり、「測定した内角の合計」が出ます。
4. 表の行が3つ以上うまると、最後の行に **n角形 → n − 3 本・n − 2 こ・180° × (n − 2)** が出ます（それまでは、先に自分で考えるようにかくしています）。
5. 「へこんだ形もためす（発展）」：へこんだ形（180° より大きい内角）にもできます。A からの対角線が外に出る形では、対角線が引けないことを知らせます。
6. 「✏️ 練習問題」：○角形の内角の和／三角形の数／内角の和から何角形か（5〜12角形）。

### ③ 外角の和

1. n と形の決め方は ② と同じ（へこまない形だけ）。
2. 「▶ 歩く」：カメが A をスタートして辺にそって歩き、頂点ごとに**外角の分だけ向きを変えます**。「⏭ 1つ進む」で、歩く・向きを変える を1つずつ、「⏮ はじめから」でスタートにもどります。
3. 右の「カメが回った角」のメーターに、外角が順に集まります。1周すると円がうまって **360°（ちょうど1回転）**。
4. その下に「内角 ＋ 外角 ＝ 180° が n こ → 180° × n、そこから内角の和をひくと 360°」の式も出ます。
5. 「外角をぜんぶ見せる」で、歩く前から全部の外角を表示できます。
6. 「✏️ 練習問題」：○角形の外角の和（百角形も出ます）／外角が1つだけわからない五・六角形（外角を先に決めて、その外角になる図をかきます）／内角の和と外角の和を合わせると。

### ④ 正多角形

1. 「正多角形」：n（3〜20）を変えると、正 n 角形と「内角の和 → 1つの内角 ＝ 和 ÷ n → 1つの外角 ＝ 360° ÷ n」が出ます。わりきれないときは分数（例：900/7°）と「約 128.6°」で表示します。
2. 「星形（発展）」：n この点を k こおきに結んだ星（n ＝ 5, 7〜12。星にならない 6 はとばします）。先の角とその和（180° × (n − 2k)）が出ます。n ＝ 5・2こおき のときは、5つの点をドラッグしてゆがめても和が 180° のままであることを確かめられます。
3. 「✏️ 練習問題」：正○角形の1つの内角／1つの外角／外角から正何角形か／内角から正何角形か／星形の先の角の和（発展）。答えが整数になる n だけで出します。

ボタン：✏️ 練習問題／↶ ひとつもどす（ドラッグ・スライダー・ボタン操作も1回分もどせる。パートごと）／⟲ もういちど（そのパートをはじめの形に。② の表は残る）／💡 ヒント（押すたびに次のヒント）／📄 ワークシートの問題（② を八角形で開く）。練習問題は「✖ 問題をおわる」で図にもどります。キーボードの数字・Enter でも答えられます。

## 授業での使い方（例）

- **導入（5分）**：ワークシートの予想「八角形の内角の和は？」を挙手で集める（180° × 8 ＝ 1440° とする生徒が多い）。
- **展開①（10分）**：① で三角形の角を切りとって一直線に。頂点を動かしても 180° のまま。外角にうつして「外角 ＝ となりにない2つの内角の和」。小学校の「切って並べる」とのちがい（平行線で説明できる）を話題にする。
- **展開②（15分）**：② で「📄 ワークシートの問題」→ 八角形の対角線を引き、三角形 6 こ → 1080°。五角形・六角形… でも確かめて記録し、表から n角形の式を自分で書く。
- **展開③（10分）**：③ でカメを1周。n を変えても 360°。式（180° × n − 180° × (n − 2)）でも確かめる。
- **練習（5分）**：② ③ ④ の練習問題。つまずきが出たら「🔁 この型を練習」「👀 元の図で確かめる」。
- **まとめ**：ワークシートの④に「n角形の内角の和は 180° × (n − 2)、外角の和は 360°」。
- **別の時間に**：④ で正多角形の角、発展として星形の角の和。

## じっさいとのちがい（かんたんにしたところ）

- 角の大きさは画面上で測った値で、1° より小さいところは四捨五入しています。四捨五入で合計が 1° ずれないよう、端数のいちばん大きい角で調整して表示しています（本当の角は小数をふくみます）。
- ①〜③ の頂点は「方眼にすいつく」とき、方眼の点にすいつきます。三角形がつぶれる形（4° 未満の角）・辺が交わる形にはなりません。③ はへこまない形だけです。
- ① の練習問題の図、③ の「外角が1つわからない」問題の図は、問題の角になるように計算してかいていますが、画面の大きさに合わせて縮めています。
- ④ の正多角形の角は分数で正確に計算しています（小数は表示だけ）。
- ③ のカメは、頂点でその場で向きを変えるとしています。

## つまずき検知の一覧

| 型 | どこで見つけるか | 練習するパート |
|---|---|---|
| n と n − 2 の取りちがえ | ② で三角形の数に n（n − 1）、内角の和に 180° × n（× (n − 1)）、何角形かに n − 2（n ＋ 2）を答えた。④ で1つの内角に 180°、正何角形かに n ± 2 を答えた | ② |
| 対角線の本数と三角形の数の取りちがえ | ② で三角形の数に n − 3、内角の和に 180° × (n − 3)、何角形かに n ± 1 を答えた | ②（三角形の数・内角の和の問題） |
| 外角の和が n によって変わると考えた | ③ で外角の和を 360° 以外で答えた（180° × (n − 2) など）、外角が1つわからない問題で内角の和からひいた、② で内角の和に 360° を答えた | ③ |
| 内角と外角のとりちがえ | ① で外角を求めるのに ∠C（内角）を、のこりの角に ∠A ＋ ∠B を答えた。③ で内角の値を答えた。④ で1つの内角と外角を入れかえた | ①（外角の問題） |
| 三角形の内角の和（180°）の使いまちがい | ① で 360° からひいた値、180° から1つだけひいた値を答えた | ①（のこりの角の問題） |
| 和のまま答えた（÷ n をわすれた） | ④ で1つの内角に 180° × (n − 2)、1つの外角に 360° を答えた | ④（内角・外角の問題） |
| 星形の角と多角形の内角の和をまぜた | ④ の星形の問題で 540°・360° などを答えた | ④（星形の問題） |
| 計算まちがい | 上のどれにもあてはまらないまちがい | いまのパート |

「🔎 あなたのつまずき」に、この時間に出た型と説明が出ます。「🔁 この型を練習」でその型の問題があるパートへ移り、「👀 元の図で確かめる」で、その型が見える場面（例：六角形に対角線を引いた図、カメが1周する図、外角に角をうつす図）を出します。
記録は、この端末の localStorage（キー `ikechan-math-多角形の角`、ワークシートと同じ）に入ります：つまずきの型ごとの回数・パートごとの正解の数・ヒントの回数。先生モードで合計を見たり消したりできます。

## ワークシート

- 問題：「八角形の内角の和は何度だろうか？」
- 予想：720°／1080°／1440°／360°／わからない
- 記録する列：多角形・n・三角形の数・内角の和・外角の和（② で対角線を引いて答えたあと、③ でカメを1周させたあと、① ④ でいつでも）
- まとめのヒント：「n角形は、1つの頂点から対角線を引くと三角形が〜こできるので、内角の和は 180° × 〜。外角の和は〜」

## 先生が改造するとき

- つまずきの型は `TRIPS`、パートの名前と説明は `PARTS`、練習問題は `makeQ`（パートごと。答えを先に決めて作る）にまとまっています。
- 頂点の色は `VC`、図の大きさは `W`・`H`、方眼の1目もりは `G`。
- ② のはじめの n は `defaults` の中の `n: 5` です。
