# ブロックで わり算の筆算

小学4年生の算数「わり算の筆算」で使う、筆算の手順をブロック操作と結びつけるシミュレーション教材です。次のことを体験します。

- **「たてる→かける→ひく→おろす」は、大きい位から順に分けていく操作** であること
- 分けきれない位は **ばらして下の位といっしょにする**（＝「おろす」の意味）
- **商がたたない位に0を書く** こと（816÷8 は 12 ではなく 102）、**あまりの意味**
- 2けたでわる筆算の **かりの商** の立て方（96÷23 を 90÷20 と見る）と、大きすぎたときの修正

## 基本情報

- **ファイル**：`ブロックで わり算の筆算.html`。この1ファイルだけで動きます。
  - ネット接続・外部ライブラリ・画像ファイル・音声ファイルは不要です（効果音はブラウザの中で作っています）。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。
  - テンキーは1つ60px以上、そのほかのボタンも最小48pxです。
  - 画面が広いときは「筆算｜テンキー｜ブロック」の横ならび、せまいときは縦ならびになります。
  - キーボードでは、→ ← スペースでステップを進める・もどす、数字・Backspace・Enter で答えを入れられます。
- **漢字**：4年生までに習う漢字を使い、ふりがなをつけています（筆算・商・位・配る・皿 など）。5年生で習う「仮」は使わず「かりの商」と書いています。ふりがなは「せってい」で消せます。
- **記録**：正解数やつまずきは保存しません。保存されるのは「せってい」だけです（このブラウザの中だけ）。
- 前からある `わり算の筆算.html`（筆算れんしゅう）は、手書き入力で筆算の形を練習する別の教材です。この教材は「意味の理解」を受け持ちます。

## しくみ（コードのつくり）

- **ステップの自動生成（`makeSteps(わられる数, わる数)`）**：筆算の手順を上から順に並べた「台本（配列）」を作ります。画面はこの配列を1つずつ読んで描くだけです。「もどる」は1つ前の台本を読み直すだけなので、筆算とブロックの表示がずれません。
- 台本の1行（ステップ）には、次のものが入っています。
  - `type`：start／lead（この位には商がたたない）／barasu（ばらして下の位といっしょに）／tate（たてる）／kari（かりの商）／over（かけたら大きすぎた）／fix（たてなおす）／zero（商に0）／kake（かける）／hiku（ひく）／oro（おろす）／end
  - `msg`：説明のことば
  - `written`：その時点の筆算のすがた（商・各行の数字・光らせるマス・おろす矢印）
  - `blocks`：その時点のブロックのすがた（つくえの上・お皿の上・光らせる場所・動き）
  - `info`：児童が答えるときに使う数（いま分けている数・たてる数・かけた答え・ひいた答え・正しい答え など）
- **ステップの作り方**：
  1. いちばん上の位から見て、わる数より小さければ「この位には商がたたない」→ ばらして下の位といっしょにする（216÷3 なら 2÷3 はできない → 21÷3）。
  2. 商がたつ位から一の位まで、1つの位ずつ「たてる→かける→ひく→おろす」。
  3. その位の数がわる数より小さいときは、商に0を書いて、すぐ次の数をおろします（0×8＝0 の行は書かない、教科書の書き方）。
  4. 2けたでわるときは、上のけただけで見当をつけます（96÷23 → 9÷2 → 4）。かけてみて大きすぎたら、1ずつ小さくした「over → fix」のステップを入れます。上のけただけで見当をつけると、かりの商は正しい商より小さくなることはないので、「小さくする」修正だけで足ります。
- **児童が答えるモード**：1つ前のステップとの「ちがい」（新しく書かれたマス）を自動で見つけて、そこを入力マス（？）にします。答えを判定するのも、同じ台本の `info` と比べるだけです。
- **ブロックの動き**：お皿に配るときと、ばらすときに、ブロックが置き場から飛んでいきます（動く前の位置を覚えておき、新しい位置まで動かす方法）。「動きを減らす」では止まります。

## 色だけに頼らない区別

| ステップ | 色 | わくの形 |
|---|---|---|
| たてる | オレンジ | 実線 |
| かける | 青 | 点線 |
| ひく | 緑 | 二重線 |
| おろす | むらさき | 破線 |

- 筆算の数字・ブロック・上の説明らんの左はしが、同じ色・同じわくの形で光ります。上には「①たてる→②かける→③ひく→④おろす」の道しるべがあり、今のステップの名前も文字で出ます。
- 筆算の列とブロックの置き場は、位ごとに同じ背景色です（百＝黄・十＝水色・一＝ピンク）。位の名前も書いてあります。
- ブロックは、いた（黄色の正方形）・ぼう（水色の細長い形）・ばら（オレンジの小さい正方形）で、形でも区別できます。

## モード

### 1. 👀 しくみを 見よう

- 式を入れて「はじめる」→「つぎへ ▶」で1ステップずつ進みます。例のボタン（72÷3、84÷4、65÷4、216÷3、816÷8、96÷23、84÷28）もあります。
- 72÷3 の流れ：ぼう7本をお皿3まいに2本ずつ配る → 3×2＝6 → 7−6＝1 → 残った1本をばら10こにばらして、ばら2こといっしょに12こ → 4こずつ配る → 答え 24。
- まだおろしていない位のブロックは、うすく「まだ おろして いない」と表示します。

### 2. ✏️ いっしょに とこう

- 筆算の「？」のマスに答えを入れます。たてる数・かけた答え・ひいた答えを、その場で判定します。正解するとブロックがそのとおりに動き、説明が出ます。
- 商がたたない位では「くばれる？」と位ごとに問い、「ばらして となりの位と いっしょにする」を押させます。おろすは「↓ おろす」ボタン（その数字を打ってもよい）です。
- **つまずきへの対応**
  - **商の0の書き忘れ**：816÷8 の十の位で「この位には たてられない」を押すと、「答えが 12 になっちゃう（8×12＝96 で 816 にもどらない）」と伝え、ブロックでお皿に「0本」の様子を見せます。
  - **たてた数が小さすぎる**：そのまま かける・ひく まで進ませ、ひいた答えがわる数以上になったら「もう少したてられるよ」と気づかせて、たてなおさせます。
  - **たてた数が大きすぎる**：「3×3＝9 は 7 より大きいから ひけないよ」。
  - **ひいた答えがわる数以上**（計算ミス）：「わる数より小さくなるはず」。
  - **かりの商**：見当（9÷2 など）より大きい数は理由つきで返します。見当と正しい商のあいだの数を答えたときは受けとって進みます。
- 「💡 ヒント」は押すたびにくわしくなり（例：「3のだんで 7をこえない いちばん大きい答えは？」→「3×1＝3、3×2＝6、3×3＝9」→ 答え）、ブロックも表示します。

### 3. 📝 れんしゅう

- レベル：1＝2けた÷1けた／2＝3けた÷1けた／3＝商に0がたつ／4＝2けた÷2けた（見当どおり）／5＝かりの商を なおす／まぜる。
- あまり（まぜる・あり・なし）と問題数（3・5・10）を選べます。問題はでたらめに作り、台本を作ってみて条件に合うもの（例：レベル3は「zero」のステップがあるもの）だけを出します。わる数が20・30のような数は、見当の練習にならないので出しません。
- 筆算のマスを光らせる手がかりは消しています（ヒントで出ます）。
- おわると「1回でできた数・ヒントを使った回数・つまずいたステップ（たてる・かける・ひく・おろす 別）・問題ごとの結果」を表示します。保存はしません。

### 4. 🔍 かりの 商

- 2けたでわる筆算を「つぎへ」で進めます。右上のカードに、一の位をかくして見当をつける様子（84 → 8、28 → 2、8÷2＝4）、ためした商の記録（4：28×4＝112 大きすぎ ✕ → 3：28×3＝84 ひける ✔）、わられる数と「わる数×商」の長さくらべを出します。
- 例：96÷23（見当どおり）、84÷28（1回なおす）、85÷17（3回なおす）、75÷19、156÷26（3けた÷2けた）、768÷32（商が2けた）。

### 5. ✅ たしかめ算

- 「わる数 × 商 ＋ あまり」を1行ずつ計算し、もとの数にもどるかを表示します。ブロックでは、お皿のブロックとあまりを集めると、わられる数と同じになる様子を見せます。
- 商・あまりは書きかえられます。「816÷8＝12」では「96≠816 → 商に0を書くのをわすれていないかな？」、「100÷7＝13あまり9」では「もとの数にもどったけど、あまりがわる数より大きい」と出ます。

### 6. 🧑‍🏫 先生モード

- 筆算を画面の高さいっぱいに大きく表示し、「つぎへ」でステップを進めます。説明の文・ブロックを かくせます。「⛶ ぜんがめん」と合わせて使います。

## せってい

| 項目 | 選べるもの | はじめ |
|---|---|---|
| れんしゅうの レベル | 1〜5・まぜる | 1 |
| あまり | まぜる・あり・なし | まぜる |
| 問題の数 | 3・5・10 | 5 |
| ブロック | 見せる・見せない（筆算だけ） | 見せる |
| ふりがな | つける・つけない | つける |
| こうかおん | ON・OFF | ON |
| うごき | じどう・へらす・ふつう | じどう |

「じどう」は、パソコンやタブレットの「視差効果を減らす」設定に合わせます。

## 動作確認の方法

1. `ブロックで わり算の筆算.html` をブラウザ（Chrome・Edge・Safari）で開きます。ダブルクリックで開けます。
2. **しくみを見よう**：72÷3 で「つぎへ」を8回押し、ぼう7本 → 2本ずつ配る → 1本をばら10こに → ばら12こ → 4こずつ → 答え24 と進むか。筆算の数字とブロックが同じ色で光るか。「もどる」で1つ前にもどるか。
3. **商に0**：816÷8 で、十の位に「0」がたち、お皿に「0本」と出るか。8−8＝0 の 0 が、1をおろしたあとうすい灰色になるか。
4. **かりの商**：84÷28 で「4（かり）→ 28×4＝112 ひけない！ → 3」と進むか。112 がはみ出して赤く表示されるか。
5. **いっしょにとこう**：72÷3 で、たてるに「1」を入れる → 3、4 と答える → 「もう少したてられるよ」が出るか。816÷8 の十の位で「この位には たてられない」→「答えが12になっちゃう」が出るか。
6. **れんしゅう**：問題数3で最後まで解き、「けっかを見る」で結果が出るか。
7. **たしかめ算**：例の「816÷8＝12 ❓」で「つぎへ」を3回押し、「96≠816」と0の書き忘れのヒントが出るか。
8. **せってい**：ブロックを「見せない」にすると筆算だけになるか。ふりがな・効果音・動きの切りかえ。
9. 画面のはば：スマホ（縦）・タブレット・電子黒板（横長）で、横にはみ出さないか。

## 授業での使い方の例

### 例1：筆算の意味（わり算の筆算 1時間目）

1. 72まいの色紙を3人で同じ数ずつ分ける場面。「10まいのたば7つと、ばら2まい」をどう配るか考える。
2. **先生モード** または **しくみを見よう** で 72÷3。「まず、たば（ぼう）から配ろう」→ 2本ずつ配ると1本あまる。
3. 「残った1本はどうする？」と問い、ばらして10まいにする → ばら2まいといっしょに12まい、と進める。
4. 筆算の「7−6＝1」と「2をおろす」が、ブロックの「1本残る」「ばらしていっしょにする」と同じ色で光ることを確かめる。「たてる・かける・ひく・おろす」の名前をここでまとめる。
5. **いっしょにとこう** で 84÷4、65÷4（あまりあり）を1人1台で。最後に **たしかめ算** で「3×24＋0＝72」になることも確かめる。

### 例2：商に0がたつ場合

1. 816÷8 を、まずノートで解かせる。「12」と「102」が出たら、どちらが正しいかを話し合う。
2. **たしかめ算** で「816÷8＝12」を確かめる → 8×12＝96 で 816 にもどらない。
3. **しくみを見よう** で 816÷8。十の位で「ぼう1本を8まいに分けると、1本ずつも配れない」→ お皿は「0本」→ 商の十の位に0を書く、を見る。「0を書かないと、2が十の位に入ってしまう」ことを位の背景色で確かめる。
4. **れんしゅう** のレベル3（商に0がたつ）で練習する。

### 例3：かりの商（2けたでわる筆算）

1. 96÷23 を「23を20と見ると？」と問いかけ、**かりの商** モードで 9÷2＝4 → 23×4＝92 → ひける、を見る（見当がそのまま正解になる例）。
2. 84÷28 を見当で立てると 4。かけると 112 で 84 より大きい → 「ひけない！」。長さくらべのバーで、はみ出す様子を見せ、「1小さくする」と 3 で正解になることを確かめる。
3. 85÷17 では 8 → 7 → 6 → 5 と3回なおすことになる。「見当は大きめに出ることがある。大きすぎたら1ずつ小さくすればよい」とまとめる。
4. **れんしゅう** のレベル4・5で練習する。たてた数が小さすぎると、かけてひいたところで「もう少したてられるよ」と気づけるようになっています。
