# 円周角と円の性質（点を動かして、円周角と中心角の関係や円の性質を見つける）

中学3年「円」のアプリです。もとの「円周角シミュレーター」（点 P を動かして円周角と中心角をくらべる）を広げ、円周角の定理・その逆・半円の弧と直角・定理の証明・まとめの練習までを1つのページで学べるようにしました。発展として、円に内接する四角形と接弦定理（高校の数学A）も入れています。いちばんのねらいは、**図の中から「直径」「同じ弧」「中心角」「接線」を見つけて、使う定理を見分けられること**です。

## 基本情報

- **ファイル**：本体 `円周角シミュレーター.html`（ファイル名は前のまま。リンクを変えないため）、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3・図形）の「円周角と円の性質」から開けます。
- **画面のならび**：広い画面は 左＝図・右＝操作と答える欄 の2列（図は上に止まったまま）。スマホはたて1列。
- **記録**：この端末の localStorage（保存キー `ikechan-math-円周角シミュレーター`）に、ワークシートといっしょに入れます。
- **URL の設定**：`?teacher=1` … 先生モード、`?part=1〜6` … そのパートから始める、`?ws=1`／`?ws=0` … ワークシートをひらいて／とじて始める、`?debug=1` … 動作確認用（`window.__dbg`）

## パート

| パート | すること |
|---|---|
| ① 円周角と中心角 | **⭕ 円周の上**：● P・A・B をドラッグ。P に対応する弧（P をふくまない弧）を紫の太い弧、P を動かしても角が同じ弧を緑の点線で見せる。円周角・中心角・「円周角 ＝ 中心角 × ½」が連動。「＋ 点Q」で同じ弧のもう1つの円周角（反対側の弧に置くと「たして 180°」）。「▶ 自動」「⌒ AB を直径にする」。**🧭 円の外にも出す**：P を円の内側・外側にも動かせて、あしあと（▲ 大きい／● 同じ／▼ 小さい。色と形と模様で区別）が残る。円周をまたいだところには必ず ● を置く。 |
| ② 定理の逆 | A・B・C・D を方眼で動かし、∠ADB が ∠ACB と同じになる場所で「📌 D の場所を記録」。● が4こたまると、かくれていた A・B・C を通る円があらわれる。「すいつく」がオンのとき、D は円の近くでピタッと止まる。D を直線 AB の反対側に置くと「×」（角が等しくても同じ円周上とはいえない）。 |
| ③ 半円と直角 | **⌒ 直径と直角**：A・B は直径のまま動き、∠APB はいつも 90°。「💡 なぜ 90°？」で OP をひき、二等辺三角形2つから a ＋ b ＝ 90° を見る。**📐 直角定規で中心さがし**：中心はかくしてある。定規の角を円周上に置くと AB はいつも直径（10.0cm）。2本のこすと中心があらわれる。かたむきはスライダー＋数＋黄色の ●。**✏️ 接線の作図**：円の外の点 P から接線をひく5つの手順（PO → 中点 M → 半径 MO の円 → 交点 T・T′ → 接線）。PO が直径なので ∠PTO ＝ 90°。PT ＝ PT′ も表示。 |
| ④ 発展 | **⬠ 内接四角形**：A・B・C・D を円周上で動かす（順番はくずれない）。∠A ＋ ∠C ＝ ∠B ＋ ∠D ＝ 180°。「💡 なぜ 180°？」で2つの中心角（合わせて 360°）、「↗ 外角を見る」で ∠DCE ＝ ∠A、「🧭 D を円の外にも出す」で ∠B ＋ ∠D が 180° より大きい／小さい（② の「反対側」の場合とつながる）。**📏 接線と半径**（中1 の復習）：T を通る直線の向きを変える。半径 OT と 90° のときだけ円と1点で交わる（接線）。**📐 接線と弦**：∠XTA ＝ ∠TPA（接弦定理）。「💡 なぜ等しい？」で直径 TD′ をひく。「→ P を T に近づける」で PT が接線に近づく。 |
| ⑤ 証明 | 証明パズルの型。カードをタップして、上の行から順にならべる。① 中心が辺の上（二等辺三角形 OPA と外角）→ ② 中心が角の内部（直径 PC をひき、① を2回使って たす）→ ③ 中心が角の外部（直径 PC をひき、① を2回使って ひく）。② ③ の「① を使う」2行はどちらが先でもよい。カードを置くと、その行で使う辺・角が赤むらさきに光る（角の大きさつき）。A・B・P を動かしても、その場合の形のまま（中心の位置が変わる所で止まる）。完成した場合には ✅。 |
| ⑥ まとめの練習 | ① 〜 ⑤ の問題がまざって10問。「発展（④）もまぜる」で ④ も出る。けっかは「1回で正解した数」とパートごとの数。まちがえたパートへ「↩ もどる」ボタン。この端末のベストを記録。 |

### 練習問題（「✏️ 練習問題」）

角度の答えが整数になるように、答えを先に決めてから図をつくります。図は書いてある角度に合わせて正確にかきます（全体を少し回して、毎回同じ向きにならないようにしています）。角度の問題は、正解すると2問め「使った定理は？」に進みます。

- ①：中心角 → 円周角、円周角 → 中心角、同じ弧の円周角、P が劣弧にあるとき（中心角が 180° より大きい）
- ②：4点が同じ円周上にある？（ある／角がちがう／反対側／錯角のわな＝等脚でない台形）、定理の逆を使って x を求める
- ③：直径 → 90°、同じ弧＋直径、90° → 直径、接線と半径
- ④（発展）：内接四角形の対角、外角、接弦定理（2つの向き）
- ⑤：証明の1行を空らんにして、入るカードを4つからえらぶ

## ワークシート

- ①予想「点P を円周の上で動かすと、∠APB の大きさはどうなる？ 中心角とどんな関係？」（いつも同じ・P の場所で変わる・A・B に近いほど小さい・わからない）→ ②「📄 ワークシートの問題」で ① を開き、P を3か所以上に動かして「＋ 記録する」（P の場所・∠APB・中心角・∠APB÷中心角）。「🧭 円の外にも出す」で円の内側・外側も記録 → ③気づき → ④まとめ。

## 授業例

1時間めから順に、パートを1つずつ進める例です。

1. **円周角の定理**（①）：「🙈 数値をかくす」でクイズ。P を動かして記録し、いつも同じ・中心角の半分を見つける。P を円の外に出して、同じになるのは円周上だけと確かめる。
2. **証明**（⑤）：① 中心が辺の上 → ② 内部 → ③ 外部の順にカードをならべる。「なぜ3つに分けるの？」を話し合う。
3. **定理の逆**（②）：同じ角になる点を記録して、円があらわれるのを見る。練習問題で「錯角のわな」を考える。
4. **半円と直角・接線**（③）：直角定規で中心をさがす（実物の三角定規と紙の円でもやってみる）。接線の作図。
5. **まとめ**（⑥）：10問チャレンジ。まちがえたパートにもどって図で確かめる。発展をあつかうクラスでは ④ も。

## 正しさ・じっさいとのちがい

- ① の A・B は「すいつく」がオンのとき 2°ごと（円周角がちょうど整数になる）、オフのとき 1°ごとに動きます。P を円の外に出すときと ② の角度は、小数第1位までの四捨五入です。
- ② で同じ円周上かどうかは、角度ではなく、点と円のきょりで判定しています。
- ③ の長さは 1cm ＝ 35px として見せています（画面の大きさは実物とはちがいます）。接線の作図の「垂直二等分線」は、コンパスの線を省いて中点 M だけをかいています。
- ④ の内接四角形・接弦定理は、高校（数学A）の内容です（画面に「発展」と書いています）。接線と半径の垂直は中1 の作図で学ぶ内容です。
- 証明の書き方（ことばや行の分け方）は教科書や先生によって少しちがいます。このアプリの書き方は一例です。
