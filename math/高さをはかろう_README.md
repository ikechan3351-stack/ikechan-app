# 高さをはかろう（相似を使って、直接はかれない高さや距離を求める）

中学3年「図形と相似」の利用のアプリです。影の長さ・川をはさんだ三角形・縮図（地図の縮尺、仰角の作図）を使って、直接はかれない高さや距離を、相似な三角形と比例式で求めます。はかった値には誤差があることも、記録をとって確かめます。

## 基本情報

- **ファイル**：本体 `高さをはかろう.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3・図形）から開けます。
- **画面のならび**：広い画面は 左＝図・右＝操作と表 の2列（図は上に止まったまま）。スマホはたて1列。
- **記録**：この端末の localStorage（保存キー `ikechan-math-高さをはかろう`）に、ワークシートといっしょに入れます。
- **URL の設定**：`?teacher=1` … 先生モード、`?part=1〜4` … そのパートから始める、`?ws=1`／`?ws=0` … ワークシートをひらいて／とじて始める、`?debug=1` … 動作確認用（`window.__dbg`）

## パート

| パート | すること |
|---|---|
| ① 影で高さ | 横から見た校庭（左が東）。時刻（9:30〜14:30、スライダーと数）を変えると、太陽の高さが変わり、棒と木の影の長さが変わる（理科「かげの動き」と同じ計算：北緯35度・春分の日）。棒の高さは 1m・1.5m・2m、● で棒の位置を動かせる。「📏 影をはかって記録」で、棒の影・木の影（cm の位）と、比例式で計算した木の高さを表に記録。「はかる誤差を入れる」（±1.5% くらい）をオンにすると、はかるたびに少しずれる。「✅ 答え合わせ」で、じっさいの高さと誤差（m・%）を出す。「🌳 ほかの木」で別の高さの木。 |
| ② 川の幅 | 上から見た図。向こう岸の木 P、真向かいの A、岸にそって AB・BC（スライダー）、C から岸に垂直に D をドラッグ。D から B をのぞく線が P を通ると「一直線！」。△PAB∽△DCB（直角・対頂角）から AP ＝ AB × CD ÷ BC。記録・答え合わせ・ほかの川。 |
| ③ 縮図 | 🗺 地図の縮尺（1/500・1/1000・1/2000）：湖の P と Q に定規を合わせ（近づけるとすいつく）、縮図の長さ × 縮尺の分母 → じっさいの長さ。📐 仰角で高さ（発展）：建物までの距離と、クリノメーターではかった仰角から 1/500 の縮図をかき、定規で BC をはかって × 500 ＋ 目の高さ 1.5m。 |
| ④ ミッション | 🏫 校舎の高さ（24m はなれて仰角 34°、1/400）：① 6.0cm の AB をかく → ② 分度器で 34° の線 → ③ 垂線をひいて交点 C → ④ 定規で BC をはかる → ⑤ 高さを入力して答え合わせ。💧 水面にうつる木（水たまりの方法、1/200）：① T を O から 5.0cm におく → ② はね返る光の線（入る角＝はね返る角）→ ③ 垂線と交点 R → ④ TR をはかる → ⑤ 計算。答え合わせは「はかった長さからの計算」と合っているかを見て、じっさいの高さとの誤差（m・%）も出す。 |

### 練習問題（「✏️ 練習問題」、4択）

- ①：棒の高さ・棒の影・木の影 → 木の高さ
- ②：AB・BC・CD → 川の幅
- ③：地図の縮尺（1/1000・1/2000・1/25000）、仰角の縮図の BC → 建物の高さ（目の高さを足す）
- ④：水たまりの方法（目の高さ・水たまりまで・木まで）→ 木の高さ

## ワークシート

- ①予想「同じ時刻に、影の長さが2倍のものの高さは、何倍？」（2倍・4倍・同じ・わからない）→ ②「📄 ワークシートの問題」で ① を開き、10:00 に棒 1m で影をはかって記録、同じ時刻で棒 2m にして記録（時刻・棒の高さ・棒の影・木の影・木の高さ）→ ③気づき → ④まとめ。

## 授業例（1〜2時間）

1. 「校庭の木の高さを、木にのぼらずにはかるには？」と問い、ワークシートの予想。
2. ① で時刻を変えて影をはかり、比例式で木の高さを求める。時刻を変えても答えが同じになること、誤差があることを記録から確かめる。棒 1m と 2m で影が2倍になることを確かめる。
3. ② で川の幅（相似な三角形の見つけ方：直角・対頂角）。
4. ③ で縮尺と、仰角の縮図（目の高さを足す）。
5. ④ のミッションで、定規と分度器で縮図をかいてはかる。答えがみんな少しずつちがう理由（読みとりの誤差）を話し合う。実際の校庭で影や仰角をはかる活動につなげる。

## 正しさ・じっさいとのちがい

- **地面は水平、太陽の光は平行**（太陽はとても遠いので）、木・棒・建物は地面に**垂直に立っている**と考えています。
- 太陽の高さは、北緯35度（東京あたり）・春分の日として計算しています（理科「かげの動き」と同じ）。
- 影の長さは cm の位で読みます。「はかる誤差を入れる」をオンにすると、はかるたびに ±1.5% くらいずれます。
- 縮図の長さは 0.1cm（1mm）の位まで読むので、答えにも少し誤差が出ます（ミッションの答え合わせは、はかった長さからの計算と ±0.15m 以内なら正解）。
- 木・川・建物の大きさは架空です。目の高さは 1.5m としています。
- ③ の「仰角で高さ」は発展の内容です（三角比は使わず、縮図をかいて求めます）。
