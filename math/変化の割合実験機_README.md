# 変化の割合実験機（直線で調べる → x の増加量を変える → ほかの関数とくらべる → 自分で計算）

中学2年「一次関数の変化の割合＝傾き」のアプリです。2点 A・B を動かして、*x* の増加量と *y* の増加量、変化の割合をくらべます。比例・一次関数・反比例・*y*＝*ax*²（発展）で測りくらべて、**一次関数（と比例）だけ変化の割合が一定**であることを発見させます。

2026年10月に、共通部品（graph-engine.js・math-render.js・worksheet.js）で作り直しました。前からあった機能（A・B のドラッグ、直線固定、1ずつの階段、x を1ずつ増やす表、計算の流れ）は ① に残しています。

## 基本情報

- **ファイル**：本体 `変化の割合実験機.html`、共通部品 `math-render.js`・`graph-engine.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中2）から開けます。
- **画面のならび**：左にグラフ、右に計算と表。はば 760px 以上で2列（「傾きと切片 直線の式」と同じ形）。ワークシートは右はしの「📝 ワークシート」でひらきます。
- **URL の設定**
  - `?teacher=1` … 先生モード（④ の「答えを見る」・ワークシートのヒントと解答例）
  - `?mode=line`・`step`・`cmp`・`calc` … はじめに開くタブ
  - `?ws=1` … ワークシートをひらいて開く

## 色と線のきまり（「傾きと切片 直線の式」とそろえる）

| もの | 見え方 |
|---|---|
| *x* の増加量 | オレンジの実線（ラベル「x ＋5」） |
| *y* の増加量 | 青の点線（ラベル「y ＋3」） |
| 関数のグラフ | むらさきの線 |
| 2点を通る直線 | 緑青（自由に動かすときは実線、関数があるときは点線） |
| 点 A・B | 緑青の点（ドラッグできる） |

## 使い方

### ① 直線で調べる（表とグラフ）
- A・B をドラッグします（「すいつく／すいつかない」はグラフの上のボタンで切りかえ）。座標・A と B を通る直線の式・変化の割合の計算・意味（*x* が1増えると *y* は…）が出ます。
- 「直線固定」をオンにすると、決めた式 *y*＝*ax*＋*b* の上だけを動きます。*a* は分数（1/3・2/3・3/2 など）もえらべます。
- 「1ずつの階段」：A から B まで、*x* が 1 ずつ増えるときの *y* の増え方を階段で見せます。
- **表とグラフの連動**：*x* を 1 ずつ増やした表に、A・B の列が黄色く光り、その間の増加量（＋1、＋3）が色つきで出ます。表の数をタップすると、A → B の順に点がその場所へ動きます。
- 「📌 ワークシート用に今の2点をおぼえる」。

### ② x の増加量を変える
- 関数（一次関数・*y*＝*ax*²（発展）・反比例）と *a*（一次関数は *b* も）をえらびます。
- A から *x* が ＋1・＋2・＋3・＋4 増えたときの三角形を重ねて見せます（「三角形を重ねる」をオフにすると1つだけ）。えらんだ増加量の三角形がこく出ます。
- 表「*x* の増加量・*y* の増加量・わった値」が出ます。
  - 一次関数なら「*y* の増加量は *x* の増加量に比例し、わった値はいつも同じ。三角形は形が同じまま大きくなる」と出ます。
  - そのほかの関数なら「わった値が変わる」と出ます。
- A はドラッグで動かせます。

### ③ ほかの関数とくらべる
- 比例・一次関数・反比例・*y*＝*ax*²（発展）をえらび、A・B をいろいろな場所に動かして「📌 記録する」を押します。
- 記録の表と、関数ごとのまとめ（いつも ○／ばらばら）が出ます。
- 記録が 6 回以上、関数が 2 種類以上になると、「いつも同じだったのは、どの関数？」の問題が出ます（あてはまるものをぜんぶえらぶ）。正解は 比例・一次関数 です。

### ④ 自分で計算
- 一次関数か反比例の2点（負の数をふくむことが多い）について、*x* の増加量・*y* の増加量・変化の割合を入れます。
  - 右から左へ（増加量が負）の問題も出ます。
  - 正解すると、計算の流れとグラフの三角形が出ます。

## ワークシート

- もんだい：「2点を通る直線の変化の割合（傾き）と、一次関数の式 *y*＝*ax*＋*b* の *a* には、どんな関係があるだろうか？」
- 予想：いつも等しい／点の場所によってちがう／関係ない／わからない
- 記録：関数・点A・点B・*x* の増加量・*y* の増加量・変化の割合（①②③ では今の2点、④ では解いた問題が入る）。
- まとめ：一次関数では変化の割合は一定で *a* に等しい。反比例や *y*＝*ax*² では一定でない。
- 保存キーは `ikechan-math-変化の割合実験機`（つまずきの記録もこの中）。

## 授業での使い方の例（50分）

1. **予想（5分）**：ワークシートで予想。
2. **① 直線で調べる（15分）**：直線固定で *y*＝2*x*−1。A・B を3通り以上動かして記録し、変化の割合がいつも 2 になることを確かめる。表のタップで、表とグラフの三角形の対応を見る。
3. **② 増加量を変える（10分）**：＋1・＋2・＋3 で *y* の増加量が 2・4・6、わった値はいつも 2。*y*＝*x*²（発展）に切りかえると変わることも見せる。
4. **③ くらべる（10分）**：比例・反比例・*y*＝*x*² でも記録し、「一定なのは？」に答える。
5. **④ 計算・まとめ（10分）**：負の数の入った問題で練習し、ワークシートにまとめる。

## 正しさについて（※じっさいとのちがい）

- 座標・関数の値・変化の割合は、すべて分数（Fraction）で厳密に計算します。曲線（反比例・*y*＝*ax*²）を描くときだけ小数を使います。
- *y*＝*ax*² は中学3年で学ぶ関数なので、「発展」と表示しています。
- 反比例のグラフの点は、*x*＝0 には置けません（0 に動かすと、となりの位置になります）。
- グラフは画面のはしで切れていますが、本当はどこまでものびています。

## つまずき検知の一覧

| 型 | 見つけ方 | 例 |
|---|---|---|
| 🔃 x の増加量と y の増加量を取りちがえた | ④ で増加量を逆のらんに入れた／変化の割合を Δx÷Δy にした | Δx＝3、Δy＝6 で 1/2 |
| ± ひく順番がそろっていない | ④ で増加量の一方だけ符号が逆／変化の割合の符号が逆 | |
| ( ) 負の数をひくときのかっこ | ④ で B の値 − （A の値の絶対値）を入れた | −1−(−2) を −3 |
| ✏ 計算のまちがい | ④ のそのほか | |
| 〰 一次関数でない関数も「一定」と考えた | ③ の問題で、反比例や *y*＝*ax*² もえらんだ | |

つまずきは右の列に「あなたのつまずき」として出て、回数が「つまずきの記録」に残ります。
