# 式の利用（乗法公式・因数分解で、数や図形のきまりを説明する）

中学3年「多項式の利用（式の利用）」のアプリです。2年の「ためして 説明して 文字式」（2-02）の発展で、**展開・因数分解**を使って説明します。
「連続する2つの奇数の積に1を加えると？」のようなことがらを、まず**数でためし**、次に**文字式で説明**します。暗算のくふう（99²＝(100−1)²）や、**道の面積＝道幅×中央線の長さ**の説明もあつかいます。

## 基本情報

- **ファイル**：本体 `式の利用.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）・スマホ。
- **URL の設定**
  - `?teacher=1` … 先生モード（各パートの「▶ 自動で」ボタン・ワークシートのヒントと模範解答）
  - `?part=1`〜`4` … はじめに開くパート
  - `?ws=0` … ワークシートをとじて開く

## 4つのパート

### ① 数の性質（ためす → 説明）
左＝ことがら、中央＝実験、右＝文字式で説明（2-02 と同じならび）。

| ことがら | 文字での表し方 | 説明の中心の式 |
|---|---|---|
| 連続する2つの偶数の2乗の差は、4の倍数 | 2*n*, 2*n*＋2 | (2*n*＋2)²−(2*n*)²＝8*n*＋4＝4(2*n*＋1) |
| 連続する2つの奇数の積に1を加えると、間の偶数の2乗 | 2*n*＋1, 2*n*＋3 | (2*n*＋1)(2*n*＋3)＋1＝4*n*²＋8*n*＋4＝(2*n*＋2)² |
| 連続する3つの整数で、両はしの積＋1＝まん中の2乗 | *n*, *n*＋1, *n*＋2 | *n*(*n*＋2)＋1＝*n*²＋2*n*＋1＝(*n*＋1)² |
| 2つの奇数の積は、奇数 | 2*m*＋1, 2*n*＋1 | 4*mn*＋2*m*＋2*n*＋1＝2(2*mn*＋*m*＋*n*)＋1 |
| 2けたの整数－入れかえた数 は、9の倍数 | 10*a*＋*b*, 10*b*＋*a* | 9*a*−9*b*＝9(*a*−*b*) |

- **実験**：数を入れて「✔ ためす」、「🔟 10組ためす」「🐘 大きな数で」。ます目の図で、L字（2乗の差）・長方形を正方形にならべかえる（積＋1）・2こずつ組にして1こあまる（奇数×奇数）を見せます。3組以上ためすと「どんな数でも言える？」と聞きます。
- **説明**：① 表し方をえらぶ（文字のスライダー＋「➡ この数で実験する」）→ ② 展開した式を入力 → ③ 「4×(整数)」「( )²」などの形を入力 → 説明文が完成。
- 式の入力は、² ( ) ＋ − π のボタンでも入れられます。書き方のちがい（項の順番、全角・半角、² と ^2）は気にしません。

### ② 計算のくふう（公式で暗算）
「(x＋a)²」「(x−a)²」「(x＋a)(x−a)」「2乗の差（因数分解）」「おまかせ」をえらび、① どう見るか（きりのよい数を使う）→ ② どの公式か → ③ 途中の数と答え、の順に進みます。右に面積図が出ます。問題は きりのよい数（20〜1000）と差を先に決めて作り、同じ問題は続けて出ません。

### ③ 図形（道の面積）
正方形・長方形の花だん、円の池のまわりに、道幅 *a* の道。○ をドラッグ（またはスライダー・数の入力）で大きさを変えると、S（外側−内側）・ℓ（中央線）・*a*ℓ が計算され、いつも S＝*a*ℓ になることが見えます。「✂ 切り分けて見る」で、道が台形（円は台形に近い形）に分かれます。右側で、外側の長さ → S の展開 → ℓ → *a*ℓ の順に文字式で説明します。

### ④ 説明の組み立て（カード）
2-14「証明の組み立てパズル」と同じ型。①〜⑤（文字で表す・式に表す・展開する・形を見る・結論）の行に、カードをタップで入れます。**まちがいのカード**（同じ文字でおいた・展開ミス・数でためしただけ など）がまざっていて、えらぶと つまずきとして出ます。①の5つ＋道の面積（正方形・円）の7題。

## 授業での使い方（例）

1. ワークシートの予想「連続する2つの奇数の積に1を加えると？」（偶数の2乗／奇数の2乗／奇数／きまりはない）。
2. ① で 1×3＋1、3×5＋1、5×7＋1 … とためし、表を見て気づきを出す（4の倍数・平方数・間の偶数の2乗）。ます目の図で「長方形が正方形になる」ことを確かめる。
3. ① の右側（または ④ のカード）で文字式の説明をつくる。ワークシートのまとめに書く。
4. ② で暗算のくふう、③ で道の面積へ広げる。

## 正しさについて（じっさいとのちがい）

- 式の判定は、入力した式を多項式として計算し、正しい式と等しいかで調べます（数を入れたときの値ではなく、式として等しいか）。
- 道の長さは 0.1m きざみ、計算は分数で厳密に行い、表示だけ小数にしています。円の面積は π を文字のように残します。
- ② の面積図は、見やすいように長さを変えてかいています。
- 実験のます目は、数が大きいときや負の数のときは表示しません。

## つまずき検知の一覧

| つまずき | どこで出るか | もどる先 |
|---|---|---|
| 別の整数を、同じ文字（同じ式）で表した | ① 表し方（2*n*＋1 と 2*n*＋1 など）、④ カード | ① |
| 「連続する」数の表し方のまちがい | ① 表し方（2*m*, 2*n* など）、④ | ① |
| 奇数を *n*＋1 と表した／偶数・奇数の表し方 | ① 表し方、④ | ① |
| 2けたの整数を *ab* や *a*＋*b* と表した | ① 表し方、④ | ① |
| 展開で、まん中の項をわすれた（(a＋b)²＝a²＋b²） | ① ③ の展開、② の答え、④ | ②（この型を練習） |
| 2ab の「2」をわすれた | ① ③ の展開、② の途中の数 | ② |
| (x−a)² のまん中の符号 | ② | ② |
| (x＋a)(x−a) を x²＋a² とした | ② | ② |
| x²−a² を (x−a)² とした | ② の見方・答え | ② |
| −( ) のかっこをはずすときの符号 | ① の展開（2けたの差）、④ | ① |
| 「○×(整数)」「( )²」の形にしていない | ① の形、④ | ① |
| 数でためしただけで「いつも」と言った | ① の「言える？」、④ | ① |
| 結論を先に書いた | ④ | ④ |
| 外側の長さで、道幅の数え方をまちがえた | ③ ①、④ | ③ |
| 中央線の長さを、内側や外側の線で考えた | ③ の ℓ、④ | ③ |

記録は localStorage（キー `ikechan-math-式の利用`）の中の `trips`、できたものの印は `done` に入ります。画面下の「📒 つまずきの記録」で回数が見られ、「記録を消す」で消せます。
