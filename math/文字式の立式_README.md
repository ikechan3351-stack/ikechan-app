# 文字式の立式

中学1年「文字と式」のアプリです。
数量を文字を使った式に表すこと（立式）と、文字式の書き方のきまり（× をはぶく・数は文字の前・1 は書かない・同じ文字の積は累乗・÷ は分数）を、4つの画面で練習します。

## 基本情報

- **ファイル**：本体 `文字式の立式.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中1）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン・スマホ。広い画面では「問題｜ボタンと説明」の2列、せまい画面では縦に並びます。
- **URL の設定**
  - `?teacher=1` … 先生モード（選択肢に ★答え、② の「▶ 式を組み立てる」、③ の答え、ワークシートのヒントと解答例）
  - `?tab=rule`・`?tab=scene`・`?tab=sub`・`?tab=rev` … はじめに開くタブ
  - `?ws=0` … ワークシートをとじて開く

## 使い方

### ① きまり
- 「a×3」「1×a」「a×a×a」「a÷3」「(a+b)×3」「a×3−b÷2」などを、きまりどおりに書いたものを4つからえらびます。数と文字は毎回かわります。
- 正解すると、そのきまりの説明が出ます。右の「文字式の書き方のきまり」に6つのきまりをまとめています。
- 「▶ つぎの問題」「↶ ひとつもどす」（前の問題へ）「⟲ もういちど」（点数もリセット）。

### ② 式にする
1. 場面カード（例「1個 x 円のおにぎりを 3 個と、1本 y 円のお茶を 2 本買ったときの代金」）を読み、正しい式を4つからえらびます。
2. 正解すると、式の項と場面の数量に**同じ色と同じ下線の形**（オレンジ・実線／青・二重線／緑・点線）がつき、「3x … 1個 x 円のおにぎりを 3 個」のようにつながりが出ます。
3. 「③ 数を入れてみる →」で、同じ場面の代入へ進めます。
- 場面は13こ：おにぎりとお茶・弁当のおつり・電車とジュース・スマホのデータ量・クラスの集金・ケーキのわりかん・体育館の列・水そうの水・自転車の道のり・えんぴつを分ける・ノートとペン・ジュースの残り・文化祭のチケット（値段はすべて架空）。

### ③ 代入
- 場面をえらび、文字ごとのスライダー（数の入力もできます）で数を入れます。
- 場面の文の文字が、黄色の点線のわくの**数**に変わり、「3x+2y → 3×120+2×150 → ＝660 円」の流れで式の値が出ます。
- 値がマイナスになると「場面に合わない」と出ます（スマホのデータ量で 1日に使う量を多くしたときなど）。
- 下の「🎯 式の値をもとめよう」で、出された数のときの式の値を答えます。答えはいつも整数です。2回まちがえると答えと計算が出ます。

### ④ 説明（式 → 場面）
- 式（例 3x＋2y）と文字の意味を見て、その式が表している場面の文を3つからえらびます（式から場面への逆向き）。

## ワークシート

| ステップ | 内容 |
|---|---|
| ① 予想 | 「1個 x 円のおにぎりを 3 個と、1本 y 円のお茶を 2 本買ったときの代金を式で表すと？」 3x＋2y／x3＋y2／5xy／わからない ＋ 理由ひとこと |
| ② 操作 | ② で正解したら「＋ 記録する」（場面・式）。③ で数を入れたら「＋ 記録する」（場面・式・代入と値） |
| ③ 気づき | 自由に書く |
| ④ まとめ | 式で書くと？（3x＋2y）／ことばで言うと？（文字式の書き方のきまり） |

保存キーは `ikechan-math-文字式の立式`（つまずきの記録も同じキーの中に入ります）。

## 授業例（中1・文字を使った式）

1. **予想（5分）**：ワークシート①。x3＋y2 や 5xy をえらんだ生徒の考えも聞く。
2. **きまり（10分）**：① を数問。まちがえた型を「あなたのつまずき」で確認。
3. **式にする（15分）**：② で場面を式に。先生モードの「▶ 式を組み立てる」で、部分ごとに式にして ＋・− でつなぐ流れを見せる。
4. **代入（10分）**：③ で x＝100 などを入れ、3x が 3100 にならないこと（× をおぎなう）を確かめる。
5. **まとめ（5分）**：ワークシート④。時間があれば ④ で逆向き（式 → 場面）。

## 正しさとじっさいとのちがい

- 式の値は分数で厳密に計算しています（わり算の場面も、答えが整数になる数だけを問題に出します）。
- 文字の順番（アルファベット順）は、教科書で「ふつうはそうする」とされている書き方です。① の「文字の順番」のまちがいは、式の値としてはまちがいではありません。
- 場面の値段・データ量は架空のものです。

## つまずき検知の一覧

| 型の名前 | どんなときに出るか | 画面のことば（要点） |
|---|---|---|
| 数を文字のうしろに書いた | ① a3・(a+b)3、② x3+y2 などをえらんだ | 数は文字の前に書く |
| 1 を書いた | ① 1a・−1a、② 5a+1b をえらんだ | 1×a は a、(−1)×a は −a |
| × や ÷ をはぶいていない | ① 3×a・a÷3 のままのものをえらんだ | × をはぶき、÷ は分数の形 |
| ÷ を分数にするとき、上と下が逆 | ① a÷3 を 3/a、② x を 6 人で分けるを 6/x | わられる数が分子 |
| 同じ文字の積を累乗にしていない | ① a×a を 2a・aa | a×a は a²、2a は a＋a |
| かっこを落とした | ① (a+b)×3 を 3a+b、④ 平均を「片方の半分をたす」 | かっこの中ひとまとまりに計算している |
| 文字の順番 | ① 3ba、② ba | ふつうはアルファベット順 |
| かけ算をたし算にした | ① a+3、② 3+x+2+y など | 代金＝1個の値段×個数 |
| ちがう項をひとつにまとめた | ② 5xy・13x・30a | 文字や形がちがう項はまとめられない |
| × と ÷ の取りちがえ | ② 4a（わりかん）・x/3（道のり） | 分ける・1人分はわり算、何こ分はかけ算 |
| ひき算の順番が逆 | ② 2a−1000・7b−a・600−x | はじめにある量から使った量をひく |
| 場面の数量を読み落とした | ② x+120（往復を見落とし）・a−b | 往復・○個・○日の数をもう一度見る |
| 代入のとき × をわすれた | ③ 3x に x＝100 を入れて 3100 として計算した答え | × をおぎなってから計算 |
| 式が表すものの読みちがえ | ④ ちがう文をえらんだ | 式の数や ＋・− が文のどこに出てくるかくらべる |

- 記録は「📒 あなたのつまずき」に回数で出ます。「🔁 類題」でその型の問題だけを出せます（「記録を消す」で消せます）。

## 先生が改造するとき

- 場面を足す：HTML の中の `SCENES` に1行足します（`{0:…}` でかこんだ部分が式の0番目の項に対応。`vars` は ③ のスライダーの [はじめ, 最小, 最大, きざみ]）。
- ④ の問題を足す：`REVS` に1行足します。
- ① の問題の型を足す：`RULE_MAKERS` に関数を足します。
