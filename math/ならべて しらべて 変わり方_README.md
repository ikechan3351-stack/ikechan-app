# ならべて しらべて 変わり方

小学5年生の算数「変わり方調べ」（東京書籍 新しい算数 5下 93〜95ページ）で使う教材です。図形を1つずつならべたときの数の変わり方を**表**にまとめ、きまりを見つけて **□ と ○ の式**に表します。

- □（ならべた数）が1ふえると、○（まわりの長さ・ストローの本数）はいつも同じ数ずつふえる
- □×（ふえる数）＋（はじめの分）＝○の式に表すと、□が大きいときの○もすぐ求められる
- ○がわかっているときは、式を逆にたどって□を求める

今までの「関数の箱」（`関数の箱.html`）は、中学につながる発展・練習用として残しています。

## 基本情報

- **ファイル**：`ならべて しらべて 変わり方.html`。共通ファイル `worksheet.js`・`worksheet.css` を同じフォルダから読みこみます。
  - ネット接続・外部ライブラリ・画像ファイルは不要です。図はすべて SVG。
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「算数・数学」（5年）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）。本文20px以上・ボタン48px以上。スマホのたて向きでも画面がはみ出しません。
- **漢字**：変わり方・表・式・正方形・正三角形・辺 などにふりがなをつけています。「せってい」で消せます。
- **ワークシート**：よそう → やってみる → わかったこと → まとめ（小学生向け）。「きろくする」で、場面・□・○・見つけたきまり（式）を記録します。
- **保存**：ワークシートと「せってい」を、このブラウザの localStorage（キー：`ikechan-math-ならべて しらべて 変わり方`）に保存します。もんだいの成績は保存しません。

## 4つの場面

| 場面 | □ | ○ | 式 |
|---|---|---|---|
| 🟦 正方形の まわり | 1辺1cmの正方形を横にならべた数 | まわりの長さ（cm） | □×2＋2＝○ |
| 🔺 ストローの 三角形 | ストローでつなげた正三角形の数 | ストローの本数 | □×2＋1＝○ |
| 🟧 ストローの 正方形 | ストローでつなげた正方形の数 | ストローの本数 | □×3＋1＝○ |
| 🪜 だんの まわり | 正方形をだんにつんだ、だんの数 | まわりの長さ（cm） | □×4＝○ |

## 3つの画面

### 🧩 ならべて しらべよう

- 「＋ ならべる」で1つずつふやします（8まで）。いまふえた分は、色と点線（正方形はしま）で区別します。□と○が表にたまります（まだのところは「？」）。
- 「🔮 つぎを よそう」で、ならべる前に次の○を予想して入れ、「ならべて たしかめる」。
- 「🔍 ふえ方を 見る」で、表の○のあいだに「＋3」などが出ます。「□が 1 ふえると、○は いくつ ふえる？」に答えると、理由（となりといっしょに使う1本など）が出ます。
- 「− とる」「↩ ひとつ もどす」（表ももどる）「🔄 もういちど」があります。

### 🧮 きまりを 式に

1. 表（□1〜5と○、ふえ方）と、4つならべた図。「🎨 式の わけを 図で 見る」で、はじめの分（緑の太い線）と1つ分ずつのまとまり（色と線のもよう）に分けて、×ふえる数＋はじめの数 になるわけを見せます（だんは、線を右と下にうつすと正方形のまわりと同じ）。
2. 式「□ × ［ ］ ＋ ［ ］ ＝ ○」をつくる。せいかいすると □＝1・2・3 のたしかめが出ます。まちがえたときは、表と合わなくなるところを見せます。
3. □が20のときの○。「➡ 表を のばして しらべる」で表を20までのばすこともできます（10までのばすと、式のよさの声かけ）。
4. ○がわかっているときの□（○は毎回変わる）。

### ✏️ もんだい

| 種類 | 例 | 答え方 |
|---|---|---|
| 表の つづき | □1〜4と○の表 → □が6のときの○ | 数字ボタン（2回まで） |
| 式を えらぶ | 表に合う式を4つから | えらぶ（1回） |
| □が 大きい とき | ストローの三角形を20こならべると何本？ | 数字ボタン（2回まで） |
| ○から □ | ストローを43本つかった。何こならべた？ | 数字ボタン（2回まで） |
| 図を 見て | 3つならべた図から、10こならべると？ | 数字ボタン（2回まで） |

- 5問なら1つずつ、10問なら2つずつ（「せってい」でえらべます）。PCはキーボードの数字・Backspace・Enter も使えます。

## つまずき検知

| 型の名前 | 見つけ方 | 出るところ |
|---|---|---|
| ふえる 数だけの 式 | □×3＝○ のように、はじめの分（＋1）をわすれた／○から□で、ひかずにわった | きまりを 式に・もんだい |
| はじめの 数で かける | 1つめの○（4）を使って □×4＝○ とした | きまりを 式に・もんだい |
| □と ○の とりちがえ | ○から□を求めるのに、□に○の数を入れて計算した（43×3＋1 など） | きまりを 式に・もんだい |

- もんだいでは、見つけた型を「あなたの つまずき」として出し、次にその型の「にた もんだい」を1問足します。終わりに型ごとの回数と、「🧮 きまりを 式に」へのボタンを出します。
- 「1つずつ数えて、きまりを使わない」は答えの数から見分けられないので、型にはせず、表をのばしすぎたときの声かけにしています。

## 先生モード（アドレスの最後に `?teacher=1`）

- 題名の横に「先生モード」のしるし。ならべて しらべよう：「💡 こたえ」で表を8までうめる。きまりを 式に：「💡 こたえ」で式と③④の答え。もんだい：「💡 こたえ」。ワークシートに先生用のヒントと解答例が出ます。

## 授業での使い方の例

1. **表にまとめる（1時間）**：「ならべて しらべよう」でストローの正方形を1つずつならべ、表にまとめる。「つぎを よそう」で予想してからならべ、ふえ方（3本ずつ）とそのわけ（左の1本はとなりといっしょ）を話し合う。
2. **式に表す（1時間）**：「きまりを 式に」で □×3＋1＝○ をつくり、図の色わけでわけを説明する。□が20のとき・○が43のときを式で求め、表をのばすより便利なことを確かめる。ほかの場面でも同じように考える。
3. **まとめ**：「もんだい」で練習し、つまずきの型をふりかえる。

## 正しさと、じっさいとのちがい

- ストローはどれも同じ長さで、すきまなくつなげるものとしています。
- 表だけの問題のきまりは、□×（2〜6）＋（1〜5）＝○の中から作っています。

## 色だけに頼らない区別

| 区別するもの | 色 | 色以外の手がかり |
|---|---|---|
| いまふえた分 | 青 | 点線（ストロー）／しま模様（正方形） |
| はじめの分／1つ分ずつ（式のわけ） | 緑／色ちがい | 太い実線／線のもよう（実線・点線・細かい点線） |
| □／○ | 青／オレンジ | 四角のわく／丸いわく |
| 正解／まちがい | 緑／赤むらさき | ◎・△ の記号 |
