# 根号の計算ドリル（レベル別・つまずき別の計算練習）

中学3年「平方根」の計算（√ の中を小さくする・有理化・乗除・加減・乗法公式）を、**レベル別に10問ずつ**練習するアプリです。
まちがえた答えから「どこでつまずいたか（つまずきの型）」を見つけて記録し、**その型の類題**をふくしゅうできます。
「正負の数ドリル」（1-03）と同じ形です。

## 基本情報

- **ファイル**：本体 `根号の計算ドリル.html`、共通部品 `math-render.js`（式の表示・分数・√ の簡約）、`worksheet.js`・`worksheet.css`（ワークシート）。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）・スマホ。横長の広い画面では「問題｜キーパッド」の2列、せまい画面では縦に並びます。
- **記録**：この端末の localStorage（保存キー `ikechan-math-根号の計算ドリル`）に、ワークシートといっしょに入れます（解いた問題は新しい3000問まで）。
- **URL の設定**：`?teacher=1` … 先生モード、`?ws=1`／`?ws=0` … ワークシートをひらいて／とじて始める

## レベル

| レベル | 内容 | 例 |
|---|---|---|
| ① | 乗法・除法 | √6×√8、√48÷√3、2√3×4√6、6√10÷2√5 |
| ② | a√b の形にする（外に出す・中に入れる） | √72 → 6√2、2√12 → 4√3、3√2 → √18 |
| ③ | 分母の有理化 | 1/√2、3/√6、5/√12、√2/√3、5/(2√5) |
| ④ | 加法・減法 | √12+√27、√8+√18−√2、√12+√8−√27、√12+6/√3 |
| ⑤ | かっこをふくむ式・乗法公式 | √2(√3+1)、(√3+1)(√3−1)、(√5+2)²、(√2+√3)²、(√5+2)(√5−3) |
| 🎲 | ミックス | ①〜⑤から2問ずつ（順番はばらばら） |

問題の上に「計算しなさい」「a√b の形にしなさい」「√a の形にしなさい」「分母を有理化しなさい」の指示が出ます。

## 答えの入れ方

答えの欄は「マス」に分かれています。**√ の外の数（a）と √ の中の数（b）を別のマスに入れます。**

| 入れたい答え | 押すキー |
|---|---|
| 6√2 | 6 → √ → 2 |
| √6 | √ → 6 |
| √6／2（分数） | √ → 6 → 分数 → 2（「分数」で分母のマスへ） |
| 9＋4√5 | 9 → ＋ → 4 → √ → 5 |
| 3√2−3 | 3 → √ → 2 → − → 3 |
| −√3 | − → √ → 3 |

- マスをタップ（クリック）すると、そこへ移って直せます。「⌫ けす」は1文字ずつもどす（空のマスで押すとマスを消す）、「ぜんぶけす」でやり直し。
- 分母にも √ を入れられます（1/√2 のように）。このときは値は合っていても「分母に √ が残っている」になります。
- キーボード：数字、r＝√、/＝分数、+ −、← →＝マスの移動、Backspace＝1文字けす、Delete＝ぜんぶけす、Enter＝答え合わせ／つぎへ、Esc＝やめる。

## 使い方

1. レベルをえらんで「10問チャレンジ」。
2. 答えを入れて「こたえる」。
   - **○ せいかい**：つぎの問題へ。
   - **△ おしい**（値は合っているが形がちがう）／**× ざんねん**：つまずきの型に合わせた一言（例「分母にも同じ √ をかけたかな？」）が出て、**1回だけなおせます**。なおして正解なら **△**。
   - **2回目もまちがい**：正しい答えと、**解き方のアニメ**が自動で出ます。
   - 答えたあとは「解き方を見る ▶」で、いつでもアニメを見られます。
3. 10問おわると結果の画面。
   - ○・△・× の数と、問題ごとの「あなたの答え → 正しい答え」とつまずきの型。
   - **あなたのつまずき**：型の名前・回数・説明・実際にまちがえた例。
   - 「この型の類題（5問）」：その型のまちがいが起きる問題だけを5問出します。
   - 「🧮 電卓でたしかめる」（足し算で根号の中をたした型）、「べつの教材でたしかめる」（素数のふるい・乗法公式タイル）。
- はじめの画面の「この端末のつまずき（さいきん100問）」からも類題を始められます。
- 「さいしょから」：同じレベルで新しい10問をやり直します（もういちど）。

### 解き方のアニメ

「もとの式 → … → 答え」を1行ずつ（1.7秒ごと）出します。√ を簡単にする行は
**素因数分解 → 同じ数の2つ組を見つける（色と線の形で囲む）→ 2つ組を √ の外に出す（とび出す動き）→ まとめる** の順です。
加減の問題では、項ごとに「√12 を簡単に」の行が出てから、「それぞれ簡単にした式 → √ の中が同じ項をまとめる」になります。

### 🧮 しらべよう（ワークシート）

予想「√2＋√3 は √5 ？」を、電卓のような小数で確かめます。

- √ の中の数を2つ入れると、√a・√b・√a＋√b・√(a＋b) の小数（小数第4位を四捨五入）が出て、「✖ ちがう」が分かります（√2＋√3 ≈ 3.146、√5 ≈ 2.236）。
- 「2乗してくらべると」(√2＋√3)²＝5＋2√6、(√5)²＝5 も出ます。
- 2・8 のように √ の中が同じ数になる組では「ほんとうの値 √2＋√8＝3√2（＝√18）」も出ます。
- 「かけ算なら √a×√b と √(ab) は同じ」も比べられます。
- 「＋ ワークシートに記録」で表に1行入ります（式・√a＋√b・√(a＋b)・同じ？）。ワークシートは ①予想 → ②記録 → ③気づき → ④まとめ（式とことば）で、印刷・テキストのコピーができます。

### 🖨 プリント（A4・20問＋答え）

- レベル（①〜⑤・ミックス）と**シード番号**をえらんで「印刷する」。1ページめが問題（月日・組・番・名前・点数の欄、問題ごとに〔計算〕〔a√b に〕〔√a に〕〔有理化〕の札）、2ページめが答え（赤字）です。
- 同じレベル・同じシード番号なら、何度印刷しても同じ問題になります。

## 先生モード（`?teacher=1`）

- 問題の画面の左下（スマホでは右上）に**答え**が出ます。「解き方 ▶」で、答える前でも解き方のアニメを再生できます（電子黒板での説明用）。
- 「クラスのつまずきを黒板に出す」：この端末で解いた記録を集めて大きく出します（今日／この1週間／ぜんぶ、型ごとの棒グラフと例、レベル別の正答率、記録を消す）。
- ワークシートに先生用のヒントと解答例が出ます。

## 授業例（中3・根号をふくむ式の計算）

1. **予想（5分）**：「√2＋√3 は √5 ？」をワークシートの①に書く。理由も一言。
2. **たしかめる（5分）**：「🧮 しらべよう」で 2・3 を入れて小数をくらべ、記録。2・8、3・12 もためして「√ の中が同じになればまとめられる」に気づく。③④を書く。
3. **個人練習（20分）**：レベル②（a√b の形）→ ④（加減）の10問チャレンジ。結果の「あなたのつまずき」から類題5問。
4. **全体（10分）**：先生モードの「クラスのつまずき」で多かった型を見て、「解き方 ▶」のアニメで確認する。
5. **宿題**：プリント（シード番号を板書しておくと、答え合わせのプリントも同じものを出せる）。

## 正しさのくふうと「じっさいとのちがい」

- 計算は小数を使わず、「√ の中（平方因数のない数）ごとの係数（分数）」の組で厳密に行います。生徒の答えも同じ形にして、値が同じかどうかをくらべます。
- 小数は「しらべよう」で見せるためだけに使います（小数第4位を四捨五入した、およその値）。
- 答えがきれいな形になるよう、√ の中や係数をえらんで問題を作っています（④⑤の √ の中は 200 まで、③の分子は 12 まで など）。
- つまずきの型は、答えから「たぶんこうまちがえた」と推測したものです。ちがう考え方で同じ答えになることもあります。
- 確認したこと：①〜⑤の問題を各800問作り、問題の式を小数で計算した値と答えが一致すること、正しい答えを入れると必ず ○ になること、わなの答えが正しい答えと同じにならないこと、を調べました。

## つまずき検知の一覧

| 型 | 見つけ方 | 例 |
|---|---|---|
| 根号の中を素因数分解していない | 値は合っているが、√ の中に 2乗の数（4・9・25…）が残っている | √72 → 3√8、√72、2√18 |
| √ の外と中で、2乗の関係をまちがえた | わな：外に出すとき 2乗のまま／中に入れるとき 2乗しない | √72 → 36√2、3√2 → √6、√3×√6 → 9√2 |
| 足し算で根号の中をたした | わな：√ の中どうしをたした | √12＋√27 → √39、2√3＋3√3 → 5√6 |
| 有理化で分子だけに√をかけた | わな：分子にだけ √ をかけて、分母がそのまま／消えた | 3/√6 → 3√6、5/(2√5) → 5√5/2 |
| 約分忘れ | 値は合っているが、分母と √ の外の数がまだ約分できる | 6/√3 → 6√3/3、3/√6 → 3√6/6 |
| 分母に √ が残っている | 値は合っているが、分母に √ がある | 1/√2 のまま |
| 同じ √ の項をまとめていない | 値は合っているが、√ の中が同じ項が2つ以上ある | √12＋√27 → 2√3＋3√3 |
| 問題の形の指示とちがう | 「√a の形に」で、値は合っているが √ の外に数がある | 3√2 → 3√2 |
| √a×√a＝a をわすれた | わな：√3×√3 を √3 にした | 2√3×4√3 → 8√3、√3(√3＋2) → 3√3 |
| 分配法則で かけわすれた | わな：かっこの2つめの項にかけていない | √2(√3＋1) → √6＋1 |
| 乗法公式のまちがい | わな：まん中の項をわすれた・2倍わすれ・符号・(x＋a)(x−a) をたし算に | (√5＋2)² → 9、(√3＋1)(√3−1) → 4 |
| 符号のまちがい | 答えの符号だけが反対 | √2−√8 → √2 |
| 計算ミス（√ の部分は合っている） | √ の中の数は正しいが、外の数がちがう | √12＋√27 → 6√3 |
| そのほか | 上のどれでもない | |

「値は合っているが形がちがう」型は △（おしい）の一言を出します。1つの答えに形の型が2つあるときは、どちらも記録します。

## 改造のしかた（先生向け）

- 問題の作り方は `genL1`〜`genL5`、つまずきの型の名前・一言・説明は `TYPES` にあります。
- 問題は `mk({ text, prompt, ans, steps, traps, can })` で作ります。`ans` は `svT(係数, √の中)` を `svAdd` でたしたもの、`traps` は `[型の名前, まちがえたときの答え]` の並びです。
- 小学校の関連教材：`九九マスター.html`（同じ数どうしのかけ算＝平方数）。ほかに `平方根の数直線.html`・`素数のふるい.html`・`乗法公式タイル.html`。
