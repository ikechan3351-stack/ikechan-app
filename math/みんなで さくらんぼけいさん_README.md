# 🍒 みんなで さくらんぼけいさん（小学1年・電子黒板の説明用）

先生が電子黒板で、くりあがりのたし算・くりさがりのひき算を説明するためのアプリです。
画面に出るのは図とボタンだけで、説明のことばは先生が話します（問いかけの文・音声・効果音・記録はありません）。

- ファイル：`math/みんなで さくらんぼけいさん.html`（1ファイルで動く。外部ファイル・通信なし）
- 子どもが一人で解くときは、別のアプリ `math/さくらんぼけいさん.html` を使います

## 使い方

1. 「たしざん」「ひきざん」を選ぶ
2. 「つぎ ▶」を押すたびに1場面進む。問いかける場所が黄色く光って止まるので、そこで子どもに聞く。もう一度押すと数字が入る
3. 2場面目で2つの数が光ったら、**分ける数をタップ**する（下の表）。タップせずに「つぎ」を押すと、おすすめの解き方で進む
4. 「◀ まえ」「↺ さいしょから」はいつでも押せる。2場面目までもどれば、別の解き方を選び直せる

| 問題 | タップする場所 | 解き方 |
|---|---|---|
| たし算 8+3 | うしろの 3 | 3を2と1に分けて、8と2で10（加数分解） |
| たし算 8+3 | まえの 8 | 8を7と1に分けて、3と7で10（被加数分解） |
| たし算 7+8（どちらも6以上） | 「5と 5」 | どちらも5とのこりに分けて、5と5で10 |
| ひき算 13−8 | まえの 13 | 13を10と3に分けて、10から8をとる（減加法） |
| ひき算 13−8 | うしろの 8 | 8を3と5に分けて、バラの3、10から5の順にとる（減減法） |

### ソーセージを やく（たし算）

10になる2つ（8+3なら 8 と さくらんぼの 2）が光った次の場面で、2つをソーセージでかこみ、ジュージューとゆれてから、こげめと「10」が付きます。その次の「つぎ」で、ブロックが10のわくに入ります。
5と5のときは、5を1つずつ丸でかこんで下でつなぐ「ガッチャンコ」になります（ジュージューはしません）。
「まえ」でもどったときや画面の大きさが変わったときは、アニメなしで焼けた形をすぐ出します。

### 式への書きこみ（ひき算）

えんぴつで書いたような線が、1本ずつ順に書かれます（今の「さくらんぼけいさん」のまなぶと同じ形）。

- **10からとる（14−8）**：10から8をとる場面で、8から10へ矢印 → 次の「つぎ」で、10にななめ線、10の左下に答え（2）
- **バラからとる（12−3）**：バラをとる場面で、12の一の位（2）とさくらんぼのバラ（2）を丸でかこむ → 次の「つぎ」で、一の位にななめ線、下に「10」

「まえ」でもどったときは、その場面までの書きこみをアニメなしですぐ出します。

「つぎ」だけで進むと、たし算は小さいほうの数を分け、ひき算は10からとる解き方になります。

## 問題の変え方

- **もんだいを かえる**：数字ボタンで選ぶ。くりあがり・くりさがりにならない組み合わせは押せない（たし算36問・ひき算36問）
- **べつの もんだい**：同じ種類から別の1問を出す
- **URL**：授業スライドにリンクを貼ると、その問題から始められる
  - `みんなで さくらんぼけいさん.html?q=8p3` … 8+3（p は plus）
  - `みんなで さくらんぼけいさん.html?q=13m8` … 13−8（m は minus）
  - 範囲外の問題を書いたときは、はじめの問題（8+3）が開く

## 操作

- タッチ・マウス・キーボードで動く。→ または Enter でつぎ、← でまえ（プレゼン用のリモコンでも進められることが多い）
- 「ぜんがめん」で画面いっぱいに表示

## 授業での使い方の例

- **導入**：8+3 を出し、2場面目で「どちらの数を分けると、10がつくりやすいかな？」と聞く
- **展開**：「8はあといくつで10？」で空のわくを見せて止め、子どもの答えを聞いてから「つぎ」で確かめる
- **くらべる**：3+9 を、3を分ける・9を分けるの両方で見せる。ひき算も 13 を分ける・8 を分けるで比べる
- **まとめ**：右上の①②の式と、さくらんぼ・ブロックを見ながらノートに書く

## ※じっさいとのちがい・注意

- 「バラからとる」は、さくらんぼけいさんのアプリでは一部の問題（15問）に限っていますが、計算はどの問題でも成り立つので、ここでは全問で選べます。授業の問題に合わせて先生が選んでください
- 右上の①②の式は、説明とノートをつなぐために入れています

## 直すとき

- 解き方ごとの場面は、HTML の中の表 `METHODS` と関数 `splitAdd` に、上から順に書いてあります。場面を足したり順番を変えたりするときは、ここだけ直します
- 大きさは `layout()` と `geo()` が画面に合わせて計算します
