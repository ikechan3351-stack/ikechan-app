# 🎒 さんすうセット ていがくねん

さんすうボード①〜⑥ を、**小学1・2年で使うものだけにしぼって1つにまとめた入り口**です。最初にボードをえらぶだけで使えます。①〜⑥ の数が多くて、先生方がどれを使えばよいか迷ってしまう、という声から作りました。

- 新しいアプリではありません。中身は ①〜⑥ と同じアプリです。①〜⑥ はこれまでどおり残っていて、3年生以上でも使えます。
- **ファイル**：`さんすうセット ていがくねん.html`（入り口）。ボードは同じフォルダの ①〜⑥ のファイルを使います。ネット接続・外部ライブラリは不要です。

## 使い方

1. 入り口のカード（🟦おはじき・ブロック／🥢かぞえぼう・タイル／🪙おかね／🔷いろいた・タングラム／🟠ジオボード／🕐とけい）をタップする。
2. ボードが開く。使い方は ①〜⑥ と同じ。
3. 左上の **🏠 ボードえらび** で入り口にもどり、べつのボードをえらべる。

## しぼっているところ（低学年モード）

入り口からは、ボードを `?low=1` をつけて開きます。この合図があるときだけ、つぎのように変わります。合図がなければ ①〜⑥ は今までどおりです。

| ボード | 低学年モードでの変化 |
|---|---|
| ① おはじきボード | 変化なし（もともと低学年向け） |
| ② かぞえぼう・タイル | 変化なし（1000までの数） |
| ③ おかね | 学年は **1ねん・2ねん** だけ（500円玉まで） |
| ④ いろいた・タングラム | 学年は **1ねん・2ねん** だけ。タングラムはそのまま使える |
| ⑤ ジオボード | いつも **低学年用**。「だれ むけ」の切りかえと、はじめの「えらんでね」画面を出さない |
| ⑥ とけいと じかん | 変化なし（もともと1・2年） |

どのボードでも、左上の「← トップ」が「🏠 ボードえらび」に変わります。

## 先生モード

- 入り口の右上の **🧑‍🏫 せんせい** を押すと、えらんだボードが先生モード（📝もんだい・💾くばる）で開きます。アドレスに `?teacher=1` が入るので、そのままブックマークできます。
- ボードの中で先生モードを切りかえても、低学年モードはそのまま続きます。

## つづきから（自動保存）

- ボードのようすは、ふつうの ①〜⑥ とは**べつに**保存されます（保存のキーの最後に `-ていがくねん` がつく）。ふつうの ①〜⑥ で使った3年生以上のボードがまざりません。
- そのタブで1回目に開いたときは、ふつうどおり「つづきから／あたらしく」を聞きます。2回目からは聞かずに、そのまま続きを開きます（ボードを行ったり来たりしやすくするため）。

## しくみ（コードのつくり）

- 入り口：ボードの表 `BOARDS`（絵文字・名前・ファイル・説明・札）からカードを作ります。ボードを足すときは、ここに1行足します。
- ①〜⑥ 側：`const LOW = params.get('low') === '1';` で合図を読みとり、`SAVE_KEY` の後ろにある「ていがくねんから ひらいた とき」の部分で、もどるリンクとつづきからを切りかえています。③は `GRADE_LIST`、④は学年ボタンの `for`、⑤は `if (LOW) LEVEL = 'low';` で学年をしぼっています。

## これからの予定

- べつのボードの「ボード入りの画像」を 📂ひらく でえらんだとき、そのボードに自動で切りかえる。
