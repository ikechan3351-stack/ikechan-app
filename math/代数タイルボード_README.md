# 代数タイルボード

代数タイル（x²・x・1、y²・y・xy）を指で置いて、文字式・一次方程式・展開と因数分解を「見える化」するボード。中1〜中3。
参考：Brainingcamp の Algebra Tiles（考え方を参考にし、見た目・操作はこのサイトの教材にそろえて作り直したもの）。

## 使い方
- 左の道具箱から、タイルをボードへドラッグ。「＋ 正 / − 負」で道具箱の色を切りかえる。
- **タップ**：うらがえす（正⇔負）。**ながおし**：まわす（たて⇔よこ）。上の「タップ」で入れかえられる。
- 正と負の同じタイルを重ねると **ゼロペア** で消える。🧹ゼロペア でまとめて消せる。
- 道具箱か 🗑️ にもどすと すてる。↩ ひとつもどす（Ctrl+Z）、🗑️ リセット。
- 👁️ ひょうじ：式を見せる／かくす（「？」になる）、タイルの文字、🧲すいつく、ゼロペアで消える、y のタイルも使う。
- ✏️ ペン（赤・黒・緑）、📷 しゃしん（クリップボードへコピー。できないときは PNG を保存）。

## マット
| マット | できること |
|---|---|
| なし | 自由にならべる |
| 式 | マットの中のタイルを式にして上に表示 |
| 方程式 | 左辺・右辺に分けて方程式を表示。「🔒 この式で はじめる」で はじめの式を決めると、つりあい（解が変わらないか）を見はる。x = ○ になると「とけた！」 |
| かけ算 | 上の帯＝よこ、左の帯＝たて、中＝面積。たて × よこ ＝ 面積 になると「ぴったり！」 |

## おだい（📝。すべて乱数。答えを先に決めてから式を作る）
- 式マット：式をつくろう／まとめよう（同類項。ゼロペアがまざっている）
- 方程式マット：x の係数が1／両辺に x／負の数も（解は整数）
- かけ算マット：展開しよう／因数分解しよう／因数分解（負の数も）／(x + a)² の形

## 先生モード（`?teacher=1`）
- ✨こたえ：かけ算マットは たて・よこから中を うめた長方形を ならべる（因数分解のおだいでは たて・よこも置く）。方程式マットは解を表示。
- 方程式の「あと すこし」に解をそえる。

## URL のオプション
- `?mat=expr` / `eq` / `prod` / `none`：はじめのマット
- `?jh=1`：「数学操作ボード 中学」から開いたとき。左上が「🏠 ボードえらび」になり、入り口にもどれる

## 授業例
- 中1 文字式：x と 1 は まとめられない（x の長さは 1 の整数倍にしていない）。−(…) はタイルを全部うらがえす。
- 中1 一次方程式：両辺から同じものをとる。片方だけ変えると つまずき表示 → ↩ で もどして考える。
- 中3 展開・因数分解：(x + a)(x + b) の長方形。負の数がある因数分解は、ゼロペア（＋x と −x）を足すと長方形にできる。

## つまずき検知
| 型 | 出るとき |
|---|---|
| かたほうの辺だけ かえた | 方程式マットで、はじめの式と解が変わった状態で 2回操作した／x = ○ の形にした |
| 符号 | かけ算マットで、中のタイルの大きさ（係数の絶対値）は あっているが 符号がちがう |
| 帯のタイルの向き | かけ算マットの帯に、細い向きでないタイルを置いた |

## ※じっさいとのちがい
- タイルの式は、マットの中にあるタイル（タイルのまん中の位置）で数える。
- かけ算マットの「ぴったり」は、式（係数）が同じかで判定している。長方形の形にすきまがないかまでは調べていない。
- 解き方の自動再生はない（こたえを ならべる だけ）。
