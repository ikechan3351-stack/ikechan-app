# 中学数学アプリのルール（中学1〜3年）

このファイルは `math/` フォルダの中で作業するときに読みこまれる。全体のルールはリポジトリ直下の `CLAUDE.md` を見る。

### 置き場所とファイル

- 1つのアプリは `math/` の中の1つの HTML ファイルにする（例: `math/連立方程式のグラフ.html`）。CSS と JS も同じファイルの中に書く。今の教材と同じ形。
- 共通ファイルは次のものだけ: `math/math-render.js`（数式の表示・分数計算・√の簡約）、`math/graph-engine.js`（座標平面とグラフ）、`math/worksheet.js` と `math/worksheet.css`（ワークシート）、`math/動点エンジン.js`（図形の辺を動く点と面積の区間ごとの式。中2の動点・中3の二次関数の動点で使う）。各アプリからは `<script src="math-render.js">` のように読みこむ。共通ファイルを直したら、使っている教材ぜんぶで動作を確かめる。
- 「5問ミニテスト」の問題データだけは、学年ごとの別ファイル `math/minitest-data/中1.js`・`中2.js`・`中3.js` にする（JSON は file: で読めないので .js にする）。問題の `id` は一度決めたら変えない（記録がずれるため）。
- 外部ライブラリ・CDN・画像ファイルは使わない（学校のネットワーク制限やオフラインでも動くように）。数式も図も、HTML・Canvas・SVG でコードで描く。
- ファイル名は日本語にする。アドレスに `game`・`battle` を入れない（学校のフィルターで止まる）。
- 「もどる」リンクは `../index.html`。説明書は `math/○○_README.md` として同じフォルダに置く。
- 通信が必要な機能（サーバー、ログイン）は作らない。対戦は1台の画面で行う形にする。

### 見た目

- 配色・フォント・カードの形は、今の算数・数学教材とそろえる。電子黒板で後ろの席からも読めるよう、式は大きく。
- 文字は大きく（本文18px以上、式は24px以上）、ボタンは44px以上でタッチしやすく。
- 中学生向けなので、ふりがなは基本的に付けない。小学校で習っていない用語（平方根、因数分解など）は、画面のすみに短い説明を付ける。
- 色だけで区別しない（形・文字・線の種類・模様も使う）。色覚のちがいに配慮した色にする。共通の色のきまり（案）: 正の数・増える＝オレンジ、負の数・減る＝青、正解・そろった＝緑、まちがい・注意＝赤紫（ほかの色と区別できるよう記号もつける）。
- タブレットの横向き（1024×768）を基準にし、スマホの縦向きでも画面がくずれないようにする。

### 操作

- マウスでもタッチでも動くようにする（pointer events を使う）。
- 「もういちど（リセット）」と「ひとつもどす」を必ず置く。
- スライダーには必ず数値入力も付ける（正確な値を入れたいため）。
- ドラッグする点には、整数にすいつく／すいつかない、の切りかえを付ける。
- 見えないものは「見える化」する（面積図・タイル・矢印・色）。式・表・グラフが連動して動くようにする。

### 学びの流れ

- 「①予想 → ②操作 → ③気づき → ④まとめ（式とことば）」のワークシート（`math/worksheet.js`）を付ける。
- 保存には localStorage を使い、キーは「`ikechan-math-ファイル名`」にする。
- `?teacher=1` を付けると先生モード（ヒント・答え・解き方の自動再生）になる。トップページのフラグ `t` を付ける。
- **つまずき検知**を入れる。よくあるまちがいは型に名前をつけて検出し、「あなたのつまずき」として画面に出し、その型の類題や元の図にもどす。
- 小学校の関連教材（前提になる学習）へのリンクを1つ付ける。

### 正しさ

- 計算は、分数と根号を使って厳密に行う（小数の誤差で答えがずれないようにする）。見せるときだけ小数にする。
- 乱数で作る問題は、答えがきれいな数（整数や簡単な分数）になるように、答えを先に決めてから式を作る。同じ問題が続けて出ないようにする。
- 数値や式は学習指導要領の範囲をこえない。発展内容にはタイトルまたは画面に「発展」と書く。
- かんたんにした部分は、画面のすみに「※じっさいとのちがい」として短く書く。
- 実在する会社・商品・人の名前は使わない（料金などは架空のものにする）。

### 作り方の順番

- 作る前に、画面の案（何を動かせて、何が記録されるか）を説明して、ユーザーの了承をもらう。
- 題名は生徒に伝わることばで考え、候補を3つ出して、ユーザーに選ばせる。
- 先生が改造しやすいように、コードに日本語のコメントを付ける。
- 大きいアプリは、パート1だけ作って確かめてから、パートを足す。
- できたら内蔵ブラウザで開き、操作・リセット・タッチ・スマホ幅・先生モードを確かめ、不具合を直してから報告する。
- 完成したら `index.html` の `D` に1行足し、README（使い方・授業例・正しさのちがい・つまずき検知の一覧）を書く。`python3 tools/update-obsidian-note.py` で Obsidian のノートも更新する。

## 小学5・6年アプリのルール（東京書籍「新しい算数」令和6年度版に合わせる）

上の中学ルール（置き場所・操作・学びの流れ・正しさ・作り方の順番）をそのまま使う。ちがうところだけ、ここに書く。

- **単元に合わせる**：教科書の単元ごとに1本。今ある教材がある単元は、それを活かして足りない部分だけ直す。
- **ことば**：習っていない漢字にはふりがな（`<ruby>`）を付ける。専門用語（約分・通分・合同・倍数など）は言いかえずに残し、ふりがなを付ける。題名は子どものことばで、候補3つからユーザーが選ぶ。
- **見た目**：本文は20px以上、ボタンは48px以上。1つの画面でやることは1つにしぼる。
- **ワークシート**：`math/worksheet.js` を使い、`Worksheet.init({ kids: true, ... })` にする（見出しが「よそう → やってみる → わかったこと → まとめ」の小学生向けのことばになる）。
- **つまずき検知**：1アプリ2〜3型にしぼる（例：小数のかけ算で小数点の位置をまちがえる、通分で分子をそのままにする）。
- **リンク**：前の学年の関連教材へのリンクを1つ、中学の続きの教材があればそこへのリンクも1つ付ける。
- **正しさ**：数値は教科書の範囲をこえない。こえるものは「発展」と書く。分数は `math/math-render.js` の Fraction で計算する。
- **計画表**：進み具合は `math/小学算数アプリ計画.md` で管理する。1つ完成したら「✅」に書きかえる。
