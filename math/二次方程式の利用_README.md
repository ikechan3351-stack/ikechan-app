# 二次方程式の利用（文章題・図形・動点）

中学3年「二次方程式の利用」で、文章題・図形・動点から二次方程式を立てて解き、**解が問題に合うかを吟味する**アプリです。
はじめに図形を動かして（x を変えて）面積などが決まった値になる x を**実験**でさがし、そのあと式を立てて解いて、**実験と計算が一致する**かをたしかめます。

## 基本情報

- **ファイル**：本体 `二次方程式の利用.html`、共通部品 `math-render.js`（式の表示・分数）、`graph-engine.js`（グラフとドラッグできる点）、`動点エンジン.js`（④ の動く点の位置と面積。「動く点Pと面積のグラフ」と同じ部品）、`worksheet.js`・`worksheet.css`（ワークシート）。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中3）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス）・スマホ。広い画面では「図｜グラフ」の2列、せまい画面では縦に並びます。
- **記録**：この端末の localStorage（保存キー `ikechan-math-二次方程式の利用`）に、ワークシートといっしょに入れます。
- **URL の設定**：`?teacher=1` … 先生モード、`?type=1〜5` … その型の問題から始める（書かなければ、ワークシートの問題から始まる）、`?ws=1`／`?ws=0` … ワークシートをひらいて／とじて始める

## 問題の型

| 型 | 例 | 式 | 吟味 |
|---|---|---|---|
| ① 整数 | 連続する2つの正の整数の積が 56 | x(x＋1)＝56 | x＝7、−8 → 正の整数なので −8 は合わない |
| | 連続する2つの整数の積が 56 | 同じ | 整数なので、7 と 8、−8 と −7 の2組とも合う |
| | 正の整数で、2乗の和が 41 | x²＋(x＋1)²＝41 | x＝4、−5 → −5 は合わない |
| ② 箱 | 10cm×12cm の紙の四すみから x cm の正方形を切って、底面積 48cm² | (10−2x)(12−2x)＝48 | x＝2、9 → 0＜x＜5 なので 9 は合わない（底の辺が負） |
| ③ 道のある庭 | 10m×15m の土地に、はば x m の十字の道。花だん 84m² | (10−x)(15−x)＝84 | x＝3、22 → 0＜x＜10 なので 22 は合わない |
| ④ 動く点 | 長方形 ABCD（AB＝6cm）、P は A→B、Q は AE＝2cm の点E から D へ、どちらも毎秒 1cm。△APQ＝12cm² | ½x(x＋2)＝12 | x＝4、−6 → 0≦x≦6 なので −6 は合わない（時間が負） |
| | 1辺 8cm の正方形で、P は A→B、Q は B→C。△PBQ＝6cm² | ½x(8−x)＝6 | x＝2、6 → 2つとも合う |
| | AB＝10cm、BC＝6cm。P は毎秒 1cm、Q は毎秒 2cm。△PBQ＝16cm² | ½(10−x)×2x＝16 | x＝2、8 → 0≦x≦3（Q が C に着くまで）なので 8 は合わない |
| ⑤ ボール | 秒速 20m で投げ上げる h＝20t−5t²。高さ 15m は何秒後？ | 20t−5t²＝15 | t＝1、3 → 上がるときと下がるとき、2つとも合う |
| | 高さ 20m から秒速 15m で投げ上げる h＝20＋15t−5t²。地面に落ちるのは？ | 20＋15t−5t²＝0 | t＝4、−1 → −1 は合わない（時間が負） |

（数は「🎲 新しい問題」で変わります。答えを先に決めて作っているので、解はいつも整数です。）

## 使い方（5つのステップ）

1. **🔬 実験**：スライダー・数の入力・グラフの点で x を動かします。図と「x＝○ のとき、面積＝○」が変わります。目標の値になると緑になり、「実験で見つけた x」に残ります。③ では「➡ 道を はしに寄せる」で、花だんが (たて−x)(横−x) の長方形になることが見られます。
2. **✏️ 式**：4まいのカードから、問題に合う式をえらびます。まちがえると理由とつまずきの型が出ます。
3. **🧮 解く**：二次方程式の解を**2つとも**入れます（まだ問題に合うかは考えない）。「🧮 解き方を見る」で、整理 → 係数でわる → 因数分解 → 解 の流れが出ます。
4. **🔍 吟味**：それぞれの解が問題に合うかを えらびます。合わないときは理由（負の数／長さが 0 や負／点が辺をこえる／時間が負）をえらび、**自分のことばでも書きます**（書いたことばは、ワークシートの記録に入ります）。「🔬 図で見る」で、その x の図にできます（変域の外なら図にできない、と出ます）。
5. **🏁 答え**：答えをえらぶと、実験で見つけた x と計算の答えをくらべて「一致」をたしかめます。

### グラフの見方

- **太いオレンジ**：問題の変域の中での量（④ は動点エンジンで計算した、ほんとうの面積）。
- **灰色の点線**：式のグラフ（変域の外も）。合わない解は、この点線の上にある。
- **緑の点線**：目標の値。解いたあとは、解の点（合う ○ 緑・合わない × 赤紫）が出ます。

## 授業での使い方（例）

- **導入（ワークシート）**：はじめに開くと、ワークシートの問題（④ △APQ＝12cm²）になっています。「何秒後？ いくつありそう？」と予想させ、スライダーで実験（4秒後の1つだけ見つかる）。式を立てて解くと x＝4、−6 の2つ出る。なぜ −6 は実験で出ないのかを話し合い、グラフの点線で −6 のところを見せる。
- **くらべる**：④ の「正方形」や ⑤ の「高さ ○m」は、2つとも合う問題。「1つだけ合う問題」「2つとも合う問題」をくらべて、吟味が必要なわけをまとめる。
- **式の立て方**：② ③ は、図にかきこんでから式を立てる練習に。③ の「道を はしに寄せる」で、(たて−x)(横−x) になるわけを見せる。

## 先生モード（`?teacher=1`）

- 「▶ 自動で見せる（先生）」：スライダーを動かして実験 → 正しい式 → 解き方 → 吟味（図で見る）→ 答え まで自動で進みます（もう一度押すと止まります）。
- 式・解・合う／合わない・答えの表示、この端末のつまずきの合計。
- ワークシートに、先生用のヒントと解答例が出ます。

## 正しさについて（じっさいとのちがい）

- 計算は分数（Fraction）で厳密に行っています。④ の面積は動点エンジン（くつひもの公式）で計算し、変域の中では式と一致することを確かめています。
- ⑤ のボールは空気の抵抗を考えず、落ち方を「5t²」と簡単にしています（ほんとうは約 4.9t²）。図では、時間がたつようすが分かるように、ボールを右へずらしてかいています。
- ① のスライダーは整数だけにしています（−13〜12）。
- ④ で点が止まったあとの面積と、灰色の点線（式のグラフ）はちがいます。点線は「式だけで考えたときのグラフ」です。

## つまずき検知の一覧

| 型 | 見つけるところ | 練習へ |
|---|---|---|
| x の範囲（変域）を考えなかった | 吟味で、合わない解を「問題に合う」とした | ④ |
| 問題に合わない解も、答えにした | 答えで、両方の解（または合わない解）をえらんだ | ② |
| 問題に合う解を、すててしまった | 吟味で、合う解を「合わない」とした | ⑤ |
| 合う解が2つあるのに、1つだけ答えた | 答えで、1つだけえらんだ（2つとも合う問題） | ⑤ |
| 式の立て方（問題文と式が合っていない） | 式のカード（和と積・(x＋1)²・体積・道の面積・÷2 以外の長さのまちがい など） | ② |
| 箱の底の辺で、切りとる長さを片側だけひいた | ② の (W−x)(L−x) のカード | ② |
| 道の重なりを考えなかった | ③ の WL−Wx−Lx のカード | ③ |
| 三角形の面積の ÷2 をわすれた | ④ の ÷2 のない式のカード | ④ |
| 方程式を解く計算のまちがい | 解の入力 | — |
