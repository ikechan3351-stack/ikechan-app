# 数直線ジャンプ（正の数・負の数のたし算・ひき算）

中学1年「正負の数」の**加法と減法**を、数直線の上のカンガルーの「ジャンプ」で見えるようにするアプリです。
(+3)+(−5) は「右へ3、左へ5」。ひき算は「ひく数と反対の向きに進む」ことを矢印の色・形・向きで見せ、「ひく数の符号を変えたたし算」に書きかえても同じ着地点になることをたしかめます。

## 基本情報

- **ファイル**：本体 `数直線ジャンプ.html`、共通部品 `math-render.js`・`worksheet.js`・`worksheet.css`。ネット接続・外部ライブラリは不要です。
- **公開ページ**：トップページ「算数・数学」（中1）から開けます。
- **対応する機器**：電子黒板・タブレット（タッチ）・パソコン（マウス・キーボード）・スマホ。
- **URL の設定**
  - `?teacher=1` … 先生モード（自動再生ボタン・ドリルの答え・ワークシートのヒントと解答例）
  - `?mode=drill` … はじめからドリルモードで開く
  - `?ws=0` … ワークシートをとじて開く（`?ws=1` でひらく）

## 使い方

### 🔬 じっけんモード
1. 「最初の数」「計算（たす／ひく）」「次の数」を選んで式を作ります。
   - 「＋ 正」「− 負」で符号、▼▲ か数字の入力で大きさ（0〜9）を決めます。入力欄に −5 と打ってもかまいません。
   - 「ためしてみよう」のボタンで、よく使う式をすぐに出せます。
2. 「🦘 ジャンプ！」… カンガルーが 0 から1目もりずつジャンプします。
   - 1回目：最初の数の向きへ進む
   - 2回目（たす）：その数の向きのまま進む …… **実線・三角の矢じり（▶）**
   - 2回目（ひく）：まず、ひく数のもとの向きを**灰色の細い点線（✕）**で見せてから、**反対の向き**へ進む …… **点線・二重の矢じり（≫）**
   - 右へ進む矢印はオレンジ、左へ進む矢印は青。色だけでなく、線の種類・矢じりの形・ことばのラベルでも区別しています。
   - 着地点に吹き出しで答えが出て、式にも「＝ 答え」が出ます。
3. 「✏️ ひき算 → たし算に書きかえる」（ひき算のとき）… (+3)−(−5) ＝ (+3)+(+5) と式を書きかえ、数直線の**下側**でたし算のジャンプをします。上（ひき算）と下（たし算）が同じ着地点になることが見えます。
4. 「↶ ひとつもどす」で前の式に、「⟲ もういちど」ではじめの式 (+3)+(−5) にもどります。
5. 答えが −15〜+15 からはみ出す式は、注意が出てジャンプできません。

### 🎯 ドリルモード
1. 式が出ます（答えを先に決めてから式を作るので、答えは −9〜+9 の整数。同じ問題は続けて出ません）。
2. 着地点を予想して数直線をタップします（ドラッグ、← → キーでも動かせます。目もりにすいつきます）。
3. 「✔ 答え合わせ」でジャンプが再生され、○／× が出ます。
4. × のときは「あなたのつまずき」に型の名前と説明が出て、線の下に**赤紫の点線「あなたの考え」**（✕ で終わる）が描かれます。
   - 「▶ 数直線でもう一度見る」「✏️ たし算に書きかえて見る」「🔁 この型の類題」で、図にもどったり、同じ型の問題を練習したりできます。
5. 「問題」で ぜんぶ／たし算／ひき算 をしぼれます。「📒 これまでの記録」に正答率とつまずきの回数が残ります（「記録を消す」で消せます）。

### そのほか
- 「ジャンプのはやさ」：ふつう／はやい／アニメなし。
- 画面の下に「符号」「加法・減法」「数直線の向き」の短い説明があります。
- 「📏 小学校の数直線にもどる」で `数直線ツール.html` を開けます。

## ワークシート（右がわ・スマホでは下）

| ステップ | 内容 |
|---|---|
| ① 予想 | 「(+3)−(−5) は、いくつ？」 −2（左へ進む）／+8（右へ進む）／+2／わからない ＋ 理由ひとこと |
| ② 操作 | じっけんモードでジャンプ → 書きかえ をしてから「＋ 記録する」。式・着地点・たし算に書きかえた式が表に入る |
| ③ 気づき | 自由に書く |
| ④ まとめ | 式で書くと？（例 (+3)−(−5)=(+3)+(+5)）／ことばで言うと？（ひき算がたし算に変わる理由） |

保存キーは `ikechan-math-数直線ジャンプ`（ドリルの記録も同じキーの中に入ります）。

## 授業例（中1・正負の数の加法と減法 2〜3時間目）

1. **導入（5分）**：じっけんモードで (+3)+(−5) をジャンプ。「たすときは、その数の向きに進む」を確認。
2. **予想（5分）**：ワークシート①で (+3)−(−5) を予想させる。−2 と +8 で意見が分かれやすい。
3. **操作（10分）**：(+3)−(+5) と (+3)−(−5) をジャンプ。灰色の点線（もとの向き）と、実際に進む点線の矢印を比べる。「ひく＝反対の向き」に気づかせる。
4. **書きかえ（10分）**：「✏️ たし算に書きかえる」で上と下が同じ着地点になることを見せ、④まとめを書く。
5. **練習（10分）**：ドリルモード。まちがえたら「あなたのつまずき」を読み、「この型の類題」で練習。
- 先生モードの「▶ 解き方を自動再生」で、ジャンプ → 書きかえを続けて電子黒板に見せられます。

## つまずき検知の一覧（ドリルモード）

| 型の名前 | 見つけ方（予想 p、式 a ○ b） | 例 | 画面のことば |
|---|---|---|---|
| ↔ 向きの変えわすれ | ひき算で p ＝ a＋b（ひく数の向きのまま進んだ） | (+3)−(−5) で −2 | ひく数の向きにそのまま進んでいる。ひくときは反対へ |
| ± 符号の見落とし（次の数） | 次の数が負で、− を + と読んだ答え | (+3)+(−5) で +8 | (−5) を (+5) と読んでいませんか |
| ± 符号の見落とし（最初の数） | 最初の数が負で、− を + と読んだ答え | (−4)+(+6) で +10 | 最初のジャンプは 0 から左へ |
| ⇄ 答えの符号のまちがい | p ＝ −(正しい答え) | (+3)+(−5) で +2 | 着地点が 0 の反対がわ |
| 👣 数えまちがい（1つずれ） | 正しい答えと 1 ちがう | (+3)+(−5) で −3 | ジャンプの数を目もり1つずつ数えなおそう |
| ？ そのほか | 上のどれでもない | | 1回目・2回目のジャンプを順に見なおそう |

- (+3)−(−5) で −2 と答えた場合は、「向きの変えわすれ」と「(−5) を (+5) と読んだ」のどちらでも同じ答えになるので、「向きの変えわすれ」として数え、説明にもう一方の可能性も書いています。
- 「この型の類題」は、型に合わせて出します（向きの変えわすれ → 同じ符号の数をひくひき算、符号の見落とし → 負の数が入る問題）。

## 正しさ・じっさいとのちがい

- 数直線は −15〜+15 の整数だけです。ほんとうの数直線は左右にどこまでも続き、小数や分数の点もあります（画面にも「※じっさいとのちがい」として書いています）。
- 式の数は −9〜+9 の整数にしています。計算は整数だけなので誤差はありません。
- ドリルの予想は整数にすいつきます（答えが整数だけなので、すいつかない切りかえは付けていません）。
- 0 には符号をつけず、正の数は「+3」のように + をつけて表示しています（教科書の導入の書き方に合わせています）。
