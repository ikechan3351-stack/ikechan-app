# 漢字ガンバ　まとめ絵の指示文（5字ずつ・16回）

ChatGPT などで、**5字ぶんの絵を1枚にまとめて** つくるための文です。
できた絵を Claude に送ると、1つずつ切り分けてアプリに入れます。

## つかい方

1. ChatGPT の新しいチャットを開きます。
2. **1回目だけ**、見本のポスター画像を貼りつけてから、下の「1回目」の文を送ります。
3. 2回目からは、**同じチャットのまま** 文だけを送ります（タッチがそろいます）。
4. できた絵を、そのまま Claude とのチャットに送ります（「まとまり3です」など一言そえると助かります）。

うまくいかないとき：
- 文字や数字が入ってしまったら →「文字や数字を消して、もう一度」と送る
- マスがずれたら →「6つの同じ大きさの正方形のマスに、きちんと区切って」と送る

---

## 1回目（一 二 三 四 五）※見本のポスター画像もいっしょに貼る

```
この画像と同じ、やさしい絵本のようなタッチで、新しい絵を1枚つくってください。

【形】横3マス×たて2マスの、同じ大きさの正方形のマスに区切った1枚の絵（横長）。
　　　マスとマスの間は白いすき間をあける。背景は白。
【大事】絵の中に 文字・数字・ふりがな・記号は ぜったいに入れない。
【マスの中身】左上から順に
　1. りんごが 1こ
　2. 子どもが 2人 ならんで 歩いている
　3. おにぎりが 3こ
　4. チューリップが 4本
　5. 風船が 5こ
　6. 空白（なにも かかない）
```

## 2回目から（同じチャットで、文だけを送る）

毎回、はじめにこの1行をつけてあります：
「さっきと同じタッチ・同じ形（横3×たて2の正方形のマス、白い背景、文字・数字・記号なし、6マス目は空白）で、つぎの絵をつくってください。」
