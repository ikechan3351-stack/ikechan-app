# 漢字ガンバ　絵をつくるための AI への指示文

画像をつくる AI（ChatGPT・Gemini など）に、下の文をそのまま貼りつけて絵をつくります。

## つかい方

1. 下の「**共通の指示**」を先に AI に送ります（1回だけ）。絵のタッチをそろえるためです。
2. つぎに、つくりたい字の「指示文」を1つずつ送ります。
3. できた画像を **`字.png`**（例：`山.png`）という名前で、このフォルダの中の **`img`** フォルダに入れます。
4. 画像を入れた字は、アプリの絵文字が自動でその画像にかわります。入れていない字は絵文字のままです。

- 絵の中に **文字を入れない** ようにしてください（答えが見えてしまうため）。
- 子どもに見せる前に、意味がまちがって伝わらない絵か、先生の目でたしかめてください。
- 1つのまとまり（5字）ずつつくると、すぐに授業で使えます。

## 共通の指示

```
これから、小学1年生（特別支援学級をふくむ）の漢字学習アプリにのせる絵を1枚ずつ頼みます。すべて次の条件でそろえてください。
・正方形（1024×1024）、白い背景
・やさしい線と、うすい水彩のような色の、絵本のようなイラスト
・描くものは画面の中央に1つだけ大きく。背景はシンプルに
・文字・数字・記号は絵の中に入れない（数をあらわす絵は、ものの数で表す）
・こわい表現、暴力、特定のキャラクターや商品は入れない
```
