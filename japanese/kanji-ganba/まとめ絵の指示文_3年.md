# 漢字ガンバ　まとめ絵の指示文　3年（5字ずつ・40回）

ChatGPT などで、**5字ぶんの絵を1枚にまとめて** つくるための文です。
できた絵を Claude に送ると、1つずつ切り分けてアプリに入れます（`img/字.png`）。

## つかい方

1年・2年のときと同じです（`まとめ絵の指示文.md` を見てください）。

1. ChatGPT の新しいチャットを開きます。
2. **1回目だけ**、1年か2年の絵（見本）を貼りつけてから、下の「1回目」の文を送ります。タッチがこれまでの絵とそろいます。
3. 2回目からは、**同じチャットのまま** 文だけを送ります。
4. できた絵を、そのまま Claude とのチャットに送ります（「3年のまとまり3です」など一言そえると助かります）。

## 3年の絵で気をつけること

- 3年の字には「意」「相」「由」「定」のように、ものの絵にしにくい字がさらに多くあります。そういう字は、**アプリの例文（つかいかた）の場面** を絵にしています。
- 絵の中に **文字・数字・時計の数字・カレンダーの数字** は入れません（答えが見えてしまうため）。
- 「死」「血」「悪」「苦」などは、こわすぎない・いたすぎない、やさしい絵にしてもらってください。
- 子どもに見せる前に、意味がまちがって伝わらない絵か、先生の目でたしかめてください。

うまくいかないとき：
- 文字や数字が入ってしまったら →「文字や数字を消して、もう一度」と送る
- マスがずれたら →「6つの同じ大きさの正方形のマスに、きちんと区切って」と送る
