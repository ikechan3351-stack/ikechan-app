# 一次関数ゲーム（Python版）

パソコンで直接うごかす Python 版です。
ブラウザ版（Web で公開しているもの）は、このフォルダの外にあります。

| ここにあるもの | なにか |
| --- | --- |
| `一次関数ゲーム.py` | Python 版の本体（tkinter） |
| `一次関数ゲーム起動.command` | ↑をダブルクリックで起動する用 |
| `pygame_web/main.py` | Pygame 版の本体 |
| `一次関数ゲームPygame起動.command` | ↑をダブルクリックで起動する用 |
| `pygame_web/sounds/` | 効果音・BGM |
| `pygame_web/build/` | Web 用に書き出したもの（自動生成なので git には入れない） |

## 動かしかた

`.command` ファイルをダブルクリックするだけです。
（はじめての1回だけ、Mac が「開けません」と出ることがあります。そのときは
ファイルを右クリック →「開く」を選んでください。）
