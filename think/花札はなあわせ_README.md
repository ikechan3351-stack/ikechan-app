# 花札 はなあわせ（ロボ2体と3人で遊ぶ花札）

3人で遊ぶ花札「花合わせ」を、ロボ（コンピューター）2体と遊べるようにしたものです。同じ月の札を合わせて取り、札の点数と「役」で勝負します。3回戦の合計で順位が決まります。

あとで、それぞれの端末から合言葉で集まって遊ぶ「みんなで対戦」版（オンライン版）を作る予定です。この1台版は、そのための練習用でもあります。

## 基本情報

- **ファイル**：`花札はなあわせ.html`（これ1つで動きます。ネット接続・外部ライブラリは不要）
- **人数**：あなた1人＋ロボ2体
- **対応する機器**：スマホ（縦）・タブレット・パソコン
- **札の絵**：プログラムで描いたオリジナルの絵です（市販の札の絵は使っていません）。
- 企画メモ：脳メモ `教材開発/企画/2026-11-19_花札はなあわせ.md`

## ルール

1. 48まいの札を、手札7まい×3人・場札6まい・山札21まいに分ける（場に同じ月が4まいあれば配り直し）。
2. 自分の番：手札を1まい出す。場に**同じ月の札**があれば、2まいとも取る。なければ場に置く。
   - 同じ月が場に2まいあるときは、どちらか1まいを選んで取る。
   - 同じ月が場に3まいあるときは、4まいぜんぶ取る。
3. つづけて山札を1まいめくり、同じように取る（または場に置く）。
4. 3人が7回ずつ出したら1回戦おわり。3回戦の合計点で順位を決める。

## 点数

- 札の点数：光20・タネ10・短冊5・カス1（ぜんぶで264点）
- 1回戦の得点 ＝ 取った札の点数 − 88点 ＋ 役の点数（88点は264点の3分の1）
- 最後に場にのこった札は、だれの点にもならない。

| 役 | そろえる札 | 点 |
|---|---|---|
| 五光 | 光5まい | 200 |
| 四光 | 「柳に雨」いがいの光4まい | 60 |
| 三光 | 「柳に雨」いがいの光3まい | 30 |
| 赤短 | 松・梅・桜の赤短 | 40 |
| 青短 | 牡丹・菊・紅葉の青短 | 40 |
| 猪鹿蝶 | 萩に猪・紅葉に鹿・牡丹に蝶 | 20 |
| 花見で一杯 | 桜に幕・菊に盃 | 20 |
| 月見で一杯 | 芒に月・菊に盃 | 20 |

役の点数は地域によってちがいます。HTMLの中の `YAKU_PTS`（札の点数は `PTS`）の1か所を直すと変えられます。

## 操作

- 手札をタップすると少し上がる → もう一度タップで出す。
- 取る札を選ぶときは、動いている札をタップ。
- 札を**長押し**すると大きく表示される。
- 相手の名前の欄をタップすると、その人が取った札が見られる。
- 「📖 札の一覧」：12か月の札（月・花・昔の月の名前・札の種類）と役の点数の表。

## ロボの考え方

- **やさしい**：取れる札があれば取る（どれを出すかはでたらめ）。取れないときは点数の低い札を置く。
- **つよい**：点数の高い札や、自分の役に近づく札をねらう。ほかの人の役になりそうな札を先に取ってじゃまする。取れないときは、取られても困らない札を置く。相手の手札や山札はのぞかない。
