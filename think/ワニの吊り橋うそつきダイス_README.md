# ワニの吊り橋 うそつきダイス（うそを見ぬく はったりゲーム）

ワニのいる川にかかる吊り橋を、サイコロでわたっていく対戦ゲームです。出た目は自分だけが見て「○すすむ！」と言います。**うそをついてもいい**のがポイントで、ほかの人は「うそだ！」か「しんじる」を選びます。

ボードゲーム「チャオチャオ」をヒントに、家族が作った「ボード」と「サイコロ」の道具（コマを手で動かす版）をもとにして、**ルールの進行をアプリがしてくれる**ように作り直したものです。

## 基本情報

- **ファイル**：`ワニの吊り橋うそつきダイス.html`（これ1つで動きます。ネット接続・外部ライブラリは不要）
- **公開ページ**：https://ikechan3351-stack.github.io/ikechan-app/ のトップページ「ゲーム・パズル」から開けます。
- **人数**：2〜4人。1人ずつ「ひと」か「コンピューター（ロボ）」を選べます。1人でもロボと遊べます。
- **対応する機器**：タブレット・パソコン・スマホ・電子黒板。**1台をみんなで回して**遊びます。

## ルール

1. 自分の番になったら、ほかの人に見えないようにサイコロ（コップの中）をふる。
2. サイコロの目は **1・2・3・4・❌・❌**。出た数を「○すすむ！」と言う。うそでもよい。❌ が出たら、うそをつくしかない。
3. ほかの人は「うそだ！」か「しんじる」を選ぶ。
   - 「うそだ！」→ コップをあけて確かめる。ほんとうなら言った数だけ進む。うそならコマはワニの川へ落ちる。
   - だれも疑わない → 言った数だけ進む。
4. 板は8まい。こえるとゴール。**ゴールに2こ** わたらせた人の勝ち。
5. コマは1人7こ。落ちたら次のコマがスタートから出なおす。全部落ちたら、その人はおしまい。
6. 疑ってはずれても、疑った人に罰はありません。

## コンピューター（ロボ）の考え方

- 言う数：ふつうは本当の数を言い、ときどき（約15%）大きい数でうそをつく。❌ のときは、ゴールにとどく数を言うことが多い。
- 疑うかどうか：大きい数ほど、またゴールにとどく数ほど「うそだ！」と言いやすい。

## 使い方のコツ

- 人どうしで遊ぶときは、手番の人に「🙈 ほかの人は見ないでね」と表示されます。画面を自分の方に向けてサイコロをふりましょう。
- 「うそだ！」のボタンには名前がついているので、だれが疑ったかを押し分けます。
- 音は画面下の「🔊 音」で消せます。

## 授業での使い方の例

- 学級活動・雨の日の休み時間に、グループで1台。
- 「4すすむ」は本当に言っていいのか？ ❌ が出る確率は 6回に2回（3分の1）…など、**確率（中2）の導入の話題**にもなります。
