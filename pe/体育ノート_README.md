# 🤸 体育ノート（マット運動）

わざの動画をとって・はって、お手本とならべてスローでくらべ、ポイントごとにふりかえるアプリです。
対象：小学1〜6年（1・2年／3・4年／5・6年で わざを切りかえ）。Chromebook での利用を想定しています。

## できること

| 機能 | 内容 |
|---|---|
| わざえらび | 学年のまとまりごとに、マット運動のわざ（全22種）をカードでえらぶ |
| ポイント | わざごとに3〜4つのポイント。ふりがな付き、🔊で読み上げ |
| じぶんの動画 | 📹 カメラでとる（3びょう・10びょう まってから とれる、最大60秒）／📁 動画ファイルをえらぶ |
| スロー再生 | 0.25倍・0.5倍・ふつう、コマおくり・コマもどし、くりかえし、左右はんてん |
| お手本 | ファイル・YouTube・Googleドライブ・動画のURL・カメラ撮影のどれからでも入れられる。じぶんや友だちの動画を「お手本にする」こともできる |
| くらべる | お手本と、または まえの じぶんと、左右にならべて「いっしょに再生」。🚩でスタート位置をそろえられる |
| ふりかえり | ポイントごとに ◎できた・○だいたい・△もう少し、気づいたこと・つぎのめあてを書く（自動で保存） |
| ダウンロード | 動画をファイルにして、ロイロノートや Google Classroom で提出できる |

## 動画の保存場所（大事）

- 動画は **その端末のブラウザの中（IndexedDB）だけ** に保存されます。インターネットには送られません。
- ブラウザの「閲覧履歴データの削除」をすると消えます。ほかの端末からは見られません。
- シークレットモードでは保存できません。
- 残しておきたい動画は「💾 ダウンロード」で提出・保存してください。

## 先生用（電子黒板）

- 画面の下の「👩‍🏫 先生用」か、アドレスに `?teacher=1` を付けると先生用になります。
- 文字が大きくなり、お手本を大きく映せます。ポイントはタップで1つずつひらきます（「ぜんぶ ひらく」もあり）。
- **お手本つきリンク**：YouTube や Googleドライブのリンクでお手本を入れておき、トップの「🔗 お手本つきリンクを つくる」を押すと、お手本入りのリンクができます。子どもがそのリンクをひらくと、お手本が入った状態になります（ファイルで入れたお手本はリンクに入りません）。
- Googleドライブの動画は「リンクを知っている全員」が見られるようにしておいてください。Googleドライブのリンクでは、スロー再生とコマおくりは使えません（ダウンロードしてファイルで入れると使えます）。
- 学校の設定で YouTube が見られない場合は、ファイルで入れてください。

## アドレスでの指定

| 書き方 | 意味 |
|---|---|
| `?teacher=1` | 先生用 |
| `?waza=zenten` | そのわざのページをひらく（わざの id は HTML の `WAZA` を参照） |
| `?band=1`〜`3` | 1・2年／3・4年／5・6年 |
| `?grade=4` | 学年から まとまりをえらぶ |

## わざを増やすには

HTML の中の `WAZA` に1行足します。`{漢字|よみ}` と書くとふりがなになります。
跳び箱・鉄棒も同じ形で増やせるようにしてあります（今後の予定）。
